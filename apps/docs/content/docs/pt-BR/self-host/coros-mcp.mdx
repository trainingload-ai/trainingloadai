# Conexão COROS

A auto-hospedagem atualmente não oferece suporte a uma conexão direta com o COROS. Exporte um arquivo de atividade suportado (FIT, TCX ou GPX) da plataforma de origem e [envie-o para o Trainingload.ai](/pt-BR/docs/guide/upload-activity-files).

As conexões pessoais suportadas na auto-hospedagem são:

- [Intervals.icu](/pt-BR/docs/self-host/configuration)
- [Garmin Personal API](/pt-BR/docs/self-host/garmin-personal-api)

Para a Nuvem, consulte o [guia de conexão de plataformas](/pt-BR/docs/guide/connect-third-party-platforms).
