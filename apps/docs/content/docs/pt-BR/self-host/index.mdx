# Auto-hospedagem

A auto-hospedagem permite usar o Trainingload.ai no seu próprio computador ou servidor. Suas atividades, planos de treino e arquivos enviados ficam no seu dispositivo, e você acompanha e gerencia os treinos pelo navegador.

Cada instância auto-hospedada é voltada para uma única pessoa. Você cuida do dispositivo, das atualizações do software e dos backups. Se preferir abrir o aplicativo e começar imediatamente, leia [Auto-hospedagem vs. Nuvem](/pt-BR/docs/self-host/self-host-vs-cloud) primeiro.

## O que você pode fazer

- Importar atividades e analisar detalhes, linha do tempo e carga de treino.
- Organizar os treinos no calendário e comparar treinos planejados com concluídos.
- Enviar arquivos FIT, GPX ou TCX, ou conectar Intervals.icu e Garmin Personal API com chaves pessoais.
- Configurar seu próprio serviço de IA para usar o Treinador de IA, ou manter a IA desativada.

## O que preparar antes de instalar

- Um dispositivo que atenda aos [requisitos de instalação](/pt-BR/docs/self-host/installation), com Docker Compose instalado.
- Espaço em disco suficiente para seus dados de treino e arquivos enviados.
- Um local separado para guardar backups e conseguir recuperar os dados em caso de falha do dispositivo.

Use um pacote oficial, versionado e assinado e siga o guia para verificá-lo antes da instalação. Você não precisa compilar o código-fonte nem montar contêineres manualmente. O Docker Compose é o método de instalação atualmente suportado.

## Para onde vão seus dados

Atividades, planos e arquivos enviados são salvos no seu dispositivo. Conectar uma plataforma de treino envia ou recebe dados de acordo com as opções de sincronização escolhidas. Usar um serviço externo de IA envia ao provedor selecionado as informações de treino necessárias para responder àquela solicitação.

A IA vem desativada por padrão. Para habilitá-la, siga o [guia de configuração](/pt-BR/docs/self-host/configuration) e informe sua própria chave de API do provedor. A cobrança pelo uso da API é feita por esse provedor.
