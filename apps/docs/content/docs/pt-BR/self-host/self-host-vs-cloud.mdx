# Auto-hospedagem vs. Nuvem

Escolha a Nuvem se quiser começar a usar o Trainingload.ai diretamente. Escolha a auto-hospedagem se quiser manter seus dados de treino no seu próprio computador ou servidor e tiver disponibilidade para instalar e manter a aplicação.

## Comparação rápida

| O que importa para você | Nuvem | Auto-hospedagem |
| --- | --- | --- |
| Primeiros passos | Abra o aplicativo e crie uma conta | Baixe o pacote de lançamento e siga o guia de instalação no seu dispositivo |
| Onde ficam seus dados | Serviço em nuvem do Trainingload.ai | Seu dispositivo, incluindo atividades, planos e arquivos enviados |
| Importação de treinos | Conecte uma plataforma suportada ou envie arquivos de atividade | Envie arquivos de atividade ou conecte Intervals.icu e Garmin Personal API com chaves próprias |
| Uso do Treinador de IA | Use a franquia de IA incluída no plano da sua conta | Desativada por padrão; configure seu próprio serviço de IA e pague diretamente ao provedor |
| Contas | Use sua conta na Nuvem | Uma pessoa por instância auto-hospedada |
| Backups e recuperação | O Trainingload.ai mantém o serviço em nuvem | Você salva os backups e faz a restauração quando necessário |
| Atualizações do software | O Trainingload.ai atualiza o serviço | Você segue o guia de atualização para instalar uma nova versão |

## Qual opção atende melhor ao seu perfil?

**Escolha a Nuvem** se você quer dedicar seu tempo a treinar e revisar sessões, sem precisar instalar software, executar atualizações ou gerenciar backups por conta própria.

**Escolha a auto-hospedagem** se você quer armazenar seus próprios dados de treino, consegue manter um dispositivo rodando a aplicação e vai cuidar das atualizações e dos backups. A auto-hospedagem é para uso pessoal; uma única instância não suporta múltiplos usuários.

## Confira como você vai importar treinos

A auto-hospedagem atualmente suporta:

- upload de arquivos de atividade **FIT, GPX e TCX**;
- conexão com **Intervals.icu** usando uma chave de API pessoal;
- conexão com **Garmin Personal API** usando uma chave de API pessoal.

Se você depende de uma plataforma específica, confira primeiro [Conectar dados](/pt-BR/docs/guide/connect-data) e as [configurações de conexão na auto-hospedagem](/pt-BR/docs/self-host/configuration#connect-intervalsicu). A Nuvem e a auto-hospedagem oferecem métodos de conexão diferentes. Se outra plataforma permitir exportar um arquivo de atividade suportado, você pode enviá-lo manualmente.

**O Trainingload.ai atualmente não oferece suporte a um aplicativo para Apple Watch.**

## Como a IA funciona e quanto custa

A IA vem desativada por padrão. Você pode usar todos os recursos sem IA sem precisar configurá-la. Para usar o Treinador de IA, escolha um provedor nas configurações e informe sua própria chave de API; veja [Configurar IA](/pt-BR/docs/self-host/configuration#configure-ai-in-the-client).

A auto-hospedagem não utiliza assinaturas nem créditos de IA da Nuvem do Trainingload.ai. O provedor de IA escolhido cobra diretamente pelo uso da API.

Quando você usa um serviço de IA externo, as informações de treino necessárias para aquela pergunta são enviadas a esse provedor. Instalar a aplicação localmente não faz um serviço externo de IA rodar localmente. A sincronização com plataformas de treino também exige conexão com a internet.

## O que você precisará manter

- Manter espaço livre suficiente no dispositivo e deixar a aplicação em execução quando precisar dela.
- Fazer backup antes de atualizar e guardar uma cópia fora do dispositivo onde a aplicação roda.
- Verificar se seus backups podem ser restaurados, garantindo uma cópia utilizável caso o dispositivo falhe.
- Seguir o [guia de gerenciamento e atualização](/pt-BR/docs/self-host/operations) para atualizar a aplicação.

## Próximo passo

Para a Nuvem, [abra o aplicativo](https://app.trainingload.ai/en) e siga [Primeiros passos](/pt-BR/docs/guide/getting-started) para importar sua primeira atividade.

Para auto-hospedagem, comece pelo [guia de instalação](/pt-BR/docs/self-host/installation). As etapas de instalação, backup e atualização são detalhadas em seus respectivos guias.
