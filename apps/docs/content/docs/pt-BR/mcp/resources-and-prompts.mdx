# Recursos e prompts do MCP

Esta página é gerada a partir do catálogo de conteúdo MCP do servidor. Não a edite diretamente; execute `pnpm --dir apps/server mcp:reference`.

Os recursos (resources) oferecem aos clientes orientações estáveis sobre métricas, segurança e capacidades autorizadas sem ler dados adicionais do atleta. Os prompts produzem modelos estruturados de perguntas; os dados reais continuam vindo das ferramentas protegidas por escopos (scopes) OAuth.

## Recursos

| URI | Nome | Finalidade |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | Guia de interpretação de métricas do TrainingLoad | Definições e limites de interpretação para carga, ATL, CTL, TSB, faixas de prontidão, cobertura e dados ausentes. |
| `trainingload://guide/privacy-and-safety` | Guia de privacidade e segurança do TrainingLoad | Limites de somente leitura, tratamento de texto não confiável, limites de dados de saúde e classes de dados excluídas. |
| `trainingload://catalog/capabilities` | Catálogo de capacidades autorizadas do TrainingLoad | Nomes, descrições e escopos (scopes) OAuth das ferramentas somente leitura autorizadas no momento. |
