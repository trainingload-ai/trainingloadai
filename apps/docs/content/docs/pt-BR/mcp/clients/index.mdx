# Guias de clientes

Escolha o cliente que você utiliza. Todos os guias conectam ao mesmo endpoint usando o OAuth do TrainingLoad e não exigem chave de API.

- [ChatGPT](/pt-BR/docs/mcp/clients/chatgpt)
- [Codex](/pt-BR/docs/mcp/clients/codex)
- [Claude Code](/pt-BR/docs/mcp/clients/claude-code)
- [Claude Desktop](/pt-BR/docs/mcp/clients/claude-desktop)
- [Cursor](/pt-BR/docs/mcp/clients/cursor)
- [VS Code](/pt-BR/docs/mcp/clients/vscode)
- [opencode](/pt-BR/docs/mcp/clients/opencode)

Após a configuração, use o [checklist de aceite compartilhado](/pt-BR/docs/mcp/connect#checklist-de-aceite-para-cada-cliente) para verificar o OAuth, a descoberta de ferramentas e a primeira chamada.
