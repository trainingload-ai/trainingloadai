# Termos e estados do produto

Consulte aqui nomes ou status desconhecidos para entender o que significam e o que fazer em seguida.

## Termos comuns

| Termo | Significado |
| --- | --- |
| Perfil do atleta | Fuso horário, unidades, limiares, zonas, preferências e contexto esportivo usados para interpretar o treino |
| Plano de treino | Um cronograma de treinamento com treinos individuais que você pode salvar como rascunho, ativar ou encerrar |
| Treino planejado | O que estava previsto para uma data específica, incluindo esporte, estrutura, duração, intensidade e carga esperada quando disponível |
| Atividade concluída | O que foi realmente gravado, sincronizado ou enviado a partir de um dispositivo ou plataforma |
| Vínculo plano–atividade | Uma relação explícita que indica que uma atividade concluída corresponde a um treino planejado específico |
| Estado atual | Carga de treino recente, dados de recuperação, feedback subjetivo e outros contextos usados na decisão de hoje |
| Revisão | Uma interpretação de uma atividade, dia, semana, mês ou plano com base nas evidências disponíveis |
| Operação de IA | Uma ação proposta ou executada, como criar, mover ou alterar um treino planejado |

## Estados da atividade

| Estado | O que significa | O que fazer |
| --- | --- | --- |
| Enviando ou importando | O arquivo ou pacote da plataforma ainda está sendo transferido | Aguarde antes de tentar novamente |
| Processando | A atividade existe, mas os dados derivados ainda podem estar incompletos | Não interprete carga ou gráficos ausentes ainda |
| Pronto | A análise da atividade foi concluída | Revise os dados que a origem realmente forneceu |
| Falhou | A importação ou o processamento não pôde ser concluído | Leia o erro exibido e consulte a solução de problemas |
| Duplicata | A mesma atividade de origem ou arquivo equivalente já existe | Verifique o registro existente e evite importar o mesmo treino duas vezes |

## Estados do plano e do treino

| Estado | O que significa |
| --- | --- |
| Rascunho | O plano ainda pode ser revisado ou editado antes de se tornar o plano atual |
| Ativo | O plano que você está seguindo, com os treinos exibidos nas datas agendadas |
| Concluído | O período do plano terminou e continua disponível para consulta |
| Planejado | Um treino está agendado, mas ainda não tem resultado final de execução |
| Treino concluído | Um treino planejado está marcado como concluído, geralmente com uma atividade vinculada ou registro explícito de conclusão |
| Pulado | O treino não foi realizado intencionalmente |
| Atividade não planejada | Uma atividade concluída não corresponde a nenhum treino agendado |

## Carga, revisão e créditos

- **Carga de treino** é uma estimativa derivada da dose de treinamento. Sua disponibilidade depende do esporte, duração, dados de sensores, limiares e regras de fonte de carga.
- **Revisão do treinador** é uma interpretação baseada em evidências — não é dado bruto do dispositivo nem diagnóstico médico.
- **Créditos de IA** são unidades de uso para operações de IA elegíveis. O extrato de créditos descreve consumo; não descreve carga de treino nem permissões da conta.
- **Conta Demo** permite navegar por dados de exemplo. Faça login na sua conta para salvar alterações, importar atividades ou trabalhar com seus próprios registros de treino.
