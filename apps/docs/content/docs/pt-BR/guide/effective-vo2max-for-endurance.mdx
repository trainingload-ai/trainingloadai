# Effective VO2max for Endurance Decisions

effective VO2max is most useful as a trend signal.
Use it to validate whether current training stress is producing useful adaptation.

## What it does well

- Flags medium-term changes in performance response.
- Helps detect stagnation earlier than race-day feedback.
- Improves context for load adjustments.

## What it cannot do alone

- It cannot explain execution quality by itself.
- It cannot replace pacing, power, and heart-rate analysis.
- It should not be treated as a single-score verdict.

## How to use it with load metrics

Pair effective VO2max with:

- [ATL](/docs/metrics/pmc/acute-training-load) for recent stress.
- [TSB](/docs/metrics/pmc/training-stress-balance) for freshness.
- [Training Stress Score](/docs/metrics/training-load/training-stress-score) for session load.

If effective VO2max stalls while ATL stays high, reduce intensity before increasing volume.

## Suggested review cadence

- Daily: scan for abrupt drift and obvious recovery issues.
- Weekly: compare trend direction with plan completion.
- Block-end: confirm whether adaptation matched objective.
