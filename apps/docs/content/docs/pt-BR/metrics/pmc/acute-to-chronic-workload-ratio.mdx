# O que é ACWR?

A **razão de carga aguda:crônica (ACWR)** compara a carga recente modelada com a carga de longo prazo. No Trainingload.ai, A:C é a [Fadiga (ATL)](/pt-BR/docs/metrics/pmc/acute-training-load) de hoje dividida pelo [Condicionamento físico (CTL)](/pt-BR/docs/metrics/pmc/chronic-training-load) de hoje.

Ela pode destacar uma mudança de contexto, mas não prevê lesão nem prontidão.

```text
ACWR_today = ATL_today / CTL_today
```

Com ATL 60 e CTL 50, a ACWR é `1.20`. Se a CTL for zero, o produto retorna `0`.

O Trainingload.ai usa uma **razão exponencial acoplada do PMC**: a carga de hoje entra tanto na ATL, com constante de tempo de sete dias, quanto na CTL, com constante de 42 dias. Não é uma média simples de 7/28 dias nem uma variante desacoplada.

Acima de 1, ATL supera CTL; perto de 1, as curvas são semelhantes; abaixo de 1, ATL é menor. A razão esconde a escala: `12 / 10` e `120 / 100` resultam em 1,20. Uma CTL muito pequena também pode gerar valor alto após uma única sessão.

As faixas `<0.8`, `0.8–<1.3`, `1.3–<1.5` e `≥1.5` são regras visuais, não evidência de estado ótimo, seguro ou perigoso.
