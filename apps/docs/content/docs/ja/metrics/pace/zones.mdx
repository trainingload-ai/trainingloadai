# Pace Zones

**ペースゾーン** は、ランニング強度を管理するための直接的で実用的な方法です。心拍より反応が速く、暑さや心拍ドリフトの影響を受けにくい場面があります。

Trainingload.ai は **Functional Threshold Pace (FTPa / Threshold Pace)** を基準にしたクラシックなゾーンモデルを使います。

## FTPa とは

FTPa は、およそ 1 時間全力に近く維持できる最速ペースです。

- エリートではハーフマラソンから 15K ペースに近いことがあります。
- 市民ランナーでは 10K ペース前後または少し遅いことが多いです。

## ゾーン定義

| Zone    | 名称      | % FTPa    | 主な目的                     |
| :------ | :-------- | :-------- | :--------------------------- |
| **Z1**  | Recovery  | > 129%    | 回復、循環促進               |
| **Z2**  | Aerobic   | 114%-129% | 有酸素ベース                 |
| **Z3**  | Tempo     | 106%-113% | テンポ、マラソン寄りの持続力 |
| **Z4**  | Threshold | 100%-105% | 乳酸処理、閾値向上           |
| **Z5a** | VO2max    | 90%-99%   | VO2max インターバル          |
| **Z5b** | Anaerobic | < 90%     | スプリント、無酸素能力       |

> ペースの割合は時間ベースです。数字が大きいほど遅いペースになります。

## Trainingload.ai のアドバイス

- 平坦で条件が良い日はペースを重視する。
- 暑さ、湿度、向かい風、疲労が強い日は心拍も合わせて見る。
- 4-6 週間ごとに FTPa を見直す。
