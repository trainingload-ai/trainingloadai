# 急性・慢性負荷比（ACWR）とは

**ACWR** は、モデル化された直近負荷と長期負荷を比較する比率です。Trainingload.ai では、当日の[疲労（ATL）](/ja/docs/metrics/pmc/acute-training-load)を当日の[フィットネス（CTL）](/ja/docs/metrics/pmc/chronic-training-load)で割ります。

負荷の変化を見つける手掛かりにはなりますが、傷害やレディネスを予測する指標ではありません。

```text
ACWR_today = ATL_today / CTL_today
```

ATL が 60、CTL が 50 なら ACWR は `1.20` です。CTL が 0 の場合、0 除算を避けるため製品は `0` を返します。

Trainingload.ai が使うのは**結合型の指数 PMC 比**です。当日負荷は、時定数 7 日の ATL と 42 日の CTL の両方に入ります。単純な 7 日／28 日平均でも、直近期間を除外する非結合型でもありません。

1 より大きければ ATL が CTL を上回り、1 付近なら近く、1 未満なら下回ります。ただし、`12 / 10` と `120 / 100` はどちらも 1.20 です。CTL が小さい時期は、1 回の負荷でも比率が大きくなり得ます。

`<0.8`、`0.8–<1.3`、`1.3–<1.5`、`≥1.5` は表示ルールです。「最適」「安全」「危険」を証明する区分ではありません。
