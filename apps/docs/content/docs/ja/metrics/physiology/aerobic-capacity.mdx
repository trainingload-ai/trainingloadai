# Aerobic Capacity

持久系トレーニングでは、**有酸素能力** はほぼ **VO2 Max** と同じ意味で使われます。最大努力時にどれだけ酸素を使えるかを表し、通常は体重あたりの `ml/kg/min` で表されます。

エンジンの大きさのようなもので、天井が高いほど高い強度を維持する余地が増えます。ただし、パフォーマンスを決めるのは VO2 Max だけではありません。

## 特徴

- **上限を表す**: 最大に近づくと、酸素利用を意志だけで大きく引き上げることはできません。
- **単発値よりトレンド**: 時計やプラットフォームの VO2 Max は推定値で、暑さ、坂、疲労、センサー誤差で揺れます。
- **成績のスイッチではない**: 同じ VO2 Max でも、閾値、ランニングエコノミー、耐久性で結果は変わります。

## 推定

### ラボテスト

ガス分析を伴う漸増負荷テストが、もっとも「真の VO2 Max」に近い方法です。

### フィールド推定

日常のトレーニング判断には、繰り返しやすいフィールド推定の方が役立つこともあります。

## Aerobic capacity と aerobic threshold

- **Aerobic capacity (VO2 Max)** は天井です。
- **Aerobic threshold (AeT)** は土台です。

良い持久系トレーニングは天井を上げるだけでなく、AeT や AnT を VO2 Max に対して高い割合まで押し上げます。
