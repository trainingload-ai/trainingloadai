# 無酸素性作業閾値とは？AnTと閾値トレーニングの境界

**無酸素性作業閾値（AnT）** は、しばらく維持できる巡航強度から、疲労が急に溜まる強度への境界です。閾値トレーニングの基準に使われ、FTP、閾値心拍、閾値ペースの近くに置かれることが多いですが、それらはフィールドの近似であり、同じ検査定義ではありません。

多くのトレーニングシステムでは、閾値トレーニングの中心基準として使われ、FTP と一緒に語られることもあります。

## 特徴

- **限られた持続時間**: 多くの選手では、数十分から約 1 時間維持できる強度に近い。
- **境界を超えると高コスト**: 少し上げるだけで維持が急に難しくなります。
- **定義に幅がある**: ガス交換、血中乳酸など測定方法で数値が変わることがあります。

## 実用的な推定

ラボがない場合は、再現しやすいフィールドテストを使います。

- 20 分の一定全力走。
- 平均パワー、ペース、心拍を取り、実用的な補正をかける。

## トレーニングでの意味

AnT が上がると、より高い「持続可能な」強度で走れるようになります。ただし、パフォーマンスには経済性、耐久性、補給、ペーシングも関わります。

## よくある質問

### 無酸素性作業閾値とは？

ほぼ定常で維持できる上限強度です。それを超えると同じペースやパワーを長く保てなくなります。

### 乳酸閾値と同じですか？

近い強度帯を指すことが多いですが、測り方が違います。乳酸閾値は血中乳酸、AnT はガス交換や乳酸の折れ点を使うことがあります。数字を同一視しないでください。[乳酸閾値](/ja/docs/metrics/physiology/lactate-threshold)を参照。

### ラボなしでどう推定しますか？

再現しやすいフィールドテスト、よくあるのは 20 分のできるだけ一定な全力走です。平均パワー、ペース、心拍を取り、実務的な補正をかけます。FTP 推定と同じ発想です。

### FTPやLTHRとの関係は？

FTP、LTHR、閾値ペースは同じ強度帯の実用的な代替です。信頼できる閾値があると、Trainingload.ai は閾値セッションの分類とゾーン校正に使います。
