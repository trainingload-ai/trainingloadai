# Lactate Threshold (LT)

日常のトレーニングでは、**Lactate Threshold (LT)** は [Anaerobic Threshold (AnT)](./anaerobic-threshold) に近いものとして扱われることが多いです。ただし、定義と測定方法は違うため、数値が完全に一致するとは限りません。

## 定義と測定

- **LT**: 漸増負荷テスト中に血中乳酸を測って決めることが多い。
- **AnT**: ガス交換または乳酸の変曲点など、定義によって決まります。

一部では 4 mmol/L の固定値を使いますが、それが全員の本当の閾値という意味ではありません。

## 実用的な意味

用語が LT、AnT、OBLA などに分かれていても、トレーニング上の要点は同じです。

- 長く維持できる最高に近い強度の目安。
- テンポ走、閾値走、持続インターバルの基準。

## なぜ乳酸が重要か

乳酸は「毒」ではなく、糖代謝の副産物であり燃料でもあります。強度が上がると、乳酸蓄積に伴う反応が筋の焼ける感覚や出力低下と関係します。LT は、強度と持続可能性を結びつける実用的なマーカーです。
