# Anaerobic Capacity

**無酸素能力** は、短い時間にどれだけ大きな「バースト」エネルギーを使えるかを表します。スプリント、急加速、短い急坂で現れます。

## 特徴

- **短時間**: 数秒から数十秒の領域で重要です。
- **定常的な体力とは別**: 閾値や有酸素ベースとは違う能力です。
- **典型場面**: フィニッシュスプリント、アタックへの反応、短い登り。

## トレーニングでの意味

マラソンやロングトライアスロンでは中心的ではないことが多い一方、ロードレースやトレイルなど、変化への対応が必要な競技では重要です。

持続できないけれど決定的な「ターボ」のような能力です。
