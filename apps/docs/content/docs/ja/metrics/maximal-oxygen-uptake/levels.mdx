# VO2 Max Levels

> このページの VO2 Max 値はすべて **推定値** であり、ラボ測定 VO2 Max ではありません。読みやすさのため、推定 VO2 Max も VO2 Max と呼びます。

Trainingload.ai は、推定 VO2 Max を 5 段階に分類し、現在の有酸素フィットネスをすばやく読めるようにします。

## VO2 Max レベルとは

VO2 Max レベルは、`ml·kg⁻¹·min⁻¹` で表される連続値を、実用的なフィットネス段階へ変換する方法です。

役立つ場面:

- 現在位置をすばやく読む。
- 同じデバイス/アルゴリズムで長期トレンドを見る。
- 年齢と性別を考慮して比較する。

先に推定したい場合:

- [VO2 Max Calculator](/ja/vo2-max-calculator)

VO2 Max の意味を詳しく知りたい場合:

- [VO2 Max (Maximal Oxygen Uptake)](/ja/docs/metrics/maximal-oxygen-uptake)

## 良い VO2 Max レベルとは

「良い」は年齢、性別、競技、トレーニング歴で変わります。実用的には、年齢と性別の閾値を参考にしつつ、自分自身の長期トレンドを重視します。

## 年齢または性別がない場合

| Level     | VO2 Max (ml·kg⁻¹·min⁻¹) |
| :-------- | :---------------------- |
| Excellent | ≥ 50                    |
| Very Good | ≥ 40 and < 50           |
| Good      | ≥ 35 and < 40           |
| Fair      | ≥ 30 and < 35           |
| Poor      | < 30                    |

## Garmin VO2 Max レベルは信頼できるか

Garmin の VO2 Max はモデル推定です。ラボ測定ではありません。

実用上は:

- 同じデバイス/エコシステム内で比較する。
- ブランド間で生値を比べない。
- 5K/10K など再現しやすい努力でクロスチェックする。

## 血中酸素と VO2 Max は同じか

- **血中酸素 (SpO₂)**: 今この瞬間の血液中酸素飽和度。
- **VO2 Max**: 強い運動中に酸素経路全体が発揮できる最大能力。

関連する場面はありますが、同じ指標ではありません。

## VO2 Max レベルを上げるには

- 一貫した有酸素ベース（イージー / Z2 ボリューム）
- 周期的な VO2 強度インターバル
- 十分な回復を伴う漸進的な負荷増加
