# W' (Anaerobic Work Capacity)

**W'**（W prime）は、**無酸素性作業容量** を表します。通常はジュールで表され、**[Critical Power (CP)](/ja/docs/metrics/power/critical-power)** を超えて運動するときに使える有限のエネルギー量です。

## 基本イメージ

パフォーマンスは 2 つに分けて考えられます。

1. **有酸素エンジン (CP)**: CP 以下なら長く続けられる土台。
2. **無酸素バッテリー (W')**: CP を超えた瞬間から消費される有限の予備エネルギー。

## W' の消費と回復

- **消費**: パワーが CP を超えると、`現在のパワー - CP` に応じて W' が減ります。
- **回復**: パワーが CP を下回ると、W' は回復し始めます。CP から大きく下げるほど回復しやすくなります。

## 「空になる」とは

W' が 0 になっても、動けなくなるわけではありません。**CP を超えるパワーを維持できなくなる** という意味です。

## 実用例

- **レースペーシング**: 短い TT や登坂で、ゴール付近で W' を使い切るように配分する。
- **インターバル分析**: W' balance を見て、無酸素容量をどれだけ使ったか確認する。
