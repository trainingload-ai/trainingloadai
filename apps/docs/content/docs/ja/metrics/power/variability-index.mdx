# Variability Index (VI)

**Variability Index (VI)** は、パワーの変動度を表す指標です。

```text
VI = Normalized Power / Average Power
```

## どう読むか

- **VI ≈ 1.00**: かなり一定した努力。
- **VI 1.05 前後**: 少し変動があるが、持久系イベントではよくある範囲。
- **VI が高い**: インターバル、アタック、信号停止、地形変化などで強度が大きく揺れている。

## なぜ重要か

同じ平均パワーでも、上げ下げが多い走りは生理的コストが高くなります。VI は、ペーシングの安定性を確認するために役立ちます。

## 実用例

- **TT / トライアスロン**: VI は低いほど効率的なことが多い。
- **ロードレース**: 高い VI はレース展開やアタックへの反応を反映します。
- **ロングライド**: VI が高すぎる場合、無駄な加速が多い可能性があります。
