# トレーニング指標用語集

最終更新：2026年5月23日

このページは Trainingload.ai の持久系トレーニング指標用語集です。トレーニング負荷、PMC、パワー、心拍、ペース、VO2 Max、生理学ドキュメントで使われる主要な概念を整理し、各用語から詳しい解説ページへ移動できます。

トレーニング指標は組み合わせて読むと役立ちます。負荷指標はトレーニング量、心拍は身体内部の反応、パワーとペースは外部出力、生理学指標は能力の土台や制限要因を説明します。1つの数値だけで状態を判断するのは避けます。

## クイック定義

| 用語 | 簡単な意味 | 主な使い方 |
| --- | --- | --- |
| training load | 一定期間のトレーニングが身体に与えたストレス。 | 積む、維持する、回復する判断。 |
| PMC | Performance Management Chart。通常は CTL、ATL、TSB を一緒に見る。 | フィットネス、疲労、フォームを同時に確認する。 |
| CTL | Chronic Training Load。長期的な負荷傾向。 | トレーニングが持続的に積み上がっているか確認する。 |
| ATL | Acute Training Load。短期的な負荷または疲労傾向。 | 重要セッション前の短期ストレスを見る。 |
| TSB | Training Stress Balance。CTL と ATL から見た新鮮さの推定。 | ハード練習、回復、テーパーのタイミング判断。 |
| TSS | Training Stress Score。時間と強度に基づくトレーニングストレス。 | ワークアウトや週ごとの負荷比較。 |
| TRIMP | Training Impulse。心拍ベースの負荷推定。 | パワーがない場合の内部負荷推定。 |
| FTP | Functional Threshold Power。実用的な閾値パワー基準。 | パワーゾーンとワークアウト目標設定。 |
| CP | Critical Power。モデル化された持続可能パワー境界。 | パワー持続能力と W′ の理解。 |
| LTHR | Lactate Threshold Heart Rate。乳酸閾値心拍の実用基準。 | 心拍ゾーン設定。 |
| VO2 Max | 最大酸素摂取量、または推定された有酸素能力指標。 | 有酸素能力の傾向確認。 |

## この用語集の使い方

このページは地図として使います。今日押すべきか回復すべきかを判断したい場合は、training load、PMC、CTL、ATL、TSB から見ます。強度を設定したい場合は、FTP、CP、LTHR、パワーゾーン、心拍ゾーン、ペースゾーンを見ます。長期的な能力反応を確認したい場合は、VO2 Max、effective VO2max、生理学指標も合わせます。
