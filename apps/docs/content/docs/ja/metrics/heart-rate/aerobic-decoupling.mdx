# Aerobic Decoupling

**Aerobic Decoupling**（心拍デカップリング / cardiac drift）は、一定努力の中で心拍とパワーまたはペースの関係がどれだけズレていくかを見る指標です。

## 基本概念

理想的な有酸素状態では、**入力**（心拍）と **出力**（パワーまたはペース）が安定して対応します。

長い一定強度の運動中に次のどちらかが起きると、デカップリングがあると考えます。

1. パワーやペースは近いのに、心拍が徐々に上がる。
2. 心拍は近いのに、パワーやペースが徐々に落ちる。

これは疲労、暑さ、脱水、補給不足、または強度設定の高さを反映することがあります。

## 計算の考え方

一定状態のワークアウトを前半と後半に分け、それぞれの Efficiency Factor を比べます。

- **Pw:Hr**: パワーを出力として使う。
- **Pa:Hr**: ペースまたは速度を出力として使う。

$$
Pw:Hr[\%] / Pa:Hr[\%] = \frac{AE_1 - AE_2}{AE_1} \times 100\%
$$

## 5% ルール

Joe Friel の実践的な目安では、**5%** がひとつの境界です。

| デカップリング | 解釈                                                       |
| :------------- | :--------------------------------------------------------- |
| **< 5%**       | 有酸素ベースが安定している                                 |
| **5%-10%**     | まずまずだが、長時間で疲労が出ている                       |
| **> 10%**      | その強度または時間に対して有酸素ベースが不足している可能性 |

## 使い方

長い Z2 セッションや Aerobic Threshold Test で使うのが向いています。短い活動や変動の大きいインターバルでは意味が薄くなります。
