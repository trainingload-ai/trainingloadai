# 週次トレーニングレビュー

## 到達目標

15〜20分の振り返りで、文章にまとめた結論を1つ、主要な調整を多くても1つ、そしてその判断が妥当だったかを検証する日付またはワークアウトを決めて終えます。

## 1. データの網羅性を確認する

[アクティビティ一覧と検索](/ja/docs/guide/activity-feed-search)を開きます。週間合計を見る前に、処理エラー、重複記録、誤ったプラン紐づけを解消しておきます。

## 2. 予定と実績を比較する

[カレンダー](/ja/docs/guide/calendar)と現在のトレーニングプランを使い、完了・短縮・スキップ・代替・予定外それぞれの回数を整理します。達成率の数値だけで1週間を評価しないようにします。

## 3. トレーニング負荷（トレーニング量と質）を確認する

[ダッシュボード](/ja/docs/guide/dashboard)と[トレーニング負荷](/ja/docs/metrics/training-load)を確認します。種目フィルターと対象期間をそろえたうえで、合計値だけでなく変化の要因となった個別セッションを確認します。

## 4. 体の反応と文脈を加える

記録がある場合は、睡眠、HRV、安静時心拍数、セッション RPE、筋肉痛、主観的な疲労感もあわせて確認します。回復データが欠けている場合は判断の確度が下がるだけであり、回復が良好だったとも不良だったとも断定できません。

## 5. 次のアクションを決める

次の中から1つを選びます。

- プランはそのまま維持する。
- セッションを1つ移動する。
- 時間または強度の目標を1つ下げる。
- セッションを1つリカバリーメニューに置き換える。
- トレーニング指導の範囲を超える懸念がある場合は、専門家や医療機関への相談に切り替える。

## レビューの確認

判断の根拠、決定内容、影響する具体的な予定ワークアウト、次回の確認ポイントを書き留めます。[AIコーチ](/ja/docs/guide/ai-coach)を使う場合は、回答が同じ対象期間と根拠に基づいているかを確認してください。
