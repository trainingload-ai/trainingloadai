# トレーニングワークフロー全体像

アクティビティのインポートとトレーニングプランの作成から、実施結果の振り返りまでをこの順序で進めます。各ステップには対応するガイドと、完了を確認するための目安を用意しています。

## トレーニングのループ

| ステップ | 確認する問い | 主なガイド | 完了の目安 |
| --- | --- | --- | --- |
| 1. 基準設定 | 単位・タイムゾーン・閾値・ゾーンは現状に合っているか | [プロフィール・閾値・ゾーン](/ja/docs/guide/profile-thresholds-zones) | 種目と現在の競技力に合ったプロフィールになっている |
| 2. 連携 | どのデータソースからアクティビティと健康データを取り込むか | [データの連携](/ja/docs/guide/connect-data) | 少なくとも1件のアクティビティが Ready 状態になっている |
| 3. 計画 | 現在の目標とスケジュールはどうなっているか | [トレーニングプランを作成する](/ja/docs/guide/create-training-plan) | 内容を確認済みのプランが有効化されている、または有効化できる状態にある |
| 4. 実行 | 今日は何を行うべきか | [今日のトレーニングと現在の状態](/ja/docs/guide/today-and-current-state) | 予定ワークアウトと当日の制約を把握している |
| 5. 記録 | 実際に何を行ったか | [モバイル記録とファイルアップロード](/ja/docs/guide/mobile-recording) | 完了したアクティビティが保存またはインポートされている |
| 6. 突き合わせ | そのアクティビティはどの予定ワークアウトに対応するか | [アクティビティ一覧と検索](/ja/docs/guide/activity-feed-search) | 予定と実績が正しく紐づいている、または意図どおり別扱いにされている |
| 7. 振り返り | そのアクティビティと直近の傾向から何が読み取れるか | [アクティビティ詳細](/ja/docs/guide/activity-detail) | データソース・負荷・チャート・状況から妥当な解釈ができている |
| 8. 判断 | 今後のトレーニングは予定どおりでよいか | [AIコーチ](/ja/docs/guide/ai-coach) | 変更案がある場合は内容が明示され、確認済みである |
| 9. 継続 | 今週とサイクル全体は目標に向かっているか | [週次トレーニングレビュー](/ja/docs/workflow/weekly-review) | 次の確認タイミングと次の重要ワークアウトが明確になっている |

## まずは基本ルートから

新しいアカウントを設定するときや、一連の機能が正しくつながっているか確認したいときは、[最初のトレーニングと振り返りを完了する](/ja/docs/workflow/first-training-cycle)から始めてください。

予定どおりにいかない場面では、状況別のガイドを活用できます。

- [スキップ・短縮・代替・予定外のトレーニングへの対処](/ja/docs/workflow/when-training-changes)
- [アクティビティ・トレーニング負荷・回復データの欠損や異常への対処](/ja/docs/workflow/data-and-load-problems)
- [予定と実績を比較する週次レビュー](/ja/docs/workflow/weekly-review)

## 事実の確認と判断を切り分ける

アクティビティ記録やチャート、AIコーチの回答は判断材料（エビデンス）であり、プランを自動的に書き換えるものではありません。まずデータソースと対象期間を確認し、次にその解釈を整理したうえで、今後のトレーニングを変えるべきかどうかを判断します。
