# 最初のトレーニングと振り返りを完了する

## 到達目標

信頼できるプロフィール、Ready 状態のアクティビティ1件、有効化済みまたは確認済みのトレーニングプラン1件、そして次のワークアウトに関する明確な判断がそろった状態を目指します。

## 始める前に

- ご自身のアクティビティ記録を使用してください。スクリーンショットやファイルを共有する場合は、アカウントの認証情報や自宅の位置情報が含まれていないか事前に確認してください。
- 複数の双方向連携を有効にする前に、まずは主となるインポート経路を1つに決めてください。
- プラットフォーム連携がまだ準備できていない場合は、直近の FIT、TCX、または GPX ファイルを1つ手元に用意しておくとスムーズです。

## 1. アスリートプロフィールを調整する

[プロフィール・閾値・ゾーン](/ja/docs/guide/profile-thresholds-zones)に沿って、タイムゾーン、単位、種目ごとの閾値、優先するトレーニング負荷ソースを確認します。

## 2. 完了済みアクティビティを1件取り込む

継続的に同期したい場合は[データの連携](/ja/docs/guide/connect-data)、まずは1件だけ確実に試したい場合は[アクティビティファイルのアップロード](/ja/docs/guide/upload-activity-files)を使用します。

アクティビティが Ready 状態になるまで待ってください。一覧にカードが表示されただけでは、チャートやトレーニング負荷の計算が完了しているとは限りません。

## 3. アクティビティ記録を確認する

[アクティビティ詳細](/ja/docs/guide/activity-detail)を開き、データソース、開始時刻、時間、距離、心拍数やパワーの有無、ラップ、トレーニング負荷を確認します。取得できなかったセンサーデータは、実測値のように補完されるのではなく欠損のまま扱われるのが正常です。

## 4. トレーニングプランを作成または選択する

[トレーニングプランを作成する](/ja/docs/guide/create-training-plan)の手順でスケジュールを確認し、目標・日程・種目・負荷量が現実的であると判断できてから有効化します。

## 5. 予定と実績を突き合わせる

[カレンダー](/ja/docs/guide/calendar)を開きます。完了したアクティビティが予定ワークアウトと同じセッションであれば紐づけ、無関係なアクティビティや予定外の練習は紐づけずに別扱いのまま残します。

## 6. 次に行うことを決める

[今日のトレーニングと現在の状態](/ja/docs/guide/today-and-current-state)を確認したうえで、[AIコーチ](/ja/docs/guide/ai-coach)に焦点を絞った質問を1つ投げかけます。判断したい内容、対象期間、制約条件、確認してほしい根拠を具体的に伝えると精度が上がります。

## サイクルの完了確認

- プロフィールの単位・タイムゾーン・閾値が意図どおりに設定されている。
- 1件のアクティビティが Ready 状態になり、データソースが実際に提供した項目が正しく表示されている。
- 現在のプランと今日のワークアウトが表示されている。
- 同じセッションに該当する場合のみ、予定と実績が紐づけられている。
- 今後の変更案がある場合は明示されており、後から見直せる状態になっている。

次のステップとして、[週次トレーニングレビュー](/ja/docs/workflow/weekly-review)を実施してみてください。
