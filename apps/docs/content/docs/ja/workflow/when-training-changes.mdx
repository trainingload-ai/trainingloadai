# トレーニングが予定どおりにいかなかったとき

## 到達目標

予定と実績の履歴をありのまま残しつつ、今後のトレーニングへの変更は根拠のある最小限にとどめます。

## 状況に合った記録方法を選ぶ

| 実際に起きたこと | 正しい記録方法 | やってはいけないこと |
| --- | --- | --- |
| ワークアウトをスキップした | 予定ワークアウトをスキップまたは未完了のまま残す | 0分のダミーアクティビティをアップロードする |
| ワークアウトを短縮した | 実際に短くなったアクティビティを予定ワークアウトに紐づける | 目標に合うよう完了済みデータを書き換える |
| 別の内容に差し替えた | 予定していた種別と実際に行った種別の両方が見える状態で残す | 変更を隠すために無関係なアクティビティ名へ書き換える |
| 予定外のワークアウトを行った | 特定の予定を代替した場合を除き、紐づけずに残す | 日付が近い予定ワークアウトに無理やり紐づける |
| 実施日を移動した | 予定変更が実際の判断を反映している場合のみ、予定セッションを移動する | 完了済みアクティビティのタイムスタンプをずらす |

## 調整前に確認する

1. [カレンダー](/ja/docs/guide/calendar)で該当する日を開きます。
2. [アクティビティ一覧と検索](/ja/docs/guide/activity-feed-search)でデータソースと処理ステータスを確認します。
3. [アクティビティ詳細](/ja/docs/guide/activity-detail)でトレーニング負荷とセンサーデータの取得状況を確認します。
4. 今回の変更を、直近の負荷推移、睡眠や回復状況、次の重要ワークアウトと照らし合わせます。
5. 調整が必要と判断した場合は、まず「実施タイミング」「時間」「強度」のうち主要な1要素だけを変更します。

## スケジュール変更を適用する

Web 版または Personal では、対象の日付を右クリックして **Adjust schedule** を選択します。下書き内で今後のワークアウトを移動するか内容を編集し、変更前後の日付と内容を比較したうえで確定します。下書きを保存して後から続けたい場合は、[カレンダーのスケジュール調整手順](/ja/docs/guide/calendar#adjust-upcoming-workouts)を参照してください。

## AIコーチに的確に相談する

たとえば「昨日は睡眠不足のため45分のイージーランを25分に短縮しました。土曜日のロングランは変更すべきですか？」のように、意思決定に直結する質問を投げかけてください。制約を示さずにプラン全体の作り直しを求めるような曖昧なプロンプトは避けるのがポイントです。

## 結果の確認

カレンダー上に「何を予定していたか」「実際に何を行ったか」「なぜ違いが生じたか」「今後のどのワークアウトを変更したか」がそのまま残っていることを確認します。元のアクティビティ記録そのものは変更せず保持してください。
