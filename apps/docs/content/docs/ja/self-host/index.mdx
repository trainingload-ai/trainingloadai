# セルフホスト

セルフホスト版を使うと、ご自身のパソコンやサーバー上で Trainingload.ai を運用できます。アクティビティ、トレーニングプラン、アップロードしたファイルは手元の環境に保存され、ブラウザからトレーニングの確認や管理を行えます。

1つのセルフホストインスタンスは1人専用です。端末の保守、ソフトウェアのアップデート、バックアップの管理はご自身で行います。アプリを開いてすぐに使い始めたい場合は、先に[セルフホストとクラウドの比較](/ja/docs/self-host/self-host-vs-cloud)をご確認ください。

## できること

- アクティビティをインポートし、詳細データ・タイムライン・トレーニング負荷を確認できます。
- カレンダー上でトレーニングを予定管理し、予定ワークアウトと完了済みアクティビティを比較できます。
- FIT・GPX・TCX ファイルのアップロードに加えて、個人用キーで Intervals.icu や Garmin Personal API と連携できます。
- ご自身の AI サービスを設定してAIコーチを利用することも、AI をオフのまま使うこともできます。

## インストール前の準備

- [インストール要件](/ja/docs/self-host/installation)を満たし、Docker Compose が導入された端末。
- トレーニングデータとアップロードファイルを保存できる十分なディスク空き容量。
- 端末故障時に復旧できるよう、バックアップを保管する別の保存先。

インストール前に、公式のバージョン付き署名済みリリースバンドルを使用し、手順に従って検証してください。ソースコードから自前でビルドしたりコンテナを組み立てたりする必要はありません。現在サポートされている導入方式は Docker Compose です。

## データの保存先と外部送信

アクティビティ、トレーニングプラン、アップロードしたファイルはお使いの端末に保存されます。トレーニングプラットフォームを連携した場合は、選択した同期設定に応じてデータが送受信されます。外部 AI サービスを有効にした場合は、そのリクエストの応答に必要なトレーニング情報が選択したプロバイダーへ送信されます。

AI はデフォルトでオフになっています。有効にするには[設定ガイド](/ja/docs/self-host/configuration)に従い、ご自身のプロバイダー API キーを入力してください。API の利用料金はそのプロバイダーから請求されます。
