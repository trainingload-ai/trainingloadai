# Garmin Personal API

セルフホストインスタンスでは、ご自身の Garmin Personal API キーを使って、デバイスおよびアカウントから完了済みアクティビティや、取得可能な睡眠・HRV・安静時心拍数などのデータを取り込めます。

このページはセルフホスト版専用です。クラウド版の認可と履歴インポートについては、[サードパーティプラットフォーム連携ガイド](/ja/docs/guide/connect-third-party-platforms#connect-garmin-for-new-data)を参照してください。

## ご自身のアカウントを連携する

1. Garmin Connect の[個人 API キー設定ページ](https://connect.garmin.com/app/settings/personalApiToken)でキーを作成します。中国リージョンのアカウントをご利用の場合は、対応する Garmin Connect リージョンを使用してください。
2. Trainingload.ai で **Account → Third Party Connections → Garmin → Connection settings** を開きます。
3. アカウントのリージョンを選択し、`Asia/Tokyo` や `Asia/Shanghai` などのタイムゾーンを確認します。
4. 必要に応じてアクティビティのインポート、睡眠・回復データ、定期同期を選択し、キーを貼り付けて接続します。
5. **Sync now** を選択します。日付を空欄にすると直近30日間が対象になります。過去の期間を指定することも可能です。

Garmin のパスワードやブラウザの Cookie を入力する必要はありません。キーはご自身のインスタンス内で暗号化されて保存されます。チャット、Issue、ログには送信しないでください。作成後は安全に保管し、失効または期限切れになった場合は交換してください（有効期限は Garmin 側で表示される設定を確認してください）。

## 同期後に確認する項目

| データ | 確認する結果 |
| --- | --- |
| 完了済みアクティビティ | アクティビティ一覧に該当レコードが表示される。開いてデータソース、時刻、利用可能なチャートを確認する |
| 睡眠・HRV・安静時心拍数・歩数 | 該当日付に Garmin から提供された値が表示される。欠損値が 0 で埋められることはない |
| 体重・ストレス・血中酸素飽和度・Body Battery | Garmin 側の意味を保持したまま表示される。これらの値が ATL・CTL・TSB を置き換えることはない |
| 追加指標 | **Advanced data and operations** から日付指定で読み込める。ローカルのスポーツ設定が自動変更されることはない |
| 栄養・月経データ | 定期同期の対象外。追加で読み込む場合は別途確認が必要 |

取得できる項目はデバイスの記録内容、リージョン、Garmin 側の権限に依存します。すべてのアカウントに表の全項目が存在するわけではありません。接続後は必ず同期結果を確認してください。認識できないデータはエラーとして報告され、空の結果は 0 を意味しません。

この連携は個人データの読み取り専用です。今後の予定ワークアウトを Garmin へ作成・送信する機能はありません。

## 履歴インポートと進捗

- 対象日付を指定してください。期間判定にはアカウントのタイムゾーンが使われます。
- **Queued** はリクエストが保存された状態です。アクティビティが **Imported** として計上されるのは、ダウンロードとインポートが完了した後です。
- 画面を再読み込みしても実行中のタスクは消えません。大量の履歴を取り込む際は繰り返し送信せず完了を待ってください。
- 1回の履歴リクエストで最大10年分を指定できます。所要時間はアクティビティ件数と Garmin 側の制限に依存します。
- 再同期すると毎回コピーが増えるのではなく、既存の Garmin レコードが照合・更新されます。
- 一部の項目が失敗した場合は表示されるエラーを確認してください。正常に読み取れた他の項目はそのままインポートが完了する場合があります。

定期同期を使うには、連携設定で該当オプションを有効にしてください。検出レコード件数（discovered）とインポート成功件数は一致しない場合があります。

## キーの期限切れ・連携解除・バックアップ

キーが期限切れまたは失効した場合は、**Replace key or reauthorize** を使用します。新しいキーを入力する前に、リージョンと対象アカウントが一致しているか確認してください。

連携を解除すると以降の同期は停止しますが、保存済みのオフラインバックアップは消去されません。[インスタンスの運用管理](/ja/docs/self-host/operations)に従い、データベースバックアップとあわせて元のインスタンスキーを安全に保管してください。リストア後に連携を引き継ぐには元のキーが必要です。

この連携はご自身の Garmin データ向けです。他人のキーを集めて1つの個人インスタンスでマルチユーザーサービスを提供しないでください。詳しくは [Garmin Personal API 公式紹介ページ](https://developer.garmin.com/gc-developer-program/personal/personal-api/)を参照してください。
