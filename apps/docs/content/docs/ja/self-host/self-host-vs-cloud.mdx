# セルフホストとクラウドの比較

すぐに Trainingload.ai を使い始めたい場合はクラウド版、トレーニングデータを自分のパソコンやサーバーに保管し、インストールや保守を自分で行いたい場合はセルフホスト版を選んでください。

## 早見表

| 比較項目 | クラウド | セルフホスト |
| --- | --- | --- |
| 始め方 | アプリを開いてアカウントを作成する | リリースバンドルをダウンロードし、手順に沿って自分の端末へインストールする |
| データの保存先 | Trainingload.ai のクラウドサービス | 自分の端末（アクティビティ・プラン・アップロードファイルを含む） |
| トレーニングのインポート | 対応プラットフォームとの連携、またはアクティビティファイルのアップロード | ファイルアップロード、または個人キーでの Intervals.icu・Garmin Personal API 連携 |
| AIコーチの利用 | アカウントプランに含まれる AI 利用枠を使用 | デフォルトでオフ。自分で AI サービスを設定し、そのプロバイダーへ直接支払う |
| アカウント | クラウドアカウントを使用 | 1インスタンスにつき1名専用 |
| バックアップと復旧 | Trainingload.ai がクラウドサービスを保守 | 自分でバックアップを保存し、必要時にリストアする |
| ソフトウェア更新 | Trainingload.ai がサービスを更新 | アップグレード手順に従って新リリースを導入する |

## どちらが向いているか

**クラウド版が向いている方：** ソフトウェアのインストール、アップデート、バックアップ管理に手間をかけず、トレーニングと振り返りに集中したい場合。

**セルフホスト版が向いている方：** トレーニングデータを自分の手元で管理したい、アプリを動かす端末を維持できる、かつ定期的な更新とバックアップを行える場合。セルフホスト版は個人利用向けであり、1つのインスタンスに複数ユーザーを作成することはできません。

## トレーニングのインポート方法を確認する

セルフホスト版で現在サポートしている取り込み方法は次のとおりです。

- **FIT・GPX・TCX** アクティビティファイルのアップロード
- 個人 API キーによる **Intervals.icu** 連携
- 個人 API キーによる **Garmin Personal API** 連携

特定のトレーニングプラットフォームに依存している場合は、先に[データの連携](/ja/docs/guide/connect-data)と[セルフホストの連携設定](/ja/docs/self-host/configuration#connect-intervalsicu)を確認してください。クラウド版とセルフホスト版では提供される連携方式が異なります。他プラットフォームであっても対応形式のアクティビティファイルをエクスポートできるなら、ファイルアップロードで取り込めます。

**Trainingload.ai は現在、Apple Watch アプリには対応していません。**

## AI の仕組みと費用

AI はデフォルトでオフです。設定しなくても AI 以外の機能はすべて利用できます。AIコーチを使いたい場合は、設定画面でプロバイダーを選び、ご自身の API キーを入力してください。詳しくは[クライアントでの AI 設定](/ja/docs/self-host/configuration#configure-ai-in-the-client)を参照してください。

セルフホスト版では Trainingload.ai クラウドのサブスクリプションや AI クレジットは使用しません。API の利用料金は、設定した AI プロバイダーから直接請求されます。

外部 AI サービスを使う場合、そのリクエストに必要なトレーニング情報が対象プロバイダーへ送信されます。アプリをローカルにインストールしても、外部 AI サービスがローカル動作するわけではありません。また、トレーニングプラットフォームとの同期にもインターネット接続が必要です。

## セルフホストで必要になる保守作業

- 端末に十分な空き容量を確保し、必要なタイミングでアプリを稼働させる。
- アップデート前に必ずバックアップを取り、アプリ稼働端末とは別の場所にコピーを保管する。
- 端末故障時に確実に復旧できるよう、バックアップからリストアできることを定期的に確認する。
- アプリの更新は[インスタンスの運用管理](/ja/docs/self-host/operations)の手順に従って行う。

## 次のステップ

クラウド版を使う場合は、[アプリを開く](https://app.trainingload.ai/en)からアカウントを作成し、[はじめに](/ja/docs/guide/getting-started)に沿って最初のアクティビティをインポートしてください。

セルフホスト版を使う場合は、[クイックスタート](/ja/docs/self-host/installation)から始めましょう。インストール、バックアップ、アップグレードの詳細手順はそれぞれの専用ガイドにまとめています。
