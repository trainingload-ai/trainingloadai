# COROS 連携

セルフホスト版では現在、COROS との直接連携には対応していません。元のプラットフォームから対応形式（FIT・TCX・GPX）のアクティビティファイルをエクスポートし、[Trainingload.ai へアップロード](/ja/docs/guide/upload-activity-files)してください。

セルフホスト版で対応している個人連携は次のとおりです。

- [Intervals.icu](/ja/docs/self-host/configuration)
- [Garmin Personal API](/ja/docs/self-host/garmin-personal-api)

クラウド版での連携方法については、[サードパーティプラットフォーム連携ガイド](/ja/docs/guide/connect-third-party-platforms)を参照してください。
