# マラソン調整にPMCを活用する

PMC の指標は蓄積されたトレーニングストレスを表します。ワークアウトの安全性を判定したり、生理学的適応を証明したり、疲労を医学的に診断したりするものではありません。マラソン期には、練習の継続性とポイント練習の狙いを守るために活用しましょう。

## 始める前に

- 関連するアクティビティの処理が完了し、負荷が PMC に反映されていることを確認します。
- プロフィールでランニングの閾値とアクティビティ負荷ソースの優先順位を確認します。
- 実施済みアクティビティを予定ワークアウトに紐づけます。
- 判断対象期間を 1 つ決めます（通常は過去 2〜6 週間＋今後 7 日間）。
- 次のポイント練習（ロング走、マラソンペース走、閾値走、レース）を特定します。
- 睡眠、体調不良、痛み、移動、暑熱、セッション RPE など、グラフには載らない文脈を記録しておきます。

## 1. 正しい PMC 期間を開く

**分析 → PMC / フィットネス管理** を開き、**ランニング** を選択します。記録済み履歴で負荷の積み上げと直近の変化を確認してから、関連する将来の日付をチェックします。指標切替・日付確認・予測前提の詳細は[PMCの履歴と予測を読む](/ja/docs/guide/pmc-forecast)を参照してください。より短い期間を見たいときは、ダッシュボードの体力・疲労・コンディションカードを開いて履歴タブを選びます。

3 つのシグナルはまとめて読みます。

- [CTL（体力）](/ja/docs/metrics/pmc/chronic-training-load)：長期的な負荷傾向を要約します。
- [ATL（疲労）](/ja/docs/metrics/pmc/acute-training-load)：直近のトレーニングストレスにより速く反応します。
- [TSB（コンディション）](/ja/docs/metrics/pmc/training-stress-balance)：長期負荷と短期負荷の関係を示す文脈であり、万全な状態の保証ではありません。

## 2. 曲線の変化を生んだ出来事を特定する

ATL が急上昇した日、CTL の向きが変わった日、または TSB が大きく動いた日を見つけ、その前後のアクティビティと予定ワークアウトを開きます。

変化の原因が次のどれにあるかを確認しましょう。

- 予定されていた高負荷週
- レース、ロング走、または想定以上にきつかったポイント練習
- 予定外の追加アクティビティ
- 閾値または負荷ソース設定の変更
- 重複データ、誤った種目分類、または不完全なアクティビティデータ

曲線の動きが実際のトレーニングや既知の設定変更で説明できるようになるまで、プランを変更しないでください。

## 3. トレーニング負荷と実行の質を比較する

カレンダーまたは進行中のプランを使って、次の点を確認します。

- ポイント練習は本来の目的通りにこなせているか？
- イージーランは本当に楽に走れているか、それとも実行の質が落ちているか？
- セッションをスキップした理由はスケジュール都合、疲労、痛み、あるいは不適切なメニュー設計のどれか？
- 実際の今週の負荷を踏まえても、次のポイント練習は無理なく収まるか？

PMC は「どれだけストレスが積み上がったか」を教えてくれます。予実比較の根拠は「そのストレスが狙った練習成果につながっているか」を教えてくれます。

## 4. 必要最小限の調整を選ぶ

PMC のパターンは厳格な自動ルールではなく、見直しのきっかけとして使います。

### 直近の負荷が上がり、ポイント練習の質が落ちている

- 可能であれば週のリズム自体は維持します。
- 優先度の低いポイント練習を 1 回、軽い有酸素ジョグまたは休養に置き換えます。
- ロング走とマラソンペース走の両方を無理に救おうとせず、重要な一方を守ります。
- 24〜48 時間後、または次の実施セッション後に改めて確認します。

### ポイント練習前に TSB がいつもより低い

- ご自身がうまく練習を積めていたときの通常範囲や、現在の主観的体調と比較します。
- スケジュール上可能であれば、ワークアウトを 24〜48 時間後ろへずらします。
- 遅らせると週全体が崩れる場合は、目的を保ったまま時間・距離を少し短縮します。
- TSB から怪我や病気を推測しないでください。実際の症状と必要に応じて専門家の助言を優先してください。

### CTL は上がっているのに実行の質が低下している

- いったん負荷の引き上げを止めます。
- 閾値・負荷ソース優先順位・重複アクティビティによって曲線が過大評価されていないか確認します。
- ボリュームや強度をさらに足す前に、1 週間だけ構成をシンプルにします。
- 次の同等のポイント練習を確認ポイントに設定します。

### 曲線が安定しており、実行の質も良好

プランは変更せずそのまま続けます。グラフが見られるからといって、毎回何か手を加える必要はありません。

## 5. 判断内容を記録する

プランを変更する前に次の 5 項目を書き出します。

1. **観測したパターン：** PMC でいつ、何が変化したか
2. **実行上の根拠：** 懸念を裏付けるアクティビティや未実施ワークアウト
3. **調整内容：** 変更する具体的な将来ワークアウトと項目
4. **守るべき意図：** その週で引き続き達成したいこと
5. **確認ポイント：** 判断を検証する日付または次のセッション

このまとめを[AIコーチ](/ja/docs/guide/ai-coach)に渡し、プランを踏まえた控えめな調整案を 1 つ作成してもらうこともできます。

## 調整結果を確認する

- 選択した種目と期間がマラソンの判断に合致していること
- 曲線の変化が実際のアクティビティまたは既知の設定変更で説明できること
- PMC とあわせて主観的体調とポイント練習の質も考慮したこと
- 意図した将来のワークアウトだけが変更され、完了済み履歴が残っていること
- 具体的な次の確認ポイントが設定されていること
- 次の結果が期待と異なった場合に元へ戻したり修正したりできること

## トラブルシューティング

- **PMC が空になる：** アクティビティが完了（Ready）状態か、種目範囲、およびアクティビティに有効なトレーニング負荷があるかを確認してください。リクエストエラー時は「再試行」を使用します。
- **設定編集後に数値が変わった：** 変更した閾値または負荷ソースを特定し、比較期間全体を一貫して読み直してください。
- **1 件のアクティビティで極端なスパイクが出た：** そのアクティビティを開き、時間、センサーデータ、種目分類、重複、選択された負荷ソースを確認してください。
- **プランとグラフで日付がずれている：** アカウントのタイムゾーンとアクティビティ開始時刻を確認してください。
- **指標と主観的体調が一致しない：** どちらかを切り捨てるのではなく、食い違い自体を調査すべき材料として扱い、次の調整は控えめにしてください。
- **痛み・体調不良・普段と違う症状がある：** PMC や AIコーチを医学的な運動許可の代わりに使わないでください。トレーニングを中止または変更し、必要に応じて専門家の指導を受けてください。
