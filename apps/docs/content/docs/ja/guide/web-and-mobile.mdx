# Webとモバイル

Cloud 版の Web アプリと iPhone アプリは同じアカウントを共有します。保存と同期が完了すれば、別の端末からプラン、アクティビティ、プロフィール設定、コーチとの会話、通知をそのまま引き継いで閲覧できます。

このページでは Cloud 版を対象としています。セルフホスト環境については、[インストールガイド](/ja/docs/self-host/installation)に従ってブラウザからアクセスしてください。現在、Apple Watch アプリには対応していません。

## 端末を切り替える前に

- 両方の端末で同じ Trainingload.ai アカウントにサインインしていることを確認してください。
- プロフィール内のタイムゾーンと単位を確認してください。カレンダーの日付や表示値はこれらに依存します。
- 別の端末で同じプランやプロフィール項目を開く前に、現在の編集を保存してください。
- プラン操作、AIコーチ、インポート、解析済みデータの表示にはネットワーク接続が必要です。

## Webが向いている場面

- 複数週にわたるトレーニングプランを作成・確認するとき
- 持久系や筋力トレーニングの構造化ワークアウトを編集するとき
- 詳細なグラフ、ルートマップ、パワー・ペース・心拍数・PMC トレンドを比較するとき
- サードパーティ連携や過去の履歴インポートを管理するとき
- 大量のアクティビティ一覧を確認したり、過去の記録を検索したりするとき

## モバイルが向いている場面

- トレーニング当日に「今日」「カレンダー」「コーチ」「プラン」「マイページ」を確認するとき
- スマートフォンで屋外ワークアウトを記録するとき
- 保存直後に実施済みセッションを素早く振り返るとき
- 実施済みアクティビティを予定ワークアウトに紐づけるとき
- 外出先で現在の状態を更新したり、通知やプランの進捗を確認したりするとき

## 同期されるデータ

| データ | Web | モバイル | 備考 |
| --- | --- | --- | --- |
| プロフィール・単位・タイムゾーン | 閲覧・編集可 | 閲覧・編集可 | カレンダーの日付はタイムゾーンに依存します。 |
| アクティビティと分析 | フル詳細表示 | 日次ビュー・詳細ビュー | アクティビティが最初に表示された後も解析処理が続く場合があります。 |
| プランとワークアウト | フル作成・編集可 | 閲覧・作成・実行・紐づけ | 複雑な編集は通常 Web のほうが操作しやすくなります。 |
| AIコーチ | セッションと操作 | セッションと操作 | 適用した変更は同じプランに反映されます。 |
| 通知とレビュー | 利用可 | 利用可 | レビュー自動化はアカウント設定に従います。 |
| プラットフォーム連携 | フル管理可 | 一部の連携・権限設定 | 利用できる機能はプラットフォームや端末により異なります。 |

## 更新と競合のルール

同じプランやプロフィール項目を 2 台の端末で編集した場合、最後に正常保存された内容が優先されます。次の編集を行う前に、以下の手順で最新化してください。

1. 一覧画面または詳細画面に戻ります。
2. モバイルでは下に引いて更新、Web では再読み込み／再取得を行います。
3. 最新の値が表示されていることを確認します。
4. 次の変更を適用します。

別のリクエストで同じレコードが先に変更されていた場合、古い状態からのプラン更新は拒否されることがあります。古い画面から何度も送信せず、プランを再読み込みしてから意図した変更を適用し直してください。

## 別の端末で作業を引き継ぐ

1. 最初の端末で現在の操作を完了し、保存します。
2. 2 台目の端末で該当する一覧画面または詳細画面を開きます。
3. モバイルでは下に引いて更新、Web では再読み込み／再取得を行います。
4. 先ほど変更したアクティビティの時刻、プランのバージョン、またはプロフィール値が反映されていることを確認します。
5. サーバー上の最新値が表示されてから編集を続けます。

## オフライン時の動作

モバイル記録は計測中のデータをローカルに保持し、可能な場合は中断されたセッションを復元できるよう設計されています。一方、サーバー連携が必要な画面では、最新のプラン・AI の応答・解析結果を取得するためにネットワーク接続が必要です。

再接続後は次の点に注意してください。

- 記録やインポートのアップロードが完了するまで待ちます。
- 同じワークアウトに対して重複アップロードを開始しないでください。
- アクティビティ一覧に 1 件だけ表示されていることを確認します。
- アクティビティを開き、解析がまだ処理中であれば完了を待ちます。

## 同期を確認する

- 両方の端末でプロフィールの単位とタイムゾーンが一致していること
- 実施済みアクティビティが同じ開始時刻・ソースで 1 件だけ表示されていること
- 進行中のプランと次のワークアウトに、同じステータスと最新の編集内容が反映されていること
- 片方の端末で適用した AIコーチの操作が、もう一方の端末でも同じプランに反映されていること
- 通知や完了済みレビューが更新後に未読へ戻らないこと

## トラブルシューティング

### 片方の端末に古いデータが表示される

一覧画面または詳細画面に戻って更新してください。ネットワーク接続と、両方の端末で同じアカウントにサインインしていることを確認しましょう。サーバーの最新値が表示されるまで古いコピーを編集しないでください。

### プラン編集時にバージョン競合エラーが出る

別の正常なリクエストが先にプランを変更しています。プランを再読み込みし、現在のワークアウト内容と意図した変更を比較したうえで、新しいバージョンに対して変更を再適用してください。

### モバイルの記録が Web に表示されない

アップロードが完了するまでモバイルアプリを利用可能な状態に保ち、その後 Web のアクティビティ一覧を更新してください。アクティビティ自体は表示されているのにグラフが未完成な場合は処理中のため、2 回目のアップロードは行わないでください。

### 端末によって連携設定が異なる

完全な管理画面を使うには、Web の **アカウント → サードパーティ連携** を開いてください。モバイルでは一部の認可や権限フローのみ表示される場合があります。

### カレンダーの日付がずれている

両端末のアカウントタイムゾーンと、アクティビティに記録された開始時刻を比較してください。ワークアウトを移動したり作り直したりする前に、まずプロフィール設定を修正しましょう。
