# アクティビティファイルのアップロード

ウォッチ、サイクルコンピューター、またはトレーニングプラットフォームからエクスポートした記録をアップロードすると、Trainingload.ai 上で詳細・グラフ・トレーニング負荷を確認できます。以下の手順は Web アプリでの操作です。

## ファイルを準備する [#before-uploading]

FIT、TCX、または GPX 形式のワークアウトファイルを用意します。一度に最大 100 ファイルまでアップロードできます。デバイスやプラットフォームから直接エクスポートしたオリジナルファイルを使うと、心拍数・パワー・ルートデータが最も確実に保持されます。

## アクティビティ画面からアップロードする

1. 左サイドバーの **アクティビティ** をクリックしてアクティビティページを開きます。
2. 右端にある **アクティビティファイルをアップロード** カード内の **アクティビティファイルを選択** をクリックします。

3. インポートしたいファイルをダイアログへドラッグ＆ドロップするか、ファイル選択エリアをクリックして選びます。
4. ダイアログ右下の **アップロード** をクリックします。

アップロード後にインポート進捗ダイアログが開き、ファイルごとの結果が表示されます。

## インポート進捗を確認する [#import-statuses]

インポート処理中もほかの画面を閲覧できます。ダイアログを閉じた場合は、アクティビティページの **インポート進捗** をクリックすると再表示できます。

| 表示されるステータス | 対処方法 |
| --- | --- |
| Queued / Normalizing / Materializing / Building analysis | ファイルは処理中です。インポート完了までお待ちください。 |
| Done | アクティビティ一覧に戻り、取り込まれた記録を確認します。 |
| Skipped | 通常は一致する記録がすでに存在します。アクティビティ一覧で探してください。 |
| Failed / Dead | ファイル横のメッセージを読み、下記のトラブルシューティングを試してください。 |

## インポートしたアクティビティを探す [#after-upload]

インポートが完了したら、左サイドバーの **アクティビティ** をクリックします。ワークアウトの日付から記録を探して開くと、時間・距離・グラフ・トレーニング負荷を確認できます。

各画面の使い方は[アクティビティ一覧と検索](/ja/docs/guide/activity-feed-search)および[アクティビティ詳細](/ja/docs/guide/activity-detail)をご覧ください。

## トラブルシューティング

### アップロードボタンが押せない

まずファイルを選択してください。形式チェックが進行中の場合は少しお待ちください。エラーが表示されているファイルがある場合は、メッセージに従って対処するか該当ファイルを外してから再試行してください。

### 重複の警告が表示される

すでにアクティビティ一覧に同じワークアウトがある場合は、既存の記録を残すかアップロードをキャンセルできます。別のコピーとして残したい場合にのみ強制インポートを選択してください。

### ファイルのアップロードやインポートが失敗する

ファイル横のエラーメッセージを確認してください。デバイスやプラットフォームから元の FIT・TCX・GPX ファイルをもう一度エクスポートし、そのファイル単体でアップロードを試してください。ファイル名の拡張子を書き換えても形式は変換されません。

スクリーンショット、通常の CSV スプレッドシート、終日の健康データのみを含む FIT ファイルは、ここからはワークアウト記録としてインポートできません。

### 心拍数・パワー・ルートが表示されない

まずアクティビティの解析処理が終わるのを待ってください。グラフを表示するには元の記録に対応するデータが含まれている必要があります。たとえば GPS を含まないインドアワークアウトではルートは表示されません。連携元プラットフォームを確認し、オリジナルファイルの再エクスポートも試してみてください。

## 別のファイル形式が必要ですか？ [#convert-between-formats]

アップロードは FIT・TCX・GPX に対応しているため、通常は変換不要です。別のプラットフォーム向けに形式変換が必要な場合は、[FIT・GPX・TCX 変換ツール](/ja/converter)をご利用ください。
