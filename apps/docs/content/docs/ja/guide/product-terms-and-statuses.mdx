# プロダクト用語とステータス

画面上で見慣れない名称やステータスを見かけたときは、ここで意味と次の操作を確認できます。

## よく使われる用語

| 用語 | 意味 |
| --- | --- |
| アスリートプロフィール | トレーニングの解釈に使われるタイムゾーン、単位、閾値、ゾーン、設定、種目情報 |
| トレーニングプラン | 複数のワークアウトを含むトレーニング計画。ドラフトとして保存、有効化、または終了できます |
| 予定ワークアウト | 特定の日に行う予定のトレーニング。種目、構成、時間、強度、利用可能な場合は予定負荷を含みます |
| 実施済みアクティビティ | デバイスやプラットフォームから実際に記録・同期・アップロードされたトレーニング記録 |
| プランとアクティビティの紐づけ | ある実施済みアクティビティが特定の予定ワークアウトに対応していることを明示する関連づけ |
| 現在の状態 | 最近のトレーニング負荷、回復データ、主観的なフィードバックなど、今日の判断に使う状況情報 |
| レビュー | 利用可能なデータをもとに、単発のアクティビティ、1日、1週間、1か月、またはプラン全体を解釈した結果 |
| AI操作 | 今後のトレーニングの作成・移動・変更など、AI によって提案または実行されるアクション |

## アクティビティのステータス

| ステータス | 意味 | 対処方法 |
| --- | --- | --- |
| アップロード中／インポート中 | ファイルまたはプラットフォームからのデータ転送が進行中です | 再試行する前に完了を待ちます |
| 処理中 | アクティビティ自体は作成済みですが、派生データがまだそろっていない可能性があります | トレーニング負荷やグラフの欠落をこの時点で判断しないでください |
| 完了（準備完了） | アクティビティの解析が完了しています | 元データに実際に含まれている項目を確認します |
| 失敗 | インポートまたは処理を完了できませんでした | 表示されているエラーを確認し、トラブルシューティングへ進みます |
| 重複 | 同じソースのアクティビティまたは同等のファイルがすでに存在します | 既存の記録を確認し、同じワークアウトを二重に取り込まないようにします |

## プランとワークアウトのステータス

| ステータス | 意味 |
| --- | --- |
| ドラフト | 現在のプランとして適用する前に、確認・編集できる状態です |
| 進行中（アクティブ） | 現在実行しているプランで、各ワークアウトが予定日に表示されます |
| 完了 | プラン期間が終了した状態です。終了後も振り返りに利用できます |
| 予定 | ワークアウトがスケジュールされているが、まだ最終的な実施結果がない状態です |
| 完了済みワークアウト | 予定ワークアウトが完了として記録された状態です（通常はアクティビティの紐づけまたは完了記録を伴います） |
| スキップ | 意図的に実施しないと判断されたワークアウトです |
| 予定外のアクティビティ | どの予定ワークアウトにも対応していない実施済みアクティビティです |

## トレーニング負荷・レビュー・クレジット

- **トレーニング負荷**は、トレーニング量を数値化した派生推定値です。算出できるかどうかは種目、時間、センサーデータ、閾値、および負荷ソースの優先ルールによって決まります。
- **コーチレビュー**はデータに基づく解釈であり、デバイスの生データや医学的診断ではありません。
- **AIクレジット**は対象となる AI 操作で消費される利用単位です。クレジット履歴は消費状況を表すものであり、トレーニング負荷やアカウント権限を示すものではありません。
- **Demoアカウント**はサンプルデータを閲覧するためのアカウントです。変更の保存、アクティビティのインポート、ご自身のトレーニング記録の管理を行うには、ご自身のアカウントでサインインしてください。
