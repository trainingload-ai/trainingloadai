# レース（大会）管理

レースイベントはトレーニングプランとは独立して管理されます。これにより、レースを通常の予定ワークアウトとして扱わずに、プラン判断へ適切に反映させることができます。

## 始める前に

- 公式の開催日、現地スタート時刻、タイムゾーンを確認します。
- 練習レース（低優先度）なのか、ピークを合わせたい本命レースなのかを決めます。
- 当日にある予定ワークアウトとは切り分けて管理します。
- 目標タイムは根拠のない願望ではなく、実際の目標として設定する場合に入力します。

## レースを追加する

**レース（Competitions）** を開き、**レースを追加** を選択して次を入力します。

- レース名
- 日付または期間
- スタート時刻とタイムゾーン（時刻が重要な場合）
- 種目および任意の種目詳細
- 距離（該当する場合）
- 重要度：低（Low）、中（Medium）、高（High）、最重要（Critical）
- 目標タイプ（選択した場合は目標タイムも含む）
- 開催地とメモ

重要度は「プラン側でそのレースをどれだけ保護すべきか」を表します。すべてのレースを最重要にしないでください。近接した日程に最重要レースを複数置くと、優先度が上がるどころか現実的な計画の競合が生じます。

## イベントを確認する

保存後、カウントダウン、日付、種目、目標、重要度を確認します。登録したレースは関連するカレンダーや日別ビューにも表示されます。

Trainingload.ai はイベント期間と前後の予定トレーニングから、現在のプランへの影響を評価できます。この影響表示は判断材料であり、重複するすべてのワークアウトを自動で削除すべきだという保証ではありません。

## レース当日の競合を解消する

同じ日に予定ワークアウトとレースが重なった場合は、次の手順で整理します。

1. イベントの日付とタイムゾーンが正しいか確認します。
2. レースが予定ワークアウトの代わりになるのか、同じ目的を満たすのか、あるいは別の軽いセッションと併用するのかを決めます。
3. 予定ワークアウトを明示的に編集・スキップ・移動します。
4. 前後の高強度日やリカバリー日も見直します。
5. レースの優先度が明確になってから、必要に応じて AIコーチに調整案を相談します。

## 安全に更新する

レース記録はバージョン管理された更新を行います。別のリクエストで先にイベントが変更されていた場合は、再読み込みして最新版を確認してから保存し直してください。

## 中止（キャンセル）・復元・削除

- **中止（Cancel）**：記録を残したまま、予定レース対象から外します。
- **復元（Restore）**：中止したレースが再び対象になったときに元へ戻します。
- **削除（Delete）**：記録自体を削除します。誤登録や不要なテストデータにのみ使用してください。

## 登録結果の確認

- イベントが正しい年・カレンダー日付に表示されていること
- カウントダウンと現地時刻が正確であること
- 目標距離・日付・目標タイムが正しいこと
- 対象期間のプランがある場合、現在のプランへの影響が読み込めること
- レース当日のワークアウトとの競合が暗黙に書き換わらず、明示的に確認できること

## トラブルシューティング

- **カウントダウンがずれている：** イベント日付・開始時刻・イベントタイムゾーン・アカウントタイムゾーンをまとめて確認してください。
- **カレンダーにレースが表示されない：** 中止状態になっていないか、および表示中の日付範囲に含まれているか確認してください。
- **プランへの影響が読み込めない：** 進行中のプランがイベント期間と重なっているか確認し、古いプランまたはイベント状態を更新してください。
- **競合が解消されないように見える：** レース登録がプランを自動で書き換えることはありません。予定ワークアウトを明示的に移動・スキップ・編集してください。
- **更新時に競合エラーが出る：** イベントを再読み込みし、最新版に対して変更を再適用してください。
