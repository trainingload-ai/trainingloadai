# 最初のアクティビティをインポート [#get-started-with-your-first-activity]

ウォッチ、サイクルコンピューター、またはトレーニングプラットフォームから記録をインポートすると、Trainingload.ai 上でアクティビティ詳細、グラフ、トレーニング負荷を確認できます。このガイドでは、Web アプリでのプラットフォーム同期とファイルアップロードの手順を説明します。

## 始める前に

[Trainingload.ai を開く](https://app.trainingload.ai/en)からご自身のアカウントでサインインしてください。セルフホスト環境をご利用の場合は、ご自身のインスタンスを開きます。まず画面の雰囲気を見てみたい場合は、[Demo を閲覧](https://demo.trainingload.ai/en)できます。

## 1. インポート方法を選ぶ [#2-choose-one-route-for-the-first-activity]

| 同期方法 | ガイド |
| --- | --- |
| サードパーティのトレーニングプラットフォームから同期（Strava、Garmin、Intervals.icu） | [プラットフォームを連携する](#connect-a-training-platform) |
| アクティビティファイルから同期（FIT、TCX、GPX） | [ファイルをアップロードする](#upload-a-workout-file) |
| スマートフォンから同期 | [モバイル同期ガイドを読む](/ja/docs/guide/account-permissions-and-usage#2-review-mobile-permissions-and-data-sources) |

セルフホスト環境で対応している連携については、[設定](/ja/docs/self-host/configuration)をご覧ください。下記のファイルアップロード手順も利用できます。

## 2. 記録をインポートする [#3-import-and-wait-for-processing]

### 方法 1：トレーニングプラットフォームを連携する [#connect-a-training-platform]

1. サイドバー下部にあるアカウントメニューを開き、**アカウント** を選択して **サードパーティ連携** までスクロールします。
2. 記録が保存されているプラットフォームを選び、ダイアログの案内に従って接続します。
3. 必要に応じて、初回インポートまたは手動同期オプションを実行します。
4. サイドバーの **アクティビティ** を開き、同期された記録を確認します。

プラットフォームごとに対応している履歴の取得範囲が異なります。接続や履歴インポートの詳細手順は、[Strava・Garmin・COROSなどのプラットフォームを接続](/ja/docs/guide/connect-third-party-platforms)を参照してください。

### 方法 2：ワークアウトファイルをアップロードする [#upload-a-workout-file]

ウォッチ、サイクルコンピューター、またはトレーニングプラットフォームから FIT・TCX・GPX ファイルをエクスポートし、次の手順でアップロードします。

1. 左サイドバーの **アクティビティ** をクリックしてアクティビティ一覧ページを開きます。
2. 右端にある **アクティビティファイルをアップロード** カード内の **アクティビティファイルを選択** をクリックします。

3. インポートしたいファイルをダイアログへドラッグ＆ドロップするか、ファイル選択エリアをクリックして選びます。
4. ダイアログ右下の **アップロード** をクリックします。

アップロード後、インポート進捗ダイアログが表示されます。取り込みが完了したら **アクティビティ** に戻り、記録を確認してください。重複の警告が表示された場合は、同じワークアウトを二重に取り込まず既存の記録を残すことができます。詳しくは[アクティビティファイルのアップロード](/ja/docs/guide/upload-activity-files)をご覧ください。

## 3. インポートしたアクティビティを開く [#4-verify-the-first-recorded-result]

**アクティビティ** 一覧から日付を頼りにワークアウトを探し、詳細画面を開きます。時間、距離、トレーニング負荷に加え、元データに含まれるグラフやルートを確認できます。画面の各要素については[アクティビティ詳細](/ja/docs/guide/activity-detail)をご覧ください。

インポート直後のアクティビティは処理中の場合があります。すべての結果を見る前に解析が完了するまでお待ちください。心拍数・パワー・ルートのグラフを表示するには対応する計測データが必要であり、GPS を含まない記録にはルートは表示されません。

## よくある質問

### プラットフォームを連携したのにアクティビティが表示されません

プラットフォームが接続状態になっているかと、アクティビティ一覧の日付フィルターを確認してください。過去のワークアウトは別途履歴インポートが必要な場合があります。各プラットフォームのオプションに従うか、ワークアウトファイルをエクスポートして Trainingload.ai にアップロードしてください。

### アクティビティに心拍数やルートが表示されません

まず処理が完了するまでお待ちください。元のファイルに心拍数・パワー・GPS データが含まれていない場合、対応するグラフは表示されません。元のプラットフォームではそれらのデータが表示されている場合は、元のアクティビティファイルをエクスポートして再アップロードしてみてください。

### アクティビティが別の日に表示されます

アカウントのタイムゾーンと、記録の開始時刻を確認してください。タイムゾーンと単位の設定については[プロフィール・閾値・ゾーン](/ja/docs/guide/profile-thresholds-zones)を参照してください。

### Demo ではなぜアップロードできないのですか？

Demo はサンプルデータを閲覧するための環境です。ご自身の記録をインポートするには、[メインアプリを開く](https://app.trainingload.ai/en)からご自身のアカウントでサインインしてください。
