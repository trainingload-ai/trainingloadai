# アクティビティ履歴とベストエフォート

履歴ツールを使うと、「何が起きたか」という全体像から特定の元アクティビティまで素早く辿れます。「アクティビティ統計」はトレーニング量をまとめ、「距離別ベスト」は持続パフォーマンスを順位付けし、「マップ」はルートの文脈を加えます。

これらのページはあくまで記録データを可視化したものです。公式レース記録の証明、フィニッシュタイムの予測、さらなる確認なしでのパフォーマンス変化の原因特定を行うものではありません。

## 始める前に

- インポートしたアクティビティが「完了（Ready）」ステータスになるのを待ちます。
- 種目分類、タイムゾーン、単位系を確認します。
- 合計値やベスト記録を比較する前に、重複や明らかなセンサーエラーを修正しておきます。
- 調べたい問いに合った期間を選びます。
- マップ表示には有効な GPS 座標が必要です（インドアや GPS なしのアクティビティも他の画面には表示されます）。

## 1. 年間のアクティビティ量を確認する

**分析 → アクティビティ統計（Activity Stats）** を開きます。このページは現在のアクティビティ一覧の種目フィルターを引き継ぐため、レポートを読む前にそのフィルターを確認してください。

サイドバーから年を選択します。選択可能な年は、対象種目で最も古いアクティビティがある年まで遡れます。ヒートマップは選択年の利用可能な 365 日間を対象に、アクティビティ実施日数を可視化します。

ヒートマップの下で指標を 1 つ選びます。

- 距離
- 時間
- 心拍数
- アクティビティ回数
- カロリー

続いて折れ線グラフを日別・週別・月別で集計します。短期の確認には日別、継続性の確認には週別、大きなボリューム比較には月別が適しています。心拍数は該当値の平均、距離や時間などの加算可能な指標は合計で集計されます。

## 2. ベストエフォートを探す

**分析 → 距離別ベスト（Best Distance）** を開き、次の順に設定します。

1. **ランニング**、**サイクリング**、**スイミング** から種目を選びます。
2. **距離別（By Distance）** または **時間別（By Time）** を選びます。
3. 対象期間を設定します。
4. 距離または時間のターゲットを選びます。
5. ランキング結果を確認します（各ターゲットにつき最大 10 件取得されます）。
6. 記録行から元のアクティビティを開きます。

**距離別** は「この距離を最も速く走った（漕いだ・泳いだ）タイムは？」、**時間別** は「この時間でどこまで進めたか？」に答えます。表示されるペースを使うと、同じ種目・文脈の中でパフォーマンスを比較しやすくなります。

すべての行を公式の自己ベスト（PB）とみなさないでください。ここに出るのは選択データ・期間内で検出された条件適合の最高区間であり、練習セッション由来の場合や GPS 精度に左右される場合があり、アクティビティの再処理や修正によって変わることがあります。

## 3. マップでルート履歴を確認する

**マップ（Map）** を開き、期間と種目のフィルターを設定します。条件に一致し、有効な GPS データを含むアクティビティのルートが描画されます。

マップの活用例：

- 場所やルートの形からアクティビティを探す
- 繰り返し走ったコースを比較する
- アクティビティを開く前に、欠損や不自然なルートに気づく
- 選択したアクティビティからルート付きのシェアポスターを作成する

ルートを選択するとアクティビティポスターが開きます。指標や処理ステータス、センサーデータの詳細を確認したいときは、ポスターからアクティビティ詳細ページへ進んでください。

マップは機密性の高い位置情報を含みます。共有する前にポスターとルートを確認し、自宅・職場などプライベートな開始地点が露出しないよう注意してください。

## 4. 不自然な結果を調査する

年間合計、ベストエフォート、ルートに違和感がある場合は次の順で確認します。

1. 元のアクティビティを開きます。
2. 開始時刻、種目、連携元、処理ステータス、単位系を確認します。
3. GPS、距離、時間、一時停止、関連センサーストリームを確認します。
4. 重複や誤った種目分類がないかチェックします。
5. 元のアクティビティや設定を修正したあと、サマリーページを更新します。

常に元のアクティビティを根拠として扱ってください。サマリーページは問題の発見には役立ちますが、単独で原因解明や修復を行うことはできません。

## 結果の確認

- アクティビティ統計で意図した種目・年・指標・集計単位が選ばれていること
- ベストエフォートの各行から想定通りの元アクティビティが開き、日付が一致していること
- マップで選んだルートが期待するアクティビティに属していること
- GPS のないアクティビティがマップに出ないことを「インポート漏れ」と誤解していないこと
- 共有するポスターにプライベートな位置情報が含まれていないこと

## トラブルシューティング

- **アクティビティ統計に意図しない種目が出る：** アクティビティ一覧に戻って種目フィルターを変更し、アクティビティ統計を開き直すか更新してください。
- **今年しか選べない：** 選択した種目に前年以前の該当アクティビティがないか、最古アクティビティの取得が完了していません。
- **ヒートマップと折れ線グラフの印象が異なる：** ヒートマップは実施日数を数え、折れ線グラフは選択した指標と集計単位を表示します。
- **ベストエフォートが表示されない：** 期間を広げ、種目とターゲットを確認し、対象アクティビティに有効な距離・時間データがあるか確認してください。
- **あり得ない記録が出ている：** 採用する前に GPS スパイク、一時停止、距離・時間、重複アクティビティを確認してください。
- **マップにアクティビティが出ない：** フィルター範囲外か、有効な GPS ルートが含まれていません。
- **ルートを選んだら別のポスターのように見える：** 共有する前にアクティビティ日付を確認し、詳細画面を開いて確かめてください。
