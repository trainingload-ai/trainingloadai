# モバイル記録

このガイドでは、スマートフォンでワークアウトを記録して保存し、Trainingload.ai のアクティビティ履歴に正しく表示されるまでの流れを解説します。

## 始める前に

- Web と同じアカウントでモバイルアプリにサインインします。
- 屋外 GPS 記録のために位置情報の権限を有効にします。
- OS で提供されており、ワークアウト中に画面をロックする予定がある場合は、バックグラウンドでの位置情報アクセスを許可します。
- バックグラウンドアプリを停止する設定になっている端末では、Trainingload.ai に対する強いバッテリー制限を解除します。
- 予定時間に対してスマートフォンのバッテリー残量と空き容量が十分にあることを確認します。

## 1. 権限を確認する

ワークアウトを始める前に **マイページ → メニュー → データ認可** を開き、位置情報やヘルスケアデータの権限を確認します。外部プラットフォーム連携の権限とスマートフォンの GPS 権限は別物です。プラットフォームを接続しても、スマートフォンに位置情報の記録権限は付与されません。

## 2. レコーダーを開く

**今日** タブで予定ワークアウトを開き、種目と構成を確認したうえで **今日のワークアウトを開始** を選択します。進行中のプランからワークアウトを開くこともできます。屋外セッションの場合は開始前に位置情報権限を確認しましょう。

## 3. ワークアウトを開始・確認する

1. **今日のワークアウトを開始** を 1 回選択し、準備案内に従ってカウントダウンを待ちます。
2. 経過時間が増えていくことを確認します。
3. 屋外セッションでは、距離やルートデータが更新され始めることを確認します。
4. セッションが確実に記録中になってから画面をロックしてください。

アプリが一時停止されたあとにフォアグラウンドへ戻った場合は、進行中のセッションが復元されるまで待ちます。復元処理中に 2 つ目の記録を開始しないでください。

## 4. 終了して保存する

セッションが終わったら、次の手順で保存します。

1. 記録を停止します。
2. 時間・距離・種目を確認します。
3. ワークアウトを保存します。
4. アップロードまたはインポートの引き継ぎが完了するまで、アプリをオンライン状態に保ちます。

モバイルアプリは記録中のデータを端末内にローカル保存し、中断された記録には復元フローを備えています。端末への保存が成功しても、サーバー側のすべてのグラフが即座に完成するわけではありません。アップロード後に解析処理が続きます。

## 結果を確認する

**マイページ → アクティビティ** または該当日のカレンダーを開き、次の点を確認します。

- そのセッションのアクティビティが 1 件だけ作成されていること
- 開始時刻・種目・時間・距離が妥当であること
- GPS ワークアウトの場合、マップが表示されていること
- センサー由来のグラフは、記録にそのデータが含まれている場合にのみ表示されること
- 該当する予定ワークアウトに紐づけできること

## トラブルシューティング

### 経過時間は増えるのに距離が 0 のまま

位置情報権限、GPS の受信状況、選択した種目が屋外距離を計測する種目かどうかを確認してください。開けた場所へ移動し、測位が安定するのを待ちましょう。

### 画面をロックすると記録が止まる

バックグラウンド位置情報を許可し、アプリのバッテリー最適化を解除してください。OS 側の設定がアプリ内の権限状態より優先される場合があります。

### アクティビティが 2 件表示される

同期が完了待ちの状態にあるうちに、ローカル記録ファイルを別途アップロードしないでください。開始時刻と時間を比較し、重複と確認できたコピーだけを削除してください。

### アクティビティはあるのにグラフが表示されない

解析が完了するまで待ってから画面を更新してください。心拍数・パワー・ケイデンスが表示されない場合は、元の記録にそれらのデータが含まれていなかった可能性もあります。
