# AIコーチ

AIコーチに依頼すると、アクティビティの解説、プラン達成状況のレビュー、次のワークアウトを調整すべきかどうかの相談ができます。回答は利用可能なトレーニング記録に基づいて生成されます。提案を適用する前に、根拠となる記録と変更内容を必ず確認してください。

主な活用用途：

- アクティビティの解釈
- 日次・週次・月次のトレーニングレビュー
- プランのフォローアップ
- AI アシストによるプラン作成
- ワークアウト調整の相談
- トレーニング負荷・回復・ペース・心拍数・パワーに関する質問

## 始める前に

- 対象となるアクティビティの処理が完了していることを確認します。
- プロフィールの閾値・ゾーン・現在の状態を最新に保ちます。
- プラン実行に関するアドバイスを得たい場合は、実施済みアクティビティを予定ワークアウトに紐づけておきます。
- 「すべてまとめて見て」ではなく、実際の判断や 1 つの具体的な質問に絞って相談します。

## 会話を始める

Web または Personal のサイドバーから **コーチ** を選択します。モバイルアプリ、アクティビティ詳細ページ、プランページ、レビュー通知からも開けます。

新しいチャットを始めるか、サイドバーから既存の会話を選んでメッセージと文脈を引き継げます。

Web の **コーチ** ページでは、進行中のプラン、今日のワークアウト、今週の進捗、最近のアクティビティ、会話履歴を確認できます。該当項目を選択して会話を開き、履歴から日次・週次・月次レビューを参照し、提案を適用する前に引用された記録を確認してください。

## AIコーチが参照できる情報

開いた入口と利用可能なデータに応じて、AIコーチは次の情報を参照できます。

- 最近のアクティビティ
- アクティビティ詳細と時系列分析
- 現在のトレーニングプラン
- プランのワークアウトと完了ステータス
- 紐づけられたアクティビティ
- トレーニング負荷の指標
- プロフィール・閾値・ゾーン
- 日次・週次・月次レビューのサマリー

データが最新であるほど AIコーチの精度は高まります。アクティビティが処理中だったり閾値が未設定だったりすると、提案は一般的な内容になりやすくなります。

## アクティビティレビュー

単発のアクティビティについては、次のような質問が効果的です。

- 「このワークアウトは予定の目標強度に合っていましたか？」
- 「後半の心拍ドリフトは気にするレベルですか？」
- 「登坂が多かったこのライドをどう解釈すべきですか？」
- 「次のポイント練習に向けて注意すべき点は？」

良いアクティビティレビューは、生データとワークアウト本来の目的を組み合わせて解釈します。

## プランのフォローアップ

プラン詳細ページから AIコーチを開くと、そのプランの文脈付きで進捗を振り返れます。

役立つ質問例：

- 「ここまでのプランの進み具合はどうですか？」
- 「抜けてしまったワークアウトのうち、最も影響が大きいのはどれ？」
- 「次のワークアウトは別日にずらすべき？」
- 「実績負荷が予定負荷を上回りすぎていますか？」
- 「今日のセッションを踏まえて、来週をどう変えるべき？」

AIコーチがスケジュール変更を提案した場合は、**ワークアウトカレンダーを表示** を選んで同じ会話内で変更前後のワークアウトを比較します。日付と内容を確認したうえで **プラン変更を確定** を選択してください。スケジュール編集の詳細は[カレンダー](/ja/docs/guide/calendar#adjust-upcoming-workouts)をご覧ください。

## AIプランドラフト

AI アシストでプランを作成する際、入力したプラン要件が AIコーチに渡されます。重要な情報が不足している場合は AIコーチから追加質問があり、そのうえでプランドラフトが提示されます。

ドラフトは次の観点で丁寧に確認してください。

- 週ごとの構成
- 高強度日と軽めの日のリズム
- ワークアウト内容の説明
- 種目タイプ
- リカバリーの配置
- 合計のトレーニング量

ドラフトを保存するとプランが作成されますが、実際の生活リズムに無理がないか確認する判断はご自身で行ってください。

## 質問と確認

不足している条件によって提案が大きく変わる場合、AIコーチが選択肢を提示して確認することがあります。

例：

- ロング走・ロングライドを置きたい曜日
- レース日や目標距離
- 現在の怪我・痛みの懸念
- 回復優先かボリューム維持かの方針

こうした質問に答えることで、ご自身の制約に沿った提案が得られます。

## 変更の適用と取り消し（Undo）

ワークアウト調整など、一部の AIコーチ操作はトレーニングデータへ直接変更を適用できます。影響の大きい変更は、適用前に必ず確認画面が提示されます。

適用した操作が取り消し（Undo）に対応している場合、元に戻したいときは速やかに取り消しボタンを使ってください。取り消し可能時間には制限がある場合があります。

## セッション履歴

履歴画面では次の操作ができます。

- 以前のチャットを再開する
- レビューセッションを開き直す
- 便利なセッションの名前を変更する・ピン留めする
- 不要なセッションを削除する

レビュー通知から全セッション一覧を開いた場合は、スレッドを選ぶ前に日次・週次・月次の選択フィルターを確認してください。

過去の自分のメッセージを編集した場合、編集後の依頼と整合性を保つため、それ以降の会話内容が置き換わることがあります。

## より良い質問のコツ

下したいトレーニング判断を具体的に伝えるのがポイントです。

伝わりやすい例：

- 「明日ロング走の予定ですが、今日のワークアウトが予定よりきつくなりました。調整すべきですか？」
- 「今週の実績負荷とプランを比較して、控えめな調整案を 1 つ提案してください。」
- 「イージーランを 2 回逃しました。埋め合わせるべきですか、そのまま次へ進むべきですか？」

伝わりにくい例：

- 「どう思いますか？」
- 「全部分析して。」
- 「速くして。」

AIコーチは、現実のトレーニング判断に結びついた問いほど力を発揮します。

## 有用な回答を見極めるポイント

質の高い回答には次の特徴があります。

- 正しいアクティビティ・プラン・期間・指標の文脈を参照している
- 観測された事実と、解釈・不確実性を区別している
- なぜその提案になるのかを根拠から説明している
- 理由の薄い大規模書き換えより、控えめな次の一手を優先している
- 重要なデータやスケジュール変更の前に確認を求めている

回答が誤った文脈を参照しているように見える場合は、操作を確定しないでください。対象のアクティビティやプラン名を明示して、まずコーチに再確認させましょう。

## トラブルシューティング

- **回答が一般的すぎる：** 処理完了を待ち、不足している閾値を更新し、対象のアクティビティ詳細やプラン詳細ページから質問してください。
- **別のプランやアクティビティについて話している：** 正しい詳細ページから開くか、正確な対象名と日付を指定してください。
- **ツール連携アクションが失敗する：** 元のページを更新し、対象レコードがまだ存在することを確認してから最小単位の操作を再試行してください。
- **提案されたプランが非現実的に見える：** 週あたりの練習可能日、使用器具、最近のベースライン、レース予定、怪我や痛みの制約を具体的に伝えてください（ただし医学的診断は求めないでください）。
- **誤って変更を適用してしまった：** 取り消し（Undo）が使える場合はすぐ実行し、使えない場合は対象のプランやワークアウトを直接見直して編集してください。
