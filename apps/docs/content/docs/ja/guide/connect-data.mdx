# トレーニングデータの接続

実施済みワークアウトを Trainingload.ai にインポートし、日付・ソース・詳細を確認します。元の記録がどこに保存されているかに応じて、プラットフォーム連携、ファイルアップロード、スマートフォン記録のいずれかを選びます。

[Demo でアクティビティを閲覧](https://demo.trainingload.ai/en/activities)できます。ファイルのインポートやプラットフォームの認可にはご自身のアカウントが必要です。アップロード画面のスクリーンショットには実アプリのサンプルアカウントを使用しています。

## 1. ソースを選ぶ

| 経路 | 適している場面 | 後から確認すること |
| --- | --- | --- |
| 対応プラットフォーム連携 | インポートまたは同期したいアクティビティが外部プラットフォームにある場合 | 提供される同期方向・対象期間・ジョブ結果、および取り込まれたアクティビティ |
| オリジナルの FIT・TCX・GPX ファイル | 特定のワークアウト、アーカイブ、または直接連携できないソースの場合 | ファイルごとの検証結果とインポートバッチの結果 |
| モバイル記録 | Trainingload.ai アプリでワークアウトを直接記録する場合 | 記録終了後の同期状況と作成されたアクティビティ |

各プラットフォームの対応機能と認可手順については、[トレーニングアプリ連携](/ja/docs/guide/integrations)および[Strava・Garmin・COROSを接続してワークアウトを取り込む](/ja/docs/guide/connect-third-party-platforms)を参照してください。ご利用の環境・アカウントで実際に表示される操作を基準にしてください。一度きりの履歴インポートと継続的な自動同期は異なる機能です。

## 2. 既知のワークアウトで主経路を 1 つ決める

まずは基準となるワークアウトを 1 件選び、日付・種目・おおよその時間を把握しておきます。同じセッションがデバイスから複数サービスへ転送されている場合は、一括で履歴を取り込む前にどの経路を主経路にするか決めてください。

元の記録ファイルは手元に残しておきましょう。変換済みファイルやサマリーのみのファイルでは、オリジナルの FIT エクスポートと含まれる項目が異なる場合があります。アクティビティのインポートにはワークアウト記録が必要であり、終日の健康データのみを含むエクスポートは別種のデータです。

## 3. 選んだ経路でインポートする

### ファイルアップロード

1. **アクティビティ** を開き、アップロード入口を選択します。
2. オリジナルファイルを選び、形式チェックの完了を待ちます。
3. 検出された形式と検証エラーの有無を確認します。拡張子だけでは実際のファイル形式を保証できません。
4. アップロードを進め、重複の確認表示が出た場合は内容を確認します。
5. バッチ進捗ダイアログでファイルごとの結果を確認します。ダイアログを閉じた場合でも最近のバッチを再表示できます。

形式チェック・重複対応・バッチステータスの詳細は[アクティビティファイルのアップロード](/ja/docs/guide/upload-activity-files)をご覧ください。

### プラットフォーム同期

対象プラットフォームの接続設定を開き、提供されているデータ方向を確認したうえで認可を完了し、用意されている場合は初回インポートまたは手動同期を実行します。ジョブの結果が出るまで待ち、アクティビティ一覧で基準となるワークアウトを探します。

同期の要件と過去データの取得範囲はプラットフォームごとに異なります。接続済みと表示されていても、想定した過去ワークアウトがすでに到着しているとは限りません。認証情報は必ずプラットフォームの公式接続フローにのみ入力してください。

### モバイル記録

記録を終了して保存し、アプリの同期完了を待ちます。同じワークアウトを再記録する前に、復元待ちや未アップロードの状態がないか確認してください。手順は[モバイル記録](/ja/docs/guide/mobile-recording)を参照してください。

## 4. インポート進捗とアクティビティ解析を区別する

| 表示されている状態 | 確認すること |
| --- | --- |
| キュー待ちまたは処理中のインポート項目 | インポートバッチ内で最終ステータスになるまで待ちます |
| 完了、またはアクティビティへのリンク | アクティビティを開き、個別の解析ステータスを確認します |
| 重複としてスキップ | どの既存アクティビティと一致したか確認します |
| 一部失敗 | どのファイルまたは解析が失敗したかを特定し、利用可能な結果を確認します |
| 失敗 | 元ファイルやプラットフォーム操作を再試行する前にエラー内容を確認します |

すべてのグラフや派生指標が完成する前に、アクティビティ自体が一覧に表示されることがあります。センサーデータの欠如、処理リクエストの失敗、非対応ファイルではそれぞれ対処法が異なります。

## 5. 記録されたアクティビティを確認する

ソース、種目、現地日付、時間、距離を確認します。そのうえで、元の記録に実際に含まれている計測項目だけをチェックしてください。

| 元データに含まれる情報 | 表示・分析できる内容 |
| --- | --- |
| GPS サンプル | 記録されたルートと位置情報に基づくコンテキスト |
| 心拍数サンプル | 心拍数グラフと対応する派生分析 |
| パワーサンプル | パワーグラフと閾値ベースの分析（推定パワーは別途明示されます） |
| 利用可能な時系列レコード | 対応している詳細グラフ、タイムライン確認、区間統計 |

連携元のプラットフォームに記録・共有されていない計測値は取得できません。想定した項目が欠けている場合は、インポートをやり直す前に連携元プラットフォームと元ファイルを比較してください。

## 6. 日常のトレーニング運用へつなげる

[アクティビティ詳細](/ja/docs/guide/activity-detail)を開いて内容を振り返ります。カレンダーで現地日付を確認し、該当する予定ワークアウトに紐づけましょう。その後、対象種目と利用可能な履歴を使って [PMC](/ja/docs/guide/pmc-forecast) を確認します。

アクティビティ同期が完了しても、睡眠・HRV・終日の健康データがすべて取り込まれているとは限りません。利用可能なデータカテゴリごとに個別に確認してください。

## 結果の確認

基準となるワークアウトが意図した経路から 1 件だけ表示され、インポートと解析の結果が明確で、ソースと日付が正しく、センサー項目の有無を説明できる状態になっていれば完了です。予定セッションに該当する場合は、記録内容を確認したうえで紐づけを行ってください。

## よくある質問

### プラットフォームは接続済みなのにアクティビティが見つかりません

対応する取得期間、接続した元アカウント、同期ジョブの結果、アクティビティ一覧のフィルターを確認してください。提供されている手動同期を 1 回実行し、別のインポートを始める前にジョブ完了を待ちましょう。

### 同じワークアウトが 2 件表示されます

ソース、開始時刻、時間、センサー項目の網羅状況を比較してください。記録を削除する前に（特に片方がプランに紐づいている場合）、重複転送している経路がないか確認しましょう。

### インポート後にグラフが空です

アクティビティの処理ステータスと、元データに利用可能な時系列サンプルが含まれているか確認してください。サマリー数値だけではすべてのグラフは描画されません。リクエストエラーが出ている場合は画面上の再試行操作を使用してください。

### 連携を解除するとインポート済みの履歴も消えますか？

プラットフォーム連携の解除とアクティビティ削除は別の操作です。確定する前に接続ダイアログの説明を確認し、既存のアクティビティは別途チェックしてください。
