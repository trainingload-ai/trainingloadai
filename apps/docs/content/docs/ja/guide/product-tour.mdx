# プロダクトツアー

Trainingload.ai では、トレーニングの計画、実施済みアクティビティのインポート、トレーニング負荷やパフォーマンス変化のレビュー、そして次の練習の調整を一貫して行えます。このガイドでは各ページでできることを紹介します。

## 画面の移動方法

Web および macOS Personal のサイドバーからは、**ホーム**、**プラン**、**カレンダー**、**アクティビティ**、**概要**、さらに設定済みの場合は **コーチ** を開けます。**設定** はサイドバーの下部にあります。Web のツールバーまたは Personal のウィンドウタイトルバーにあるサイドバー切替ボタンや戻る／進むボタンも利用できます。Personal では、**Trainingload.ai → 設定** または `Cmd+,` でも同じ設定ページを開けます。

## ホームと「今日」

Web の「ホーム」またはモバイルの「今日」を開くと、予定されているトレーニング、最近のアクティビティ、確認が必要なリマインダーが表示されます。今日の練習内容を決める前に、プラン・アドバイス・現在の状態をまとめて比較できます。

## アクティビティ

「アクティビティ」は実施済みワークアウトの記録一覧です。ここでは次の操作が行えます。

- プラットフォーム連携または FIT・TCX・GPX ファイルからデータをインポートする
- フィードを検索・絞り込む
- 詳細なルートマップやセンサーグラフを開く
- 対応している項目で種目分類やセッション RPE を修正する
- アクティビティをエクスポートまたは削除する
- アクティビティを予定ワークアウトに紐づける
- 筋力トレーニング特有の種目・セットデータを確認する

詳しくは[アクティビティ一覧と検索](/ja/docs/guide/activity-feed-search)および[アクティビティ詳細](/ja/docs/guide/activity-detail)をご覧ください。

## カレンダーと日別詳細

カレンダーでは、予定ワークアウト・実施済みアクティビティ・レース予定を同じ日付軸に並べて表示します。日別詳細は「何をする予定だったか」と「実際に何をしたか」をつなぐ画面であり、未紐づけのアクティビティやレース当日の重複に最も早く気づけます。

日付選択、アクティビティの紐づけ、予定案の調整については[カレンダーガイド](/ja/docs/guide/calendar)をご覧ください。

## プランと構造化ワークアウト

トレーニングプランは手動で作成することも、AIコーチにドラフト作成を依頼することもできます。各ワークアウトにはステップ、強度目標、メモを設定できます。プランを開始したあとは、実施済みアクティビティを紐づけて予定負荷と実績負荷を比較し、必要に応じて一時停止・完了・スケジュール調整を行えます。

続きは[プランとワークアウト](/ja/docs/planning)をご覧ください。

## AIコーチ

AIコーチは、アクティビティ・プラン・トレーニング状態をもとに質問に答え、プラン案を作成し、ワークアウトの調整を提案します。変更を適用する前に、AI が参照した記録と、変更前後の日付・ワークアウト内容・トレーニング負荷を確認してください。

## レース（大会）

レースの日付、種目、距離、重要度、目標タイム、開催地、メモを「レース」に登録できます。トレーニングスケジュールとの兼ね合いを確認しやすく、通常のワークアウトとは分けて管理できるため便利です。

## ダッシュボードと分析

ダッシュボード、分析、パワー、心拍数、ペース、PMC、距離別ベスト、マップ、指標履歴といった各ビューは、同じアクティビティ履歴から異なる問いに答えます。単発の数値を眺めるだけでなく、「トレーニング負荷が安定して積み上がっているか」「効率が改善しているか」といった仮説を検証するために活用してください。

## プロフィール・閾値・ゾーン・現在の状態

プロフィール設定では、単位、タイムゾーン、体組成データ、種目設定、閾値、ゾーンモデル、負荷ソースの優先順位を設定します。モバイルから入力する「現在の状態」は、その日のレビューに役立つ短期的なコンディション情報を補完します。

## 連携・通知・利用状況

「連携」では対応プラットフォームとのアクティビティ・ワークアウト送受信を管理します。「通知」にはインポートやレビューの結果が届きます。「レビュー自動化」では自動実行する AI レビューの対象を設定でき、「利用状況」では AI 利用枠と消費状況を確認できます。

## モバイル記録

スマートフォンでワークアウトを記録し、保存後にアップロード完了を待ちます。グラフや分析を開く前に、アクティビティ一覧に表示されていることを確認してください。記録が中断された場合は、新たにアップロードをやり直す前に既存セッションを復元できるか確認しましょう。
