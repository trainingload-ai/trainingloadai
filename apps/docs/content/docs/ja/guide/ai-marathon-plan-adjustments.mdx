# AIによるマラソンプラン調整

AIコーチは、プラン・アクティビティ・トレーニング負荷の文脈を結びつけて調整案を作成できますが、マラソン期全体の計画を黙って書き換えるべきではありません。確認してから適用できる「明確で控えめな提案を 1 つ作る」ために活用しましょう。

## 始める前に

- 対象の進行中プランを開き、日付・目標・現在の週を確認します。
- 最近のアクティビティの処理を完了させ、予定ワークアウトに紐づけます。
- 関連する PMC 期間を確認し、必要に応じて有効 VO2max / VDOT の推移もチェックします。
- 現実の制約条件（練習可能日、痛みや体調不良の懸念、移動・旅行、使用器具、最も守りたいポイント練習）を整理します。
- 下したい判断を 1 つに絞ります（例：明日のマラソンペース走を予定通り行うか移動するか、向こう 7 日間をシンプルにするか、抜けたロング走にどう対応するか）。
- AIコーチに医学的な運動許可や怪我の診断を求めないでください。

## 1. プランの文脈から始める

誤ったスケジュールについて議論するリスクを減らすため、進行中のプランから AIコーチを開くか、新しい会話で正確なプラン名と対象週を明示します。

プロンプトは次の 4 要素で構成すると効果的です。

1. **判断（Decision）：** 答えが欲しい 1 つの問い
2. **根拠（Evidence）：** 実施済み／未実施セッション、PMC パターン、反応トレンド、主観的体調
3. **制約（Constraints）：** 変更してはいけない日付やワークアウト
4. **出力形式（Output）：** 控えめな調整案 1 つと次の確認ポイント

プロンプト例：

> 進行中のマラソンプランの第 7 週をレビューしてください。火曜の閾値走が予定よりきつく、週末後に ATL が上昇しましたが、土曜のロング走は維持したいです。今後 7 日間で最大 1 件の調整案を作成してください。週間頻度は保ち、根拠・具体的な変更内容・次の確認ポイントを説明してください。まだ適用はしないでください。

## 2. AIが参照した根拠を確認する

変更内容を検討する前に、回答が次の要素を正しく参照しているか確認します。

- 正しいプラン・週・種目
- 正しい実施済みまたは未実施のワークアウト
- CTL・ATL・TSB の適切な対象期間
- 実際の次のポイント練習
- こちらが伝えた制約条件

対象が 1 つでも違っている場合は一度止め、正しい情報を伝え直してください。誤った記録に基づくもっともらしい提案を確定してはいけません。

## 3. 最小限の変更を依頼する

調整は次の優先順で検討します。

1. 根拠が不十分な場合は、プランを変更せず維持する
2. 目的を変えずにワークアウトの日程を移動する
3. 構成を保ったまま 1 つのワークアウトだけ時間を短縮する
4. 優先度の低いポイント練習 1 回を軽い有酸素ジョグまたは休養に置き換える
5. 小さな調整では解決できない場合にのみ、週全体のボリュームや強度を変更する

頻度・ボリューム・強度・ポイント練習の配置を同時に変えないでください。要因が混ざり、結果の評価ややり直しが難しくなります。

## 4. 確定前に提案をレビューする

コーチとの会話内で **ワークアウトカレンダーを表示** を選び、プレビュー上で変更前と変更後のセッションを見比べます。

| チェック項目 | 確認する問い |
| --- | --- |
| 対象（Target） | 意図した将来のワークアウトと日付になっているか？ |
| 範囲（Scope） | 変更される主要な変数は 1 つだけか？ |
| 目的（Purpose） | マラソン期の本来の狙いを引き続き満たしているか？ |
| 制約（Constraints） | 守りたいロング走・レース・休養日・練習可能日が維持されているか？ |
| 根拠（Evidence） | 観測されたデータと解釈が説明の中で区別されているか？ |
| 確認点（Review） | 次のチェックポイントが明確になっているか？ |

完了済み履歴、別のプラン、無関係な複数ワークアウト、または守るべき制約を変更しているドラフトは、そのまま確定せず却下または修正を依頼してください。

## 5. 確定後、プランを確認する

スケジュールを確認したら **プラン変更を確定** を選択し、続けて次を行います。

1. 進行中のプランまたはカレンダーを開き直します。
2. 対象ワークアウトの日付・種目・時間・構成を確認します。
3. 周辺のワークアウトが意図せず変わっていないか確認します。
4. 利用可能な場合は、プランやレビューのメモに調整理由を残します。
5. 次の同等のポイント練習後に確認ポイントを設定します。

適用後に誤りに気づき、取り消し（Undo）が表示されている場合はすぐに実行してください。表示されない場合は現在のプランバージョンを確認し、影響を受けた将来のワークアウトだけを直接編集します。

## 調整結果の検証

- AIコーチが正しいプラン・週・アクティビティ・期間を参照していたこと
- 確定前に変更前後の具体的な内容を確認できたこと
- 意図した将来のワークアウトだけが変更されたこと
- 完了済み・スキップ済み・紐づけ済みの履歴がそのまま保持されていること
- 守るべき制約とマラソン期の目的が維持されていること
- 進行中のプランとカレンダーに同じ更新内容が反映されていること
- 次の具体的な確認ポイントが記録されていること

## トラブルシューティング

- **回答が一般的すぎる：** プランページから会話を開き、正確な週とワークアウト名、根拠、制約を伝えてください。
- **別のアクティビティやプランを参照している：** 確定しないでください。正しいレコードを開くか、対象プランの文脈で新しい会話を始めましょう。
- **提案の書き換え範囲が広すぎる：** 「変更は 1 件、主要変数は 1 つ、守るべき制約を明示、対象は最大 7 日間」と指定し直してください。
- **バージョン競合で適用に失敗する：** 進行中のプランを再読み込みして最新版を確認し、最小限の変更を改めて依頼・適用してください。
- **適用結果が想定と違う：** Undo が使える場合はすぐ実行し、使えない場合はプランを確認して該当の将来ワークアウトだけ手動修正してください。
- **データがまだ処理中または不足している：** プランは変更せず、処理完了や紐づけを終えてから改めて相談してください。
- **痛み・体調不良・異常な症状が判断の主因である：** 専門家や医療従事者の助言を受けてください。AIコーチは診断や運動可否の判断を行えません。
