# 持久系トレーニングの有効VO2maxを理解する

Trainingload.ai は利用可能なアクティビティデータから有効 VO2max / VDOT 値を推定します。詳細ビューではその推移を確認でき、比較可能なランニング履歴が十分にそろっている場合は条件付きの見通しも表示されます。これらはモデルによる推定値であり、ラボでの実測値や将来の結果を保証するものではありません。

[Demo でダッシュボードを開く](https://demo.trainingload.ai/en/dashboard)をクリックし、**VO2Max** カードを選択して画面を確認できます。予測が表示されるかどうかは Demo 内の現在データに依存します。下の予測スクリーンショットにはアプリで描画したサンプルデータを使用しています。

## 始める前に

- 最近のランニングアクティビティをインポートし、処理完了を待ちます。
- プロフィールで最大心拍数、選択中の推定ソース、および補正係数を確認します。
- 信頼できる入力データと近い目的を持つアクティビティを使い、センサー・地形・推定設定の変更点があれば把握しておきます。
- 結論を記録するときは、「個別アクティビティの推定値」「現在値」「将来予測」を明確に区別しましょう。

この予測は条件を満たすランニング観測データを使用します。ダッシュボードの種目フィルターを切り替えても、サイクリングやスイミングの予測が生成されるわけではありません。

## 1. VO2Max 詳細ビューを開く

ダッシュボードで **VO2Max** を見つけてカードを選択します。詳細ビューには現在値、利用可能な場合の 4 週間見通し、グラフ、履歴期間タブ、解説テキスト、および **コーチに質問（Ask Coach）** が表示されます。

予測が利用できない場合でも現在値は表示されることがあります。利用可否のメッセージと、グラフに将来予測が実際に描かれているかを確認してください。

## 2. 履歴ウィンドウを選ぶ

**7日**・**14日**・**30日**・**60日** のタブで、確認したい記録履歴の期間を選びます。まずは比較可能なアクティビティが複数含まれる期間から見始めましょう。

予測が利用可能な場合、グラフには選択タブに対応する将来期間（最大 30 日間）も表示されます。たとえば 7 日タブでは 30 日タブより短い将来区間が表示されますが、サマリーの **4週間後（In four weeks）** の数値自体は引き続き 4 週間時点の終端値を示します。

## 3. どの数値を読んでいるか確認する

| 表示項目 | 表している内容 |
| --- | --- |
| 現在の VO2Max | プロダクト上に表示される現在値 |
| 履歴値とアクティビティ点 | 選択した履歴期間内の各日付における推定値または記録 |
| 現在の推定水準（Current estimated level） | グラフが対応表示している場合、履歴カットオフ時点におけるモデル推定水準 |
| 4週間後（In four weeks） | 利用可能な 4 週間予測の終端値 |
| 参考範囲 または 80%予測区間 | 使用中のモデルに応じてラベル付けされる、予測に付随する幅 |

プロダクトの現在値とモデル推定水準は異なる場合があります。比較する前にラベルと日付を確認してください。また、将来の点は実施済みワークアウトを表すものではありません。

履歴または将来の点にポインターを合わせると、グラフ上の詳細値を確認できます。不自然な履歴点がある場合は、その日付から **アクティビティ** 一覧で元の記録を開き、体力が変わったと結論づける前に計測状態と推定ソースを確認してください。

## 4. 予測とその範囲を読み解く

見通しが利用可能な場合、サマリーには **4週間後** の値、現在値に対する増減方向、付随する範囲、履歴の基準日が表示されます。これらは必ずまとめて読んでください。

**参考範囲（reference range）** は統計的に較正された **80%予測区間（80% prediction interval）** とは異なります。画面に「80%予測区間」と明示されている場合は、記録や共有の際もそのラベルを正確に保ってください。どちらのラベルも、将来の値が必ずその帯の中に収まることを保証するものではありません。

この予測は過去の観測値とモデルの前提に従うものであり、PMC のスケジュール連動型負荷予測とは別物です。将来のワークアウトをカレンダーに追加しても、それだけで VO2Max が表示分だけ向上する証明にはなりません。

推定値は振り返りの文脈として使い、実際のワークアウト実行状況やトレーニング負荷と照らし合わせてください。負荷のワークフローは[PMCの履歴と予測を読む](/ja/docs/guide/pmc-forecast)をご覧ください。

## 5. 予測が利用できない場合の対処

設定を変更する前に、まず表示されているメッセージを確認してください。

| メッセージ | 次のステップ |
| --- | --- |
| さらにランニング履歴が必要です | 条件を満たす処理済みランニング記録を継続的に蓄積してください。現在値だけでは予測に十分な根拠になりません。 |
| 新しいランニング記録が必要です | 直近の該当観測が古くなっていないか確認し、最近のアクティビティをインポートしてください。 |
| 算出方法が変更されました | 推定ソースや補正設定を確認してください。新しい比較可能な観測データが必要になる場合があります。 |
| 予測を利用できません | 利用可能な履歴を引き続き活用しつつ、リクエスト状態やデータ状態を確認してください。 |

履歴グラフが空白に見える場合、選択中の 7 日ウィンドウに観測が含まれていないだけのこともあります。すべての記録が欠けていると結論づける前に、より長い期間タブを試してください。推定値の欠落は「0」ではありません。

好みの予測値を出すためだけに最大心拍数や補正設定を変えないでください。設定変更は表示値だけでなく過去の比較可能性にも影響します。

## 6. 根拠についてAIコーチに質問する

詳細ビューの **コーチに質問（Ask Coach）** を選択すると、現在の水準、過去の推移、および利用可能な 4 週間見通しについて尋ねる質問文が用意されます。目的に合っているか確認して送信してください。

解説してほしい日付やアクティビティを追記し、「記録された事実とモデル推定値を切り分け、不足している文脈も挙げてほしい」と伝えると精度が上がります。このリンクを開いただけでは自動送信やプラン変更は行われません。

提案された変更を確定する前は、アクティビティの根拠、プランの文脈、および通常の[AIコーチ確認フロー](/ja/docs/guide/ai-coach)を確認してください。

## 結果の確認

履歴ウィンドウ、入力ソース、対象日付、現在値、予測の利用可否、範囲ラベルを控えておきましょう。どの観測データが傾向を裏付けており、どこからが予測なのかを説明できる状態になっていれば完了です。

## よくある質問

### 7 日タブを選んでも「4週間後」のサマリーが変わらないのはなぜですか？

タブはグラフの表示期間を切り替えます。グラフに表示される将来区間は短くなりますが、サマリーは引き続き 4 週間終端の予測値を示します。

### 現在値はあるのに予測が表示されないのはなぜですか？

現在値の表示と予測モデルの生成では必要なデータ条件が異なります。ランニング観測数が不足している、データが古い、比較不能である、またはモデルが利用できない場合に予測は非表示になります。

### 1 回のアクティビティが全体の傾向とズレるのはなぜですか？

単発アクティビティの推定値とモデルの現在水準は集計している根拠が異なります。そのアクティビティのソース、センサー品質、地形、練習目的を確認し、1 点だけでブロック全体の成果を判断せず複数の適切な記録を比較してください。

### 予定ワークアウトを追加するとこの予測も変わりますか？

PMC は予定ワークアウトや習慣から将来の負荷を推定しますが、VO2Max の見通しは過去の観測モデルに基づいています。2 つの予測を同じ計算として扱わないでください。

### ウォッチやラボ測定の結果と数値が違うのはなぜですか？

算出方法、入力データ、測定日が異なる場合があります。それぞれの系列の中で一貫して推移を追うことが大切です。測定と推定の概念については[最大酸素摂取量（VO2 Max）](/ja/docs/metrics/maximal-oxygen-uptake)をご覧ください。
