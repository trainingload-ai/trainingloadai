# Strava・Garmin・COROSを接続してワークアウトを取り込む

Cloud サービスでトレーニングプラットフォームを接続し、同期する項目を選び、最初のアクティビティが正しく取り込まれたことを確認します。Garmin OAuth は新しいデータを受信し、ファイルインポートは過去の履歴を補います。

セルフホスト環境では、別途 [Intervals.icu 設定](/ja/docs/self-host/configuration#connect-intervalsicu)および [Garmin Personal API ガイド](/ja/docs/self-host/garmin-personal-api)を参照してください。セルフホスト環境では、以下に記載するすべての Cloud 連携が利用できるわけではありません。

## 始める前に

- 取り込みたいワークアウトを所有しているプラットフォームアカウントでサインインします。
- 各ワークアウトの主経路を 1 つ決めます。たとえば、COROS の記録を COROS 直接と Strava 経由の両方から取り込まないようにします。
- Trainingload.ai にすでに表示されている最新のアクティビティを控えておきます。
- 同期方向を有効にする前に、プロフィール・ゾーン・予定ワークアウトをどちら側で管理するか決めておきます。
- API キーと一時ダウンロードリンクは、必ず該当する Trainingload.ai の接続ダイアログにのみ入力してください。

## 接続画面を開く

Web では、サイドバー下部のアカウントメニューから **アカウント** を開き、**サードパーティ連携** で対象のプラットフォームを選択します。

モバイルでは、**マイページ → メニュー → データ認可** を開きます。OAuth はシステムブラウザでプラットフォームを開き、承認後にアプリへ戻ります。Strava、Polar、COROS、Suunto、Wahoo、Intervals.icu、および Garmin OAuth 接続はモバイルでも管理できます。Garmin の履歴 ZIP や一時リンクによるインポートも、モバイルの Garmin 設定から利用可能です。

対象のプラットフォームカードが表示されない場合、現在のアカウントでは直接連携を利用できません。連携元から FIT・TCX・GPX ファイルをエクスポートし、アクティビティ画面からアップロードしてください。

## Strava を接続する

1. **連携 → Strava** を開きます。
2. 認可前に、直近 60 日間を今すぐインポートするかどうかを選びます。
3. 継続的なデータ方向を選びます。
   - 新しい Strava アクティビティを自動インポートする
   - Strava 以外のアクティビティを Trainingload.ai から Strava へアップロードする
   - Strava からアスリートプロフィールとゾーンをインポートする
   - アスリートプロフィールとゾーンを Strava へアップロードする
4. **Strava と接続** を選択し、求められたアクセス権を承認して Trainingload.ai に戻ります。
5. Strava を開き直して保存済み設定を確認し、突き合わせが必要な場合は **今すぐ同期** を 1 回実行します。

どちらを正本にするか意図的に決めていない限り、プロフィールの両方向同期を同時に有効にしないでください。自動アクティビティインポートは Strava からの通知で動作します。手動同期は突き合わせ用であり、同じ期間を繰り返しインポートするためのものではありません。

Strava がアカウントの唯一のサインイン方法である場合、パスワードまたは別のログインアカウントを追加するまで連携解除が制限されることがあります。これは Trainingload.ai アカウントへのアクセスを保護するためです。

## Polar を接続する

1. **連携 → Polar** を開きます。
2. 直近 30 日間を今すぐインポートするかどうかを選びます。
3. Polar を継続的なソースとする場合は、新規アクティビティの自動同期を有効にします。
4. Polar から対応する日次活動量・継続心拍数・睡眠データを取り込みたい場合のみ、ウェルネス同期を有効にします。
5. **Polar と接続** を選択し、Polar Flow でアクセスを承認して Trainingload.ai に戻ります。
6. ダイアログを開き直し、直近のデータが表示されていない場合は **今すぐ同期** を 1 回実行します。

Polar の手動同期は対応する直近期間をチェックするものであり、アカウント全体のアーカイブ取得ではありません。Strava と同様に、Polar が唯一のサインイン方法である場合は別のサインイン方法を追加するまで解除できません。

## COROS を接続する

1. **連携 → COROS** を開き、OAuth 認可を完了します。
2. カードが接続済みになったら、**アクティビティを同期** を選択してワークアウトを突き合わせます。
3. Web では **日次データを同期**、モバイルでは **ヘルスを今すぐ同期** を選択し、対応する日次・健康データを同期します。
4. カードに表示されている最終同期状態とエラーの有無を確認します。

COROS ではアクティビティ同期と日次データ同期の操作が意図的に分離されています。アクティビティ同期が成功していても、ヘルス同期が実行されたとは限りません。COROS カードが表示されない場合は、代わりにアクティビティファイルのアップロードを使用してください。

## Intervals.icu を接続する [#connect-intervalsicu]

特別な理由がない限り、OAuth を使用することをおすすめします。

### OAuth

1. **連携 → Intervals.icu → OAuth** を開きます。
2. Intervals.icu 側で Trainingload.ai を認可し、同じアカウントに戻ります。
3. 必要な同期方向を選択します。
4. 設定を保存し、初回同期または手動同期を 1 回実行します。

### API キー

1. ご自身の Intervals.icu アカウントで API キーを作成またはコピーします。
2. **連携 → Intervals.icu → API キー** を開きます。
3. 保護された入力欄にキーを貼り付けて接続します。
4. アカウントで別のキーがすでに使われている場合は、差し替えを確認します。

Trainingload.ai は保存済みのキーを再表示せず、接続済み画面では末尾 4 桁のみ表示します。OAuth から API キーへ、または API キーから OAuth へ切り替えても、すでにインポート済みの履歴は保持され、今後の同期に使う認証情報のみが変更されます。

現在有効な機能に応じて、ダイアログでは次の項目を設定できます。

- 毎日の自動アクティビティ同期
- Trainingload.ai からのアクティビティエクスポート
- アスリートプロフィールとゾーンのインポート／エクスポート
- 予定ワークアウトのインポート／エクスポート

ゾーンと予定ワークアウトをどちらのプラットフォームで管理するか決めておいてください。両方向の自動更新を有効にすると、残したかった変更が上書きされることがあります。

予定ワークアウトのインポートには、インターバルステップを持たない通常のカレンダーワークアウトも含まれます。これらは独立したワークアウトであり、トレーニングプランがなくても取り込まれます。日付・名称・種目・説明および入力された時間がカレンダーとホームの「今日のワークアウト」に表示され、未入力の時間や強度は不明のままになります。実施済みアクティビティを手動で紐づけたり、紐づけを解除したりできます。アクティビティをアップロードしても、これらの通常ワークアウトが自動的に完了扱いになることはありません。これらに対するローカル編集は Intervals.icu へエクスポートされず、構造化ワークアウトファイルも生成されません。

## Suunto を接続する

1. **連携 → Suunto** を開きます。
2. 必要な継続方向（自動ワークアウトインポート、ウェルネスデータ、実施済みアクティビティのエクスポート、予定ワークアウトのエクスポート）を選びます。
3. OAuth 接続を選択し、Suunto 側でワークアウトへのアクセスを承認します。
4. Trainingload.ai に戻り、最近のワークアウトの初回インポートを待ちます。
5. 設定変更の保存や **今すぐ同期** の実行が必要な場合はダイアログを開き直します。

新しいワークアウトは通常 Suunto からの通知で届き、定期的な突き合わせ同期がバックアップとして機能します。ウェルネスデータには対応する心拍数・歩数・睡眠・回復データが含まれる場合があります。連携を解除しても、すでに取り込まれたワークアウトは削除されません。

## Wahoo を接続する

1. **連携 → Wahoo** を開きます。
2. 必要な方向（自動ワークアウトインポート、実施済みアクティビティのエクスポート、予定ワークアウトのエクスポート、プロフィールのインポート／エクスポート）を選びます。
3. OAuth を開始し、Wahoo でアクセスを承認して Trainingload.ai に戻ります。
4. 設定を保存し、直近のワークアウトが欠けている場合は **今すぐ同期** を 1 回実行します。

どちらのプラットフォームを正本にするか決めずに、プロフィールのインポートとエクスポートを同時に有効にしないでください。再接続を試す前に、ダイアログ内の最終同期時刻と最新エラー欄を確認しましょう。

## モバイルで連携を管理する

モバイルの連携シートは Web と同じ保存済み接続を参照するため、変更内容は両方のクライアントに反映されます。

1. **マイページ → メニュー → データ認可** を開き、プラットフォームを選択します。
2. Strava や Polar で初回同期オプションが表示される場合は、OAuth の前に選択します。
3. システムブラウザで認可を完了し、アプリへ戻る操作を許可します。
4. プラットフォームを開き直し、対応する同期方向を設定します。
5. **設定を保存** を選択し、突き合わせが必要なときだけ **今すぐ同期** を実行します。
6. COROS の場合は、アクティビティ同期とヘルス同期を個別に実行してください。

Intervals.icu には専用のモバイル設定シートがあります。Garmin 設定からも ZIP または一時ダウンロードリンクによる履歴インポートを利用できます。

## 新規データ用に Garmin を接続する

**現在、Trainingload.ai の Garmin 公式 OAuth 接続では、認可前に記録されたアクティビティを取得できません。接続を解除して再接続しても履歴は補完されません。** 過去の記録には Garmin の完全エクスポート ZIP（または一時ダウンロードリンク）をインポートするか、個別の FIT・TCX・GPX ファイルをアップロードしてください。この制限はセルフホスト版の Garmin Personal API には当てはまりません。セルフホスト環境では専用ガイドに従ってください。

1. **アカウント → サードパーティ連携 → Garmin** を開きます。
2. **OAuth** を選択し、Garmin 側でアクセスを承認して Trainingload.ai に戻ります。
3. ページに **Garmin 接続済み** と表示されていることを確認します。
4. 必要に応じて **新規アクティビティ** や **健康と回復** を有効にし、設定を保存します。
5. 新しくワークアウトを記録した後、アクティビティ画面でソースと詳細を確認します。

この接続は新しいデータのみを受信します。過去のアクティビティには下記の **ファイルインポート** を使用してください。OAuth が表示されない場合もファイルインポートを使用します。セルフホスト環境の場合は [Garmin Personal API ガイド](/ja/docs/self-host/garmin-personal-api)を参照してください。

## Garmin 履歴をインポートする

履歴インポートは過去のアクティビティを取り込むための機能であり、継続同期を有効にするものではありません。新しいトレーニングを受信するには上記の Garmin OAuth 接続を使用してください。

1. Web では **アカウント → サードパーティ連携 → Garmin**、モバイルでは **マイページ → メニュー → データ認可 → Garmin → 履歴インポート** を開きます。
2. ダイアログから [Garmin 公式データエクスポートページ](https://www.garmin.com/account/datamanagement/exportdata/) を開き、エクスポートを依頼します。
3. Garmin からのメールが届くのを待ちます（到着までの時間は Garmin 側に依存します）。
4. インポート方法を選びます。Garmin 完全エクスポート ZIP をダウンロードしてアップロードするか、メールの **Download** ボタンに設定されている URL をコピーします。
5. Garmin 履歴インポートダイアログで **ファイルをアップロード** または **URL を使用** を選び、**インポートを開始** を選択します。非常に大きなエクスポートでは URL 方式のほうが高速なことが一般的です。
6. ダイアログに戻り、キュー待ち・ダウンロード中・スキャン中・インポート中・完了・一部失敗・失敗の各ステータスを確認します。
7. 完了したら、検出件数・キュー登録件数・インポート件数・重複件数が想定と合っているか比較します。

エクスポート URL は一時的なダウンロード認証情報として機能します。チャット、AIコーチ、Issue、スクリーンショットには絶対に貼り付けないでください。Trainingload.ai は安全な Garmin ホストの URL のみを受け入れ、ジョブ待機中は暗号化して保持し、アーカイブのダウンロード完了後に削除します。直接アップロードされた ZIP も同様にインポートにのみ使用され、スキャン後に削除されます。

## ログインアカウントとの違い

**ログインアカウント** 配下にある Google、Apple、GitHub は認証手段です。これらを連携するとサインインに使えるようになりますが、ワークアウト・健康データ・プラン・プロフィールゾーンはインポートされません。パスワードを設定するか別のアカウントを連携するまで、最後に残ったログイン手段は削除できない場合があります。

## すべての接続を確認する

プラットフォームを接続したあとは、次の点を確認しましょう。

1. カードが **接続済み** と表示されていること。
2. カードを開き直し、選んだ設定が保存されていること。
3. 初回同期または手動突き合わせを最大 1 回だけ実行すること。
4. **アクティビティ** を開き、想定したソースで既知の最新ワークアウトが 1 件表示されていること。
5. アクティビティ詳細を開き、心拍数・パワー・GPS・標高など元データに含まれる項目が正しく反映されていること。
6. 双方向機能を使う場合は、影響の小さいテスト変更を 1 件行い、意図した転送先のみが変わることを確認すること。

OAuth から戻ってきたことだけでアクティビティがインポートされたと判断しないでください。認可・データ取り込み・アクティビティ解析はそれぞれ別の段階です。

## トラブルシューティング

| 症状 | 確認すべき点 |
| --- | --- |
| OAuth から戻ったのにカードが未接続のまま | プラットフォームカードからやり直し、求められた権限をすべて承認して、同じ Trainingload.ai アカウントに戻っているか確認してください。古い認可 URL は再利用しないでください。 |
| 接続済みなのに最近のアクティビティが表示されない | プラットフォームの初回取得期間を確認し、手動同期を 1 回実行して処理を待ってから、アクティビティを日付とソースで検索してください。古い記録にはファイルアップロードや Garmin 履歴インポートが必要な場合があります。 |
| 同じワークアウトが 2 件表示される | 両方のソースラベルを確認し、さらにデータを取り込む前に重複転送している経路を無効にしてください。 |
| 心拍数・パワー・GPS・標高が欠けている | まず元のプラットフォームでアクティビティを開いてください。元側が提供していないストリームデータは取り込めません。 |
| プラットフォームカードが表示されない | COROS の提供状況はプラットフォーム側の承認や段階公開状況に依存する場合があります。利用できない間はファイルアップロードを使用してください。 |
| Intervals.icu で新しいキーへの差し替えが拒否される | 新しいキーが対象アカウントのものか確認し、認証情報の差し替えを明示的に承認してください。 |
| Garmin がリンクを拒否する | ダウンロードした ZIP を直接アップロードするか、メール画面の URL ではなく **Download** ボタンのリンク先 URL をコピーし、安全な Garmin ホストの URL であることを確認してください。 |
| 連携解除ボタンが使えない | そのプラットフォームが唯一のサインイン手段になっている場合、先にパスワードまたは別のログインアカウントを追加してください。 |

## よくある質問

### Strava を Trainingload.ai に接続するには？

**アカウント → サードパーティ連携 → Strava** を開き、60 日間のインポートとデータ方向を選択してから認可します。戻ったあと最新のライドやランが見当たらない場合は、Strava を開き直して **今すぐ同期** を 1 回実行してください。

### Garmin を接続して継続同期できますか？

はい。Garmin の **OAuth** 接続は、保存した設定に従って新しいアクティビティと許可された健康データを受信します。**履歴ファイルインポート** は過去の記録を補うものであり、継続同期は有効になりません。両方を併用できますが、同じアクティビティを繰り返しインポートしないよう注意してください。

### COROS や Polar はどう接続しますか？

プラットフォームカードを認可してから初回同期を実行します。COROS は **アクティビティを同期** と日次／ヘルス同期が分かれており、片方の成功はもう一方の実行を保証しません。Polar は直近 30 日間と、必要に応じてウェルネスデータを取り込めます。

### 同じワークアウトが 2 回表示されるのはなぜですか？

同じ記録が 2 つのインポート経路（例：COROS 直接＋Strava 経由）から取り込まれています。ワークアウトごとに主経路を 1 つに決め、追加の履歴を取り込む前に余分な経路を無効にしてください。

## 次のステップ

- 2 つ目の経路を認可する前に[トレーニングアプリ連携](/ja/docs/guide/integrations)で各サービスを比較する。
- 処理やソース識別の仕組みは[トレーニングデータの接続](/ja/docs/guide/connect-data)で確認する。
- 非対応プラットフォームや個別の過去ファイルには[アクティビティファイルのアップロード](/ja/docs/guide/upload-activity-files)を利用する。
- 最初の 1 週間分のセッションを取り込んだら[CTL・ATL・TSB でトレーニング負荷をプラン内で管理](/ja/training-load)する。
