# アクティビティ一覧と検索

アクティビティ一覧は、Trainingload.ai における実施済みワークアウトのメインフィードです。同期されたアクティビティ、アップロードしたファイル、手動インポート、マッププレビュー、トレーニング負荷、プランへの紐づけ情報をまとめて表示します。

次のような確認をしたいときに活用してください。

- 最近どんなトレーニングをしたか
- 新しいインポートが到着したか
- まだレビューしていないワークアウトはどれか
- アクティビティが正しいプランのワークアウトに紐づいているか
- より詳しく分析するためのアクティビティ詳細ページはどこか

## 始める前に

- プラットフォームを連携するか、[アクティビティファイルをアップロード](/ja/docs/guide/upload-activity-files)します。
- 特定のインポートを探す場合は、おおよその日付・種目・ソースを把握しておきます。
- アクティビティをプランに紐づける場合は、対象プランが進行中でありアクティビティの日付を含んでいることを確認します。

## 確認ワークフロー

1. **アクティビティ** を開き、一覧を更新します。
2. 最新のカードと処理ステータスを確認します。
3. 期間、種目、その他の表示フィルターで一覧を絞り込みます。
4. 指標や負荷が欠けていると判断する前に、アクティビティ詳細画面を開いて確認します。
5. 日付・種目・セッションの意図を確認したうえで、予定ワークアウトに紐づけます。

## アクティビティ一覧

**アクティビティ** を開くと最近のワークアウトが表示されます。各カードには次の情報が表示されます。

- アクティビティタイトル
- 種目タイプ
- 開始時刻
- 距離と時間
- トレーニング負荷（利用可能な場合）
- 取り込み元（Garmin、Strava、手動アップロードなど）
- アクティビティステータス
- マップのサムネイル（ルートデータがある場合）
- プランワークアウトへの紐づけ（進行中プランの期間内にある場合）

スクロールすると過去の項目が追加読み込みされます。モバイルでは一覧の上部から下に引いて更新します。

## アクティビティのステータス

カードには次のようなステータスが表示されることがあります。

- **同期済み（Synced）**：Trainingload.ai にインポートまたは同期された状態です。
- **レビュー待ち（Pending review）**：利用可能ですが、まだレビューされていません。
- **レビュー済み（Reviewed）**：すでにレビュー済み、またはレビューフローを完了しています。
- **不明（Unknown）**：ステータス情報を取得できませんでした。

ステータスラベルは一覧の整理に役立ちますが、詳細ページの代わりにはなりません。グラフや指標、解析結果を確認するときは必ずアクティビティを開いてください。

## 検索とフィルター

一覧が多すぎる場合は検索やフィルターを使います。

主なクイックフィルター：

- 直近 7 日間
- 直近 30 日間
- ランニング
- サイクリング
- スイミング

検索ページのフィルターを使って一覧を絞り込みます。探しているアクティビティが見つからない場合は、フィルターを解除して期間を広げ、種目とソースを確認してください。

## アクティビティを開く

サマリーカード以上の情報を見たいときはアクティビティを開きます。

詳細ページでは次を確認できます。

- 詳細なサマリー指標
- グラフと時系列データ
- ルートと地形のコンテキスト
- トレーニング負荷と強度
- 心拍数・パワー・ペース・標高の推移
- そのワークアウトに対する AIコーチ向けプロンプト

詳しくは[アクティビティ詳細](/ja/docs/guide/activity-detail)をご覧ください。

## プランのワークアウトに紐づける

進行中のプランがあり、アクティビティの日付がプラン期間内に入っている場合、カードにプラン紐づけ操作が表示されます。

これを使って実施済みワークアウトを該当するプランセッションに結びつけます。

紐づけを行うことで、Trainingload.ai は次を比較できるようになります。

- 予定ワークアウトと実施済みアクティビティ
- 予定負荷と実績負荷
- 完了ステータス
- プラン遵守率
- AIコーチによるプランのフォローアップ

誤ったワークアウトに紐づけてしまった場合は、紐づけを解除して正しいものを手動で選び直してください。

## アクティビティのエクスポートと削除

カードのメニューには次の操作が含まれる場合があります。

- **表示**：アクティビティ詳細ページを開きます。
- **エクスポート**：対応している場合、GPX・FIT・TCX 形式でダウンロードします。
- **削除**：確認のうえでアクティビティを削除します。

削除は慎重に行ってください。プランのワークアウトに紐づいているアクティビティを削除すると、プランの実行サマリーや負荷比較が変化します。

## マップ表示への入口

アクティビティページからマップビューを開ける場合があります。ルートの文脈を確認したいときに便利です。

- 複数ルートの比較
- どこでトレーニングしたかの振り返り
- GPS 付きアクティビティの視覚的な検索
- ルートに欠損や異常がないかのチェック

場所の確認にはマップビューが適していますが、詳細な指標分析にはアクティビティ詳細ページを使用してください。

## トラブルシューティング

アクティビティが見つからない場合：

- インポートバッチが完了しているか確認します。
- 一覧を更新します。
- より広い期間で検索します。
- 元のプラットフォームにそのワークアウトが実際に存在するか確認します。
- 削除済み、またはフィルターで除外されていないか確認します。

トレーニング負荷やグラフが表示されない場合：

- アクティビティ詳細ページを開き、処理ステータスを確認します。
- 元ファイルに必要なセンサーデータが含まれているか確認します。
- プロフィールの閾値とゾーンを確認します。
- アップロード直後の場合は、解析完了まで待ちます。

## 結果の確認

- 目的のアクティビティが正しい開始時刻・種目・ソースで 1 件だけ表示されていること
- カードを開くと期待通りのアクティビティ詳細へ遷移すること
- 紐づけ済みアクティビティが、単に近い日付ではなく意図した予定ワークアウトに紐づいていること
- フィルターを解除してもアクティビティが意図せず消えないこと
- エクスポートや削除は対象のアクティビティであることを確認してから実行すること
