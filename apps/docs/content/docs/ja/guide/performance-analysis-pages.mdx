# パフォーマンス分析ページ

「分析（Analysis）」を開くと、パワー、心拍数、ペース、PMC など、トレーニングのパフォーマンスと負荷を見るための各種ビューを選べます。調べたい問いに合わせて下の表からページを選んでください。

## 始める前に

- 対象のアクティビティが「完了（Ready）」ステータスになるのを待ちます。
- ゾーン分布を解釈する前に、プロフィールの閾値と種目別ゾーンを確認します。
- 1 つの種目と 1 つの判断対象期間に絞ります。
- 選んだページに必要なセンサーデータ（パワー、心拍数、または有効な距離と時間）がアクティビティに含まれていることを確認します。
- ページをまたいで数値を比較する際は、同じ単位系とタイムゾーンを使用します。

## 1. 「分析」からページを選ぶ

**分析** を開き、ツールを検索または選択します。

| 調べたい問い | ページ | 表示される内容 |
| --- | --- | --- |
| どれくらいの量・頻度で練習したか？ | アクティビティ統計（Activity Stats） | 年間ヒートマップと、距離・時間・心拍数・回数・カロリーの推移 |
| 最近のトレーニング負荷はどう変化したか？ | PMC | CTL・ATL・TSB による負荷コンテキスト |
| 持続パフォーマンスのベスト記録は？ | 距離別ベスト（Best Distance） | 固定距離または固定時間ごとのランキング |
| パワー能力はどう変化したか？ | パワー（Power） | カーブ、最大パワー、ゾーン分布、パワープロフィール |
| 特定種目のペースはどう変化したか？ | ペース（Pace） | ペースカーブとペースゾーン分布 |
| 心拍の持続値やゾーン配分はどうか？ | 心拍数（Heart Rate） | 心拍カーブと心拍ゾーン分布 |

**Progression** には **近日公開（Coming soon）** と表示されています。現在利用可能なレポートとして扱ったり、既存ページで答えられる問いのために待ったりする必要はありません。

## 2. グラフを読む前にフィルターを揃える

パワー、ペース、心拍数の各ページでは、最初に種目と期間を設定し、タブを切り替える間も固定しておきます。

- 現在の状態を確認する場合は単一の期間を使用します。
- 複数期間の比較は、ページが対応しており比較目的が明確な場合にのみ追加してください。
- 「ペース」では特定の種目を指定する必要があり、全種目一括表示はありません。
- 「パワー」と「心拍数」は全種目表示も可能ですが、複数種目が混ざると解釈が難しくなることがあります。
- グラフが表示されない場合、選択期間内に条件を満たすセンサーデータが存在しないケースが多くあります。

結果を比較するときは、種目・持続時間・対象期間をセットで記録しましょう。たとえば単発の最高値に頼るのではなく、直近 90 日間のサイクリング 5 分パワーをその前の 90 日間と比較するほうが意味のある判断になります。

## 3. パワータブを使い分ける

パワーページには 4 つのビューがあります。

- **カーブ（Curve）**：持続時間ごとの最高持続パワーを示す表とグラフ。複数期間の比較に対応します。
- **最大値（Maximum）**：選択条件における最大パワーの推移。
- **ゾーン（Zones）**：設定済みパワーゾーンごとの時間・作業分布。複数期間の比較に対応します。
- **プロフィール（Profile）**：選択した種目と期間におけるパワープロフィール。

時間別の出力能力には「カーブ」、強度の配分には「ゾーン」、全体傾向の把握には「プロフィール」を使います。それぞれ異なる問いに答えるビューであり、1 つの「体力」判定に無理やり統合しないでください。

## 4. ペースと心拍数を使う

ペースページには次が含まれます。

- **カーブ（Curve）**：距離ごとのペースパフォーマンスを示す表とグラフ。
- **ゾーン（Zones）**：設定済みペースゾーンごとの時間・作業分布。

フィルターに表示されるランニング、サイクリング、スイミングから種目を選びます。スイミングペースはスイミング固有の距離基準、ランニングとサイクリングはそれぞれの表示文脈を使用するため、異なる種目間で生のペース数値を直接比較しないでください。

心拍数ページには次が含まれます。

- **カーブ（Curve）**：持続時間ごとの心拍数の推移。
- **ゾーン（Zones）**：設定済み心拍ゾーンごとの分布。

心拍数は運動に対する身体の反応シグナルです。数値が高いほど良いと決めつけず、時間、ペースやパワー、環境条件、疲労、センサー品質とあわせて解釈してください。

## 5. PMC で負荷の文脈を加える

蓄積されたトレーニングストレスを確認したいときは **PMC / フィットネス管理** を開きます。種目を選び、現在の CTL・ATL・TSB カードをセットで読んだうえで、グラフを「コンディション（Form）」「体力（Fitness）」「疲労（Fatigue）」で切り替えます。日次負荷パネルと日付ツールチップで特定時点の背景を確認できます。

このページでは記録済みの履歴と、利用可能な将来予測を明確に区別しています。将来の日付を解釈する前にその負荷の算出根拠を確認してください。予測が表示されていないことは負荷ゼロを意味しません。詳しい手順、データ要件、ダッシュボード履歴タブについては[PMCの履歴と予測を読む](/ja/docs/guide/pmc-forecast)をご覧ください。

能力応答の推移と別途提供される 4 週間見通しについては、[持久系トレーニングの有効VO2maxを理解する](/ja/docs/guide/effective-vo2max-for-endurance)を参照してください。これらの根拠をプランレビューにつなげる流れは[トレーニング分析ワークフロー](/ja/docs/guide/training-analysis-workflow)をご覧ください。

## 6. 結果を元のアクティビティまで遡って確認する

カーブ上の点、ゾーン分布、負荷の変化が気になったときは、次の手順で裏付けを取ります。

1. 種目、期間、タブ、持続時間、数値を控えます。
2. 該当するアクティビティを開くか、アクティビティ検索で要因となったセッションを探します。
3. 処理ステータス、センサー項目の網羅状況、閾値、明らかなスパイクや欠損を確認します。
4. 観測された事実とご自身の解釈を切り分けます。
5. 根拠に裏付けられた最小限のトレーニング判断を行います。

## 分析結果の確認

- 選んだページが調べたい問いに合っていること
- 種目・期間・単位・ゾーン設定が記録されていること
- 結果が条件を満たす「完了（Ready）」アクティビティに裏付けられていること
- センサーの欠損や異常値を黙って平均化せず、明示的に把握していること
- トレーニング上の判断が元のアクティビティとプランの文脈に紐づいていること

## トラブルシューティング

- **分析ツールの検索で何も出ない：** 検索語をクリアしてください。ツール検索はローカライズされたタイトルと説明に一致します。
- **カードが開けない：** 「近日公開（Coming soon）」と表示されていないか確認してください。
- **カーブやゾーングラフが空になる：** 期間を広げ、正しい種目を選び、該当アクティビティに必要なセンサーストリームが含まれているか確認してください。
- **閾値を編集した後に数値が変わった：** ゾーン分布や派生指標が変わることがあります。過去と比較する前に新しい設定を記録しておきましょう。
- **パワー・ペース・心拍数で印象が異なる：** それぞれ異なる入力と生体反応を測っています。都合の良いグラフだけを選ぶのではなく、問い・対象セッション・環境条件を見直してください。
- **全種目表示の結果がちぐはぐに見える：** 単一種目に切り替えて比較し直してください。
