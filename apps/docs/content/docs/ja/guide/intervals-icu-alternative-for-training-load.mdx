# トレーニング負荷管理における Intervals.icu との比較

すでに Intervals.icu でトレーニングを分析している場合は、ツールを完全に置き換えるか、既存の分析ワークフローを維持しつつ計画とレビューのために Trainingload.ai を併用するかを検討してみてください。

Intervals.icu はアクティビティタイムライン、パワー・心拍グラフ、インターバル分析、カスタムグラフを提供しています。現在の機能は同サービスの[アクティビティ分析概要](https://www.intervals.icu/features/analyze/)をご確認ください。

## Trainingload.ai で試すべきポイント

- 実施済みアクティビティを予定ワークアウトに紐づけ、元のスケジュールと実際の結果を比較する
- アクティビティタイムライン、PMC、パフォーマンス傾向をプランと並べてレビューする
- アクティビティやプランから AIコーチを開き、解説を読んだり提案されたワークアウト変更を確認したりする

まずは[アクティビティ詳細](/ja/docs/guide/activity-detail)、[タイムライン](/ja/docs/guide/activity-timeline)、[プランのステータス管理](/ja/docs/planning/plan-lifecycle)から始め、普段実際に使っているトレーニング業務を比較してみましょう。

## Intervals.icu の記録を接続する

1. Cloud 版では[プラットフォーム接続ガイド](/ja/docs/guide/connect-third-party-platforms#connect-intervalsicu)、セルフホスト環境では[API キー設定](/ja/docs/self-host/configuration#connect-intervalsicu)に従います。
2. 必要な同期方向を選びます。両側から同じスケジュールを更新できるようにする前に、ゾーンとプランの正本をどちらにするか決めてください。
3. 既知のアクティビティを 1 件同期し、日付・時間・ソース・センサーデータを確認します。
4. [カレンダー](/ja/docs/guide/calendar)でワークアウトに紐づけ、予定負荷と実績負荷を比較します。

## 結果を比較する際の注意点

同じアクティビティでも、プラットフォームによってトレーニング負荷やゾーン分布が異なることがあります。差を解釈する前に、元の記録・閾値・負荷ソース設定を比較してください。アクティビティを接続しても、すべてのカスタムグラフ・カスタム項目・プランが自動コピーされるわけではありません。

インポート → ワークアウト紐づけ → レビューという一連の流れを 1 回試す間は両方のプラットフォームを残し、ご自身に合う運用を見極めてください。まずは画面を見てみたい場合は[Demo を開く](https://demo.trainingload.ai/en)をご利用ください。
