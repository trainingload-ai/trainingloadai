# PMCの履歴と予測を読む

PMC は、記録済みのトレーニング負荷と条件付きの将来見通しを一か所にまとめて表示します。トレーニングストレスがどう変化してきたか、そして利用可能な今後の入力からどのような推移が想定されるかを調べるのに役立ちます。予測はあくまで現在の入力に基づく推定値であり、ワークアウトの実施を確定したり特定の判断が適切だと保証したりするものではありません。

[Demo でフィットネス管理を開く](https://demo.trainingload.ai/en/pmc)ことができます。公開 Demo は読み取り専用です。開いたら確認したい種目を選択してください。予測曲線を含むスクリーンショットにはアプリで描画したサンプルデータを使用しています。Demo の数値や予測の表示可否はその時点の記録内容に依存します。

## 始める前に

- 実施済みアクティビティをインポートし、トレーニング負荷の処理完了を待ちます。
- アクティビティの種目分類、閾値、負荷ソース設定、アカウントのタイムゾーンを確認します。
- プランに基づく予測を使う場合は、有効な予定負荷を持つスケジュール済みワークアウトを用意します（ドラフトや日程未定のワークアウトは自動で将来の日次負荷になりません）。
- グラフを説明する際は、記録済みトレーニング・予定トレーニング・推定習慣を明確に区別しましょう。

## 1. フィットネス管理を開いて種目を選ぶ

分析ツールから **PMC / フィットネス管理** を開きます。右上の **種目（Sport）** から「全種目」「ランニング」「サイクリング」「スイミング」を選択します。上部の現在値カード 3 枚とグラフはその範囲を対象とします。

特定のトレーニングブロックを調査するときは、まず 1 種目から始めましょう。ダッシュボード、PMC、関連アクティビティの間を行き来するときも対象範囲を再確認してください。

メインの PMC ページは通常、過去 60 日間の履歴と今後 28 日間の見通しを表示します。上部グラフでは選択中の指標を 1 つ表示し、その下に日次負荷を表示します。

## 2. 見通しを見る前に現在値を読む

3 枚のカードは必ずセットで読みましょう。

| 指標 | 表している内容 | これ単体では証明できないこと |
| --- | --- | --- |
| 体力 / CTL | 長期的に蓄積されたトレーニング負荷 | 測定されたパフォーマンス向上そのもの |
| 疲労 / ATL | 直近のトレーニング負荷により敏感に反応する指標 | 実際の主観的疲労感の診断 |
| コンディション / TSB | 長期負荷と直近負荷のバランス関係 | ワークアウトやレースに向けた万全さの保証 |

上部のカードは記録済みの現在状態を示します。将来の日付にカーソルを合わせてもカード自体は予測値に置き換わりません。算出方法の詳細は [CTL](/ja/docs/metrics/pmc/chronic-training-load)、[ATL](/ja/docs/metrics/pmc/acute-training-load)、[TSB](/ja/docs/metrics/pmc/training-stress-balance) をご覧ください。

## 3. 指標を切り替え、1 日単位で確認する

1. グラフ上部で **コンディション（Form）**、**体力（Fitness）**、**疲労（Fatigue）** を切り替えます。
2. 確認したい日付にポインターを合わせます。ツールチップには日付、記録済み／予測の区分、CTL・ATL・TSB、日次負荷が表示されます。
3. 将来の日付では、数値だけでなく表示されている「算出根拠（basis）」も確認します。
4. 同じ日付の下部負荷パネルと照らし合わせます。曲線の動きと日次負荷は別の量です。

グラフはキーボード操作にも対応しています。グラフにフォーカスを当てて左右の矢印キーで日付を移動でき、**Escape** でツールチップを閉じられます。タッチ端末では日付をタップして確認します。

## 4. 記録済み履歴と条件付き予測を切り分ける

凡例と **今日（Today）** の境界線を目印に読み取ります。記録済みの値は実線、利用可能な将来予測は破線で表示されます。日次負荷パネルでは、記録済み負荷が塗りつぶしバー、将来負荷が淡い表示で区別されます。

通常の予測は有効な予定トレーニングを優先して使用します。該当する予定入力がない場合は、十分に新しく有効な直近トレーニングパターンを用いることがあります。どの根拠が使われているかは各日付のツールチップで確認してください。

| 表示される根拠 | 解釈のしかた |
| --- | --- |
| 予定トレーニング（Scheduled training） | 該当する予定ワークアウトから将来負荷を算出しています。 |
| 最近のトレーニング習慣（Recent training habits） | 最近の練習パターンの推定値を使用しています。カレンダーに新しいワークアウトが追加されたわけではありません。 |
| トレーニング休止（Pause training） | その期間に追加トレーニングを行わない前提のシナリオです。 |
| 予測なし（No forecast） | 利用可能な入力データではその日付の値を算出できません。 |

グラフを開いてもトレーニングが予定登録されたりプラン変更が保存されたりすることはありません。予定ワークアウトがない日は、必ずしも確定した休養日とは限りません。また、負荷が欠落している状態を「負荷ゼロ」とみなさないでください。

見通しの途中で予測が利用できなくなった場合、それ以降の値も前の入力に依存するため空白になることがあります。新しいアクティビティをインポートしたりスケジュールを変更したりすると見通しは更新されます。

## 5. 将来領域が空白になる理由を理解する

将来曲線が表示されない場合でも、過去の履歴自体は引き続き分析に活用できます。空白になる主な原因は、トレーニング履歴が短い／古いこと、記録済み負荷が不足していること、または予定ワークアウトに有効な予定負荷が設定されていないことです。

日付と種目範囲を確認したうえで、最近のアクティビティと該当スケジュールを見直してください。ツールチップに **予測を利用できません** と出ている場合は、その不確実性をそのまま前提にしましょう。ページに **更新に失敗したため前回の結果を表示しています** と出ている場合は、最新取得ではなく直前の結果です。初回読み込みが失敗した場合は **再試行** を使用してください。

## 6. この文脈のままAIコーチに相談する

ページ上部の **コーチに質問（Ask Coach）** を選択します。リンクされた質問には選択中の種目と見通しの文脈が引き継がれます。送信前に準備された質問文を確認してください。リンクを開いただけではトレーニング変更は適用されません。

「最近の負荷変化をどう見るか」「予定セッションのタイミングは適切か」といった具体的な課題を添えましょう。回答が参照したアクティビティと将来前提を確認し、プランやワークアウトの編集案が出た場合は通常の確認フローに従ってください。

マラソンに特化した調整手順は[マラソン調整にPMCを活用する](/ja/docs/guide/pmc-marathon-adjustment)へ進んでください。

## ダッシュボードで短い期間を確認する

ダッシュボードの「体力」「疲労」「コンディション」カードを開くと個別指標ビューが表示されます。ここでは **7日**・**14日**・**30日**・**60日** の履歴タブを切り替えられ、表示される将来期間も選択タブに応じて最大 30 日間まで連動します。これはメイン PMC ページの広範な見通しとは表示範囲が異なります。

グラフを読む前に期間タブを確認し、現在値と選択した将来の日付の区別を保ちましょう。

## 結果の確認

確認した 1 点について、種目・日付・指標・記録済み／予測の区分・負荷根拠を説明できれば完了です。良い解釈では、曲線の動きを実際のアクティビティや予定入力に結びつけつつ、データが欠けている部分も明示します。

## よくある質問

### 将来の日付にカーソルを合わせても上部カードが変わらないのはなぜですか？

上部カードは現在の記録値を表示する仕様です。選択した将来の日付の値はツールチップを確認してください。

### ワークアウトを完了したあとに予測が変わったのはなぜですか？

実績負荷とプランへの紐づけによって入力が更新されるためです。比較する前にアクティビティの処理完了と正しいワークアウトへの紐づけを確認してください。

### ダッシュボードのカードとメイン PMC ページでグラフの範囲が違うのはなぜですか？

ダッシュボードカードの履歴タブは、より短い将来予測ウィンドウと連動します。メイン PMC ページには独自の広い範囲があるため、画面上の位置ではなく同じ種目・同じ日付同士を比較してください。

### グラフ画面から予測シナリオを切り替えられますか？

メインページでは種目と指標を選べます。通常の閲覧では該当するプランと習慣入力が自動選択されます。コーチや共有リンクから開いた場合は別のシナリオが指定されていることもあるため、すべての画面が同じ前提と決めつけず日付ごとの算出根拠を確認してください。

### TSB のカラーゾーンは準備万端であることを証明しますか？

あくまで負荷コンテキストを読みやすくするための参考帯です。実際の体調やパフォーマンスに影響するすべての要因を含んでいるわけではありません。
