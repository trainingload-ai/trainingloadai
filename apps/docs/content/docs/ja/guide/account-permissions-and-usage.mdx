# アカウント・権限・データエクスポート・AI利用状況

アカウント設定は本人確認とアクセス管理を、権限設定はどのデバイスやプラットフォームのデータを取り込めるかを、利用状況はメンバーシップと AI クレジットの消費状況を示します。新しい端末をセットアップするときや機能が見当たらないときは、これらをまとめて確認してください。

このページでは Cloud アカウントを対象としています。セルフホスト環境ではローカルの個人アカウントを使用するため、[セルフホスト設定](/ja/docs/self-host/configuration)をご覧ください。

## 始める前に

- Web とモバイルで同じ Trainingload.ai アカウントにサインインしておきます。
- 認証コードを受け取れるよう、アカウントのメールアドレスにアクセスできる状態にします。
- モバイルでは、OS 側でヘルスケアや位置情報の権限をすでに拒否していないか把握しておきます。
- スイッチをオンにする前に、自動更新を許可したい閾値を決めておきます。
- 認証コード、パスワード、接続認証情報、または個人を特定できるアカウント ID を含むスクリーンショットは共有しないでください。

## 1. 本人情報とパスワード状態を確認する

Web では **アカウント**、モバイルでは **マイページ → メニュー → アカウント** を開きます。

確認できる項目：

- 表示名
- アカウントのメールアドレスと認証状態
- パスワードが設定済みかどうか

現在のメールアドレス欄は読み取り専用です。アカウントが未認証の場合は 6 桁の認証コードをリクエストし、有効期限内に入力してください。Web では送信されたコードは 5 分間有効で、カウントダウン中は再送できません。

パスワードが未設定の場合は **パスワードを設定**、すでに設定済みの場合は **パスワードを変更** を使用します。OAuth で作成したアカウントではパスワード未設定と表示されるのが正常ですので、アカウント不良と判断せず画面のパスワード設定操作を使ってください。

### アクセス回復とサインイン完了

ログインページで **パスワードを忘れた場合** を選択すると、リセット用メールをリクエストできます。必ず最新のリセットリンクのみを開き、Trainingload.ai のリセット画面に戻ったことを確認してから新しいパスワードを設定してください。期限切れ・不正・使用済みのトークンでは完了できないため、新しくリセットを依頼する必要があります。

OAuth サインインでは、アプリに戻る前に完了画面またはエラー画面を経由する場合があります。完了画面から自動遷移しない場合はログイン画面に戻って 1 回やり直してください。エラーページが表示された場合は、トークンやコールバック URL 全文を含めずに表示されたエラーテキストのみ控えてください。

外部アプリが Trainingload.ai へのアクセスを求めた場合、OAuth 同意画面に「リクエスト元アプリ」「サインイン中のアカウント」「要求されるスコープ」「戻り先」の 4 点が表示されます。すべて意図したものと一致する場合にのみ承認してください。拒否するとアクセス権を付与せずに元の操作へ戻ります。

## 2. モバイルの権限とデータソースを確認する [#2-review-mobile-permissions-and-data-sources]

**マイページ → メニュー → データ認可** またはモバイルの **権限** ページを開きます。データソースはローカル端末のソースとサードパーティサービスに分かれています。

ローカルソース：

- **ヘルスケア**：対応する健康データ・ワークアウトの読み取りを認可し、許可済み／一部許可の状態確認、過去データ同期のリクエスト、接続デバイスの管理、OS のヘルスケア設定を開く操作が行えます。
- **位置情報**：ルート記録を許可します。以前に拒否している場合は OS 設定を開きます。

サードパーティソースには Strava、Polar、COROS、Suunto、Wahoo、Intervals.icu などが表示されます。各行に現在の状態が示されており、開くことで接続・詳細設定・連携ページへの移動が行えます。

端末の OS 権限とサーバー連携は別々の状態です。OS 側でヘルスケアが許可されていても、Trainingload.ai のデバイス接続を再接続する必要がある場合があります。OS 設定から戻ったあとはソース詳細を開き直し、両方の状態を再取得してください。

## 3. 指標の自動更新を管理する

Web またはモバイルで **アカウント → 自動更新** を開きます。各スイッチで 1 つの指標に対する自動更新を許可します。

| グループ | 指標 |
| --- | --- |
| パワー | FTP、CP、W′、Pmax |
| ペース | TP、CS |
| 心拍数 | LTHR、最大心拍数 |

条件を満たすデータから Trainingload.ai に自動更新させたい指標だけを有効にしてください。スイッチをオンにしても即座に新しい値が出るわけではなく、十分な対応アクティビティデータが必要です。

自動更新によってゾーン、グラフ、構造化ワークアウト、トレーニング負荷の解釈に使われる閾値が変わる場合があります。更新後は指標履歴と最近のアクティビティを確認してから、新旧の期間を比較してください。

## 4. メンバーシップと AI 利用状況を確認する

アカウントのメンバーシップカードには次の情報が表示されます。

- 現在のプランと有効状態
- メンバーシップ期間または有効期限の情報
- 課金元
- 期間末での解約予定の有無

アプリ内からサブスクリプション管理操作を行えるのは、対応する課金元で有効なサブスクリプションのみです。ほかの利用経路ではメンバーシップ状態が表示されても、同じ管理操作は表示されない場合があります。

メンバーシップカードまたはモバイルのアカウント画面から **利用状況** を開くと、次の項目を確認できます。

- 現在のプラン
- 利用可能なクレジット（直近の完了操作が前回残高を超えた場合のマイナス残高を含む）
- 月額サブスクリプション付与クレジットの使用量・残量・有効期限
- 利用可能またはメンバーシップ制限付きのクレジットパック残高と最も近い有効期限
- 未精算残高、消費推移、操作回数、個別の台帳履歴

表示期間は 1 日、7 日、30 日、当月累計、先月から選べます。台帳には Standard（1×）、Deep（3×）、混合モードの操作、サブスクリプション付与、クレジットパック、ギフト、返金、未精算相殺が記録されます。1 クレジットは、キャッシュ入力・非キャッシュ入力・出力・モード・全体係数を適用した 1,000 等価トークンに相当し、固定のメッセージ数ではありません。

## 5. アプリの表示設定を変更する

Web で **設定** を開くと次の項目を設定できます。

- ライト／ダーク／システムテーマ
- メートル法またはヤード・ポンド法
- グラフ横軸の動作
- 12 時間表示または 24 時間表示
- インターフェースの表示言語

これらの項目は **保存** を押すまで仮の値として扱われます。言語を変更すると現在のルートも選択したロケールへ切り替わり、次回以降の訪問用に保存されます。単位や時刻形式は表示上の設定であり、元のアクティビティ記録自体は書き換えません。

## 6. アカウントデータをエクスポートする

Web で **アカウント → データエクスポート** を開き、目的に合った形式を選びます。

- **AI分析用**：分析向けのコンパクトなパッケージを作成します。アップロード済みのオリジナルファイルは含まれません。
- **フルバックアップ**：より広範なアーカイブを作成します。正確な位置情報を保持する設定を選んだ場合はオリジナルファイルも含められます。

エクスポートを依頼する前に、ルート位置情報の扱いを選択します。

- よく訪れる場所をマスクする
- GPS データを削除する
- 正確な位置情報を保持する

オリジナルファイルを含めると、ファイル自体に位置情報が含まれる可能性があるため自動的に「正確な位置情報を保持する」扱いになります。正確な位置情報を含むエクスポートは機密情報として扱い、内容を十分に理解していない限り AI サービスへアップロードしたり他者と共有したりしないでください。

エクスポート生成は非同期で実行されます。ページを開いたままにするか後で戻って最新ジョブを更新し、ステータスが **準備完了** になってからダウンロードしてください。画面にはアーカイブサイズと有効期限が表示されます。準備完了・失敗・期限切れのジョブは一覧から削除できます。

## 7. 安全にアカウントを削除する

アカウント削除は取り消すことができず、非同期で処理されます。モバイルで開始する前に次の手順を行ってください。

1. 残しておきたいデータをすべてエクスポートします。
2. 表示されているメンバーシップと課金プロバイダーを確認します。
3. フロー内で求められた場合は自動更新を解約します。
4. すべての最終確認事項を読み、同意を選択します。
5. 削除リクエストを送信し、受付完了画面が表示されてから画面を離れます。

リクエスト送信後、アカウントはサインアウトされ、バックグラウンドで削除処理が進む間アクティブなアクセスが無効になります。完了は通常 24 時間以内、最大 7 日間かかることがあります。受付完了画面からログイン画面に戻りますが、元のアカウントを復元することはできません。

サブスクリプションの扱いは現在の課金元によって異なります。Web 課金の自動更新は、削除を続行する前に解約が必要な場合があります。Apple 経由の更新は Apple 側で管理されており、別途解約しない限り Trainingload.ai アカウント削除後も継続することがあります。アカウント削除自体は返金を保証するものではなく、削除後に改めてサブスクリプションを購入しても削除済みデータは復元されません。

## 8. 複数端末間で設定を確認する

アカウント・連携・権限・自動更新の設定を変更したあとは、次の手順で確認してください。

1. 現在の端末で保存または操作を完了します。
2. ソース一覧に戻り、表示された状態を確認します。
3. もう一方の端末を更新します。
4. 同じメールアドレスと、対応するサーバー保存設定が一致していることを確認します。
5. ローカル権限については、権限を付与した端末上で OS のステータスを確認してください。ローカル権限は別のスマートフォンには引き継がれません。

## 設定の確認チェックリスト

- Web とモバイルで同じアカウントメールアドレスが表示されていること
- メール認証とパスワード状態が意図したサインイン方法と一致していること
- ヘルスケアと位置情報が想定通りの端末ステータスになっていること
- サードパーティ連携が想定通りのサーバー接続状態になっていること
- 意図した自動更新スイッチのみが有効になっていること
- メンバーシップ状態と利用状況台帳が最近の付与や AI 操作と一致していること
- リクエストしたエクスポートが「準備完了」になり、期限前にダウンロードでき、選択した位置情報プライバシー設定が反映されていること
- テーマ・単位・グラフ・時刻形式・言語の設定が、設定画面を開き直しても維持されていること

## トラブルシューティング

- **認証コードが使えない：** 6 桁すべてを入力しているか、メールアドレスと有効期限を確認し、再送ボタンが有効になってから新しいコードをリクエストしてください。
- **メールアドレスを編集できない：** 現在のアカウント画面ではメールアドレス変更は提供されておらず、意図的に読み取り専用になっています。
- **ヘルスケアは許可済みなのに未接続：** ヘルスケア画面を開き直し、アプリ／サーバー／デバイスの接続状態を確認して、表示されている場合は再接続を実行してください。
- **位置情報が拒否のまま：** OS のアプリ設定を開いてください。一度拒否した権限は再度システムダイアログが表示されないことがあります。
- **OAuth 後にプラットフォームが未接続と表示される：** ソース状態を更新し、同じ Trainingload.ai アカウントであることを確認したうえで、プラットフォーム別設定を見直してください。
- **自動更新の指標が変わらない：** スイッチがオンになっていることと、最近の該当アクティビティに十分な対応データが含まれていることを確認してください。
- **利用状況が空に見える：** 期間を広げ、そのアカウントに AI 付与または消費イベントがあるか確認してください。
- **アプリ内でメンバーシップを管理できない：** アプリ内管理は対応する有効なサブスクリプション課金元のみに表示されます。表示されている課金元を確認してください。
- **エクスポートを開始できない：** 進行中のエクスポートジョブが完了するのを待ち、ページを更新してから再試行してください。
- **エクスポートの期限が切れた：** 期限切れジョブを削除し、必要なプライバシー設定で新しいアーカイブをリクエストしてください。
- **サブスクリプションが原因でアカウント削除できない：** 削除フローに表示される課金元ごとの更新停止手順を完了し、状態を更新してください。Apple 課金の場合は Apple 側で別途自動更新を解約してください。
- **リセットリンクが拒否される：** 新しいリセットメールをリクエストし、最新のリンクを使ってください。使用済み・期限切れのトークンは再利用できません。
- **見覚えのない OAuth 同意画面が出た：** リクエストを拒否し、リクエスト元アプリ・スコープ・アカウント・戻り先を確認してからやり直してください。
- **表示設定が変わっていないように見える：** **保存** を押してから設定画面を開き直してください。ローカルの表示設定とサーバー側のロケールは反映タイミングが異なる場合があります。
