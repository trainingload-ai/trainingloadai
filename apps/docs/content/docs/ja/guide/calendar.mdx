# カレンダーで予定と実績のトレーニングを比較する

カレンダーは、これからの予定と記録済みのトレーニングを共通の日付軸上に並べて表示します。同じ日付にある予定ワークアウトとアクティビティは別々のレコードです。それぞれの詳細と紐づけを確認して、その記録が予定セッションの実績に該当するかを明確にしましょう。

[Demo でカレンダーを開く](https://demo.trainingload.ai/en/calendar)ことができます。スクリーンショットは実 Web アプリのサンプルプラン・アクティビティデータを使用しています。Demo では任意の日付を閲覧できますが、紐づけやスケジュール変更の保存にはご自身のアカウントが必要です。

## 始める前に

アカウントのタイムゾーンとアクティビティの開始時刻を確認します。予定トレーニングについては、進行中プランの開始日とスケジュールを確認してください。負荷や解析の欠落を判断する前に、インポート済みアクティビティの処理完了を待ちましょう。

Web および macOS 版 Trainingload.ai Personal では、サイドバーから **カレンダー** を開きます。狭い Web 画面ではカレンダーボタンから月ピッカーを開きます。モバイルアプリでは **カレンダー** タブを開きます。

## 1. 日付を探して選択する

広い画面ではカレンダーをスクロールするか、月セレクターと矢印ボタンを使って移動します。日付を選択するとその日のパネルが表示され、**今日** を押すと現在日に戻ります。

選択した日付に応じて日別パネルの内容が切り替わります。1 つの日付には予定セッション、独立した予定ワークアウト、記録済みアクティビティ、またはそれらの組み合わせが含まれることがあります。開く前に各項目のラベルを確認しましょう。

## 2. 日別パネルを読む

**トレーニング** で予定ワークアウトを、**アクティビティ** で記録済みアクティビティを確認します。選択日、表示されている負荷、件数をチェックし、1 日の全体を見たいときは **1日の詳細を表示** を選びます。

| レコード | 比較前に確認すること |
| --- | --- |
| 予定ワークアウト | 目的、予定日、種目、構成、メモ、実行ステータス |
| 実施済みアクティビティ | 開始時刻、ソース、種目、記録された時間・距離、処理状態、センサー項目の有無 |
| 紐づけ | 正しいアクティビティが意図したワークアウトに実際に紐づいているか |

完了ラベルだけではどの記録が紐づいているか判別できません。実際の運動内容を確認するには[アクティビティ詳細](/ja/docs/guide/activity-detail)を開いてください。

## 3. 正しいアクティビティをワークアウトに紐づける

ご自身のアカウントで予定ワークアウトの詳細を開き、**アクティビティを紐づける** を選択します。

1. ワークアウトに予定日と正しい種目が設定されていることを確認します。
2. 先にアクティビティ詳細で記録の開始時刻を確認しておき、その日の候補一覧でタイトルと時間を照合して該当の記録を見分けます。
3. 一致する記録を選択し、完了フィードバックを待ちます。
4. その記録が別の予定セッションに紐づいている場合は、**紐づけを置き換えますか？** の確認内容をよく読んでから置き換えてください。
5. ワークアウトとアクティビティの両方を開き直し、紐づけが反映されていることを確認します。

候補が表示されない場合は、同期状態、アクティビティの現地日付、ワークアウトの予定日と種目を確認してください。無関係なアクティビティを選ぶ前に、まずそれらの食い違いを解消しましょう。

誤った紐づけを直すには、既存リンクの **紐づけを解除** を使うか、正しいアクティビティを選び直します。紐づけ解除とアクティビティ削除はまったく別の操作です。Demo ではこれらの書き込み操作は無効になっています。

## 4. 予定内容と実績内容を比較する

最初に目的と構成を比較し、続いて記録された時間・距離・強度・利用可能なトレーニング負荷を見比べます。セッションを短縮・変更・スキップした場合はその理由を残しておきましょう。元のプランにない追加アクティビティも、実際のトレーニング負荷として重要です。

予定負荷や実績負荷が表示されない場合は、ゼロとみなす前に閾値・種目・処理状態を確認してください。完了・スキップ・延期など現在のワークアウト状態に応じた操作は[進行中のプランを管理する](/ja/docs/guide/manage-active-plan)を参照してください。

## 5. サマリーの対象範囲を確認する

カレンダーでは **プラン** と **月** のサマリーが表示されることがあります。件数・距離・時間・負荷を比較する前に、選択中のスコープと日付境界を確認してください。

プラン進捗は進行中のサイクル全体を対象とし、月次概要は表示中のカレンダー月を対象とします。比較期間が異なるため、すべてのサマリーが同じ期間を指していると決めつけず表示コンテキストを確認しましょう。

より広い視点の振り返りには[週間レビュー](/ja/docs/workflow/weekly-review)を、蓄積負荷と条件付き見通しを確認したい場合は [PMC](/ja/docs/guide/pmc-forecast) を活用してください。

## 結果の確認

選択日・日別パネル・開いた各レコードの日付が一致しており、予定ワークアウトとアクティビティが意図通りに紐づき、負荷比較において対象範囲と欠損データの有無を説明できる状態になっていれば完了です。

## 今後のワークアウトを調整する [#adjust-upcoming-workouts]

1. プランが進行中の状態で、Web または Personal のカレンダー上で日付を右クリックし、**スケジュールを調整** を選択します。
2. 今後のワークアウトを別の日へドラッグするか、右クリックして **ワークアウトを移動** から日付を選びます。ワークアウトメニューの **ワークアウトを編集** で内容を変更できます。日付メニューからワークアウトを追加、ワークアウトメニューから削除することもでき、エディタはこれらの変更を 1 つのドラフトにまとめます。
3. ペアになった色と **変更前**／**変更後** のラベルを確認します。**変更を確認** を選び、**プラン変更を確定** を押してまとめて適用します。あとで続ける場合はエディタを閉じて **ドラフトを保存** を選び、次回 **スケジュールを調整** から保留中の調整を開き直せます。
4. カレンダーを開き直し、新しい日付とワークアウト内容を確認します。確定前に元のスケジュールが変更されていた場合は、**最新のスケジュールを読み込む** を使って残りの適用可能な編集を確認してください。

狭い画面では、ワークアウトのメニューまたはドラッグハンドルを使って月グリッド上で移動します。過去の日付・完了済み・紐づけ済みのセッションは日程変更から保護される場合があります。

メインカレンダーからワークアウトを 1 件だけ移動するには、新しい日付へドラッグするかメニューから **ワークアウトを移動** を選び、プレビューで日付を確認してから **調整を確定** を選択します。

コーチとの会話で **ワークアウトカレンダーを表示** が提示された場合は、そこからプレビューを開けます。同じ会話内で対応する変更を確認・編集し、保存済みドラフトを確認したうえで確定できます。

## よくある質問

### アクティビティが別の日付に表示されるのはなぜですか？

アクティビティの開始時刻・タイムゾーンとアカウントの表示タイムゾーンを比較し、さらにプラン開始日と予定日も確認してください。ワークアウトを移動する前にまず日付のズレの原因を確かめましょう。

### プランのワークアウトが見当たらないのはなぜですか？

進行中のプラン、その期間、および個々のワークアウトの日程とステータスを確認してください。移動やスキップされたセッションは元の位置に表示されない場合があります。

### 1 回のトレーニングに 2 件のレコードが表示されるのはなぜですか？

予定セッションと実際のアクティビティは別々のレコードです。両者の紐づけを確認してください。実際のアクティビティ自体が 2 件ある場合は、削除する前に重複転送や重複インポートを確認しましょう。

### Demo ではなぜアクティビティを紐づけできないのですか？

Demo はサンプルの閲覧用です。紐づけやスケジュール変更には適切なアカウント権限が必要です。

### 変更が拒否された場合はどうすればよいですか？

エラーメッセージを読み、最新のプランまたはアクティビティ状態を再読み込みしてから再試行してください。意図した紐づけやスケジュールが実際に更新されたかも確認しましょう。
