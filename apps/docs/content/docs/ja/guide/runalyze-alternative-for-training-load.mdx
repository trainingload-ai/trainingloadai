# トレーニング負荷管理における Runalyze との比較

Runalyze でランニングパフォーマンスを振り返っている場合は、同じ最近のアクティビティと「今後の練習について下したい判断」を使って両ツールを比較してみるのが効果的です。

Runalyze は有効 VO2max、レースタイム予測、トレーニング負荷、アクティビティ統計などを提供しています。算出手法や最新機能は同サービスの[公式機能一覧](https://runalyze.com/help/article/features?_locale=en)をご確認ください。

## Trainingload.ai での振り返り方

- まず[アクティビティ詳細を開き](/ja/docs/guide/activity-detail)、記録されたワークアウトを確認する
- [有効 VO2max の履歴を確認し](/ja/docs/guide/effective-vo2max-for-endurance)、最近の推定値の推移を見る
- [PMC を開き](/ja/docs/guide/pmc-forecast)、トレーニングスケジュールとあわせてトレーニング負荷を解釈する
- アクティビティを予定ワークアウトに紐づけ、[AIコーチ](/ja/docs/guide/ai-coach)に達成状況のレビューや調整案を相談する

## ご自身の記録で比較する手順

1. 元のプラットフォームから対応する FIT・GPX・TCX ファイルをエクスポートするか、[プラットフォーム連携](/ja/docs/guide/connect-data)を使用します。
2. 直近のトレーニングブロックを取り込み、日付・ソース・閾値を確認します。
3. よく把握しているワークアウトを 1 件選び、記録された時間・距離・心拍数・ペースを比較します。
4. そのうえでトレーニング負荷と体力推定値を確認します（単発の推定値の差だけで体力の変化を断定しないでください）。

## 再設定が必要になる項目

プラットフォームごとに有効サンプルの扱い、補正係数、閾値設定が異なるため、有効 VO2max や負荷の履歴が完全一致しない場合があります。また、アクティビティのアップロードだけで Runalyze のタグ、ギア（シューズ等）、カスタム設定、すべての過去統計が自動移行されるわけではありません。

予定と実績のレビューを一通り試す間は元の記録を残し、移行するか併用するかを判断してください。まず画面を確認したい場合は[Demo を開く](https://demo.trainingload.ai/en)をご利用ください。
