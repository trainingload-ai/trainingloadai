# 今日のアドバイスと現在の状態を活用する

1 日のトレーニング方針を整理するときは、Web の **ホーム** またはモバイルアプリの **今日** を開きます。現在のプラン、記録済みアクティビティ、トレーニング負荷の文脈とあわせてアドバイスを読み、実際の状況に合った操作を選びましょう。

[Demo のホームページを開く](https://demo.trainingload.ai/en)ことで画面を体験できます。Demo は閲覧専用であり、ワークアウト・リマインダー・プラン変更の保存にはご自身のアカウントが必要です。スクリーンショットは実 Web アプリのサンプル例です。モバイルには独自のシートと記録操作が用意されています。

## 始める前に

アカウントのタイムゾーン、進行中のプラン、最近のアクティビティの処理が完了しているかを確認します。AI 機能を使う場合は、データ共有設定とご利用環境での AI 設定・利用権限も確認しておきましょう。プランがある日と、予定ワークアウトがない日では出発点が異なります。

## 1. 操作する前にその日の全体像を読む

ホームで日付と現在のプランを確認し、今日の予定ワークアウト、最近のアクティビティ、現在の状態または週間負荷セクションをチェックします。今日に表示されているワークアウトは「実施予定のセッション」、記録済みアクティビティは「実際に行われたトレーニングの根拠」です。

まだ同期されていないアクティビティがある場合は、それが抜け落ちた状態のアドバイスをそのまま解釈せず、先に同期を解決してください。必要に応じて[トレーニングデータの接続](/ja/docs/guide/connect-data)を参照してください。

## 2. アドバイスを開いて根拠を確認する

アドバイスカードを選択して詳細シートを開きます。提案の全文、不確実性に関する記述、および利用可能な場合は **この提案の理由** を読みます。表示されるボタンは、その日の提案とスケジュールによって変わります。

- 予定セッションがある場合、そのワークアウトを開く操作が表示されることがあります。
- データ不足の状況では、連携・インポート・アクティビティ確認への導線が表示されることがあります。
- 質問や判断が必要な場合は、対応するコーチフローを開けます。
- 独立した提案ワークアウトやリマインダーは、その提案で用意されている場合にのみ表示されます。

シートを開くだけではワークアウトは作成されず、プラン変更も適用されません。新しいアクティビティやプラン情報が届いてアドバイスが更新された場合は、操作する前に最新版を確認してください。

## 3. 状況に応じたアクションを実行する

### 既存のワークアウトを開く

表示されたワークアウト操作から開き、日付・種目・構成・メモ・ステータスを確認します。完了済みトレーニングについては、完了ラベルだけで判断せずアクティビティの紐づけも確認しましょう。

モバイルアプリでは、対応する予定セッションから持久系記録や筋力トレーニング実行画面へ入れます。詳細は[モバイル記録](/ja/docs/guide/mobile-recording)または[モバイルでのプラン作成と筋力トレーニング実施](/ja/docs/guide/mobile-plans-and-strength)を参照してください。

### 提案された独立ワークアウトを確認する

シートに **提案ワークアウト** が含まれている場合は、プレビューを開いて種目・時間・強度・構成を確認します。追加またはスケジュール操作を選ぶと、今日向けの独立ワークアウトが作成されます。作成後は日次ワークアウト表示で確認してください。既存のトレーニングプランとは別のスケジュールとして扱われます。

提案の有効期限が切れている場合、すでにワークアウトが予定されている場合、または当日の実施可能時間帯を過ぎている場合は追加できないことがあります。提案を更新し、今日のスケジュールを確認してから再試行してください。

### リマインダーを設定する

Web ではリマインダー操作を選び、**リマインド時刻** を指定して **スケジュール** を押します。画面が受け付ける範囲の時刻を選び、完了フィードバックを待ってください。リマインダーはあとで確認を促すものであり、トレーニング完了を意味するものではありません。

モバイルでは対応する通知タイミングの選択肢が表示されます。通知が届くかどうかはアプリの通知設定と端末の権限設定にも依存するため、毎回同じ時刻が使えると決めつけず表示された選択肢を確認してください。

### コーチに相談する・保留中の判断を確認する

アドバイスについて相談したい場合は **コーチ** を選択し、送信前に質問内容と参照されるアクティビティを確認します。保留中の調整案や評価を開くときは、どのワークアウトに対するものか、何の情報が必要か、確定すると何が変わるかを確認しましょう。

アクティビティやプランを開くのは単なる画面遷移ですが、ワークアウトの作成、リマインダー保存、調整案の確定はアカウントの状態を変更します。それぞれの操作結果は個別に確認してください。

## 4. 実際に行った内容を記録する

トレーニング後はアクティビティを同期またはインポートし、処理完了を待ってから該当する予定セッションに紐づけます。予定していた内容と、記録された時間・距離・強度・利用可能なトレーニング負荷を比較しましょう。

ワークアウトを移動・短縮・スキップした場合や、プラン外で実施した場合もその経緯を残してください。更新手順は[カレンダーガイド](/ja/docs/guide/calendar)および[進行中のプランを管理する](/ja/docs/guide/manage-active-plan)を参照してください。

## 5. モバイルのフィードバックと現在の状態カードを使う

モバイルのアドバイスシートでは、「今日は休養する」「別の場所でトレーニングした」「同期待ち」「あとで確認する」といったフィードバックを送れる場合があります。これはアドバイス生成の文脈を補うためのものであり、実施済みアクティビティ自体は通常通り記録・同期する必要があります。

モバイルで「現在の状態」カードをカスタマイズするには、**現在の状態** 横の設定ボタンを開き、対応指標を追加・削除して並び替え、編集を完了します。各カードを開くと詳細が確認でき、ドキュメントへの入口から指標の意味も調べられます。

トレーニング負荷や能力の長期推移を見るには、[PMC](/ja/docs/guide/pmc-forecast) および [VO2Max](/ja/docs/guide/effective-vo2max-for-endurance) を確認してください。現在のカード、過去の実績点、将来の予測値はそれぞれ異なる性質の根拠です。

## 6. 変更後は更新する

モバイルの「今日」画面は下に引いて更新できます。別の端末でアクティビティをインポートしたりプランを変更したりしたあとは、画面を更新して日付・ステータス・紐づけを確認してから編集を続けてください。Web 画面も戻った際に更新されることがあるため、最新の表示内容を確認しましょう。

## 結果の確認

その日の予定セッション、記録済みアクティビティ、アドバイスの根拠、そして選んだ操作の効果を把握できていれば完了です。保存したワークアウト、紐づけ、リマインダーが想定した場所に表示されていることを確認してください。

## よくある質問

### 今日のアドバイスが表示されない／利用できないのはなぜですか？

データ共有設定、AI 設定または利用権限、リクエスト状態、および利用可能なトレーニングデータの有無を確認してください。読み込み中やフォールバック表示を新しい提案とみなさず、明示的なエラーや再試行操作に従ってください。

### アドバイスが変わったのはなぜですか？

新しいアクティビティの到着、プラン変更、状況更新、または有効期限切れによって再生成されることがあります。以前の提案を適用する前に最新版を確認してください。

### ワークアウトを開くボタンがないのはなぜですか？

表示される操作は提案内容と現在のデータに依存します。進行中のプラン、予定日、ワークアウトのステータスを確認し、必要に応じてカレンダーやプランから該当セッションを開いてください。

### 実施したワークアウトがアドバイスに反映されていません

同期状態、アクティビティの処理状況、現地日付、プランへの紐づけを確認してください。モバイルでは記録が反映されるまでの間、適切なフィードバックを送信しておくこともできます。

### アドバイスは自動的にプランを変更しますか？

表示された操作の説明と結果を確認してください。アドバイス、独立ワークアウトの追加、プラン調整案の適用はそれぞれ効果が異なります。レビューと確定の流れについては[AIコーチ](/ja/docs/guide/ai-coach)をご覧ください。
