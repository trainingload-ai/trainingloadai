# アクティビティ詳細

アクティビティ詳細では、1 件の実施済みワークアウトを深く振り返ることができます。記録されたアクティビティ、ルート、グラフ、種目別の指標、利用可能なコーチレビューが一か所にまとまっています。まずはソースとサマリーを確認し、気になる区間を掘り下げてから、ワークアウトの狙いと結果を照らし合わせましょう。

[10km レースのデモを開く](https://demo.trainingload.ai/en/activities/17921623926005309429)と、読み取り専用の Demo アカウントで実際のアクティビティを確認できます。タブやグラフは自由に操作できますが、変更の保存にはご自身のアカウントが必要です。

## 始める前に

- アクティビティをインポートまたは記録し、処理完了を待ちます。
- アクティビティの種目と日付を確認し、プロフィールの単位系と関連閾値を確認しておきます。
- 調べたいデータを含むアクティビティを選びます（心拍分析には心拍サンプル、パワー分析にはパワーデータ、ルート表示には GPS が必要です）。
- 予定と実績を比較する場合は、対応するプランワークアウトと紐づけ状態を確認します。

サマリー数値のみのアクティビティも確認できますが、表示されるグラフは少なくなります。利用できるタブは種目と記録データに依存します。

## 1. アクティビティを開き、ソースを確認する

**アクティビティ** を開いてワークアウトを選択し、タイトル・種目・開始時刻・ソース・距離・時間を確認します。検索画面、マップ、カレンダー、または紐づいたプランワークアウトからも開けます。

処理がまだ進行中の場合は、グラフが欠けていると判断せず完了を待ってください。すべての解析が終わる前にアクティビティ自体が表示されることがあります。

| 処理ステータス | 対処方法 |
| --- | --- |
| 解析中（Analyzing） | アクティビティの処理が終わるのを待ってから更新します。 |
| 完了（Ready） | 利用可能なデータの確認を続けます。 |
| 一部失敗（Partial failed） | 欠けている解析を確認しつつ、完了済みの項目を活用します。 |
| 失敗（Failed） | 再試行または再インポートの前に元ファイルと失敗情報を確認します。 |

## 2. 調べたい問いに合わせてビューを選ぶ

デスクトップ Web では、ルートの下に分析タブが並びます。まずは **概要** を見てから、問いに合ったタブを開きましょう。モバイルではその種目で利用できる詳細・グラフビューを使用します。後述の同期タイムラインはデスクトップ Web 向けのワークフローです。

| ビュー | 調べる内容 | データ・対象範囲 |
| --- | --- | --- |
| 概要（Overview） | セッションサマリー、利用可能なグラフ、天候、種目別情報 | 表示項目はアクティビティに依存します。 |
| タイムライン（Timeline） | 同期されたグラフとルート上で 1 時点や選択区間を比較 | デスクトップ Web のランニング・サイクリング（有効な時系列データが必要）。 |
| ラップ（Laps） | 記録されたラップごとのサマリー指標を比較 | アクティビティにラップがあり、種目が対応している場合に表示されます。 |
| ベストエフォート（Best efforts） | 距離別・時間別の最大持続出力と統計を確認 | 種目と記録ストリームに依存します。 |
| 心拍数（Heart Rate） | 心肺反応、ゾーン、対応する派生指標 | 対応する分析には心拍数データが必要です。 |
| パワー（Power） | パワー出力、ゾーン、効率関連指標 | 対応するパワーデータが必要です（推定パワーは明示されます）。 |
| ペース（Pace） | ペーシングおよびペース関連分析 | 対応するランニングアクティビティで表示されます。 |
| ランニングダイナミクス | フォーム・技術に関連する計測値 | 該当センサーストリームを含むランニングで表示されます。 |

スイミングやその他の種目には独自の表示ルールがあります。タブが表示されないのは処理失敗ではなく、種目や元データの内容による場合もあります。

## 3. 文脈を踏まえて区間を詳しく見る

登坂、ペースアップ、インターバルなどを詳しく確認したいときは **タイムライン** を開きます。特定の時点にカーソルを合わせて数値を比較するか、範囲を選択して平均・最小・最大値と対応するルート区間を確認できます。

範囲選択・グラフ設定・分析セグメント編集の完全な手順は[タイムラインでワークアウトを分析する](/ja/docs/guide/activity-timeline)をご覧ください。

デバイスが記録したラップを比較するには **ラップ** を使います。最も高い持続パフォーマンスを調べたいときは **ベストエフォート** が便利です。ベストエフォートでは対応する場合に距離基準と時間基準を切り替えられ、**列を編集** で表示する統計項目と並び順を変更できます。位置情報がある場合は、1 列目や数値を選択すると対応するルート区間が表示されます。

## 4. 強度とトレーニング負荷を読み取る

アクティビティの種目と設定済み閾値を踏まえて、ペース・心拍数・パワーの分析を確認します。セッション同士を比較するときは、どの負荷ソースが使われているかが重要です。

- パワーベースの負荷は、パワーデータと該当する閾値を使用します。
- ランニングのペースベース負荷は、ペース・地形・閾値の条件に依存します。
- 心拍数ベースの負荷は、心拍記録とプロフィール設定を使用します。
- 上記のシグナルがない場合は、ほかの負荷算出方法が適用されることがあります。

対応する概念は[トレーニング負荷](/ja/docs/metrics/training-load)で確認できます。ゾーンや強度が不自然に見える場合は、[プロフィール・閾値・ゾーン](/ja/docs/guide/profile-thresholds-zones)を見直してください。

対応する心拍分析では、有酸素デカップリングによってアクティビティ全体を通じた出力と心拍数の関係変化を比較できます。Pw:Hr や Pa:Hr を解釈する前に、[有酸素デカップリング](/ja/docs/metrics/heart-rate/aerobic-decoupling)で前提条件を確認しましょう。強度変動が大きいセッションや中断が多いセッションでは、一定ペース走とは異なる文脈が必要です。

## 5. ルートとプランの文脈を加える

ルート表示を使って強度の変化を地形と結びつけます。上り坂、信号待ち、天候・環境条件によってペースや心拍数の変化を説明できることが多くあります。GPS がない場合は、残りの記録データから判断しましょう。

予定ワークアウトに該当するセッションであれば、カレンダーやプランで紐づけを確認します。予定内容・完了状況・負荷を比較する前に、意図したセッションに紐づいているかチェックしてください。誤った紐づけがある場合は、プランレビューを依頼する前に修正しましょう。手順は[進行中のプランを管理する](/ja/docs/guide/manage-active-plan)を参照してください。

## 6. コーチレビューを読む、または焦点を絞って質問する

**コーチレビュー** セクションには、利用可能な AI レビューの状態が表示されます。データ共有の確認を求められた場合は、ご自身のデータで AI を使う前に設定を完了してください。処理中またはレビュー生成待ちの場合もあります。リクエスト失敗時は表示されている再試行アクションを使用します。

AIコーチに続けて相談するときは、対象のアクティビティと具体的な質問を明確に伝えます。「予定強度と一致していたか」「後半に何が変わったか」「最近のトレーニングの中でどう位置づけられるか」といった切り口が効果的です。プラン変更案を適用する前に、回答が参照しているアクティビティ・期間・根拠を確認してください。

レビューと確定のワークフローは[AIコーチ](/ja/docs/guide/ai-coach)をご覧ください。

## レビュー結果の確認

対象のアクティビティとデータソースを把握し、調べた区間を説明でき、どの記録データが結論の裏付けになっているかを言える状態を目指しましょう。予定トレーニングであれば紐づけ先ワークアウトも確認し、センサー欠損や不確かな解釈があればメモしたうえで次の判断につなげてください。

## よくある質問

### 一部のグラフやタブが表示されないのはなぜですか？

処理ステータス、種目、センサー項目の有無を確認してください。サマリーのみのファイルでは時系列サンプル付きファイルと同じ分析は提供されません。また、デスクトップ Web とモバイルアプリでも提供する詳細機能は異なります。

### ビューによって数値が異なるのはなぜですか？

単位、選択範囲、計算方法の違いを確認してください。タイムラインの区間統計は全体または選択範囲の集計であり、カーソル位置の数値は単一サンプルの値です。また、デバイス記録のラップ集計と再計算された分析セグメントでは入力データが異なる場合があります。

### ルートが表示されないのはなぜですか？

ファイルに GPS が含まれていない、プライバシー処理で位置情報が除外された、またはマップのリクエストが失敗した可能性があります。利用可能なグラフとマップのエラー状態を別々に確認してください。

### デモアクティビティを編集できますか？

公開 Demo は閲覧専用です。アクティビティ編集、分析セグメント保存、プラン変更にはご自身のアカウントでサインインする必要があります。
