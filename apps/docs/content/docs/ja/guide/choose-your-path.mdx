# 目的に合わせて始め方を選ぶ

Trainingload.ai を使い始めるために、最初からすべての指標を設定する必要はありません。まずは今いちばん達成したい目的を選んで一通り試し、あとから詳細設定を整えていきましょう。

## 最近のトレーニングを分析したい

ほかのプラットフォームにトレーニング記録がある場合や、FIT・TCX・GPX ファイルをお持ちの場合に適しています。

1. [最初のアクティビティをインポート](/ja/docs/guide/getting-started)を完了します。
2. [プラットフォームを連携](/ja/docs/guide/integrations)するか、[アクティビティファイルをアップロード](/ja/docs/guide/upload-activity-files)します。
3. [アクティビティ詳細](/ja/docs/guide/activity-detail)を開き、時間、距離、種目、利用可能なセンサーデータが正しく表示されているか確認します。
4. [ダッシュボード](/ja/docs/guide/dashboard)と[トレーニング分析ワークフロー](/ja/docs/guide/training-analysis-workflow)を使って傾向を読み解きます。

**完了の目安：** 少なくとも 1 件のアクティビティの処理が完了し、グラフが想定通りの元データと一致していること。

## トレーニングプランに沿って練習したい

過去データの分析よりも、次のワークアウトを計画通りに進めることを重視する場合に適しています。

1. [プロフィール・閾値・ゾーン](/ja/docs/guide/profile-thresholds-zones)を確認します。
2. 手動または AI を使って[トレーニングプランを作成](/ja/docs/guide/create-training-plan)します。
3. 各ワークアウトの内容を確認し、希望の開始日でプランを有効化します。
4. [カレンダー](/ja/docs/guide/calendar)またはプランページで今日のセッションを確認します。
5. トレーニング後に、[実施済みアクティビティを予定ワークアウトに紐づけ](/ja/docs/guide/manage-active-plan)ます。

**完了の目安：** プランが有効化され、今日のワークアウトが表示されており、最初の実施済みアクティビティが紐づけられている（または紐づけ可能な状態である）こと。

## 主にモバイルでトレーニングしたい

モバイルは今日のトレーニング確認、計測記録、素早いレビュー、プラン実行に便利です。詳細なグラフ比較や複数週にわたるプラン編集には、画面の広い Web が適しています。

1. [Web とモバイル](/ja/docs/guide/web-and-mobile)を読み、同期されるデータの範囲を確認します。
2. [モバイル記録](/ja/docs/guide/mobile-recording)の権限チェックリストを完了します。
3. ワークアウトを記録またはインポートします。
4. 「今日」「カレンダー」「プラン」「コーチ」「マイページ」から同じアカウントのワークフローを続けます。

**完了の目安：** モバイルで記録を保存でき、同期後にアカウントへアクティビティが表示されること。

## AIにトレーニングの作成や調整を手伝ってほしい

AIコーチは、プロフィール・最近のアクティビティ・現在のプランがそろっているほど精度の高い提案を行えます。

1. 確かな数値がわかる閾値を入力します（不明な値は推測せず空欄のままにしてください）。
2. 普段の練習量がわかる程度に最近のトレーニングをインポートします。
3. [AIコーチ](/ja/docs/guide/ai-coach)を開き、目標・期間・制約条件・練習可能な曜日を伝えます。
4. プラン案やワークアウトの調整案は、適用する前に必ず内容を確認します。

**完了の目安：** 提案内容が実際のプランやアクティビティを根拠としており、保存前に変更内容が確認できること。

## 筋力トレーニングのワークアウトを作成したい

1. 手動プランを作成するか、既存のプランを開きます。
2. ワークアウトエディタで **筋力トレーニング** を選択します。
3. [筋力トレーニングワークアウト](/ja/docs/planning/strength-workouts)に沿って、種目・セット数・負荷・強度・休息時間を追加します。
4. 使用またはエクスポートする前に保存し、プレビューを確認します。

## 迷ったときは

まずは[最初のアクティビティをインポート](/ja/docs/guide/getting-started)から始めてみてください。プロフィール → 実施済みアクティビティ → トレーニング負荷 → プラン → レビューという最小限の一連の流れを体験できます。
