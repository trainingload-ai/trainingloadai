# モバイルでのプラン作成と筋力トレーニング実施

スマートフォン上でトレーニングプランのドラフトを作成したり、予定された筋力トレーニングワークアウトを開いて 1 セットずつ実績を記録したりできます。このガイドでは両方の手順を説明します。

## 始める前に

- サインインし、「プラン」タブでご自身のアカウントが読み込めることを確認します。
- プランの期間と短い名称を決めておきます。
- 筋力セッションでは、行う種目と使用できる器具を決めておきます。
- まずドラフトとして作成し、有効化する前に全体のスケジュールを確認してください。

## 1. プランの作成方法を選ぶ

**プラン** を開き、**プランを作成** を選択して次のどちらかを選びます。

- **手動** — 持久系や筋力の各セッションを自分で配置します。
- **AI** — 目標や制約条件を伝え、AIコーチとの対話でプラン作成を進めます。

以下の手順では「手動」を使用します。

## 2. プランの基本情報を入力する

プラン名を入力し、1〜24 週間の期間を選択します。必要に応じて説明欄に方針・制約・優先事項を記録します。名称と期間に誤りがないことを確認してから次に進んでください（後から期間を短くする際、新しい範囲外にワークアウトを残すことはできません）。

## 3. スケジュールを組み立てる

スケジュールをスクロールし、ワークアウトを配置したい日を開きます。1 日に複数セッションを設定でき、セッション番号で順序を管理します。

ワークアウト構造は次の 2 種類から選びます。

- **持久系** — ランニング、サイクリング、スイミング、ストレッチのステップを構成します。視覚的に組み立てる手動モードと、対応テキスト記法の DSL モードが選べます。
- **筋力トレーニング** — 種目ごとにウォームアップ／メインのセットグループ、セット数、回数または時間、負荷、強度（RPE など）、休息時間を設定します。

各ワークアウトでは次を行います。

1. 週・曜日・セッション順を確認します。
2. わかりやすい名前を付けます。
3. 実施上の注意点はメモ欄に記載します。
4. 持久系または筋力の構造を作成して検証します。
5. ワークアウトをプランドラフトに保存します。

## 4. 確認してドラフトを保存する

少なくとも 1 件のワークアウトを追加してから確認画面へ進みます。総週数、セッション数、トレーニング日数、時系列スケジュールを比較確認して保存します。新規作成したプランはドラフト状態のまま保存されるため、有効化する前に見直せます。

プラン詳細を開き、すべてのワークアウトが意図した相対日に配置されているか確認してください。有効化は[プランのステータス管理](/ja/docs/planning/plan-lifecycle)を読んでから行いましょう。

## 5. 予定の筋力ワークアウトを開始する

予定された筋力セッションを行う準備ができたら、「今日」「カレンダー」または進行中のプランから該当ワークアウトを開き、**予定通り開始** を選択します。アプリは処方内容から実際の筋力アクティビティを作成し、ライブ記録画面を開きます。

セッションの「開始」と「完了」は別です。予定の処方内容は参照できる状態のまま、実際に行ったセットデータが記録されます。

## 6. セッションを記録する

各種目・各セットについて次を行います。

1. 予定されている負荷・回数または時間を確認します。
2. 実際に実施した内容が異なる場合は、実績の負荷や結果を調整します。
3. セットを完了にします（誤ってタップした場合は元に戻せます）。
4. 実施内容に合わせてすべての種目と進捗を記録します。

記録を削除せずにライブ画面を離れることもでき、あとから予定セッションを開けば再開できます。

## 7. 終了して確認する

必要に応じてセッション RPE（1〜10）を選択し、**ワークアウトを終了** を選びます。アプリはアクティビティを完了し、詳細ページを開きます。

以下を確認してください。

- 時間とセッション RPE が実際のセッションを反映していること
- 完了したセット・負荷・回数・時間設定が正しいこと
- アクティビティが予定ワークアウトに紐づいたままになっていること
- 予定内容と実績内容が視覚的に区別できること

## よくある問題

- **スケジュール画面から先へ進めない：** 有効なワークアウトを少なくとも 1 件追加し、すべてのワークアウトがプラン期間内に収まっていることを確認してください。
- **筋力ワークアウトを保存できない：** 種目名、1 つ以上のセットグループ、および有効なセット数／回数を入力してください。
- **「予定通り開始」が失敗する：** 通信状況を確認し、予定ワークアウトを更新して、筋力トレーニング構造が保持されているか確認してください。
- **ライブ画面を閉じてしまった：** 予定ワークアウトを開き直せば、アクティビティ記録は保持されています。
