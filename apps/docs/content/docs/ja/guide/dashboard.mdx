# ダッシュボード

ダッシュボードは、最近のトレーニング傾向を最も素早く把握できる画面です。サマリーカード、フィットネスステータス、カスタマイズ可能な概要指標をまとめて確認できます。

次のような問いに答えたいときに活用してください。

- 最近どれくらいトレーニングできているか
- トレーニング負荷は上昇傾向か、安定しているか、下降しているか
- どの種目が傾向を牽引しているか
- アクティビティ、PMC、パワー、ペース、心拍数の詳細ページを深掘りすべきか

## 始める前に

- 選択した期間で傾向が読み取れる程度に最近のアクティビティをインポートしておきます。
- 強度ベースの指標を比較する前に、閾値と負荷ソースの優先順位を設定しておきます。
- ランニング・サイクリング・スイミングで異なる閾値を使っている場合は、種目ごとに 1 つずつ絞り込んで確認します。

## 傾向確認のワークフロー

1. 確認したい期間と種目を選択します。
2. フィットネスステータスは診断や最終判定ではなく、傾向として読み取ります。
3. 変化があったカードやグラフを特定します。
4. その変化の背景にある個別のアクティビティを開きます。
5. プランを変更する前に、対応する PMC・パワー・ペース・心拍数の詳細ページへ進みます。

## フィルター

ダッシュボードでは全体に効くフィルターを利用できます。

- **期間**：直近の集計期間を切り替えます。
- **種目タイプ**：ランニング、サイクリング、スイミング、またはすべてのアクティビティに絞り込みます。

フィルターを変更すると、カードとグラフが選択した条件に合わせて更新されます。

## フィットネスステータス

フィットネスステータスカードは、現在のトレーニング状況の概要をまとめたものです。最終判断のためではなく、全体を素早く見渡すために使います。

主なシグナル：

- 長期的な負荷と体力（CTL）の推移
- 最近の疲労（ATL）
- コンディション（TSB）のバランス
- トレーニングの継続性

背景となるモデルについては以下をご覧ください。

- [慢性トレーニング負荷（CTL）](/ja/docs/metrics/pmc/chronic-training-load)
- [急性トレーニング負荷（ATL）](/ja/docs/metrics/pmc/acute-training-load)
- [トレーニングストレスバランス（TSB）](/ja/docs/metrics/pmc/training-stress-balance)

## 概要カード

概要カードには、トレーニング量やパフォーマンス関連の指標が集約されます。データ内容に応じて、距離、時間、獲得標高、心拍数、パワー、ケイデンスなどが表示されます。

概要カードで変化に気づいたら、該当する詳細ページを開いて確認しましょう。

- **アクティビティ**：数値の元になっている個別のワークアウト
- **PMC**：トレーニング負荷の長期推移
- **パワー**：FTP、CP、NP、VI、パワーカーブ
- **ペース**：ランニングペース、GAP、NGP、距離別ベスト
- **心拍数**：心拍反応、ゾーン、EF、デカップリング

## レイアウトを編集する

デスクトップ版では、ダッシュボードの主要セクションのレイアウトを編集できます。現在のトレーニング期に合わせて配置を最適化しましょう。

例：

- ベース期はトレーニング負荷と継続性を最上部に配置する
- レース特異期はパワーやペースの指標を上部に配置する
- 高負荷週のあとは回復と疲労が見やすい位置に残す

編集後はレイアウトを保存すると、次回以降も同じ構成で開けます。

## ダッシュボードの変化をどう解釈するか

あるカードが 1 日だけ変化したからといって過剰反応しないでください。おすすめの手順は次のとおりです。

1. 期間フィルターと種目フィルターが適切か確認します。
2. 変化の要因となった最近のアクティビティを開きます。
3. トレーニング負荷と主観的な疲労感を照らし合わせます。
4. プランを踏まえた解釈が欲しい場合は AIコーチに相談します。

ダッシュボードはあくまで出発点です。最終的な判断では、プラン、最近のワークアウト、体調を総合的に考慮しましょう。

## 結果の確認

- 有効なフィルターが、調べたい問いと一致していること
- 表示されているアクティビティと合計値が同じ期間・種目スコープであること
- 見つけた傾向を具体的な実施済みアクティビティに遡って確認できること
- 閾値依存の指標が最新のプロフィール値を使っていること
- 保存したデスクトップレイアウトが、ダッシュボードを開き直しても維持されていること

## トラブルシューティング

- **カードが空になる：** 期間を広げ、種目フィルターを解除し、アクティビティが完了状態（Ready）になっているか確認してください。
- **合計値がアクティビティ一覧と合わない：** タイムゾーン、日付範囲、種目フィルター、処理ステータスを比較してください。
- **負荷やステータスが急に変わった：** トレーニング自体が変わったと決めつける前に、閾値履歴と負荷ソースの優先順位を確認してください。
- **レイアウトが保存されない：** 編集を保存し、更新前にサインイン済みであることを確認してください。
- **特定のカードが極端な値を示す：** 異常値に基づいて判断する前に、元のアクティビティを開いてセンサーデータの品質を確認してください。
