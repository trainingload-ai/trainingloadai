# トレーニング負荷管理における TrainingPeaks との比較

TrainingPeaks を使っている場合は、「コーチの予定に従う」「トレーニング負荷を確認する」「実績を踏まえて来週のワークアウトを調整する」といった、普段最も行う作業から比較を始めてみましょう。

TrainingPeaks はトレーニングカレンダー、コーチ連携、プランマーケットプレイス、Virtual インドアトレーニングを提供しています。最新の機能と料金は [TrainingPeaks 公式サイト](https://www.trainingpeaks.com/)および[アスリート向け料金ページ](https://www.trainingpeaks.com/pricing/for-athletes/)をご確認ください。

## Trainingload.ai でのトレーニング管理

- スキップや未紐づけのセッションも含め、カレンダー上で予定ワークアウトと記録済みアクティビティを比較する
- 最近のトレーニングや回復状況とあわせて PMC とパフォーマンス傾向をレビューする
- AIコーチにアクティビティの解説やワークアウト調整案を依頼し、適用前に変更内容を確認する
- 公式テンプレート、手動エディタ、または AIコーチのドラフトからトレーニングプランを作成する

Trainingload.ai には TrainingPeaks のコーチマーケットプレイスや Virtual 機能はありません。すでに特定のコーチやデバイス連携フローに依存している場合は、元のプラットフォームが必要な部分を事前に確認してください。

## 1 週間分のトレーニングで試してみる

1. [最近のアクティビティをインポート](/ja/docs/guide/connect-data)し、ソース・日付・閾値を確認します。
2. 今後のワークアウト用に[プランドラフトを作成](/ja/docs/guide/create-training-plan)します。
3. [カレンダー](/ja/docs/guide/calendar)で実施済みアクティビティを 1 件紐づけ、予定負荷と実績負荷を比較します。
4. 該当するアクティビティまたはプランから[AIコーチ](/ja/docs/guide/ai-coach)を開き、調整を適用する前に 1 つ回答をレビューします。

試用期間中も元の記録は残しておいてください。負荷算出方法・閾値・対象期間の違いにより、過去曲線がプラットフォーム間で完全一致しない場合があります。

## 記録を移す前に確認すること

- アクティビティファイルのアップロードはアカウント全体の完全移行ではありません。
- プラン、レース予定、メモはアクティビティと一緒に自動移行されるわけではないため個別に確認してください。
- 設定を変更する前に、既存の FTP、閾値心拍数、ペース設定を使って結果を比較しましょう。
- アカウント利用枠と AI 利用状況については[Trainingload.ai の料金](/ja/pricing)をご確認ください。

続けて[トレーニング分析ワークフロー](/ja/docs/guide/training-analysis-workflow)を読むか、まずサンプルを見てみたい場合は[Demo を開く](https://demo.trainingload.ai/en)をご利用ください。
