# 通知とレビュー自動化

通知を使うと、インポート結果や完了したレビューを素早く確認できます。レビュー自動化を有効にすると、対象となる日次・週次・月次レビューを毎回手動で依頼しなくても自動生成できます。

## 自動化を有効にする前に

- 日次・週次・月次の区切りが正しくなるよう、タイムゾーンを正確に設定します。
- アクティビティを継続的にインポートし、進行中のプランを最新状態に保ちます。
- プラン実行をレビュー対象にしたい場合は、実施済みアクティビティを紐づけておきます。
- アカウントの利用権限と AI 利用枠を確認しておきます。

## 通知の種類

通知には、一般的なシステムメッセージ、継続トレーニングプランの更新、完了したトレーニングレビューなどが届きます。また、インポートダイアログではバックグラウンド処理の完了時に通知が届く旨が案内される場合があり、ダイアログを開き続ける必要はありません。

通知画面から次の操作が行えます。

- 関連するレビューや対象ページを開く
- 個別の通知を既読にする
- すべての通知を既読にする

通知を既読にしても、元のアクティビティ、プラン、コーチセッションが削除されることはありません。

## トレーニングレビューを読む

日次レビューは前日のアクティビティを一覧表示し、週次レビューは直近の完了週を種目別に集計し、月次レビューは直近の完了カレンダー月を週ごとにまとめます。利用可能な場合は、コーチからのインサイトとして「良かった点」「注意すべき点」「次の期間の重点ポイント」が提示されます。引用されているアクティビティを選択すると元の記録を確認できます。

週次レビューでは、トレーニング日数、平均セッション時間、および利用可能な場合はトレーニング負荷も表示されます。同じ日に複数セッションを実施した場合は 1 トレーニング日としてカウントされます。

睡眠時間、HRV、安静時心拍数は記録がある場合に表示されます。日次レビューでは翌日の回復記録と算出可能な最近のベースラインを使用します。週次・月次レビューでは記録された日数が示され、比較可能な場合は前期間との比較も表示されます。

Web では 2 つの期間を比較するペアバーが表示され、テーブルでは実数値に加えて、前期間の値が 0 より大きい場合のセッション数・時間・比較可能な回復指標の変化率を確認できます。

## レビュー自動化を設定する

Web では **アカウント → AIレビュー自動化**、モバイルでは該当のアカウントパネルを開きます。

設定できるスイッチには次が含まれます。

- アクティビティレビュー
- 日次レビュー
- 週次レビュー
- 月次レビュー
- プランレビュー

自動化の利用可否はアカウントの権限と AI 利用上限に依存します。スイッチをオンにするとそのカテゴリの自動実行が許可されますが、必要なアクティビティやプランデータが欠けている場合は有益な出力が得られないことがあります。

## レビューに必要なトレーニング記録を整える

自動化を頼りにする前に、次の点を整えておきましょう。

1. 日次・週次の境界はタイムゾーンに依存するため、タイムゾーンを確認します。
2. 実施済みアクティビティを継続的にインポートします。
3. 進行中のプランを最新状態に保ちます。
4. 実施済みアクティビティを予定ワークアウトに紐づけます。
5. 必要に応じてセッション RPE や現在の状態を入力します。

## 手動でレビューを実行する

手動レビュー操作が提供されている画面では、自動化スケジュールを変えずに直近の完了日・完了週・完了月のレビューをリクエストできます。レビュージョブはバックグラウンドで実行されるため、次のリクエストを送る前に完了を待ってください。

## 正常動作の確認

- 設定画面を開き直しても保存したスイッチが有効なままであること
- 完了したレビューが通知またはコーチ画面に表示されること
- 通知を開くと想定通りのレビューへ遷移すること
- レビューが正しい対象期間・プラン・アクティビティを参照していること

## トラブルシューティング

レビューが表示されない場合は、利用権限、AI 利用枠、タイムゾーン、データの有無、およびバックグラウンドジョブがまだ実行中かどうかを確認してください。構造化アクションの失敗については[トラブルシューティング](/ja/docs/guide/troubleshooting)をご覧ください。

レビューを何度も再リクエストしても欠けているアクティビティは補われず、AI 利用枠を消費する可能性があります。まずアクティビティのインポートと処理が完了しているか確認し、すでに生成中の場合は完了を待ちましょう。
