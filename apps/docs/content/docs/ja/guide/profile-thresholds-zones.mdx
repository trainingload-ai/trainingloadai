# プロフィール・閾値・ゾーン

プロフィール、閾値、トレーニングゾーンを設定することで、トレーニング負荷の推定値、ゾーングラフ、コーチングのアドバイスがあなたの実情を反映するようになります。たとえばパワートレーニングには適切な FTP が必要であり、心拍ゾーンは選択した基準値とモデルに依存します。

初日からすべての項目を埋める必要はありません。確かな数値から設定を始め、テストやレース、安定したトレーニングデータの蓄積に応じて更新していきましょう。

## 始める前に

- 最近の信頼できるテスト、レース、デバイス、またはコーチによる現在値を用意します。
- 実際に使用している種目とセンサーを把握しておきます。
- ほかのアスリートの閾値やゾーンをコピーしないでください。
- 推移が重要な値については、測定日と測定方法を控えておきましょう。

## キャリブレーション手順

1. タイムゾーン、単位系、基本的なプロフィール項目を設定します。
2. 根拠のある最新の閾値のみを入力します。
3. センサーの信頼性に基づいて負荷ソースの優先順位を選択します。
4. 対象となる種目ごとにゾーンを選択または定義します。
5. 保存後、最近の完了済みアクティビティを確認し、単位・ゾーン・トレーニング負荷の解釈が意図通りか確かめます。

## 基本プロフィール

基本プロフィールは、表示形式、カレンダーの日付判定、一部の生理学的計算に影響します。

確認する項目：

- **タイムゾーン**：カレンダーの日付、レビュー期間、日付ベースのトレーニング表示に使用されます。
- **単位系**：距離、ペース、獲得標高などの表示単位を切り替えます。
- **体重**：体重あたりパワー（W/kg）や体重関連指標の算出に役立ちます。
- **身長・生年月日・性別**：年齢、体格、参考基準範囲が関係する計算に使用されます。
- **メイン種目**：種目ごとの初期設定や表示選択の基準になります。

タイムゾーンが誤っていると、ワークアウトが別の日付に表示されることがあります。カレンダーやレビュー集計を評価する前に、まずタイムゾーンを正しく設定してください。

## 主な閾値

閾値はワークアウトの生データを強度やトレーニング負荷へと変換するための基準です。

主な項目は次のとおりです。

- **FTP**：機能的作業閾値パワー。主にサイクリングのパワー強度とパワーベースの負荷に使用されます。
- **CP**：クリティカルパワー。パワー持続曲線や CP ベースの分析に役立ちます。
- **W'（W Prime）**：クリティカルパワーを上回る領域で使用できる有限の作業容量です。
- **Pmax**：パワープロファイリングにおけるピークパワーの基準値です。
- **LTHR**：乳酸性作業閾値心拍数。心拍ゾーンや閾値ベースの心拍分析に役立ちます。
- **最大心拍数（Max HR）**：最大心拍数ベースのゾーンや心拍比較に使用されます。
- **安静時心拍数**：最大心拍数と組み合わせて心拍予備能（HRR）の計算に使用されます。
- **CS**：クリティカルスピード。ペースや速度の基準値として使用されます。
- **TP**：閾値ペース（または閾値速度）。種目や表示設定に応じて使用されます。

過去最高の記録ではなく、最新の信頼できる数値を使用してください。閾値は現在のトレーニング判断において維持できる水準を表す必要があります。

## 負荷ソースの優先順位

Trainingload.ai は複数のシグナルからアクティビティのトレーニング負荷を算出できます。負荷ソースの優先順位は、複数のデータが利用できる場合にどれを優先するかを指定します。

利用可能なソース：

- **パワー**
- **心拍数**
- **ペース**
- **セッション RPE**

実用的な初期設定は、最も信頼性の高いセンサーを先頭に置くことです。

- 信頼できるパワーメーターを使ったサイクリング：パワーを最優先
- パワーなしのランニング：地形やデータ品質に応じてペースまたは心拍数を最優先
- インドアやセンサーが限られるセッション：心拍数またはセッション RPE が有用

負荷ソースの優先順位を変更すると、過去のトレーニング負荷の解釈も変わる場合があります。単発のワークアウトの見栄えを良くするためではなく、データ品質やトレーニング環境が変わったときに変更してください。

## ゾーンモデル

トレーニングゾーンは強度をいくつかの領域に分け、グラフ、ワークアウト目標、レビューで活用できるようにします。

Trainingload.ai はモデルベースとカスタムの両方のゾーンに対応しています。

- **心拍ゾーン**：最大心拍数、心拍予備能（HRR）、LTHR、またはカスタム値を使用できます。
- **パワーゾーン**：FTP、CP、またはカスタム値を使用できます。
- **ペースゾーン**：CS またはカスタム値を使用できます。

ゾーンモデルはあくまで便利な目安であり、絶対的な基準ではありません。コーチが特定のモデルを使っている場合はそれに合わせましょう。ラボテストやフィールドテストによる実測ゾーンがある場合は、カスタムゾーンの使用が適しています。

## 種目別ゾーン

ゾーンは種目によって異なります。ランニング、サイクリング、スイミングを常に同じ基準で解釈するべきではありません。

例：

- サイクリングのパワーゾーンはサイクリングのパワー基準値に依存します。
- ランニングのペースゾーンはランニングの速度・ペース基準値に依存します。
- スイミングのペースゾーンは通常 100m あたりで表されます。
- 心拍反応はランニング・サイクリング・スイミングで異なる場合があります。

実際に取り組んでいる種目のゾーンを設定してください。ゾーンが未設定でもアクティビティのインポート自体は可能ですが、グラフ、ワークアウト目標、AIコーチの説明が抽象的になりやすくなります。

## カスタムゾーン

次のような場合はカスタムゾーンを使用してください。

- コーチがすでに独自のゾーンを定義しているとき
- ラボテストや信頼できるプロトコルで測定したとき
- モデル自動生成のゾーンが実際のトレーニング感覚と合わないとき
- デフォルトモデルでは表現できない種目固有の範囲が必要なとき

カスタムゾーンは絶対値で入力します。

- パワー：ワット（W）
- 心拍数：bpm
- ランニングペース：秒／km
- スイミングペース：秒／100m

ゾーン名は簡潔で順序がわかるようにしておきましょう。わかりやすいラベルにすると、グラフや AIコーチのコンテキストが読みやすくなります。

## 閾値を更新するタイミング

現在の設定が実態と合わなくなってきた十分な根拠がそろったタイミングで閾値を更新してください。

更新を検討すべき良い理由：

- 最近のテストで信頼できる新しい値が得られた
- レース結果によって現在の基準が明確に変わった
- 数週間のワークアウトで継続的な向上または低下が見られる
- 使用デバイスや計測方法が変わった
- 長期の休養・体調不良・怪我から復帰した

極端に調子が良かった日や悪かった日 1 回だけで閾値を変更しないでください。閾値の更新は一時的なノイズを追うのではなく、安定した傾向を反映するものであるべきです。

## AIコーチへの影響

AIコーチはプロフィール、閾値、ゾーン、負荷ソースの優先順位を前提情報として活用します。

設定が整っているほど、AIコーチは次のような問いに的確に答えられます。

- ワークアウトが狙った強度と一致していたか
- トレーニング負荷が急激に上がりすぎていないか
- 最近の疲労を踏まえて予定ワークアウトが適切か
- ペース・心拍数・パワーの目標が現実的か

主要な値が未設定でも AIコーチは支援できますが、より慎重な判断となり追加の確認質問をすることがあります。

## 設定を確認する

- カレンダーの日付がご自身の現地トレーニング日と一致していること
- 距離・ペース・体重・獲得標高が意図した単位で表示されていること
- ゾーングラフが選択した種目と基準値を使用していること
- 必要なデータがある場合、最近のアクティビティの負荷ソースが設定した優先順位と一致していること
- コーチの回答で引用される閾値やゾーンが保存済み設定と一致していること

## トラブルシューティング

- **アクティビティが別の日付に移動した：** アカウントのタイムゾーンを修正し、元の開始時刻とソース側のタイムゾーンを再確認してください。
- **ゾーンが簡単すぎる／きつすぎる：** 個別の境界値を書き換える前に、基準値・モデル・種目・単位を確認してください。
- **設定変更後にトレーニング負荷が変わった：** どの閾値または負荷ソース優先順位を変更したか確認してください。アクティビティ自体は変わっていなくても、過去の解釈が更新されることがあります。
- **スイミングのペースがおかしい：** ランニングペースの単位ではなく、100m あたりの秒数になっているか確認してください。
- **値がわからない項目がある：** 推測して入力せず、信頼できる根拠が得られるまで未設定のままにしてください。
