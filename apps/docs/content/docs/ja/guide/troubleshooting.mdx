# トラブルシューティング

まずは実際に画面で見えている症状から切り分けましょう。どの段階で失敗しているか把握する前に、プラットフォームの再接続、アクティビティ削除、プランの再作成を行わないようにしてください。

## サインインや認可がループする

1. ブラウザまたはモバイルアプリがサービスへ正常に通信できるか確認します。
2. OAuth フローは、開始したのと同じブラウザセッション内で完了させます。
3. 別のログイン手段を解除する前に、アカウントに有効なログイン手段が残っているか確認します。
4. サインインページを再読み込みしてから 1 回だけ再試行します。

外部プラットフォームの認可には成功したのに Trainingload.ai 側で未接続のままになる場合は、プラットフォームダイアログを開き直し、コールバックエラーや権限エラーが出ていないか確認してください。

## 同期されたはずのアクティビティが見当たらない

1. 連携元プラットフォームにそのワークアウトが存在することを確認します。
2. プラットフォームの接続状態を確認します。
3. 利用可能な場合、手動同期または突き合わせ同期を 1 回だけ実行します。
4. インポートバッチが完了するのを待ちます。
5. アクティビティ一覧で日付と種目を指定して検索します。

何度も連携解除と再接続を繰り返さないでください。元の権限問題を解決しないまま、重複したインポート処理を発生させる恐れがあります。

## アクティビティは表示されているが分析が不完全

アクティビティ自体はすべての派生グラフが完成する前に表示されることがあります。処理完了後に画面を更新してください。特定の指標グループだけが表示されない場合は、元のデータストリームを確認します。

- 心拍分析には心拍数サンプルが必要です。
- パワー分析にはパワーサンプルと適切な種目／プロフィール設定が必要です。
- ルートと標高表示には GPS／標高データが必要です。
- ペースと距離の分析には有効な距離・時間データが必要です。

## 指標の数値がおかしく見える

次の順で確認してください。

1. 種目タイプと種目定義
2. 単位系とタイムゾーン
3. 閾値と適用開始日
4. ゾーンモデルとカスタム境界値
5. 選択中の負荷ソース優先順位
6. 生のアクティビティストリーム

閾値を変更するとその後の計算の解釈に影響します。1 回のワークアウトの見栄えに合わせるために数値をいじらず、変更理由を記録しておきましょう。

## ワークアウトを保存できない

持久系ワークアウトでは、各構造化ステップに有効な時間または距離と、対応する目標が設定されているか確認します。筋力トレーニングワークアウトでは、次の条件を満たしているか確認してください。

- 種目が少なくとも 1 つ存在する
- すべての種目に名前が入っている
- すべての種目に少なくとも 1 つのセットグループがある
- すべての種目に少なくとも 1 つのメインセット（ワークセット）が含まれている

エディタにはローカライズされた検証メッセージが表示され、修正できるよう未保存のドラフトが開いたまま保持されます。

## 別の場所でプランが変更されたと表示される

バージョン競合やステータス競合が表示された場合、画面を読み込んだあとに別のリクエストがプランを変更しています。プランを再読み込みして最新状態を確認してから編集を再適用してください。古い画面から削除などの破壊的操作を無闇に再試行しないでください。

## モバイル記録の同期が完了していない

復元できる可能性がある間は、アプリをアンインストールしたりローカルストレージを消去したりしないでください。記録画面を開き直してセッションの復元を待ち、ネットワークへ再接続してください。詳しくは[モバイル記録](/ja/docs/guide/mobile-recording)をご覧ください。

## AIコーチがリクエストを完了できない

- 非常に大きな依頼は短くするか、段階に分けて質問します。
- 対象のプランやアクティビティが削除されずアクセス可能か確認します。
- AI 利用枠の上限を確認します。
- 構造化アクションが検証エラーになった場合は、意図する変更内容を通常の文章で伝えて再試行します。
- 変更前後のプレビューで確認できない調整案は絶対に適用しないでください。

## 問い合わせ時に役立つ情報を集める

不具合を報告する際は、次の情報を添えてください。

- おおよその発生時刻とタイムゾーン
- Web かモバイルか、OS、アプリまたはブラウザのバージョン
- 発生したページやワークフロー（認証情報は含めない）
- 共有して差し支えない範囲でのアクティビティハッシュ ID、プラン ID、またはプラットフォーム名
- 画面に表示された正確なエラーメッセージ文言
- 個人情報を隠したスクリーンショット

パスワード、OAuth トークン、API キー、自宅の正確な座標は絶対に送信しないでください。
