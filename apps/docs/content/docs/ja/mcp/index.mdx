# TrainingLoad MCP

TrainingLoad MCPを使うと、ChatGPT、Codex、Claudeをはじめとする対応AIクライアントに自分のトレーニングデータを接続できます。アクティビティ記録を1件ずつコピーしなくても、直近のトレーニング負荷、トレーニングプランの達成状況、パフォーマンスの推移、同期の不具合などをそのまま質問できます。MCPはデータの読み取り専用であり、トレーニングスケジュールを変更することはありません。

**サーバーURL:** `https://api.trainingload.ai/mcp`

APIキーは不要です。接続時にクライアントがTrainingLoadのOAuth画面を開き、クライアント名と要求されるスコープを確認したうえで認可できます。認可は後からアカウント設定でいつでも取り消せます。

## 読み取れるトレーニング情報

| 質問の例 | 主な機能 |
| --- | --- |
| 現在のトレーニング状態はどうなっていますか？ | トレーニングスナップショット、レディネス指標、負荷の推移 |
| 2つのトレーニングブロック間で何が変わりましたか？ | 期間比較、種目別内訳、アクティビティ統計、継続性の分析 |
| ランニング、サイクリング、スイミングのフィットネスは変化していますか？ | フィットネス推移、トレーニングゾーン、自己ベスト |
| トレーニングプランにどの程度沿って進められていますか？ | プランの一覧・サマリー、予定ワークアウト、ワークアウト詳細、ステータス別の達成率 |
| どんなトレーニングを完了しましたか？ | アクティビティ一覧、プライバシー保護済みの詳細、ゾーン別滞在時間、ラップ／スプリットサマリー |
| 今後の大会予定はどうなっていますか？ | 大会一覧およびアカウントに紐づく大会詳細 |
| 連携サービスが同期されない原因は何ですか？ | 接続状態と同期の可否確認 |
| コンディションや健康面の指標に変化はありますか？ | 個別認可された日次ヘルスサマリー |

各フィールドとスコープの詳細は[ツールリファレンス](/ja/docs/mcp/tools)をご覧ください。クライアントは、指標の解釈、安全上の境界、繰り返し使える分析ワークフローをまとめた3つの組み込み[リソースとプロンプト](/ja/docs/mcp/resources-and-prompts)も利用できます。

## 試してみたい質問の例

- 「今週のトレーニング量とトレーニング負荷を先週と比較して、変化の主な要因になったアクティビティを教えて」
- 「今週のトレーニングプランはどれくらい完了している？アクティビティが紐付いていないワークアウトも教えて」
- 「最近のランニング指標はどう変わっている？比較可能なデータが欠けている日付も挙げて」

回答を確認するときは、対象の日付範囲、参照されたアクティビティ、欠損データの有無を必ずチェックしてください。傾向データはトレーニングの振り返りに役立ちますが、医学的な結論を導くものではありません。

## 接続前に知っておきたい制限事項

- **読み取り専用:** クライアントはアクティビティ、トレーニングプラン、大会、プロフィール、外部連携、アカウント設定を変更できません。
- **本人のデータのみ:** クライアントが照会できるのは、認可された自分のアカウントに属する記録に限られます。
- **サマリーデータのみ:** 正確なGPS軌跡、生のセンサーストリーム、連携サービスの認証情報、完全なFITファイルは返されません。
- **ヘルス権限は別管理:** `health:read` はデフォルトの認可範囲に含まれません。
- **アクセスはいつでも解除可能:** 使わなくなったクライアントの権限は、アカウント設定からいつでも取り消せます。
