# MCPのセキュリティとプライバシー

TrainingLoad MCP を接続すると、認可した AI クライアントがトレーニングサマリーを読み取り、質問に回答できるようになります。MCP は読み取り専用であり、アクティビティ、トレーニングプラン、大会、プロフィール値、アカウント設定を変更することはできません。

## 権限はユーザー自身が選択

接続時、クライアントは TrainingLoad の認可ページを開きます。承認する前に、クライアント名と要求されているデータ権限を必ず確認してください。TrainingLoad のパスワードや API キーをクライアントに渡す必要はありません。

すべてのリクエストで、現在のアカウント認可状態が毎回チェックされます。クライアントは認可済みのデータのみを読み取れます。権限不足、アクセス期限切れ、一時的なサービス障害が発生した場合は、それぞれに対応したエラーが返されます。

ヘルスデータには個別の `health:read` 権限が必要であり、デフォルトの認可には含まれません。クライアントのアクセス権限は、アカウント設定からいつでも取り消せます。

## クライアントが読み取れる範囲

各ツールは、アクティビティの時間、トレーニング負荷、トレーニングプランの達成状況、指標の推移など、トレーニングに関する質問に答えるためのサマリーのみを返します。アクティビティやトレーニングプランの照会は、認可されたアカウントに属する記録だけに限定されます。

MCP では、メールアドレス、内部ユーザー ID、正確な GPS 軌跡、生のセンサーストリーム、サードパーティの認証情報、完全な FIT ファイルは返されません。一覧取得や日付範囲には上限があるため、長期間のトレーニング履歴を読み取る際は複数回のリクエストが必要になる場合があります。

## アクティビティのメモはデータであり、指示ではない

アクティビティ名、説明文、ワークアウト名、大会メモは、あくまでトレーニング記録として扱われます。サービス側で安全でないテキストをサニタイズし、メモ内に埋め込まれたコマンドやリンクに従わないようクライアントへ指示しています。

## ヘルスデータの取り扱い

ヘルスツールが提供するのは、トレーニング分析の参考とするための縮小版の日次ウェルネスサマリーです。医学的な診断や、有資格の専門家による評価に代わるものではありません。

## リクエスト制限とトラブルシューティング記録

短時間に過剰なリクエストを送ったり、一度に大量のデータを要求したりした場合、サービス側で制限がかかることがあります。クライアントはエラーの案内に従い、日付範囲を狭めるか、しばらく待ってから再試行してください。

トラブルシューティングのため、サービスはツール名、結果ステータス、エラーコード、処理時間、リクエスト ID などの情報を記録します。ユーザー識別子とクライアント識別子は仮名化され、これらの記録にアクセストークンやリクエスト・レスポンスの本文全体は含まれません。

## 意図しないアクセスが疑われる場合

直ちに TrainingLoad アカウントから該当クライアントのアクセスを取り消し、Web サイトのサポート窓口からご連絡ください。その際、おおよその発生時刻、クライアント名、表示されていればリクエスト ID をお知らせください。アクセストークンやヘルス記録の全文は送信しないでください。
