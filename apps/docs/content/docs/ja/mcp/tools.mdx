# MCPツールリファレンス

このページはサーバーの機能カタログから自動生成されます。直接編集せず、`pnpm --dir apps/server mcp:reference` を実行してください。すべてのツールは、OAuth で認可されたアスリートのデータのみを読み取ります。

> `health:read` はデフォルトの認可範囲に含まれません。初回の `get_health_summary` 呼び出し前に、クライアント側で段階的認可を要求する必要があります。

| ツール | 用途 | OAuth スコープ |
| --- | --- | --- |
| `get_training_snapshot` | 認可されたアスリートの直近のトレーニング負荷、フィットネス、疲労、フォーム、前週比、直近のアクティビティを集約して取得します。複数の個別ツールを呼び出す前に、まずこのツールの利用を優先してください。 | `training:read` `plan:read` `activity:read` |
| `get_athlete_profile` | 認可されたアスリートの種目設定とトレーニング閾値を読み取ります。氏名、メールアドレス、生年月日、内部ユーザー ID は返しません。 | `profile:read` |
| `list_activities` | 指定した範囲内で、認可されたアスリートのアクティビティサマリーを検索します。生のセンサーストリームや正確な GPS 軌跡は返しません。 | `activity:read` |
| `get_activity` | 不透明なハッシュ ID を指定して、認可されたアクティビティを1件読み取ります。サマリー指標のみを返し、正確なルートや生のセンサーサンプルは除外されます。 | `activity:read` |
| `get_activity_zones` | 認可された1件のアクティビティについて、保存済みの心拍・パワー・ペースのゾーン分布を読み取ります。集計された時間と割合のみを返し、センサーサンプルは返しません。 | `activity:read` |
| `get_activity_splits` | 認可された1件のアクティビティのラップ／スプリットサマリーを、不透明なページネーション付きで範囲制限して読み取ります。正確な座標や生のセンサーサンプルは除外されます。 | `activity:read` |
| `get_activity_statistics` | 指定期間における種目別のアクティビティ件数、アクティブ日数、時間、距離、標準トレーニング負荷を集計します。指標のカバレッジと打ち切りステータスも含まれます。 | `training:read` `activity:read` |
| `get_training_load` | 最大180日間の範囲で、認可されたアスリートのトレーニング負荷、フィットネス、疲労、フォームの時系列データを読み取ります。 | `training:read` |
| `compare_training_periods` | 2つの指定期間について、トレーニング負荷、1日平均、アクティブ日数を比較します。結果は観察データであり、フィットネスや回復状態の変化を断定するものではありません。 | `training:read` |
| `get_training_breakdown` | 最大180日間の範囲で、認可されたアスリートのトレーニング負荷をランニング、サイクリング、スイミング、その他に分解して取得します。 | `training:read` |
| `get_training_consistency` | 14〜180日間の範囲で、保存日カバレッジ、連続アクティブ日数、日次負荷のばらつき、週次負荷を要約します。欠損日は 0 として扱わず、欠損のまま保持します。 | `training:read` |
| `get_training_readiness` | 現在のトレーニング負荷、フォーム、フレッシュネス、直近負荷バンドを観察用のトレーニング指標として返します。医学的評価やトレーニング実施の指示ではありません。 | `training:read` `plan:read` `activity:read` |
| `get_fitness_trends` | 1つのフィットネス指標と明示された1つのソース系統について、指定期間の履歴を読み取ります。推定値は参考情報であり、AUTO または MANUAL の値がプロフィール記録です。 | `profile:read` |
| `get_training_zones` | アスリートの現在解決されている心拍・ペース・パワーゾーンを読み取ります。各設定がカスタム、算出値、利用不可のいずれであるかも含まれます。 | `profile:read` |
| `get_personal_bests` | 指定した日付範囲内で、標準またはカスタムの距離・時間ターゲットに対する集計済み自己ベスト記録を読み取ります。ルートや生のセンサーデータは返しません。 | `activity:read` |
| `list_training_plans` | 指定した日付範囲と重なる認可済みトレーニングプランを検索します。継続型プランでは periodWeeks と endDate が null になります。generatedThrough は公開済みの最新日付であり、プラン終了日や途切れのない網羅を保証するものではありません。 | `plan:read` |
| `get_plan_summary` | ユーザーが所有するトレーニングプランのサマリー（達成率、予定負荷と実績負荷、週次進捗、種目別内訳）を読み取ります。継続型プランの合計は workoutWindow 内のみを対象とし、periodWeeks は null であり、通算合計ではありません。プランが変更されることはありません。 | `plan:read` `activity:read` |
| `list_planned_workouts` | 指定した日付範囲内の認可済み予定ワークアウトを、不透明なページネーション付きで一覧取得します。 | `plan:read` |
| `get_planned_workout` | 認可された予定ワークアウト1件と、その構造化ステップを読み取ります。このツールがトレーニングプランを変更することはありません。 | `plan:read` |
| `get_plan_adherence` | 指定した日付範囲について、ステータスに基づくトレーニングプランの達成状況を要約します。DONE は完了、SKIPPED はスキップ、PLANNED または IN_PROGRESS は未完了として扱われます。 | `plan:read` |
| `list_competitions` | 指定した日付範囲内にある、認可されたアスリートの大会一覧を不透明なページネーション付きで取得します。 | `competition:read` |
| `get_competition` | 不透明なイベント ID を指定して、認可された大会1件（日程、目標、場所、メモを含む）を読み取ります。このツールが大会情報を変更することはありません。 | `competition:read` |
| `get_health_summary` | 選択された日次の回復、睡眠、心拍、ストレス、活動サマリーを読み取ります。ウェルネスの参考情報であり、医学的な診断や推奨ではありません。 | `health:read` |
| `get_integration_status` | 対応している外部トレーニングサービスの接続状況と同期の可否を読み取ります。外部アカウント識別子、認証情報、生のエラーメッセージは返しません。 | `profile:read` |
