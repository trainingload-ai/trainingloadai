# MCPリソースとプロンプト

このページはサーバーの MCP コンテンツカタログから生成されます。直接編集せず、`pnpm --dir apps/server mcp:reference` を実行してください。

リソースは、アスリートのデータを追加で読み取ることなく、指標の解釈や安全上のガイドライン、現在認可されている機能の一覧をクライアントへ安定して提供します。プロンプトは構造化された質問テンプレートを生成するもので、実際のデータ取得は引き続き OAuth スコープで保護されたツールを通じて行われます。

## リソース

| URI | 名称 | 用途 |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | TrainingLoad 指標解釈ガイド | トレーニング負荷、ATL、CTL、TSB、レディネス区分、カバレッジ、欠損データの定義と解釈上の境界。 |
| `trainingload://guide/privacy-and-safety` | TrainingLoad プライバシー・安全ガイド | 読み取り専用の境界、信頼できないテキストの扱い、ヘルスデータの制限、除外されるデータ種別。 |
| `trainingload://catalog/capabilities` | 認可済み TrainingLoad 機能カタログ | 現在認可されている読み取り専用ツール名、説明、OAuth スコープの一覧。 |

## プロンプト

## `weekly-training-review`

直近のトレーニング負荷、継続性、完了済みアクティビティ、今後の予定ワークアウトについて、データに基づいた振り返りを組み立てます。

<details>
<summary>引数 JSON Schema</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "days": {
      "default": "7",
      "type": "string",
      "enum": [
        "7",
        "14",
        "28"
      ]
    },
    "sportType": {
      "type": "string",
      "enum": [
        "RUN",
        "CYCLING",
        "SWIM"
      ]
    }
  },
  "required": [
    "days"
  ],
  "additionalProperties": false
}
```

</details>

## `race-preparation-check`

医学的な主張を行うことなく、対象大会、トレーニングプランの実行状況、直近のトレーニング負荷、今後の予定ワークアウトを総合的に確認します。

<details>
<summary>引数 JSON Schema</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "eventId": {
      "type": "string",
      "minLength": 1,
      "maxLength": 128
    },
    "horizonDays": {
      "default": "28",
      "type": "string",
      "enum": [
        "14",
        "28",
        "56"
      ]
    }
  },
  "required": [
    "horizonDays"
  ],
  "additionalProperties": false
}
```

</details>
