# クライアント別ガイド

お使いのクライアントを選択してください。どのガイドでも同じエンドポイントへ TrainingLoad OAuth 経由で接続でき、API キーは不要です。

- [ChatGPT](/ja/docs/mcp/clients/chatgpt)
- [Codex](/ja/docs/mcp/clients/codex)
- [Claude Code](/ja/docs/mcp/clients/claude-code)
- [Claude Desktop](/ja/docs/mcp/clients/claude-desktop)
- [Cursor](/ja/docs/mcp/clients/cursor)
- [VS Code](/ja/docs/mcp/clients/vscode)
- [opencode](/ja/docs/mcp/clients/opencode)

設定が終わったら、[すべてのクライアント共通の動作確認手順](/ja/docs/mcp/connect#すべてのクライアント共通の動作確認手順)に沿って、OAuth 認可、ツール検出、初回呼び出しが正しく動作することを確認してください。
