# MCP変更履歴

## 2026-10-15 — 読み取り専用トレーニング機能の全面拡充

- ツールカタログを 17個から 24個に拡張しました。
- 明示的なカバレッジと打ち切り（truncation）セマンティクスを備えた、集約アクティビティ統計とトレーニング継続性分析を追加しました。
- プライバシー保護済みのアクティビティゾーン分布およびラップ／スプリット詳細を追加しました。
- トレーニングプランの一覧取得、プラン単位の達成率／負荷サマリー、単一大会の詳細取得を追加しました。
- 3つの組み込み MCP リソースと 3つの再利用可能なプロンプトを追加し、生成リファレンスドキュメント（バイリンガル）とリリースゲート検証を整備しました。

## 2026-10-15 — 高度な読み取り専用分析とオンボーディング拡充（先行マイルストーン）

- ツールカタログを 9個から 17個に拡張しました。
- 期間比較、種目別トレーニング負荷の内訳、トレーニングレディネス指標を追加しました。
- フィットネス推移、トレーニングゾーン、自己ベストを追加しました。
- ステータスベースのプラン達成率と、外部連携・同期状態の確認機能を追加しました。
- 仕組み解説、ユースケース、および 7種類のクライアント別接続ガイドを追加しました。
- 機能紹介ページを拡充し、OAuth 接続から透過的なツール呼び出し、根拠に基づく回答までを一貫して説明するようにしました。

## 2026-10-14 — 初期の読み取り専用プロダクト公開

- トレーニング、アクティビティ、トレーニングプラン、大会、プロフィール、ヘルスに関する 9個の読み取り専用機能を追加しました。
- 集約ツール優先のサーバー指示と Zod ベースの入出力コントラクトを追加しました。
- OAuth スコープによるフィルタリング、`health:read` の個別認可、取り消し状態の可視化、レート制限、監査記録、OpenTelemetry 計装を追加しました。
- `2025-11-25` および `2026-07-28` 互換のステートレス MCP SDK v2 トランスポートを追加しました。
- 自動生成のツールリファレンスとクライアント接続ガイドを追加しました。

本リリースに書き込み用ツールは含まれていません。
