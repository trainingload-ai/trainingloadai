# プランのステータスとインポートを管理する

プランのステータスによって、編集中の下書き、現在実施中のプラン、一時停止中のスケジュール、終了済みのトレーニングブロックを明確に区別できます。プランをインポートまたは有効化する前に、ステータスと日程を必ず確認してください。

## ステータスを変更する前に

- 対象のプランを開き、名前、目標、期間、現在のステータスを確認します。
- 別の端末で開いたままのワークアウト編集があれば保存または破棄します。
- プランを終了・削除する前に、完了済み・スキップ済み・紐づけ済みのワークアウトを確認します。
- 意味のある履歴が残っているプランは、削除ではなくステータス変更を優先してください。

## Draft（下書き）

プランの作成、インポート、見直しを行う段階では下書きを使います。下書きのワークアウトは、現在実施中のスケジュールとして扱われることなく自由に編集できます。

有効化する前に、以下を確認してください。

- 目標と対象期間。
- 開始日と週の割り当て。
- 週ごとのリズムと回復日の間隔。
- 種目とワークアウト構造。
- 閾値に依存する目標値。
- 第1週の負荷が現在の体力に対して現実的かどうか。

## 有効化（Activate） [#activate]

プランを有効化すると、ワークアウトがカレンダーの日付や日々の画面に配置されます。その後は完了済みアクティビティを紐づけたり、負荷を比較したり、AIコーチに進捗の振り返りを相談したりできるようになります。

1. プラン詳細ページを開きます。
2. **Start** を選択し、開始日を指定します。
3. **Review with coach** を選択します。
4. カレンダープレビューで日付、ワークアウト内容、回復間隔を確認します。
5. 提案されたスケジュールを確定してプランを開始します。

**確認ポイント：** プランのステータスが Active になり、想定どおりのカレンダー日付にワークアウトが表示されていること。

## 一時停止と再開（Pause / Resume）

体調不良、出張・旅行、故障の確認、計画的な休養など、日々の実行ガイドを一時的に止めつつプランを残したいときに一時停止を使います。

一時停止しても、完了済みアクティビティやワークアウトの紐づけは消えません。再開する際は、残りの日程と負荷量が現状に合っているかを見直し、休んだ分を元の強度で無理に埋め合わせるのではなくプラン側を調整してください。

## 完了（Complete）

意図していたトレーニングブロックが終わったらプランを完了にします。達成率、実績負荷と予想負荷の差、主要アクティビティの紐づけ、次のブロックへ引き継ぐべき学びを振り返ってください。

完了はキャンセルとは異なります。一部のセッションをスキップしていても、意図した区切りに到達した場合は完了として記録します。

## キャンセル（Cancel）

プランを今後実施せず、完了扱いにもしたくない場合はキャンセルにします。将来の判断に役立つ理由がある場合は、プランやコーチング記録に背景を残しておくと有効です。

## 既存の VDOT プランリンクについて

公開 VDOT プランジェネレーターの提供は終了しています。すでにインポートリンクをお持ちの場合は、下書き保存前に日程・ペース目標・スケジュールをプレビュー確認してください。古いリンクの期限が切れている場合は、[トレーニングプランを作成する](/ja/docs/guide/create-training-plan)から現在利用できる作成方法を選んでください。

## 削除（Delete）

削除はステータス変更よりも破壊的な操作です。意味のあるトレーニング履歴を含むプランには完了またはキャンセルを使ってください。削除を使うのは、誤って作成した下書きや不要なテスト用下書きであり、確認ダイアログで対象レコードが明確に特定できる場合のみにしてください。

## ワークアウトの実施ステータス

個々の予定ワークアウトは、実施中プランのフローに沿って完了・スキップなどに更新できます。完了済みアクティビティの紐づけは別の事実記録です。ステータスはプラン上の判断を記録し、紐づけはどの実アクティビティがそのセッションを満たしたかを記録します。

## 同時編集の保護

プランレコードにはバージョン管理された更新機構が使われています。ページを開いた後に別の端末や AI 操作でプランが更新された場合は、再読み込みして最新版を確認してから操作をやり直してください。これにより、古い編集で新しい判断が誤って上書きされるのを防ぎます。

## ステータス変更の確認

- プラン詳細に意図した新しいステータスが表示されている。
- 現在のプラン、「今日」、カレンダーの各画面に同じ実行状態が反映されている。
- 既存のワークアウト完了状態とアクティビティ紐づけがそのまま保たれている。
- 一時停止またはキャンセルによって、履歴を書き換えることなく日々の実行ガイドだけが止まっている。
- 完了にしたプランが、意図的に終了したブロックとして保持されている。
- 新規有効化したプランの第1週が想定どおりのカレンダー日付に配置されている。
- インポートした VDOT 生成プランが、有効化前に独立した下書きとして表示されている。

## トラブルシューティング

- **Start が選択できない：** 必須項目を入力し、期間設定を確認したうえで、他のプラン状態ルールによる制約がないか確認してください。
- **ワークアウトが想定と違う日に表示される：** 有効化の開始日、プラン相対の曜日オフセット、アカウントのタイムゾーン、カレンダー日付を照合してください。
- **意図しないプランが現在のプランとして表示される：** プラン一覧に戻ってステータスを比較し、意図したレコードだけを有効化してください。
- **一時停止や再開が別端末に反映されない：** 別端末の「今日」、カレンダー、プラン詳細を再読み込みしてください。
- **更新時にバージョン競合が報告される：** プランを再読み込みし、最新バージョンに対して判断を適用し直してください。
- **VDOT インポートリンクが失敗する：** リンク全体を漏れなくコピーしているか確認してください。期限切れの場合は、公式テンプレート・手動エディタ・AIコーチのいずれかで新しい下書きを作成してください。
- **削除がブロックされる、またはリスクが高い：** 履歴を残すべきプランはキャンセルまたは完了にしてください。削除は確認画面で特定できる不要な下書きのみに限定してください。
