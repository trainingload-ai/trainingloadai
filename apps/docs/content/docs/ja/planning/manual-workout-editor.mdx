# Trainingload でワークアウトを手動編集する

このページは **Trainingload.ai アプリ内の手動ワークアウトエディタ** に関する製品ドキュメントです。トレーニングプランを開いたあと、種目の選択、持久系ステップまたは筋力セットの追加、プレビュー確認、妥当な下書きの保存までを行う手順を解説します。

独立した公開の**ワークアウトエディタ**や**ワークアウトビルダー**ではありません。ブラウザで自由にステップを下書きしてワークアウト DSL をコピーしたい場合は、[ワークアウトエディタ＆ビルダー](/ja/workout-editor)をご利用ください。アプリ内での保存、筋力ビルダー、プラン日程への配置を行う際にこのページに戻ってください。

## 始める前に

- 手動プラン、または編集可能なプランワークアウトを開きます。
- ゾーン目標やパーセント目標を使う場合は、基準となるアスリート閾値が正しいか確認します。
- 対象セッションが持久系か筋力かをあらかじめ決めます。
- 先に公開ツールで下書きしたい場合は、[ワークアウトエディタでセッションを作成](/ja/workout-editor)してから、ここに貼り付けるか再構成します。

## 1. 種目を選ぶ

手動エディタでは、プラン作成に適した種目に意図的に絞り込んでいます。

- ランニング：Running、Trail Running、Treadmill
- サイクリング：Cycling、Mountain Biking、Indoor Cycling
- スイミング：Pool Swimming、Open Water Swimming
- その他：Strength Training

選択した種目によって利用可能な目標単位が変わり、ワークアウト構造タイプも切り替わります。持久系と筋力を切り替えると互換性のない下書き構造がリセットされるため、詳細なステップを入力する前に種目を決めてください。

## 2. 名前とメモを追加する

名前には「有酸素インターバル」「下半身ストレングス」など短い識別名を付けます。メモには機械構造にすべきでない人向けの指示を書きます。

- フォームや技術のキュー
- 必要な用具のリマインド
- 補給ガイド
- コースや地形の注意点
- 中断または負荷軽減の判断条件

DSL 欄に説明文を書かないでください。ワークアウトのステップは Manual モードまたは Rules モードに入れ、コーチング上の補足はメモに書きます。

## 3. 持久系ワークアウトを作成する

Manual モードでステップまたはリピートモジュールを追加します。各ステップでは次の順に操作します。

1. ウォームアップ、ワーク、リカバリーなどのステップ種別を選びます。
2. 時間または距離を設定します。
3. 目標値は、信頼できる基準値がある場合にのみ設定します。
4. インターバルでは同じワークとリカバリーを何度も複製せず、リピートモジュールを使います。
5. 構造を変えるたびにプレビューチャートを確認します。

有効な持久系構造には少なくとも1つの意味のあるステップが必要です。範囲目標では開始値が終了値以下である必要があります。

## 4. 筋力ワークアウトを作成する

**Strength Training** を選ぶと筋力ビルダーが開きます。[筋力ワークアウト](/ja/docs/planning/strength-workouts)に沿って種目とワークセットを追加してください。テキスト入力を使う場合は[筋力ワークアウト DSL](/ja/docs/planning/strength-workout-dsl)を参照してください。

## 5. 必要に応じて Rules モードを使う

Rules モードではサポートされたワークアウト DSL を入力できます。簡潔な記述や再利用しやすいテキスト作成に便利ですが、自由記述のコーチメモ欄ではありません。

Rules モードで保存する前に次を確認してください。

- 対応する DSL 式につき1指示を保つ。
- 自然言語の説明はメモに書く。
- 入力を検証し、描画された構造を確認する。
- 対応する構文は[持久系ワークアウト DSL](/ja/docs/planning/workout-dsl)または[筋力ワークアウト DSL](/ja/docs/planning/strength-workout-dsl)を確認する。
- 同じ DSL を先に[公開ワークアウトエディタで下書き](/ja/workout-editor)してから貼り付けることもできます。

## 6. 保存する

**Save Draft** を選択します。Trainingload.ai が内容を検証してからプラン下書きへ追加します。

## 保存したワークアウトを確認する

次の点を確認してください。

- 種目ラベルが正しい。
- プレビューが意図したワーク／リカバリー順、または筋力セット構成と一致している。
- メモと構造が分離されている。
- 保存したワークアウトが正しい週・日・セッション順に表示されている。
- 十分な情報がある場合にのみ予想負荷が表示されている。

## トラブルシューティング

- **種目一覧に想定外の項目がない／少ない：** 手動プランのワークアウトエディタを開いているか確認してください。作成時の選択肢は上記の9種目に限定されています（アクティビティ分類画面にはより広い一覧があります）。
- **種目を切り替えたら下書きが消えた：** 持久系と筋力の構造は互換性がありません。最初に種目を選び、切り替える前に再利用したいメモやルールをコピーしてください。
- **持久系プレビューが空になる：** 意味のあるステップを1つ以上追加し、時間・距離および目標値が有効であることを確認してください。
- **範囲目標が拒否される：** 低い値を先、高い値を後に指定し、選択種目に対応した単位になっているか確認してください。
- **「Enter a name for every exercise」と表示される：** すべての筋力種目に名前を入力してください。プレースホルダー文字列は保存対象になりません。
- **筋力種目が保存できない：** すべての種目に少なくとも1つのセットグループと1つのワークセットを追加してください。
- **Rules のエラーが英語のまま表示される：** 生のサーバーメッセージをメモ欄にコピーせず、表示されたメッセージ、選択種目、エラー行の DSL を控えてサポートへ連絡してください。
- **保存したワークアウトが別の日付に表示される：** プラン開始日、週・日のオフセット、セッション順、アカウントのタイムゾーンを確認してください。

## よくある質問

### 手動ワークアウトエディタとは何ですか？

Trainingload 内で予定ワークアウト1件を編集するアプリ内画面です。種目を選び、持久系ステップや筋力種目を追加し、コーチメモを添えてプレビュー確認のうえ、指定の週・日に保存できます。公開の[ワークアウトエディタ＆ビルダー](/ja/workout-editor)は別途提供されている下書きツールです。

### Trainingload でワークアウトを手動編集するにはどうすればよいですか？

編集可能なプランワークアウトを開き、先に種目を選んでからステップまたはリピートモジュールを追加します。時間または距離を設定し、閾値が信頼できる場合のみ目標を付け、インターバルには同じペアを複製するのではなくリピートモジュールを使ってください。

### アプリ内エディタで筋力セッションも作れますか？

はい。**Strength Training** を選ぶと筋力ビルダーが開きます。名前を付けた種目と、各種目につき少なくとも1つのワークセットを追加してください。テキスト入力を行う場合は[筋力ワークアウト DSL](/ja/docs/planning/strength-workout-dsl)を使用します。

### Manual モードと Rules モードはどう使い分けますか？

画面上でクリックしながらステップを組み立てたいときは Manual モード、簡潔で再利用しやすい DSL で書きたいときは Rules モードを使います。DSL 欄にコーチングの説明文を書かず、メモ欄に分けてください。詳しくは[持久系ワークアウト DSL](/ja/docs/planning/workout-dsl)を参照してください。

### 種目を切り替えると下書きがリセットされるのはなぜですか？

持久系と筋力ではワークアウト構造に互換性がないためです。詳細なステップを入力する前に種目を確定し、切り替える際は再利用するメモやルールをあらかじめコピーしておいてください。

- スケジュール全体が整ったら[プランのステータスとインポートを管理する](/ja/docs/planning/plan-lifecycle)へ進み、プランを有効化します。

- 筋力セッションのビジュアル編集は[筋力ワークアウト](/ja/docs/planning/strength-workouts)を参照します。
- セッション完了後は、[AIコーチの振り返りでトレーニング負荷を安全に調整](/ja/ai-training-plan)します。
