# Trainingload でワークアウトを手動編集する

これは **Trainingload.ai アプリ内の手動ワークアウトエディタ** の製品ドキュメントです。プランの 1 セッションを開き、種目を選び、持久系ステップか筋力セットを追加し、プレビューして妥当な下書きを保存する手順です。

公開の**ワークアウトエディタ**や**ワークアウトビルダー**ではありません。ブラウザで下書きして DSL をコピーしたい場合は、[ワークアウトエディタ＆構造化ビルダー](/ja/workout-editor) を使ってください。アプリ内の保存、筋力ビルダー、日付配置が必要になったらこのページに戻ります。

## 始める前に

- 手動プラン、または編集できるプランワークアウトを開く。
- ゾーンやパーセント目標を使うなら、閾値が信頼できるか確認する。
- 持久系か筋力かを先に決める。
- 先に公開ツールで下書きするなら、[ワークアウトエディタで構造化セッションを下書きする](/ja/workout-editor)。

## 1. 種目を選ぶ

手動エディタの種目は計画用に絞っています。

- ラン：Running、Trail Running、Treadmill。
- バイク：Cycling、Mountain Biking、Indoor Cycling。
- スイム：Pool Swimming、Open Water Swimming。
- その他：Strength Training。

種目を変えると使える目標単位と構造タイプが変わります。持久系と筋力を切り替えると互換のない下書きはリセットされるので、詳細を入れる前に種目を決めてください。

## 2. 名前とメモ

名前は「有酸素インターバル」「下半身筋力」など短い識別に使います。メモは機械構造にしない人向けの指示です。

- 技術のキュー。
- 用具。
- 補給。
- ルートや地形。
- 中止や負荷を動かす条件。

DSL 欄に文章を書かないでください。ステップは Manual または Rules、説明はメモです。

## 3. 持久系ワークアウト

手動モードでステップまたはリピートを追加します。

1. ウォームアップ、ワーク、リカバリーなど種類を選ぶ。
2. 時間または距離を入れる。
3. 信頼できる基準値があるときだけ目標を付ける。
4. インターバルは同じ組を何度も複製せず、リピートを使う。
5. 構造が変わるたびにチャートを見る。

意味のあるステップが 1 つ以上必要です。範囲目標は開始値が終了値以下である必要があります。

## 4. 筋力ワークアウト

**Strength Training** を選ぶと筋力ビルダーが開きます。種目名を入れ、各種目に少なくとも 1 つのワークセットを追加します。テキスト入力が必要なら、対応する DSL を Rules に書いて検証してください。

## 5. Rulesモード

Rules は対応するワークアウト DSL を受け付けます。短い繰り返し入力向きで、自由記述のコーチメモ欄ではありません。

保存前に、対応する DSL を 1 行 1 指示にし、自然文はメモへ移し、検証して描画を確認します。[持久系ワークアウト DSL](/ja/docs/planning/workout-dsl) を読んでください。同じ DSL を先に [公開ワークアウトエディタ](/ja/workout-editor) で下書きしてから貼ることもできます。

## 6. 保存

**Save Draft** を選ぶと、Trainingload.ai が検証してからプラン下書きに追加します。

## よくある質問

### 手動ワークアウトエディタとは？

Trainingload でプラン上の 1 セッションを編集するアプリ内画面です。種目を選び、持久系ステップか筋力種目を追加し、メモを付け、プレビューして、週と日から保存します。公開の [ワークアウトエディタ＆ビルダー](/ja/workout-editor) は別の下書きツールです。

### Trainingload でワークアウトを手動編集するには？

編集できるプランワークアウトを開き、先に種目を選び、ステップかリピートを追加します。時間または距離を入れ、閾値が確かなときだけ目標を付けます。

### 筋力も作れますか？

はい。**Strength Training** を選び、種目名を入れ、各種目に少なくとも 1 つのワークセットを追加します。

### 種目を変えたら下書きが消えた理由は？

持久系と筋力の構造は互換がありません。詳細の前に種目を決め、切り替える前に再利用するメモやルールをコピーしてください。
