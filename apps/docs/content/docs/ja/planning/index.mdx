# トレーニングプランとワークアウト

Trainingload.ai では、トレーニングプランを静的な PDF ではなく生きたワークスペースとして扱います。プランには日付指定または相対日程のワークアウトが含まれ、各ワークアウトには機械可読な構造、人向けのメモ、予想トレーニング負荷、実施ステータス、完了済みアクティビティへのリンクを持たせることができます。

## プランニングのモデル

## プランのステータス

- **Draft（下書き）** — 作成・編集中のプランです。実施前の確認に使います。
- **Active（実施中）** — 開始日が設定され、日々の実行コンテキストとなる現在のプランです。
- **Paused（一時停止）** — プランと履歴を保持したまま、一時的に停止している状態です。
- **Completed（完了）** — 意図どおりに終了したプランです。
- **Canceled（キャンセル）** — 予定どおりの完了に至らず終了したプランです。

すでに完了済みアクティビティが紐づいているプランのステータスを変更する前に、[プランのステータスとインポートを管理する](/ja/docs/planning/plan-lifecycle)を確認してください。

## ワークアウト構造の種類

### 持久系（Endurance）

持久系ワークアウトは、ウォームアップ、ワーク、リカバリー、リピートなどのステップで構成され、時間または距離の指定に加えて、ゾーン、ペース、速度、パワー、ケイデンス、心拍数といった任意の目標を設定できます。

アプリ内のビジュアル編集には[手動ワークアウトエディタガイド](/ja/docs/planning/manual-workout-editor)、公開ツールで下書きするには[ワークアウトエディタ＆ビルダー](/ja/workout-editor)、簡潔なテキスト記法を使うには[持久系ワークアウト DSL](/ja/docs/planning/workout-dsl)を参照してください。

### 筋力（Strength）

筋力ワークアウトは種目（エクササイズ）とセットグループで構成されます。回数または時間で処方でき、対応する項目ではオープン負荷、固定重量、1RM 比率、自重、努力度（RPE / RIR）、レスト時間を指定できます。

ビジュアル操作には[筋力ワークアウト](/ja/docs/planning/strength-workouts)、Rules モードでのテキスト記述には[筋力ワークアウト DSL](/ja/docs/planning/strength-workout-dsl)を参照してください。

## 予想負荷と実績負荷

予想負荷（Expected load）は、ワークアウト構造・閾値・目標情報から十分な根拠が得られる場合にのみ算出されます。実績負荷（Actual load）は完了済みアクティビティと設定済みの負荷ソース優先順位から算出されます。

この2つの数値は異なる問いに答えます。

- **予想負荷：** 「このプランではどれだけの負荷を意図していたか？」
- **実績負荷：** 「実際に完了したセッションでどれだけの負荷が生じたか？」

予想負荷を表示させるためだけに根拠のない閾値や目標を入力しないでください。不確かな精度より、明示的に未算出とするほうが安全です。
