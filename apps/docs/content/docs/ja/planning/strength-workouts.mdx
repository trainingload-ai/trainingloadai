# 筋力ワークアウト

筋力ワークアウトでは、時間や距離をベースにした持久系ステップではなく、種目、セット数、回数、負荷、努力度、レスト時間の設計が必要です。Trainingload.ai は専用の筋力エディタを備えており、予定した処方内容と完了済みの筋力アクティビティを並べて確認できます。

## 始める前に

- プランの下書き、または編集可能な今後のワークアウトを開きます。完了済みアクティビティを新しい処方として書き換えないでください。
- 種目で **Strength Training** を選び、筋力エディタを開きます。
- **Manual** モードと **Rules** モードのどちらを使うか決めます。どちらも同じワークアウト構造として保存されます。
- 種目名、器具、信頼できる重量または 1RM の値、想定する RPE / RIR を用意します。数値の負荷が決まっていない場合は **Open Load** を選んでください。

## 2. セッション全体の目安を設定する

予定時間とセッション RPE は、プラン管理上必要な場合にのみ設定します。セッション RPE はワークアウト全体の想定きつさを表すものであり、各セットの努力度目標とは別です。

## 3. 種目を追加する

すべての種目に空でない名前を付ける必要があります。予定と完了済みセッションを後から比較しやすいよう、一貫性のあるわかりやすい種目名を使ってください。器具（Equipment）は任意であり、種目名を繰り返すのではなく必要な器具を記載します。

例：

- バックスクワット — Barbell
- ルーマニアンデッドリフト — Barbell
- 懸垂（プルアップ） — Bodyweight
- スプリットスクワット — Dumbbells

## 4. セットグループを追加する

セットグループは、同じ処方で繰り返す一連のセットをまとめたものです。

- **Warm-up（ウォームアップ）** — 準備セット（任意）。
- **Work（ワーク）** — 主となるトレーニング処方を定義するセット（すべての種目で必須）。

回数ベースの種目には回数（レップ）、アイソメトリックや時間制の種目には時間を選びます。回数レンジを指定する場合は、最小値が最大値以下になるようにしてください。

## 5. 負荷（Load）を選ぶ

- **Open load（オープン負荷）** — 数値の負荷を指定しません。使用器具や現在の筋力が不明なときに使います。
- **Fixed weight（固定重量）** — 対応する単位付きの数値重量。
- **Percent of 1RM（1RM 比率）** — 対象種目の現在有効な 1RM が分かっている場合にのみ使用します。
- **Bodyweight（自重）** — アスリート自身の体重。
- **Bodyweight offset（自重＋荷重／補助）** — 対応している場合、自重に対して外部重量を加減算します。

AI が生成する筋力プランでは、ツールで裏付けられた履歴や既知の 1RM がないにもかかわらず kg・lb・1RM 比率を推測して埋め込むべきではありません。オープン負荷と RPE / RIR の目安を組み合わせるのが安全な既定値です。

## 6. 努力度（Effort）とレストを追加する

主観的なきつさを示すには RPE、限界までの余力回数を示すには RIR を使います。意図的な狙いがない限り、高すぎる重量と極端に低い努力度目標を組み合わせるような矛盾した指定は避けてください。

レスト時間はセットグループごとに保存されます。すべての種目を同じレスト時間に統一するのではなく、狙う質を保つのに十分な時間を設定してください。

## 7. 同じワークアウトを Strength DSL で記述する

**Rules** モードでは、筋力セッションを次のように記述できます。

```text
duration 50m
session rpe 6

exercise "Back Squat" equipment barbell {
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 80kg rpe 7 rest 3m
}

exercise "Pull Up" equipment bodyweight {
  work 3x8 bodyweight rir 2 rest 90s
}
```

完全な文法、多言語の種目名、負荷の書き方、検証フロー、エラー対処については[筋力ワークアウト DSL](/ja/docs/planning/strength-workout-dsl)を参照してください。Strength DSL は静的なセッション処方であり、`if/else`、週次漸進、ディロードスクリプト、入れ子ブロック、任意の実行スクリプトには対応していません。

## ワークアウトを確認する

保存前に次を確認してください。

- 少なくとも1つの種目が存在する。
- すべての種目に名前が入っている。
- すべての種目に少なくとも1つのセットグループがある。
- すべての種目に少なくとも1つのワークセットグループが含まれている。
- セット数、回数、秒数、努力度、負荷がサポート範囲内に収まっている。
- プレビューが意図したセッション内容と一致している。

保存後はワークアウトを開き直し、ビジュアルビルダーまたは正規化後の Strength DSL に同じ構造が表示されていることを確認してください。プレビュー概要の種目数とワークセット数も意図どおりになっているか確認します。

## トラブルシューティング

- **「Enter a name for every exercise」と表示される：** DSL では空でない引用符付きの種目名を入れ、ビジュアルビルダーでは Exercise 欄を入力してください。
- **「Each exercise needs at least one set group」と表示される：** 種目ブロックを閉じる前に、ウォームアップまたはワークのセットグループを追加してください。
- **「Each exercise needs at least one work set」と表示される：** ウォームアップのみの種目は無効です。少なくとも1行 `work` を追加してください。
- **回数レンジがエラーになる：** `3x8-12` のように低い値を先に書いてください。
- **負荷または努力度の検証に失敗する：** サポートされた負荷形式を使い、RPE と RIR はどちらか一方のみを指定してください。
- **閉じ波括弧が拒否される：** 各種目は1回だけ閉じ、種目ブロックを入れ子にしないでください。
- **筋力から持久系へ切り替えるとエディタが空になる：** 構造が意図的に異なるためです。種目を切り替える前に必要なテキストを保存またはコピーしてください。

## 完了済みの筋力セッション

筋力アクティビティでは、種目、セット完了状況、セッション全体の完了状態を記録できます。ワークアウト後は筋力アクティビティ詳細を開き、種目名、完了セット、負荷、回数・時間、セッション全体の文脈を確認してから振り返りに活用してください。
