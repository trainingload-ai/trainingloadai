# Ressources et prompts MCP

Cette page est générée à partir du catalogue de contenu MCP du serveur. Ne la modifiez pas directement ; exécutez `pnpm --dir apps/server mcp:reference`.

Les ressources fournissent aux clients IA des repères stables sur les métriques, les limites de sécurité et les capacités autorisées, sans lire de données athlète supplémentaires. Les prompts génèrent des modèles de questions structurés ; les données réelles proviennent toujours des outils encadrés par les portées (scopes) OAuth.

## Ressources

| URI | Nom | Objectif |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | Guide d’interprétation des métriques TrainingLoad | Définitions et limites d’interprétation pour la charge d’entraînement, l’ATL, la CTL, la TSB, les plages de disponibilité (readiness), la couverture et les données manquantes. |
| `trainingload://guide/privacy-and-safety` | Guide de confidentialité et de sécurité TrainingLoad | Limites en lecture seule, traitement du texte non fiable, cadre des données de santé et catégories de données exclues. |
| `trainingload://catalog/capabilities` | Catalogue des capacités TrainingLoad autorisées | Noms des outils en lecture seule actuellement autorisés, descriptions et portées (scopes) OAuth. |

## Prompts

## `weekly-training-review`

Construire un bilan étayé par les données sur la charge d’entraînement récente, la régularité, les activités réalisées et les séances planifiées à venir.

<details>
<summary>Schéma JSON des arguments</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "days": {
      "default": "7",
      "type": "string",
      "enum": [
        "7",
        "14",
        "28"
      ]
    },
    "sportType": {
      "type": "string",
      "enum": [
        "RUN",
        "CYCLING",
        "SWIM"
      ]
    }
  },
  "required": [
    "days"
  ],
  "additionalProperties": false
}
```

</details>

## `race-preparation-check`

Examiner une compétition, la réalisation du plan d’entraînement, la charge récente et les séances planifiées à venir sans formuler de conclusion médicale.

<details>
<summary>Schéma JSON des arguments</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "eventId": {
      "type": "string",
      "minLength": 1,
      "maxLength": 128
    },
    "horizonDays": {
      "default": "28",
      "type": "string",
      "enum": [
        "14",
        "28",
        "56"
      ]
    }
  },
  "required": [
    "horizonDays"
  ],
  "additionalProperties": false
}
```

</details>
