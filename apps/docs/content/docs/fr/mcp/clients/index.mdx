# Guides par client

Choisissez le client IA que vous utilisez. Chaque guide se connecte au même point de terminaison via OAuth TrainingLoad et ne nécessite aucune clé API.

- [ChatGPT](/fr/docs/mcp/clients/chatgpt)
- [Codex](/fr/docs/mcp/clients/codex)
- [Claude Code](/fr/docs/mcp/clients/claude-code)
- [Claude Desktop](/fr/docs/mcp/clients/claude-desktop)
- [Cursor](/fr/docs/mcp/clients/cursor)
- [VS Code](/fr/docs/mcp/clients/vscode)
- [opencode](/fr/docs/mcp/clients/opencode)

Une fois la configuration terminée, suivez la [vérification commune à chaque client](/fr/docs/mcp/connect#vérification-pour-chaque-client) afin de confirmer OAuth, la découverte des outils et le premier appel d’outil.
