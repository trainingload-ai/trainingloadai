# Connecter opencode

Ajoutez le serveur distant dans `opencode.json` :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "trainingload": {
      "type": "remote",
      "url": "https://api.trainingload.ai/mcp",
      "enabled": true
    }
  }
}
```

Exécutez ensuite :

```bash
opencode mcp auth trainingload
opencode mcp list
```

Après l’autorisation OAuth, demandez : « Vérifie mes connexions aux plateformes d’entraînement tierces et explique quels sens de synchronisation sont actuellement disponibles. » Cette requête doit appeler `get_integration_status`.

Si l’authentification ne s’ouvre pas automatiquement, relancez `opencode mcp auth trainingload`. Ne placez jamais de jeton d’accès dans le fichier de configuration.

[Guide MCP officiel opencode](https://opencode.ai/docs/mcp-servers/)
