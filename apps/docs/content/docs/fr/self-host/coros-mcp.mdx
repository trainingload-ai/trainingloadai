# Connexion COROS

L’auto-hébergement ne prend pas actuellement en charge de connexion directe à COROS. Exportez un fichier d’activité pris en charge (FIT, TCX ou GPX) depuis la plateforme source, puis [téléversez-le dans Trainingload.ai](/fr/docs/guide/upload-activity-files).

Les connexions personnelles prises en charge en auto-hébergement sont :

- [Intervals.icu](/fr/docs/self-host/configuration)
- [Garmin Personal API](/fr/docs/self-host/garmin-personal-api)

Pour la version Cloud, consultez le [guide de connexion des plateformes](/fr/docs/guide/connect-third-party-platforms).
