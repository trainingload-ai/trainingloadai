# Zones de puissance

Les zones de puissance découpent l’échelle continue de puissance en « plages » d’entraînement exploitables. Elles offrent un langage cohérent (Z1–Z7 / Z1–Z5) pour aligner chaque séance sur les filières énergétiques visées et les scénarios de course.

## Puissance de référence : FTP

Les pourcentages de zones reposent sur une valeur de référence :

- **FTP** : voir [Functional Threshold Power (FTP)](./functional-threshold-power)
- **CP** : voir [Puissance critique (CP)](./critical-power), en particulier pour les modèles de puissance en course à pied comme Stryd.

Si vous connaissez déjà votre FTP ou votre CP, utilisez le [calculateur de zones de puissance à partir de la FTP ou de la CP](/fr/power-zones-calculator) pour calculer vos bornes.

## Comment lire les bornes de zones

Toutes les plages en « % FTP » ci-dessous sont exprimées sous forme d’intervalles **sans chevauchement**. Par exemple :

- Z1 : ≤ 55 %
- Z2 : 56 %–75 %

Lorsqu’un pourcentage tombe exactement sur une borne (par exemple 128 %), il faut l’affecter de façon constante. Trainingload.ai attribue généralement la borne à la **zone supérieure** (par ex. 128 % → Z7) afin d’éviter toute ambiguïté.

## 1. Joe Friel : modèle cyclisme à 7 zones

Le modèle de Joe Friel compte 7 zones allant de la récupération active au sprint neuromusculaire. Très utilisé en cyclisme, il peut aussi s’appliquer à la course à pied si la référence de seuil est adaptée.

| Zone | Nom | Anglais | % FTP | Usage typique |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | Récupération active | Active Recovery | ≤ 55 % | Vélo très souple / footing de récupération ; favorise la récupération. |
| **Z2** | Endurance | Endurance | 56 %–75 % | Sorties longues / base aérobie ; développe la capacité aérobie et l’oxydation des lipides. |
| **Z3** | Tempo | Tempo | 76 %–90 % | Travail soutenu régulier ; renforce la durabilité et l’économie de glycogène. |
| **Z4** | Seuil | Threshold | 91 %–105 % | Travail au seuil ; élève la puissance soutenable et la tenue au seuil. |
| **Z5** | VO2max | VO2 Max | 106 %–120 % | Intervalles VO2 ; relève le plafond aérobie à haute intensité. |
| **Z6** | Anaérobie | Anaerobic | 121 %–150 % | Intervalles anaérobies ; améliore la tolérance au lactate et la répétabilité. |
| **Z7** | Neuromusculaire | Neuromuscular | ≥ 151 % | Sprints courts / démarrages ; recrutement neuromusculaire. |

> Source : [Joe Friel](https://joefrieltraining.com/a-quick-guide-to-setting-zones/)

## 2. Jim Vance : modèle course à pied à 7 zones

Le modèle de Jim Vance comporte également 7 zones, mais découpe plus finement les basses intensités. Z1–Z3 correspondent bien au découpage quotidien « marche / facile / régulier » et aident à affiner le contrôle de l’endurance et du tempo.

| Zone | Nom | Anglais | % FTP | Usage typique |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | Récupération / marche | Recovery/Walking | ≤ 80 % | Récupération, échauffement, très facile. |
| **Z2** | Endurance | Endurance | 81 %–88 % | Plage principale d’endurance aérobie ; soutenable. |
| **Z3** | Tempo | Tempo | 89 %–95 % | Intensité régulière plus appuyée, proche du seuil. |
| **Z4** | Seuil | Threshold | 96 %–105 % | Travail au seuil et durabilité. |
| **Z5** | Haute intensité | High Intensity | 106 %–115 % | Intervalles à haute intensité (haut du spectre aérobie). |
| **Z6** | VO2 | VO2 | 116 %–128 % | Intervalles VO2 (la borne 128 % est souvent affectée à Z7). |
| **Z7** | Capacité anaérobie | Anaerobic Capacity | ≥ 128 % | Répétitions courtes axées sur la capacité anaérobie et l’explosivité. |

> Source : [Jim Vance, *Run with Power*](https://www.velopress.com/books/run-with-power/)

## 3. Stryd : modèle course à pied à 5 zones

Le modèle Stryd regroupe le haut du spectre dans une structure plus simple à 5 zones pour la course à pied. Il prend généralement la **CP** comme référence, mais la correspondance en pourcentages reste identique si vous utilisez la FTP.

| Zone | Nom | Anglais | % FTP | Usage typique |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | Facile | Easy | ≤ 80 % | Footings de récupération et sorties faciles. |
| **Z2** | Modéré | Moderate | 81 %–90 % | Sorties d’endurance régulières ; intensité principale des sorties longues. |
| **Z3** | Seuil | Threshold | 91 %–100 % | Plage centrale pour le travail au seuil et au tempo. |
| **Z4** | Intervalle | Interval | 101 %–115 % | Intervalles VO2 / haute intensité. |
| **Z5** | Répétition | Repetition | ≥ 116 % | Répétitions courtes, sprints, accélérations anaérobies. |

>
> Source : [Stryd](https://blog.stryd.com/2018/02/21/nicks-training-manual-lesson-3-if-you-dont-follow-a-plan-you-can-easily-trash-your-legs-for-weeks/)

## Comment calculer vos bornes de zones

Soit $B$ votre puissance de référence (FTP ou CP). Pour calculer une borne, multipliez le pourcentage par $B$ :

```text
W = B * (pct / 100)
```

### Exemple : FRIEL Z2 (56 %–75 %)

Supposons $B = 250 W$ :

```text
Z2_min = 250 * 0.56 = 140 W
Z2_max = 250 * 0.75 = 187.5 W
```

Votre Z2 se situe donc autour de **140 W – 188 W** (l’affichage réel peut être arrondi au watt près).

## Conseils Trainingload.ai

Trainingload.ai utilise les zones de puissance pour comparer l’intensité prévue à l’intensité réalisée :

1. **Définissez vos seuils par discipline** : la puissance en course à pied et en cyclisme diffère. Maintenez vos CP/FTP séparément et choisissez le modèle adapté.
2. **Mettez-les régulièrement à jour** : la FTP et la CP évoluent avec l’entraînement ; refaites un test périodiquement ou utilisez l’estimation automatique pour garder des zones pertinentes.
3. **Considérez les zones comme des plages cibles** : les bornes ne sont pas des murs. L’essentiel est de maintenir la majorité du travail dans le stimulus d’entraînement visé.
4. **Analysez les séances réalisées** : après une séance, la répartition par zones montre rapidement si une journée facile a dérivé trop haut ou si une séance clé d’intervalles a manqué la plage visée.
