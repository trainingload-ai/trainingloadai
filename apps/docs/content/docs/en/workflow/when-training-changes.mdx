# When Training Does Not Match the Plan

## Outcome

Preserve an honest plan-versus-actual history and make only the smallest justified change to future training.

## Choose the matching case

| What happened | Record it as | Do not do |
| --- | --- | --- |
| Workout skipped | Keep the planned workout skipped or incomplete | Upload a fake zero-duration activity |
| Workout shortened | Link the real shorter activity to the planned workout | Edit the completed data to match the target |
| Workout replaced | Keep the planned and completed session types visible | Rename an unrelated activity to hide the change |
| Unplanned workout | Keep the activity unlinked unless it replaced a specific session | Force it onto the nearest workout by date |
| Workout moved | Move the planned session only if that reflects the real decision | Shift the completed activity timestamp |

## Review before adjusting

1. Open the relevant day in [Calendar](/docs/guide/calendar).
2. Confirm activity source and processing state in [Activities](/docs/guide/activity-feed-search).
3. Review load and sensor coverage in [Activity detail](/docs/guide/activity-detail).
4. Compare the change with recent load, sleep or recovery context, and the next key session.
5. If an adjustment is justified, change one primary variable first: timing, duration, or intensity.

## Use AI Coach precisely

Ask a decision question such as: “Yesterday's easy run was shortened from 45 to 25 minutes because of poor sleep. Should Saturday's long run change?” Avoid prompts that ask the coach to rewrite the entire plan without constraints.

## Verify the result

The calendar should still show what was planned, what was completed, why they differ, and which future workout changed. The original activity evidence must remain unchanged.
