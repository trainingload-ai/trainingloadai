# First End-to-End Training Cycle

## Outcome

Finish with one trustworthy athlete profile, one Ready activity, one active or reviewed plan, and a clear next-workout decision.

## Before you begin

- Use synthetic or your own training data; never share account tokens or precise home locations.
- Choose one primary import path before enabling multiple two-way integrations.
- Have a recent FIT, TCX, or GPX file available if no platform connection is ready.

## 1. Calibrate the athlete profile

Follow [Profile, thresholds, and zones](/docs/guide/profile-thresholds-zones). Confirm time zone, units, sport-specific thresholds, and the preferred load source.

## 2. Bring in one completed activity

Use [Connect data](/docs/guide/connect-data) for continuous synchronization or [Upload activity files](/docs/guide/upload-activity-files) for a controlled first import.

Wait until the activity is Ready. A visible activity card alone does not prove that charts and load have finished processing.

## 3. Review the activity evidence

Open [Activity detail](/docs/guide/activity-detail). Check source, start time, duration, distance, heart rate or power availability, laps, and load. Missing sensor data should remain missing rather than be inferred as measured data.

## 4. Create or select the plan

Use [Create a training plan](/docs/guide/create-training-plan), inspect the schedule, and activate it only after the goal, dates, sports, and workload look plausible.

## 5. Reconcile plan and actual

Open [Calendar](/docs/guide/calendar). Link the completed activity to the correct planned workout when they represent the same session. Leave unrelated or unplanned activities separate.

## 6. Decide what happens next

Open [Today and current state](/docs/guide/today-and-current-state), then ask [AI Coach](/docs/guide/ai-coach) one focused question. Include the decision, time range, constraints, and evidence you want checked.

## Verify the cycle

- The athlete profile uses the intended units, time zone, and thresholds.
- One activity is Ready and exposes the data that its source actually supplied.
- The current plan and today's workout are visible.
- Plan and actual are linked only when they represent the same session.
- Any future change is explicit and remains reviewable.

Next, run the [weekly review](/docs/workflow/weekly-review).
