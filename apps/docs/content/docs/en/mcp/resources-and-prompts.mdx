# MCP resources and prompts

This page is generated from the server MCP content catalog. Do not edit it directly; run `pnpm --dir apps/server mcp:reference`.

Resources give clients stable metric, safety, and authorized-capability guidance without reading additional athlete data. Prompts produce structured question templates; actual data still comes from OAuth-scoped tools.

## Resources

| URI | Name | Purpose |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | TrainingLoad metric interpretation guide | Definitions and interpretation boundaries for load, ATL, CTL, TSB, readiness bands, coverage, and missing data. |
| `trainingload://guide/privacy-and-safety` | TrainingLoad privacy and safety guide | Read-only boundaries, untrusted-text handling, health limits, and excluded data classes. |
| `trainingload://catalog/capabilities` | Authorized TrainingLoad capability catalog | The currently authorized read-only tool names, descriptions, and OAuth scopes. |
