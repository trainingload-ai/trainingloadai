# MCP changelog

## 2026-10-15 — Complete read-only training surface

- Expanded the catalog from 17 to 24 tools.
- Added aggregate activity statistics and training-consistency analysis with explicit coverage and truncation semantics.
- Added privacy-reduced activity zone and lap/split detail.
- Added training-plan discovery, plan-level completion/load summary, and single-competition detail.
- Added three native MCP resources and three reusable prompts, with generated bilingual reference documentation and release-gate validation.

## 2026-10-15 — Advanced read-only analysis and complete onboarding (earlier milestone)

- Expanded the catalog from 9 to 17 tools.
- Added period comparison, sport load breakdown, and training-readiness indicators.
- Added fitness trends, training zones, and personal bests.
- Added status-based plan adherence and integration/sync readiness.
- Added how-it-works, use-case, and seven dedicated client guides.
- Expanded the feature page from OAuth connection through transparent calls to evidence-backed answers.

## 2026-10-14 — Initial read-only product surface

- Added nine read-only training, activity, plan, competition, profile, and health capabilities.
- Added aggregate-first server instructions and Zod-backed input/output contracts.
- Added OAuth scope filtering, separate `health:read` authorization, revocation visibility, limits, audit records, and OpenTelemetry instrumentation.
- Added stateless MCP SDK v2 transport with `2025-11-25` and `2026-07-28` compatibility.
- Added generated tool reference and client connection guides.

There are no write tools in this release.
