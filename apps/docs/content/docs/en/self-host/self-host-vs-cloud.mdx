# Self-hosted vs Cloud

Choose Cloud to start using Trainingload.ai directly. Choose self-hosting if you want to keep your training data on your own computer or server and are willing to install and maintain the application.

## Quick comparison

| What matters to you | Cloud | Self-hosted |
| --- | --- | --- |
| Getting started | Open the app and create an account | Download a release bundle and follow the installation guide on your own device |
| Where your data lives | Trainingload.ai's Cloud service | Your device, including activities, plans, and uploaded files |
| Importing training | Connect a supported training platform or upload activity files | Upload activity files, or connect Intervals.icu and Garmin Personal API with your own keys |
| Using AI Coach | Use the AI allowance included with your account plan | Off by default; configure your own AI service and pay that provider |
| Accounts | Use your Cloud account | One person per self-hosted instance |
| Backups and recovery | Trainingload.ai maintains the Cloud service | You save backups and restore them when needed |
| Software updates | Trainingload.ai updates the service | You follow the upgrade guide to install a new release |

## Which fits your needs?

**Choose Cloud** if you want to spend your time training and reviewing workouts, without installing software, running updates, or managing backups yourself.

**Choose self-hosting** if you want to store your own training data, can maintain a device to run the application, and will keep it updated and backed up. Self-hosting is for personal use; one instance cannot contain multiple users.

## Check how you will import training

Self-hosting currently supports:

- uploading **FIT, GPX, and TCX** activity files;
- connecting **Intervals.icu** with a personal API key;
- connecting **Garmin Personal API** with a personal API key.

If you rely on a particular training platform, check [Connect data](/docs/guide/connect-data) and the [self-hosted connection settings](/docs/self-host/configuration#connect-intervalsicu) first. Cloud and self-hosting offer different connection methods. If another platform can export a supported activity file, you can upload that file instead.

**Trainingload.ai does not currently support an Apple Watch app.**

## How AI works and what it costs

AI is off by default. You can use non-AI features without configuring it. To use AI Coach, choose a provider in settings and enter your own API key; see [Configure AI](/docs/self-host/configuration#configure-ai-in-the-client).

Self-hosting does not use Trainingload.ai Cloud memberships or AI credits. Your chosen AI provider charges you for its API usage.

When you use an external AI service, the training information needed for that request is sent to that provider. Installing the application locally does not make an external AI service run locally. Syncing with a training platform also needs an internet connection.

## What you will need to maintain

- Keep enough free space on the device and run the application when you need it.
- Back up before updating, and keep a copy away from the device running the application.
- Check that your backups can be restored so you have a usable copy if the device fails.
- Follow the [management and upgrade guide](/docs/self-host/operations) to update the application.

## Next step

For Cloud, [open the app](https://app.trainingload.ai/en) and follow [Getting started](/docs/guide/getting-started) to import your first activity.

For self-hosting, start with the [installation guide](/docs/self-host/installation). Installation, backup, and upgrade steps are covered in their own guides.
