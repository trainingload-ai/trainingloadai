# COROS connection

Self-hosting does not currently support a direct COROS connection. Export a supported FIT, TCX, or GPX activity file from the source platform, then [upload it to Trainingload.ai](/docs/guide/upload-activity-files).

Supported personal connections for self-hosting are:

- [Intervals.icu](/docs/self-host/configuration)
- [Garmin Personal API](/docs/self-host/garmin-personal-api)

For Cloud, see the [platform connection guide](/docs/guide/connect-third-party-platforms).
