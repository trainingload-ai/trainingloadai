# COROS MCP

Self-host **does not enable** COROS MCP. There is no supported Self-host setup path for COROS authorization, activity import, or workout delivery through MCP.

Supported personal connections on Self-host:

- [Intervals.icu](/docs/self-host/configuration)
- [Garmin Personal API](/docs/self-host/garmin-personal-api)

The managed/closed-source product documents its own integrations separately.
