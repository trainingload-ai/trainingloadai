# Garmin Personal API

In a self-hosted instance, use your own Garmin Personal API key to import completed activities and available sleep, HRV, resting heart rate, and other data from your device and account.

This page covers self-hosting only. For Cloud authorization and history import, use the [platform connection guide](/docs/guide/connect-third-party-platforms#connect-garmin-for-new-data).

## Connect your own account

1. Create a key in Garmin Connect's [personal API key settings](https://connect.garmin.com/app/settings/personalApiToken). Use the matching Garmin Connect region for a China account.
2. In Trainingload.ai, open **Account → Third Party Connections → Garmin → Connection settings**.
3. Choose the account region and confirm its time zone, such as `Asia/Shanghai`.
4. Choose activity import, sleep and recovery data, and scheduled sync as needed. Paste the key and connect.
5. Select **Sync now**. Blank dates default to the most recent 30 days; you can also choose a historical range.

You do not need to supply a Garmin password or browser cookies. The key is encrypted in your own instance. Do not send it in chat, issues, or logs. Keep it safe after creation and replace it if revoked or expired; use the expiry options shown by Garmin.

## What to check after syncing

| Data | Result to check |
| --- | --- |
| Completed activities | A matching record appears in Activities; open it to inspect the source, time, and available charts |
| Sleep, HRV, resting heart rate, steps | The relevant date shows data supplied by Garmin; missing values are not filled with zero |
| Weight, stress, oxygen saturation, Body Battery | Garmin's meaning is preserved; these values do not replace ATL, CTL, or TSB |
| Additional metrics | Read by date in **Advanced data and operations**, without automatically changing local sport settings |
| Nutrition and menstrual data | Excluded from scheduled sync; additional reads require separate confirmation |

Availability depends on device records, region, and Garmin permissions. Not every account has every item in this table. Check the sync result after connecting. Unrecognized data produces an error; an empty result does not mean zero.

This connection reads personal data. It does not create or send future workouts to Garmin.

## History and progress

- Choose the relevant dates; ranges use the account time zone.
- **Queued** means the request was saved. An activity counts as **Imported** only after download and import finish.
- Refreshing does not clear a running task. Wait for a large import instead of repeatedly submitting it.
- One history request can cover up to ten years. Duration depends on activity volume and Garmin limits.
- Syncing again checks and updates existing Garmin records rather than creating a new copy every time.
- Read the displayed error if an item fails. Other successfully read items may still finish importing.

Enable the relevant options in connection settings for scheduled sync. A discovered-record count is not a successful-import count.

## Expired keys, disconnection, and backups

Use **Replace key or reauthorize** when a key expires or is revoked. Check the region and account before entering its replacement.

Disconnecting stops future sync but does not erase offline backups you already saved. Follow the [backup and recovery guide](/docs/self-host/operations) to keep the original instance keys safe with your database backup. Restored connections need those keys.

This connection is for your own Garmin data. Do not collect other people's keys to provide a multi-user service from one personal instance. See the [official Garmin Personal API introduction](https://developer.garmin.com/gc-developer-program/personal/personal-api/) for more information.
