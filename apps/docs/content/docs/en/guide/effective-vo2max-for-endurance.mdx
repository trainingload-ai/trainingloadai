# Understand Effective VO2max in Endurance Training

Trainingload.ai uses available activity evidence to estimate an effective VO2max / VDOT value. The detail view helps you inspect its history and, when enough comparable running history is available, a conditional outlook. These are model estimates rather than laboratory measurements or guaranteed future results.

[Open the dashboard in Demo](https://demo.trainingload.ai/en/dashboard), then select the **VO2Max** card. The Demo's current records determine whether a forecast is available. The forecast screenshot below uses synthetic example data rendered by the app.

## Before you begin

- Import recent running activities and wait for processing to complete.
- Check maximum heart rate, the selected estimation source and any correction factor used in your profile.
- Use activities with reliable inputs and comparable purposes. Note changes in sensors, terrain or estimation settings.
- Keep the distinction between activity estimates, the current value and the forecast when recording your conclusion.

The forecast uses eligible running observations. Changing the dashboard sport filter does not create a cycling or swimming forecast.

## 1. Open the VO2Max detail view

On the dashboard, find **VO2Max** and select its card. The detail view contains the current value, any available four-week outlook, the chart, history-range tabs, explanatory text and **Ask Coach**.

The current value can remain visible even when a forecast is unavailable. Check the availability message and whether the chart actually contains future estimates.

## 2. Choose a history window

Use **7**, **14**, **30** or **60** day tabs to choose the recorded history you want to inspect. Start with a window containing several comparable activities.

When a forecast is available, the chart also shows a future window matching the selected tab, capped at 30 days. For example, the 7-day tab shows a shorter future section than the 30-day tab. The summary's **In four weeks** value still refers to its four-week endpoint.

## 3. Identify which value you are reading

| Display | What it represents |
| --- | --- |
| Current VO2Max | The current value shown by the product. |
| Historical values and activity points | The estimates or records available for dates in the selected history window. |
| Current estimated level | A model's estimated level at its historical cutoff when the chart offers that reading. |
| In four weeks | The endpoint of the available four-week forecast. |
| Reference range or 80% prediction interval | The range associated with the forecast, labelled according to the model in use. |

The current product value and model-estimated level can differ. Read the label and date before comparing them. A future point does not represent a completed workout.

Move over a historical or future point to inspect the chart's available readings. For an unusual historical point, use its date to find the original activity in **Activities**. Check the recording and estimation source before deciding that your fitness changed.

## 4. Read the forecast and its range

When the outlook is available, the summary shows **In four weeks**, a direction relative to the current value, the associated range and the history cutoff date. Read these together.

A **reference range** is not a calibrated 80% prediction interval. If the page explicitly labels an **80% prediction interval**, retain that label when reporting it. Neither label promises that your future value will fall inside the band.

The forecast follows historical observations and the model's assumptions. It is separate from PMC's schedule-based load outlook. Adding a future workout does not by itself demonstrate that VO2Max will improve by the displayed amount.

Use the estimate as context for a review, then compare it with recorded workout execution and training load. Follow [PMC History and Forecasts](/docs/guide/pmc-forecast) for the load workflow.

## 5. Handle an unavailable forecast

Read the displayed state before changing settings.

| Message | Next step |
| --- | --- |
| More running history is needed | Continue accumulating eligible processed running records. A current value alone does not supply enough forecast evidence. |
| New running records are needed | Check whether the most recent eligible observations are outdated, then import recent activity. |
| The calculation method changed | Check source and correction settings. New comparable observations may be needed. |
| Forecast unavailable | Keep using available history and inspect the request or data state. |

A blank history chart can also mean the selected 7-day window contains no observations. Try a longer history window before concluding that all records are missing. Missing estimates are not zero values.

Avoid changing maximum heart rate or correction settings simply to obtain a preferred forecast. A settings change can alter comparability as well as the displayed values.

## 6. Ask Coach about the evidence

Select **Ask Coach** in the detail view. The prepared question asks about the current level, historical changes and any available four-week outlook. Review and send it when it matches your question.

Add the dates and activities you want explained. Ask the coach to separate recorded evidence from estimates, and to identify missing context. Opening this link does not send a question automatically or apply a plan change.

Before confirming a proposed change, check the activity evidence, plan context and the normal [AI Coach confirmation flow](/docs/guide/ai-coach).

## Check the result

Record the history window, input source, relevant dates, current value, forecast availability and the range label. You should be able to explain which observations support a trend and which portion remains a forecast.

## Common questions

### Why does the four-week summary stay the same when I select 7 days?

The tab changes the chart window. The summary still describes the four-week endpoint, while the chart can show a shorter part of the available outlook.

### Why is there a current value but no forecast?

The current display and forecast have different evidence requirements. The forecast can be unavailable because running observations are insufficient, stale, incomparable or unavailable to the model.

### Why does a single activity differ from the trend?

An activity estimate and a model's current level summarize different evidence. Check the source, sensor quality, terrain and purpose of that activity. Compare several suitable records rather than treating one point as a training-block result.

### Will a planned workout change this prediction?

PMC estimates future load from applicable scheduled inputs and habits. The VO2Max outlook is based on its historical observation model. Do not treat the two forecasts as the same calculation.

### Why does it differ from my watch or a laboratory result?

They can use different methods, inputs and dates. Keep each series consistent. Read [VO2 Max](/docs/metrics/maximal-oxygen-uptake) for measurement and estimation concepts.
