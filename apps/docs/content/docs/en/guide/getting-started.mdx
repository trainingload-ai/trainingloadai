# Get Started with Your First Activity

Start by bringing one completed workout into Trainingload.ai and confirming that it was recorded correctly. That activity can then support review, training-load context and comparison with a planned workout.

[Explore the read-only Demo](https://demo.trainingload.ai/en). The screenshot uses synthetic training data in the real app to show how a populated home page fits together. Your initial account can have empty sections while you complete setup.

## Before you begin

Prepare one original FIT, TCX or GPX activity file, or access to a supported source platform containing a known workout. Choose a session whose date, sport and approximate duration you can recognize.

For the Cloud service, sign in and complete any account-verification steps shown. For a Self-host instance, complete the [Self-host installation and owner setup](/docs/self-host/installation) first, then use that instance's account. Available platform connections depend on the deployment and its configured providers.

## 1. Check the profile and display settings

Open **Settings / Account** on Web, or **Me / Account** in the mobile app. Check the account timezone and unit preferences before comparing calendar dates or pace values.

Enter reliable profile information and any thresholds you already know. Keep the sport associated with each threshold correct. For the full editing workflow, use [Profile, Thresholds, and Zones](/docs/guide/profile-thresholds-zones).

If you need help estimating a threshold, use the relevant tool and review the result before saving it. An uncertain threshold is a reason to qualify an intensity or load interpretation.

## 2. Choose one route for the first activity

| Your starting point | Next step |
| --- | --- |
| You have an original activity file | Open Activities and use the upload entry. |
| Your workouts are in a supported online platform | Open that platform's connection settings and follow its authorization and synchronization flow. |
| You are already recording in the mobile app | Finish and synchronize a recording, then find it in Activities. |

Use [Connect Training Data](/docs/guide/connect-data) to choose a route. The same workout can pass through several services, so identify the source you intend to keep before starting a history import.

## 3. Import and wait for processing

For a file, open **Activities**, choose the upload action, select the original file and review the format inspection. Continue with the import, then inspect each item's result in the batch-progress dialog. If a duplicate is detected, compare it with the existing activity before deciding whether a separate copy is needed.

For a connected platform, follow the initial-sync or import action offered by its settings. A connected account and a completed import are separate states. Find the expected workout in Activities after the job runs.

Detailed file selection, duplicate choices and batch states are covered in [Upload Activity Files](/docs/guide/upload-activity-files).

## 4. Verify the first recorded result

1. Find the activity by its date and sport in **Activities**.
2. Check the source, start time, distance and duration against the original recording.
3. Wait for **Ready**, or inspect any partial-analysis or failure message.
4. Open activity detail and check the available route, laps and sensor charts.
5. Confirm that the activity appears on the expected local date in the calendar.

A file with summary values alone can produce fewer charts than a file containing recorded samples. Missing GPS or heart rate should be explained by the source data, processing state or an explicit error.

Use the [Activity Detail guide](/docs/guide/activity-detail) to review the result, then the [Timeline guide](/docs/guide/activity-timeline) when you need to inspect one effort.

## 5. Choose the next task

- To understand recorded load, open [PMC history and forecasts](/docs/guide/pmc-forecast). New or incomplete history can limit the outlook.
- To organize future training, [create a plan](/docs/guide/create-training-plan), review its dates and workouts, then activate it when appropriate. Templates, manual editing and AI-assisted drafts are separate creation paths.
- To use the day-to-day workflow, open [Today and Current Status](/docs/guide/today-and-current-state).
- To ask about a workout, open [AI Coach](/docs/guide/ai-coach) with a specific activity or plan question. Review data-sharing choices and any proposed edits before applying them.

## Check the result

The first-use task is complete when the account timezone and units are appropriate, one identifiable activity has a clear processing result, and its detail and calendar date agree with the recording. Keep any missing sensor coverage or uncertain threshold in your interpretation.

## Common questions

### Why is the home page less populated than the screenshot?

The example contains a plan and recorded activities. A new account fills these sections as you add the corresponding records. Use the first activity's processing result to verify import success.

### Why is a chart or forecast empty?

Check the required sensor data, processing status and history window. An available activity does not guarantee every analysis or forecast has enough evidence.

### Why is the activity on the wrong day?

Compare its start time and timezone with the account's display timezone. Confirm the date context before moving or linking a planned workout.

### Why can I not upload or change something in Demo?

Demo supports browsing the examples. Importing files, connecting your platforms and saving changes require your own account or Self-host instance.
