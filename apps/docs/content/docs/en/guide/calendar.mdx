# Calendar

The calendar brings planned workouts and completed activities into one date-based view. It is useful when you want to see how the training plan and real training line up across days and weeks.

Use it to answer:

- What is scheduled today?
- What did I actually complete?
- How much load landed on this day or week?
- Did missed or moved workouts change the rhythm of the plan?
- Which day should I open for more detail?

## Before you begin

- Set the account time zone correctly.
- Let newly imported activities finish processing.
- Activate a plan if you expect planned workouts to appear.
- Confirm the plan start date before comparing relative plan days with calendar dates.

## Daily review workflow

1. Return to Today, then navigate to the week or month you need.
2. Select a date and separate planned training from completed activity.
3. Open the planned workout to understand intent.
4. Open the completed activity to verify what actually happened.
5. Link them from the supported plan or activity control when they belong together.

## Month and week views

The calendar shows a month view on larger screens. On mobile, it can use a week-focused view so each day remains readable.

Use navigation controls to:

- Move to the previous or next month.
- Move to the previous or next week on mobile week view.
- Jump back to today.
- Pick another month.

The selected date controls the detail panel on the side or bottom of the screen.

## What each day can show

A calendar day can include:

- Planned workouts from the active plan.
- Completed activities.
- Daily load.
- Visual indicators for plan range.
- Sport-specific styling for workouts or activities.

Calendar markers are meant for scanning. Open the day panel or activity detail page when you need exact metrics.

## Selected day panel

The selected day panel shows the details for one date.

It can include:

- Selected date.
- Daily load.
- Activity count.
- Planned workout count.
- Planned workout cards or charts.
- Completed activity list.
- Link to the full day page.

Open a planned workout to inspect the workout description and chart. Open a completed activity to review its activity detail page.

## Training and activity tabs

The day panel separates planned training and completed activities.

Use **Training** to review:

- Planned workouts.
- Workout structure.
- Sport type.
- Session details.

Use **Activity** to review:

- Completed workouts for the selected day.
- Distance and duration.
- Sport type.
- Links to activity details.

This separation helps avoid confusing "what was planned" with "what happened."

## Summary scope

The calendar can summarize training by plan progress or by calendar month.

When an active plan exists, the plan scope helps you review the current plan period. Without an active plan, the month scope still gives a useful overview.

Summary metrics can include:

- Activity count.
- Training load.
- Distance.
- Duration.
- Comparison with the previous period.

Use these summaries to spot patterns, not to judge one day in isolation.

## Calendar vs current plan

Use the calendar when you want date context across multiple days.

Use the current plan page when you want to execute or adjust the plan:

- Mark workouts done or skipped.
- Move unfinished workouts.
- Compare expected and actual load in the plan workflow.
- Ask AI Coach for plan follow-up.

The calendar is for orientation; the current plan page is for execution.

## Verify the result

- The selected date, detail panel, and visible week or month agree.
- Planned workouts appear only inside the activated plan range.
- Completed activities use their correct local calendar date.
- Opening each item leads to the expected workout or activity.
- Daily and period summaries use the scope currently shown in the UI.

## Troubleshooting

If a workout or activity appears on an unexpected day:

- Check your profile time zone.
- Check the activity start time and activity time zone.
- Confirm the plan start date.
- Confirm the activity has finished processing.
- Check whether search or calendar data needs refreshing.

If planned workouts are missing:

- Confirm a plan is active.
- Check whether the selected date is inside the active plan range.
- Open the plan detail page to confirm the workout schedule.
