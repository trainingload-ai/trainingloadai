# Compare Planned and Recorded Training in Calendar

Calendar puts future intentions and recorded training into a shared date context. A planned workout and an activity on the same date are separate records. Use their detail and association to establish whether the recording represents that planned session.

[Open Calendar in Demo](https://demo.trainingload.ai/en/calendar). The screenshots use sample plan and activity data in the real Web app. Navigate to a relevant date in Demo; saving associations or schedule changes requires your own account.

## Before you begin

Check the account timezone and activity start time. For planned training, verify the active plan's start date and workout schedule. Let imported activities finish processing before judging missing load or analysis.

The following workflow uses Web. Narrow screens can use the offered week or month controls and a day sheet; mobile apps use their corresponding date and workout entries.

## 1. Find and select the day

Use the previous/next controls or the month selector to locate the date, or return to **Today**. Check the visible month or week, then select a day.

The selected date determines the day panel. A date can contain planned sessions, independent scheduled workouts, recorded activities or a combination of them. Check the item labels before opening one.

## 2. Read the day panel

Use **Training** to inspect the scheduled workout and **Activities** to inspect the recording. Review the selected date, displayed load and item counts. Choose **View day** when you need the complete day view.

| Record | Check before comparing |
| --- | --- |
| Planned workout | Purpose, scheduled date, sport, structure, notes and execution status. |
| Completed activity | Start time, source, sport, recorded duration/distance, processing and sensor coverage. |
| Association | Whether the correct activity is actually linked to the intended workout. |

A completion label alone does not identify the recording. Open [Activity Detail](/docs/guide/activity-detail) to investigate the actual effort.

## 3. Associate the correct activity with a workout

In your account, open the scheduled workout's detail and its **Link activity** entry.

1. Confirm the workout has a scheduled date and the correct sport.
2. Check the recording's start time in activity detail first. In the offered list for that day, compare title and duration to identify that recording.
3. Select the matching recording and wait for success feedback.
4. If it belongs to another planned session, read the **Replace link?** confirmation before replacing it.
5. Reopen the workout and activity to verify the association.

If no candidate appears, check synchronization, the activity's local date, the workout schedule and sport. Resolve those differences before selecting an unrelated activity.

To fix an incorrect association, use the existing link's **Remove link** or choose the intended activity. Removing an association and deleting an activity have different effects. Demo disables these write actions.

## 4. Compare intended and recorded work

Compare purpose and structure first, then the recorded duration, distance, intensity and available load. Record why a session was shortened, replaced or skipped. Additional activity can be real training even when it was not part of the original plan.

A missing expected or actual load is a data condition to investigate. Check thresholds, sport and processing before treating it as zero. Follow [Manage an Active Plan](/docs/guide/manage-active-plan) for completion, skip, postpone and other execution actions offered by the current workout state.

## 5. Check the summary scope

Calendar can offer **Plan** and **Month** summaries. Read the active scope and displayed date boundaries before comparing counts, distance, duration or load.

Plan progress uses the active cycle. A month overview uses the visible calendar month. Their comparison windows differ, so use the displayed context instead of assuming every summary describes the same period.

Use [Weekly Review](/docs/workflow/weekly-review) for the broader review and [PMC](/docs/guide/pmc-forecast) when the question concerns accumulated load and a conditional outlook.

## Check the result

The selected day, day panel and opened records should agree on the date. The planned workout and activity should have the intended association, and any load comparison should name its scope and missing data.

## Common questions

### Why is the activity on a different date?

Compare the activity start time and timezone with the account's display timezone, then check the plan start and scheduled date. Confirm the date before moving a workout.

### Why is the plan workout missing?

Check the active plan, its date range and the individual workout's schedule and status. A moved or skipped session may no longer appear where you expected.

### Why are two records shown for one training session?

The planned session and actual activity are separate records. Confirm their association. If two actual activities also exist, inspect source forwarding and duplicate import before deleting anything.

### Why can I not link the activity in Demo?

Demo permits inspection of the examples. Association and schedule changes require the appropriate account permissions.

### What if a change is rejected?

Read the error and refresh the latest plan or activity state before retrying. Verify that the intended association or schedule actually changed.
