# Upload Activity Files

Upload a recording exported from your watch, bike computer or training platform to see its details, charts and training load in Trainingload.ai. These steps use the web app.

## Prepare your files [#before-uploading]

Use FIT, TCX or GPX workout files. You can upload up to 100 files at once. Original files exported from your device or platform give you the best chance of retaining heart rate, power and route data.

## Upload from Activities

1. Click **Activities** in the left sidebar to open the Activities page.
2. In the **Upload activity files** card on the far right, click **Choose activity files**.

The import progress dialog opens after upload and shows the result for each file.

## Follow import progress [#import-statuses]

You can keep browsing while the files are imported. If you close the dialog, click **Import Progress** on the Activities page to reopen it.

| Status shown | What to do |
| --- | --- |
| Queued, Normalizing, Materializing, Building analysis | Your files are still being processed. Wait for the import to finish. |
| Done | Return to Activities to find the recording. |
| Skipped | A matching recording usually already exists. Look for it in Activities. |
| Failed, Dead | Read the message beside the file and try the troubleshooting steps below. |

## Find your imported activities [#after-upload]

Once the import is complete, click **Activities** in the left sidebar. Find your recording by its workout date and click it to view duration, distance, charts and training load.

See [Activities Feed and Search](/docs/guide/activity-feed-search) and [Activity Details](/docs/guide/activity-detail) for a page tour.

## Troubleshooting

### The Upload button is disabled

Choose your files first. If they are still being checked, wait a moment. If a file shows an error, follow the message or remove that file before trying again.

### I see a duplicate warning

If the workout is already in Activities, you can keep the existing recording or cancel the upload. Only force a new import if you want to keep a separate copy.

### A file fails to upload or import

Read the message beside the file. Try exporting the original FIT, TCX or GPX file from your device or platform again, then upload that file on its own. Changing a filename extension does not convert the file.

Screenshots, ordinary CSV spreadsheets, and FIT files containing only all-day health data cannot be used here to import a workout recording.

### My recording has no heart rate, power or route

Wait for activity processing to finish first. Charts need the corresponding data in the original recording. An indoor workout without GPS, for example, will not show a route. Check the source platform and try exporting its original workout file again.

## Need another file format? [#convert-between-formats]

Uploads support FIT, TCX and GPX, so conversion is usually unnecessary. If you also need the file for another platform, use the [FIT, GPX and TCX converter](/converter).
