# MCP-Ressourcen und Prompts

Diese Seite wird aus dem MCP-Inhaltskatalog des Servers erzeugt. Bearbeite sie nicht direkt; führe `pnpm --dir apps/server mcp:reference` aus.

Ressourcen liefern Clients stabile Leitlinien zu Kennzahlen, Sicherheit und dem autorisierten Fähigkeitskatalog, ohne zusätzliche Athletendaten zu lesen. Prompts erzeugen strukturierte Fragevorlagen; die eigentlichen Daten stammen weiterhin aus OAuth-gesicherten Tools.

## Ressourcen

| URI | Name | Zweck |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | Leitfaden zur Interpretation von TrainingLoad-Kennzahlen | Definitionen und Interpretationsgrenzen für Trainingsbelastung, ATL, CTL, TSB, Bereitschaftsbereiche, Datenabdeckung und fehlende Daten. |
| `trainingload://guide/privacy-and-safety` | Leitfaden zu Datenschutz und Sicherheit bei TrainingLoad | Schreibgeschützte Grenzen, Umgang mit nicht vertrauenswürdigem Text, Grenzen bei Gesundheitsdaten und ausgeschlossene Datenklassen. |
| `trainingload://catalog/capabilities` | Autorisierter TrainingLoad-Fähigkeitskatalog | Die aktuell autorisierten schreibgeschützten Tool-Namen, Beschreibungen und OAuth-Scopes. |

## Prompts

## `weekly-training-review`

Erstellt einen datengestützten Rückblick auf aktuelle Trainingsbelastung, Konstanz, Aktivitäten und anstehende Einheiten.

<details>
<summary>Argument-JSON-Schema</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "days": {
      "default": "7",
      "type": "string",
      "enum": [
        "7",
        "14",
        "28"
      ]
    },
    "sportType": {
      "type": "string",
      "enum": [
        "RUN",
        "CYCLING",
        "SWIM"
      ]
    }
  },
  "required": [
    "days"
  ],
  "additionalProperties": false
}
```

</details>

## `race-preparation-check`

Prüft einen Wettkampf, die Umsetzung des Trainingsplans, die aktuelle Trainingsbelastung und anstehende Einheiten, ohne medizinische Aussagen zu treffen.

<details>
<summary>Argument-JSON-Schema</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "eventId": {
      "type": "string",
      "minLength": 1,
      "maxLength": 128
    },
    "horizonDays": {
      "default": "28",
      "type": "string",
      "enum": [
        "14",
        "28",
        "56"
      ]
    }
  },
  "required": [
    "horizonDays"
  ],
  "additionalProperties": false
}
```

</details>
