# Was ist der Intensity Factor (IF) beim Radfahren und Laufen?

Der **Intensity Factor (IF)** beschreibt die Intensität einer Einheit relativ zu deiner Schwelle: [Normalized Power](/de/docs/metrics/power/normalized-power) ÷ [FTP](/de/docs/metrics/power/functional-threshold-power). Er beantwortet die Frage „Wie hart war diese Einheit?“, sodass eine Fahrt mit 150 W für die eine Person locker und für eine andere am Limit sein kann.

Damit macht IF die Trainingsintensität auch zwischen Athletinnen und Athleten unterschiedlichen Leistungsniveaus vergleichbar.

## Berechnungsformel

IF ist das Verhältnis von [Normalized Power (NP)](/de/docs/metrics/power/normalized-power) zu [Functional Threshold Power (FTP)](/de/docs/metrics/power/functional-threshold-power):

$$
IF = \frac{NP}{FTP}
$$

**Beispiel**:
-   Angenommen deine FTP liegt bei 200 W.
-   Du absolvierst eine Ausfahrt mit NP = 150 W.
-   Dann gilt $IF = 150 / 200 = 0.75$.

> **Hinweis**: Dasselbe Prinzip gilt fürs Laufen (mit rFTP und NGP). Die Herzfrequenz ist wegen **Verzögerung und kardiovaskulärer Drift** in der Regel weniger präzise als Leistung.

### IF-Berechnung beim Laufen

Beim Laufen verwenden wir meist **rFTP (Lauf-Schwellenleistung)** oder **CP (Critical Power)** als Referenz:

$$
IF_{run} = \frac{RunPower}{CP}
$$

Oder bei Pace-basierter Steuerung:

$$
IF_{pace} = \frac{NGP}{ThresholdPace}
$$

*Hinweis: [NGP (Normalized Graded Pace)](/de/docs/metrics/pace/normalized-graded-pace) ist eine steigungsangepasste, normalisierte Pace.*

## Warum sich der Blick auf IF lohnt

### 1. Vergleich zwischen Athletinnen und Athleten
- **Absolute Leistung**: Ein Profi rollt bei 200 W ganz entspannt; für Einsteigerinnen oder Einsteiger können 200 W maximal sein. Watt allein sagen nichts über die relative Anstrengung aus.
- **Relative Intensität (IF)**: Haben beide einen IF von 0,75, leisten beide dieselbe relative aerobe Grundlagenarbeit.

### 2. Trainingszonen auf einen Blick erkennen
IF ist der schnellste Weg, um zu sehen, in welchem Intensitätsbereich eine Einheit lag:

| IF-Bereich | Trainingszone | Typische Einordnung |
| :--- | :--- | :--- |
| **< 0,75** | **Z1 / Z2** | **Regeneration / aerobe Grundlage**. Locker bis moderat, typisch für Grundlagen- oder Erholungseinheiten. |
| **0,75 – 0,85** | **Z3 / Sweet Spot** | **Tempo / Sweet Spot**. Moderat anstrengend und je nach Dauer und Sportart gut durchhaltbar. |
| **0,85 – 0,95** | **Z4** | **Schwelle**. Sehr anstrengend, nahe der FTP; typisch für Schwellenintervalle oder Zeitfahren. |
| **0,95 – 1,05** | **Z5** | **VO₂max**. Sehr hohe Intensität, meist in kürzeren Intervallen absolviert. |
| **> 1,05** | **Z6 / Z7** | **Anaerob / Sprint**. Kurze Spitzenbelastungen; meist nur in kurzen Rennen oder Tests. |

## Typische Anwendungsfälle

### 1. FTP-Einstellung überprüfen
Wenn du bei einem **einstündigen Solo-Zeitfahren (TT)** einen **IF ≈ 1,1** hältst (deine NP also 1,1× deiner FTP entspricht), ist deine **FTP wahrscheinlich zu niedrig eingestellt**.
- **Warum**: FTP beschreibt typischerweise die höchste Leistung, die du nahe dem Fließgleichgewicht rund eine Stunde lang halten kannst. Bleibt dein IF eine volle Stunde deutlich über 1,0, solltest du deine Schwelle überprüfen.

### 2. Wettkampf-Pacing steuern
Bei langen Ausdauerwettkämpfen schützt ein kontrollierter IF dein Pacing im Finale und deine Verpflegungsstrategie:

| Wettkampftyp | Ziel-IF-Bereich | Risikohinweis |
| :--- | :--- | :--- |
| **Ironman** | **0,65 – 0,75** | Eine höhere Radintensität erhöht das Risiko für Einbrüche beim Laufen und bei der Energieversorgung. |
| **Mitteldistanz (70.3)** | **0,75 – 0,85** | Das obere Ende ist offensiv und hängt stark von deiner Lauf-Haltbarkeit ab. |
| **Olympische Distanz** | **0,85 – 0,95** | Schwellennahes Radfahren; genügend Reserve für den abschließenden Lauf lassen. |

### 3. Zentraler Baustein des Training Stress Score (TSS)
IF ist ein direkter Multiplikator im **[TSS](/de/docs/metrics/training-load/training-stress-score)** – er bestimmt, wie schnell sich TSS ansammelt:

$$
TSS = \frac{t \times NP \times IF}{FTP \times 3600} \times 100
$$

- Schon ein kleiner Anstieg des IF erhöht den TSS stark (in der Formel steckt effektiv ein $IF^2$-Zusammenhang).

## Empfehlungen von Trainingload.ai

Trainingload.ai nutzt IF, um den Charakter einer Einheit zu verstehen – nicht nur deren Gesamtbelastung:

1.  **IF am Ziel der Einheit ausrichten**: Aerobe Grundlageneinheiten sollten kontrolliert bleiben; Schwellen- oder VO₂max-Einheiten liegen bewusst höher.
2.  **Vorsicht bei sehr kurzen Einheiten**: Bei Einheiten unter rund 20 Minuten kann IF ungewöhnlich hoch wirken und sollte nicht wie bei einer langen, gleichmäßigen Einheit interpretiert werden.
3.  **Schwellenwerte prüfen**: Zeigen lockere Einheiten regelmäßig einen IF über 0,8, war die Einheit entweder nicht wirklich locker oder dein Schwellenwert muss neu kalibriert werden.

## Grenzen

-   **Verzerrung bei kurzen, harten Einheiten**: Bei sehr kurzen Einheiten (z. B. ~10 Minuten) kann das Verhalten von NP den IF ungewöhnlich hoch erscheinen lassen.
-   **Abhängigkeit von einer stimmigen FTP**: Ist die FTP veraltet oder falsch, verliert auch der IF seine Aussagekraft.

## FAQ

### Was ist der Intensity Factor?

Der Intensity Factor ist NP ÷ FTP (oder NGP ÷ Schwellenpace beim Laufen). Ein IF von 0,75 steht für die meisten Athletinnen und Athleten für eine kontrollierte aerobe Einheit; ein IF nahe 1,0 entspricht etwa einer Stunde an der Schwelle.

### Wie wird IF im Radtraining genutzt?

Über den IF-Bereich prüfst du, ob eine Ausfahrt in der geplanten Zone blieb, steuerst dein Pacing bei langen Rennen und erkennst eine zu niedrig eingestellte FTP – ein IF ≈ 1,1 über eine volle Stunde deutet meist auf eine unterschätzte Schwelle hin.

### Funktioniert IF auch beim Laufen?

Ja, über die Lauf-Schwellenleistung bzw. CP oder über NGP im Verhältnis zur Schwellenpace. Herzfrequenzbasierter IF ist wegen Verzögerung und Drift weniger genau.

### Wie beeinflusst IF den TSS?

TSS skaliert mit IF². Ein kleiner Anstieg des IF erhöht die Belastung deutlich stärker als eine prozentual gleiche Verlängerung der Dauer – deshalb verzerrt eine falsche FTP sowohl IF als auch TSS.
