# Produktbegriffe und Status

Schlage hier unbekannte Begriffe oder Statusmeldungen nach, um sofort zu verstehen, was sie bedeuten und was dein nächster Schritt ist.

## Häufige Begriffe

| Begriff | Bedeutung |
| --- | --- |
| Athletenprofil | Zeitzone, Einheiten, Schwellenwerte, Zonen, Voreinstellungen und Sportartenkontext zur Einordnung deines Trainings |
| Trainingsplan | Ein strukturierter Zeitplan aus einzelnen Einheiten, den du als Entwurf speichern, aktivieren oder abschließen kannst |
| Geplante Einheit | Was für ein bestimmtes Datum vorgesehen ist – inklusive Sportart, Struktur, Dauer, Intensität und erwarteter Trainingsbelastung (sofern verfügbar) |
| Absolvierte Aktivität | Was tatsächlich aufgezeichnet, synchronisiert oder von einem Gerät bzw. einer Plattform hochgeladen wurde |
| Plan-Aktivitäts-Verknüpfung | Eine eindeutige Zuordnung, die zeigt, dass eine absolvierte Aktivität einer bestimmten geplanten Einheit entspricht |
| Aktueller Zustand | Jüngste Trainingsbelastung, Erholungsdaten, subjektives Feedback und weiterer Kontext für die heutige Trainingsentscheidung |
| Auswertung (Review) | Eine Einordnung einer Aktivität, eines Tages, einer Woche, eines Monats oder eines Trainingsplans auf Basis der vorliegenden Daten |
| KI-Aktion | Eine vorgeschlagene oder ausgeführte Aktion wie das Erstellen, Verschieben oder Ändern geplanter Einheiten |

## Aktivitätsstatus

| Status | Was er bedeutet | Was du tun solltest |
| --- | --- | --- |
| Wird hochgeladen / importiert | Die Datei oder die Daten des Anbieters werden noch übertragen | Kurz abwarten, bevor du es erneut versuchst |
| Wird verarbeitet | Die Aktivität existiert bereits, abgeleitete Daten sind aber eventuell noch unvollständig | Fehlende Belastungswerte oder Diagramme noch nicht bewerten |
| Bereit | Die Analyse der Aktivität ist abgeschlossen | Prüfe die Daten, die die Quelle tatsächlich geliefert hat |
| Fehlgeschlagen | Import oder Verarbeitung konnten nicht abgeschlossen werden | Sichtbare Fehlermeldung lesen und in der Fehlerbehebung nachsehen |
| Duplikat | Dieselbe Quellaktivität oder eine identische Datei existiert bereits | Bestehenden Eintrag prüfen und dieselbe Einheit nicht doppelt importieren |

## Plan- und Einheitenstatus

| Status | Was er bedeutet |
| --- | --- |
| Entwurf | Der Trainingsplan kann noch geprüft und bearbeitet werden, bevor er aktiv wird |
| Aktiv | Der Trainingsplan, dem du aktuell folgst – seine Einheiten erscheinen an den geplanten Tagen |
| Abgeschlossen | Der Zeitraum des Plans ist beendet; er bleibt für Rückblicke verfügbar |
| Geplant | Eine Einheit ist terminiert, hat aber noch kein endgültiges Ergebnis |
| Abgeschlossene Einheit | Eine geplante Einheit ist als erledigt markiert, meist über eine verknüpfte Aktivität oder eine manuelle Abschlussmarkierung |
| Übersprungen | Die Einheit wurde bewusst nicht absolviert |
| Ungeplante Aktivität | Eine absolvierte Aktivität gehört zu keiner geplanten Einheit |

## Trainingsbelastung, Auswertungen und KI-Credits

- **Trainingsbelastung** ist eine abgeleitete Schätzung der Trainingsdosis. Ihre Verfügbarkeit hängt von Sportart, Dauer, Sensordaten, Schwellenwerten und den Regeln für die Belastungsquellen ab.
- **Coach-Auswertung** ist eine datenbasierte Einordnung – weder rohe Gerätedaten noch eine medizinische Diagnose.
- **KI-Credits** sind Nutzungseinheiten für entsprechende KI-Aktionen. Das Credit-Protokoll zeigt deinen Verbrauch; es beschreibt weder Trainingsbelastung noch Kontoberechtigungen.
- **Demo-Konto** ermöglicht dir das Stöbern in Beispieldaten. Melde dich in deinem eigenen Konto an, um Änderungen zu speichern, Aktivitäten zu importieren oder mit deinen eigenen Trainingsdaten zu arbeiten.
