# COROS-Verbindung

Beim Self-Hosting wird derzeit keine direkte COROS-Verbindung unterstützt. Exportiere eine unterstützte FIT-, TCX- oder GPX-Aktivitätsdatei aus der Quellplattform und [lade sie in Trainingload.ai hoch](/de/docs/guide/upload-activity-files).

Unterstützte persönliche Verbindungen beim Self-Hosting sind:

- [Intervals.icu](/de/docs/self-host/configuration)
- [Garmin Personal API](/de/docs/self-host/garmin-personal-api)

Informationen zur Cloud findest du in der [Anleitung zu Drittanbieter-Verbindungen](/de/docs/guide/connect-third-party-platforms).
