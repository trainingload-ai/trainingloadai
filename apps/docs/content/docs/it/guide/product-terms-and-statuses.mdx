# Termini e stati del prodotto

Consulta questa pagina quando incontri nomi o stati poco familiari per capire cosa significano e cosa fare dopo.

## Termini comuni

| Termine | Significato |
| --- | --- |
| Profilo atleta | Fuso orario, unità di misura, soglie, zone, preferenze e contesto sportivo usati per interpretare l'allenamento |
| Piano di allenamento | Un programma composto da singole sessioni che puoi salvare come bozza, attivare o concludere |
| Allenamento pianificato | Ciò che era previsto per una data specifica, inclusi sport, struttura, durata, intensità e carico stimato quando disponibile |
| Attività completata | Ciò che è stato effettivamente registrato, sincronizzato o caricato da un dispositivo o una piattaforma |
| Collegamento piano-attività | Una relazione esplicita che indica quale attività completata corrisponde a uno specifico allenamento pianificato |
| Stato attuale | Carico di allenamento recente, segnali di recupero, feedback soggettivi e altro contesto usato per decidere cosa fare oggi |
| Revisione | Un'interpretazione di un'attività, una giornata, una settimana, un mese o un piano basata sui dati disponibili |
| Operazione AI | Un'azione proposta o eseguita, come creare, spostare o modificare allenamenti pianificati |

## Stati delle attività

| Stato | Cosa significa | Cosa fare |
| --- | --- | --- |
| In caricamento o importazione | Il file o il pacchetto dati del provider è ancora in trasferimento | Attendi prima di riprovare |
| In elaborazione | L'attività esiste già, ma i dati derivati potrebbero essere ancora incompleti | Non interpretare ancora carico o grafici mancanti |
| Pronto (Ready) | L'analisi dell'attività è completata | Esamina i dati effettivamente forniti dalla fonte |
| Non riuscito (Failed) | L'importazione o l'elaborazione non si è potuta completare | Leggi l'errore visibile, poi consulta la risoluzione dei problemi |
| Duplicato | Esiste già la stessa attività sorgente o un file equivalente | Controlla il record esistente ed evita di importare due volte lo stesso allenamento |

## Stati di piani e allenamenti

| Stato | Cosa significa |
| --- | --- |
| Bozza | Il piano può ancora essere rivisto o modificato prima di diventare attivo |
| Attivo | Il piano che stai seguendo, con gli allenamenti visibili nelle date programmate |
| Completato | Il periodo del piano si è concluso e rimane consultabile per la revisione |
| Pianificato | Una sessione è programmata ma non ha ancora un esito finale di esecuzione |
| Allenamento completato | Un allenamento pianificato è segnato come completato, di solito con un'attività collegata o una registrazione esplicita |
| Saltato | La sessione non è stata svolta intenzionalmente |
| Attività non pianificata | Un'attività completata che non corrisponde a nessuna sessione programmata |

## Carico, revisioni e crediti

- **Carico di allenamento**: una stima derivata della dose di lavoro. La sua disponibilità dipende da sport, durata, dati dei sensori, soglie e regole di priorità delle fonti di carico.
- **Revisione del Coach AI**: un'interpretazione basata sui dati raccolti, non un dato grezzo del dispositivo e non una diagnosi medica.
- **Crediti AI**: unità di utilizzo per le operazioni AI idonee. Il registro dei crediti descrive il consumo, non il carico di allenamento né i permessi dell'account.
- **Account Demo**: ti permette di esplorare dati di esempio. Accedi al tuo account personale per salvare modifiche, importare attività o lavorare sui tuoi dati reali.
