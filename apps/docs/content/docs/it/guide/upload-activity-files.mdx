# Caricare file di attività

Carica una registrazione esportata dal tuo orologio, ciclocomputer o piattaforma di allenamento per vederne dettagli, grafici e carico di allenamento in Trainingload.ai. Questi passaggi si riferiscono all'app web.

## Prepara i tuoi file [#before-uploading]

Usa file di allenamento FIT, TCX o GPX. Puoi caricare fino a 100 file alla volta. I file originali esportati direttamente dal dispositivo o dalla piattaforma offrono le migliori probabilità di mantenere frequenza cardiaca, potenza e traccia del percorso.

## Carica da Attività

1. Fai clic su **Attività** nella barra laterale sinistra per aprire la pagina Attività.
2. Nella scheda **Carica file di attività** sul lato destro, fai clic su **Scegli file di attività**.

3. Trascina i file che vuoi importare nella finestra di dialogo, oppure fai clic sull'area di selezione per sceglierli.
4. Fai clic su **Carica** nell'angolo in basso a destra della finestra.

Dopo il caricamento si apre la finestra di avanzamento dell'importazione che mostra l'esito di ogni file.

## Segui l'avanzamento dell'importazione [#import-statuses]

Puoi continuare a navigare nell'app mentre i file vengono importati. Se chiudi la finestra, fai clic su **Avanzamento importazione** nella pagina Attività per riaprirla.

| Stato mostrato | Cosa fare |
| --- | --- |
| Queued, Normalizing, Materializing, Building analysis | I file sono ancora in elaborazione. Attendi il completamento dell'importazione. |
| Done | Torna in Attività per trovare la registrazione. |
| Skipped | Esiste probabilmente già una registrazione corrispondente. Cercala in Attività. |
| Failed, Dead | Leggi il messaggio accanto al file e segui i passaggi di risoluzione dei problemi qui sotto. |

## Trova le attività importate [#after-upload]

Al termine dell'importazione, fai clic su **Attività** nella barra laterale sinistra. Trova la registrazione in base alla data dell'allenamento e aprila per visualizzare durata, distanza, grafici e carico di allenamento.

Consulta [Feed e ricerca attività](/it/docs/guide/activity-feed-search) e [Dettaglio attività](/it/docs/guide/activity-detail) per esplorare la pagina.

## Risoluzione dei problemi

### Il pulsante Carica è disabilitato

Seleziona prima i file. Se il controllo preliminare è ancora in corso, attendi qualche istante. Se un file mostra un errore, segui il messaggio o rimuovi quel file prima di riprovare.

### Compare un avviso di duplicato

Se l'allenamento è già presente in Attività, puoi mantenere la registrazione esistente o annullare il caricamento. Forza una nuova importazione solo se vuoi davvero tenere una copia separata.

### Un file non si carica o non si importa

Leggi il messaggio accanto al file. Prova a esportare di nuovo il file originale FIT, TCX o GPX dal dispositivo o dalla piattaforma e caricalo singolarmente. Rinominare l'estensione del file non ne converte il formato.

Screenshot, comuni fogli di calcolo CSV e file FIT contenenti solo dati giornalieri di salute non possono essere usati qui per importare una registrazione di allenamento.

### La registrazione non ha frequenza cardiaca, potenza o percorso

Attendi prima il completamento dell'elaborazione dell'attività. I grafici richiedono i dati corrispondenti nella registrazione originale: un allenamento indoor senza GPS, ad esempio, non mostrerà una traccia su mappa. Controlla sulla piattaforma di origine e prova a esportare di nuovo il file originale dell'allenamento.

## Ti serve un altro formato di file? [#convert-between-formats]

Il caricamento supporta FIT, TCX e GPX, quindi la conversione di solito non serve. Se hai bisogno del file anche per un'altra piattaforma, usa il [convertitore FIT, GPX e TCX](/it/converter).
