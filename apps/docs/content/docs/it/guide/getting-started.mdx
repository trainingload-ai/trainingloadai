# Importa la tua prima attività [#get-started-with-your-first-activity]

Importa una registrazione dal tuo orologio, ciclocomputer o piattaforma di allenamento per vedere dettagli dell'attività, grafici e carico di allenamento in Trainingload.ai. Questa guida spiega la sincronizzazione da piattaforma e il caricamento file nell'app web.

## Prima di iniziare

[Apri Trainingload.ai](https://app.trainingload.ai/en) e accedi con il tuo account. Se usi una distribuzione self-hosted, apri la tua istanza. Per esplorare prima l'interfaccia, [sfoglia la Demo](https://demo.trainingload.ai/en).

## 1. Scegli come importare [#2-choose-one-route-for-the-first-activity]

| Metodo di sincronizzazione | Guida |
| --- | --- |
| Sincronizzazione da una piattaforma di terze parti (Strava, Garmin, Intervals.icu) | [Collega la piattaforma](#connect-a-training-platform) |
| Sincronizzazione da file di attività (FIT, TCX, GPX) | [Carica il file](#upload-a-workout-file) |
| Sincronizzazione dal telefono | [Leggi la guida alla sincronizzazione dal telefono](/it/docs/guide/account-permissions-and-usage#2-review-mobile-permissions-and-data-sources) |

Se usi self-hosting, consulta [Configurazione](/it/docs/self-host/configuration) per le connessioni supportate. Puoi comunque usare i passaggi di caricamento file qui sotto.

## 2. Importa la tua registrazione [#3-import-and-wait-for-processing]

### Opzione 1: collega una piattaforma di allenamento [#connect-a-training-platform]

1. Apri il menu account in fondo alla barra laterale, scegli **Account**, poi scorri fino a **Third Party Connections**.
2. Seleziona la piattaforma che contiene le tue registrazioni e segui la finestra guidata per collegarla.
3. Usa l'opzione di importazione iniziale o sincronizzazione manuale se necessario.
4. Apri **Attività** nella barra laterale per trovare le registrazioni sincronizzate.

Ogni piattaforma supporta un intervallo storico diverso. Consulta [Collegare Strava, Garmin e altre piattaforme](/it/docs/guide/connect-third-party-platforms) per i passaggi di connessione e importazione dello storico.

### Opzione 2: carica un file di attività [#upload-a-workout-file]

Esporta un file FIT, TCX o GPX dal tuo orologio, ciclocomputer o piattaforma di allenamento, poi:

1. Fai clic su **Attività** nella barra laterale sinistra per aprire la pagina Attività.
2. Nella scheda **Carica file di attività** sul lato destro, fai clic su **Scegli file di attività**.

Dopo il caricamento si apre la finestra di avanzamento dell'importazione. Una volta terminata, torna in **Attività** per vedere le tue registrazioni. Se compare un avviso di duplicato, puoi mantenere la registrazione già presente invece di importare due volte lo stesso allenamento. Consulta [Caricare file di attività](/it/docs/guide/upload-activity-files) per maggiori dettagli.

## 3. Apri la tua attività importata [#4-verify-the-first-recorded-result]

Trova l'allenamento per data in **Attività** e apri i suoi dettagli. Vedrai durata, distanza, carico di allenamento e tutti i grafici e percorsi supportati dalla registrazione. Consulta [Dettaglio attività](/it/docs/guide/activity-detail) per una panoramica della pagina.

Un'attività appena importata potrebbe essere ancora in elaborazione. Attendi il completamento dell'analisi prima di valutare i risultati definitivi. I grafici di frequenza cardiaca, potenza e percorso richiedono i relativi dati registrati; una sessione senza GPS non mostrerà una traccia su mappa.

## Domande frequenti

### Ho collegato una piattaforma ma non vedo le mie attività

Verifica che la piattaforma risulti collegata e controlla i filtri per data in Attività. Gli allenamenti passati potrebbero richiedere un'importazione storica dedicata. Segui le opzioni previste dalla piattaforma, oppure esporta il file dell'attività e caricalo in Trainingload.ai.

### La mia attività non ha frequenza cardiaca o percorso

Attendi che l'elaborazione termini. Se il file originale non contiene dati di frequenza cardiaca, potenza o GPS, i grafici corrispondenti non verranno mostrati. Se invece sulla piattaforma di origine quei dati sono presenti, prova a esportare il file originale dell'attività e ricaricarlo.

### L'attività compare nella data sbagliata

Controlla il fuso orario del tuo account e l'orario di inizio della registrazione. Consulta [Profilo, soglie e zone](/it/docs/guide/profile-thresholds-zones) per impostare fuso orario e unità di misura.

### Perché non posso caricare file nella Demo?

La Demo serve solo per esplorare dati di esempio. Per importare le tue registrazioni, [apri l'app principale](https://app.trainingload.ai/en) e accedi al tuo account.
