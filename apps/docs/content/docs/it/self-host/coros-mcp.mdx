# Connessione COROS

Il self-hosting attualmente non supporta una connessione diretta con COROS. Esporta un file attività supportato in formato FIT, TCX o GPX dalla piattaforma sorgente, poi [caricalo su Trainingload.ai](/it/docs/guide/upload-activity-files).

Le connessioni personali supportate in self-host sono:

- [Intervals.icu](/it/docs/self-host/configuration)
- [Garmin Personal API](/it/docs/self-host/garmin-personal-api)

Per Cloud, consulta la [guida al collegamento delle piattaforme](/it/docs/guide/connect-third-party-platforms).
