# Self-hosting

Il self-hosting ti consente di usare Trainingload.ai sul tuo computer o server. Attività, piani di allenamento e file caricati restano sul tuo dispositivo e gestisci gli allenamenti direttamente dal browser.

Un'istanza in self-host è pensata per una sola persona. Ti occupi tu del dispositivo, degli aggiornamenti software e dei backup. Se preferisci aprire l'app e iniziare subito, leggi prima [Self-host vs Cloud](/it/docs/self-host/self-host-vs-cloud).

## Cosa puoi fare

- Importare attività e consultarne dettagli, cronologia e carico di allenamento.
- Organizzare gli allenamenti nel calendario e confrontare sessioni pianificate e completate.
- Caricare file FIT, GPX o TCX, oppure collegare Intervals.icu e Garmin Personal API con chiavi personali.
- Configurare il tuo servizio AI per usare il Coach AI, oppure lasciare l'AI disattivata.

## Cosa preparare prima di installare

- Un dispositivo che soddisfi i [requisiti di installazione](/it/docs/self-host/installation), con Docker Compose installato.
- Spazio su disco sufficiente per i tuoi dati di allenamento e i file caricati.
- Una posizione separata per conservare i backup così da poter ripristinare i dati in caso di guasto del dispositivo.

Usa un pacchetto di release ufficiale, versionato e firmato e segui la guida per verificarlo prima dell'installazione. Non devi compilare il codice sorgente né assemblare i container manualmente. Docker Compose è attualmente il metodo di installazione supportato.

## Dove vanno i tuoi dati

Attività, piani e file caricati vengono salvati sul tuo dispositivo. Collegare una piattaforma di allenamento invia o riceve dati in base alle opzioni di sincronizzazione che selezioni. Usare un servizio AI esterno invia al provider scelto le informazioni di allenamento necessarie per quella richiesta.

L'AI è disattivata per impostazione predefinita. Per abilitarla, segui la [guida alla configurazione](/it/docs/self-host/configuration) e inserisci la chiave API del tuo provider. I costi di utilizzo API sono addebitati da quel provider.
