# Connetti opencode

Aggiungi il server remoto in `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "trainingload": {
      "type": "remote",
      "url": "https://api.trainingload.ai/mcp",
      "enabled": true
    }
  }
}
```

Poi esegui:

```bash
opencode mcp auth trainingload
opencode mcp list
```

Dopo OAuth, chiedi: «Controlla le mie connessioni con piattaforme di allenamento di terze parti e spiega quali direzioni di sincronizzazione sono attualmente disponibili.» Questa richiesta dovrebbe chiamare `get_integration_status`.

Se l'autenticazione non si apre automaticamente, riesegui `opencode mcp auth trainingload`. Non inserire alcun token nel file di configurazione.

[Guida ufficiale MCP di opencode](https://opencode.ai/docs/mcp-servers/)
