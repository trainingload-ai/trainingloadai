# Guide ai client

Scegli il client che utilizzi. Ogni guida si connette allo stesso endpoint tramite TrainingLoad OAuth e non richiede alcuna chiave API.

- [ChatGPT](/it/docs/mcp/clients/chatgpt)
- [Codex](/it/docs/mcp/clients/codex)
- [Claude Code](/it/docs/mcp/clients/claude-code)
- [Claude Desktop](/it/docs/mcp/clients/claude-desktop)
- [Cursor](/it/docs/mcp/clients/cursor)
- [VS Code](/it/docs/mcp/clients/vscode)
- [opencode](/it/docs/mcp/clients/opencode)

Dopo la configurazione, segui la [verifica di accettazione condivisa](/it/docs/mcp/connect#verifica-di-accettazione-per-ogni-client) per controllare OAuth, il rilevamento degli strumenti e la prima chiamata.
