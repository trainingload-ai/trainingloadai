# Risorse e prompt MCP

Questa pagina è generata dal catalogo dei contenuti MCP del server. Non modificarla direttamente; esegui `pnpm --dir apps/server mcp:reference`.

Le risorse forniscono ai client linee guida stabili su metriche, sicurezza e funzionalità autorizzate senza leggere ulteriori dati dell'atleta. I prompt producono modelli di richiesta strutturati; i dati reali provengono comunque dagli strumenti regolati dagli scope OAuth.

## Risorse

| URI | Nome | Scopo |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | Guida all'interpretazione delle metriche TrainingLoad | Definizioni e limiti di interpretazione per carico, ATL, CTL, TSB, fasce di readiness, copertura e dati mancanti. |
| `trainingload://guide/privacy-and-safety` | Guida a privacy e sicurezza di TrainingLoad | Confini in sola lettura, gestione del testo non attendibile, limiti sui dati sanitari e categorie di dati escluse. |
| `trainingload://catalog/capabilities` | Catalogo delle funzionalità TrainingLoad autorizzate | Nomi degli strumenti in sola lettura attualmente autorizzati, descrizioni e scope OAuth. |

## `weekly-training-review`

Costruisci una revisione basata sui dati di carico recente, costanza, attività e allenamenti imminenti.

<details>
<summary>Schema JSON degli argomenti</summary>

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "days": {
      "default": "7",
      "type": "string",
      "enum": [
        "7",
        "14",
        "28"
      ]
    },
    "sportType": {
      "type": "string",
      "enum": [
        "RUN",
        "CYCLING",
        "SWIM"
      ]
    }
  },
  "required": [
    "days"
  ],
  "additionalProperties": false
}
```

</details>
