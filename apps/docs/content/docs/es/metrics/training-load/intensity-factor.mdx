# ¿Qué es el Factor de intensidad (IF) en ciclismo y carrera?

El **Factor de intensidad (IF)** mide la intensidad de una sesión en relación con tu umbral: [Potencia normalizada (NP)](/es/docs/metrics/power/normalized-power) ÷ [FTP](/es/docs/metrics/power/functional-threshold-power). Responde a «¿qué tan dura fue esta sesión?», de modo que rodar a 150 W puede ser suave para un deportista y un esfuerzo máximo para otro.

Responde a «¿cómo de exigente fue este entrenamiento?» y permite comparar la intensidad entre deportistas con niveles muy distintos.

## Fórmula de cálculo

El IF es el cociente entre la [Potencia normalizada (NP)](/es/docs/metrics/power/normalized-power) y el [Functional Threshold Power (FTP)](/es/docs/metrics/power/functional-threshold-power):

$$
IF = \frac{NP}{FTP}
$$

**Ejemplo**:
-   Supón que tu FTP es de 200 W.
-   Completas una salida con NP = 150 W.
-   Entonces $IF = 150 / 200 = 0.75$.

> **Nota**: la misma lógica se aplica a la carrera a pie (usando rFTP y NGP). La frecuencia cardíaca suele ser menos precisa que la potencia debido a su **retraso y deriva**.

### Cálculo del IF en carrera a pie

Para correr solemos utilizar **rFTP (potencia umbral de carrera)** o **CP (Potencia crítica)** como referencia:

$$
IF_{run} = \frac{RunPower}{CP}
$$

O bien, si se utiliza ritmo:

$$
IF_{pace} = \frac{NGP}{ThresholdPace}
$$

*Nota: el [NGP (Ritmo normalizado con pendiente)](/es/docs/metrics/pace/normalized-graded-pace) es un ritmo normalizado ajustado a la pendiente.*

## ¿Por qué fijarse en el IF?

### 1. Comparación entre deportistas
- **Potencia absoluta**: un profesional puede rodar a 200 W con facilidad; un principiante puede ir al máximo a 200 W. Los vatios por sí solos no reflejan el esfuerzo relativo.
- **Intensidad relativa (IF)**: si ambos registran un IF = 0.75, están realizando el mismo trabajo relativo de resistencia aeróbica.

### 2. Identificar zonas de entrenamiento
El IF es la forma más rápida de ver en qué dominio de intensidad se ubicó una sesión:

| Rango de IF | Zona de entrenamiento | Descripción típica |
| :--- | :--- | :--- |
| **< 0.75** | **Z1 / Z2** | **Recuperación / resistencia aeróbica**. Trabajo suave a moderado, habitual en base o sesiones de recuperación. |
| **0.75 - 0.85** | **Z3 / Sweet Spot** | **Tempo / sweet spot**. Moderadamente exigente y sostenible para muchos deportistas según duración y deporte. |
| **0.85 - 0.95** | **Z4** | **Umbral**. Muy exigente, cerca del FTP; frecuente en series o contrarrelojes. |
| **0.95 - 1.05** | **Z5** | **VO₂max**. Trabajo de muy alta intensidad, normalmente en intervalos más cortos. |
| **> 1.05** | **Z6 / Z7** | **Anaeróbico / esprint**. Ráfagas cortas; habitualmente solo en pruebas cortas o tests. |

## Escenarios típicos de aplicación

### 1. Validar tu configuración de FTP
Si mantienes un **IF ≈ 1.1** durante una **contrarreloj individual (CRI) completa de 1 hora** (es decir, tu NP es 1.1× tu FTP), probablemente tu **FTP está configurado demasiado bajo**.
- **Por qué**: el FTP suele considerarse la mayor potencia sostenible cerca de un estado estacionario durante alrededor de una hora. Si el IF se mantiene muy por encima de 1.0 una hora entera, conviene revisar tu estimación de umbral.

### 2. Estrategia de ritmo en competición
En pruebas de larga distancia, controlar el IF protege tu ritmo y tu nutrición en el tramo final:

| Tipo de prueba | Rango de IF objetivo | Nota de riesgo |
| :--- | :--- | :--- |
| **Ironman** | **0.65 - 0.75** | Una intensidad ciclista más alta aumenta el riesgo en la carrera a pie y la nutrición. |
| **Medio Ironman (70.3)** | **0.75 - 0.85** | El extremo superior es agresivo y depende mucho de tu durabilidad corriendo. |
| **Distancia olímpica** | **0.85 - 0.95** | Segmento ciclista cercano al umbral; deja margen para correr después. |

### 3. Pieza central del Training Stress Score (TSS)
El IF es un multiplicador dentro del **[TSS](./training-stress-score)**: marca la rapidez con la que se acumula el TSS:

$$
TSS = \frac{t \times NP \times IF}{FTP \times 3600} \times 100
$$

- Un pequeño aumento del IF eleva mucho el TSS (en esencia, la fórmula sigue una relación proporcional a $IF^2$).

## Recomendaciones de Trainingload.ai

Trainingload.ai usa el IF para interpretar el carácter de un entrenamiento, no solo su carga total:

1.  **Alinea el IF con el objetivo de la sesión**: las sesiones de base aeróbica deben mantenerse controladas; las de umbral o VO₂max son intencionadamente más altas.
2.  **Cuidado con las sesiones muy cortas**: en entrenamientos de menos de unos 20 minutos, el IF puede parecer inusualmente alto y no debe interpretarse igual que en una salida larga y constante.
3.  **Revisa tus umbrales**: si tus sesiones suaves muestran con frecuencia un IF superior a 0.8, o bien no estás entrenando tan suave como crees o tu umbral necesita recalibrarse.

## Limitaciones

-   **Sesgo en sesiones cortas e intensas**: en sesiones muy breves (p. ej., ~10 minutos), el comportamiento de la NP puede hacer que el IF parezca artificialmente alto.
-   **Depende de un FTP fiable**: si tu FTP está desactualizado o es erróneo, el IF pierde sentido.

## Preguntas frecuentes

### ¿Qué es el Factor de intensidad?

El Factor de intensidad es NP ÷ FTP (o NGP ÷ ritmo umbral en carrera). Un IF de 0.75 representa una sesión aeróbica controlada para la mayoría de los deportistas; un IF cercano a 1.0 equivale aproximadamente a una hora a umbral.

### ¿Cómo se usa el IF en ciclismo?

Usa el rango de IF para comprobar si una salida se mantuvo en la zona prevista, regular pruebas largas y detectar un FTP demasiado bajo: sostener IF ≈ 1.1 durante una hora completa suele indicar que tu umbral está subestimado.

### ¿Sirve el IF para correr?

Sí, utilizando rFTP/CP o NGP frente al ritmo umbral. El IF basado en frecuencia cardíaca es menos preciso debido al retraso y la deriva cardíaca.

### ¿Cómo afecta el IF al TSS?

El TSS escala con $IF^2$. Un pequeño aumento del IF añade mucha más carga que el mismo incremento proporcional en duración; por eso un FTP incorrecto distorsiona tanto el IF como el TSS.
