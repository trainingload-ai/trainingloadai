# Elige tu camino

No necesitas configurar todas las métricas antes de que Trainingload.ai te resulte útil. Elige primero el resultado que buscas, completa esa ruta y vuelve más adelante para una configuración más detallada.

## Quiero entender mi entrenamiento reciente

Elige este camino si ya tienes sesiones completadas en otra plataforma o como archivos FIT, TCX o GPX.

1. Completa [Importa tu primera actividad](/es/docs/guide/getting-started).
2. [Conecta una plataforma](/es/docs/guide/integrations) o [sube archivos de actividad](/es/docs/guide/upload-activity-files).
3. Abre el [Detalle de actividad](/es/docs/guide/activity-detail) y confirma que la duración, la distancia, el deporte y los datos de sensores disponibles son correctos.
4. Usa el [Panel](/es/docs/guide/dashboard) y el [flujo de análisis de entrenamiento](/es/docs/guide/training-analysis-workflow) para interpretar la tendencia.

**Habrás terminado cuando:** al menos una actividad haya finalizado el procesamiento y sus gráficas coincidan con los datos de origen que esperabas.

## Quiero seguir un plan de entrenamiento

Elige este camino si te importa más tu próxima sesión que el análisis histórico.

1. Revisa tu [perfil, umbrales y zonas](/es/docs/guide/profile-thresholds-zones).
2. [Crea un plan de entrenamiento](/es/docs/guide/create-training-plan) manualmente o con IA.
3. Revisa las sesiones y activa el plan con la fecha de inicio deseada.
4. Usa el [Calendario](/es/docs/guide/calendar) o la página Plan para encontrar la sesión de hoy.
5. Después de entrenar, [vincula la actividad completada con la sesión planificada](/es/docs/guide/manage-active-plan).

**Habrás terminado cuando:** el plan esté activo, la sesión de hoy sea visible y la primera actividad completada esté vinculada o lista para vincularse.

## Entreno principalmente desde el móvil

Usa el móvil para el entrenamiento del día, grabar actividades, hacer revisiones rápidas y seguir el plan. Usa la web cuando necesites más espacio para gráficas detalladas o para editar un plan de varias semanas.

1. Lee [Web y móvil](/es/docs/guide/web-and-mobile) para saber qué datos se mantienen sincronizados.
2. Completa la lista de permisos en [Grabación móvil](/es/docs/guide/mobile-recording).
3. Graba o importa una sesión.
4. Abre Hoy, Calendario, Plan, Entrenador o Yo para continuar el mismo flujo de tu cuenta.

## Quiero que la IA me ayude a crear o ajustar el entrenamiento

El Entrenador con IA funciona mejor cuando ya dispone de tu perfil, tus actividades recientes y tu plan.

1. Añade los umbrales de los que te fíes; deja en blanco los valores desconocidos en lugar de adivinarlos.
2. Importa suficiente entrenamiento reciente como para reflejar tu carga habitual.
3. Abre el [Entrenador con IA](/es/docs/guide/ai-coach) e indica tu objetivo, horizonte temporal, restricciones y días disponibles.
4. Revisa cada borrador de plan o ajuste de sesión antes de aplicarlo.

**Habrás terminado cuando:** la recomendación cite tu plan o tus actividades reales y el cambio propuesto se muestre antes de guardarse.

## Creo sesiones de fuerza

1. Crea o abre un plan manual.
2. Elige **Entrenamiento de fuerza** en el editor de sesiones.
3. Sigue [Sesiones de fuerza](/es/docs/planning/strength-workouts) para añadir ejercicios, series de trabajo, carga, esfuerzo y descansos.
4. Guarda y comprueba la vista previa antes de usar o exportar la sesión.

## Si no sabes por dónde empezar

Empieza por [Importa tu primera actividad](/es/docs/guide/getting-started). Sigue el ciclo completo más corto: perfil → actividad completada → carga de entrenamiento → plan → revisión.
