# Términos y estados del producto

Consulta aquí los nombres o estados que no te resulten familiares para entender qué significan y qué hacer a continuación.

## Términos comunes

| Término | Significado |
| --- | --- |
| Perfil del deportista | Zona horaria, unidades, umbrales, zonas, preferencias y contexto deportivo usados para interpretar el entrenamiento |
| Plan de entrenamiento | Calendario de entrenamiento con sesiones individuales que puedes guardar como borrador, activar o finalizar |
| Sesión planificada | Lo previsto para una fecha concreta, incluyendo deporte, estructura, duración, intensidad y carga estimada cuando esté disponible |
| Actividad completada | Lo que se grabó, sincronizó o subió realmente desde un dispositivo o plataforma |
| Vínculo entre plan y actividad | Relación explícita que indica que una actividad completada corresponde a una sesión planificada concreta |
| Estado actual | Carga de entrenamiento reciente, datos de recuperación, valoración subjetiva y otro contexto usado para decidir el entrenamiento de hoy |
| Revisión | Interpretación de una actividad, día, semana, mes o plan basada en la evidencia disponible |
| Operación de IA | Acción propuesta o ejecutada, como crear, mover o modificar entrenamiento planificado |

## Estados de actividad

| Estado | Qué significa | Qué hacer |
| --- | --- | --- |
| Subiendo o importando | El archivo o los datos de la plataforma siguen transfiriéndose | Espera antes de reintentar |
| Procesando | La actividad ya existe, pero los datos derivados pueden estar aún incompletos | No interpretes todavía gráficas o carga faltantes |
| Lista | El análisis de la actividad ha terminado | Revisa los datos que realmente aportó la fuente |
| Fallida | La importación o el procesamiento no pudieron completarse | Lee el error visible y consulta la guía de solución de problemas |
| Duplicada | Ya existe la misma actividad de origen o un archivo equivalente | Revisa el registro existente y evita importar la misma sesión dos veces |

## Estados de planes y sesiones

| Estado | Qué significa |
| --- | --- |
| Borrador | El plan todavía puede revisarse o editarse antes de convertirse en actual |
| Activo | El plan que estás siguiendo, con sesiones mostradas en sus fechas programadas |
| Completado | El periodo del plan ha terminado y sigue disponible para consulta |
| Planificada | Una sesión está programada pero aún no tiene un resultado final de ejecución |
| Sesión completada | Una sesión planificada marcada como completada, normalmente con una actividad vinculada o un registro explícito de cumplimiento |
| Omitida | La sesión no se realizó de forma intencionada |
| Actividad no planificada | Una actividad completada que no corresponde a ninguna sesión programada |

## Carga, revisiones y créditos

- La **carga de entrenamiento** es una estimación derivada de la dosis de entrenamiento. Su disponibilidad depende del deporte, la duración, los datos de sensores, los umbrales y las reglas de prioridad de fuente de carga.
- La **revisión del entrenador** es una interpretación basada en evidencia, no datos brutos del dispositivo ni un diagnóstico médico.
- Los **créditos de IA** son unidades de uso para las operaciones de IA elegibles. El registro de créditos describe el consumo; no describe la carga de entrenamiento ni los permisos de la cuenta.
- La **cuenta Demo** te permite explorar datos de ejemplo. Inicia sesión en tu propia cuenta para guardar cambios, importar actividades o trabajar con tus propios registros de entrenamiento.
