# Registro de cambios de MCP

## 2026-10-15 — Superficie completa de entrenamiento de solo lectura

- Se amplió el catálogo de 17 a 24 herramientas.
- Se añadieron estadísticas agregadas de actividad y análisis de constancia del entrenamiento con semántica explícita de cobertura y truncamiento.
- Se añadió detalle con privacidad reducida de zonas y vueltas o parciales por actividad.
- Se añadieron descubrimiento de planes de entrenamiento, resumen de cumplimiento y carga por plan, y detalle individual de competición.
- Se añadieron tres recursos MCP nativos y tres prompts reutilizables, junto con documentación de referencia generada y validación de compuerta de lanzamiento.

## 2026-10-15 — Análisis avanzado de solo lectura e incorporación completa (hito anterior)

- Se amplió el catálogo de 9 a 17 herramientas.
- Se añadieron comparación de períodos, desglose de carga por deporte e indicadores de disposición para el entrenamiento.
- Se añadieron tendencias de estado de forma, zonas de entrenamiento y marcas personales.
- Se añadieron adherencia al plan basada en estado y estado de integración y sincronización.
- Se añadieron las páginas de funcionamiento, casos de uso y siete guías dedicadas de clientes.
- Se amplió la página de producto desde la conexión OAuth hasta las llamadas de herramienta transparentes y las respuestas respaldadas por evidencia.

## 2026-10-14 — Superficie inicial de producto de solo lectura

- Se añadieron nueve capacidades de solo lectura para entrenamiento, actividades, planes, competiciones, perfil y salud.
- Se añadieron instrucciones de servidor orientadas primero a herramientas agregadas y contratos de entrada y salida respaldados por Zod.
- Se añadieron filtrado por alcance (scope) de OAuth, autorización independiente de `health:read`, visibilidad de revocación, límites, registros de auditoría e instrumentación OpenTelemetry.
- Se añadió transporte sin estado con MCP SDK v2 compatible con `2025-11-25` y `2026-07-28`.
- Se añadieron la referencia generada de herramientas y las guías de conexión para clientes.

No hay herramientas de escritura en esta versión.
