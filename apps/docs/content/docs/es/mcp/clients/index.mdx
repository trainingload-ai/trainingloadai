# Guías de clientes

Elige el cliente que utilizas. Todas las guías conectan con el mismo punto de conexión mediante TrainingLoad OAuth y no requieren ninguna clave de API.

- [ChatGPT](/es/docs/mcp/clients/chatgpt)
- [Codex](/es/docs/mcp/clients/codex)
- [Claude Code](/es/docs/mcp/clients/claude-code)
- [Claude Desktop](/es/docs/mcp/clients/claude-desktop)
- [Cursor](/es/docs/mcp/clients/cursor)
- [VS Code](/es/docs/mcp/clients/vscode)
- [opencode](/es/docs/mcp/clients/opencode)

Después de la configuración, sigue la [prueba de funcionamiento compartida](/es/docs/mcp/connect#prueba-de-funcionamiento-para-cada-cliente) para verificar OAuth, el descubrimiento de herramientas y la primera llamada de herramienta.
