# Referencia de herramientas de MCP

Esta página se genera a partir del catálogo de capacidades del servidor. No la edites directamente; ejecuta `pnpm --dir apps/server mcp:reference`. Cada herramienta lee únicamente los datos del deportista autorizado mediante OAuth.

> `health:read` no forma parte de la autorización predeterminada. Los clientes deben solicitar autorización incremental antes de la primera llamada a `get_health_summary`.

| Herramienta | Propósito | Alcances (scopes) de OAuth |
| --- | --- | --- |
| `get_training_snapshot` | Agrega la carga de entrenamiento reciente, el estado de forma, la fatiga, la frescura, la variación semanal y las actividades recientes del deportista autorizado. Prioriza esta herramienta antes de realizar varias llamadas más específicas. | `training:read` `plan:read` `activity:read` |
| `get_athlete_profile` | Lee las preferencias deportivas y los umbrales de entrenamiento del deportista autorizado. No devuelve nombre, correo electrónico, fecha de nacimiento ni ID interno de usuario. | `profile:read` |
| `list_activities` | Busca resúmenes de actividades del deportista autorizado dentro de un rango acotado. No devuelve flujos brutos de sensores ni trazados GPS precisos. | `activity:read` |
| `get_activity` | Lee una actividad autorizada mediante su ID hash opaco. Devuelve solo métricas resumidas; se excluyen la ruta precisa y las muestras brutas de sensores. | `activity:read` |
| `get_activity_zones` | Lee las distribuciones almacenadas de zonas de frecuencia cardíaca, potencia y ritmo de una actividad autorizada. Devuelve únicamente duración agregada y porcentajes, nunca muestras de sensores. | `activity:read` |
| `get_activity_splits` | Lee resúmenes acotados de vueltas o parciales de una actividad autorizada con paginación opaca. Se excluyen las coordenadas exactas y las muestras brutas de sensores. | `activity:read` |
| `get_activity_statistics` | Agrega el número de actividades, días activos, duración, distancia y carga de entrenamiento canónica por deporte durante un período acotado, incluyendo cobertura de métricas y estado de truncamiento. | `training:read` `activity:read` |
| `get_training_load` | Lee la serie de carga de entrenamiento, estado de forma, fatiga y frescura del deportista autorizado para un rango máximo de 180 días. | `training:read` |
| `compare_training_periods` | Compara la carga, la media diaria y los días activos entre dos períodos de entrenamiento acotados. El resultado es observacional y no demuestra un cambio en el estado de forma ni en la recuperación. | `training:read` |
| `get_training_breakdown` | Desglosa la carga de entrenamiento del deportista autorizado entre carrera, ciclismo, natación y otras cargas para un rango máximo de 180 días. | `training:read` |
| `get_training_consistency` | Resume la cobertura de días almacenados, rachas de días activos, variabilidad de carga diaria y carga semanal entre 14 y 180 días. Los días sin datos siguen figurando como ausentes en lugar de tratarse como cero. | `training:read` |
| `get_training_readiness` | Devuelve la carga actual, la forma, la frescura y las bandas de carga reciente como indicadores observacionales de entrenamiento. No es una evaluación médica ni una directriz para entrenar. | `training:read` `plan:read` `activity:read` |
| `get_fitness_trends` | Lee un historial acotado para una métrica de estado de forma del deportista y una fuente explícita. Los valores estimados son orientativos; los valores AUTO o MANUAL corresponden a registros del perfil. | `profile:read` |
| `get_training_zones` | Lee las zonas actuales resueltas de frecuencia cardíaca, ritmo y potencia del deportista, indicando si cada ajuste es personalizado, derivado o no disponible. | `profile:read` |
| `get_personal_bests` | Lee las mejores marcas procesadas para objetivos de distancia o tiempo estándar o personalizados dentro de un rango de fechas acotado. No devuelve rutas ni datos brutos de sensores. | `activity:read` |
| `list_training_plans` | Descubre planes de entrenamiento autorizados que se solapan con un rango de fechas acotado. Los planes continuos tienen periodWeeks y endDate nulos. generatedThrough es la última fecha publicada, no el final del plan ni una garantía de cobertura ininterrumpida. | `plan:read` |
| `get_plan_summary` | Lee el resumen de un plan de entrenamiento propio del usuario con cumplimiento, carga planificada frente a real, progreso semanal y desglose por deporte. Los totales de planes continuos cubren únicamente workoutWindow, con periodWeeks nulo; no son totales históricos. El plan nunca se modifica. | `plan:read` `activity:read` |
| `list_planned_workouts` | Lista las sesiones planificadas autorizadas en un rango de fechas acotado con paginación opaca. | `plan:read` |
| `get_planned_workout` | Lee una sesión planificada autorizada y sus pasos estructurados. Esta herramienta nunca modifica el plan de entrenamiento. | `plan:read` |
| `get_plan_adherence` | Resume la adherencia al plan de entrenamiento según el estado en un rango de fechas acotado. DONE equivale a completada, SKIPPED a omitida y PLANNED o IN_PROGRESS sigue pendiente. | `plan:read` |
| `list_competitions` | Lista las competiciones del deportista autorizado en un rango de fechas acotado con paginación opaca. | `competition:read` |
| `get_competition` | Lee una competición autorizada mediante su ID de evento opaco, incluyendo calendario, objetivo, ubicación y notas. Esta herramienta nunca modifica el evento. | `competition:read` |
| `get_health_summary` | Lee resúmenes diarios seleccionados de recuperación, sueño, frecuencia cardíaca, estrés y actividad. Es contexto de bienestar, no un diagnóstico ni una recomendación médica. | `health:read` |
| `get_integration_status` | Lee el estado de conexión y disponibilidad de sincronización para proveedores de entrenamiento compatibles sin devolver identificadores de cuentas externas, credenciales ni mensajes de error en bruto. | `profile:read` |
