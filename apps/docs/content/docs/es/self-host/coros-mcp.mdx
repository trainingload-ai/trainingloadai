# Conexión con COROS

El autohospedaje no admite actualmente una conexión directa con COROS. Exporta un archivo de actividad compatible en formato FIT, TCX o GPX desde la plataforma de origen y luego [súbelo a Trainingload.ai](/es/docs/guide/upload-activity-files).

Las conexiones personales admitidas en autohospedaje son:

- [Intervals.icu](/es/docs/self-host/configuration)
- [Garmin Personal API](/es/docs/self-host/garmin-personal-api)

Para Cloud, consulta la [guía de conexión de plataformas](/es/docs/guide/connect-third-party-platforms).
