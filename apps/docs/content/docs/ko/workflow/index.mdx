# 전체 훈련 워크플로

활동 가져오기와 훈련 계획 수립부터 완료한 훈련 리뷰까지 아래 순서대로 진행합니다. 각 단계는 관련 가이드와 완료 여부를 점검할 수 있는 결과 기준을 제공합니다.

## 훈련 순환 단계

| 단계 | 확인할 질문 | 기본 가이드 | 완료 기준 |
| --- | --- | --- | --- |
| 1. 보정 | 단위, 시간대, 임곗값, 구간(Zone)이 적절하게 설정되었는가? | [프로필, 임곗값 및 구간](/ko/docs/guide/profile-thresholds-zones) | 프로필이 종목과 현재 수행 능력에 일치함 |
| 2. 연결 | 활동과 건강 데이터를 어느 소스에서 가져오는가? | [데이터 연결](/ko/docs/guide/connect-data) | 최소 1개 이상의 활동이 Ready 상태에 도달함 |
| 3. 계획 | 현재 목표와 훈련 일정은 무엇인가? | [훈련 플랜 만들기](/ko/docs/guide/create-training-plan) | 검토를 마친 플랜이 활성화되었거나 활성화할 준비가 됨 |
| 4. 실행 | 오늘 어떤 훈련을 해야 하는가? | [오늘의 훈련과 현재 상태](/ko/docs/guide/today-and-current-state) | 선수가 예정된 세션과 제약 조건을 파악함 |
| 5. 기록 | 실제로 어떤 훈련을 수행했는가? | [모바일 기록 및 파일 업로드](/ko/docs/guide/mobile-recording) | 완료된 활동이 저장되거나 가져와짐 |
| 6. 대조 | 해당 활동이 계획된 워크아웃에 해당하는가? | [활동 피드 및 검색](/ko/docs/guide/activity-feed-search) | 계획과 실제 상태가 정확히 연결되었거나 의도적으로 분리됨 |
| 7. 리뷰 | 활동 데이터와 최근 추세가 무엇을 보여주는가? | [활동 상세](/ko/docs/guide/activity-detail) | 출처, 훈련 부하, 차트, 맥락이 해석을 뒷받침함 |
| 8. 결정 | 앞으로의 훈련 계획을 유지해야 하는가? | [AI 코치](/ko/docs/guide/ai-coach) | 제안된 변경 사항이 명확히 정리되고 검토됨 |
| 9. 반복 | 이번 주와 전체 사이클이 목표를 향해 순조롭게 나아가고 있는가? | [주간 훈련 리뷰](/ko/docs/workflow/weekly-review) | 다음 리뷰 시점과 다음 핵심 세션이 명확함 |

## 기본 경로로 시작하기

새 계정을 설정하거나 전체 제품 흐름이 원활히 연결되었는지 확인하려면 [첫 번째 훈련과 리뷰 완료하기](/ko/docs/workflow/first-training-cycle)부터 시작합니다.

이후 실제 훈련이 계획과 달라질 때는 아래 시나리오 가이드를 참고합니다.

- [건너뛰거나 단축, 대체되었거나 예정에 없던 훈련](/ko/docs/workflow/when-training-changes)
- [활동, 훈련 부하 또는 회복 데이터 누락](/ko/docs/workflow/data-and-load-problems)
- [주간 계획 대비 실적 리뷰](/ko/docs/workflow/weekly-review)

## 관찰과 결정을 분리하기

활동 기록, 차트, AI 메시지는 의사결정을 위한 근거일 뿐 자동으로 플랜을 변경하지 않습니다. 먼저 데이터 출처와 기간을 확인한 뒤 해석을 정리하고, 그다음에야 향후 훈련을 바꿀지 결정합니다.
