# 실제 훈련이 계획과 다를 때

## 목표 결과

계획 대비 실적 이력을 정직하게 보존하면서, 향후 훈련에는 근거가 충분한 최소한의 변경만 적용합니다.

## 상황별 기록 방법

| 실제 상황 | 올바른 기록 방식 | 하지 말아야 할 행동 |
| --- | --- | --- |
| 훈련을 건너뜀 | 계획된 워크아웃을 건너뜀 또는 미완료 상태로 유지 | 운동 시간이 0인 가짜 활동 업로드 |
| 훈련을 단축함 | 실제로 짧게 수행한 활동을 계획된 워크아웃에 연결 | 완료된 활동 데이터를 목표치에 맞게 수정 |
| 다른 훈련으로 대체함 | 계획된 세션과 실제 완료된 세션 유형을 모두 보이게 유지 | 변경 사실을 숨기려고 무관한 활동의 이름을 바꿈 |
| 예정에 없던 훈련 | 특정 세션을 대체한 것이 아니라면 연결하지 않고 유지 | 날짜가 가장 가까운 워크아웃에 억지로 연결 |
| 훈련 날짜를 옮김 | 실제 결정에 부합할 때만 계획된 세션의 날짜를 이동 | 완료된 활동의 타임스탬프를 임의로 이동 |

## 조정 전에 먼저 검토하기

1. [캘린더](/ko/docs/guide/calendar)에서 해당 날짜를 엽니다.
2. [활동 피드 및 검색](/ko/docs/guide/activity-feed-search)에서 활동 출처와 처리 상태를 확인합니다.
3. [활동 상세](/ko/docs/guide/activity-detail)에서 훈련 부하와 센서 데이터 포함 여부를 검토합니다.
4. 이번 변경을 최근 훈련 부하, 수면·회복 맥락, 다음 핵심 세션과 함께 비교합니다.
5. 조정이 필요하다면 일정, 시간, 강도 중 핵심 변수 하나만 먼저 변경합니다.

## 일정 변경 적용하기

웹 또는 Personal 환경에서 날짜를 마우스 오른쪽 버튼으로 클릭하고 **일정 조정(Adjust schedule)**을 선택합니다. 초안에서 예정된 워크아웃의 날짜를 옮기거나 처방 내용을 수정합니다. 원래 날짜·내용과 수정된 날짜·내용을 비교한 뒤 확정합니다. 초안을 저장하고 나중에 이어서 작업하려면 [캘린더 조정 단계](/ko/docs/guide/calendar#adjust-upcoming-workouts)를 참고합니다.

## AI 코치를 정확하게 활용하기

“어제 수면 상태가 좋지 않아 45분 예정이었던 가벼운 러닝을 25분으로 줄였습니다. 토요일 롱런을 조정해야 할까요?”처럼 구체적인 의사결정 질문을 던집니다. 제약 조건 없이 전체 플랜을 다시 짜 달라는 식의 요청은 피합니다.

## 결과 검증하기

캘린더에는 계획된 내용, 실제 완료한 내용, 두 기록이 다른 이유, 그리고 어떤 향후 워크아웃이 변경되었는지가 그대로 드러나야 합니다. 원본 활동 데이터는 변경되지 않은 상태로 유지되어야 합니다.
