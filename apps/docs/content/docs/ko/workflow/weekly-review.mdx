# 주간 훈련 리뷰

## 목표 결과

15~20분 내로 리뷰를 마치고, 글로 정리된 결론 1개, 최대 1개의 핵심 조정 사항, 그리고 그 결정이 효과적이었는지 다시 확인할 날짜 또는 워크아웃을 정합니다.

## 1. 데이터 완전성 점검하기

[활동 피드 및 검색](/ko/docs/guide/activity-feed-search)을 엽니다. 주간 합계를 읽기 전에 처리 실패, 중복 활동, 잘못된 플랜 연결부터 먼저 정리합니다.

## 2. 계획과 실적 비교하기

[캘린더](/ko/docs/guide/calendar)와 현재 플랜을 함께 확인합니다. 완료, 단축, 건너뜀, 대체, 예정 외 세션의 수를 각각 파악합니다. 리뷰를 단순 완료율 숫자 하나에만 의존하지 않습니다.

## 3. 훈련량(Training Dose) 리뷰하기

[대시보드](/ko/docs/guide/dashboard)와 [훈련 부하](/ko/docs/metrics/training-load)를 확인합니다. 종목과 기간 필터를 일관되게 유지합니다. 합산 수치만 보지 말고 변화를 만든 개별 세션이 무엇인지 찾아냅니다.

## 4. 신체 반응과 맥락 더하기

수면, HRV, 안정시 심박수, 세션 RPE, 근육통, 주관적 피로 데이터가 있다면 함께 검토합니다. 회복 데이터가 누락되었다면 판단 신뢰도가 낮아질 뿐, 회복이 좋았다거나 나빴다는 증거가 되지는 않습니다.

## 5. 다음 조치 결정하기

다음 중 하나를 선택합니다.

- 현재 플랜을 그대로 유지합니다.
- 세션 하나의 일정을 이동합니다.
- 세션 하나의 시간 또는 강도 목표를 낮춥니다.
- 세션 하나를 회복 훈련으로 대체합니다.
- 훈련 가이드라인 범위를 넘어서는 문제라면 전문가 또는 의료진 검토로 넘깁니다.

## 리뷰 결과 검증하기

근거, 결정 내용, 영향을 받는 정확한 향후 세션, 다음 리뷰 시점을 기록합니다. [AI 코치](/ko/docs/guide/ai-coach)를 함께 사용했다면 AI 코치의 답변이 동일한 기간과 근거를 인용하고 있는지 확인합니다.
