# 타임라인으로 워크아웃 분석하기

타임라인(Timeline)은 활동에 기록된 여러 센서 스트림을 하나의 가로축 위에 정렬해 보여 줍니다. 특정 시점을 자세히 확인하거나 선택한 구간의 페이스, 파워, 심박수, 케이던스, 경로를 한꺼번에 비교할 때 사용하세요. 왼쪽의 구간 통계와 차트 내부의 지점 수치는 서로 다른 질문에 답합니다.

이 가이드는 러닝과 사이클링의 **데스크톱 웹** 환경을 기준으로 합니다. 표시되는 차트는 활동에 기록된 데이터에 따라 달라집니다. 전체 활동 리뷰 흐름은 [활동 상세 분석](/ko/docs/guide/activity-detail)부터 살펴보세요.

## 예시 활동 열기

[10km 레이스 데모 활동 열기](https://demo.trainingload.ai/en/activities/17921623926005309429)로 이동한 뒤 경로 아래의 **Timeline(타임라인)** 탭을 선택하세요. 활동은 처음에 Overview로 열리며, 데모는 읽기 전용이므로 분석 구간 저장 및 편집은 비활성화되어 있습니다.

본인 활동의 경우 처리가 완료될 때까지 기다린 뒤 시계열 샘플이 기록되어 있는지 확인하세요. 요약 수치만 있는 활동은 동기화 타임라인을 제공하지 않습니다. 실내 세션은 GPS가 없어도 유효한 차트를 볼 수 있습니다. 데이터를 해석하기 전에 종목, 역치, 단위가 맞는지 확인하세요.

## 1. 전체 활동 흐름 읽기

**Timeline**을 선택하면 상단에 구간(Segment) 헤더, 왼쪽에 지표 설정과 구간 통계, 오른쪽에 나란히 정렬된 차트가 표시됩니다. 가로축은 기본적으로 시간(Time) 모드로 시작하며, 위치 데이터가 있는 활동은 탭 위에 경로 지도가 유지됩니다.

긴 활동은 화면에 보이는 차트 너비를 넘어 이어집니다. 가로로 스크롤해 후반부 구간을 확인할 수 있으며, 별도로 구간을 선택하기 전까지 왼쪽의 구간 통계는 활동 전체를 기준으로 표시됩니다.

초기 상태에서 왼쪽의 **Average(평균)**, **Min(최소)**, **Max(최대)**는 전체 활동 수치입니다. 유효한 샘플이 없는 지표는 표시되지 않을 수 있으며, 스트림 중간에 비어 있는 구간은 차트에서 끊긴 선으로 나타납니다.

## 2. 특정 시점 탐색하기

마우스 포인터를 차트 위로 움직이면 같은 가로 위치에서 각 차트 안에 뜨는 지점 수치를 동시에 읽을 수 있습니다. GPS 데이터가 있으면 지도에 해당 지점의 위치도 함께 표시됩니다.

클릭하면 특정 위치를 고정할 수 있으며, 포인터가 차트 밖으로 벗어나면 임시 호버 수치는 숨겨집니다. 왼쪽의 구간 통계는 계속해서 전체 활동 또는 현재 선택된 구간에 고정됩니다.

타임라인의 위치 탐색 컨트롤에 포커스를 두고 좌우 화살표 키로 샘플을 이동하거나 **Home**, **End** 키로 시작과 끝 경계로 바로 이동할 수 있습니다. 포커스가 벗어나면 키보드 탐색 수치는 숨겨집니다.

| 질문 | 확인할 위치 |
| --- | --- |
| 이 순간에 기록된 수치는? | 각 차트 내부에 표시되는 지점(호버) 수치 |
| 이 구간 전반의 평균 수준은? | 왼쪽 구간 통계의 평균(Average) |
| 이 구간에서 기록된 유효 최저·최고치는? | 같은 범위의 최소(Min)와 최대(Max) |

## 3. 원하는 구간을 선택해 비교하기

기기가 기록한 랩을 선택하거나 원하는 범위를 직접 드래그해 지정할 수 있습니다.

1. 상단의 구간 헤더를 클릭하면 해당 구간이 강조되고 통계가 갱신됩니다. 같은 헤더를 한 번 더 클릭하면 선택이 해제됩니다.
2. 다른 범위를 보고 싶다면 차트 위를 가로로 드래그했다가 놓습니다. 모든 차트가 선택한 범위로 함께 확대됩니다.
3. 선택한 구간의 평균·최소·최대 값을 실제 차트 흐름과 비교하고, 포인터를 움직여 구간 내부의 개별 샘플을 확인합니다.
4. 위치 데이터가 있다면 지도에서 강조된 경로 구간을 확인해 해당 노력이 어떤 지형에서 이루어졌는지 파악합니다.

긴 지속주에서는 페이스나 파워가 일정하게 유지되는 동안 심박수가 변하는지(드리프트) 살펴보세요. 반복 인터벌에서는 질주 구간과 회복 구간이 원래 세션 의도에 맞았는지 비교하고, 지속 시간·지형·정지 구간·센서 데이터를 함께 고려해 패턴을 해석합니다.

## 4. 전체 활동으로 복귀하거나 가로축 변경하기

**Segments** 옆의 **Timeline options(타임라인 옵션)**를 열고 **Show full activity(전체 활동 보기)**를 선택하면 선택 범위가 해제되고 전체 차트 뷰로 돌아옵니다. 차트를 더블클릭하거나 타임라인에서 **Escape** 키를 눌러도 선택과 확대가 초기화됩니다.

같은 메뉴에서 **Horizontal axis(가로축)**를 **Time(시간)**과 **Distance(거리)** 사이에서 전환할 수 있습니다. 거리 모드는 유효한 누적 거리 기록이 있어야 하며, 축을 바꿔도 선택한 구간의 원래 시간 경계는 그대로 유지됩니다.

## 5. 차트 구성 맞춤 설정하기

**Pace**나 **Heart rate** 같은 지표 이름을 클릭하면 차트 설정이 열립니다. 여기서 표시할 지표, 선 색상, 차트 높이, 스무딩(평활화)을 바꿀 수 있으며, **Move up(위로 이동)**, **Move down(아래로 이동)**, **Remove chart(차트 제거)**로 차트 순서를 정리할 수 있습니다.

하단의 **Add chart(차트 추가)**를 사용하면 지원하는 다른 스트림을 추가할 수 있습니다. 원본 곡선과 스무딩 곡선을 나란히 비교하고 싶다면 같은 지표를 두 번 추가하는 것도 가능합니다. **Expand(확대)**는 개별 차트를 더 크게 펼쳐 보여 줍니다.

스무딩은 화면에 그려지는 곡선 형태에만 영향을 주며, 지점 수치와 구간 통계는 기록된 데이터 본연의 의미를 유지합니다. 차트 레이아웃은 현재 브라우저의 환경설정에 저장되며 원본 활동 데이터는 변경하지 않습니다.

## 6. 본인 계정에서 분석 구간 편집하기

기기가 기록한 랩과 다른 기준으로 구간을 나누어 분석하고 싶다면 **Edit segments(구간 편집)**를 사용합니다. 활동 편집 권한이 있는 본인 계정으로 로그인되어 있어야 합니다.

1. **Edit segments**를 열고 각 구간의 이름, 시작 시각, 종료 시각을 확인합니다.
2. 구간 이름을 바꾸거나 경계를 수정합니다. 필요한 경우 **Add segment in a gap(빈 구간에 추가)**, **Split in half(절반으로 나누기)**, **Merge next(다음 구간과 합치기)**, **Remove(삭제)**를 활용할 수 있습니다.
3. 모든 경계는 활동 전체 범위 안에 있어야 하며, 시작 시각이 종료 시각보다 빠르고 서로 겹치지 않아야 합니다.
4. **Save segments(구간 저장)**를 눌러 갱신된 구간 통계를 확인합니다. **Cancel(취소)**은 저장하지 않고 초안을 닫습니다.

분석 구간을 저장해도 원본 파일, 기기 랩, 활동 전체 훈련 부하는 그대로 유지됩니다. 경계를 수정한 구간은 기록된 시계열 스트림에서 해당 범위의 통계를 다시 계산합니다. **Restore device laps(기기 랩 복원)**를 누르면 편집기의 구간 정의가 원래 기기 랩 범위로 되돌아가며, 이후 저장할 수 있습니다.

다른 창에서 구간 정의가 이미 수정되었다면 편집기를 닫고 다시 열어 최신 버전을 불러온 뒤 편집하세요. 저장이 실패해도 작성 중인 초안은 유지되어 다시 시도할 수 있습니다. 공개 데모에서는 이 편집 기능이 비활성화되어 있습니다.

## 결과 확인

구간을 선택한 뒤 경계, 구간 통계, 지도 경로 구간이 모두 활동의 같은 부분을 가리키는지 확인하세요. 전체 활동 보기로 복원했을 때 통계가 전체 기준으로 돌아오는지 점검하고, 본인 계정에서 분석 구간을 저장했다면 활동을 다시 열어 정의가 유지되는지 확인합니다.

## 자주 묻는 질문

### 포인터를 움직여도 왼쪽 숫자가 바뀌지 않는 이유는?

왼쪽 수치는 전체 활동 또는 현재 선택된 구간 전체의 요약입니다. 포인터가 가리키는 단일 지점의 값은 각 차트 안에 뜨는 수치를 확인하세요.

### 차트에 빈 구간이나 대시(`-`)가 보이는 이유는?

스트림 누락, 샘플링 공백 또는 유효하지 않은 측정값 때문에 빈 구간이나 대시가 표시될 수 있습니다. 정지 상태에서 기록된 속도·케이던스·파워의 `0`은 유효한 값이지만, 멈춘 샘플에는 유효한 페이스가 없으며 누락된 심박수 샘플은 `0`으로 대체되지 않습니다.

### 경계를 수정한 뒤 랩 수치가 달라진 이유는?

수정하지 않은 기기 랩은 가져온 요약 값을 그대로 쓸 수 있지만, 수정하거나 직접 만든 분석 구간은 해당 범위의 유효 샘플로 통계를 다시 계산합니다. 데이터 누락 여부와 선택한 경계에 따라 결과가 달라집니다.

### 파워 값에 Estimated(추정치) 라벨이 붙어 있는 이유는?

해당 스트림이 파워미터 실측이 아닌 추정 파워이기 때문입니다. 파워미터 기록과 비교하거나 강도를 해석할 때 이 소스를 염두에 두세요.

### 선택한 구간이 경로 지도에서 강조되지 않는 이유는?

해당 시간대에 유효한 GPS 데이터가 없거나 지도를 불러오지 못했을 수 있습니다. 기록된 차트는 계속 살펴보고 지도 오류 상태는 별도로 확인하세요.

### 스마트폰에서는 왜 타임라인이 보이지 않나요?

이 타임라인 워크플로는 데스크톱 웹에서 제공됩니다. 모바일에서는 해당 앱과 종목이 지원하는 활동 상세 및 데이터 차트를 이용하거나 데스크톱에서 활동을 열어 보세요.

### 차트 로딩에 실패하면 어떻게 하나요?

화면에 제공되는 재시도 버튼을 사용하세요. 다른 정상 로드된 차트는 계속 사용할 수 있습니다. 새로고침이 실패한 경우 페이지가 이전 결과를 유지하면서 오류 상태를 함께 표시할 수 있으므로, 데이터 자체의 누락과 요청 실패를 구분해 확인하세요.
