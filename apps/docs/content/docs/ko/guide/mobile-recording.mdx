# 모바일 활동 기록

이 가이드를 따라가면 스마트폰으로 기록해 저장한 워크아웃이 Trainingload.ai 활동 기록에 정상적으로 표시되는 상태까지 마칠 수 있습니다.

## 시작하기 전에

- 웹과 동일한 계정으로 모바일 앱에 로그인합니다.
- 야외 GPS 기록을 위해 위치(Location) 권한을 허용합니다.
- 운동 중 화면을 잠글 계획이고 운영체제가 백그라운드 위치 권한을 제공한다면 허용해 둡니다.
- 기기가 백그라운드 앱을 강제로 절전·일시 중지한다면 Trainingload.ai의 과도한 배터리 제한을 해제합니다.
- 예정된 운동 시간 동안 스마트폰 배터리와 저장 공간이 충분한지 확인합니다.

## 1. 권한 확인

운동을 시작하기 전에 **Me → Menu → Data authorization**에서 위치 및 건강 데이터 권한을 확인합니다. 외부 플랫폼 권한과 스마트폰 GPS 권한은 별개이므로, 외부 플랫폼을 연동했다고 해서 스마트폰 위치 기록 권한까지 자동으로 허용되지는 않습니다.

## 2. 기록 화면 열기

**Today** 탭에서 예정된 워크아웃을 열어 종목과 구성을 확인한 뒤 **Start today's workout(오늘의 워크아웃 시작)**을 선택합니다. 진행 중인 플랜에서도 같은 워크아웃을 열 수 있습니다. 야외 훈련 전에는 위치 권한 상태를 다시 한 번 확인하세요.

## 3. 워크아웃 시작 및 모니터링

1. **Start today's workout**을 한 번 선택하고 준비 안내를 따른 뒤 카운트다운을 기다립니다.
2. 경과 시간이 정상적으로 증가하는지 확인합니다.
3. 야외 세션이라면 거리나 경로 데이터가 갱신되기 시작하는지 확인합니다.
4. 세션이 정상적으로 진행 중인 것을 확인한 뒤에 화면을 잠급니다.

앱이 일시 중지되었다가 다시 포그라운드로 돌아오면 활성 세션이 복원될 때까지 기다려 주세요. 복구가 진행되는 동안 두 번째 기록을 새로 시작하지 마세요.

## 4. 종료 및 저장

운동을 마친 뒤 다음 순서를 따릅니다.

1. 기록을 중지합니다.
2. 운동 시간, 거리, 종목이 맞는지 검토합니다.
3. 워크아웃을 저장합니다.
4. 업로드 또는 가져오기 전달이 완료될 때까지 앱의 네트워크 연결을 유지합니다.

모바일 앱은 세션 진행 중 기록 데이터를 로컬에 보관하며, 중단된 기록을 위한 복구 흐름을 제공합니다. 로컬 저장이 끝났다고 해서 서버의 모든 차트가 즉시 완성되는 것은 아니며, 업로드 완료 후 분석 처리가 이어서 진행됩니다.

## 결과 확인

**Me → Activities** 또는 해당 날짜의 캘린더를 열어 다음을 확인합니다.

- 해당 세션의 활동이 하나만 생성되었습니다.
- 시작 시각, 종목, 운동 시간, 거리가 실제와 부합합니다.
- GPS 워크아웃인 경우 지도가 표시됩니다.
- 센서 기반 차트는 기록에 해당 데이터가 포함된 경우에만 표시됩니다.
- 해당 활동을 예정된 워크아웃에 연결할 수 있습니다.

## 문제 해결

### 시간은 올라가는데 거리가 0으로 유지됩니다

위치 권한, GPS 수신 상태, 선택한 종목이 야외 거리 측정을 사용하는지 확인하세요. 탁 트인 야외 공간으로 이동해 위치 수신이 준비될 때까지 잠시 기다립니다.

### 화면을 잠그면 기록이 멈춥니다

백그라운드 위치 권한을 허용하고 앱의 배터리 최적화를 해제하세요. 운영체제 설정이 앱 내부 권한 설정보다 우선 적용될 수 있습니다.

### 활동이 두 번 표시됩니다

동기화가 대기 중일 때 로컬에 기록된 파일을 별도로 다시 업로드하지 마세요. 시작 시각과 운동 시간을 비교한 뒤 중복이 확실한 사본 하나만 삭제합니다.

### 활동은 생성되었는데 차트가 비어 있습니다

분석 처리가 끝날 때까지 기다린 뒤 새로고침하세요. 심박수, 파워, 케이던스가 보이지 않는 것은 애초에 기록에 해당 스트림이 포함되지 않았기 때문일 수도 있습니다.
