# 알림 및 자동 리뷰

알림을 통해 활동 가져오기 결과와 완료된 리뷰를 빠르게 확인할 수 있습니다. 리뷰 자동화를 켜 두면 조건을 충족하는 일간, 주간 또는 월간 리뷰를 매번 직접 요청하지 않아도 자동으로 생성받을 수 있습니다.

## 자동화를 켜기 전에

- 일간·주간·월간 날짜 경계가 정확하도록 계정 시간대를 올바르게 설정합니다.
- 활동을 꾸준히 가져오고 진행 중인 훈련 플랜을 최신 상태로 유지합니다.
- 플랜 실행 내용까지 리뷰에 반영하려면 완료된 활동을 예정 워크아웃에 연결해 둡니다.
- 계정 이용 권한과 AI 사용 가능 크레딧을 확인합니다.

## 알림 유형

알림에는 일반 시스템 메시지, 연속 훈련 플랜 업데이트, 완료된 훈련 리뷰가 포함될 수 있습니다. 가져오기 대화상자에서도 백그라운드 배치가 끝나면 알림으로 안내되므로, 완료될 때까지 창을 계속 열어 둘 필요가 없습니다.

알림 화면에서 할 수 있는 작업:

- 관련 리뷰 또는 대상 화면 열기
- 개별 알림 읽음 표시
- 모든 알림 일괄 읽음 표시

알림을 읽음 처리해도 연결된 활동, 플랜 또는 AI 코치 세션은 삭제되지 않습니다.

## 훈련 리뷰 읽기

일간 리뷰는 전날의 활동을 정리하고, 주간 리뷰는 직전 완료된 한 주를 종목별로 요약하며, 월간 리뷰는 직전 완료된 달력 월을 주차별로 묶어 보여 줍니다. 지원되는 경우 코치 인사이트에서 잘된 점, 주의할 점, 다음 기간에 집중할 한 가지 포인트를 짚어 줍니다. 인용된 활동을 클릭하면 원본 기록으로 바로 이동해 확인할 수 있습니다.

주간 리뷰에는 훈련 일수, 평균 세션 시간, 그리고 산출 가능한 경우 훈련 부하가 함께 표시됩니다. 같은 날 여러 세션을 수행했더라도 훈련 일수는 하루로 계산됩니다.

수면 시간, HRV, 안정시 심박수 기록이 있으면 함께 표시됩니다. 일간 리뷰는 다음 날의 회복 기록과 계산 가능한 최근 기준선(baseline)을 활용하며, 주간·월간 리뷰는 기록된 일수를 표시하고 비교 가능한 수치가 있을 때 이전 기간과 비교해 줍니다.

웹에서는 두 기간을 쌍 막대 차트로 비교해 보여 줍니다. 표에는 원래 수치가 유지되며, 이전 기간 값이 0보다 클 때 세션 횟수, 운동 시간, 비교 가능한 회복 지표의 증감률이 함께 표시됩니다.

## 리뷰 자동화 설정하기

웹에서는 **Account → AI Review Automation**, 모바일에서는 계정의 자동 리뷰 설정 패널을 엽니다.

제공되는 스위치 항목:

- 활동 리뷰(Activity review)
- 일간 리뷰(Daily review)
- 주간 리뷰(Weekly review)
- 월간 리뷰(Monthly review)
- 플랜 리뷰(Plan review)

자동화 제공 여부는 계정 권한과 AI 사용 한도에 따라 달라집니다. 스위치를 켜는 것은 해당 유형의 자동 리뷰를 허용한다는 뜻이며, 필요한 활동이나 플랜 데이터가 없을 때에도 유의미한 결과를 보장하지는 않습니다.

## 리뷰에 훈련 기록이 제대로 반영되도록 준비하기

자동 리뷰를 활용하기 전에 다음을 점검하세요.

1. 일간·주간 경계 기준이 되는 시간대를 확인합니다.
2. 완료된 활동을 꾸준히 가져옵니다.
3. 진행 중인 플랜을 최신 상태로 유지합니다.
4. 완료된 활동을 예정된 워크아웃에 연결합니다.
5. 필요할 때 세션 RPE나 현재 상태 맥락을 입력합니다.

## 수동으로 리뷰 실행하기

제품에서 수동 리뷰 실행 제어가 제공되는 경우, 자동화 일정을 바꾸지 않고도 직전 완료된 하루·한 주·한 달에 대한 리뷰를 직접 요청할 수 있습니다. 리뷰 작업은 백그라운드에서 실행되므로 완료될 때까지 같은 요청을 중복 제출하지 말고 기다려 주세요.

## 정상 동작 확인

- 설정을 다시 열어도 저장한 스위치가 켜진 상태로 유지됩니다.
- 리뷰가 완료되면 알림이나 코치 목록에 새 항목이 생성됩니다.
- 알림을 열면 해당하는 리뷰 화면으로 이동합니다.
- 리뷰가 올바른 기간, 플랜 또는 활동을 참조하고 있습니다.

## 문제 해결

리뷰가 생성되지 않으면 계정 권한, AI 사용량, 시간대, 데이터 유무, 백그라운드 작업 진행 여부를 확인하세요. 구조화 작업 오류가 발생했다면 [문제 해결](/ko/docs/guide/troubleshooting)을 참고하세요.

리뷰를 다시 요청한다고 누락된 활동이 채워지지는 않으며 불필요한 AI 사용량만 소비될 수 있습니다. 먼저 활동이 정상적으로 가져와지고 처리되었는지 확인하고, 이미 리뷰가 생성 중이라면 결과가 나올 때까지 기다려 주세요.
