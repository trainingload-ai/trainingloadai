# 퍼포먼스 분석 페이지 안내

**Analysis(분석)**를 열어 파워(Power), 심박수(Heart Rate), 페이스(Pace), PMC 등 다양한 퍼포먼스 및 훈련 부하 뷰를 선택할 수 있습니다. 아래 질문 표를 참고해 지금 필요한 페이지를 찾아보세요.

## 시작하기 전에

- 분석할 활동이 모두 준비 완료(Ready) 상태가 될 때까지 기다립니다.
- 존 분포를 해석하기 전에 프로필 역치와 종목별 존 설정을 확인합니다.
- 하나의 종목과 하나의 의사결정 기간을 정합니다.
- 해당 페이지에 필요한 센서 데이터(파워, 심박수 또는 유효한 거리·시간)가 활동에 포함되어 있는지 확인합니다.
- 여러 페이지를 넘나들며 수치를 비교할 때는 동일한 단위 체계와 시간대를 유지합니다.

## 1. 분석 허브에서 페이지 선택하기

**Analysis(분석)**를 열고 도구를 검색하거나 선택합니다.

| 질문 | 페이지 | 제공하는 정보 |
| --- | --- | --- |
| 얼마나 자주, 얼마나 많이 훈련했는가? | Activity Stats(활동 통계) | 연간 히트맵 및 거리·시간·심박수·횟수·칼로리 추세 |
| 최근 훈련 부하가 어떻게 변했는가? | PMC | CTL, ATL, TSB 훈련 부하 맥락 |
| 구간별 최고 지속 기록은 어떠한가? | Best Distance(구간 최고 기록) | 고정 거리 또는 고정 시간 기준 순위 기록 |
| 파워 기량이 어떻게 변했는가? | Power(파워) | 파워 커브, 최대 파워, 존 분포, 파워 프로필 |
| 특정 종목의 페이스가 어떻게 변했는가? | Pace(페이스) | 페이스 커브 및 페이스 존 분포 |
| 심박수 지속 기록과 존 체류 시간은 어떠한가? | Heart Rate(심박수) | 심박수 커브 및 심박수 존 분포 |

**Progression** 카드에는 **Coming soon(출시 예정)** 표시가 붙어 있습니다. 현재 사용 가능한 리포트로 오해하거나 기존 페이지에서 이미 확인할 수 있는 질문을 위해 기다리지 마세요.

## 2. 차트를 읽기 전에 필터부터 고정하기

Power, Pace, Heart Rate 페이지에서는 종목과 날짜 범위를 먼저 지정하고, 탭을 이동하며 비교하는 동안 필터를 동일하게 유지하세요.

- 현재 상태를 확인할 때는 단일 기간을 사용합니다.
- 페이지가 지원하고 명확한 비교 목적이 있을 때만 여러 기간을 추가합니다.
- Pace는 특정 종목을 선택해야 하며 전체 종목 통합 뷰를 제공하지 않습니다.
- Power와 Heart Rate는 전체 종목을 포함할 수 있지만, 여러 종목이 섞이면 해석이 어려워질 수 있습니다.
- 차트가 비어 있다면 선택한 기간 안에 조건을 충족하는 센서 데이터가 없는 경우가 많습니다.

결과를 비교할 때는 종목, 지속 시간, 날짜 범위를 함께 기록해 두세요. 예를 들어 단일 최고치 하나에 의존하기보다 최근 90일과 직전 90일의 사이클링 5분 파워를 비교하는 편이 훨씬 유의미합니다.

## 3. 파워(Power) 탭 활용하기

Power 페이지는 네 가지 뷰로 구성됩니다.

- **Curve(커브)**: 지속 시간별 최고 지속 파워 표와 차트(복수 기간 비교 지원)
- **Maximum(최대 파워)**: 선택한 맥락의 최대 파워 기록
- **Zones(존)**: 설정된 파워 존별 작업량 분포(복수 기간 비교 지원)
- **Profile(프로필)**: 선택한 종목과 기간의 파워 프로필 맥락

지속 시간별 기량은 Curve, 강도 분포는 Zones, 전반적 위치 파악은 Profile로 확인하세요. 각각 서로 다른 질문에 답하므로 하나의 "체력 점수"로 단순화해 해석하지 않는 것이 좋습니다.

## 4. 페이스(Pace)와 심박수(Heart Rate) 활용하기

Pace 페이지 구성:

- **Curve(커브)**: 거리별 페이스 퍼포먼스 표와 차트
- **Zones(존)**: 설정된 페이스 존별 시간 또는 작업량 분포

필터에서 제공하는 러닝, 사이클링, 수영 중 하나를 선택합니다. 수영 페이스는 수영 전용 거리 기준을, 러닝과 사이클링은 각 종목의 표시 단위를 사용하므로 서로 다른 종목의 원시 페이스 수치를 직접 비교하지 마세요.

Heart Rate 페이지 구성:

- **Curve(커브)**: 지속 심박수 표와 차트
- **Zones(존)**: 설정된 심박수 존 분포

심박수는 출력이 아니라 신체의 '반응 신호'입니다. 높은 수치가 무조건 더 좋다고 보지 말고 지속 시간, 페이스 또는 파워, 환경 조건, 피로도, 센서 품질과 함께 해석하세요.

## 5. PMC로 훈련 부하 맥락 더하기

누적된 훈련 압력을 확인할 때는 **PMC / Fitness management**를 엽니다. 종목을 고르고 현재 CTL, ATL, TSB 카드를 함께 읽은 뒤 차트를 Form(컨디션), Fitness(체력), Fatigue(피로) 사이에서 전환해 보세요. 하단의 일간 부하 패널과 날짜 툴팁이 특정 지점의 변화를 설명해 줍니다.

이 페이지는 기록된 과거 이력과 조건부 미래 예측을 명확히 구분합니다. 미래 날짜 수치를 해석하기 전에 해당 날짜의 부하 산출 근거를 먼저 읽어야 하며, 예측이 비어 있다고 부하가 0이라는 뜻은 아닙니다. 전체 워크플로, 데이터 요건, 대시보드 히스토리 탭 안내는 [PMC 기록 및 예측 읽기](/ko/docs/guide/pmc-forecast)를 참고하세요.

기량 반응 추세와 별도의 4주 전망은 [지구력 훈련에서 유효 VO2max 이해하기](/ko/docs/guide/effective-vo2max-for-endurance)를 살펴보고, 이 근거를 플랜 리뷰와 연결하려면 [훈련 분석 워크플로](/ko/docs/guide/training-analysis-workflow)로 이어가세요.

## 6. 분석 결과를 원본 활동으로 거슬러 확인하기

커브의 특정 지점, 존 분포 또는 부하 변화가 눈에 띄면 다음 순서로 검증합니다.

1. 종목, 날짜 범위, 탭, 지속 시간, 수치를 메모합니다.
2. 해당 활동을 열거나 활동 검색으로 원인이 된 세션을 찾습니다.
3. 처리 상태, 센서 포함 범위, 역치, 명백한 스파이크나 신호 끊김 여부를 확인합니다.
4. 관측된 사실과 본인의 해석을 분리합니다.
5. 근거가 뒷받침하는 가장 작은 단위의 의사결정을 내립니다.

## 분석 검증 체크리스트

- 선택한 페이지가 확인하려는 질문에 부합합니다.
- 종목, 기간, 단위, 존 설정을 함께 기록했습니다.
- 조건을 충족하는 준비 완료(Ready) 활동이 결과를 뒷받침합니다.
- 센서 공백이나 이상치를 평균에 묻어 두지 않고 명시했습니다.
- 모든 훈련 결정이 기반 활동과 플랜 맥락으로 추적 가능합니다.

## 문제 해결

- **분석 도구 검색 결과가 없음:** 검색어를 지우세요. 도구 검색은 현재 언어의 제목과 설명을 기준으로 일치시킵니다.
- **카드를 열 수 없음:** 출시 예정(Coming soon) 표시가 붙은 카드인지 확인하세요.
- **커브나 존 차트가 비어 있음:** 기간을 넓히고 올바른 종목을 선택했으며 대상 활동에 필요한 센서 스트림이 포함되어 있는지 확인합니다.
- **역치 수정 후 수치가 바뀜:** 존 분포와 파생 맥락이 달라질 수 있으므로 과거 기록과 비교하기 전에 변경된 설정을 기록해 두세요.
- **파워, 페이스, 심박수가 서로 다른 이야기를 함:** 각 지표는 서로 다른 입력과 생리적 반응을 측정합니다. 유리해 보이는 차트 하나만 고르지 말고 질문, 원본 세션, 당시 환경을 다시 점검하세요.
- **전체 종목 결과가 일관되지 않음:** 단일 종목으로 전환해 다시 비교하세요.
