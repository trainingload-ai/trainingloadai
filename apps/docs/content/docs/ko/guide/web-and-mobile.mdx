# 웹과 모바일 연동

Cloud 웹 앱과 iPhone 앱은 같은 계정을 공유합니다. 저장과 동기화가 완료되면 다른 기기에서도 훈련 플랜, 활동, 프로필 값, AI 코치 대화, 알림을 그대로 이어서 볼 수 있습니다.

이 문서는 Cloud 환경을 기준으로 합니다. 셀프 호스팅 환경이라면 [설치 가이드](/ko/docs/self-host/installation)에 따라 브라우저에서 앱에 접속하세요. Apple Watch 앱은 현재 지원하지 않습니다.

## 기기를 전환하기 전에

- 두 기기 모두 동일한 Trainingload.ai 계정으로 로그인합니다.
- 프로필에서 시간대와 단위를 확인합니다. 캘린더 날짜와 표시 값이 이 설정에 따라 결정됩니다.
- 다른 기기에서 같은 플랜이나 프로필 항목을 열기 전에 현재 편집 중인 내용을 먼저 저장합니다.
- 플랜, AI 코치, 가져오기, 분석 처리 결과를 불러오려면 네트워크 연결이 필요합니다.

## 웹 앱이 유리한 작업

- 여러 주에 걸친 훈련 플랜을 작성하거나 전체적으로 검토할 때
- 구조화된 지구력 또는 근력 워크아웃을 세밀하게 편집할 때
- 상세 차트, 지도, 파워, 페이스, 심박수, PMC 추세를 비교 분석할 때
- 외부 플랫폼 연동과 과거 기록 가져오기를 관리할 때
- 방대한 활동 피드를 리뷰하거나 예전 훈련 기록을 검색할 때

## 모바일 앱이 유리한 작업

- 훈련 당일 Today, Calendar, Coach, Plan, Me 화면을 수시로 확인할 때
- 스마트폰으로 야외 워크아웃을 직접 기록할 때
- 저장 직후 완료된 세션을 빠르게 리뷰할 때
- 완료된 활동을 예정된 워크아웃에 바로 연결할 때
- 데스크톱이 없는 곳에서 현재 상태를 업데이트하거나 알림을 확인하고 플랜을 실행할 때

## 동기화되는 항목

| 데이터 | 웹 | 모바일 | 비고 |
| --- | --- | --- | --- |
| 프로필, 단위, 시간대 | 조회 및 편집 | 조회 및 편집 | 캘린더 날짜는 시간대 설정에 따릅니다. |
| 활동 및 분석 | 전체 상세 보기 | 일일 및 상세 보기 | 활동이 먼저 표시된 뒤 분석 처리가 완료될 수 있습니다. |
| 플랜 및 워크아웃 | 전체 생성 및 편집 | 조회, 생성, 실행 및 연결 | 복잡한 편집은 보통 웹이 더 편리합니다. |
| AI 코치 | 세션 및 작업 | 세션 및 작업 | 적용된 변경 사항은 동일한 플랜에 반영됩니다. |
| 알림 및 리뷰 | 지원 | 지원 | 리뷰 자동화는 계정 환경설정을 따릅니다. |
| 외부 플랫폼 연동 | 전체 관리 | 일부 연동 및 권한 흐름 | 지원 범위는 플랫폼과 운영체제에 따라 다릅니다. |

## 새로고침 및 충돌 처리 규칙

두 기기에서 같은 플랜이나 프로필 항목을 수정하면 가장 마지막에 성공적으로 저장된 값이 기준이 됩니다. 두 번째 편집을 시작하기 전에 다음 순서를 따르세요.

1. 목록 또는 상세 화면으로 돌아갑니다.
2. 모바일에서는 아래로 당겨 새로고침하고, 웹에서는 페이지를 새로고침하거나 데이터를 다시 불러옵니다.
3. 최신 값이 표시되는지 확인합니다.
4. 다음 변경 사항을 적용합니다.

다른 요청이 같은 기록을 먼저 수정했다면 플랜 업데이트 시 이전 버전의 편집이 거부될 수 있습니다. 오래된 버전을 반복 저장하려 하지 말고 플랜을 새로고침한 뒤 의도한 변경을 다시 적용하세요.

## 다른 기기에서 작업 이어가기

1. 첫 번째 기기에서 현재 작업을 마치고 저장합니다.
2. 두 번째 기기에서 해당하는 목록 또는 상세 화면을 엽니다.
3. 모바일은 당겨서 새로고침, 웹은 새로고침/재조회를 실행합니다.
4. 방금 수정한 활동 타임스탬프, 플랜 버전 또는 프로필 값이 반영되었는지 확인합니다.
5. 서버의 최신 값이 표시된 것을 확인한 뒤 이어서 편집합니다.

## 오프라인 동작 기준

모바일 활동 기록은 진행 중인 데이터를 로컬에 안전하게 보관하고, 가능한 경우 중단된 세션을 복구하도록 설계되어 있습니다. 다만 서버에 저장된 최신 플랜, AI 응답, 처리된 분석 결과를 불러오려면 네트워크 연결이 필요합니다.

네트워크에 다시 연결된 뒤에는 다음을 확인하세요.

- 기록이나 가져오기의 업로드가 완료될 때까지 기다립니다.
- 같은 워크아웃을 중복 업로드하지 않습니다.
- 활동(Activities) 목록에 해당 활동이 한 번만 표시되는지 확인합니다.
- 활동을 열었을 때 분석이 아직 처리 중이면 잠시 기다립니다.

## 동기화 정상 여부 확인

- 두 환경에서 동일한 프로필 단위와 시간대가 표시됩니다.
- 완료된 활동이 동일한 시작 시각과 소스로 한 번만 표시됩니다.
- 진행 중인 플랜과 예정된 워크아웃에 동일한 상태와 최신 수정 내용이 반영되어 있습니다.
- 한쪽에서 적용한 AI 코치 작업이 다른 쪽의 플랜에도 반영됩니다.
- 알림과 완료된 리뷰가 새로고침 후 다시 읽지 않음 상태로 돌아가지 않습니다.

## 문제 해결

### 한쪽 기기에 예전 데이터가 보입니다

목록이나 상세 화면으로 돌아가 새로고침하세요. 네트워크 연결 상태와 두 기기가 같은 계정으로 로그인되어 있는지 확인하고, 최신 서버 값이 보이기 전에는 오래된 화면에서 편집하지 마세요.

### 플랜 편집 시 버전 충돌 오류가 발생합니다

다른 요청이 플랜을 먼저 변경한 상태입니다. 플랜을 새로 불러온 뒤 현재 워크아웃과 의도한 변경 내용을 비교하고 새 버전에 다시 적용하세요.

### 모바일에서 기록한 활동이 웹에 보이지 않습니다

업로드가 완료될 때까지 모바일 앱을 유지한 뒤 웹의 활동(Activities) 페이지를 새로고침하세요. 활동은 보이지만 차트가 불완전하다면 아직 처리 중이므로 중복 업로드를 하지 마세요.

### 웹과 모바일의 플랫폼 연동 설정이 다릅니다

전체 연동 관리는 웹의 **Account → Third Party Connections**를 이용하세요. 모바일에서는 일부 인증이나 권한 흐름만 제공될 수 있습니다.

### 캘린더 날짜가 서로 다릅니다

두 기기의 계정 시간대 설정과 활동에 기록된 시작 시각을 비교해 보세요. 워크아웃을 이동하거나 새로 만들기 전에 프로필 시간대 설정부터 바로잡아야 합니다.
