# 훈련 부하 관리를 위한 Intervals.icu 대안

이미 Intervals.icu로 훈련을 분석하고 있다면, 기존 도구를 완전히 대체할지 아니면 분석 워크플로는 유지하면서 훈련 계획과 리뷰용으로 Trainingload.ai를 함께 시험해 볼지 먼저 방향을 정하는 것이 좋습니다.

Intervals.icu는 활동 타임라인, 파워·심박수 차트, 인터벌 분석, 사용자 지정 차트 등을 제공합니다. 최신 기능은 Intervals.icu의 [활동 분석 개요](https://www.intervals.icu/features/analyze/)에서 확인할 수 있습니다.

## Trainingload.ai에서 직접 해 볼 작업

- 완료된 활동을 예정된 워크아웃에 연결해 원래 일정과 실제 수행 결과를 비교합니다.
- 활동 타임라인, PMC, 퍼포먼스 추세를 훈련 플랜과 함께 살펴봅니다.
- 활동 상세나 플랜 화면에서 AI 코치를 열어 답변을 검토하거나 워크아웃 변경 제안을 미리 확인합니다.

[활동 상세 분석](/ko/docs/guide/activity-detail), [타임라인](/ko/docs/guide/activity-timeline), [플랜 상태 관리](/ko/docs/planning/plan-lifecycle)부터 시작해 평소 실제로 자주 수행하는 훈련 작업을 기준으로 비교해 보세요.

## Intervals.icu 기록 연동하기

1. Cloud 환경이라면 [플랫폼 연동 가이드](/ko/docs/guide/connect-third-party-platforms#connect-intervalsicu)를, 셀프 호스팅 환경이라면 [API 키 설정 안내](/ko/docs/self-host/configuration#connect-intervalsicu)를 따릅니다.
2. 필요한 동기화 방향을 선택합니다. 두 플랫폼이 같은 일정을 동시에 수정하도록 허용하기 전에 어느 쪽에서 훈련 존과 플랜을 관리할지 기준을 정해 두세요.
3. 잘 알고 있는 활동 하나를 동기화해 날짜, 시간, 소스, 센서 데이터가 제대로 들어왔는지 확인합니다.
4. [훈련 캘린더](/ko/docs/guide/calendar)에서 해당 활동을 워크아웃에 연결한 뒤 예상 부하와 실제 부하를 비교합니다.

## 분석 결과 비교 시 유의사항

같은 활동이라도 플랫폼마다 훈련 부하 수치나 존 분포가 다르게 나올 수 있습니다. 차이를 해석하기 전에 원본 기록, 역치 설정, 부하 소스 설정을 먼저 비교해 보세요. 활동을 연동한다고 해서 Intervals.icu의 모든 사용자 지정 차트, 커스텀 필드, 플랜이 자동으로 복사되지는 않습니다.

활동 가져오기부터 워크아웃 연결, 리뷰까지 한 사이클을 직접 시험해 보는 동안에는 두 플랫폼을 함께 유지한 뒤 본인에게 가장 잘 맞는 구성을 선택하세요. 인터페이스를 먼저 살펴보고 싶다면 [데모 열기](https://demo.trainingload.ai/en)를 이용해 보세요.
