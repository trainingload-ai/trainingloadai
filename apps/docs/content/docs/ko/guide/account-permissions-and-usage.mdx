# 계정, 권한, 데이터 내보내기 및 AI 사용량

계정 설정은 신원과 접근 권한을 관리하고, 권한 설정은 어떤 기기와 외부 플랫폼의 데이터가 Trainingload.ai로 들어올 수 있는지 제어하며, 사용량 화면은 멤버십과 AI 소비 내역을 보여 줍니다. 새 기기를 설정하거나 특정 기능이 보이지 않을 때 이 항목들을 함께 점검하세요.

이 문서는 Cloud 계정을 기준으로 합니다. 셀프 호스팅 환경은 로컬 개인 계정을 사용하므로 [셀프 호스팅 설정](/ko/docs/self-host/configuration)을 참고하세요.

## 시작하기 전에

- 웹과 모바일에서 동일한 Trainingload.ai 계정으로 로그인합니다.
- 인증 코드를 받을 수 있도록 계정 이메일에 접근 가능한 상태를 유지합니다.
- 모바일에서 운영체제가 건강(Health) 또는 위치(Location) 접근 권한을 이미 거부했는지 미리 확인합니다.
- 자동 업데이트 스위치를 켜기 전에 어떤 역치를 자동으로 갱신할지 결정합니다.
- 인증 코드, 비밀번호, 연동 자격 증명, 개인 계정 식별자가 포함된 스크린샷은 절대 공유하지 않습니다.

## 1. 계정 신원 및 비밀번호 상태 확인

웹에서는 **Account(계정)**를, 모바일에서는 **Me → Menu → Account**를 엽니다.

확인할 수 있는 항목:

- 표시 이름(Display name)
- 계정 이메일 및 인증 상태
- 비밀번호 설정 여부

현재 이메일 입력란은 읽기 전용입니다. 아직 인증되지 않은 계정이라면 6자리 인증 코드를 요청해 만료 전에 입력합니다. 웹에서는 발송된 코드가 5분간 유효하며 카운트다운이 진행 중일 때는 재발송할 수 없습니다.

비밀번호가 설정되어 있지 않으면 **Set password(비밀번호 설정)**, 이미 있다면 **Change password(비밀번호 변경)**를 사용합니다. OAuth로 가입한 계정은 비밀번호가 미설정 상태로 표시될 수 있으며, 이는 계정 오류가 아니므로 화면의 비밀번호 설정 버튼을 이용하면 됩니다.

### 계정 접근 복구 및 로그인 완료

로그인 페이지에서 **Forgot password(비밀번호 찾기)**를 눌러 재설정 이메일을 요청합니다. 가장 최근에 받은 재설정 링크만 열고, Trainingload.ai 재설정 화면으로 정상 연결되는지 확인한 뒤 새 비밀번호를 설정하세요. 만료되었거나 손상되었거나 이미 사용한 토큰은 새 재설정 요청으로 교체해야 합니다.

OAuth 로그인은 앱으로 돌아오기 전 완료 또는 오류 화면을 거칠 수 있습니다. 완료 화면에서 자동 이동되지 않으면 로그인 페이지로 돌아가 한 번만 다시 시도하고, 오류 페이지가 표시되면 토큰이나 전체 콜백 URL을 노출하지 않고 화면의 오류 문구만 기록해 두세요.

다른 애플리케이션이 Trainingload.ai 접근을 요청할 때는 OAuth 동의 페이지에 요청 앱, 로그인 계정, 요청 범위(scopes), 반환 대상 주소가 표시됩니다. 네 가지가 모두 의도한 내용과 일치할 때만 승인하세요. 거절하면 요청한 권한을 부여하지 않고 제어권이 돌아옵니다.

## 2. 모바일 권한 및 데이터 소스 확인 [#2-review-mobile-permissions-and-data-sources]

모바일에서 **Me → Menu → Data authorization** 또는 **Permissions** 페이지를 엽니다. 데이터 소스는 로컬 기기 소스와 서드파티 서비스로 나뉩니다.

로컬 기기 소스:

- **Health(건강)**: 지원하는 건강 및 워크아웃 읽기 권한을 승인하고, 전체 승인 또는 부분 승인 상태를 확인하며, 과거 기록 동기화를 요청하거나 연결된 기기를 관리하고 시스템 건강 설정을 엽니다.
- **Location(위치)**: 경로 기록 권한을 허용하거나, 권한이 거부된 경우 시스템 설정을 엽니다.

서드파티 소스에는 Strava, Polar, COROS, Suunto, Wahoo, Intervals.icu 등이 포함될 수 있습니다. 각 소스 행에 현재 상태가 표시되며, 항목을 열면 연동 진행, 플랫폼별 설정 확인 또는 연동 페이지 이동이 가능합니다.

기기 권한과 서버 연동은 서로 다른 상태입니다. 운영체제에서 건강(Health) 권한을 허용했더라도 Trainingload.ai 기기 연동은 다시 연결해야 할 수 있습니다. 시스템 설정에서 돌아온 뒤 소스 상세 화면을 다시 열어 앱이 두 상태를 모두 새로고침하도록 하세요.

## 3. 자동 지표 업데이트 제어

웹이나 모바일에서 **Account → Auto update**를 엽니다. 각 스위치는 개별 지표의 자동 업데이트 허용 여부를 제어합니다.

| 그룹 | 지표 |
| --- | --- |
| 파워 | FTP, CP, W′, Pmax |
| 페이스 | TP, CS |
| 심박수 | LTHR, Max HR |

충분한 근거가 쌓였을 때 Trainingload.ai가 자동으로 갱신해도 좋은 지표만 켜 두세요. 스위치를 켠다고 즉시 새 값이 계산되는 것은 아니며, 시스템이 지원하는 활동 데이터가 충분히 쌓여야 반영됩니다.

자동 업데이트는 존, 차트, 구조화 워크아웃, 훈련 부하 해석에 쓰이는 역치를 바꿀 수 있습니다. 업데이트 이후에는 지표 히스토리를 확인하고 최근 활동을 먼저 리뷰한 뒤 이전 기간과 새 기간을 비교하세요.

## 4. 멤버십 및 AI 사용량 리뷰

계정의 멤버십 카드에서는 다음 정보를 확인할 수 있습니다.

- 현재 요금제 및 활성 상태
- 멤버십 기간 또는 만료 안내
- 결제 수단(결제 제공자)
- 기간 종료 시 해지 예약 여부

지원하는 구독 결제 제공자의 활성 구독에서만 앱 내 구독 관리 버튼이 표시됩니다. 다른 경로의 이용 권한은 멤버십 상태만 표시되고 동일한 관리 제어는 보이지 않을 수 있습니다.

멤버십 카드 또는 모바일 계정 영역에서 **Usage(사용량)**를 열면 다음 내용을 확인할 수 있습니다.

- 현재 요금제
- 사용 가능 크레딧(직전 완료 작업이 기존 잔액을 초과한 경우 마이너스 잔액 포함)
- 월간 구독 크레딧 사용량, 잔여량, 만료일
- 사용 가능하거나 멤버십에 잠겨 있는 크레딧 팩 잔액 및 가장 빠른 만료일
- 미정산 부채, 소비 추세, 작업 횟수 및 개별 원장(ledger) 내역

기간은 1일, 7일, 30일, 이번 달 누적, 지난 달 중에서 선택할 수 있습니다. 원장 항목에는 Standard(1×), Deep(3×), 혼합 모드 작업, 구독 지급, 크레딧 팩, 선물, 환불, 부채 상계가 구분되어 표시됩니다. 1크레딧은 캐시 입력, 비캐시 입력, 출력, 모드, 전역 배수를 모두 반영한 환산 토큰 1,000개에 해당하며, 고정된 메시지 횟수가 아닙니다.

## 5. 앱 환경설정 지정

웹에서 **Settings(설정)**를 열면 다음 항목을 설정할 수 있습니다.

- 라이트, 다크 또는 시스템 테마
- 미터법 또는 야드·파운드법 단위
- 차트 X축 동작 방식
- 12시간제 또는 24시간제 시간 표시
- 선호 인터페이스 언어

이 설정은 **Save(저장)**를 누르기 전까지 임시 상태로 유지됩니다. 언어를 변경하면 현재 경로도 선택한 로케일로 이동하며 이후 방문 시에도 선호 언어가 유지됩니다. 단위와 시간 형식은 화면 표시만 바꾸며 원본 활동 기록을 덮어쓰지 않습니다.

## 6. 계정 데이터 내보내기

웹에서 **Account → Data export**를 열고 다음 작업에 맞는 내보내기 옵션을 선택합니다.

- **AI analysis(AI 분석용)**: 분석 중심의 경량 패키지를 생성하며, 원본 업로드 파일은 포함하지 않습니다.
- **Full backup(전체 백업)**: 더 넓은 범위의 아카이브를 생성하며, 정확한 위치 데이터를 유지할 때 원본 파일도 포함할 수 있습니다.

내보내기를 요청하기 전에 경로 위치 정보 처리 방식을 선택합니다.

- 자주 방문하는 위치 마스킹(redact)
- GPS 데이터 제거
- 정확한 위치 유지

원본 파일을 포함하면 파일 자체에 위치 데이터가 들어 있을 수 있으므로 정확한 위치 유지가 강제됩니다. 정확한 위치가 포함된 내보내기 파일은 민감한 개인정보로 취급하고, 아카이브 내용을 정확히 이해한 경우가 아니라면 AI 서비스에 업로드하거나 타인과 공유하지 마세요.

내보내기 생성은 비동기로 진행됩니다. 페이지를 열어 두거나 나중에 돌아와 최신 작업을 새로고침한 뒤 상태가 **Ready(준비 완료)**가 되었을 때 다운로드합니다. 페이지에 아카이브 크기와 만료 시각이 표시되며, 준비 완료·실패·만료된 내보내기 작업은 목록에서 삭제할 수 있습니다.

## 7. 안전한 계정 삭제

계정 삭제는 영구적이며 비동기로 처리됩니다. 모바일에서 삭제를 시작하기 전에 다음 순서를 따르세요.

1. 보관해야 할 데이터를 먼저 내보냅니다.
2. 화면에 표시된 멤버십과 결제 제공자를 확인합니다.
3. 절차에서 요구할 경우 자동 갱신을 먼저 해지합니다.
4. 마지막 안내 및 동의 항목을 모두 읽고 선택합니다.
5. 삭제 요청을 제출하고 접수 완료 화면이 나올 때까지 화면을 닫지 않습니다.

요청이 접수되면 계정이 로그아웃되고 활성 접근 권한이 제거되며 백그라운드에서 삭제가 이어집니다. 완료는 보통 24시간 이내이며 최대 7일까지 걸릴 수 있습니다. 접수 완료 화면에서 로그인 화면으로 이동하더라도 기존 계정을 복구할 수는 없습니다.

구독 처리는 활성 결제 제공자에 따라 다릅니다. 웹 결제는 삭제를 진행하기 전에 갱신 해지가 필요할 수 있으며, Apple 결제는 Apple에서 별도로 관리되므로 Trainingload.ai 계정을 삭제하더라도 Apple 측에서 따로 해지하지 않으면 갱신이 계속될 수 있습니다. 계정 삭제 자체가 환불을 보장하지 않으며, 나중에 다시 구독해도 삭제된 데이터는 복원되지 않습니다.

## 8. 기기 간 설정 동기화 확인

계정, 연동, 권한 또는 자동 업데이트 설정을 변경한 뒤에는 다음을 확인합니다.

1. 현재 기기에서 변경을 저장하거나 완료합니다.
2. 소스 목록으로 돌아가 표시 상태를 확인합니다.
3. 다른 기기에서 새로고침합니다.
4. 동일한 계정 이메일과 서버 저장 설정이 일치하는지 확인합니다.
5. 로컬 권한은 권한을 허용한 해당 기기의 운영체제 설정에서 확인합니다. 로컬 권한은 다른 스마트폰으로 이전되지 않습니다.

## 설정 검증 체크리스트

- 웹과 모바일 세션에 동일한 계정 이메일이 표시됩니다.
- 이메일 인증과 비밀번호 상태가 의도한 로그인 방식과 일치합니다.
- 건강(Health)과 위치(Location) 권한이 기기 수준에서 의도한 상태입니다.
- 서드파티 플랫폼이 서버에서 의도한 연동 상태를 보여 줍니다.
- 원하는 자동 지표 업데이트 스위치만 켜져 있습니다.
- 멤버십 상태와 사용량 원장이 최근 지급 내역이나 AI 작업과 일치합니다.
- 요청한 데이터 내보내기가 Ready 상태에 도달해 만료 전에 정상 다운로드되며 선택한 위치 보호 옵션이 반영되어 있습니다.
- 설정을 다시 열어도 테마, 단위, 차트, 시간 형식, 언어 설정이 유지됩니다.

## 문제 해결

- **인증 코드가 작동하지 않음:** 6자리를 모두 입력했는지, 이메일과 만료 시각이 맞는지 확인하고 재발송 버튼이 활성화된 뒤 새 코드를 요청합니다.
- **이메일을 수정할 수 없음:** 현재 계정 UI에서는 이메일 변경을 제공하지 않으며, 해당 필드는 의도적으로 읽기 전용입니다.
- **건강 권한은 허용되었는데 미연동 상태임:** Health 항목을 다시 열어 앱/서버/기기 연결 상태를 확인하고 재연결 옵션이 보이면 실행합니다.
- **위치 권한이 계속 거부됨:** 이전에 거부된 권한은 시스템 팝업이 다시 뜨지 않을 수 있으므로 운영체제의 앱 설정에서 직접 변경합니다.
- **OAuth 후 플랫폼이 미연동으로 보임:** 소스 상태를 새로고침하고 같은 Trainingload.ai 계정인지 확인한 뒤 플랫폼별 설정을 점검합니다.
- **자동 업데이트 지표가 바뀌지 않음:** 스위치가 켜져 있는지와 최근 대상 활동에 지원하는 데이터가 충분히 포함되어 있는지 확인합니다.
- **사용량 화면이 비어 있음:** 더 넓은 기간을 선택하고 계정에 AI 지급 또는 소비 이력이 있는지 확인합니다.
- **앱 안에서 멤버십을 관리할 수 없음:** 지원하는 활성 구독 제공자에서만 관리 버튼이 노출됩니다. 표시된 결제 제공자를 확인하세요.
- **내보내기 요청이 시작되지 않음:** 진행 중인 내보내기 작업이 끝날 때까지 기다린 뒤 페이지를 새로고침해 다시 시도합니다.
- **내보내기가 만료됨:** 만료된 작업을 제거하고 원하는 위치 보호 옵션으로 새 아카이브를 요청합니다.
- **구독 때문에 계정 삭제가 진행되지 않음:** 삭제 흐름에 안내된 결제 제공자별 갱신 해지 절차를 따른 뒤 상태를 새로고침합니다. Apple 결제는 Apple에서 별도 해지가 필요합니다.
- **비밀번호 재설정 링크가 거부됨:** 새 이메일을 요청해 가장 최근 링크를 사용하세요. 이미 사용했거나 만료된 토큰은 재사용할 수 없습니다.
- **OAuth 동의 화면이 낯설게 보임:** 요청을 거절하고 요청 앱, 권한 범위, 계정, 반환 대상 주소를 확인한 뒤 다시 진행합니다.
- **환경설정이 바뀌지 않은 것처럼 보임:** Save를 누른 뒤 Settings를 다시 여세요. 로컬 표시 설정과 서버 로케일은 갱신 시점이 다를 수 있습니다.
