# 활동 파일 업로드

워치, 사이클링 컴퓨터 또는 훈련 플랫폼에서 내보낸 기록 파일을 업로드하면 Trainingload.ai에서 활동 상세 정보, 차트, 훈련 부하를 바로 확인할 수 있습니다. 이 절차는 웹 앱을 기준으로 합니다.

## 파일 준비 [#before-uploading]

FIT, TCX 또는 GPX 워크아웃 파일을 사용합니다. 한 번에 최대 100개까지 업로드할 수 있습니다. 기기나 플랫폼에서 직접 내보낸 원본 파일을 사용하면 심박수, 파워, 경로 데이터가 온전히 유지될 가능성이 가장 높습니다.

## 활동 페이지에서 업로드하기

1. 왼쪽 사이드바에서 **Activities(활동)**를 클릭해 활동 페이지를 엽니다.
2. 맨 오른쪽의 **Upload activity files(활동 파일 업로드)** 카드에서 **Choose activity files(활동 파일 선택)**를 클릭합니다.

업로드를 시작하면 가져오기 진행 상황 대화상자가 열리며 파일별 처리 결과를 보여 줍니다.

## 가져오기 진행 상태 확인 [#import-statuses]

파일이 가져와지는 동안 다른 페이지를 계속 둘러봐도 됩니다. 진행 상황 대화상자를 닫았다면 활동 페이지의 **Import Progress(가져오기 진행 상황)**를 클릭해 다시 열 수 있습니다.

| 표시되는 상태 | 해야 할 일 |
| --- | --- |
| Queued, Normalizing, Materializing, Building analysis | 파일이 아직 처리 중입니다. 가져오기가 끝날 때까지 기다립니다. |
| Done | **Activities(활동)**로 돌아가 가져온 기록을 확인합니다. |
| Skipped | 일치하는 기록이 이미 존재하는 경우가 많습니다. 활동 목록에서 기존 기록을 확인하세요. |
| Failed, Dead | 파일 옆의 메시지를 읽고 아래 문제 해결 절차를 따릅니다. |

## 가져온 활동 찾기 [#after-upload]

가져오기가 완료되면 왼쪽 사이드바에서 **Activities(활동)**를 클릭합니다. 운동 날짜로 기록을 찾아 클릭하면 운동 시간, 거리, 차트, 훈련 부하를 확인할 수 있습니다.

페이지 구성 안내는 [활동 피드 및 검색](/ko/docs/guide/activity-feed-search)과 [활동 상세 분석](/ko/docs/guide/activity-detail)을 참고하세요.

## 문제 해결

### Upload 버튼이 비활성화되어 있습니다

먼저 파일을 선택하세요. 파일 검사가 진행 중이라면 잠시 기다려 주세요. 특정 파일에 오류가 표시된다면 안내 메시지를 확인하거나 해당 파일을 목록에서 제거한 뒤 다시 시도합니다.

### 중복 경고가 표시됩니다

해당 워크아웃이 이미 활동 목록에 있다면 기존 기록을 유지하거나 업로드를 취소할 수 있습니다. 별도 사본을 일부러 보관해야 할 때만 새 가져오기를 강제로 진행하세요.

### 파일 업로드 또는 가져오기에 실패합니다

파일 옆에 표시된 오류 메시지를 확인하세요. 기기나 플랫폼에서 원본 FIT, TCX 또는 GPX 파일을 다시 내보낸 뒤 그 파일만 단독으로 업로드해 보세요. 파일 확장자 이름만 바꾼다고 파일 형식이 변환되지는 않습니다.

스크린샷, 일반 CSV 스프레드시트, 종일 건강 데이터만 담긴 FIT 파일은 여기에서 워크아웃 기록으로 가져올 수 없습니다.

### 기록에 심박수, 파워 또는 경로가 보이지 않습니다

먼저 활동 분석 처리가 완료될 때까지 기다려 주세요. 차트를 그리려면 원본 기록에 해당 센서 데이터가 들어 있어야 합니다. 예를 들어 GPS가 없는 실내 워크아웃은 경로가 표시되지 않습니다. 원본 플랫폼에서 데이터가 있는지 확인하고 원본 워크아웃 파일을 다시 내보내 보세요.

## 다른 파일 형식이 필요하신가요? [#convert-between-formats]

업로드는 FIT, TCX, GPX를 모두 지원하므로 보통 별도 변환이 필요 없습니다. 다른 플랫폼용으로 파일 형식을 바꿔야 한다면 [FIT, GPX, TCX 변환기](/ko/converter)를 이용해 보세요.
