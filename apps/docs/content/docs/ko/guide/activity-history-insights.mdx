# 활동 기록 및 구간 최고 기록

활동 기록 분석 도구를 활용하면 "전체적으로 어떤 훈련을 했는가?"라는 질문에서 구체적인 원본 활동까지 빠르게 내려갈 수 있습니다. Activity Stats는 훈련량을 요약하고, Best Distance는 지속 구간 최고 기록을 순위별로 보여 주며, Map은 이동 경로 맥락을 더해 줍니다.

이 페이지들은 기록된 데이터를 사실대로 보여 줍니다. 공식 대회 기록을 인증하거나 완주 시간을 예측하지 않으며, 추가 리뷰 없이 퍼포먼스 변화의 원인까지 자동으로 단정하지 않습니다.

## 시작하기 전에

- 가져온 활동이 준비 완료(Ready) 상태에 도달할 때까지 기다립니다.
- 종목 분류, 시간대, 단위 체계를 확인합니다.
- 합계나 최고 기록을 비교하기 전에 중복 활동과 명백한 센서 오류를 정리합니다.
- 확인하려는 질문에 맞는 기간을 선택합니다.
- 지도(Map)는 유효한 GPS 좌표가 필요하며, 실내 활동이나 GPS가 없는 활동은 지도에 나오지 않더라도 다른 분석 페이지에는 정상적으로 표시됩니다.

## 1. 연간 활동량 리뷰 (Activity Stats)

**Analysis → Activity Stats**를 엽니다. 이 페이지는 현재 **Activities** 페이지에 적용된 종목 필터를 그대로 사용하므로, 리포트를 읽기 전에 종목 필터를 먼저 맞추세요.

사이드바에서 연도를 선택합니다. 선택한 종목의 가장 오래된 활동 연도까지 선택할 수 있으며, 히트맵은 선택한 연도의 365일 범위를 대상으로 활동한 날짜 수를 보여 줍니다.

히트맵 아래에서 지표 하나를 고릅니다.

- 거리(Distance)
- 운동 시간(Duration)
- 심박수(Heart rate)
- 활동 횟수(Activity count)
- 칼로리(Calories)

그다음 선 차트를 일별(day), 주별(week), 월별(month)로 집계해 살펴봅니다. 짧은 기간을 파고들 때는 일별, 훈련 일관성을 볼 때는 주별, 전체 볼륨 추세를 비교할 때는 월별 집계가 유용합니다. 심박수는 기여 값의 평균으로, 거리와 시간처럼 합산 가능한 지표는 합계로 계산됩니다.

## 2. 구간 최고 기록 찾기 (Best Distance)

**Analysis → Best Distance**를 열고 아래 순서로 확인합니다.

1. **Run(러닝)**, **Cycling(사이클링)** 또는 **Swim(수영)**을 선택합니다.
2. **By Distance(거리별)** 또는 **By Time(시간별)**을 선택합니다.
3. 날짜 범위를 설정합니다.
4. 거리 또는 지속 시간 목표를 선택합니다.
5. 순위별 기록을 검토합니다(목표당 최대 10개 결과 조회).
6. 기록 행을 클릭해 원본 활동을 엽니다.

**By Distance**는 "이 거리를 가장 빠르게 달린 기록은?"에, **By Time**은 "이 시간 동안 가장 멀리 이동한 거리는?"에 답합니다. 함께 표시되는 페이스는 같은 종목과 조건 안에서 기록을 비교하는 데 도움이 됩니다.

표시된 모든 행을 곧바로 개인 최고 기록(PR)으로 단정하지 마세요. 이는 선택한 데이터와 기간 안에서 조건을 만족하는 최상위 구간이며, 일반 훈련 중 기록일 수도 있고 GPS 품질에 좌우될 수 있으며 활동을 재처리하거나 수정하면 달라질 수 있습니다.

## 3. 지도에서 경로 기록 살펴보기 (Map)

**Map(지도)**을 열고 기간과 종목 필터를 설정합니다. 조건에 맞고 유효한 GPS 데이터가 포함된 활동의 경로가 지도에 그려집니다.

지도 활용법:

- 위치나 경로 모양으로 특정 활동 찾기
- 반복적으로 훈련한 코스 비교하기
- 활동을 열기 전에 끊겼거나 비정상적인 경로 발견하기
- 선택한 활동의 경로 기반 공유 포스터 만들기

경로를 선택하면 해당 활동 포스터가 열립니다. 세부 지표, 처리 상태, 센서 근거를 확인하려면 포스터에서 전체 활동 상세 페이지로 이동하세요.

지도에는 민감한 위치 정보가 담겨 있습니다. 포스터를 공유하기 전에 경로를 꼭 확인해 집, 직장 등 사적인 출발 위치가 노출되지 않도록 주의하세요.

## 4. 예상과 다른 결과 추적하기

연간 합계, 구간 최고 기록 또는 경로가 이상하게 보일 때는 다음 순서로 확인합니다.

1. 원본 활동을 엽니다.
2. 시작 시각, 종목, 원본 플랫폼, 처리 상태, 단위 체계를 확인합니다.
3. GPS, 거리, 운동 시간, 일시 정지 구간 및 관련 센서 스트림을 점검합니다.
4. 중복 활동이나 잘못된 종목 분류가 있는지 확인합니다.
5. 원본 활동이나 설정을 수정한 뒤 요약 페이지를 새로고침합니다.

판단의 최종 근거는 항상 원본 활동입니다. 요약 페이지는 이상 징후를 발견하는 데 유용하지만, 스스로 원인을 설명하거나 고치지는 못합니다.

## 결과 검증

- Activity Stats가 의도한 종목, 연도, 지표, 집계 단위를 사용하고 있습니다.
- 구간 최고 기록 행을 클릭하면 해당 날짜의 예상 원본 활동이 열립니다.
- 선택한 지도 경로가 의도한 활동과 일치합니다.
- GPS가 없는 활동이 지도에 보이지 않는다고 가져오기 누락으로 오해하지 않았습니다.
- 공유할 포스터에서 민감한 위치 정보 노출 여부를 확인했습니다.

## 문제 해결

- **Activity Stats에 다른 종목이 표시됨:** **Activities** 페이지로 돌아가 종목 필터를 바꾼 뒤 Activity Stats를 다시 열거나 새로고침하세요.
- **올해 연도만 선택할 수 있음:** 선택한 종목에 이전 연도의 조건 충족 활동이 없거나, 가장 오래된 활동 조회가 아직 완료되지 않았습니다.
- **히트맵과 선 차트 숫자가 다르게 보임:** 히트맵은 활동한 날짜 수를 세고, 선 차트는 선택한 지표와 집계 단위를 표시합니다.
- **기대한 구간 최고 기록이 보이지 않음:** 기간을 넓히고 종목과 목표를 확인한 뒤 해당 활동에 유효한 거리·시간 데이터가 있는지 점검합니다.
- **비현실적인 기록이 표시됨:** 기록을 활용하기 전에 GPS 튐(스파이크), 일시 정지, 거리·시간 이상, 중복 활동 여부를 확인하세요.
- **활동이 지도에 표시되지 않음:** 필터 범위를 벗어났거나 유효한 GPS 경로가 없는 활동일 수 있습니다.
- **경로를 눌렀더니 다른 활동 포스터가 열림:** 활동 날짜를 확인하고 공유하기 전에 전체 활동 상세 페이지를 열어 검증하세요.
