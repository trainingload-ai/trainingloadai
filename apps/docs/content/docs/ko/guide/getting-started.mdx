# 첫 번째 활동 가져오기 [#get-started-with-your-first-activity]

워치, 사이클링 컴퓨터 또는 훈련 플랫폼의 기록을 가져오면 Trainingload.ai에서 활동 상세 정보, 차트, 훈련 부하를 바로 확인할 수 있습니다. 이 가이드는 웹 앱에서 플랫폼 동기화와 파일 업로드를 진행하는 방법을 안내합니다.

## 시작하기 전에

[Trainingload.ai 열기](https://app.trainingload.ai/en)에서 본인 계정으로 로그인합니다. 셀프 호스팅 환경이라면 직접 운영 중인 인스턴스를 열어 주세요. 먼저 화면을 둘러보고 싶다면 [데모 살펴보기](https://demo.trainingload.ai/en)를 이용할 수 있습니다.

## 1. 가져오기 방식 선택 [#2-choose-one-route-for-the-first-activity]

| 동기화 방식 | 안내 |
| --- | --- |
| 서드파티 훈련 플랫폼 동기화 (Strava, Garmin, Intervals.icu) | [플랫폼 연동하기](#connect-a-training-platform) |
| 활동 파일 동기화 (FIT, TCX, GPX) | [워크아웃 파일 업로드하기](#upload-a-workout-file) |
| 스마트폰에서 동기화 | [모바일 동기화 가이드 읽기](/ko/docs/guide/account-permissions-and-usage#2-review-mobile-permissions-and-data-sources) |

셀프 호스팅 환경에서 지원하는 연동 목록은 [환경 설정](/ko/docs/self-host/configuration)을 참고하세요. 아래의 파일 업로드 방식도 동일하게 사용할 수 있습니다.

## 2. 활동 기록 가져오기 [#3-import-and-wait-for-processing]

### 방법 1: 훈련 플랫폼 연동 [#connect-a-training-platform]

1. 사이드바 하단의 계정 메뉴를 열고 **Account(계정)**를 선택한 뒤 **Third Party Connections(서드파티 연동)** 항목으로 스크롤합니다.
2. 활동 기록이 저장된 플랫폼을 선택하고 안내 대화상자에 따라 연동을 완료합니다.
3. 필요에 따라 초기 가져오기(initial import) 또는 수동 동기화(manual sync) 옵션을 실행합니다.
4. 사이드바에서 **Activities(활동)**를 열어 동기화된 기록을 확인합니다.

플랫폼마다 지원하는 과거 기록 가져오기 범위가 다릅니다. 자세한 연동 및 과거 기록 가져오기 단계는 [Strava, Garmin 및 기타 플랫폼 연동](/ko/docs/guide/connect-third-party-platforms)을 참고하세요.

### 방법 2: 워크아웃 파일 업로드 [#upload-a-workout-file]

워치, 사이클링 컴퓨터 또는 훈련 플랫폼에서 FIT, TCX, GPX 파일을 내보낸 뒤 아래 순서를 따릅니다.

1. 왼쪽 사이드바에서 **Activities(활동)**를 클릭해 활동 페이지를 엽니다.
2. 맨 오른쪽의 **Upload activity files(활동 파일 업로드)** 카드에서 **Choose activity files(활동 파일 선택)**를 클릭합니다.

3. 가져올 파일을 대화상자로 드래그하거나 파일 선택 영역을 클릭해 지정합니다.
4. 대화상자 오른쪽 하단의 **Upload(업로드)** 버튼을 클릭합니다.

업로드 후 가져오기 진행 상황 대화상자가 열립니다. 가져오기가 완료되면 **Activities(활동)**로 돌아가 기록을 확인합니다. 중복 경고가 표시되면 같은 워크아웃을 두 번 가져오지 말고 기존 기록을 유지할 수 있습니다. 자세한 내용은 [활동 파일 업로드](/ko/docs/guide/upload-activity-files)를 참고하세요.

## 3. 가져온 활동 열기 [#4-verify-the-first-recorded-result]

**Activities(활동)**에서 날짜별로 워크아웃을 찾아 상세 화면을 엽니다. 기록에 포함된 시간, 거리, 훈련 부하와 차트 및 경로를 확인할 수 있습니다. 화면 구성 안내는 [활동 상세 분석](/ko/docs/guide/activity-detail)을 참고하세요.

방금 가져온 활동은 아직 처리 중일 수 있습니다. 전체 결과를 확인하기 전에 분석이 완료될 때까지 잠시 기다려 주세요. 심박수, 파워, 경로 차트는 해당 센서 데이터가 기록에 포함되어 있어야 표시되며, GPS 데이터가 없는 기록에는 경로가 표시되지 않습니다.

## 자주 묻는 질문

### 플랫폼을 연동했는데 활동이 보이지 않습니다

플랫폼 연동 상태를 확인하고 활동 페이지의 날짜 필터를 점검해 주세요. 과거 워크아웃은 별도의 기록 가져오기(history import) 실행이 필요할 수 있습니다. 해당 플랫폼의 옵션을 따르거나 원본 워크아웃 파일을 내보내 Trainingload.ai에 업로드해 보세요.

### 활동에 심박수나 경로가 표시되지 않습니다

처리가 완료될 때까지 잠시 기다려 주세요. 원본 파일에 심박수, 파워 또는 GPS 데이터가 없다면 해당 차트는 표시되지 않습니다. 원본 플랫폼에서는 해당 측정값이 보인다면 원본 활동 파일을 다시 내보내 업로드해 보세요.

### 활동이 다른 날짜에 표시됩니다

계정의 시간대(Time zone) 설정과 기록의 시작 시각을 확인하세요. 시간대 및 단위 설정 방법은 [프로필, 역치 및 존](/ko/docs/guide/profile-thresholds-zones)을 참고하세요.

### 데모에서는 왜 업로드할 수 없나요?

데모 계정은 샘플 데이터를 둘러보는 용도입니다. 본인 기록을 가져오려면 [메인 앱 열기](https://app.trainingload.ai/en)에서 본인 계정으로 로그인해 주세요.
