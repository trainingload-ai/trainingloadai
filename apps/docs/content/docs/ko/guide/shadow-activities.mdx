# 섀도 활동(Shadow Activity): 요약 정보만 표시되는 이유

**섀도 활동은 Trainingload.ai가 존재를 감지했지만 전체 상세 기록은 아직 확보하지 못한 활동을 말합니다.** 누락되지 않았음을 확인할 수 있도록 활동 제목과 시작 시각을 보존하며, 이어서 취할 수 있는 다음 조치를 함께 안내합니다.

섀도 활동은 완전히 가져온 활동이 아닙니다. 요약 정보만 가지고 차트나 훈련 부하를 임의로 만들어 내지 않으며, 전체 가져오기에 성공하면 섀도 활동이 완전한 활동 기록으로 대체됩니다. 또한 이미 확보된 완전한 기록이 있는데 이후 동기화에서 데이터를 가져오지 못하더라도 기존 전체 기록이 삭제되지는 않습니다.

현재 섀도 활동이 나타나는 주된 상황은 두 가지입니다.

## 경우 1: Intervals.icu에 활동 정보는 있지만 원본 파일을 제공할 수 없는 경우

Intervals.icu는 Strava에서 받은 활동의 요약 정보를 보여 줄 수 있지만, Intervals.icu API는 원본 활동 파일 제공을 명시적으로 제한합니다. 따라서 Intervals.icu 화면에 활동이 보인다고 해서 Trainingload.ai가 해당 API를 통해 전체 기록을 가져올 수 있는 것은 아닙니다.

이 경우 Trainingload.ai는 Strava에서 직접 데이터를 가져오려고 시도합니다. 카드의 안내에 따라 Strava를 연동하거나 권한을 갱신하거나 활동 가져오기를 활성화한 뒤 동기화가 끝날 때까지 기다려 주세요.

Strava에서도 필요한 데이터를 제공할 수 없다면 섀도 활동 상태로 남습니다. Intervals.icu 동기화를 반복해도 원본 파일 제공 제한을 우회할 수는 없습니다.

## 경우 2: Strava에 활동 상세 정보는 있지만 스트림(시계열 데이터)을 제공할 수 없는 경우

활동 이름, 총 거리, 총 시간 같은 요약 정보는 시점별 GPS, 심박수, 파워, 거리 샘플과 별도로 관리됩니다. **활동 상세 정보가 존재한다고 해서 가져올 수 있는 스트림 데이터가 반드시 함께 제공되는 것은 아닙니다.**

- **샘플 데이터가 애초에 없는 경우:** 예를 들어 기기 기록 없이 Strava에 거리와 시간만 수동으로 입력한 활동입니다. 상세 페이지는 존재하지만 재시도해도 없는 샘플이 생성되지는 않습니다.
- **기록을 일시적으로 가져올 수 없는 경우:** 원본 플랫폼이 아직 활동을 처리 중이거나 상세 데이터 엔드포인트가 일시적으로 응답하지 않을 수 있습니다. 한 번의 "찾을 수 없음(not found)" 응답만으로 활동 삭제나 스트림의 영구 부재를 단정하지는 않습니다.

Trainingload.ai는 일시적 가용성 실패에 대해 제한된 횟수만큼 자동 재시도를 수행합니다. 그래도 기록을 가져올 수 없으면 섀도 활동을 유지하고 재시도 옵션을 제공합니다. 심박수, 파워 또는 GPS 중 일부만 빠졌다고 해서 무조건 섀도 활동이 되지는 않습니다. 사용 가능한 시계열 데이터가 있다면 일부 분석만 생략된 채 정상적으로 가져올 수 있습니다.

## 어떻게 대응해야 하나요?

| 확인된 상황 | 권장 조치 |
| --- | --- |
| 카드에서 연동, 권한 갱신 또는 가져오기 활성화를 안내함 | 안내된 설정을 완료한 뒤 동기화가 끝나기를 기다리거나 재시도합니다. |
| 방금 업로드했거나 아직 처리 중인 활동임 | 원본 플랫폼의 처리가 끝날 때까지 기다린 뒤 한 번 재시도합니다. |
| 일시적인 원본 플랫폼 장애가 복구됨 | 전체 기록을 다시 요청하도록 한 번 재시도합니다. |
| 수동으로 입력해 샘플이 전혀 없는 활동임 | 반복 재시도로 해결되지 않습니다. 원본 기기 기록 파일이 있는지 확인하세요. |
| 여러 번 시도해도 계속 섀도 활동으로 남음 | 원본 플랫폼에서 활동 파일을 내보낼 수 있는지 확인하고, 필요하면 지원팀에 문의하세요. |

재시도는 데이터를 다시 요청하는 동작이며, 원본 플랫폼이 이제 데이터를 제공할 수 있다고 보장하지는 않습니다. 재시도 전에 섀도 활동이나 기존 전체 활동을 먼저 삭제할 필요는 없습니다. 연동을 반복적으로 해제하고 다시 연결해도 없는 샘플 데이터가 새로 만들어지지는 않습니다.

## 원본 파일이 있는 경우

운동을 처음 기록한 기기나 플랫폼에서 활동 기록이 포함된 FIT, TCX 또는 GPX 파일을 내보낼 수 있다면 [활동 파일 업로드](/ko/docs/guide/upload-activity-files) 기능을 사용하세요. 이미 전체 활동이 존재하는 경우 중복 경고를 확인하고 날짜와 내용을 대조해 보세요.

## 지원 요청 시 참고사항

지원을 요청할 때는 활동 날짜, 원본 플랫폼 이름, 화면에 표시된 메시지, 원본 플랫폼에서 파일 내보내기 가능 여부를 함께 알려 주세요. 액세스 토큰이나 비밀번호는 절대 보내지 마세요. 추가 점검 단계는 [문제 해결](/ko/docs/guide/troubleshooting) 문서를 참고하세요.
