# 훈련 부하 관리를 위한 Runalyze 대안

러닝 퍼포먼스 리뷰에 Runalyze를 사용하고 있다면, 같은 최근 활동 기록과 다가오는 훈련에 대해 내려야 할 의사결정을 기준으로 두 도구를 나란히 비교해 보세요.

Runalyze는 유효 VO2max, 대회 기록 예측, 훈련 부하, 활동 통계 기능을 제공합니다. 계산 방식과 최신 기능은 Runalyze의 [공식 기능 개요](https://runalyze.com/help/article/features?_locale=en)에서 확인할 수 있습니다.

## Trainingload.ai에서 훈련 리뷰하기

- 먼저 [활동 상세 분석](/ko/docs/guide/activity-detail)을 열어 기록된 워크아웃을 확인합니다.
- [유효 VO2max 기록](/ko/docs/guide/effective-vo2max-for-endurance)을 살펴보며 최근 추정치가 어떻게 변했는지 점검합니다.
- [PMC](/ko/docs/guide/pmc-forecast)를 열어 훈련 일정과 함께 부하 흐름을 해석합니다.
- 완료된 활동을 예정 워크아웃에 연결한 뒤 [AI 코치](/ko/docs/guide/ai-coach)에게 완료 리뷰나 조정 제안을 요청합니다.

## 본인 기록으로 비교하는 방법

1. 원본 플랫폼에서 지원하는 FIT, GPX 또는 TCX 파일을 내보내거나 [플랫폼 연동](/ko/docs/guide/connect-data)을 사용합니다.
2. 최근 훈련 블록을 가져온 뒤 날짜, 데이터 소스, 역치 설정을 확인합니다.
3. 잘 알고 있는 워크아웃 하나를 선택해 기록된 시간, 거리, 심박수, 페이스를 비교합니다.
4. 이어서 훈련 부하와 체력 추정치를 살펴봅니다. 추정치 하나가 다르게 나왔다고 해서 실제 체력이 변했다고 단정할 수는 없습니다.

## 다시 설정해야 하는 항목

플랫폼마다 유효 샘플 기준, 보정 방식, 역치 설정이 다를 수 있으므로 유효 VO2max와 훈련 부하 이력이 완전히 일치하지 않을 수 있습니다. 또한 활동 파일을 업로드해도 Runalyze의 태그, 장비, 사용자 지정 설정, 모든 과거 통계가 자동으로 이전되지는 않습니다.

계획 대비 활동 리뷰를 직접 시험해 보는 동안에는 원본 기록을 그대로 유지한 뒤, 완전히 이전할지 두 도구를 함께 사용할지 결정하세요. 인터페이스를 먼저 둘러보고 싶다면 [데모 열기](https://demo.trainingload.ai/en)를 이용해 보세요.
