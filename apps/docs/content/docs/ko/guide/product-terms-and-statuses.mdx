# 제품 용어 및 상태 안내

익숙하지 않은 용어나 상태가 보일 때 이곳에서 의미와 다음으로 해야 할 작업을 확인할 수 있습니다.

## 기본 용어

| 용어 | 의미 |
| --- | --- |
| 선수 프로필 (Athlete profile) | 훈련 해석에 쓰이는 시간대, 단위, 역치, 존, 환경설정 및 종목 맥락 |
| 훈련 플랜 (Training plan) | 개별 워크아웃으로 구성된 훈련 일정으로, 초안 저장·활성화·종료가 가능 |
| 예정된 워크아웃 (Planned workout) | 특정 날짜에 수행하도록 계획된 훈련으로, 종목·구성·시간·강도 및 예상 부하(지원 시)를 포함 |
| 완료된 활동 (Completed activity) | 기기나 플랫폼에서 실제로 기록, 동기화 또는 업로드된 운동 데이터 |
| 플랜-활동 연결 (Plan-to-activity link) | 특정 완료 활동이 어느 예정된 워크아웃을 수행한 결과인지 명시적으로 연결한 관계 |
| 현재 상태 (Current state) | 오늘의 훈련 판단에 쓰이는 최근 훈련 부하, 회복 입력, 주관적 피드백 등의 맥락 |
| 리뷰 (Review) | 확보된 근거를 바탕으로 활동, 하루, 한 주, 한 달 또는 플랜을 해석한 결과 |
| AI 작업 (AI operation) | 예정된 훈련을 생성, 이동 또는 수정하는 등 AI가 제안하거나 실행한 작업 |

## 활동 상태

| 상태 | 의미 | 해야 할 일 |
| --- | --- | --- |
| 업로드 또는 가져오기 중 (Uploading / Importing) | 파일 또는 플랫폼 데이터가 아직 전송 중입니다 | 다시 시도하지 말고 잠시 기다립니다 |
| 처리 중 (Processing) | 활동은 생성되었으나 파생 분석 데이터가 아직 완성되지 않았습니다 | 누락된 부하나 차트를 성급하게 해석하지 마세요 |
| 준비 완료 (Ready) | 활동 분석이 완료되었습니다 | 원본 소스가 실제로 제공한 데이터를 리뷰합니다 |
| 실패 (Failed) | 가져오기 또는 처리를 완료하지 못했습니다 | 화면의 오류 메시지를 확인한 뒤 문제 해결 가이드를 참고합니다 |
| 중복 (Duplicate) | 동일한 원본 활동 또는 같은 파일이 이미 존재합니다 | 기존 기록을 확인하고 같은 워크아웃을 중복으로 가져오지 않습니다 |

## 플랜 및 워크아웃 상태

| 상태 | 의미 |
| --- | --- |
| 초안 (Draft) | 현재 플랜으로 적용하기 전에 검토하거나 수정할 수 있는 상태 |
| 진행 중 (Active) | 현재 따르고 있는 플랜으로, 예정된 날짜에 워크아웃이 표시되는 상태 |
| 완료됨 (Completed) | 플랜 기간이 종료되어 리뷰용으로 보관된 상태 |
| 예정됨 (Planned) | 워크아웃이 일정에 등록되어 있으나 아직 최종 수행 결과가 없는 상태 |
| 완료된 워크아웃 (Completed workout) | 보통 활동 연결이나 명시적 완료 처리를 통해 완료로 표시된 예정 워크아웃 |
| 건너뜀 (Skipped) | 의도적으로 수행하지 않고 넘어간 워크아웃 |
| 계획 외 활동 (Unplanned activity) | 예정된 워크아웃에 해당하지 않는 완료된 활동 |

## 부하, 리뷰 및 크레딧

- **훈련 부하(Training load)**는 훈련 자극량을 추정해 산출한 파생 지표입니다. 산출 가능 여부는 종목, 시간, 센서 데이터, 역치, 부하 소스 규칙에 따라 달라집니다.
- **코치 리뷰(Coach review)**는 근거 기반 해석이며, 원본 기기 데이터나 의학적 진단이 아닙니다.
- **AI 크레딧(AI credits)**은 대상 AI 작업에 사용되는 이용 단위입니다. 크레딧 내역은 소비량을 나타낼 뿐, 훈련 부하나 계정 권한을 의미하지 않습니다.
- **데모 계정(Demo account)**은 샘플 데이터를 둘러보는 계정입니다. 변경 사항을 저장하거나 활동을 가져오고 본인 훈련 기록을 관리하려면 본인 계정으로 로그인하세요.
