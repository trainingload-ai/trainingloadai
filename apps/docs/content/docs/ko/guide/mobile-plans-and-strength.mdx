# 모바일에서 플랜 작성 및 근력 워크아웃 완료하기

스마트폰에서 직접 훈련 플랜 초안을 만들거나, 예정된 근력 워크아웃을 열어 세트 단위로 운동 기록을 남길 수 있습니다. 이 가이드는 두 작업을 모두 안내합니다.

## 시작하기 전에

- 로그인한 뒤 **Plan** 탭에서 계정 정보가 정상적으로 불러와지는지 확인합니다.
- 플랜 기간과 짧은 이름을 미리 정해 둡니다.
- 근력 세션의 경우 수행할 운동 종목과 사용 가능한 장비를 미리 정리합니다.
- 먼저 초안(Draft)으로 저장하고 전체 일정을 검토한 뒤 활성화하세요.

## 1. 플랜 생성 방식 선택

**Plan** 탭에서 **Create plan(플랜 만들기)**을 선택한 뒤 아래 두 가지 중 하나를 고릅니다.

- **Manual(수동)** — 지구력 및 근력 세션을 직접 배치합니다.
- **AI** — 목표와 제약 조건을 입력하고 AI 코치와 대화하며 계획을 이어갑니다.

이 가이드의 나머지 단계는 **Manual** 방식을 기준으로 합니다.

## 2. 플랜 기본 정보 입력

플랜 이름을 입력하고 기간(1~24주)을 선택합니다. 필요하면 설명(Description)에 훈련 원칙, 제약 사항 또는 실행 우선순위를 적어 둘 수 있습니다. 이름과 기간이 맞는지 확인한 뒤 다음으로 넘어가세요. 나중에 기간을 줄이면 새 범위를 벗어나는 날짜에 워크아웃을 남겨 둘 수 없습니다.

## 3. 일정 배치

일정을 스크롤해 워크아웃을 넣을 날짜를 엽니다. 하루에 여러 세션을 배치할 수 있으며, 세션 번호가 수행 순서를 결정합니다.

두 가지 워크아웃 구조 중 하나를 선택합니다.

- **Endurance(지구력)** — 러닝, 사이클링, 수영, 스트레칭 스텝을 구성합니다. 시각적 스텝 편집기(수동 모드) 또는 지원하는 텍스트 문법(DSL 모드)을 사용할 수 있습니다.
- **Strength(근력)** — 웜업/본 세트 그룹, 세트 수, 반복 횟수 또는 시간, 중량, 운동 강도, 휴식 시간을 종목별로 구성합니다.

모든 워크아웃에 대해 다음 순서로 설정합니다.

1. 주차, 요일, 세션 순서를 확인합니다.
2. 알아보기 쉬운 이름을 입력합니다.
3. 코칭 지침이나 주의 사항은 메모(Notes)에 적습니다.
4. 지구력 또는 근력 구조를 작성하고 유효성을 확인합니다.
5. 워크아웃을 플랜 초안에 저장합니다.

## 4. 초안 검토 및 저장

최소 한 개 이상의 워크아웃을 추가해야 검토(Review) 단계로 넘어갈 수 있습니다. 전체 주차, 총 세션 수, 훈련 일수, 시간순 일정을 비교해 확인한 뒤 저장하세요. 새 플랜은 초안 상태로 저장되므로 활성화 전에 충분히 검토할 수 있습니다.

플랜 상세 화면을 열어 모든 워크아웃이 의도한 상대 날짜에 배치되었는지 확인하고, [플랜 상태 관리](/ko/docs/planning/plan-lifecycle)를 읽은 뒤 활성화하세요.

## 5. 예정된 근력 워크아웃 시작

예정된 근력 세션을 시작할 준비가 되면 Today, Calendar 또는 진행 중인 플랜에서 해당 워크아웃을 열고 **Start as planned(계획대로 시작)**를 선택합니다. 앱이 처방 내용을 바탕으로 실제 근력 활동을 생성하고 실시간 기록 화면을 엽니다.

세션을 시작하는 것과 완료하는 것은 별개입니다. 예정된 처방 내용은 그대로 참고용으로 남고, 실제 수행한 세트 기록이 별도로 저장됩니다.

## 6. 세트별 운동 기록

각 운동 종목과 세트에 대해 다음을 진행합니다.

1. 예정된 중량과 반복 횟수 또는 시간을 확인합니다.
2. 실제 수행한 중량이나 결과가 다르면 실제 값으로 조정합니다.
3. 세트를 완료로 표시합니다. 실수로 눌렀다면 취소(Undo)할 수 있습니다.
4. 수행한 운동 내용과 종목·세션 진행률이 일치할 때까지 이어갑니다.

실시간 화면에서 나가더라도 기록은 삭제되지 않으며, 나중에 예정된 세션에서 다시 돌아와 이어갈 수 있습니다.

## 7. 종료 및 확인

선택적으로 1~10 사이의 세션 RPE를 입력한 뒤 **Finish workout(워크아웃 종료)**을 선택합니다. 앱이 활동을 완료 처리하고 상세 화면을 엽니다.

확인할 사항:

- 운동 시간과 세션 RPE가 실제 수행과 일치합니다.
- 완료된 세트, 중량, 반복 횟수, 시간제 운동 기록이 정확합니다.
- 해당 활동이 예정된 워크아웃에 정상 연결되어 있습니다.
- 계획된 값과 실제 수행 값이 시각적으로 구분됩니다.

## 자주 발생하는 문제

- **일정 단계에서 다음으로 넘어갈 수 없음:** 유효한 워크아웃을 최소 한 개 추가하고, 모든 워크아웃이 플랜 기간 안에 들어 있는지 확인하세요.
- **근력 워크아웃을 저장할 수 없음:** 운동 이름, 최소 한 개 이상의 세트 그룹, 유효한 세트/반복 값을 입력해야 합니다.
- **Start as planned가 실패함:** 네트워크 연결을 확인하고 예정 워크아웃을 새로고침한 뒤 근력 구성 데이터가 포함되어 있는지 확인하세요.
- **실시간 세션 화면에서 나갔음:** 예정된 워크아웃을 다시 열면 기존 활동 기록이 그대로 보존되어 있습니다.
