# 목적별 시작 가이드

Trainingload.ai를 유용하게 쓰기 위해 처음부터 모든 지표를 설정할 필요는 없습니다. 지금 가장 먼저 달성하고 싶은 목표를 선택해 해당 흐름을 완료하고, 세부 설정은 나중에 보완해도 충분합니다.

## 최근 훈련 내용을 분석하고 싶다면

다른 플랫폼에 저장된 완료 워크아웃이나 FIT, TCX, GPX 파일이 이미 있다면 이 경로를 선택합니다.

1. [첫 번째 활동 가져오기](/ko/docs/guide/getting-started)를 완료합니다.
2. [외부 플랫폼을 연동](/ko/docs/guide/integrations)하거나 [활동 파일을 업로드](/ko/docs/guide/upload-activity-files)합니다.
3. [활동 상세 분석](/ko/docs/guide/activity-detail)을 열어 시간, 거리, 종목 및 기록된 센서 데이터가 정확한지 확인합니다.
4. [대시보드](/ko/docs/guide/dashboard)와 [훈련 분석 워크플로](/ko/docs/guide/training-analysis-workflow)를 활용해 추세를 해석합니다.

**완료 기준:** 최소 한 개 이상의 활동 처리가 완료되고, 차트가 기대한 원본 데이터와 일치할 때입니다.

## 훈련 플랜을 따라가고 싶다면

과거 기록 분석보다 다음 워크아웃 실행이 더 중요하다면 이 경로를 선택합니다.

1. [프로필, 역치 및 존](/ko/docs/guide/profile-thresholds-zones) 설정을 확인합니다.
2. 직접 작성하거나 AI를 활용해 [훈련 플랜을 생성](/ko/docs/guide/create-training-plan)합니다.
3. 각 워크아웃을 검토한 뒤 원하는 시작일로 플랜을 활성화합니다.
4. [훈련 캘린더](/ko/docs/guide/calendar) 또는 플랜 페이지에서 오늘의 훈련을 확인합니다.
5. 훈련을 마친 뒤 [완료된 활동을 예정된 워크아웃에 연결](/ko/docs/guide/manage-active-plan)합니다.

**완료 기준:** 플랜이 활성화되어 오늘의 워크아웃이 표시되고, 첫 번째 완료 활동이 연결되었거나 연결할 준비가 되었을 때입니다.

## 주로 모바일로 훈련한다면

오늘의 훈련 확인, 활동 기록, 빠른 리뷰, 플랜 실행은 모바일에서 처리하고, 상세 차트 비교나 여러 주에 걸친 플랜 편집처럼 넓은 화면이 필요할 때는 웹을 활용합니다.

1. [웹과 모바일 연동](/ko/docs/guide/web-and-mobile)에서 어떤 데이터가 동기화되는지 확인합니다.
2. [모바일 활동 기록](/ko/docs/guide/mobile-recording)의 권한 체크리스트를 완료합니다.
3. 워크아웃을 기록하거나 가져옵니다.
4. Today, Calendar, Plan, Coach, Me 탭을 열어 동일한 계정의 워크플로를 이어갑니다.

**완료 기준:** 모바일 기록을 저장할 수 있고, 동기화 후 계정에 해당 활동이 정상적으로 표시될 때입니다.

## AI의 도움으로 훈련을 만들거나 조정하고 싶다면

AI 코치는 프로필, 최근 활동, 훈련 플랜 데이터가 갖춰져 있을 때 가장 정확한 제안을 제공합니다.

1. 신뢰할 수 있는 역치 값만 입력하고, 모르는 값은 추측해 넣지 말고 비워 둡니다.
2. 평소 훈련량을 파악할 수 있을 만큼 최근 훈련 기록을 가져옵니다.
3. [AI 코치](/ko/docs/guide/ai-coach)를 열고 목표, 기간, 제약 조건, 훈련 가능 요일을 구체적으로 전달합니다.
4. 플랜 초안이나 워크아웃 조정 제안을 적용하기 전에 모든 내용을 검토합니다.

**완료 기준:** AI 제안이 실제 플랜이나 활동 기록을 근거로 인용하며, 저장하기 전에 변경될 내용을 미리 확인할 수 있을 때입니다.

## 근력 워크아웃을 만들고 싶다면

1. 수동 플랜을 새로 만들거나 기존 플랜을 엽니다.
2. 워크아웃 편집기에서 **Strength Training(근력 훈련)**을 선택합니다.
3. [근력 워크아웃](/ko/docs/planning/strength-workouts) 가이드에 따라 운동 종목, 본 세트, 중량, 운동 강도, 휴식 시간을 추가합니다.
4. 세션을 사용하거나 내보내기 전에 저장하고 미리보기를 확인합니다.

## 어디서부터 시작할지 고민된다면

[첫 번째 활동 가져오기](/ko/docs/guide/getting-started)부터 시작해 보세요. 프로필 → 완료 활동 → 훈련 부하 → 훈련 플랜 → 리뷰로 이어지는 가장 작고 완전한 흐름을 따라갈 수 있습니다.
