# 문제 해결

눈에 보이는 증상부터 차근차근 확인하세요. 어느 단계에서 문제가 발생했는지 파악하기 전에는 플랫폼 연동을 해제하고 다시 연결하거나, 활동을 삭제하거나, 플랜을 새로 만들지 않는 것이 안전합니다.

## 로그인 또는 권한 인증이 반복되는 경우

1. 브라우저나 모바일 앱이 서비스에 정상적으로 접속할 수 있는지 확인합니다.
2. OAuth 인증 흐름은 처음 시작한 것과 같은 브라우저 세션 안에서 완료합니다.
3. 다른 로그인 수단을 해제하기 전에 계정에 사용 가능한 로그인 수단이 남아 있는지 확인합니다.
4. 로그인 페이지를 새로고침한 뒤 한 번 다시 시도합니다.

외부 플랫폼 인증은 성공했는데 Trainingload.ai에서 여전히 연결 해제 상태로 보인다면, 해당 플랫폼 연동 대화창을 다시 열어 콜백 오류나 권한 오류가 없는지 확인하세요.

## 동기화한 활동이 보이지 않는 경우

1. 원본 플랫폼에 해당 워크아웃이 실제로 존재하는지 확인합니다.
2. 플랫폼 연동 상태를 점검합니다.
3. 수동 동기화나 보정(reconciliation) 기능이 있다면 한 번 실행합니다.
4. 가져오기 배치 작업이 끝날 때까지 기다립니다.
5. **활동(Activities)** 목록에서 날짜와 종목으로 검색합니다.

연동을 반복해서 해제하고 다시 연결하지 마세요. 원본 권한 문제는 해결되지 않은 채 중복 가져오기 작업만 겹칠 수 있습니다.

## 활동은 보이지만 분석이 불완전한 경우

활동 자체가 목록에 먼저 표시된 뒤 파생 차트가 순차적으로 완성될 수 있습니다. 처리가 끝난 후 페이지를 새로고침해 보세요. 특정 지표 계열만 빠져 있다면 원본 스트림 데이터를 확인합니다.

- 심박수 분석에는 심박수 샘플이 필요합니다.
- 파워 분석에는 파워 샘플과 알맞은 종목·프로필 맥락이 필요합니다.
- 경로 및 고도 보기에는 GPS/고도 데이터가 필요합니다.
- 페이스 및 거리 분석에는 사용 가능한 거리와 시간 데이터가 필요합니다.

## 지표 수치가 이상하게 보이는 경우

다음 순서대로 점검하세요.

1. 종목 유형 및 종목 정의
2. 단위 및 시간대
3. 역치 값 및 적용 시작일
4. 훈련 존 모델 및 사용자 지정 경계값
5. 선택한 부하 소스 우선순위
6. 원본 활동 스트림 데이터

역치 값을 바꾸면 이후 계산의 해석에 영향을 줄 수 있습니다. 특정 워크아웃 하나가 보기 좋게 나오도록 숫자를 억지로 맞추지 말고, 역치를 바꾼 근거를 함께 기록해 두세요.

## 워크아웃이 저장되지 않는 경우

지구력 워크아웃이라면 각 구조화 구간(스텝)에 유효한 시간 또는 거리와 지원되는 목표값이 설정되어 있는지 확인합니다. 근력 워크아웃이라면 아래 조건을 확인하세요.

- 최소 1개 이상의 운동 항목이 존재해야 합니다.
- 모든 운동 항목에 이름이 입력되어 있어야 합니다.
- 모든 운동 항목에 최소 1개 이상의 세트 그룹이 있어야 합니다.
- 모든 운동 항목에 최소 1개 이상의 본 세트(work set)가 포함되어야 합니다.

편집기는 현지화된 검증 오류 메시지를 표시하며, 수정할 수 있도록 유효하지 않은 초안을 닫지 않고 열어 둡니다.

## 다른 곳에서 플랜이 변경된 경우

앱에서 버전 충돌이나 상태 충돌을 알리면, 현재 화면을 불러온 이후 다른 요청으로 플랜이 이미 수정되었다는 뜻입니다. 플랜을 새로고침해 최신 상태를 확인한 뒤 편집 내용을 다시 적용하세요. 오래된 화면에서 삭제나 덮어쓰기 같은 파괴적 작업을 무작정 재시도하지 마세요.

## 모바일 기록 동기화가 완료되지 않은 경우

복구가 가능한 상태라면 앱을 삭제하거나 로컬 저장소를 초기화하지 마세요. 기록 화면을 다시 열어 앱이 세션을 복원하도록 둔 뒤 네트워크에 다시 연결합니다. 자세한 내용은 [모바일 활동 기록](/ko/docs/guide/mobile-recording) 문서를 참고하세요.

## AI 코치가 요청을 완료하지 못하는 경우

- 지나치게 긴 요청은 짧게 줄이거나 여러 단계로 나누어 질문하세요.
- 대상 플랜이나 활동이 여전히 존재하며 접근 가능한 상태인지 확인합니다.
- 계정 사용량 한도를 점검합니다.
- 구조화된 작업이 검증에 실패하면 의도한 변경 내용을 자연어로 풀어 설명한 뒤 다시 시도하세요.
- 변경 전후 미리보기에서 직접 검증할 수 없는 조정안은 절대 적용하지 마세요.

## 문제 해결에 도움이 되는 정보 수집하기

문제를 제보할 때는 아래 정보를 함께 전달해 주세요.

- 대략적인 발생 시각과 시간대
- 웹/모바일 구분, 운영체제, 앱 또는 브라우저 버전
- 인증 정보가 아닌 문제가 발생한 페이지 또는 워크플로
- 공유해도 안전한 범위의 활동 해시 ID, 플랜 ID 또는 연동 플랫폼 이름
- 화면에 표시된 현지화 오류 메시지 원문
- 개인정보를 가린 스크린샷

비밀번호, OAuth 토큰, API 키 또는 정확한 집 좌표 같은 민감 정보는 절대 포함하지 마세요.
