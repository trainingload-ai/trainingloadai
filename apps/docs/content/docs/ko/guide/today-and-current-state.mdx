# 오늘의 조언과 현재 상태 활용하기

웹의 **Home(홈)**이나 모바일 앱의 **Today** 화면을 열어 하루의 훈련 방향을 잡습니다. 현재 플랜, 기록된 활동, 훈련 부하 맥락과 함께 오늘의 조언을 읽고, 실제 상황에 맞는 동작을 선택하세요.

[데모 홈 페이지 열기](https://demo.trainingload.ai/en)에서 화면 구성을 미리 둘러볼 수 있습니다. 데모는 조회 전용이며 워크아웃·알림·플랜 변경을 저장하려면 본인 계정이 필요합니다. 스크린샷은 실제 웹 앱의 예시 화면이며, 모바일에서는 전용 시트와 기록 제어가 제공됩니다.

## 시작하기 전에

계정 시간대, 진행 중인 플랜, 최근 활동의 처리 완료 여부를 먼저 확인합니다. AI 기능을 사용하려면 데이터 공유 설정과 현재 배포 환경에서 표시되는 AI 구성 또는 이용 권한을 확인하세요. 진행 중인 플랜이 있다면 좋은 맥락이 되며, 예정된 워크아웃이 없는 날에는 출발점이 달라집니다.

## 1. 행동을 결정하기 전에 오늘 화면 전체 읽기

홈에서 오늘 날짜와 현재 플랜을 확인합니다. 오늘 예정된 워크아웃, 최근 활동, 현재 상태 또는 주간 부하 섹션을 함께 살펴보세요. 오늘 목록에 표시된 워크아웃은 '계획된 세션'이고, 기록된 활동은 '실제로 수행한 훈련의 근거'입니다.

완료한 활동이 아직 동기화되지 않았다면 해당 활동이 빠진 것처럼 보이는 조언을 해석하기 전에 동기화 상태부터 해결하세요. 필요하면 [훈련 데이터 연동](/ko/docs/guide/connect-data)을 참고합니다.

## 2. 조언 카드를 열어 근거 확인하기

조언 카드를 선택해 상세 시트를 엽니다. 전체 추천 내용과 불확실성 안내, 그리고 제공되는 경우 **Why this recommendation(이 추천의 이유)**까지 읽어 보세요. 표시되는 버튼은 오늘의 추천 내용과 일정에 따라 달라집니다.

- 예정된 세션이 이미 있다면 해당 워크아웃을 바로 여는 버튼이 제공될 수 있습니다.
- 데이터가 부족한 상황이라면 플랫폼 연동, 가져오기 또는 활동 리뷰 진입점이 제공될 수 있습니다.
- 추가 질문이나 의사결정이 필요하다면 해당 AI 코치 대화로 이어지는 버튼이 열립니다.
- 독립 워크아웃 제안이나 알림 설정 버튼은 해당 제안에서 지원할 때만 표시됩니다.

상세 시트를 여는 것만으로는 워크아웃이 생성되거나 플랜이 변경되지 않습니다. 새 활동이나 플랜 정보가 반영되어 조언이 갱신되었다면 행동하기 전에 최신 버전을 다시 읽어 보세요.

## 3. 상황에 맞는 동작 선택하기

### 기존 워크아웃 열기

제공된 워크아웃 버튼을 눌러 날짜, 종목, 구성, 메모, 상태를 확인합니다. 이미 완료한 훈련이라면 완료 라벨만 보지 말고 실제 활동이 올바르게 연결되어 있는지도 함께 확인하세요.

모바일 앱에서는 지원하는 예정 세션에서 바로 지구력 기록이나 근력 훈련 실행으로 진입할 수 있습니다. 해당 흐름은 [모바일 활동 기록](/ko/docs/guide/mobile-recording) 또는 [모바일에서 플랜 작성 및 근력 워크아웃 완료하기](/ko/docs/guide/mobile-plans-and-strength)를 참고하세요.

### 제안된 독립 워크아웃 검토하기

상세 시트에 **Suggested workout(제안된 워크아웃)**이 포함되어 있다면 미리보기를 열어 종목, 운동 시간, 강도, 구성을 점검합니다. 추가 또는 일정 등록 동작을 선택하면 오늘 날짜의 독립 워크아웃(independent workout)으로 생성됩니다. 생성된 일간 워크아웃 화면을 확인해 주세요. 기존 훈련 플랜은 별도의 일정으로 그대로 유지됩니다.

제안이 만료되었거나, 오늘 이미 워크아웃이 예정되어 있거나, 훈련 가능 시간이 지난 경우에는 추가가 제한될 수 있습니다. 제안을 새로고침하고 오늘 일정을 확인한 뒤 다시 시도하세요.

### 알림(리마인더) 설정하기

웹에서는 알림 버튼을 누르고 **Remind me at(알림 시각)**을 고른 뒤 **Schedule(예약)**을 선택합니다. 화면에서 허용하는 시간 범위 안에서 지정하고 저장 성공 피드백을 확인하세요. 알림은 나중에 다시 확인하도록 알려 주는 기능이며, 훈련 완료 처리와는 다릅니다.

모바일에서는 지원하는 알림 시간 옵션을 제공합니다. 실제 알림 수신 여부는 앱의 알림 설정과 기기 권한 설정에도 영향을 받으므로, 매일 같은 시각이 제공된다고 가정하지 말고 표시되는 옵션을 확인하세요.

### AI 코치에게 질문하거나 대기 중인 조정안 리뷰하기

**Coach(AI 코치)**를 선택해 오늘의 추천에 대해 논의할 수 있습니다. 메시지를 보내기 전에 질문 내용과 참조된 활동을 확인하세요. 대기 중인 조정안이나 평가가 있다면 어떤 워크아웃을 대상으로 하는지, 어떤 정보가 필요한지, 확정했을 때 무엇이 바뀌는지 먼저 열어 확인합니다.

활동이나 플랜을 여는 것은 단순 화면 이동이지만, 워크아웃 생성·알림 저장·조정안 확정은 계정 상태를 변경하는 작업입니다. 각 동작의 결과를 개별적으로 확인하세요.

## 4. 실제 수행한 내용 기록하기

훈련이 끝나면 활동을 동기화하거나 가져온 뒤 처리 완료를 기다려 해당하는 예정 세션에 연결합니다. 계획했던 내용과 실제 기록된 시간, 거리, 강도, 훈련 부하를 비교해 보세요.

워크아웃을 다른 날로 옮겼거나, 단축·건너뜀 또는 플랜 외로 수행했다면 그 맥락을 남겨 두는 것이 좋습니다. 기록 업데이트 방법은 [훈련 캘린더](/ko/docs/guide/calendar)와 [진행 중인 플랜 관리](/ko/docs/guide/manage-active-plan)를 참고하세요.

## 5. 모바일 피드백과 현재 상태 카드 활용하기

모바일 조언 시트에서는 오늘 휴식, 다른 곳에서 훈련, 동기화 대기 중, 나중에 리뷰하기 등의 피드백을 선택할 수 있습니다. 이는 조언 생성에 맥락을 더해 주는 입력이며, 완료된 활동 자체는 여전히 정상 경로로 기록하고 동기화해야 합니다.

모바일에서 현재 상태 카드를 맞춤 설정하려면 **Current Status(현재 상태)** 옆의 설정 버튼을 열어 지원하는 지표를 추가하거나 제거하고 카드 순서를 정리한 뒤 편집을 마칩니다. 각 카드를 열면 상세 정보를 볼 수 있으며, 문서 링크를 통해 지표의 의미를 확인할 수 있습니다.

누적 훈련 부하와 기량 추세는 [PMC 예측](/ko/docs/guide/pmc-forecast)과 [지구력 유효 VO2max](/ko/docs/guide/effective-vo2max-for-endurance)에서 이어서 살펴보세요. 현재 상태 카드, 과거 시점 데이터, 미래 예측치는 서로 다른 근거를 나타냅니다.

## 6. 변경 후 새로고침하기

모바일 Today 화면은 아래로 당겨 새로고침(pull-to-refresh)을 지원합니다. 다른 기기에서 활동을 가져오거나 플랜을 수정한 뒤에는 새로고침하여 날짜, 상태, 연결 정보를 확인한 다음 편집을 이어가세요. 웹 화면도 다시 돌아왔을 때 갱신될 수 있으므로 최신 표시 내용을 확인하세요.

## 결과 확인

오늘 예정된 세션, 기록된 활동, 조언의 근거 맥락, 그리고 본인이 선택한 동작의 결과를 명확히 구분할 수 있어야 합니다. 저장한 워크아웃, 활동 연결 또는 알림이 의도한 위치에 표시되는지 확인하세요.

## 자주 묻는 질문

### 오늘의 조언이 보이지 않거나 사용할 수 없는 이유는?

데이터 공유 선택, AI 설정 또는 이용 권한, 요청 상태, 분석 가능한 훈련 근거가 충분한지 확인하세요. 로딩 상태나 대체 안내 문구를 새로 생성된 추천으로 오해하지 말고, 오류 메시지나 재시도 상태를 기준으로 판단합니다.

### 오늘의 조언 내용이 왜 바뀌었나요?

새 활동이 들어오거나, 플랜이 수정되거나, 맥락이 갱신되거나, 기존 제안이 만료되면 조언이 새로고침될 수 있습니다. 이전 제안을 그대로 적용하지 말고 최신 버전을 다시 확인하세요.

### 워크아웃 열기 버튼이 없는 이유는?

표시되는 버튼은 현재 제안 내용과 근거 데이터에 따라 달라집니다. 진행 중인 플랜, 예정 날짜, 워크아웃 상태를 확인한 뒤 캘린더나 플랜 화면에서 해당 세션을 직접 찾아보세요.

### 이미 완료한 워크아웃이 추천 내용에 반영되지 않은 이유는?

동기화 완료 여부, 활동 처리 상태, 현지 날짜, 플랜 연결 상태를 확인하세요. 모바일에서는 누락 기록이 해결되는 동안 해당 피드백 옵션을 남겨 둘 수 있습니다.

### 오늘의 조언이 자동으로 플랜을 변경하나요?

제공되는 버튼과 그 결과를 확인하세요. 단순 추천, 독립 워크아웃 추가, 플랜 조정 제안은 서로 다른 영향을 미칩니다. 검토 및 확정 절차는 [AI 코치](/ko/docs/guide/ai-coach)를 따르세요.
