# PMC 기록 및 예측 읽기

PMC(체력 관리 차트)는 기록된 훈련 부하와 조건부 미래 전망을 한 화면에 보여 줍니다. 누적 훈련 압력이 어떻게 변해 왔는지, 그리고 현재 확보된 미래 입력값에 따르면 앞으로 어떤 흐름이 예상되는지 점검할 때 활용하세요. 예측치는 입력 데이터를 바탕으로 한 추정일 뿐이며, 워크아웃이 실제로 수행되었다거나 특정 훈련 결정이 옳다는 것을 보장하지 않습니다.

[데모에서 체력 관리(PMC) 열기](https://demo.trainingload.ai/en/pmc)에서 읽기 전용 화면을 미리 둘러볼 수 있습니다. 페이지를 연 뒤 확인하려는 종목을 선택하세요. 예측 곡선이 포함된 스크린샷은 앱에서 렌더링한 샘플 데이터를 사용했으며, 데모의 실제 수치와 예측 표시 여부는 현재 데모 기록에 따라 달라집니다.

## 시작하기 전에

- 완료된 활동을 가져오고 훈련 부하 처리가 끝날 때까지 기다립니다.
- 활동의 종목 분류, 역치, 부하 소스 설정, 계정 시간대를 확인합니다.
- 플랜 기반 예측을 보려면 유효한 예상 부하를 가진 예정 워크아웃이 있어야 합니다. 초안 상태이거나 일정에 배치되지 않은 워크아웃은 미래 일간 부하로 자동 반영되지 않습니다.
- 차트를 해석할 때는 기록된 훈련, 예정된 훈련, 최근 훈련 습관 추정치를 명확히 구분하세요.

## 1. 체력 관리 페이지 열기 및 종목 선택

분석 도구에서 **PMC / Fitness management**를 엽니다. 오른쪽 상단의 **Sport(종목)** 필터에서 전체 종목(All sports), 러닝(Running), 사이클링(Cycling), 수영(Swimming) 중 하나를 선택하면 상단 세 개의 현재 상태 카드와 차트가 해당 범위로 갱신됩니다.

특정 훈련 블록을 점검할 때는 단일 종목부터 시작하는 것이 좋습니다. 대시보드, PMC, 개별 활동 화면을 오갈 때마다 종목 범위가 같은지 다시 확인하세요.

메인 PMC 페이지는 보통 과거 60일의 기록과 향후 28일의 전망을 함께 보여 줍니다. 한 번에 선택한 지표 하나의 곡선을 그리며 그 아래에 일간 부하 막대가 표시됩니다.

## 2. 전망을 보기 전에 현재 수치부터 읽기

상단 세 카드는 반드시 함께 읽으세요.

| 지표 | 설명하는 내용 | 증명하지 않는 내용 |
| --- | --- | --- |
| 체력 (Fitness / CTL) | 장기적으로 누적된 훈련 부하 | 실제 경기력 향상의 확정적 증명 |
| 피로 (Fatigue / ATL) | 최근 훈련 압력에 민감하게 반응하는 단기 신호 | 주관적 피로도에 대한 의학적 진단 |
| 컨디션 (Form / TSB) | 장기 부하와 최근 부하의 균형 관계 | 특정 워크아웃이나 대회의 준비 완료 보장 |

상단 카드는 '현재까지 기록된 상태'를 보여 줍니다. 마우스를 미래 날짜로 옮겨도 상단 카드가 예측치로 바뀌지는 않습니다. 각 지표의 계산 방식은 [CTL](/ko/docs/metrics/pmc/chronic-training-load), [ATL](/ko/docs/metrics/pmc/acute-training-load), [TSB](/ko/docs/metrics/pmc/training-stress-balance)를 참고하세요.

## 3. 지표 전환 및 특정 날짜 상세 확인

1. 차트 상단에서 **Form(컨디션)**, **Fitness(체력)** 또는 **Fatigue(피로)**를 선택합니다.
2. 확인하려는 날짜 위로 포인터를 옮깁니다. 툴팁에 날짜, 기록(Recorded) 또는 예측(Projected) 여부, CTL, ATL, TSB, 일간 부하가 표시됩니다.
3. 미래 날짜라면 숫자뿐 아니라 표시된 예측 근거(basis)도 함께 읽으세요.
4. 같은 날짜의 곡선 변화와 하단 일간 부하 막대를 비교합니다. 곡선의 이동 폭과 일간 부하 자체는 서로 다른 물리량입니다.

차트는 키보드 탐색도 지원합니다. 차트에 포커스를 두고 좌우 화살표 키로 날짜를 이동할 수 있으며, **Escape** 키로 툴팁을 닫습니다. 터치 화면에서는 차트의 날짜를 탭해 확인할 수 있습니다.

## 4. 기록된 이력과 조건부 예측 구분하기

범례와 **Today(오늘)** 경계선을 기준으로 방향을 잡으세요. 기록된 과거 값은 실선으로, 제공되는 미래 추정치는 점선으로 그려집니다. 하단 일간 부하 패널도 기록된 부하는 진하게 채운 막대로, 미래 부하는 연한 스타일로 구분해 보여 줍니다.

일반 예측은 사용 가능한 예정 훈련(Scheduled training)을 우선 반영합니다. 해당 날짜에 적용 가능한 예정 입력이 없을 때는 충분히 최근이고 활용 가능한 훈련 습관 패턴을 사용할 수 있습니다. 특정 날짜에 어떤 근거가 적용되었는지는 툴팁에서 확인하세요.

| 표시되는 근거 | 해석 방법 |
| --- | --- |
| Scheduled training(예정 훈련) | 적용 가능한 예정 워크아웃에서 미래 부하를 가져옵니다. |
| Recent training habits(최근 훈련 습관) | 최근 훈련 패턴의 추정치를 사용합니다. 캘린더에 새 워크아웃이 추가된 것은 아닙니다. |
| Pause training(훈련 중단) | 표시된 시나리오가 해당 기간 추가 훈련이 없다고 가정합니다. |
| No forecast(예측 없음) | 현재 입력 데이터로 해당 날짜의 값을 산출할 수 없습니다. |

차트를 여는 것만으로 훈련이 일정에 등록되거나 플랜 변경이 저장되지는 않습니다. 예정 워크아웃이 없는 날이 자동으로 확정된 휴식일을 의미하지 않으며, 누락된 부하를 0으로 읽어서는 안 됩니다.

전망 기간 중간에 예측이 끊기면 이후 날짜는 앞선 누락 입력에 의존하기 때문에 함께 비어 있을 수 있습니다. 새 활동을 가져오거나 일정을 변경하면 전망도 함께 갱신됩니다.

## 5. 미래 구간이 비어 있을 때 이해하기

미래 곡선이 그려지지 않더라도 과거 기록 자체는 여전히 유용합니다. 예측이 비어 있는 흔한 원인은 훈련 기록이 너무 짧거나 오래되었거나, 기록된 부하가 누락되었거나, 예정 워크아웃에 유효한 예상 부하가 없는 경우입니다.

날짜와 종목 범위를 먼저 확인한 뒤 최근 활동과 해당 일정을 점검하세요. 툴팁에 **No forecast available(예측 불가)**이 표시되면 그 불확실성을 그대로 유지하세요. 페이지에 **Update failed; showing the previous result(업데이트 실패, 이전 결과 표시 중)**가 뜨면 새로고침이 성공한 것이 아니라 직전 결과를 유지하고 있는 상태입니다. 초기 요청 자체가 실패한 경우 **Retry(재시도)** 버튼이 표시됩니다.

## 6. 이 맥락을 담아 AI 코치에게 질문하기

페이지 상단의 **Ask Coach(AI 코치에게 묻기)**를 선택하면 선택한 종목과 전망 맥락이 담긴 질문이 AI 코치로 전달됩니다. 전송하기 전에 준비된 질문 문구를 확인하세요. 링크를 여는 것만으로 훈련 일정이 변경되지는 않습니다.

최근 부하 급증이나 예정 세션 시기처럼 실제로 고민 중인 문제를 함께 적어 보세요. 답변에 사용된 활동과 미래 가정을 검증한 뒤, 제안된 플랜이나 워크아웃 수정은 일반 확정 절차를 거쳐 적용합니다.

마라톤 특화 조정 사례는 [PMC로 마라톤 훈련 조정하기](/ko/docs/guide/pmc-marathon-adjustment)에서 이어서 살펴보세요.

## 대시보드에서 더 짧은 기간 살펴보기

대시보드의 Fitness(체력), Fatigue(피로), Form(컨디션) 카드를 열면 개별 지표 상세 뷰로 들어갈 수 있습니다. 여기서는 **7일**, **14일**, **30일**, **60일** 기록 탭을 제공하며, 표시되는 미래 예측 구간도 선택한 탭에 맞춰 최대 30일까지 달라집니다. 이는 메인 PMC 페이지의 넓은 전망 범위와 다릅니다.

차트를 해석하기 전에 선택한 기간 탭을 확인하고, 현재 기록 수치와 선택한 미래 날짜 수치의 차이를 계속 구분하세요.

## 결과 확인

확인한 지점에 대해 종목, 날짜, 지표, 기록/예측 상태, 일간 부하 근거를 정확히 설명할 수 있어야 합니다. 좋은 해석은 곡선의 변화를 실제 활동이나 예정 입력과 연결하고, 근거가 부족한 부분은 솔직하게 짚어 냅니다.

## 자주 묻는 질문

### 미래 날짜에 마우스를 올려도 상단 카드 수치가 바뀌지 않는 이유는?

상단 카드는 현재 기록된 상태를 보여 줍니다. 선택한 미래 날짜의 수치는 차트 툴팁에서 확인하세요.

### 워크아웃을 완료한 뒤 예측 곡선이 바뀐 이유는?

실제 활동 부하와 플랜 연결 정보가 예측 입력을 갱신하기 때문입니다. 결과를 비교하기 전에 활동 처리가 끝나고 의도한 워크아웃에 연결되었는지 확인하세요.

### 대시보드 카드와 메인 PMC의 차트 기간이 다른 이유는?

대시보드 개별 카드의 기록 탭은 더 짧은 미래 예측 창을 함께 제어합니다. 화면 위 점의 위치만 보지 말고 같은 종목과 같은 날짜를 기준으로 비교하세요.

### 차트에서 예측 시나리오를 직접 바꿀 수 있나요?

메인 페이지에서는 종목과 지표 선택을 제공하며, 일반 방문 시 적용 가능한 플랜과 습관 입력을 자동으로 반영합니다. 일부 코치 링크나 공유 링크는 다른 시나리오를 담고 있을 수 있으므로 모든 화면이 같은 가정이라고 단정하지 말고 날짜 툴팁의 근거(basis)를 확인하세요.

### 색상이 칠해진 TSB 구간대가 준비 완료를 증명하나요?

색상 구간대는 부하 맥락을 읽기 위한 참고 기준일 뿐입니다. 실제 컨디션이나 경기력에 영향을 미치는 모든 요인을 반영하지는 않습니다.
