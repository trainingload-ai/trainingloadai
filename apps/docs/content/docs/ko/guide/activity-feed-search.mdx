# 활동 피드 및 검색

활동 피드는 Trainingload.ai에서 완료된 모든 워크아웃이 모이는 중심 목록입니다. 동기화된 활동, 업로드한 파일, 수동 가져오기, 지도 미리보기, 훈련 부하 수치, 플랜 연결 상태를 한눈에 볼 수 있습니다.

다음과 같은 질문에 답할 때 활용하세요.

- 최근에 어떤 훈련을 했는가?
- 새로 가져온 활동이 정상적으로 들어왔는가?
- 아직 리뷰가 필요한 워크아웃은 무엇인가?
- 이 활동이 올바른 플랜 워크아웃에 연결되어 있는가?
- 더 깊은 분석을 위해 활동 상세 페이지로 어디서 들어가는가?

## 시작하기 전에

- 외부 플랫폼을 연동하거나 [활동 파일을 업로드](/ko/docs/guide/upload-activity-files)합니다.
- 특정 가져오기 기록을 찾을 때는 대략적인 날짜, 종목, 소스를 알고 있으면 빠릅니다.
- 활동을 플랜에 연결하려는 경우 해당 플랜이 진행 중(Active)이고 활동 날짜가 플랜 기간 안에 포함되는지 확인합니다.

## 리뷰 워크플로

1. **Activities(활동)**를 열고 피드를 새로고침합니다.
2. 최신 카드와 각 활동의 처리 상태를 확인합니다.
3. 기간, 종목 등 화면의 필터를 사용해 목록을 좁힙니다.
4. 누락된 지표나 부하를 판단하기 전에 활동 상세 화면을 먼저 엽니다.
5. 날짜, 종목, 세션 목적을 확인한 뒤 예정된 워크아웃에 연결합니다.

## 활동 피드

**Activities(활동)**를 열면 최근 워크아웃 목록이 표시됩니다. 각 활동 카드에는 다음 정보가 포함될 수 있습니다.

- 활동 제목
- 종목 유형
- 시작 시각
- 거리 및 운동 시간
- 훈련 부하(산출 가능한 경우)
- 원본 소스(Garmin, Strava, 수동 업로드 등)
- 활동 상태
- 경로 데이터가 있을 때의 지도 썸네일
- 활동 날짜가 진행 중인 플랜 기간에 속할 때의 플랜 워크아웃 연결 표시

스크롤하면 이전 항목이 이어서 불러와지며, 모바일에서는 목록 상단을 아래로 당겨 새로고침할 수 있습니다.

## 활동 상태

활동 카드에는 다음과 같은 상태가 표시될 수 있습니다.

- **Synced(동기화됨)**: Trainingload.ai로 가져오기 또는 동기화가 완료된 상태
- **Pending review(리뷰 대기 중)**: 기록은 준비되었으나 아직 리뷰되지 않은 상태
- **Reviewed(리뷰 완료)**: 리뷰 흐름을 거쳐 이미 검토가 완료된 상태
- **Unknown(알 수 없음)**: 상태 정보를 확인할 수 없는 경우

상태 라벨은 목록을 빠르게 분류하는 데 유용하지만 활동 상세 페이지를 대신하지는 않습니다. 차트, 세부 지표 또는 처리 결과가 중요하다면 활동을 직접 열어 확인하세요.

## 검색 및 필터

피드가 너무 넓을 때는 활동 검색 기능을 활용합니다.

빠른 필터 예시:

- 최근 7일
- 최근 30일
- 러닝(Run)
- 사이클링(Cycling)
- 수영(Swim)

검색 페이지의 필터로 목록을 좁혀 보세요. 찾는 활동이 보이지 않는다면 필터를 초기화하고 날짜 범위를 넓힌 뒤 종목과 소스를 다시 확인합니다.

## 활동 상세 열기

요약 카드 이상의 정보가 필요할 때 활동을 클릭해 상세 화면을 엽니다.

상세 페이지에서 확인할 수 있는 내용:

- 전체 요약 지표
- 차트 및 시계열 데이터
- 경로 및 지형 맥락
- 훈련 부하와 강도
- 심박수, 파워, 페이스, 고도 신호
- 해당 워크아웃 대상 AI 코치 질문 프롬프트

자세한 내용은 [활동 상세 분석](/ko/docs/guide/activity-detail)을 참고하세요.

## 플랜 워크아웃에 활동 연결하기

진행 중인 플랜이 있고 활동 날짜가 플랜 기간 안에 속하면 활동 카드에 플랜 연결 제어가 표시될 수 있습니다.

이를 사용해 완료된 워크아웃을 의도한 플랜 세션과 연결하세요. 연결해 두면 Trainingload.ai에서 다음을 정확하게 비교할 수 있습니다.

- 예정된 워크아웃 vs 완료된 활동
- 예상 부하 vs 실제 부하
- 완료 상태
- 플랜 이행률
- AI 코치의 플랜 후속 분석

잘못된 워크아웃에 연결되었다면 연결을 해제하고 올바른 항목을 수동으로 다시 선택하세요.

## 활동 내보내기 또는 삭제

활동 카드 메뉴에는 다음 항목이 포함될 수 있습니다.

- **View(보기)**: 활동 상세 페이지를 엽니다.
- **Export(내보내기)**: 지원하는 경우 활동을 GPX, FIT 또는 TCX 파일로 다운로드합니다.
- **Delete(삭제)**: 확인 후 활동을 삭제합니다.

삭제는 신중하게 사용하세요. 플랜 워크아웃에 연결된 활동을 삭제하면 플랜 실행 요약과 부하 비교 결과도 함께 바뀔 수 있습니다.

## 지도 보기 진입

활동 페이지에서 지도 뷰를 여는 진입점이 제공될 수 있습니다. 다음과 같이 경로 맥락이 중요할 때 지도를 활용하세요.

- 여러 경로 비교
- 어디서 훈련했는지 시각적으로 리뷰
- GPS 기반 활동 빠르게 찾기
- 경로가 끊겼거나 비정상적인지 확인

지도는 위치 맥락 파악에 유용하며, 세부 지표 분석은 활동 상세 페이지에서 확인하는 것이 가장 좋습니다.

## 문제 해결

활동이 보이지 않는 경우:

- 가져오기 배치가 완료되었는지 확인합니다.
- 피드를 새로고침합니다.
- 더 넓은 날짜 범위로 검색합니다.
- 원본 플랫폼에 실제로 해당 워크아웃이 존재하는지 확인합니다.
- 활동이 삭제되었거나 필터에 의해 숨겨지지 않았는지 확인합니다.

훈련 부하나 차트가 보이지 않는 경우:

- 활동 상세 페이지를 열어 처리 상태를 확인합니다.
- 원본 파일에 필요한 센서 데이터가 포함되어 있는지 확인합니다.
- 프로필의 역치와 훈련 존 설정을 확인합니다.
- 방금 업로드한 활동이라면 분석 처리가 끝날 때까지 잠시 기다립니다.

## 결과 확인

- 의도한 활동이 정확한 시작 시각, 종목, 소스로 한 번만 표시됩니다.
- 카드를 열면 해당 활동의 상세 페이지로 이동합니다.
- 연결된 활동이 단순히 가까운 날짜가 아니라 실제로 의도한 예정 워크아웃에 연결되어 있습니다.
- 필터를 해제해도 활동이 예기치 않게 사라지지 않습니다.
- 내보내기나 삭제는 확인된 대상 활동에 대해서만 수행합니다.
