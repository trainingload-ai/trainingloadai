# 근력 워크아웃

근력 워크아웃은 시간과 거리 중심의 지구력 단계 대신 운동 종목, 세트, 반복 횟수, 부하, 강도(Effort), 휴식 시간으로 구성되어야 합니다. Trainingload.ai는 전용 근력 편집기를 제공하며, 완료된 근력 활동과 계획된 처방을 나란히 비교해 보여 줄 수 있습니다.

## 시작하기 전에

- 플랜 초안 또는 편집 가능한 향후 워크아웃을 엽니다. 완료된 활동을 새 처방으로 덮어쓰지 마세요.
- 종목으로 **근력 훈련(Strength Training)**을 선택해 근력 편집기를 엽니다.
- **수동(Manual)** 모드와 **규칙(Rules)** 모드 중 편한 방식을 선택합니다. 두 모드 모두 동일한 워크아웃 구조로 저장됩니다.
- 운동 이름, 장비, 신뢰할 수 있는 중량 또는 1RM 수치, 목표 RPE/RIR을 준비합니다. 정확한 수치 부하를 알 수 없다면 **오픈 부하(Open Load)**를 선택하세요.

## 2. 세션 가이드 설정하기

예정 소요 시간과 세션 RPE는 플랜에 유용할 때만 입력합니다. 세션 RPE는 각 세트의 목표 강도가 아니라 세션 전체의 의도된 난이도를 나타냅니다.

## 3. 운동 추가하기

모든 운동에는 비어 있지 않은 이름이 필요합니다. 나중에 계획과 완료 세션을 쉽게 비교할 수 있도록 일관되고 알아보기 쉬운 이름을 사용하세요. 장비는 선택 항목이며, 운동 이름을 반복하기보다 필요한 기구를 명확히 적는 데 사용합니다.

예시:

- 백 스쿼트(Back Squat) — 바벨(Barbell)
- 루마니안 데드리프트(Romanian Deadlift) — 바벨(Barbell)
- 풀업(Pull-up) — 맨몸(Bodyweight)
- 스플릿 스쿼트(Split Squat) — 덤벨(Dumbbells)

## 4. 세트 그룹 추가하기

세트 그룹은 동일한 처방으로 반복하는 세트 묶음을 정의합니다.

- **웜업(Warm-up)** — 준비 세트이며 선택 사항입니다.
- **본 세트(Work)** — 핵심 훈련 처방을 정의하는 세트이며 모든 운동에 필수입니다.

반복 기반 운동은 반복 횟수를, 등척성·버티기 운동은 시간을 선택합니다. 반복 범위를 지정할 때는 최솟값이 최댓값보다 크지 않아야 합니다.

## 5. 부하(Load) 선택하기

- **오픈 부하(Open load)** — 수치 중량을 지정하지 않습니다. 장비 상황이나 현재 근력 수준을 알 수 없을 때 사용합니다.
- **고정 중량(Fixed weight)** — 지원되는 단위가 포함된 수치 중량입니다.
- **1RM 백분율(Percent of 1RM)** — 해당 운동의 최신 1RM이 정확히 알려져 있을 때만 적합합니다.
- **맨몸(Bodyweight)** — 선수의 체중을 부하로 사용합니다.
- **맨몸 가감(Bodyweight offset)** — 지원되는 경우 체중에 외부 중량을 더하거나 보조 중량을 뺍니다.

AI가 생성하는 근력 플랜은 도구로 확인된 이력이나 알려진 1RM이 없을 때 kg, lb, 1RM 백분율을 임의로 지어내지 않아야 합니다. 오픈 부하에 RPE/RIR 큐를 조합하는 것이 더 안전한 기본값입니다.

## 6. 강도와 휴식 시간 추가하기

주관적 운동 강도는 RPE로, 예비 반복 횟수는 RIR로 표현합니다. 내부 일관성을 유지하고, 의도적인 대비가 아닌 이상 과도한 중량과 지나치게 쉬운 강도 목표를 함께 처방하지 마세요.

휴식 시간은 세트 그룹별로 저장됩니다. 모든 운동에 같은 휴식 시간을 일괄 적용하기보다 의도한 수행 품질을 유지할 수 있을 만큼 충분한 시간을 배정하세요.

## 7. 근력 DSL로 동일한 워크아웃 작성하기

**규칙(Rules)** 모드에서는 근력 세션을 다음과 같이 작성할 수 있습니다.

```text
duration 50m
session rpe 6

exercise "Back Squat" equipment barbell {
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 80kg rpe 7 rest 3m
}

exercise "Pull Up" equipment bodyweight {
  work 3x8 bodyweight rir 2 rest 90s
}
```

전체 문법, 다국어 운동 이름, 부하 형식, 검증 흐름 및 오류 해결 방법은 [근력 워크아웃 DSL](/ko/docs/planning/strength-workout-dsl)을 참고하세요. 근력 DSL은 정적 처방 형식이며 `if/else`, 주간 프로그레션, 디로드 스크립트, 중첩 블록, 임의 실행 스크립트는 지원하지 않습니다.

## 워크아웃 검증하기

저장하기 전에 다음을 확인합니다.

- 운동이 최소 1개 이상 존재합니다.
- 모든 운동에 이름이 입력되어 있습니다.
- 모든 운동에 세트 그룹이 최소 1개 이상 있습니다.
- 모든 운동에 본 세트(Work) 그룹이 최소 1개 이상 포함되어 있습니다.
- 세트 수, 반복 횟수, 초, 강도, 부하가 지원 범위 내에 있습니다.
- 미리보기가 의도한 세션과 일치합니다.

저장한 뒤 워크아웃을 다시 열어 시각적 빌더나 정규화된 근력 DSL에 동일한 구조가 유지되는지 확인합니다. 미리보기 요약에는 의도한 운동 수와 본 세트 수가 정확히 집계되어야 합니다.

## 문제 해결

- **“모든 운동의 이름을 입력하세요(Enter a name for every exercise)”:** DSL에서는 큰따옴표 안에 비어 있지 않은 이름을 입력하고, 시각적 빌더에서는 운동 이름 필드를 채웁니다.
- **“각 운동에는 최소 1개의 세트 그룹이 필요합니다(Each exercise needs at least one set group)”:** 운동 블록을 닫기 전에 웜업 또는 본 세트 그룹을 추가합니다.
- **“각 운동에는 최소 1개의 본 세트가 필요합니다(Each exercise needs at least one work set)”:** 웜업만 있는 운동은 유효하지 않으므로 `work` 줄을 1개 이상 추가합니다.
- **반복 범위 검증 실패:** `3x8-12`처럼 낮은 값을 먼저 적습니다.
- **부하 또는 강도 검증 실패:** 지원되는 부하 형식을 사용하고 RPE와 RIR 중 하나만 선택합니다.
- **닫는 중괄호가 거부됨:** 각 운동 블록을 한 번만 닫고 운동 블록 안에 다른 운동을 중첩하지 마세요.
- **근력에서 지구력으로 전환 시 편집기 초기화:** 두 구조는 의도적으로 분리되어 있습니다. 종목을 바꾸기 전에 필요한 텍스트를 저장하거나 복사해 두세요.

## 완료된 근력 세션

근력 활동에는 운동 종목, 세트 완료 여부, 세션 완료 현황을 기록할 수 있습니다. 운동이 끝나면 근력 활동 상세 화면을 열어 운동 이름, 완료된 세트, 부하, 반복 횟수/시간, 전체 세션 맥락을 확인한 뒤 리뷰에 활용하세요.
