# Trainingload에서 워크아웃을 수동으로 편집하는 방법

이 페이지는 **Trainingload.ai 내부의 수동 워크아웃 편집기(Manual Workout Editor) 제품 가이드**입니다. 훈련 플랜을 연 뒤 예정된 워크아웃을 편집하는 과정—종목 선택, 지구력 단계 또는 근력 세트 추가, 세션 미리보기, 유효한 초안 저장—을 단계별로 설명합니다.

이 화면은 독립형 공개 **워크아웃 편집기**나 **워크아웃 빌더**가 아닙니다. 브라우저에서 무료로 단계를 초안 작성하고 워크아웃 DSL을 복사할 수 있는 도구가 필요하다면 [워크아웃 편집기 및 빌더](/ko/workout-editor)를 사용하세요. 앱 내 저장, 근력 빌더, 플랜 일자별 워크플로가 필요할 때 이 가이드로 돌아오면 됩니다.

## 시작하기 전에

- 수동 플랜 또는 편집 가능한 플랜 워크아웃을 엽니다.
- 구간(Zone)이나 백분율 목표에서 참조할 선수 임곗값이 올바르게 설정되었는지 확인합니다.
- 세션이 지구력 훈련인지 근력 훈련인지 결정합니다.
- 먼저 공개 초안만 빠르게 만들고 싶다면 [워크아웃 편집기에서 세션을 작성](/ko/workout-editor)한 뒤 여기에 붙여넣거나 옮겨 적을 수 있습니다.

## 1. 종목 선택하기

수동 편집기는 계획 작성에 집중할 수 있도록 핵심 종목 목록만 제공합니다.

- 러닝: 러닝(Running), 트레일 러닝(Trail Running), 트레드밀(Treadmill)
- 사이클링: 사이클링(Cycling), 산악자전거(Mountain Biking), 실내 사이클링(Indoor Cycling)
- 수영: 수영장 수영(Pool Swimming), 오픈워터 수영(Open Water Swimming)
- 기타: 근력 훈련(Strength Training)

선택한 종목에 따라 사용 가능한 목표 단위가 달라지며, 워크아웃 구조 유형 자체도 바뀔 수 있습니다. 지구력과 근력 사이를 전환하면 호환되지 않는 초안 구조가 초기화되므로 세부 단계를 입력하기 전에 종목부터 선택하세요.

## 2. 이름과 메모 추가하기

이름에는 “유산소 인터벌”이나 “하체 근력”처럼 세션을 한눈에 알아볼 수 있는 짧은 제목을 입력합니다. 메모에는 기계 구조로 변환되지 않아야 할 사람 중심 안내를 작성합니다.

- 동작 및 자세 큐(Technique cues)
- 준비물 및 장비 알림
- 보급(Fueling) 지침
- 코스 또는 지형 메모
- 훈련을 중단하거나 강도를 줄여야 하는 조건

DSL 필드에 일반 서술문을 적지 마세요. 워크아웃 단계는 수동(Manual) 또는 규칙(Rules) 모드에 넣고, 코칭 맥락은 메모에 작성해야 합니다.

## 3. 지구력 워크아웃 작성하기

수동(Manual) 모드에서 단계(Step) 또는 반복(Repeat) 모듈을 추가합니다. 각 단계는 다음 순서로 설정합니다.

1. 웜업(warm-up), 본 운동(work), 회복(recovery) 등 단계 유형을 선택합니다.
2. 운동 시간 또는 거리를 설정합니다.
3. 선수의 신뢰할 수 있는 기준값이 있을 때만 목표(Target)를 추가합니다.
4. 인터벌 훈련은 동일한 본 운동과 회복 단계를 여러 번 복사하는 대신 반복(Repeat) 모듈을 사용합니다.
5. 구조를 변경할 때마다 미리보기 차트를 확인합니다.

유효한 지구력 구조에는 의미 있는 단계가 최소 1개 이상 필요합니다. 범위(Range) 목표를 지정할 때는 시작 값이 종료 값보다 크지 않아야 합니다.

## 4. 근력 워크아웃 작성하기

**근력 훈련(Strength Training)**을 선택하면 근력 빌더가 열립니다. [근력 워크아웃](/ko/docs/planning/strength-workouts) 안내에 따라 운동 종목과 본 세트를 추가하세요. 텍스트로 입력하려면 [근력 워크아웃 DSL](/ko/docs/planning/strength-workout-dsl)을 참고합니다.

## 5. 필요할 때 규칙(Rules) 모드 사용하기

규칙(Rules) 모드는 지원되는 워크아웃 DSL을 입력받는 모드입니다. 간결한 작성과 반복 가능한 텍스트 관리에 유용하지만, 자유 형식의 코칭 메모 입력란은 아닙니다.

규칙 모드에서 저장하기 전에 다음을 확인합니다.

- 지원되는 DSL 표현식 하나당 하나의 지침만 작성합니다.
- 자연어 설명은 메모란에 작성합니다.
- 입력 결과를 검증하고 렌더링된 구조를 확인합니다.
- 종목에 맞는 문법은 [지구력 워크아웃 DSL](/ko/docs/planning/workout-dsl) 또는 [근력 워크아웃 DSL](/ko/docs/planning/strength-workout-dsl)을 참고합니다.
- 먼저 [공개 워크아웃 편집기에서 동일한 DSL 초안을 작성](/ko/workout-editor)한 뒤 여기에 붙여넣을 수도 있습니다.

## 6. 저장하기

**초안 저장(Save Draft)**을 선택합니다. Trainingload.ai는 워크아웃을 플랜 초안에 추가하기 전에 유효성을 검증합니다.

## 저장된 워크아웃 검증하기

다음을 확인합니다.

- 종목 라벨이 정확합니다.
- 미리보기가 의도한 본 운동/회복 순서 또는 근력 세트 구성과 일치합니다.
- 메모가 워크아웃 구조와 분리되어 유지됩니다.
- 저장된 워크아웃이 올바른 주차, 요일, 세션 순서에 표시됩니다.
- 충분한 정보가 있을 때만 예상 훈련 부하가 표시됩니다.

## 문제 해결

- **종목 목록에 예상과 다른 항목이 없거나 다름:** 수동 플랜 워크아웃 편집기를 사용 중인지 확인합니다. 생성 목록은 위에서 설명한 9개 종목으로 제한되며, 활동 분류 화면에는 더 넓은 카탈로그가 표시됩니다.
- **종목을 바꾸면 초안이 사라짐:** 지구력 구조와 근력 구조는 서로 호환되지 않습니다. 종목을 먼저 선택하고, 전환 전에 재사용할 메모나 규칙 텍스트를 복사해 두세요.
- **지구력 미리보기가 비어 있음:** 의미 있는 단계를 추가하고 시간·거리 및 목표 값이 유효한지 확인합니다.
- **목표 범위가 거부됨:** 낮은 값을 높은 값보다 먼저 입력하고 선택한 종목에 맞는 단위인지 확인합니다.
- **“모든 운동의 이름을 입력하세요(Enter a name for every exercise)” 오류:** 모든 근력 운동의 이름을 직접 입력해야 합니다. 플레이스홀더 텍스트는 저장되지 않습니다.
- **근력 운동이 저장되지 않음:** 모든 운동에 세트 그룹 1개 이상과 본 세트(Work set) 1개 이상을 추가해야 합니다.
- **규칙(Rules) 오류가 영어로 표시됨:** 원본 서버 메시지를 메모에 복사하지 마세요. 현지화된 알림, 선택한 종목, 오류가 발생한 DSL 줄을 기록해 지원팀에 전달하세요.
- **저장된 워크아웃이 다른 날짜에 표시됨:** 플랜 시작일, 주차/요일 오프셋, 세션 순서, 계정 시간대를 확인합니다.

## 자주 묻는 질문(FAQ)

### 수동 워크아웃 편집기란 무엇인가요?

Trainingload 앱 내에서 예정된 워크아웃 하나를 편집하는 화면입니다. 종목을 선택하고 지구력 단계나 근력 운동을 추가한 뒤 코칭 메모를 붙이고 미리보기를 확인해 특정 주차와 요일에 저장할 수 있습니다. 공개 [워크아웃 편집기 및 빌더](/ko/workout-editor)는 별도의 초안 작성 도구입니다.

### Trainingload에서 워크아웃을 수동으로 편집하려면 어떻게 하나요?

편집 가능한 플랜 워크아웃을 열고 종목을 먼저 선택한 뒤 단계나 반복 모듈을 추가합니다. 시간 또는 거리를 설정하고 임곗값이 신뢰할 수 있을 때만 목표를 지정하세요. 인터벌은 같은 쌍을 여러 번 복사하는 대신 반복 모듈을 사용하는 것이 좋습니다.

### 앱 내 편집기에서 근력 세션도 만들 수 있나요?

네. **근력 훈련(Strength Training)**을 선택하면 근력 빌더가 열립니다. 이름이 지정된 운동과 운동당 최소 1개의 본 세트를 추가하세요. 텍스트로 입력하려면 [근력 워크아웃 DSL](/ko/docs/planning/strength-workout-dsl)을 사용합니다.

### 수동(Manual) 모드와 규칙(Rules) 모드 중 무엇을 쓰면 좋을까요?

클릭으로 단계를 조립하고 싶다면 수동 모드를, 간결하고 재사용 가능한 DSL 텍스트로 작성하고 싶다면 규칙 모드를 사용합니다. 코칭 설명문은 DSL 필드에 넣지 말고 메모에 작성하세요. 자세한 내용은 [지구력 워크아웃 DSL](/ko/docs/planning/workout-dsl)을 참고하세요.

### 종목을 바꿨더니 초안이 초기화된 이유는 무엇인가요?

지구력 구조와 근력 구조는 호환되지 않기 때문입니다. 세부 단계를 입력하기 전에 종목을 먼저 선택하고, 종목을 바꿔야 한다면 재사용할 메모나 규칙을 미리 복사해 두세요.

- 전체 일정이 준비되었다면 [플랜 상태 및 가져오기 관리](/ko/docs/planning/plan-lifecycle)를 확인하고 플랜을 활성화하세요.
- 텍스트/규칙 기반 작성법은 [지구력 워크아웃 DSL](/ko/docs/planning/workout-dsl)을 참고하세요.
- 시각적 근력 빌더는 [근력 워크아웃](/ko/docs/planning/strength-workouts)을 참고하세요.
- 세션을 완료한 뒤에는 [AI 코치 리뷰로 안전하게 훈련 부하 조정하기](/ko/ai-training-plan)를 활용해 보세요.
