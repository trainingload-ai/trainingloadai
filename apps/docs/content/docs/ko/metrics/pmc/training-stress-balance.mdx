# 컨디션(TSB)이란 무엇인가요?

**컨디션(TSB)**, 즉 훈련 스트레스 균형(Training Stress Balance)은 체력(CTL)과 피로(ATL)의 차이입니다. 빠르게 움직이는 최근 훈련 부하가 완만한 장기 훈련 부하 모델에 비해 어느 위치에 있는지를 보여 줍니다.

“컨디션”은 이해하기 쉬운 UI 명칭입니다. TSB는 두 개의 모델링된 부하 곡선에서 파생된 값이며, 경기 준비도, 회복 상태, 건강 또는 경기력을 직접 측정하지 않습니다.

## 수치의 출처

TSB에는 별도의 활동 입력값이 없습니다. Trainingload.ai는 동일한 일일 부하 시계열로 같은 날의 CTL(42일 시간 상수)과 ATL(7일 시간 상수)을 먼저 계산합니다. 따라서 두 곡선 중 하나라도 바꿀 수 있는 활동 기록, 역치, 부하 소스 설정 변경은 TSB도 함께 변화시킵니다.

TSB는 CTL·ATL과 동일한 모델링 부하 척도를 사용하며, 백분율이나 생리학적 단위가 아닙니다.

## 공식

Trainingload.ai는 Intervals.icu에서 사용하는 당일(same-day) 기준을 따릅니다.

```text
TSB_today = CTL_today − ATL_today
```

예를 들어 오늘의 CTL이 50이고 ATL이 65라면 TSB는 `50 − 65 = −15`가 됩니다.

모든 플랫폼이 같은 날짜 기준을 쓰는 것은 아닙니다. Intervals.icu는 당일 CTL에서 당일 ATL을 빼는 반면, TrainingPeaks는 공개 문서에서 오늘의 Form을 어제의 Fitness에서 어제의 Fatigue를 뺀 값으로 설명합니다. 플랫폼 간 수치를 비교하기 전에 날짜 기준, 시간 상수, 부하 소스를 반드시 확인하세요.

## 컨디션(TSB) 해석 방법

- **음수 TSB:** ATL이 CTL보다 높습니다. 즉, 최근 모델링 부하가 장기 모델 수준보다 높습니다.
- **0 부근 TSB:** 두 부하 곡선이 가까이 붙어 있습니다. 생리적으로 완벽한 균형 상태임을 증명하지는 않습니다.
- **양수 TSB:** ATL이 CTL보다 낮습니다. 즉, 최근 모델링 부하가 장기 모델 수준보다 낮습니다.

훈련 부하를 늘리면 보통 ATL이 CTL보다 빨리 올라 TSB가 하락합니다. 휴식이나 테이퍼링 기간에는 ATL이 더 빨리 떨어지므로 TSB가 상승합니다. 부호는 부하 곡선 간의 수학적 관계를 나타낼 뿐, 선수가 반드시 느껴야 할 컨디션을 규정하지 않습니다.

## 활용과 한계

TSB는 빌드 주간, 회복 주간, 테이퍼링이 의도한 대로 최근 부하와 장기 부하의 관계를 바꾸고 있는지 확인하는 데 도움이 됩니다. 선수 본인의 과거 유사한 훈련 시기와 비교할 때 가장 가치가 큽니다.

반면 TSB만으로는 레이스 준비 완료를 단정하거나, 음수 값을 무조건 위험하다고 규정하거나, 양수 값을 최적이라고 단정하거나, 휴식일을 처방하거나, 통증·질병의 원인을 설명할 수 없습니다.

보편적인 “피크”, “최적”, “고위험” 구간을 맹목적으로 쫓지 마세요. 적절한 구간은 부하 계산 방식, 종목, 훈련 경력, 개인 반응, 데이터 품질에 따라 크게 달라집니다. 항상 [체력(CTL)](/ko/docs/metrics/pmc/chronic-training-load), [피로(ATL)](/ko/docs/metrics/pmc/acute-training-load), 원본 활동, 경기력 추세, 주관적 상태를 함께 살피시기 바랍니다.
