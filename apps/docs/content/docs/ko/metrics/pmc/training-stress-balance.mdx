# 컨디션(TSB)이란?

**컨디션(TSB)**은 체력(CTL)과 피로(ATL)의 차이입니다. 빠르게 반응하는 최근 부하가 느린 장기 부하 모델에 비해 어디에 있는지 보여 줍니다.

TSB는 두 부하 곡선에서 파생된 모델 값이며, 준비도, 회복, 건강 또는 경기력을 직접 측정하지 않습니다.

```text
TSB_today = CTL_today − ATL_today
```

CTL이 50이고 ATL이 65이면 TSB는 `−15`입니다. Trainingload.ai는 Intervals.icu와 같은 당일 기준을 사용합니다. TrainingPeaks의 공개 설명은 오늘의 Form에 전날의 Fitness와 Fatigue를 사용하므로, 플랫폼 비교 전 날짜 기준, 시간 상수와 부하 소스를 확인해야 합니다.

음수는 ATL이 CTL보다 높다는 뜻이고, 양수는 낮다는 뜻입니다. 0에 가깝다는 것은 두 곡선이 비슷하다는 의미일 뿐 생리적 균형을 증명하지 않습니다. 부하를 쌓을 때는 보통 내려가고 휴식이나 테이퍼 때는 올라가지만, 부호가 선수의 느낌을 결정하지는 않습니다.

보편적인 ‘피크’, ‘최적’, ‘위험’ 구간을 안전 기준으로 사용하지 마세요. [체력(CTL)](/ko/docs/metrics/pmc/chronic-training-load), [피로(ATL)](/ko/docs/metrics/pmc/acute-training-load), 원본 활동, 수행 추세와 주관적 상태를 함께 확인하세요.
