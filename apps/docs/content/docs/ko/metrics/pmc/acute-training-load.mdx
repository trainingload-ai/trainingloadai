# 피로(ATL)란?

**피로(ATL)**, 즉 급성 훈련부하는 일일 훈련부하를 빠르게 반영하는 지수평균입니다. 최근 날짜에 더 큰 가중치를 주기 때문에 체력(CTL)보다 빠르게 변합니다. Trainingload.ai의 기본 시간 상수는 7일입니다.

‘피로’는 이해하기 쉬운 화면 명칭입니다. ATL은 모델로 계산한 최근 부하를 요약할 뿐, 생리적·주관적 피로, 회복, 건강 또는 적응을 직접 측정하지 않습니다.

## 데이터와 공식

Trainingload.ai는 각 활동에서 파워, 심박수, 페이스 또는 세션 RPE 기반 부하 중 우선순위에 맞는 값을 선택합니다. 같은 날의 여러 활동은 `daily_load`로 합산하며, 기록된 부하가 없는 날은 0으로 계산합니다.

```text
decay_ATL = exp(-1 / 7)
ATL_today = ATL_yesterday × decay_ATL + daily_load × (1 − decay_ATL)
```

기본값에서는 `decay_ATL ≈ 0.866878`이고 오늘 부하의 가중치는 약 `0.133122`입니다. 7일은 단순한 최근 7일 평균이 아니라 **시간 상수**입니다. 일정한 일일 부하로 바뀌면 ATL은 한 시간 상수에서 변화량의 약 63.2%, 세 시간 상수에서 약 95%를 반영합니다.

ATL은 최근 부하가 현재 수준보다 높으면 상승하고, 휴식·회복·테이퍼 기간에는 하락합니다. 상승했다는 사실만으로 실제 피로나 부하 적응 여부를 판단할 수는 없습니다.
