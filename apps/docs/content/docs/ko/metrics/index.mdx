# 훈련 용어집

최종 업데이트: 2026-05-23

이 페이지는 Trainingload.ai의 지구력 훈련 지표 용어집입니다. 훈련 부하, PMC, 파워, 심박수, 페이스, VO2 Max, 생리학 문서 전반에서 사용하는 용어를 설명하고, 각 용어의 상세 레퍼런스 페이지로 연결합니다.

훈련 지표는 서로 함께 볼 때 가장 큰 가치를 발휘합니다. 단일 수치만으로 훈련 상태를 온전히 설명하기는 어렵습니다. 부하 지표는 훈련 자극의 크기를, 심박수는 신체 내부 반응을, 파워와 페이스는 외부 출력을, 생리학 지표는 바탕이 되는 신체 능력을 설명합니다.

## 핵심 용어 요약

| 용어 | 쉬운 의미 | 주요 활용 |
| ------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 훈련 부하 | 완료한 훈련들이 시간에 따라 누적되어 만들어 내는 신체적 스트레스입니다. | 부하를 늘릴지, 유지할지, 회복할지 판단할 때 |
| PMC | 모델링된 CTL, ATL, TSB 부하 이력을 통합해 보여 주는 성과 관리 차트(Performance Management Chart)입니다. | 장기 부하 추세와 최근 부하 추세를 시간에 따라 비교할 때 |
| CTL | 만성 훈련 부하(Chronic Training Load)로, 완만하게 변하는 장기 부하 추세입니다. | 장기적인 훈련 부하 맥락을 파악할 때 |
| ATL | 급성 훈련 부하(Acute Training Load)로, 빠르게 변하는 최근 부하 추세입니다. | 최근 훈련 부하의 변화를 포착할 때 |
| TSB | 훈련 스트레스 균형(Training Stress Balance)으로, 현재 CTL에서 현재 ATL을 뺀 값입니다. | 최근 모델링 부하와 장기 모델링 부하의 차이를 확인할 때 |
| TSS | 훈련 스트레스 점수(Training Stress Score)로, 운동 시간과 강도를 반영한 훈련 부하 점수입니다. | 개별 훈련이나 주간 부하를 비교할 때 |
| TRIMP | 훈련 임펄스(Training Impulse)로, 심박수 기반의 훈련 부하 추정치입니다. | 파워 데이터가 없을 때 내부 부하를 추정할 때 |
| FTP | 기능적 역치 파워(Functional Threshold Power)로, 실용적인 역치 파워 기준점입니다. | 파워 존과 훈련 목표를 설정할 때 |
| CP | 임계 파워(Critical Power)로, 모델링된 지속 가능 파워 경계입니다. | 파워-지속시간 능력과 W′를 이해할 때 |
| LTHR | 젖산 역치 심박수(Lactate Threshold Heart Rate)로, 실용적인 역치 심박수 기준점입니다. | 심박수 존을 설정할 때 |
| VO2 Max | 최대산소섭취량 또는 추정된 유산소 능력 기준치입니다. | 유산소 능력의 장기 추세를 추적할 때 |

## 이 용어집 활용 방법

이 용어집은 단독 판정 도구가 아니라 전체 구조를 파악하는 지도로 활용하시기 바랍니다. 부하 변화를 살펴보려면 훈련 부하, PMC, CTL, ATL, TSB부터 확인한 뒤 모델 뒤에 있는 실제 활동과 선수 맥락을 점검하세요. 훈련 강도를 설정하려면 FTP, CP, LTHR, 파워 존, 심박수 존, 페이스 존부터 시작하시면 됩니다. 장기적인 경기력 반응을 검토할 때는 VO2 Max, 유효 VO2max, 생리학 지표, 훈련의 질, 주관적 컨디션 신호를 함께 확인하세요.
