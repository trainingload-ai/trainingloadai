# 정규화 경사도 페이스 (NGP)

**정규화 경사도 페이스(Normalized Graded Pace, NGP)**는 러닝용 강도 지표입니다. **[GAP(경사도 보정 페이스)](/ko/docs/metrics/pace/grade-adjusted-pace)**를 기반으로 하며, 계산 논리는 사이클링의 **[NP(정규화 파워)](/ko/docs/metrics/power/normalized-power)**와 유사합니다.

쉽게 비교하면 다음과 같습니다.
- **GAP**이 답하는 질문: “이 오르막·내리막 페이스는 평지에서 어느 정도 페이스와 같은가?” (순간/구간 단위 등가치)
- **NGP**가 답하는 질문: “경사와 속도 변화가 섞인 이번 러닝 전체는, 평지에서 어느 정도 일정 페이스로 달린 것과 비슷한 생리학적 부담을 주는가?” (세션 전체 등가치)

## 핵심 개념

생리학적 비용(글리코겐 소모, 젖산 축적, 전반적인 대사 스트레스)은 강도에 따라 **비선형적**으로 증가합니다.

> **예시**:
> 5:00/km로 일정하게 달리는 러닝보다, “절반은 4:00/km + 절반은 6:00/km”로 달리는 러닝이 신체에 훨씬 큰 부담을 줍니다.
> 두 러닝의 평균 페이스는 똑같이 5:00/km이지만, 두 번째 러닝의 **NGP**는 의미 있게 더 빠르게 산출되어 급가속 구간이 만든 높은 생리학적 비용을 반영합니다.

## 계산 과정

NGP는 경사도가 보정된 강도 스트림으로 계산한 뒤 다시 페이스 형태로 표시합니다.

### 정규화 단계

페이스는 시간 값(숫자가 작을수록 빠름)이기 때문에 Trainingload.ai는 가중치를 적용하기 전에 먼저 GAP을 속도/강도 등가값으로 변환한 뒤 NP와 유사한 정규화를 적용합니다.

1. **변환**: GAP 페이스를 속도 또는 강도 값으로 변환합니다.
2. **평활화**: 30초 이동 평균(rolling average)을 계산합니다.
3. **가중치 적용**: 고강도 구간을 강조하기 위해 4제곱 가중치를 적용합니다.
4. **평균 및 제곱근**: 평균을 구한 뒤 4제곱근을 취합니다.
5. **표시**: 읽기 쉽도록 결과를 다시 페이스 단위로 변환합니다.

```text
NGP_intensity = 4th_root( (1/N) * sum_{i=1..N} (GAP_intensity_rolling(i))^4 )
```

## 주요 활용 사례

### 1. 트레일 및 산악 러닝의 실제 강도 파악
고저차가 큰 지형에서는 평균 페이스가 매우 느리게 보일 수 있습니다. NGP는 실제 운동 강도가 결코 낮지 않았음을 보여 줍니다.
- **예시**: 산악 트레일 러닝의 평균 페이스가 10:00/km입니다.
- **NGP**: 실제 신체가 겪은 대사 스트레스를 반영해 훨씬 빠른 페이스로 표시될 수 있습니다.

### 2. 페이스 기반 러닝 부하 추정

Trainingload.ai는 체중 기록이 있을 때 GOVSS를 사용합니다. 체중이 없으면 기록된 페이스와 활동 시작 시 유효한 러닝 역치로 rTSS 방식의 부하를 추정합니다. 역치 페이스(TP)를 우선하며, 없으면 임계 속도(CS)를 사용합니다. 실측 파워나 심박수는 필요하지 않습니다.

```text
100 × observed hours × (normalized speed / threshold speed)²
```

경사 데이터가 유효한 페이스 기록 시간의 80% 이상이면 경사를 보정합니다. 경사가 기록되지 않은 구간은 평지로 처리합니다. 완전한 30초 구간이 없으면 관측된 평균 속도를 사용합니다. 페이스가 기록되지 않은 시간은 제외합니다.

## 지표 비교

| 지표 | 정식 명칭 | 의미 | 적합한 활용 |
| :--- | :--- | :--- | :--- |
| **평균 페이스 (Avg Pace)** | Average Pace | 실제 평균 페이스 | 평지 지속주, 완주 시간 예측 |
| **평균 GAP (Avg GAP)** | Average GAP | 경사도 보정 평균 페이스 | 큰 가감속 없는 완만한 기복 코스 |
| **NGP** | Normalized Graded Pace | 정규화 경사도 페이스 | 트레일, 인터벌, 복합 지형, rTSS 계산 |

## Trainingload.ai의 NGP 활용 방식

- **지형을 반영한 강도 기준**: 언덕이 많거나 페이스 변동이 큰 러닝에서는 평균 페이스보다 NGP가 더 정확한 정보를 제공합니다.
- **VI와 함께 활용**: **VI(변동성 지수) = NGP / Avg GAP**로 계산할 수 있습니다.
  - VI가 1.0에 가까우면 일정한 페이스로 달렸다는 뜻입니다.
  - VI > 1.05이면 인터벌 훈련이었거나 지형 변화가 매우 큰 코스였을 가능성이 높습니다.
