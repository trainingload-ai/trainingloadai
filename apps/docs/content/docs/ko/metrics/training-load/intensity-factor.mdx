# 강도 계수 (IF)란? 사이클링과 러닝에서의 활용

**강도 계수(Intensity Factor, IF)**는 역치 대비 훈련 강도를 나타내는 비율로, [정규화 파워(NP)](/ko/docs/metrics/power/normalized-power) ÷ [FTP](/ko/docs/metrics/power/functional-threshold-power)로 계산합니다. “이번 세션이 내 능력 대비 얼마나 힘들었는가?”에 답해 주므로, 똑같은 150 W 라이딩이라도 어떤 선수에게는 가벼운 회복 주행이고 다른 선수에게는 전력 주행인 차이를 정확히 구분해 줍니다.

즉, 체력 수준이 서로 다른 선수들 사이에서도 상대적인 훈련 강도를 공정하게 비교할 수 있게 해 주는 지표입니다.

## 계산 공식

IF는 [정규화 파워(NP)](/ko/docs/metrics/power/normalized-power)와 [기능적 역치 파워(FTP)](/ko/docs/metrics/power/functional-threshold-power)의 비율입니다.

$$
IF = \frac{NP}{FTP}
$$

**예시**:
- FTP가 200 W라고 가정합니다.
- NP = 150 W로 라이딩을 완료했습니다.
- 이때 $IF = 150 / 200 = 0.75$가 됩니다.

> **참고**: 러닝에도 동일한 논리가 적용됩니다(rFTP 또는 NGP 사용). 심박수는 **지연과 드리프트** 때문에 파워보다 정밀도가 떨어지는 편입니다.

### 러닝에서의 IF 계산

러닝 파워를 사용하는 경우 보통 **rFTP(러닝 역치 파워)**나 **CP(임계 파워)**를 기준값으로 사용합니다.

$$
IF_{run} = \frac{RunPower}{CP}
$$

페이스를 사용하는 경우의 공식은 다음과 같습니다.

$$
IF_{pace} = \frac{NGP}{ThresholdPace}
$$

*참고: [NGP(정규화 경사도 페이스)](/ko/docs/metrics/pace/normalized-graded-pace)는 경사도가 보정된 정규화 페이스입니다.*

## IF에 주목해야 하는 이유

### 1. 선수 간 공정한 비교
- **절대 파워**: 프로 선수에게 200 W는 가벼운 강도이지만 초보자에게는 전력일 수 있습니다. 와트 수치만으로는 노력의 크기를 알 수 없습니다.
- **상대 강도 (IF)**: 두 선수의 IF가 똑같이 0.75라면, 둘 다 본인 능력 대비 같은 수준의 유산소 지구력 훈련을 수행한 것입니다.

### 2. 훈련 존 즉시 파악
IF는 세션이 어느 강도 영역에 해당하는지 가장 빠르게 확인하는 수단입니다.

| IF 범위 | 훈련 존 | 대표적인 설명 |
| :--- | :--- | :--- |
| **< 0.75** | **Z1 / Z2** | **회복 / 유산소 지구력**. 가볍거나 편안한 강도로 기반 훈련이나 회복 세션에 주로 사용됩니다. |
| **0.75 - 0.85** | **Z3 / 스위트 스팟** | **템포 / 스위트 스팟**. 종목과 시간에 따라 비교적 오래 지속할 수 있는 중상 강도입니다. |
| **0.85 - 0.95** | **Z4** | **역치**. FTP 부근의 매우 강한 강도로, 인터벌이나 타임트라이얼에서 흔히 나타납니다. |
| **0.95 - 1.05** | **Z5** | **VO2max**. 매우 높은 강도로, 주로 짧은 인터벌 형태로 수행합니다. |
| **> 1.05** | **Z6 / Z7** | **무산소 / 스프린트**. 짧은 폭발적 출력으로 단거리 레이스나 테스트에서 주로 나타납니다. |

## 주요 활용 시나리오

### 1. FTP 설정 검증
**단독 1시간 타임트라이얼(TT)** 전체에서 **IF ≈ 1.1**(즉, NP가 FTP의 1.1배)을 유지했다면 **FTP가 실제보다 너무 낮게 설정**되어 있을 가능성이 높습니다.
- **이유**: FTP는 대체로 약 1시간 동안 거의 일정하게 유지할 수 있는 최고 파워로 간주합니다. 1시간 내내 IF가 1.0을 크게 웃돈다면 역치 추정치를 재검토해야 합니다.

### 2. 레이스 페이싱 전략
장거리 지구력 경기에서 IF를 통제하면 후반부 페이스 유지와 보급 전략을 지키는 데 큰 도움이 됩니다.

| 레이스 유형 | 목표 IF 범위 | 리스크 참고 |
| :--- | :--- | :--- |
| **아이언맨 (풀코스)** | **0.65 - 0.75** | 사이클 강도가 이보다 높으면 이어지는 런 구간과 보급 실패 위험이 커집니다. |
| **하프 아이언맨 (70.3)** | **0.75 - 0.85** | 상단 구간은 공격적인 전략이며 런 내구성에 크게 좌우됩니다. |
| **올림픽 코스** | **0.85 - 0.95** | 역치에 가까운 사이클 주행이므로 런 구간을 위한 여력을 남겨야 합니다. |

### 3. 훈련 스트레스 점수(TSS)의 핵심 구성 요소
IF는 **[TSS](./training-stress-score)**의 핵심 승수로서 TSS가 얼마나 빠르게 누적되는지를 결정합니다.

$$
TSS = \frac{t \times NP \times IF}{FTP \times 3600} \times 100
$$

- IF가 조금만 올라가도 TSS는 크게 상승합니다(공식상 실질적으로 $IF^2$에 비례).

## Trainingload.ai 권장 사항

Trainingload.ai는 총부하뿐 아니라 훈련의 성격을 해석하는 데 IF를 활용합니다.

1. **세션 목표에 맞는 IF 유지**: 유산소 기반 세션은 절제된 IF를 유지하고, 역치나 VO2max 세션은 의도적으로 높게 가져가세요.
2. **매우 짧은 세션 주의**: 약 20분 미만의 짧은 훈련에서는 IF가 비정상적으로 높게 보일 수 있으므로 장시간 지속주와 같은 기준으로 해석하지 마세요.
3. **역치 설정 점검**: 이지 세션인데도 IF가 자주 0.8을 넘는다면 실제로 너무 강하게 훈련하고 있거나 역치 설정을 다시 보정해야 할 때입니다.

## 한계점

- **짧은 고강도 세션의 편향**: 약 10분 내외의 매우 짧은 훈련에서는 NP 계산 특성상 IF가 유난히 높게 나올 수 있습니다.
- **정확한 FTP 의존성**: FTP가 오래되었거나 부정확하면 IF 수치의 의미도 함께 떨어집니다.

## 자주 묻는 질문

### 강도 계수(IF)란 무엇인가요?

강도 계수는 `NP ÷ FTP`(러닝에서는 `NGP ÷ 역치 페이스`)입니다. 대부분의 선수에게 IF 0.75는 잘 통제된 유산소 세션이고, IF 1.0 부근은 약 1시간 동안의 역치 강도 노력에 해당합니다.

### 사이클링 훈련에서 IF는 어떻게 활용하나요?

라이딩이 의도한 존에 머물렀는지 확인하고, 장거리 레이스 페이스를 설계하며, FTP가 너무 낮게 설정되지 않았는지 점검하는 데 활용합니다(1시간 내내 IF ≈ 1.1을 유지했다면 대개 FTP가 과소평가된 상태입니다).

### 러닝에도 IF를 적용할 수 있나요?

네, 러닝 역치 파워/CP 또는 NGP와 역치 페이스를 이용해 적용할 수 있습니다. 심박수 기반 IF는 심박 지연과 드리프트 때문에 정밀도가 낮습니다.

### IF가 변하면 TSS는 어떻게 달라지나요?

TSS는 $IF^2$에 비례해 증가합니다. 운동 시간을 늘리는 것보다 IF를 조금 올리는 쪽이 부하를 훨씬 크게 키우며, 잘못된 FTP가 IF와 TSS를 동시에 왜곡하는 이유도 여기에 있습니다.
