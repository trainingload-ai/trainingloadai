# 정규화 파워 (NP)

**정규화 파워(Normalized Power, NP)**는 변동이 심한 파워 출력을 하나의 등가 일정 강도로 환산한 지표입니다. 직관적으로는 다음 질문에 답하려는 개념입니다.

- 이번 라이딩과 똑같은 생리학적 부담을 일정한 파워로 탔다면 몇 와트였을까?

단순 평균 파워와 달리 NP는 고강도 급가속(surge) 구간에 더 민감하게 반응하므로, 파워 기반 TSS 같은 훈련 부하 추정에 매우 유용합니다.

## NP가 필요한 이유

운동 생리학에 따르면 운동 강도와 생리학적 비용(글리코겐 소모, 젖산 축적, 호르몬 스트레스)은 선형 관계가 아니며, 고강도로 갈수록 부담이 기하급수적으로 커집니다.

### 선형 vs. 지수
- **선형 관점 (평균 파워)**: 200 W로 1시간 일정하게 타는 것과 “100 W로 30분 + 300 W로 30분” 타는 것은 평균 파워가 똑같이 200 W입니다.
- **생리학적 관점 (NP)**: 300 W 구간이 만드는 부담은 100 W 구간에서 회복되는 양보다 훨씬 큽니다. 후자의 실제 체감과 대사 비용은 약 260–270 W로 일정하게 탄 것에 더 가깝습니다.

NP는 **4제곱 가중치(fourth-power weighting)**로 고출력 구간을 강조함으로써 단순 평균보다 실제 대사 비용에 더 가깝게 근사합니다.

## Trainingload.ai의 NP 계산 방식

Trainingload.ai는 표준 NP 정의를 따릅니다. 30초 이동 평균을 구한 뒤 4제곱하여 평균을 내고, 마지막에 4제곱근을 취합니다.

```text
P_smooth(t) = (1/30) * sum_{i=0..29} P(t-i)
NP = 4th_root( (1/N) * sum_{j=1..N} (P_smooth(j))^4 )
```

각 기호의 의미는 다음과 같습니다.
- $P(t)$: 시점 $t$에서의 순간 파워
- $P_{smooth}(t)$: 시점 $t$에서의 30초 이동 평균 파워
- $N$: 전체 샘플 수

## 주요 활용 사례

### 1. 레이스 분석
- **크리테리움(Criterium)**: 코너 탈출마다 반복되는 급가속 때문에 NP가 평균 파워보다 훨씬 높게 나타납니다. 이때 NP가 레이스의 실제 난이도를 훨씬 정확히 반영합니다.
- **타임트라이얼(TT) / 트라이애슬론**: 일정한 페이싱이 핵심이므로 NP가 평균 파워에 가까워야 합니다. NP가 평균 파워보다 크게 높다면 페이싱 변동이 과도했다는 신호입니다.

### 2. 훈련 부하 (TSS)
NP는 [TSS(훈련 스트레스 점수)](/ko/docs/metrics/training-load/training-stress-score) 계산의 핵심 입력값입니다.

```text
IF = NP / FTP
TSS ∝ Duration_sec * NP * IF
```

NP를 사용하면 인터벌처럼 강도 변동이 큰 워크아웃의 훈련 부하를 단순 평균 파워보다 훨씬 현실적으로 반영할 수 있습니다.

> **Trainingload.ai 권장 사항**:
>
> 1. **짧은 시간에서는 의미가 줄어듦**: 약 20분 미만의 짧은 활동에서는 신체가 정상 상태에 도달하지 않아 NP 노이즈가 커질 수 있습니다. 스프린트 세션은 최대 파워, 평균 파워, 인터벌 구간 지표로 평가하세요.
> 2. **NP를 인위적으로 부풀리지 마세요**: 회복 라이딩에서 NP를 높이려고 중간에 스프린트를 섞지 마세요. NP는 세션의 목적에 부합해야 합니다.
> 3. **VI와 함께 확인하세요**: [VI(변동성 지수)](./variability-index) = `NP / Avg Power`와 나란히 보세요. VI가 높을수록 출력 변동이 큰 라이딩이었다는 뜻입니다.

## 한계점

- 신뢰할 수 있는 파워 데이터에 의존합니다. 신호 끊김(dropout)이나 기기 오류가 결과에 영향을 미칩니다.
- 이동 창과 샘플링 방식에 민감합니다. 샘플링 주기나 보간 방식에 따라 NP가 소폭 달라질 수 있습니다.
- “비용 강도”를 반영할 뿐 실제 피로를 직접 측정하지는 않습니다. NP 자체가 곧바로 회복 필요량이나 근육 손상 정도를 뜻하지는 않습니다.
