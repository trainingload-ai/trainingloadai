# 파워 존 (Power Zones)

**파워 존(Power Zones)**은 연속적인 파워 출력을 실행 가능한 훈련 “기어(단계)”로 나누어 줍니다. Z1–Z7 또는 Z1–Z5 같은 일관된 언어로 강도를 소통하고, 훈련 목표를 에너지 시스템과 페이싱 시나리오에 정확히 연결할 수 있게 해 줍니다.

## 기준 파워: FTP / CP

존 백분율을 계산하려면 기준 파워가 필요합니다.

- **FTP**: [기능적 역치 파워(FTP)](./functional-threshold-power) 참고
- **CP**: 특히 Stryd 같은 러닝 파워 모델에서는 [임계 파워(CP)](./critical-power) 참고

이미 FTP나 CP를 알고 있다면 [파워 존 계산기](/ko/power-zones-calculator)에서 각 존의 와트 경계를 바로 계산해 보세요.

## 존 경계 해석 방법

아래의 모든 “% FTP” 구간은 **서로 겹치지 않는** 구간으로 표기되어 있습니다. 예를 들어:

- Z1: ≤ 55%
- Z2: 56%–75%

수치가 경계값에 정확히 걸릴 때(예: 128%)는 일관된 규칙으로 배정해야 합니다. Trainingload.ai는 모호함을 없애기 위해 경계값을 보통 **상위 존**에 배정합니다(예: 128% → Z7).

## 1. 조 프리엘(Joe Friel): 7단계 사이클링 모델

조 프리엘 모델은 회복부터 신경근 스프린트까지 7개 존으로 구분합니다. 사이클링에서 가장 널리 쓰이며, 적절한 역치 기준이 있다면 러닝에도 적용할 수 있습니다.

| 존 | 한국어 명칭 | 영문 명칭 | % FTP | 주요 활용 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 능동적 회복 | Active Recovery | ≤ 55% | 가벼운 페달링 / 회복 런, 회복 촉진 |
| **Z2** | 지구력 | Endurance | 56%–75% | LSD / 유산소 기반 구축, 유산소 능력 및 지방 산화 향상 |
| **Z3** | 템포 | Tempo | 76%–90% | 일정 강도 지속 훈련, 내구성 및 글리코겐 경제성 향상 |
| **Z4** | 역치 | Threshold | 91%–105% | 역치 훈련, 지속 파워와 역치 능력 향상 |
| **Z5** | VO2max | VO2 Max | 106%–120% | VO2 인터벌, 고강도 유산소 상한선 향상 |
| **Z6** | 무산소 | Anaerobic | 121%–150% | 무산소 인터벌, 젖산 내성 및 반복 출력 향상 |
| **Z7** | 신경근 | Neuromuscular | ≥ 151% | 짧은 스프린트 / 급가속, 신경근 동원 능력 강화 |

> 출처: [Joe Friel](https://joefrieltraining.com/a-quick-guide-to-setting-zones/)

## 2. 짐 밴스(Jim Vance): 7단계 러닝 모델

짐 밴스 모델 역시 7개 존을 사용하지만 저강도 구간을 더 세분화합니다. Z1–Z3가 일상의 “걷기 / 이지 / 지속주” 단계와 잘 맞아떨어져 지구력과 템포 강도를 정교하게 조절하는 데 유리합니다.

| 존 | 한국어 명칭 | 영문 명칭 | % FTP | 주요 활용 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 회복 / 걷기 | Recovery/Walking | ≤ 80% | 회복, 워밍업, 매우 가벼운 강도 |
| **Z2** | 지구력 | Endurance | 81%–88% | 핵심 유산소 지구력 구간, 장시간 지속 가능 |
| **Z3** | 템포 | Tempo | 89%–95% | 역치에 가까워지는 높은 지속 강도 |
| **Z4** | 역치 | Threshold | 96%–105% | 역치 훈련 및 내구성 강화 |
| **Z5** | 고강도 | High Intensity | 106%–115% | 고강도 인터벌 (상위 유산소) |
| **Z6** | VO2 | VO2 | 116%–128% | VO2 인터벌 (경계값 128%는 보통 Z7에 배정) |
| **Z7** | 무산소 능력 | Anaerobic Capacity | ≥ 128% | 무산소 능력과 폭발력 중심의 짧은 반복 훈련 |

> 출처: [Jim Vance, *Run with Power*](https://www.velopress.com/books/run-with-power/)

## 3. Stryd: 5단계 러닝 모델

Stryd 모델은 고강도 구간을 통합해 러닝에 특화된 간결한 5단계 구조를 사용합니다. 주로 **CP**를 기준값으로 사용하지만, FTP를 기준으로 써도 백분율 매핑은 동일합니다.

| 존 | 한국어 명칭 | 영문 명칭 | % FTP | 주요 활용 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 이지 | Easy | ≤ 80% | 회복 런 및 가벼운 이지 러닝 |
| **Z2** | 모더레이트 | Moderate | 81%–90% | 일정 강도 지구력 런, 장거리 주력 강도 |
| **Z3** | 역치 | Threshold | 91%–100% | 역치 및 템포 훈련의 핵심 구간 |
| **Z4** | 인터벌 | Interval | 101%–115% | VO2 / 고강도 인터벌 |
| **Z5** | 레피티션 | Repetition | ≥ 116% | 짧은 반복 질주, 스프린트, 무산소 폭발력 |

## 존 경계 계산 방법

기준 파워(FTP 또는 CP)를 $B$라고 할 때, 각 존 경계는 백분율을 $B$에 곱해 구합니다.

```text
W = B * (pct / 100)
```

### 예시: FRIEL Z2 (56%–75%)

$B = 250 W$라고 가정하면 다음과 같습니다.

```text
Z2_min = 250 * 0.56 = 140 W
Z2_max = 250 * 0.75 = 187.5 W
```

따라서 Z2 구간은 대략 **140 W – 188 W**가 됩니다(실제 화면 표시는 정수 와트로 반올림될 수 있습니다).

## Trainingload.ai 권장 사항

Trainingload.ai는 계획된 강도와 실제 완료된 강도를 비교하는 데 파워 존을 활용합니다.

1. **종목별 역치 분리 설정**: 러닝 파워와 사이클링 파워는 수치가 다릅니다. CP/FTP를 종목별로 따로 관리하고 알맞은 모델을 선택하세요.
2. **주기적 업데이트**: 훈련에 따라 FTP와 CP가 변합니다. 존이 실제 체력과 어긋나지 않도록 정기적으로 재측정하거나 자동 추정을 활용하세요.
3. **벽이 아니라 목표 대역으로 활용**: 존 경계는 절대적인 벽이 아닙니다. 훈련의 대부분이 의도한 생리적 자극 대역 안에 머물도록 하는 것이 핵심입니다.
4. **완료된 훈련 리뷰**: 세션 후 존 분포를 보면 회복일이 너무 강해졌는지, 핵심 인터벌이 목표 구간에 도달했는지 한눈에 확인할 수 있습니다.
