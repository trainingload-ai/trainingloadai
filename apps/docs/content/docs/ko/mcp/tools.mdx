# MCP 도구 레퍼런스

이 페이지는 서버 기능 카탈로그에서 자동 생성됩니다. 직접 편집하지 말고 `pnpm --dir apps/server mcp:reference`를 실행하세요. 모든 도구는 OAuth로 승인된 선수의 데이터만 읽습니다.

> `health:read`는 기본 승인 권한에 포함되지 않습니다. 클라이언트는 `get_health_summary`를 처음 호출하기 전에 점진적 권한 승인을 요청해야 합니다.

| 도구 | 용도 | OAuth 권한 범위(스코프) |
| --- | --- | --- |
| `get_training_snapshot` | 승인된 선수의 최근 훈련 부하, 체력(CTL), 피로(ATL), 폼(TSB), 주간 변화량 및 최근 활동을 한 번에 집계합니다. 범위가 좁은 도구를 여러 번 호출하기 전에 이 도구를 우선 사용하세요. | `training:read` `plan:read` `activity:read` |
| `get_athlete_profile` | 승인된 선수의 선호 종목과 훈련 역치를 조회합니다. 이름, 이메일, 생년월일 또는 내부 사용자 ID는 반환하지 않습니다. | `profile:read` |
| `list_activities` | 제한된 범위 내에서 승인된 선수의 활동 요약을 검색합니다. 원시 센서 스트림이나 정밀 GPS 트랙은 반환하지 않습니다. | `activity:read` |
| `get_activity` | 불투명 해시 ID로 승인된 단일 활동을 조회합니다. 요약 지표만 반환하며 정밀 경로와 원시 센서 샘플은 제외됩니다. | `activity:read` |
| `get_activity_zones` | 승인된 단일 활동에 저장된 심박수, 파워, 페이스 존 분포를 조회합니다. 집계 시간과 비율만 반환하며 센서 샘플은 포함되지 않습니다. | `activity:read` |
| `get_activity_splits` | 불투명 페이지네이션을 사용해 승인된 단일 활동의 제한된 랩 또는 스플릿 요약을 조회합니다. 정확한 좌표와 원시 센서 샘플은 제외됩니다. | `activity:read` |
| `get_activity_statistics` | 제한된 기간 동안 종목별 활동 수, 활동 일수, 시간, 거리 및 표준 훈련 부하를 지표 커버리지와 잘림(truncation) 상태와 함께 집계합니다. | `training:read` `activity:read` |
| `get_training_load` | 최대 180일 범위 내에서 승인된 선수의 훈련 부하, 체력(CTL), 피로(ATL), 폼(TSB) 시계열을 조회합니다. | `training:read` |
| `compare_training_periods` | 제한된 두 훈련 기간의 훈련 부하, 일평균 부하, 활동 일수를 비교합니다. 이 결과는 관찰 자료이며 체력이나 회복 상태의 변화를 단정하지 않습니다. | `training:read` |
| `get_training_breakdown` | 최대 180일 범위 내에서 승인된 선수의 훈련 부하를 러닝, 사이클링, 수영 및 기타 부하로 분해합니다. | `training:read` |
| `get_training_consistency` | 14~180일 동안의 저장 일수 커버리지, 연속 활동 일수, 일별 부하 변동성 및 주간 훈련 부하를 요약합니다. 누락된 날짜는 0으로 처리하지 않고 누락 상태로 유지합니다. | `training:read` |
| `get_training_readiness` | 현재 훈련 부하, 폼, 신선도 및 최근 부하 구간을 관찰 기반 훈련 지표로 반환합니다. 이는 의학적 평가나 훈련 지시가 아닙니다. | `training:read` `plan:read` `activity:read` |
| `get_fitness_trends` | 단일 선수 체력 지표와 명시적인 단일 소스 트랙에 대한 제한된 이력을 조회합니다. 추정치는 참고용이며, AUTO 또는 MANUAL 값은 프로필 기록입니다. | `profile:read` |
| `get_training_zones` | 현재 선수의 확정된 심박수, 페이스, 파워 존을 각 설정의 사용자 지정·자동 산출·미제공 여부와 함께 조회합니다. | `profile:read` |
| `get_personal_bests` | 제한된 날짜 범위 내에서 표준 또는 사용자 지정 거리/시간 목표에 대한 처리된 최고 기록을 조회합니다. 경로와 원시 센서 데이터는 반환하지 않습니다. | `activity:read` |
| `list_training_plans` | 제한된 날짜 범위와 겹치는 승인된 훈련 플랜을 탐색합니다. 연속(continuous) 플랜은 periodWeeks와 endDate가 null입니다. generatedThrough는 가장 최근 게시 날짜일 뿐 플랜 종료일이나 공백 없는 연속 범위를 보장하지 않습니다. | `plan:read` |
| `get_plan_summary` | 완료율, 계획 대비 실제 훈련 부하, 주간 진행률 및 종목별 구성이 포함된 본인 소유 훈련 플랜 요약을 조회합니다. 연속 플랜의 합계는 periodWeeks가 null인 상태에서 workoutWindow 범위만 집계하며 누적 전체 합계가 아닙니다. 플랜은 절대 수정되지 않습니다. | `plan:read` `activity:read` |
| `list_planned_workouts` | 불투명 페이지네이션을 사용해 제한된 날짜 범위 내의 승인된 예정 워크아웃 목록을 조회합니다. | `plan:read` |
| `get_planned_workout` | 승인된 단일 예정 워크아웃과 구조화된 단계를 조회합니다. 이 도구는 훈련 플랜을 절대 변경하지 않습니다. | `plan:read` |
| `get_plan_adherence` | 제한된 날짜 범위의 상태 기반 훈련 플랜 이행률을 요약합니다. DONE은 완료, SKIPPED는 건너뜀이며 PLANNED와 IN_PROGRESS는 대기 중으로 집계됩니다. | `plan:read` |
| `list_competitions` | 불투명 페이지네이션을 사용해 제한된 날짜 범위 내의 승인된 선수 대회 목록을 조회합니다. | `competition:read` |
| `get_competition` | 불투명 이벤트 ID로 일정, 목표, 장소 및 메모를 포함한 승인된 단일 대회를 조회합니다. 이 도구는 대회를 절대 변경하지 않습니다. | `competition:read` |
| `get_health_summary` | 선별된 일별 회복, 수면, 심박수, 스트레스 및 활동 요약을 조회합니다. 이는 컨디션 참고 맥락일 뿐 의학적 진단이나 권고가 아닙니다. | `health:read` |
| `get_integration_status` | 외부 계정 식별자, 자격 증명 또는 원시 오류 메시지를 노출하지 않으면서 지원되는 훈련 플랫폼 연동의 연결 및 동기화 준비 상태를 조회합니다. | `profile:read` |

## `list_activities`

제한된 범위 내에서 승인된 선수의 활동 요약을 검색합니다. 원시 센서 스트림이나 정밀 GPS 트랙은 반환하지 않습니다.

- **어노테이션:** `readOnlyHint=true`, `destructiveHint=false`, `idempotentHint=true`, `openWorldHint=false`
