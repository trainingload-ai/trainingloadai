# MCP 변경 이력

## 2026-10-15 — 전체 읽기 전용 훈련 기능 완성

- 도구 카탈로그를 17개에서 24개로 확장했습니다.
- 명시적인 커버리지 및 잘림(truncation) 의미를 포함한 집계 활동 통계와 훈련 일관성 분석을 추가했습니다.
- 개인정보를 최소화한 활동 존 분포 및 랩/스플릿 상세 조회를 추가했습니다.
- 훈련 플랜 탐색, 플랜 단위 완료율/부하 요약, 단일 대회 상세 조회를 추가했습니다.
- 기본 MCP 리소스 3종과 재사용 가능한 프롬프트 3종을 추가하고, 자동 생성 레퍼런스 문서와 릴리스 게이트 검증을 도입했습니다.

## 2026-10-15 — 고급 읽기 전용 분석 및 온보딩 가이드 완성(이전 마일스톤)

- 도구 카탈로그를 9개에서 17개로 확장했습니다.
- 기간 비교, 종목별 훈련 부하 분석, 훈련 준비도 지표를 추가했습니다.
- 체력 추세, 훈련 존, 개인 최고 기록 조회를 추가했습니다.
- 상태 기반 훈련 플랜 이행률과 연동/동기화 준비 상태 조회를 추가했습니다.
- 동작 방식, 활용 사례 및 7종의 클라이언트별 전용 가이드를 추가했습니다.
- OAuth 연결부터 투명한 도구 호출, 근거 기반 답변까지 아우르도록 기능 소개 페이지를 확장했습니다.

## 2026-10-14 — 초기 읽기 전용 제품 구성 출시

- 훈련, 활동, 훈련 플랜, 대회, 프로필, 건강 영역의 읽기 전용 기능 9종을 추가했습니다.
- 집계 우선(aggregate-first) 서버 지침과 Zod 기반 입출력 계약을 추가했습니다.
- OAuth 권한 범위(스코프) 필터링, 별도 `health:read` 승인, 권한 철회 가시성, 요청 제한, 감사 기록 및 OpenTelemetry 계측을 추가했습니다.
- `2025-11-25` 및 `2026-07-28` 호환성을 갖춘 무상태(stateless) MCP SDK v2 전송 계층을 추가했습니다.
- 자동 생성 도구 레퍼런스와 클라이언트 연결 가이드를 추가했습니다.

이 릴리스에는 쓰기 도구가 포함되어 있지 않습니다.
