# MCP 보안 및 개인정보 보호

TrainingLoad MCP를 연결하면 승인된 AI 클라이언트가 훈련 요약을 읽고 질문에 답할 수 있습니다. MCP는 읽기 전용이며 활동, 훈련 플랜, 대회, 프로필 값 또는 계정 설정을 변경할 수 없습니다.

## 권한은 사용자가 직접 선택합니다

연결 과정에서 클라이언트가 TrainingLoad 권한 승인 페이지를 엽니다. 승인하기 전에 클라이언트 이름과 요청된 데이터 권한을 확인하세요. 클라이언트에 TrainingLoad 비밀번호나 API 키를 제공할 필요가 없습니다.

모든 요청은 현재 계정 권한 상태를 확인합니다. 클라이언트는 사용자가 승인한 데이터만 읽을 수 있으며, 권한 누락, 접근 만료 또는 일시적인 서비스 장애가 발생하면 해당하는 오류가 반환됩니다.

건강 데이터에는 기본 권한에 포함되지 않은 별도의 `health:read` 권한이 필요합니다. 클라이언트 접근 권한은 계정에서 언제든 해제할 수 있습니다.

## 클라이언트가 읽을 수 있는 데이터

도구는 활동 시간, 훈련 부하, 플랜 이행률, 지표 추세 등 훈련 관련 질문에 필요한 요약 정보만 반환합니다. 활동 및 플랜 조회는 승인된 본인 계정에 속한 기록으로 제한됩니다.

MCP는 이메일 주소, 내부 사용자 ID, 정밀 GPS 경로, 원시 센서 스트림, 서드파티 자격 증명, 전체 FIT 파일을 반환하지 않습니다. 목록 크기와 날짜 범위에는 상한이 있으므로 더 긴 훈련 기록을 조회하려면 클라이언트가 여러 번 요청해야 할 수 있습니다.

## 활동 메모는 지시문이 아니라 데이터입니다

활동 이름, 설명, 워크아웃 이름, 대회 메모는 훈련 기록 데이터로만 취급됩니다. 서비스는 안전하지 않은 텍스트를 정제하며, 이러한 메모에 포함된 명령이나 링크를 따르지 않도록 클라이언트에 지시합니다.

## 건강 데이터 활용 경계

건강 도구는 훈련 분석을 보조하기 위한 축소된 일별 컨디션 요약을 제공합니다. 이는 의학적 진단이 아니며 자격을 갖춘 전문가의 평가를 대체하지 않습니다.

## 요청 제한 및 문제 해결 기록

서비스는 요청이 지나치게 빈번하거나 한 번에 너무 많은 데이터를 요구하는 경우 요청을 제한할 수 있습니다. 클라이언트는 오류 안내에 따라 날짜 범위를 좁히거나 잠시 기다린 뒤 재시도해야 합니다.

서비스는 도구 이름, 결과 상태, 오류 코드, 처리 시간, 요청 ID와 같은 문제 해결 정보를 보관합니다. 사용자 및 클라이언트 식별자는 가명 처리됩니다. 이러한 기록에는 액세스 토큰이나 전체 요청/응답 내용이 포함되지 않습니다.

## 원치 않는 접근이 의심되는 경우

즉시 TrainingLoad 계정에서 해당 클라이언트의 접근 권한을 철회한 뒤 웹사이트 지원 채널을 통해 신고하세요. 대략적인 시각, 클라이언트 이름, 그리고 표시된 경우 요청 ID를 함께 전달해 주세요. 액세스 토큰이나 전체 건강 기록은 절대 전송하지 마세요.
