# TrainingLoad MCP

TrainingLoad MCP를 통해 훈련 데이터를 ChatGPT, Codex, Claude 또는 기타 호환 AI 클라이언트에 연결할 수 있습니다. 개별 활동 기록을 일일이 복사할 필요 없이 최근 훈련 부하, 훈련 플랜 이행률, 퍼포먼스 추세, 동기화 문제 등을 바로 질문할 수 있습니다. MCP는 데이터를 읽기만 하며 훈련 일정을 변경하지 않습니다.

**서버 URL:** `https://api.trainingload.ai/mcp`

별도의 API 키는 필요하지 않습니다. 클라이언트가 TrainingLoad OAuth 화면을 열면 클라이언트 이름과 요청된 권한 범위(스코프)를 확인하고 승인할 수 있습니다. 나중에 계정 설정에서 언제든 접근 권한을 해제할 수 있습니다.

## 조회할 수 있는 훈련 정보

| 질문 | 주요 기능 |
| --- | --- |
| 현재 내 훈련 상태는 어떤가요? | 훈련 스냅샷, 준비도 지표, 훈련 부하 시계열 |
| 두 훈련 블록 사이에 무엇이 달라졌나요? | 기간 비교, 종목별 부하 분석, 활동 통계, 훈련 일관성 |
| 러닝, 사이클링, 수영 체력이 변하고 있나요? | 체력 추세, 훈련 존, 개인 최고 기록 |
| 훈련 플랜을 얼마나 잘 따르고 있나요? | 훈련 플랜 탐색 및 요약, 예정된 워크아웃, 워크아웃 상세, 상태 기반 이행률 |
| 어떤 훈련을 완료했나요? | 활동 목록, 개인정보 최소화 상세 정보, 존별 체류 시간, 랩/스플릿 요약 |
| 앞으로 어떤 대회가 예정되어 있나요? | 대회 목록 및 계정 범위 내 대회 상세 정보 |
| 연동 서비스가 왜 동기화되지 않나요? | 연동 연결 및 동기화 준비 상태 |
| 컨디션(웰니스) 맥락에 변화가 있나요? | 별도 동의를 거쳐 제공하는 일별 건강 요약 |

모든 필드와 권한 범위(스코프)는 [도구 레퍼런스](/ko/docs/mcp/tools)에서 확인할 수 있습니다. 또한 클라이언트는 지표 해석, 안전 경계, 반복 가능한 분석 워크플로를 위한 기본 제공 [리소스 및 프롬프트](/ko/docs/mcp/resources-and-prompts) 3종을 탐색할 수 있습니다.

## 먼저 해볼 만한 질문

- “이번 주 훈련량과 훈련 부하를 지난주와 비교해 주세요. 주요 변화를 설명하는 활동은 무엇인가요?”
- “이번 주 훈련 플랜을 얼마나 완료했고, 아직 연결된 활동이 없는 워크아웃은 무엇인가요?”
- “최근 러닝 지표가 어떻게 변했나요? 비교 가능한 데이터가 없는 날짜는 언제인가요?”

답변을 읽을 때는 사용된 날짜 범위, 참조된 활동, 누락된 데이터를 함께 확인하세요. 추세는 훈련 논의를 돕는 참고 자료일 뿐 의학적 결론을 내리지 않습니다.

## 연결 전에 알아두어야 할 제한 사항

- **읽기 전용:** 클라이언트는 활동, 훈련 플랜, 대회, 프로필, 연동 서비스 또는 계정 설정을 변경할 수 없습니다.
- **본인 데이터만 조회:** 클라이언트는 승인된 본인 계정에 속한 기록만 조회할 수 있습니다.
- **훈련 요약 중심:** 도구는 정밀 GPS 경로, 원시 센서 스트림, 연동 서비스 자격 증명 또는 전체 FIT 파일을 제공하지 않습니다.
- **별도 건강 권한:** `health:read`는 기본 권한에 포함되지 않습니다.
- **접근 권한 해제 가능:** 더 이상 사용하지 않는 클라이언트는 계정 설정에서 권한을 해제할 수 있습니다.
