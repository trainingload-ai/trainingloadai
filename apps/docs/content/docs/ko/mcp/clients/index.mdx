# 클라이언트 가이드

사용 중인 클라이언트를 선택하세요. 모든 가이드는 동일한 엔드포인트에 TrainingLoad OAuth로 연결하며 API 키가 필요하지 않습니다.

- [ChatGPT](/ko/docs/mcp/clients/chatgpt)
- [Codex](/ko/docs/mcp/clients/codex)
- [Claude Code](/ko/docs/mcp/clients/claude-code)
- [Claude Desktop](/ko/docs/mcp/clients/claude-desktop)
- [Cursor](/ko/docs/mcp/clients/cursor)
- [VS Code](/ko/docs/mcp/clients/vscode)
- [opencode](/ko/docs/mcp/clients/opencode)

설정을 마친 뒤 [모든 클라이언트 공통 검증 절차](/ko/docs/mcp/connect#모든-클라이언트-공통-검증-절차)를 따라 OAuth, 도구 탐색 및 첫 번째 호출을 확인하세요.
