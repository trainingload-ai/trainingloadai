# Claude Code 연결

현재 사용자의 모든 프로젝트에서 사용할 수 있도록 서버를 추가합니다.

```bash
claude mcp add --transport http --scope user trainingload https://api.trainingload.ai/mcp
claude mcp list
```

현재 프로젝트에만 적용하려면 `--scope user`를 생략하세요. Claude Code에서 `/mcp`를 실행해 TrainingLoad를 선택하고 브라우저 OAuth를 완료합니다.

다음 질문으로 동작을 확인하세요: “가장 최근 두 개의 28일 훈련 블록을 비교하고 어떤 결론이 추론인지 구분해 주세요.” 이 요청은 `compare_training_periods`를 호출한 뒤 필요한 경우에만 상세 도구를 추가로 호출해야 합니다.

계속 연결되지 않는다면 `claude mcp list`로 URL을 확인한 뒤 `/mcp`에서 OAuth를 다시 시도하세요.

[공식 Claude Code MCP 가이드](https://docs.anthropic.com/en/docs/claude-code/mcp)
