# ChatGPT 연결

1. ChatGPT에서 **Plugins**를 열고 플러스(+) 버튼을 누른 뒤 **Add custom MCP server**를 선택합니다. 워크스페이스에서 개발자 모드가 필요한 경우 먼저 관리자 정책에서 활성화하세요.
2. 이름에 `TrainingLoad`, 서버 URL에 `https://api.trainingload.ai/mcp`를 입력합니다.
3. 도구를 스캔한 뒤 **Connect**를 선택하면 브라우저에서 TrainingLoad OAuth 페이지가 열립니다.
4. 클라이언트 이름과 읽기 전용 권한 범위(스코프)를 확인하고 승인합니다.
5. 새 채팅에서 TrainingLoad를 활성화한 뒤 다음과 같이 질문하세요: “현재 내 훈련 상태를 요약하고 사용된 도구와 날짜 범위를 함께 알려 주세요.”

첫 번째 호출은 `get_training_snapshot`이어야 합니다. 나중에 `get_health_summary`를 요청하면 별도의 `health:read` 동의 절차가 시작됩니다.

도구 목록이 새로고침되지 않으면 채팅에서 TrainingLoad를 제거했다가 다시 활성화하세요. OAuth 오류가 발생하면 TrainingLoad에서 이전 연결 권한을 해제한 뒤 다시 연결하세요.
