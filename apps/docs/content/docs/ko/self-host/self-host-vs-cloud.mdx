# 셀프 호스팅 vs 클라우드

별도 구축 없이 Trainingload.ai를 바로 사용하고 싶다면 클라우드를 선택하세요. 훈련 데이터를 개인 컴퓨터나 서버에 직접 보관하고 애플리케이션 설치와 유지 관리를 직접 수행할 의향이 있다면 셀프 호스팅이 적합합니다.

## 한눈에 비교하기

| 주요 비교 항목 | 클라우드(Cloud) | 셀프 호스팅(Self-hosted) |
| --- | --- | --- |
| 시작 방법 | 앱을 열고 계정을 생성해 바로 시작 | 릴리스 번들을 다운로드해 개인 기기에서 설치 가이드에 따라 설치 |
| 데이터 저장 위치 | Trainingload.ai 클라우드 서비스 | 활동, 플랜, 업로드 파일을 포함해 사용자 기기에 로컬 저장 |
| 훈련 가져오기 | 지원되는 훈련 플랫폼 연동 또는 활동 파일 업로드 | 활동 파일 업로드, 또는 개인 키로 Intervals.icu 및 Garmin Personal API 연동 |
| AI 코치 사용 | 계정 플랜에 포함된 AI 사용량 활용 | 기본 비활성화. 본인의 AI 서비스를 직접 설정하고 해당 공급자에 비용 결제 |
| 계정 | 클라우드 계정 사용 | 셀프 호스팅 인스턴스 1개당 1인 전용 |
| 백업 및 복구 | Trainingload.ai가 클라우드 서비스 운영 및 관리 | 사용자가 직접 백업을 보관하고 필요 시 복구 수행 |
| 소프트웨어 업데이트 | Trainingload.ai가 자동으로 서비스 업데이트 | 업그레이드 가이드에 따라 새 릴리스를 직접 설치 |

## 나에게 맞는 방식은?

소프트웨어 설치, 업데이트, 백업 관리에 신경 쓰지 않고 온전히 훈련과 워크아웃 리뷰에 집중하고 싶다면 **클라우드**를 선택하세요.

훈련 데이터를 직접 소유·보관하고 싶고, 애플리케이션을 실행할 기기를 유지 관리하며 정기적인 업데이트와 백업을 수행할 수 있다면 **셀프 호스팅**을 선택하세요. 셀프 호스팅은 개인용이며 단일 인스턴스에서 다중 사용자를 지원하지 않습니다.

## 훈련 가져오기 방식 확인하기

셀프 호스팅은 현재 다음 가져오기 방식을 지원합니다.

- **FIT, GPX, TCX** 활동 파일 업로드
- 개인 API 키를 통한 **Intervals.icu** 연동
- 개인 API 키를 통한 **Garmin Personal API** 연동

특정 훈련 플랫폼에 의존하고 있다면 먼저 [데이터 연결](/ko/docs/guide/connect-data)과 [셀프 호스팅 연동 설정](/ko/docs/self-host/configuration#connect-intervalsicu)을 확인하세요. 클라우드와 셀프 호스팅은 지원하는 연동 방식이 다릅니다. 다른 플랫폼에서 지원되는 형식의 활동 파일을 내보낼 수 있다면 해당 파일을 직접 업로드할 수 있습니다.

**Trainingload.ai는 현재 Apple Watch 앱을 지원하지 않습니다.**

## AI 동작 방식과 비용

AI는 기본적으로 꺼져 있습니다. AI를 설정하지 않아도 비-AI 기능은 모두 정상적으로 사용할 수 있습니다. AI 코치를 사용하려면 설정에서 공급자를 선택하고 본인의 API 키를 입력하세요. 자세한 내용은 [클라이언트에서 AI 설정하기](/ko/docs/self-host/configuration#configure-ai-in-the-client)를 참고하세요.

셀프 호스팅에서는 Trainingload.ai 클라우드 멤버십이나 AI 크레딧을 사용하지 않습니다. API 사용 요금은 선택한 AI 공급자가 직접 청구합니다.

외부 AI 서비스를 사용하면 해당 요청을 처리하는 데 필요한 훈련 정보가 선택한 공급자로 전송됩니다. 애플리케이션을 로컬에 설치했다고 해서 외부 AI 서비스가 로컬에서 실행되는 것은 아닙니다. 또한 훈련 플랫폼과 동기화하려면 인터넷 연결이 필요합니다.

## 직접 관리해야 할 항목

- 기기에 충분한 여유 저장 공간을 유지하고 필요할 때 애플리케이션을 실행합니다.
- 업데이트 전에 항상 백업을 만들고, 애플리케이션이 실행되는 기기와 분리된 위치에 사본을 보관합니다.
- 기기 장애 시 실제로 복구할 수 있도록 백업 복원 가능 여부를 주기적으로 점검합니다.
- 애플리케이션을 업데이트할 때는 [인스턴스 운영 관리 가이드](/ko/docs/self-host/operations)를 따릅니다.

## 다음 단계

클라우드를 선택했다면 [앱 열기](https://app.trainingload.ai/en)에서 계정을 만들고 [시작하기](/ko/docs/guide/getting-started)를 따라 첫 활동을 가져오세요.

셀프 호스팅을 선택했다면 [설치 가이드](/ko/docs/self-host/installation)부터 시작하세요. 설치, 백업, 업그레이드 절차는 각 전용 가이드에서 자세히 다룹니다.
