# 셀프 호스팅

셀프 호스팅을 사용하면 개인 컴퓨터나 서버에서 직접 Trainingload.ai를 실행할 수 있습니다. 활동 기록, 훈련 플랜, 업로드한 파일이 모두 내 기기에 저장되며, 브라우저에서 훈련을 리뷰하고 관리할 수 있습니다.

셀프 호스팅 인스턴스 하나는 1인 전용입니다. 기기 관리, 소프트웨어 업데이트, 백업은 사용자가 직접 담당합니다. 별도 설치 없이 바로 앱을 열어 시작하고 싶다면 먼저 [셀프 호스팅 vs 클라우드](/ko/docs/self-host/self-host-vs-cloud)를 읽어 보세요.

## 할 수 있는 일

- 활동을 가져와 상세 정보, 타임라인, 훈련 부하를 리뷰합니다.
- 캘린더에서 훈련 일정을 배치하고 계획된 워크아웃과 완료된 활동을 비교합니다.
- FIT, GPX, TCX 파일을 업로드하거나 개인 키로 Intervals.icu 및 Garmin Personal API를 연동합니다.
- 직접 선택한 AI 서비스를 연결해 AI 코치를 사용하거나, AI 기능을 끈 상태로 운영할 수 있습니다.

## 설치 전 준비 사항

- [설치 요구 사항](/ko/docs/self-host/installation)을 충족하고 Docker Compose가 설치된 기기
- 훈련 데이터와 업로드 파일을 저장할 충분한 디스크 공간
- 기기 장애 시 복구할 수 있도록 백업을 보관할 별도의 저장 공간

공식적으로 버전이 지정되고 서명된 릴리스 번들을 사용하고, 설치 전에 가이드에 따라 검증을 수행하세요. 소스를 직접 빌드하거나 컨테이너를 수동으로 조립할 필요가 없습니다. 현재 공식 지원하는 설치 방식은 Docker Compose입니다.

## 데이터 저장 및 전송 경로

활동, 훈련 플랜, 업로드 파일은 모두 사용자 기기에 저장됩니다. 훈련 플랫폼을 연동하면 선택한 동기화 옵션에 따라 데이터가 송수신됩니다. 외부 AI 서비스를 활성화하면 해당 요청 처리에 필요한 훈련 정보가 선택한 AI 공급자에게 전송됩니다.

AI 기능은 기본적으로 꺼져 있습니다. 사용하려면 [인스턴스 설정 가이드](/ko/docs/self-host/configuration)에 따라 본인의 공급자 API 키를 입력하세요. API 사용 요금은 해당 공급자에게 직접 청구됩니다.
