# COROS 연결

셀프 호스팅은 현재 COROS 직접 연동을 지원하지 않습니다. 원본 플랫폼에서 지원되는 FIT, TCX 또는 GPX 활동 파일을 내보낸 뒤 [Trainingload.ai에 업로드](/ko/docs/guide/upload-activity-files)하세요.

셀프 호스팅에서 지원하는 개인 연동 방식은 다음과 같습니다.

- [Intervals.icu](/ko/docs/self-host/configuration)
- [Garmin Personal API](/ko/docs/self-host/garmin-personal-api)

클라우드 환경에서의 연동은 [타사 플랫폼 연동 가이드](/ko/docs/guide/connect-third-party-platforms)를 참고하세요.
