# Garmin Personal API

셀프 호스팅 인스턴스에서는 본인의 Garmin Personal API 키를 사용해 완료된 활동과 기기·계정에서 제공하는 수면, HRV, 안정시 심박수 등의 데이터를 가져올 수 있습니다.

이 페이지는 셀프 호스팅 전용 안내입니다. 클라우드 권한 승인 및 과거 이력 가져오기는 [타사 플랫폼 연동 가이드](/ko/docs/guide/connect-third-party-platforms#connect-garmin-for-new-data)를 참고하세요.

## 개인 계정 연결하기

1. Garmin Connect의 [Personal API 키 설정](https://connect.garmin.com/app/settings/personalApiToken)에서 키를 생성합니다. 중국 계정이라면 중국 리전에 맞는 Garmin Connect를 사용하세요.
2. Trainingload.ai에서 **계정 → 타사 연동 → Garmin → 연동 설정(Account → Third Party Connections → Garmin → Connection settings)**을 엽니다.
3. 계정 리전을 선택하고 `Asia/Seoul`처럼 시간대가 올바른지 확인합니다.
4. 필요에 따라 활동 가져오기, 수면 및 회복 데이터, 예약 동기화를 선택한 뒤 키를 붙여넣고 연결합니다.
5. **지금 동기화(Sync now)**를 선택합니다. 날짜를 비워 두면 기본으로 최근 30일을 가져오며, 원하는 과거 기간을 직접 지정할 수도 있습니다.

Garmin 비밀번호나 브라우저 쿠키를 입력할 필요는 없습니다. 입력한 키는 사용자의 인스턴스 내부에 암호화되어 저장됩니다. 키를 채팅, 이슈, 로그에 보내지 마세요. 생성 후 안전하게 관리하고 만료되거나 해지되면 교체하세요. 만료 기간은 Garmin에서 제공하는 옵션을 따릅니다.

## 동기화 후 확인할 항목

| 데이터 | 확인할 결과 |
| --- | --- |
| 완료된 활동 | 활동 목록에 일치하는 기록이 나타납니다. 활동을 열어 출처, 시각, 제공된 차트를 확인합니다 |
| 수면, HRV, 안정시 심박수, 걸음 수 | 해당 날짜에 Garmin이 제공한 데이터가 표시되며, 누락된 값은 0으로 채워지지 않습니다 |
| 체중, 스트레스, 혈중 산소포화도, Body Battery | Garmin 원래 지표의 의미가 보존되며, 이 값들이 ATL, CTL, TSB를 대체하지는 않습니다 |
| 추가 지표 | **고급 데이터 및 작업(Advanced data and operations)**에서 날짜별로 조회하며, 로컬 종목 설정을 자동으로 덮어쓰지 않습니다 |
| 영양 및 생리 주기 데이터 | 예약 동기화에서는 제외되며, 추가 조회 시 별도의 확인 절차가 필요합니다 |

데이터 제공 여부는 기기 기록, 리전, Garmin 권한 설정에 따라 달라지므로 모든 계정에 위 표의 모든 항목이 제공되지는 않습니다. 연결 후 동기화 결과를 확인하세요. 인식할 수 없는 데이터는 오류를 발생시키며, 빈 결과는 숫자 0을 의미하지 않습니다.

이 연동은 개인 데이터를 읽어 오는 읽기 전용 기능입니다. 향후 워크아웃을 생성하거나 Garmin으로 전송하지는 않습니다.

## 과거 이력 및 진행 상태

- 원하는 날짜 범위를 선택합니다. 기간 계산에는 계정 시간대가 적용됩니다.
- **대기 중(Queued)**은 요청이 저장되었다는 뜻입니다. 활동은 다운로드와 가져오기가 모두 끝난 뒤에만 **가져옴(Imported)**으로 집계됩니다.
- 페이지를 새로고침해도 실행 중인 작업은 취소되지 않습니다. 대량 가져오기는 같은 요청을 반복 제출하지 말고 완료될 때까지 기다리세요.
- 과거 이력 요청 1회당 최대 10년 기간을 지정할 수 있습니다. 소요 시간은 활동 수와 Garmin 요청 제한에 따라 달라집니다.
- 다시 동기화하면 매번 새 사본을 만드는 대신 기존 Garmin 기록을 확인하고 업데이트합니다.
- 일부 항목이 실패했다면 표시된 오류 내용을 확인하세요. 정상적으로 읽힌 다른 항목들은 계속 가져오기가 완료될 수 있습니다.

예약 동기화를 사용하려면 연동 설정에서 관련 옵션을 켜세요. 발견된 레코드 수(discovered count)는 성공적으로 가져온 수와 다릅니다.

## 만료된 키, 연결 해제 및 백업

키가 만료되거나 해지되면 **키 교체 또는 재인증(Replace key or reauthorize)**을 사용하세요. 새 키를 입력하기 전에 리전과 계정이 맞는지 확인합니다.

연결을 해제하면 이후 동기화만 중단되며, 이미 저장해 둔 오프라인 백업은 지워지지 않습니다. [인스턴스 운영 관리 가이드](/ko/docs/self-host/operations)에 따라 데이터베이스 백업과 함께 원래의 인스턴스 시크릿을 안전하게 보관하세요. 복원된 연동이 정상 작동하려면 원래 키가 필요합니다.

이 연동은 본인 개인의 Garmin 데이터를 위한 기능입니다. 개인 인스턴스 하나로 다중 사용자 서비스를 제공하기 위해 타인의 키를 수집하지 마세요. 자세한 내용은 [Garmin Personal API 공식 소개](https://developer.garmin.com/gc-developer-program/personal/personal-api/)를 참고하세요.
