# 无氧能力

你可以把 **无氧能力**理解成：身体在很短时间里能输出多少高于可持续强度的功率或速度，以及这段输出能维持多久。它常见于关键时刻的突然加速、拉开差距或终点冲刺。

## 核心特征

- **持续时间很短**：通常是几秒到几十秒（常见说法会拿“~30 秒”做一个直观锚点）。
- **更像“能量储备”而不是“巡航能力”**：它和你能否长时间稳定输出（阈值/有氧）是两类问题。
- **典型场景**：
  - 自行车比赛的终点冲刺、突然加速
  - 越野/公路跑的变速与短坡进攻
  - 间歇训练中短时间的高强度重复

## 训练意义

对于长距离耐力运动员（如马拉松、铁人三项），无氧能力通常不如有氧基础、阈值能力和耐久性核心。但对于需要频繁变速、进攻或终点冲刺的项目（如公路自行车赛、越野跑），无氧能力会明显影响关键时刻的表现。

它不像阈值能力那样可持续，但在比赛或训练需要突然提高强度时很有价值。

## Trainingload.ai 如何使用无氧能力

- **识别短高强度刺激**：用于理解冲刺、反复变速、短坡进攻等训练内容。
- **连接功率模型**：在骑行中，无氧能力常和 W′ / 无氧做功能力放在一起解释。
- **保持训练平衡**：Trainingload.ai 会把无氧刺激和阈值、VO2 Max、恢复状态一起看，避免短高强度训练挤占主要目标。
