# 功能性阈值功率 (Functional Threshold Power)

在耐力运动中，**功能性阈值**是接近稳态和明显疲劳累积之间的实用基准。它常用于制定训练区间、估算训练负荷，并追踪阈值能力是否提升。

最常见的两个术语是针对骑行的 **FTP** 和针对跑步的 **rFTP**。

## 功能性阈值功率 (FTP)

**FTP** 通常指骑行时的阈值功率。
它通常被描述为：**你在大约 60 分钟内所能维持的最大平均功率**。实际使用时，FTP 仍然是一个估计值，会受到测试方法、配速、疲劳和近期训练状态影响。

### 为什么它很重要？
-   **生理锚点**：功能性阈值功率 (FTP) 大致对应[乳酸阈值 (LT)](/zh/docs/metrics/physiology/lactate-threshold) 附近的强度范围。低于它，很多运动员可以维持更久；高于它，疲劳通常会更快累积。
-   **相对强度参考**：无论你的 FTP 是 400W 还是 150W，FTP 百分比都能让训练在个人能力范围内更可比。多数功率训练计划都基于 FTP 百分比（如 Zone 2 = 55-75% FTP）。

### 如何测定？
1.  **20分钟测试 (经典)**：全力骑 20 分钟，取平均功率乘以 **95%**。
2.  **Ramp Test (递增负荷)**：每分钟加压直到力竭，取最后一分钟功率的 **75%**。
3.  **CP 模型估算**：Trainingload.ai 基于你的历史最大功率曲线 (PDC) 自动计算，通常 `FTP ≈ 0.95 * CP`。

如果你想基于活动文件做一次估算，可以使用 [FTP 计算器](/zh/ftp-calculator)。如果你已经有不同时长的最大努力数据，可以使用 [临界功率计算器](/zh/critical-power-calculator) 拟合 CP 与 W'。

## 跑步功能性阈值功率 (Running Functional Threshold Power，rFTP)

**跑步功能性阈值功率 (rFTP)** 是随着跑步功率计（如 Stryd, Garmin, Coros 等）普及而诞生的概念。

它定义为：**你在大约 60 分钟跑步中能维持的最大平均功率**。

### rFTP vs. FTP
虽然定义相似，但数值通常**不通用**！
-   **数值差异**：大多数人的 rFTP 会高于骑行 FTP。因为跑步不仅涉及肌肉做功，还包含软组织的弹性势能存储与释放（类似于弹簧），且调用的肌群更多，心率通常也更高。
-   **独立测试**：你不能用骑行 FTP 来指导跑步训练，反之亦然。

### rFTP vs. 阈值配速
-   **rFTP (功率)**：单位是瓦特 (Watts)。不受坡度、风阻影响（如果是 Stryd 等风阻功率计），更能反映真实生理输出。
-   **Threshold Pace (配速)**：单位是 min/km。受坡度影响巨大（上坡配速慢但强度大）。
    -   *注：在平路无风环境下，rFTP 对应的配速就是阈值配速。但在越野或起伏路面，rFTP 是更稳定的指标。*

### 如何测定 rFTP？
常见的跑步功率测试（如 Stryd 协议）：
-   **3/9 测试**：全力跑 3 分钟（恢复 30 分钟）+ 全力跑 9 分钟。
-   **CP 模型**：通过采集不同时长的全力跑数据（如 30秒, 2分钟, 10分钟），拟合出临界功率 (Critical Power)，通常直接作为 rFTP。

## Trainingload.ai 如何使用 FTP

Trainingload.ai 会把 FTP 作为功率区间、强度系数 (IF) 和训练压力分数 (TSS) 的阈值参考。如果 FTP 设置过低，困难训练可能看起来比实际更高负荷；如果 FTP 设置过高，训练负荷和区间目标则可能被低估。

在计划复盘中，FTP 最适合回答：

-   完成训练是否落在计划目标区间？
-   TSS 与 IF 是否基于当前阈值计算？
-   阈值能力是否已经变化，需要更新后续训练？

## 总结

| 指标 | 全称 | 适用运动 | 单位 | 核心含义 |
| :--- | :--- | :--- | :--- | :--- |
| **FTP** | Functional Threshold Power | 骑行 | Watts | 1小时最大骑行功率 |
| **rFTP** | Running Functional Threshold Power | 跑步 | Watts | 1小时最大跑步功率 |
