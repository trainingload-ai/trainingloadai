# 功率区间 (Power Zones)

功率区间把连续的功率输出切成可执行的训练“档位”，让你能用同一套语言描述强度（Z1-Z7 / Z1-Z5），并把训练目标对齐到对应的能量系统与配速场景。

## 基准功率：FTP

功率区间的百分比需要一个“基准功率”：

- **FTP**：见 [功能性阈值功率 (FTP)](./functional-threshold-power)
- **CP**：见 [临界功率 (CP)](./critical-power)，尤其适用于 Stryd 等跑步功率模型。

如果你已经知道 FTP 或 CP，可以使用 [功率区间计算器](/zh/power-zones-calculator) 计算各区间边界。

## 区间边界怎么理解？

下面所有表格的“% FTP”都按**不重叠的区间**来写，例如：

- Z1：$\le 55\%$
- Z2：$56\%-75\%$

当某个百分比值是两个区间的分界点（例如 $128\%$），推荐把分界点归到**更高**的区间（例如 $128\%$ 归到 Z7），避免一个值落到两个区间。

## 1. Joe Friel Bike 7 区间模型

Joe Friel 模型适合用7 区间，描述从恢复到神经肌肉冲刺的全强度谱系，常用于骑行，也可以用于跑步（只要你选择了合适的FTP）。

| 区间 | 名称 | 英文名称 | % FTP | 常见用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 主动恢复 | Active Recovery | $\le 55\%$ | 放松骑/恢复跑，促进代谢与恢复。 |
| **Z2** | 耐力 | Endurance | $56\%-75\%$ | 长距离打底（LSD），提升有氧能力与脂代谢。 |
| **Z3** | 节奏 | Tempo | $76\%-90\%$ | 稳态输出，提升耐受与肌糖原利用。 |
| **Z4** | 阈值 | Threshold | $91\%-105\%$ | 阈值训练，提升可持续强度与阈值能力。 |
| **Z5** | 最大摄氧量 | VO2 Max | $106\%-120\%$ | VO2 间歇，提升高强度有氧上限。 |
| **Z6** | 无氧 | Anaerobic | $121\%-150\%$ | 无氧间歇，提升乳酸耐受与爆发耐力。 |
| **Z7** | 神经肌肉 | Neuromuscular | $\ge 151\%$ | 短冲刺/启动，偏神经募集与冲刺能力。 |

> 引用自 [joe friel](https://joefrieltraining.com/a-quick-guide-to-setting-zones/)

## 2. Jim Vance Run 7 区间模型

Jim Vance 模型同样是 7 区间，但把“低强度”切得更细：Z1-Z3 更贴近日常训练的“走/慢/稳”分层，适合精细管理耐力与节奏强度。

| 区间 | 名称 | 英文名称 | % FTP | 常见用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 恢复/步行 | Recovery/Walking | $\le 80\%$ | 恢复、热身、非常轻松的低强度。 |
| **Z2** | 耐力 | Endurance | $81\%-88\%$ | 有氧耐力主体区间，适合长时间输出。 |
| **Z3** | 节奏 | Tempo | $89\%-95\%$ | 稍高的稳态强度，接近阈值前段。 |
| **Z4** | 阈值 | Threshold | $96\%-105\%$ | 阈值训练与持续能力提升。 |
| **Z5** | 高强度 | High Intensity | $106\%-115\%$ | 高强度间歇（偏有氧高端）。 |
| **Z6** | VO2 | VO2 | $116\%-128\%$ | VO2 间歇（分界点 $128\%$ 建议归到 Z7）。 |
| **Z7** | 无氧容量 | Anaerobic Capacity | $\ge 128\%$ | 更偏无氧容量与爆发耐力的短间歇。 |

> 引用自 [Jim Vance, 《Run with Power》](https://www.velopress.com/books/run-with-power/)

## 3. Stryd Run 5 区间模型

Stryd 模型把高强度部分合并成更易执行的 5 区间，适合跑步训练。它通常以 **CP** 为基准，但如果你把基准设置为 FTP，百分比映射方式一致。

| 区间 | 名称 | 英文名称 | % FTP | 常见用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 轻松 | Easy | $\le 80\%$ | 恢复跑、轻松跑、日常低强度。 |
| **Z2** | 中等 | Moderate | $81\%-90\%$ | 稳态耐力跑、长距离主体强度。 |
| **Z3** | 阈值 | Threshold | $91\%-100\%$ | 阈值跑、节奏跑的核心区间。 |
| **Z4** | 间歇 | Interval | $101\%-115\%$ | VO2 / 高强度间歇。 |
| **Z5** | 重复 | Repetition | $\ge 116\%$ | 短重复、冲刺、无氧爆发。 |

## 如何计算我的区间？

设你的FTP为 $B$（$B$ 可能是 FTP，也可能是 CP）。当你想算某个区间的功率边界时，就是把百分比乘上 $B$：

$$
W = B \times \frac{pct}{100}
$$

### 示例：FRIEL Z2（56%-75%）

假设你的 $B = 250W$：

$$
Z2_{min} = 250 \times 0.56 = 140W
$$
$$
Z2_{max} = 250 \times 0.75 = 187.5W
$$

所以你的 Z2 大约是 **140W - 188W**（实际显示会按取整规则落在整数瓦特上）。

## Trainingload.ai 建议

Trainingload.ai 会用功率区间比较计划强度与完成强度：

1. **按运动分别设置阈值**：跑步和骑行功率体系不同，建议分别维护 CP/FTP 与对应模型。
2. **定期更新**：FTP 和 CP 会随训练变化，建议周期性复测或使用自动估算保持区间有效。
3. **把区间当作目标带**：边界不是墙，重点是让主要训练时间符合目标训练刺激。
4. **复查完成训练**：训练后区间分布可以显示轻松日是否跑/骑太重，或关键间歇是否没有达到目标区间。
