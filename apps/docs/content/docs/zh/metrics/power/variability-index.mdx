# 变异性（Variability Index）

**变异性 (VI)** 用来衡量一次骑行中的功率输出是否平稳，也可用于有跑步功率的数据。简单来说，它告诉你这次训练是比较稳定，还是包含大量变速和冲刺。

## 计算公式

VI 是[标准化功率 (NP)](/zh/docs/metrics/power/normalized-power) 与 平均功率 (Avg Power) 的比值：

$$
VI = \frac{NP}{Avg Power}
$$

-   **标准化功率**：反映生理代价（包含波动成本）。
-   **平均功率**：反映机械做功（总能量输出）。

## 核心概念：为什么要关注 变异性 (VI)？

虽然 VI 最初是为自行车功率训练设计的，但随着跑步功率计（如 Stryd、Garmin、Coros）的普及，它也可以用于跑步功率分析。

### 1. 衡量配速效率 (Efficiency)
- **骑行**：对于铁人三项或计时赛选手，VI 可以反映稳态输出能力。VI 越接近 1.0，通常说明输出越平稳，额外冲刺越少。
- **跑步**：对于马拉松跑者，VI 反映了**体能分配的经济性**。跑步没有“滑行”，因此 VI 通常比骑行更低。如果 VI 偏高，通常意味着上坡跑得太用力，或者配速忽快忽慢。

### 2. 识别比赛特征 (Race Demands)
- **公路车**：绕圈赛通常 VI 很高（>1.2），因为需要频繁地在滑行和高功率出弯之间切换。
- **越野跑**：由于地形剧烈起伏，越野跑的 VI 会显著高于路跑，但这反映了路况的客观需求而非配速失误。

## 典型参考值

由于运动模式不同，**跑步的 VI 通常远低于骑行**。

### 骑行参考值

| VI 范围 | 骑行类型 | 描述 |
| :--- | :--- | :--- |
| **1.00 - 1.05** | 铁人三项 / 计时赛 (TT) | **很平稳**。长距离稳态配速常见目标范围。 |
| **1.05 - 1.10** | 爬坡 / 稳态训练 | **较平稳**。很多 Zone 2 训练会落在这个区间。 |
| **1.10 - 1.20** | 丘陵路段 / 团练 | **中等波动**。受地形起伏或跟车影响。 |
| **> 1.20** | 绕圈赛 / 山地车 (MTB) | **高波动**。包含大量滑行和无氧冲刺。 |

### 跑步参考值

| VI 范围 | 跑步类型 | 描述 |
| :--- | :--- | :--- |
| **1.00 - 1.02** | 场地跑 / 平路马拉松 | **很平稳**。配速控制较好的平路马拉松常见范围。 |
| **1.02 - 1.05** | 丘陵路跑 / 城市跑 | **正常波动**。受红绿灯、过街天桥或坡度影响。 |
| **1.05 - 1.15** | 越野跑 (Trail) / 变速跑 | **高波动**。包含爬升、技术路段下坡或间歇训练。 |

## Trainingload.ai 如何使用 VI

- **跑步/马拉松**：平路马拉松中，较低 VI 通常代表配速更稳定；如果路线起伏明显，不应强行追求平路目标。
- **铁三/TT**：较低 VI 通常意味着更少无谓冲刺，但仍要结合地形、风和赛道策略。
- **公路/山地**：高 VI 可能是项目特征。Trainingload.ai 会把它当作比赛需求上下文，而不是自动判断为配速错误。
- **单次训练复盘**：VI 会和 NP、平均功率、IF、地形、训练目标一起解释。
