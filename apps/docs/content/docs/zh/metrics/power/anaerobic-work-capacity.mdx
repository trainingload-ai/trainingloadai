# W' (无氧做功容量)

**W' (发音为 W Prime)** 代表你的**无氧做功容量 (Anaerobic Work Capacity)**。它是一个能量单位，通常以焦耳或千焦表示，用来描述你在超过 **[临界功率 (CP)](/zh/docs/metrics/power/critical-power)** 时可用的有限做功能力。

## 核心概念

想象你的体能由两部分组成：
1.  **临界功率 (CP)**：模型中的高可持续阈值。
2.  **W'**：当功率高于 CP 时会被消耗的有限做功储备。

## W' 的消耗与恢复

-   **消耗**：当功率 > CP 时，`消耗速率 = 实时功率 - CP`。功率越高，电量耗尽得越快。
-   **恢复**：当功率 < CP 时，W' 开始恢复。恢复速度取决于你当前的功率离 CP 有多远，以及你的有氧恢复能力。

## 耗尽意味着什么？

当 **W' 降为 0** 时，并不意味着你完全动不了，而是意味着你通常**无法继续维持高于 CP 的功率**，需要把功率降向 CP 或更低。

## 应用

-   **比赛配速**: 在短距离计时赛或爬坡中，合理分配 W' 以确保在终点线前刚好用完。
-   **间歇训练**: 监控 W' Bal (W' 余额) 来评估间歇跑/骑是否真正耗尽了无氧储备。

## Trainingload.ai 如何使用 W'

Trainingload.ai 会用 W' 解读 CP 之上的训练需求。两个总 TSS 接近的训练，可能因为 W' 消耗不同，呈现出完全不同的高强度压力。

W' 适合用于复查：

-   短冲、爬坡重复或 VO2 间歇是否达到预期刺激；
-   恢复段是否足够轻松，能否恢复重复输出能力；
-   运动员更偏短时爆发储备，还是更偏持续功率能力。

如果要做模型估算，可以使用 [临界功率计算器](/zh/critical-power-calculator)，它会同时拟合 CP 与 W'。

## 局限性

W' 依赖模型拟合。它的可靠性取决于功率-时间曲线里是否有足够多的最大努力数据。如果近期缺少 1-5 分钟和 10-20 分钟区间的高质量努力，估算结果可能不稳定。
