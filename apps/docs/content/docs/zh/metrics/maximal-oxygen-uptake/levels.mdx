# 最大摄氧量等级

> 这里所有的最大摄氧量（VO2 Max）都是估算值，不是实验室气体分析测得的 VO₂max。下文为简化表达，统一称为 VO2 Max。

我们会把 VO2 max 划分为 5 个等级，便于快速理解自己当前的有氧能力处于什么区间：

## 最大摄氧量等级

最大摄氧量等级本质上是把一个连续数值（VO2 Max，单位 `ml·kg⁻¹·min⁻¹`）映射为更直观的**有氧能力档位**。它适合用来：

- **快速解读**：你当前更接近“普通 / 好 / 很好 / 极好”哪一档。
- **看趋势**：同一设备/同一算法下，长期上升通常意味着你的有氧能力在提升。
- **按年龄/性别对比**：在有年龄与性别信息时，用更贴近人群差异的阈值表来解读。

## 什么算较高的最大摄氧量等级？

“高”或“优秀”的含义取决于你的**年龄、性别、运动项目与训练史**。更实用的判断方法是：

- **先用本页的“按年龄与性别”阈值表**看你属于哪一档；
- 再用同一条件下的**趋势**评估训练是否有效（不要只盯一天的波动）。

最大摄氧量等级划分有两种方式，系统会优先使用更精细的一种：

## Garmin 的等级靠谱吗？

建议这样用：

- **同一品牌/同一设备内**：把它当作趋势指标（更有价值）。
- **不同品牌/不同算法之间**：不要直接横向比较数值大小。
- 如果你希望更可复现的“表现型基准”，可以用固定距离的全力成绩（如 5K/10K）来估算，再对比长期变化。

## 平均水平 vs 高水平

在训练应用里，不建议把高水平阈值当成单一目标；更有效的是：

- 先把 VO2 Max 提升到**对你的年龄/性别而言更健康的区间**；
- 同时提升耐力项目的关键限制因素（阈值能力、运动经济性、耐久性、配速与补给策略）。

## 血氧 vs VO2 Max：是不是一回事？

结论是：**不是一回事**。

- **血氧（SpO₂）**：反映血液携氧饱和度，更多是“当下状态”的指标（受海拔、呼吸、疾病等影响）。
- **VO2 Max**：反映在高强度运动中，身体整体“摄氧—运氧—用氧”系统的最大能力上限，更偏“能力上限”。

SpO₂ 可能会影响你在某些环境下的表现（比如高海拔），但它不能替代 VO2 Max，也不等于 VO2 Max。

## 如何提升 最大摄氧量等级

提升最大摄氧量等级通常来自“有氧底座 + 高强度刺激”的组合：

- **稳定有氧训练（Zone 2）**：让你能承载更多训练量并提高恢复效率。
- **VO2 Max 间歇**：常见 3–8 分钟重复，接近最大有氧输出，质量优先。
- **渐进负荷**：逐步增加总训练量/间歇总量，而不是一次练爆。
