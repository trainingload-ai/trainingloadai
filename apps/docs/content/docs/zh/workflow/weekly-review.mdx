# 周度训练复盘

## 完成结果

在 15–20 分钟内写出一个结论，最多做一项主要调整，并确定用哪个日期或哪节课程验证这次决定。

## 1. 检查数据完整性

打开[活动](/zh/docs/guide/activity-feed-search)。阅读周度汇总前，先处理导入失败、重复活动和错误的计划关联。

## 2. 比较计划与实际

结合[日历](/zh/docs/guide/calendar)和当前计划，分别统计完成、缩短、跳过、替换和计划外训练。不要只看完成率。

## 3. 复核训练剂量

使用[概览](/zh/docs/guide/dashboard)和[训练负荷](/zh/docs/metrics/training-load)，保持运动项目和时间范围一致，并找到真正解释变化的关键活动。

## 4. 加入身体响应和现实约束

在有数据时检查睡眠、HRV、静息心率、整节训练 RPE、酸痛和主观疲劳。恢复数据缺失会降低结论置信度，但不能证明恢复良好或较差。

## 5. 选择下一步

只选择其中一项：

- 保持计划不变。
- 移动一节课程。
- 降低一节课程的时长或强度。
- 用恢复训练替换一节课程。
- 当问题超出训练建议边界时，交由人工或医疗专业人员判断。

## 验证复盘结果

记录使用了哪些证据、做了什么决定、具体影响哪节未来课程，以及何时重新检查。如果使用[AI 教练](/zh/docs/guide/ai-coach)，确认它引用的是同一时间范围和同一组证据。
