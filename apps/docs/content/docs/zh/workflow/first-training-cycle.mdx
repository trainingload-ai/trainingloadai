# 第一次端到端训练闭环

## 完成结果

你将得到一个可信的运动档案、一条已就绪活动、一个已激活或已复核的计划，以及一个明确的下一节训练决策。

## 开始前

- 使用自己的数据或合成训练数据，不要共享账号 Token 或精确住所位置。
- 在打开多个双向同步前，先确定一个主要导入路径。
- 如果暂时没有平台连接，准备一份近期 FIT、TCX 或 GPX 文件。

## 1. 校准运动档案

按照[个人资料、阈值与区间](/zh/docs/guide/profile-thresholds-zones)检查时区、单位、分项目阈值和负荷来源优先级。

## 2. 导入一条实际活动

持续同步使用[连接数据](/zh/docs/guide/connect-data)，可控的首次导入使用[上传活动文件](/zh/docs/guide/upload-activity-files)。

等待活动进入**已就绪**状态。活动卡片已经出现，不代表图表和负荷已经完成处理。

## 3. 检查活动证据

打开[活动详情](/zh/docs/guide/activity-detail)，检查来源、开始时间、时长、距离、心率或功率覆盖、分圈和负荷。数据源没有提供的传感器数据应继续显示为缺失。

## 4. 创建或选择计划

按照[创建训练计划](/zh/docs/guide/create-training-plan)检查目标、日期、运动项目、日程和预期负荷，再决定是否激活。

## 5. 对齐计划与实际

打开[日历](/zh/docs/guide/calendar)。如果实际活动和计划课程确实是同一次训练，就建立关联；计划外或无关活动应保持独立。

## 6. 决定下一步

先查看[今日与当前状态](/zh/docs/guide/today-and-current-state)，再向[AI 教练](/zh/docs/guide/ai-coach)提出一个明确问题，包含决策目标、时间范围、约束和需要检查的证据。

## 验证整个闭环

- 档案采用预期单位、时区和阈值。
- 至少一条活动已就绪，并且只展示来源真正提供的数据。
- 当前计划和今天的课程可见。
- 只有代表同一次训练的计划与活动才建立关联。
- 任何后续调整都明确可见并可以复核。
