# 排查活动、负荷和恢复数据问题

## 从症状开始

| 症状 | 首先检查 | 下一步指南 |
| --- | --- | --- |
| 活动没有出现 | 平台连接、导入时间范围和文件状态 | [连接数据](/zh/docs/guide/connect-data) |
| 活动重复 | 多条导入路径和来源标识 | [集成](/zh/docs/guide/integrations) |
| 活动存在但没有负荷 | 处理状态、时长、心率、功率、配速和档案阈值 | [活动详情](/zh/docs/guide/activity-detail) |
| 图表或分圈报错 | 来源文件是否真的包含记录和分圈 | [上传活动文件](/zh/docs/guide/upload-activity-files) |
| 睡眠、HRV 或静息心率为空 | 健康权限、平台覆盖范围、日期和时区 | [账户、权限与用量](/zh/docs/guide/account-permissions-and-usage) |
| PMC 明显偏高或偏低 | 重复活动、缺失日期、运动筛选、负荷来源和阈值变化 | [训练分析工作流](/zh/docs/guide/training-analysis-workflow) |

## 按顺序排查

1. 确认预期数据来源和时间范围。
2. 确认来源是否提供计算所需的传感器数据。
3. 检查导入与处理状态。
4. 检查档案阈值和负荷来源优先级。
5. 把一条异常活动与一条已知正常活动比较。
6. 最后才修改配置或联系支持。

## 准备安全的支持信息

可以提供活动日期、运动项目、来源、可见状态、预期结果、实际结果和复现方式。删除邮箱、OAuth Token、API Key、精确住所位置和第三方平台私人标识。

不要为了得到更喜欢的负荷数值而修改阈值。配置变化会影响后续解释，并可能改变历史派生指标。
