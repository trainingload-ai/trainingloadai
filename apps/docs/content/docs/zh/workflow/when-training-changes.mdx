# 当实际训练没有按照计划发生

## 完成结果

保留真实的计划与实际历史，并且只对后续训练做有证据支持的最小调整。

## 选择对应情况

| 实际情况 | 正确记录方式 | 不要这样处理 |
| --- | --- | --- |
| 跳过课程 | 保留计划课程为跳过或未完成 | 上传一条虚假的零时长活动 |
| 缩短课程 | 把真实的短活动关联到计划课程 | 修改实际数据使其看起来符合目标 |
| 替换课程 | 同时保留原计划和实际项目 | 重命名无关活动来掩盖变化 |
| 计划外训练 | 保持活动未关联，除非它确实替代某节课 | 仅因为日期接近就强制关联 |
| 课程延期 | 只有真实决策发生变化时才移动计划课程 | 修改实际活动的时间戳 |

## 调整前先复核

1. 在[日历](/zh/docs/guide/calendar)打开对应日期。
2. 在[活动](/zh/docs/guide/activity-feed-search)确认来源和处理状态。
3. 在[活动详情](/zh/docs/guide/activity-detail)检查负荷和传感器覆盖。
4. 把变化与近期负荷、睡眠或恢复状态以及下一次关键课放在一起比较。
5. 如果确实需要调整，先只改一个主要变量：时间、时长或强度。

## 明确地询问 AI 教练

例如：“昨晚睡眠较差，昨天 45 分钟轻松跑缩短到 25 分钟。周六长跑是否需要调整？”不要在没有约束的情况下要求 AI 重写整份计划。

## 验证结果

日历应继续显示原计划、实际完成、差异原因以及具体修改了哪节后续课程。原始活动证据不应被改写。
