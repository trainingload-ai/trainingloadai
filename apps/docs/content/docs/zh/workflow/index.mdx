# 完整训练流程

Trainingload.ai 不是一组彼此独立的图表。可靠的训练决策需要把原计划、实际完成、数据质量和运动员当前状态连接起来。

## 训练闭环

| 阶段 | 需要回答的问题 | 主要指南 | 完成标志 |
| --- | --- | --- | --- |
| 1. 校准 | 单位、时区、阈值和区间是否可用？ | [个人资料、阈值与区间](/zh/docs/guide/profile-thresholds-zones) | 档案符合当前运动项目和能力 |
| 2. 接入 | 哪个来源提供活动和健康数据？ | [连接数据](/zh/docs/guide/connect-data) | 至少一条活动进入已就绪状态 |
| 3. 计划 | 当前目标和日程是什么？ | [创建训练计划](/zh/docs/guide/create-training-plan) | 计划已经复核并激活或等待激活 |
| 4. 执行 | 今天应该完成什么？ | [今日与当前状态](/zh/docs/guide/today-and-current-state) | 清楚计划课程和当天约束 |
| 5. 记录 | 实际发生了什么？ | [移动端记录与文件上传](/zh/docs/guide/mobile-recording) | 实际活动已经保存或导入 |
| 6. 对账 | 活动是否属于某节计划课程？ | [活动列表与搜索](/zh/docs/guide/activity-feed-search) | 计划与实际正确关联或明确分开 |
| 7. 复核 | 活动和近期趋势支持什么结论？ | [活动详情](/zh/docs/guide/activity-detail) | 来源、负荷、图表和上下文支持解释 |
| 8. 决策 | 后续训练是否需要改变？ | [AI 教练](/zh/docs/guide/ai-coach) | 建议调整清晰、可复核且未被静默执行 |
| 9. 循环 | 本周和整个周期是否仍在靠近目标？ | [周度训练复盘](/zh/docs/workflow/weekly-review) | 下一次复盘时间和关键课程明确 |

## 先走一次主流程

新账号或需要检查整套产品是否连通时，先完成[第一次端到端训练闭环](/zh/docs/workflow/first-training-cycle)。

真实训练与计划不一致时，再进入对应场景：

- [跳过、缩短、替换或计划外训练](/zh/docs/workflow/when-training-changes)
- [活动、负荷或恢复数据缺失](/zh/docs/workflow/data-and-load-problems)
- [每周计划与实际复盘](/zh/docs/workflow/weekly-review)

## 把观察与决策分开

活动、图表和 AI 消息都是证据，不是自动修改计划的指令。先确认数据来源和时间范围，再写出解释，最后决定是否调整后续训练。
