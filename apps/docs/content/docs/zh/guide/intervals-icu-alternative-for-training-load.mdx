# Intervals.icu 训练负荷替代方案

如果你已在 Intervals.icu 分析训练，可以先决定是更换工具，还是继续保留分析习惯，同时尝试 Trainingload.ai 的计划与复盘流程。

Intervals.icu 提供活动时间线、功率和心率图表、区间分析及自定义图表。可查看它的[活动分析介绍](https://www.intervals.icu/features/analyze/)了解当前功能。

## 在 Trainingload.ai 中可以尝试什么

- 把已完成活动关联到计划课程，对照原本安排与实际完成。
- 查看活动时间线、PMC 和表现趋势，再结合计划讨论下一步。
- 从活动或计划进入智能教练，检查复盘与课程调整建议。

先阅读[活动详情](/zh/docs/guide/activity-detail)、[时间线](/zh/docs/guide/activity-timeline)和[计划状态管理](/zh/docs/planning/plan-lifecycle)，按自己常用的训练任务比较。

## 连接自己的 Intervals.icu 记录

1. 云服务用户按[平台连接指南](/zh/docs/guide/connect-third-party-platforms#连接-intervalsicu)操作；自托管用户按[API Key 设置](/zh/docs/self-host/configuration#连接-intervalsicu)操作。
2. 选择需要的同步方向。先确定在哪个平台维护区间和计划，避免两边自动覆盖同一份安排。
3. 同步一条已知活动，核对日期、时长、来源和传感器数据。
4. 在[日历](/zh/docs/guide/calendar)中关联课程，再比较计划与实际负荷。

## 比较结果时注意什么

相同活动在不同平台上的负荷或区间分布可能不同。先比较原始记录、阈值和负荷来源设置，再解释差异。连接活动也不代表自动复制所有自定义图表、字段或计划。

可以先保留两个平台，完成一次“导入活动 → 关联课程 → 复盘”的流程，再决定长期使用方式。需要先看界面时，[打开 Demo](https://demo.trainingload.ai/zh)。
