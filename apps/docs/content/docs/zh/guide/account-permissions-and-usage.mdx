# 账户、权限与智能教练用量

账户设置控制身份与访问，权限控制哪些设备和平台数据可以进入 Trainingload.ai，用量页面解释会员和智能教练用量。设置新设备或调查功能缺失时，应把它们放在一起检查。

## 开始前

- 在网页端和移动端登录同一个 Trainingload.ai 账户。
- 保持可以访问账户邮箱，以便接收验证码。
- 在移动端确认操作系统是否已经拒绝健康或位置权限。
- 开启开关前，先决定允许哪些阈值自动更新。
- 不要分享验证码、密码、连接凭据或包含私人账户标识的截图。

## 1. 验证身份和密码状态

网页端打开**账户**；移动端打开**我的 → 账户**。

这里可以查看：

- 显示名称。
- 账户邮箱和验证状态。
- 是否已经设置密码。

当前邮箱字段为只读。账户尚未验证时，请请求六位验证码并在过期前输入。网页端已发送的验证码有效期为五分钟，倒计时进行中不能重复发送。

账户没有密码时使用**设置密码**，已经有密码时使用**修改密码**。通过 OAuth 登录的账户仍可能显示“未设置密码”；应使用页面提供的密码操作，不要直接判断账户异常。

### 找回访问权限并完成登录

从登录页选择**忘记密码**，请求重置邮件。只打开最新的重置链接，确认它返回 Trainingload.ai 的重置页面，再设置新密码。链接过期、格式错误或已经使用时，需要重新发起重置请求。

OAuth 登录可能先经过完成页或错误页，再返回应用。完成页没有跳转时，回到登录页重试一次；出现错误页时，只记录可见错误文字，不要分享 token 或完整回调网址。

当其他应用请求访问 Trainingload.ai 时，OAuth 授权页会显示请求应用、当前账号、请求 scope 和返回位置。只有这四项都符合预期时才同意；拒绝授权不会授予本次请求的访问权限。

## 2. 检查移动端权限与数据源

打开**我的 → 账户 → 连接**或移动端**权限**页面。数据源分成本机来源和第三方服务。

本机来源包括：

- **健康**：授权支持的健康与训练读取权限，查看已授权或部分授权状态，请求历史同步，管理已连接设备，或打开系统健康设置。
- **位置**：允许路线记录；权限被拒绝后可打开系统设置。

第三方来源可包括 Strava、Polar、COROS、Suunto、Wahoo 和 Intervals.icu。来源行会显示当前状态。打开来源后可以连接、查看平台专用设置，或继续进入连接页面。

设备权限和服务端连接是两种不同状态。健康权限可能已经在操作系统中授权，但 Trainingload.ai 设备连接仍需要重新连接。从系统设置返回后重新打开来源详情，让应用刷新两种状态。

## 3. 控制指标自动更新

在网页端或移动端打开**账户 → 自动更新**。每个开关授权一个指标更新：

| 分组 | 指标              |
| ---- | ----------------- |
| 功率 | FTP、CP、W′、Pmax |
| 配速 | TP、CS            |
| 心率 | LTHR、最大心率    |

只开启你希望 Trainingload.ai 根据有效证据更新的指标。开启开关不代表新数值会立即产生；系统仍然需要足够且受支持的活动数据。

自动更新可能改变区间、图表、结构化课程和负荷解释使用的阈值。更新后应检查指标历史，并先复核一条近期活动，再比较新旧周期。

## 4. 查看会员与智能教练用量

账户中的会员卡片显示：

- 当前方案和激活状态。
- 会员周期或到期上下文。
- 计费来源。
- 是否安排在周期结束时取消。

只有来自受支持订阅计费来源的有效订阅，才会显示应用内订阅管理操作。其他访问来源可以显示会员状态，但不一定提供同样的管理按钮。

从会员卡片或移动端账户区域打开**用量**。页面显示：

- 当前方案。
- 可用积分；上一次已完成操作超出原余额时可显示负数。
- 本月订阅积分的已用、剩余和到期时间。
- 可用或因会员失效而锁定的补充积分，以及最近到期时间。
- 未清偿债务、积分消耗趋势、操作次数和逐笔流水。

可以选择 1 天、7 天、30 天、本月至今或上个月。流水会标记标准模式（1×）、深度模式（3×）、混合模式操作、订阅发放、补充包、赠送、退款和抵债。每 1,000 个等价 tokens 计为 1 积分；等价 tokens 会综合缓存输入、未缓存输入、输出、模式和全局倍率，因此积分不能直接换算成固定消息数。

## 5. 设置应用偏好

在网页端打开**设置**，可以选择：

- 浅色、深色或跟随系统主题；
- 公制或英制单位；
- 图表横轴显示方式；
- 12 小时或 24 小时时间格式；
- 首选界面语言。

这些控件在点击**保存**前只是临时值。切换语言还会把当前路由移动到所选语言，并保存后续访问偏好。单位和时间格式只改变显示，不会改写活动原始记录。

## 6. 验证跨设备设置

修改账户、连接、权限或自动更新设置后：

1. 在当前设备保存或完成操作。
2. 返回来源列表，确认显示状态。
3. 刷新另一台设备。
4. 确认账户邮箱和相关服务端设置一致。
5. 本机权限必须在授予权限的设备上验证；它们不会自动转移到另一部手机。

## 验证设置

- 网页端和移动端显示相同账户邮箱。
- 邮箱验证和密码状态符合预期登录方式。
- 健康与位置显示预期设备权限状态。
- 第三方平台显示预期服务端连接状态。
- 只开启了预期的自动指标更新开关。
- 会员状态和用量流水与最近的配额或智能教练操作一致。
- 重新打开设置后，主题、单位、图表、时间格式和语言仍保持已保存状态。

## 故障排查

- **验证码无效**：输入完整六位数字，确认邮箱并检查有效期；只有重新发送可用后再请求新验证码。
- **无法修改邮箱**：当前账户界面没有提供邮箱修改；该字段有意设置为只读。
- **健康已授权但未连接**：重新打开健康来源，检查服务端/设备连接状态，并在页面提供时执行重新连接。
- **位置仍显示拒绝**：打开操作系统应用设置；已经拒绝的权限可能不会再次弹出系统请求。
- **OAuth 后平台仍显示未连接**：刷新来源状态，确认登录同一个 Trainingload.ai 账户，并检查平台专用设置。
- **自动指标没有变化**：确认开关已开启，且近期有效活动包含足够的受支持数据。
- **用量为空**：选择更大范围，并确认账户存在智能教练配额或消耗记录。
- **应用内无法管理会员**：只有受支持的有效订阅来源才显示管理入口；检查页面展示的计费来源。
- **重置链接被拒绝**：重新请求邮件并使用最新链接，不要复用已消费或过期 token。
- **OAuth 授权请求陌生**：先拒绝，再核对请求应用、scope、当前账号和返回位置。
- **偏好设置没有变化**：点击保存后重新打开设置；本地显示偏好与服务端语言设置的刷新时间可能不同。
