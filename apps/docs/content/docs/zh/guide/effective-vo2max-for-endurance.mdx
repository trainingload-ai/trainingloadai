# 在耐力训练里理解 effective VO2max

Trainingload.ai 使用活动中可用的证据估算 effective VO2max / VDOT。详情页用于检查历史，并在有足够可比较跑步记录时展示有条件的未来走势。这些是模型估计，不是实验室测量，也不保证未来结果。

[在 Demo 中打开概览](https://demo.trainingload.ai/zh/dashboard)，再选择**最大摄氧量**卡片。Demo 当前记录决定预测是否可用，下方带预测的截图使用应用中的合成示例数据。

## 开始前准备

- 导入近期跑步活动，等待处理完成。
- 核对个人资料中的最大心率、所选估算来源与适用的校正因子。
- 选择输入可靠、训练目的可比较的活动，记录传感器、地形或估算设置的变化。
- 记录结论时，区分活动估算、当前值与预测。

预测使用符合条件的跑步观察。切换概览运动筛选，不会因此生成骑行或游泳预测。

## 1. 打开最大摄氧量详情

在概览找到并选择**最大摄氧量**卡片。详情包含当前值、可用的四周走势、图表、历史范围标签、解释文字和**问教练**。

即使没有预测，当前值仍然可能显示。应同时检查可用性提示，以及图表是否真的包含未来估计。

## 2. 选择历史时间窗

使用 **7、14、30、60 天**标签，选择要调查的已记录历史。开始时选择能包含多条可比较活动的范围。

预测可用时，图表也会展示与标签长度对应的未来区域，最多显示 30 天。例如，7 天标签的未来区域短于 30 天标签。顶部的**四周后预计**仍表示四周终点。

## 3. 确认正在读哪种数值

| 显示内容 | 表示什么 |
| --- | --- |
| 当前最大摄氧量 | 产品当前展示的数值。 |
| 历史记录与活动点 | 所选历史范围内，对应日期可用的估计或记录。 |
| 当前估计水平 | 图表提供该读数时，表示模型在历史截止点估计的水平。 |
| 四周后预计 | 可用四周预测的终点。 |
| 参考范围或 80% 预测区间 | 模型为预测提供的范围，以页面实际标记为准。 |

产品当前值和模型估计水平可能不同，比较前先读标签与日期。未来点不表示已经完成的活动。

在历史或未来点上移动鼠标，检查可用读数。遇到异常历史点时，根据日期到**活动**中找到原始记录，核对记录和估算来源，再判断是否真的发生能力变化。

## 4. 阅读预测及其范围

未来走势可用时，顶部展示**四周后预计**、相对当前值的方向、对应范围和历史截止日期。这些信息应一起阅读。

**参考范围**不能转述成经过校准的 80% 预测区间。页面明确显示 **80% 预测区间**时，也应保留该标记。两种标记都不保证真实未来值一定落在范围内。

预测跟随历史观察与模型假设。它和 PMC 基于排期的负荷走势是不同计算。增加一节未来课程，不会直接证明最大摄氧量会提升到图中的数值。

先把估计作为复盘背景，再结合活动执行与训练负荷。负荷操作流程见[查看 PMC 历史与预测走势](/zh/docs/guide/pmc-forecast)。

## 5. 处理预测不可用

修改设置前，先读页面显示的状态。

| 提示含义 | 下一步 |
| --- | --- |
| 需要积累更多跑步记录 | 继续积累符合条件且处理完成的跑步活动。仅有当前值不等于有足够预测证据。 |
| 需要新的跑步记录 | 检查最近有效观察是否过旧，再导入近期活动。 |
| 指标计算方式改变 | 检查来源和校正设置，可能需要积累新的可比较记录。 |
| 预测暂时不可用 | 继续使用已有历史，并分别核对请求和数据状态。 |

历史图为空，也可能只是所选 7 天内没有观察。先尝试更长的历史范围，再判断是否完全没有记录。缺失估计不能当作零值。

不要为了得到希望看到的预测而随意调整最大心率或校正设置。设置变化会同时影响数值与可比性。

## 6. 携带证据问教练

选择详情中的**问教练**。准备好的问题会询问当前水平、历史变化和可用的四周走势，核对问题符合目的后再发送。

补充希望解释的日期和活动，要求教练区分已记录证据与估计，并指出缺失背景。打开链接不会自动发送问题，也不会应用计划变更。

确认提议前，核对活动证据、计划背景和正常的[智能教练确认流程](/zh/docs/guide/ai-coach)。

## 验证解释结果

记录历史时间窗、输入来源、相关日期、当前值、预测是否可用，以及范围的实际标记。你应能说明哪些观察支持历史趋势，哪部分仍是未来估计。

## 常见问题

### 为什么选择 7 天后，四周汇总没有变化

标签改变图表窗口，顶部仍表示四周终点；图表可以只展示可用未来走势中的较短一部分。

### 为什么有当前值，却没有预测

当前展示和预测的证据要求不同。跑步观察不足、过旧、不可比较或模型不可用，都可能导致没有预测。

### 为什么某次活动和趋势差异很大

活动估算与模型当前水平概括的证据不同。检查来源、传感器质量、地形和训练目的，用多条适当记录比较，不把单点直接当成阶段结论。

### 已排课程会改变这个预测吗

PMC 使用适用的计划与习惯输入估计未来负荷，最大摄氧量走势使用自己的历史观察模型。不要把两种预测当作同一计算。

### 为什么和手表或实验室结果不同

它们可能使用不同方法、输入与日期，应保持各自序列的口径一致。测量和估算概念见[最大摄氧量](/zh/docs/metrics/maximal-oxygen-uptake)。
