# 在耐力训练里理解 effective VO2max

Trainingload.ai 会根据活动中可用的证据估算 VO2max/VDOT。它应被理解为能力响应趋势，而不是实验室测量、诊断结论或每日准备度评分。真正有价值的是比较一段时间内相似活动，并把趋势与执行和负荷放在一起解释。

## 开始前准备

- 导入多条近期且可比较的耐力活动，并等待它们进入已就绪状态。
- 检查个人资料中的最大心率、跑步阈值、单位和运动类型。
- 优先选择配速或功率以及心率数据可靠的活动。
- 不要把热身、恢复步行、传感器失败和不同运动混入同类比较。
- 先提出一个复盘问题，例如当前跑步阶段是否产生了稳定的正向响应。

## 1. 打开趋势，而不只看当前值

打开**仪表盘**，选择单一运动，并设置包含多节可比较训练的日期范围。点击体能状态中的 **VO2Max** 卡片打开历史趋势。

当前值只是一个快照；历史趋势更有用，因为它能显示估算值是否稳定、正在漂移，或被单条活动主导。

## 2. 检查活动是否可比较

打开趋势背后的活动并对照：

- 运动类型与课程目的。
- 时长与地形。
- 配速或功率质量。
- 心率是否存在及传感器是否可靠。
- 高温、海拔、风、疲劳和比赛强度。
- 页面可用时显示的活动估算来源。

比赛表现估算、心率与速度估算、校正后估算不是完全相同的观察。Trainingload.ai 可以保存来自不同证据的多种 VO2max/VDOT 估算；解释前要知道当前数值来自哪一种。

## 3. 判断趋势模式

使用多条可比较记录，不要给单点套固定阈值。

### 执行稳定且趋势逐步改善

这可能说明训练阶段正在产生有效响应。还要确认关键课完成情况，并排除阈值、校正因子或传感器变化。通常不需要立即修改计划。

### 近期负荷高但趋势走平

不要自动增加训练量。对照 [ATL](/zh/docs/metrics/pmc/acute-training-load)、[TSB](/zh/docs/metrics/pmc/training-stress-balance)、计划完成度和课程质量。更安全的第一步可能是维持负荷、减少一次非必要强度，并在下一节可比较训练后复查。

### 可比较训练连续下降

检查疲劳、环境、疾病、恢复缺失和数据质量。如果执行质量也在下降，用一个小且可撤回的调整保护下一节关键课；如果只有一个点下降，应先调查该活动，不要重写整周。

### 单个数值突然异常

打开该活动，检查心率流、速度或功率、暂停、运动分类、最大心率设置，以及这次努力是否真的可比较。在找到原因前，不要让这个点决定训练阶段结论。

## 4. 把能力响应与训练压力结合

同时回答两个问题：

1. **施加了什么压力？**查看 CTL、ATL、TSB 和单次课程负荷。
2. **出现了什么响应？**查看 effective VO2max/VDOT 趋势、课程执行和主观状态。

这样可以形成四种实用情形：

| 负荷背景     | 响应趋势   | 实际解释                               |
| ------------ | ---------- | -------------------------------------- |
| 按计划上升   | 稳定或改善 | 继续执行，在既定节点复查。             |
| 高或快速上升 | 下降       | 加量前先调查恢复、数据质量和课程执行。 |
| 低或中断     | 下降       | 检查一致性、漏训、疾病和停训背景。     |
| 稳定         | 单个异常点 | 调查该活动，不要当作阶段结论。         |

## 5. 做出一个可复查决定

只选择以下一种结果：

- **继续：**趋势与执行支持当前阶段。
- **维持：**负荷保持不变，等下一节可比较训练。
- **减少一个压力源：**缩短、移动或简化一节未来课程。
- **先修正证据：**修复设置或数据后再决定。

记录理由、具体改动和用于验证的下一节可比较活动。不要为了让图表符合预期数值而随意重新校准。

## 验证解释结果

- 趋势使用单一运动和相关日期范围。
- 有多条在目的与数据质量上可比较的活动。
- 已经打开并调查突然异常的点。
- 估算来源或设置改变与真实表现变化被明确区分。
- 负荷、计划执行和主观背景支持当前解释。
- 已经定义下一次复查点。

## 故障排查

- **VO2Max 卡片为空：**确认支持的已就绪活动包含必要的配速或功率及心率数据，再扩大日期范围。
- **修改资料后趋势跳变：**最大心率、校正因子、阈值或重新计算都可能改变估算；只在已知且一致的设置下比较。
- **跑步和骑行结论不同：**分别复盘不同运动，它们使用不同活动证据，不应合并为一个表现结论。
- **比赛和轻松跑数值差异很大：**比较估算来源与课程目的，优先相信重复且可比较的观察。
- **与手表或实验室结果不同：**方法和输入不同，应保持各自序列口径一致，而不是强行追求完全相等。
- **下降同时伴随疼痛或疾病：**结合真实症状并寻求合格专业意见，估算值不能提供医疗许可。
