# 在移动端创建计划并完成力量训练

移动端可以创建完整的计划草稿，也可以执行计划中的力量课程。需要离开网页端编排课表，或在器械旁逐组记录力量训练时，使用这条工作流。

## 开始前

- 登录账号，并确认“计划”页可以加载数据。
- 确定计划名称和周期长度。
- 创建力量课程前，确定动作和可用器材。
- 先保存为草稿，检查完整课表后再激活。

## 1. 选择创建方式

打开**计划**，选择**创建计划**，然后选择：

- **手动编排**：自行安排每一节耐力或力量课程。
- **智能教练生成**：填写目标和限制，再前往智能教练继续完成计划对话。

本教程使用“手动编排”。

## 2. 填写基本信息

填写计划名称，选择 1 到 24 周的周期，并按需在说明中记录训练原则、限制或执行重点。名称和周期确认无误后再继续；如果之后缩短周期，不能让已有课程落在新周期之外。

## 3. 编排课表

上下滚动课表，打开需要安排训练的日期。同一天可以添加多节课，“当日课次”决定它们的先后顺序。

训练结构分为两类：

- **耐力训练**：跑步、骑行、游泳或拉伸步骤。手动模式用于可视化编排；DSL 模式用于系统支持的文本语法。
- **力量训练**：由动作、热身组和主训练组、组数、次数或时间、负重、强度及休息组成。

每节课程都应检查：

1. 周次、星期和当日课次顺序。
2. 容易识别的训练名称。
3. 教练指导是否保存在备注中。
4. 耐力或力量结构是否完整并通过验证。
5. 修改是否已经保存回计划草稿。

## 4. 检查并保存草稿

至少添加一节训练后才能进入检查步骤。对照周期周数、总课次、训练日数量和按时间排列的课表，然后保存计划。新计划会保持为草稿，方便激活前继续核对。

打开计划详情，确认所有课程都出现在正确的相对日期。激活前先阅读[计划生命周期](/zh/docs/planning/plan-lifecycle)。

## 5. 开始计划中的力量训练

准备执行力量课程时，从今日、日历或进行中的计划打开该课程，选择**按计划开始**。移动端会根据计划处方创建一条真实力量活动，并进入训练中界面。

开始训练不等于完成训练。计划处方会继续保留，而实际训练组用于记录真正完成的内容。

## 6. 逐组记录

对每个动作和训练组：

1. 检查计划重量、次数或持续时间。
2. 如果实际完成内容不同，调整实际重量或结果。
3. 完成后标记该组；误触时可以撤销。
4. 继续记录，直到动作和整节课的完成进度与实际一致。

暂时离开训练中页面不会删除记录，之后可以从计划课程再次进入。

## 7. 结束并验证

可以选择 1 到 10 的 session RPE，然后选择**结束训练**。移动端会完成活动并打开活动详情。

确认：

- 时长和 session RPE 与实际训练一致。
- 完成组数、重量、次数和计时训练记录正确。
- 活动仍然关联对应的计划课程。
- 计划处方与实际完成数据可以明确区分。

## 常见问题

- **无法进入检查步骤**：至少添加一节有效课程，并保证所有课程都位于计划周期内。
- **力量课程无法保存**：填写动作名称，添加至少一个组别，并检查组数和次数范围。
- **按计划开始失败**：检查网络，刷新计划课程，并确认它仍然包含力量结构。
- **不小心离开训练中页面**：重新打开计划课程，已经创建的活动记录仍会保留。
