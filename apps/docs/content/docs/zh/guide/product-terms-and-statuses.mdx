# 产品术语与状态

在执行具体任务时把本页作为参考。这些术语描述产品状态，本身并不判断一次训练是好还是坏。

## 核心对象

| 术语 | 含义 |
| --- | --- |
| 运动档案 | 用于解释训练的时区、单位、阈值、区间、偏好和运动项目上下文 |
| 训练计划 | 包含一组带日期计划课程并具有生命周期状态的训练周期 |
| 计划课程 | 某个日期原本打算完成的训练，包括项目、结构、时长、强度和可用时的预期负荷 |
| 实际活动 | 通过设备记录、第三方同步或文件上传得到的真实训练记录 |
| 计划与活动关联 | 明确表示某条实际活动对应某节计划课程的关系 |
| 当前状态 | 用于今天训练决策的近期负荷、恢复输入、主观反馈和其他上下文 |
| 复盘 | 基于现有证据对单次活动、一天、一周、一个月或整个计划形成的解释 |
| AI 操作 | 创建、移动或调整未来训练等建议或已经执行的动作 |

## 活动状态

| 状态 | 表示什么 | 应该怎么做 |
| --- | --- | --- |
| 上传中或导入中 | 文件或平台数据仍在传输 | 等待后再决定是否重试 |
| 处理中 | 活动已经存在，但派生数据可能还不完整 | 暂时不要解读缺失的负荷或图表 |
| 已就绪 | 当前支持的处理已经完成 | 检查来源真正提供的数据 |
| 失败 | 导入或处理无法完成 | 阅读可见错误并进入故障排查 |
| 重复 | 相同来源活动或等价文件已经存在 | 保留一条可信的数据路径 |

## 计划和课程状态

| 状态 | 表示什么 |
| --- | --- |
| 草稿 | 计划成为当前计划前仍可复核或修改 |
| 进行中 | 计划正在为当前及未来课程提供上下文 |
| 已完成 | 计划周期已经结束，但仍可用于复盘 |
| 已计划 | 课程已经安排，但还没有最终执行结果 |
| 已完成课程 | 课程已经完成，通常带有关联活动或明确完成记录 |
| 已跳过 | 这节课程被明确决定不执行 |
| 计划外活动 | 实际活动不代表任何已安排课程 |

## 负荷、复盘与积分

- **训练负荷**是训练剂量的派生估算，是否可用取决于运动项目、时长、传感器数据、阈值和负荷来源规则。
- **教练复盘**是基于证据的解释，不是设备原始数据，也不是医学诊断。
- **AI 积分**是符合条件的 AI 操作所消耗的用量单位。积分账单不代表训练负荷，也不代表账号权限。
- **Demo 账号**用于展示有代表性的产品状态，其限制不等于普通账号的角色和能力定义。
