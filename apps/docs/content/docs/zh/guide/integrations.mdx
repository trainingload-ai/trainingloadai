# 训练平台对接怎么选：Strava、Garmin、COROS 对照

**训练平台对接**决定训练如何进入 Trainingload.ai。先选路径：Strava 或 COROS 持续同步、Garmin 一次性历史导入、Intervals.icu 的 OAuth 或 API Key，或上传 FIT / TCX / GPX。具体授权和验证点击见[连接 Strava、Garmin 与 COROS](/zh/docs/guide/connect-third-party-platforms)。

平台能力和支持的方向可能调整，连接弹窗里实际显示的操作始终是最终依据。

## 连接前准备

- 登录真正保存训练数据的平台账号。
- 为每条活动确定一个主要来源，避免同一训练同时经过两个已连接平台转发。
- 先判断自己需要持续同步、一次性历史导入，还是单个文件上传。
- 准备好平台凭证或 API Key，但只在正式连接弹窗中输入。
- 记住 Trainingload.ai 当前最新的一条活动，方便识别首次成功导入的结果。

## 选择正确的方式

| 来源            | 适用场景                      | 连接方式               |
| --------------- | ----------------------------- | ---------------------- |
| Strava          | 持续同步活动                  | 账号连接和同步设置     |
| Polar           | 持续导入 Polar 活动           | OAuth 与同步设置       |
| COROS           | 活动、日常数据和兼容计划导出  | 账号连接与手动同步     |
| Intervals.icu   | 活动同步和兼容计划课程流程    | OAuth 或 API Key       |
| Suunto          | 持续导入训练和兼容 Guide 流程 | OAuth 与同步设置       |
| Wahoo           | 持续导入 Wahoo 训练           | OAuth 与同步设置       |
| Garmin          | 一次性历史活动导入            | 导入任务，不是长期连接 |
| FIT / TCX / GPX | 单个文件或其他平台导出        | 手动上传               |

## 连接平台

1. 选择平台卡片。
2. 阅读数据方向和同步设置。
3. 通过 OAuth 授权，或输入所需 API Key。
4. 保存同步偏好。
5. 如果弹窗提供首次同步，执行一次。
6. 打开活动列表，确认最新活动已导入。

不要把 API Key 粘贴到智能教练、计划备注或支持截图中。密钥只能输入正式连接弹窗，已保存密钥不会重新回传给客户端。

## 首次同步与自动同步

首次同步通常导入一段近期记录或启动历史任务；自动同步负责未来的新活动；部分平台还提供手动补偿同步，用于处理遗漏通知。

大量导入时，请等待当前批次完成，不要重复启动。活动可能随着各条目处理进度陆续出现。如果缺少心率、功率或 GPS，先检查来源平台和原始文件。

## Garmin 历史导入

Garmin 在当前界面中是一次性历史导入，而不是持续连接。通过 Garmin 卡片启动任务，并回到同一弹窗查看最近任务状态。

## 断开连接

断开连接会停止未来同步并移除当前凭证，一般不会删除已经导入的活动。只有确认某条活动确实不需要保留后，才单独删除它。

## 验证连接结果

- 需要持续连接的平台卡片显示“已连接”。
- 手动同步返回已完成或已排队，而不是授权错误。
- 导入活动显示预期的平台来源。
- 重新打开连接弹窗后，同步设置仍然保留。

## 故障排查

### 授权后仍显示未连接

确认已经同意全部必要权限，并且浏览器返回的是同一个 Trainingload.ai 账号。不要重复打开旧授权链接，应从平台卡片重新发起。API Key 已过期或被撤销时，在弹窗中替换新 Key。

### 连接成功但没有活动

检查平台支持的日期范围和活动类型，只执行一次首次或手动同步，然后等待任务处理。如果记录不在支持范围内，可从来源平台导出 FIT、TCX 或 GPX 文件后手动上传。

### 同一训练出现多次

先查看每条活动显示的来源，只保留一条主要同步路径。例如 COROS 直连与 COROS 经 Strava 转发不应同时承担同一批活动。删除前先阅读重复活动提示。

### 缺少心率、功率、GPS 或力量明细

先在来源平台打开原始训练。平台没有向外提供的数据流无法被导入；如果来源中确实存在，等待处理完成，再使用平台提供的补偿同步操作。

### 页面没有文档中提到的按钮

以当前账号连接弹窗实际显示为准。部分操作取决于平台授权、订阅等级或功能开放进度。

## 常见问题

### Trainingload.ai 支持哪些训练平台对接？

Strava、Polar、COROS、Intervals.icu、Suunto、Wahoo 可以保持连接。Garmin 是一次性历史导入。FIT、TCX、GPX 用于单文件或不支持的手表。

### 选 Strava 对接还是 Garmin 导入？

要让新训练持续进来，选 Strava 或其他在线平台。只要一份历史存档，选 Garmin 历史导入。之后的新 Garmin 文件仍需在线路径或手动上传。

### 同一块表能开两个对接吗？

能，但不要把同一条记录导两次。回填前先定一条主路径，例如只走 COROS 直连，不要再叠加 Strava 转发。

### 在哪里完成连接？

网页打开**账号 → 第三方平台连接**，移动端打开**我的 → 账号 → 连接**。各平台步骤见[连接 Strava、Garmin 与 COROS](/zh/docs/guide/connect-third-party-platforms)。
