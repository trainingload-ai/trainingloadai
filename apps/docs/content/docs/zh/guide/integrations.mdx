# 训练平台对接怎么选：Strava、Garmin、COROS 对照

先选择你保存训练记录的平台，再决定是持续同步新训练，还是一次性补充历史活动。本页介绍云服务的连接方式；具体步骤见[连接平台指南](/zh/docs/guide/connect-third-party-platforms)。

自托管用户请查看[Intervals.icu 设置](/zh/docs/self-host/configuration#连接-intervalsicu)和[Garmin Personal API](/zh/docs/self-host/garmin-personal-api)，或直接上传活动文件。

平台能力和支持的方向可能调整，连接弹窗里实际显示的操作始终是最终依据。

## 连接前准备

- 登录真正保存训练数据的平台账号。
- 为每条活动确定一个主要来源，避免同一训练同时经过两个已连接平台转发。
- 先判断自己需要持续同步、一次性历史导入，还是单个文件上传。
- 准备好平台凭证或 API Key，但只在正式连接弹窗中输入。
- 记住 Trainingload.ai 当前最新的一条活动，方便识别首次成功导入的结果。

## 选择正确的方式

| 来源            | 适用场景                      | 连接方式               |
| --------------- | ----------------------------- | ---------------------- |
| Strava          | 持续同步活动                  | 账号连接和同步设置     |
| Polar           | 持续导入 Polar 活动           | OAuth 与同步设置       |
| COROS           | 活动、日常数据和兼容计划导出  | 账号连接与手动同步     |
| Intervals.icu   | 活动同步和兼容计划课程流程    | OAuth 或 API Key       |
| Suunto          | 持续导入训练和兼容 Guide 流程 | OAuth 与同步设置       |
| Wahoo           | 持续导入 Wahoo 训练           | OAuth 与同步设置       |
| Garmin          | 新训练同步或补充历史活动      | OAuth 授权或文件导入   |
| FIT / TCX / GPX | 单个文件或其他平台导出        | 手动上传               |

## 连接平台

1. 选择平台卡片。
2. 阅读数据方向和同步设置。
3. 通过 OAuth 授权，或输入所需 API Key。
4. 保存同步偏好。
5. 如果弹窗提供首次同步，执行一次。
6. 打开活动列表，确认最新活动已导入。

不要把 API Key 粘贴到智能教练、计划备注或支持截图中。密钥只能输入正式连接弹窗，已保存密钥不会重新回传给客户端。

## 首次同步与自动同步

首次同步通常导入一段近期记录或启动历史任务；自动同步负责未来的新活动；部分平台还提供手动补偿同步，用于处理遗漏通知。

大量导入时，请等待当前批次完成，不要重复启动。活动可能随着各条目处理进度陆续出现。如果缺少心率、功率或 GPS，先检查来源平台和原始文件。

## Intervals.icu 的计划课会怎么同步？

这里说的是日历里安排的训练课，不是已经完成的运动记录。你可以在 Intervals.icu 的连接设置里，分别开启**导入计划课**和**导出计划课**。

- **导入计划课**：把 Intervals.icu 的新增、修改和删除同步到 Trainingload.ai。
- **导出计划课**：把 Trainingload.ai 的新增、修改和删除同步到 Intervals.icu。

**请特别留意：两个方向都开启后，删除也会同步。** 如果另一边的课从上次同步后没有改过，你删掉这一边，另一边也会删除。

### 我新增、修改或删除一节课，另一边会怎样？

下表假设两个方向都已开启：

| 你做了什么 | 另一边会怎样？ |
| --- | --- |
| 在 Trainingload.ai 新增一节课 | Intervals.icu 会出现对应的新课。 |
| 在 Intervals.icu 新增一节课 | Trainingload.ai 会出现对应的新课。 |
| 只在 Trainingload.ai 改了日期、名字或训练内容 | 对应的 Intervals.icu 课程会跟着更新。 |
| 只在 Intervals.icu 改了日期、名字或训练内容 | 对应的 Trainingload.ai 课程会跟着更新。 |
| 在 Trainingload.ai 删除一节课 | 如果 Intervals.icu 那节课没有改过，也会删除；如果改过，就保留修改后的课。 |
| 在 Intervals.icu 删除一节课 | 如果 Trainingload.ai 那节课没有改过，也会删除；如果改过，就保留修改后的课。 |

### 两边都改了，会用哪一版？

这取决于这次正在往哪边同步：

- 从 Intervals.icu 导入时，采用 Intervals.icu 的版本。
- 向 Intervals.icu 导出时，采用 Trainingload.ai 的版本。

每日自动同步会先导入、再导出。因此，如果在自动同步开始前，两边都已经改过同一节课，会优先采用 Intervals.icu 的版本。

为避免自己的修改被覆盖，建议先在一边改完，等同步后，再去另一边继续编辑。

### 为什么我删了一边，另一边还留着？

因为另一边的课在上次同步后被改过。系统会保留这些修改，不再让这两节课互相更新，也不会为了恢复原来的同步而马上把你删掉的课重新建回来。

例如，你在 Intervals.icu 删除了周日的跑步课，但此前已经在 Trainingload.ai 把它改成周六跑步。Trainingload.ai 会保留周六这节课，Intervals.icu 中被删的那节课不会因此重新出现。

如果无法确认另一边是否改过，也会先保留那节课，避免误删。已完成或已跳过的课程，以及已经关联实际运动记录的课程，也会保留需要的历史记录。

### 我删掉一节课，又重新建了一节同名的呢？

重新创建的就是一节新课，会重新同步。即使名字、日期和训练内容完全相同，也不会因此接回已经删除的旧课。平台重复发送同一条通知，则不会多建一节课。

### 为什么另一边还没更新？

同步不是两个页面同时即时变化。系统会接收平台通知，也会定时检查近期课表；每日自动检查的范围是你所在时区的昨天到未来七天。

如果你只是把课程移到了这个日期范围之外，系统会先确认它去了哪里，不会因为暂时没在范围内找到，就把它当作删除。连接暂时不可用时，也不会据此删除另一边的课程。

## Garmin 历史导入

Garmin 页面中的 **OAuth 授权**用于接收新活动和已授权的健康摘要；**文件导入**用于补充更早的训练记录。两项操作彼此独立，请按需要选择。

## 断开连接

断开连接会停止未来同步并移除当前凭证，一般不会删除已经导入的活动。只有确认某条活动确实不需要保留后，才单独删除它。

## 验证连接结果

- 需要持续连接的平台卡片显示“已连接”。
- 手动同步返回已完成或已排队，而不是授权错误。
- 导入活动显示预期的平台来源。
- 重新打开连接弹窗后，同步设置仍然保留。

## 故障排查

### 授权后仍显示未连接

确认已经同意全部必要权限，并且浏览器返回的是同一个 Trainingload.ai 账号。不要重复打开旧授权链接，应从平台卡片重新发起。API Key 已过期或被撤销时，在弹窗中替换新 Key。

### 连接成功但没有活动

检查平台支持的日期范围和活动类型，只执行一次首次或手动同步，然后等待任务处理。如果记录不在支持范围内，可从来源平台导出 FIT、TCX 或 GPX 文件后手动上传。

### 同一训练出现多次

先查看每条活动显示的来源，只保留一条主要同步路径。例如 COROS 直连与 COROS 经 Strava 转发不应同时承担同一批活动。删除前先阅读重复活动提示。

### 缺少心率、功率、GPS 或力量明细

先在来源平台打开原始训练。平台没有向外提供的数据流无法被导入；如果来源中确实存在，等待处理完成，再使用平台提供的补偿同步操作。

### 页面没有文档中提到的按钮

以当前账号连接弹窗实际显示为准。部分操作取决于平台授权、订阅等级或功能开放进度。

## 常见问题

### Trainingload.ai 支持哪些训练平台对接？

Strava、Polar、COROS、Intervals.icu、Suunto、Wahoo 可以保持连接。Garmin 支持新数据授权连接和历史文件导入。FIT、TCX、GPX 用于单文件或不支持的手表。

### 选 Strava 对接还是 Garmin 导入？

想接收新 Garmin 训练时，使用 Garmin OAuth 连接；需要补充旧记录时，使用历史文件导入。如果同一训练也会经过 Strava，请选择一条主要导入路径，避免重复。

### 同一块表能开两个对接吗？

能，但不要把同一条记录导两次。回填前先定一条主路径，例如只走 COROS 直连，不要再叠加 Strava 转发。

### 在哪里完成连接？

网页端点击右上角头像，再向下滚动到**第三方连接**区域；移动端打开**我的 → 菜单 → 数据授权**。各平台步骤见[连接 Strava、Garmin 与 COROS](/zh/docs/guide/connect-third-party-platforms)。
