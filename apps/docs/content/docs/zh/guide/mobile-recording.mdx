# 移动端运动记录

本教程的完成结果，是一条由手机保存并出现在 Trainingload.ai 活动历史中的运动记录。

## 开始前检查

- 使用与网页端相同的账号登录。
- 户外 GPS 运动需要位置权限。
- 如果锁屏后仍要记录，请允许后台位置权限。
- 如果系统会主动暂停后台应用，请取消针对 Trainingload.ai 的严格省电限制。
- 确保手机电量和存储空间足够。

## 1. 检查权限

从移动端账号区域打开**权限**，先处理位置或健康数据权限。连接运动平台不等于授权手机 GPS，这两类权限相互独立。

## 2. 打开记录器

打开**记录**，选择运动类型。户外运动应等待定位状态可用后再开始。

## 3. 开始并观察记录

1. 只点击一次开始。
2. 确认计时持续增加。
3. 户外运动应确认距离或轨迹开始更新。
4. 只有在记录明确运行后再锁屏。

如果应用从后台恢复，请先等待现有会话恢复，不要在恢复期间新建第二条记录。

## 4. 结束并保存

停止记录后，检查时长、距离和运动类型，然后保存。保持网络连接，直到上传或导入交接完成。活动可能先出现在列表中，图表和派生指标稍后才完成。

## 验证结果

打开**我的 → 活动**或对应日期，确认：

- 这次训练只有一条活动。
- 开始时间、运动类型、时长和距离合理。
- GPS 运动有地图。
- 只有原始记录包含相应数据时，才会出现心率、功率等图表。
- 活动可以关联到目标计划课程。

## 常见问题

### 时间增加但距离始终为零

检查位置权限、GPS 信号和所选运动是否应记录户外距离。移动到开阔区域并等待定位。

### 锁屏后记录停止

开启后台位置权限，并取消系统对应用的电池优化限制。

### 活动出现两次

同步仍在进行时，不要再次上传本地文件。先比较开始时间和时长，只删除确认的重复项。

### 活动存在但图表缺失

等待分析完成后刷新。也可能是原始记录没有相应传感器数据。

下一步打开[活动详情](/zh/docs/guide/activity-detail)；如果这是计划训练，再通过[执行当前计划](/zh/docs/guide/manage-active-plan)完成关联。
