# 上传活动文件

从手表、码表或运动平台导出的运动文件，可以直接上传到 Trainingload.ai，查看运动记录、图表和训练负荷。下面介绍网页端的上传步骤。

## 准备运动文件 [#上传前检查]

准备 FIT、TCX 或 GPX 格式的运动文件，一次最多可上传 100 个。建议使用设备或平台导出的原始文件，以保留心率、功率、路线等数据。

## 从活动页上传

1. 点击左侧导航中的**活动**，进入活动页面。
2. 在页面最右侧的**上传活动文件**卡片中，点击**上传活动文件**按钮。

4. 点击弹窗右下角的**上传**按钮。

上传后会打开导入进度弹窗，列出每个文件的处理结果。

## 查看导入进度 [#导入状态]

导入时可以继续浏览其他页面。如果关闭了弹窗，可以在活动页点击**导入进度**重新查看。

| 看到的状态 | 接下来怎么做 |
| --- | --- |
| 排队中、标准化中、建档中、分析生成中 | 文件还在处理，等待导入完成。 |
| 已完成 | 回到活动列表查看运动记录。 |
| 已跳过 | 通常是已有相同记录，可以先在活动列表中查找。 |
| 失败、终止 | 查看文件旁的错误提示，再按下方的方法处理。 |

## 查看导入的运动记录 [#上传完成后]

导入完成后，点击左侧导航中的**活动**，按运动日期找到刚上传的记录，再点击进入活动详情，查看时长、距离、图表和训练负荷。

具体页面介绍见[活动列表与搜索](/zh/docs/guide/activity-feed-search)和[活动详情](/zh/docs/guide/activity-detail)。

## 常见问题

### 上传按钮不能点击

先选择文件。文件检查尚未完成时，稍等片刻；如果文件旁有错误提示，按提示处理或移除该文件后再试。

### 提示运动记录重复

如果这次运动已经在活动列表中，可以保留已有记录或取消本次上传。只有确实需要保留另一份副本时，才选择强制导入。

### 文件上传或导入失败

先查看文件旁的错误提示。可以从原设备或平台重新导出 FIT、TCX 或 GPX 文件，再单独上传这个文件重试。不要只修改文件后缀名来转换格式。

截图、普通 CSV 表格，以及只包含全天健康监测数据的 FIT 文件，不适合通过这个入口导入运动记录。

### 导入后没有心率、功率或路线

先等待活动处理完成。如果原始记录不含相应数据，就不会出现对应图表；例如没有 GPS 数据的室内运动不会显示路线。可以检查原平台上的记录，并优先重新导出原始运动文件。

## 需要转换文件格式？ [#格式转换]

上传支持 FIT、TCX 和 GPX，一般不需要先转换。如果还要把文件用于其他平台，可以使用 [FIT、GPX、TCX 转换器](/zh/converter)。
