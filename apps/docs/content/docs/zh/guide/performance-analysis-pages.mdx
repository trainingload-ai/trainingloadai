# 性能分析页面

“分析”中心是工具目录，不是单一评分页。已经明确训练问题、但不确定该看哪个页面时，从这里开始。

## 开始前

- 等待相关活动进入已就绪状态。
- 解读区间分布前，检查个人阈值和分运动类型区间。
- 只选择一个运动类型和一个决策时间窗。
- 确认活动包含页面所需的传感器数据：功率、心率，或可用的距离与时间。
- 跨页面比较时保持相同单位制和时区。

## 1. 从“分析”选择页面

打开**分析**，搜索或选择工具：

| 要回答的问题                         | 页面     | 主要内容                                           |
| ------------------------------------ | -------- | -------------------------------------------------- |
| 我训练了多少、频率如何？             | 活动统计 | 年度热力图，以及距离、时长、心率、次数或卡路里趋势 |
| 最近负荷怎样变化？                   | PMC      | CTL、ATL 和 TSB 负荷上下文                         |
| 最佳持续表现是什么？                 | 最佳距离 | 按固定距离或固定时间排列的成绩                     |
| 功率能力怎样变化？                   | 功率     | 曲线、最大功率、区间分布和功率画像                 |
| 某项运动的配速怎样变化？             | 配速     | 配速曲线和配速区间分布                             |
| 数据里有哪些心率持续表现和区间时间？ | 心率     | 心率曲线和区间分布                                 |

**进步趋势（Progression）**目前标记为**即将推出**。不要把这张卡当作已经可用的报告，也不要等待它来回答现有页面已经能够回答的问题。

## 2. 阅读图表前先设置筛选

在功率、配速和心率页面，先选择运动类型和日期范围，然后在对比标签页时保持不变。

- 回答当前状态问题时使用一个时间范围。
- 只有页面允许、且比较目的明确时才添加多个范围。
- 配速必须选择具体运动类型，不提供“全部运动”。
- 功率和心率可选择全部运动，但混合运动结果通常更难解释。
- 图表为空通常意味着所选范围内没有符合条件的传感器数据。

任何结论都应附带筛选上下文。“功率提高了”并不完整；“骑行 5 分钟功率在当前 90 天相较前 90 天提高”才可追溯。

## 3. 使用功率标签页

功率页面有四种视图：

- **曲线**：不同持续时间的最佳功率表格和图表，可比较多个时间范围。
- **最大值**：所选上下文中的最大功率历史。
- **区间**：各功率区间内的训练分布，可比较多个时间范围。
- **画像**：所选运动和时间范围的功率画像上下文。

用曲线查看特定持续时间的能力，用区间查看训练如何分布，用画像补充上下文。它们回答不同问题，不应合并成一个笼统的“体能”判断。

## 4. 使用配速和心率

配速页面包含：

- **曲线**：不同距离的配速表现表格和图表。
- **区间**：配置的配速区间内的时间或训练分布。

按筛选器提供的选项选择跑步、骑行或游泳。游泳使用游泳专用的距离基准，跑步和骑行也有各自显示上下文，不要直接跨运动比较原始配速数字。

心率页面包含：

- **曲线**：持续心率表现的表格和图表。
- **区间**：配置的心率区间分布。

心率是响应信号。应结合时长、配速或功率、环境、疲劳与传感器质量解释，而不是把更高心率自动视为更好。

## 5. 用 PMC 补充负荷上下文

当问题涉及累积训练压力而不是单项表现时使用 PMC。把 [CTL](/zh/docs/metrics/pmc/chronic-training-load)、[ATL](/zh/docs/metrics/pmc/acute-training-load)和 [TSB](/zh/docs/metrics/pmc/training-stress-balance)放在一起看，并确保运动类型、日期范围与待分析活动一致。

负荷描述施加了多少训练压力，不能单独证明适应或准备度。当图表需要转化成计划决策时，继续使用[训练分析工作流](/zh/docs/guide/training-analysis-workflow)。

## 6. 把结果追溯到证据

当某个曲线点、区间分布或负荷变化很重要时：

1. 记录运动类型、日期范围、标签页、持续时间和值。
2. 打开相关活动，或用活动搜索找到可能产生结果的训练。
3. 检查处理状态、传感器覆盖、阈值及明显尖峰或掉数。
4. 区分观测结果和你的解释。
5. 只做证据支持的最小决策。

## 验证分析

- 所选页面与问题匹配。
- 已记录运动类型、时间范围、单位和区间设置。
- 结果由符合条件的已就绪活动支持。
- 传感器缺失或异常值被明确指出，而不是静默平均掉。
- 任何训练决策都能追溯到真实活动和计划上下文。

## 故障排查

- **分析搜索没有结果**：清空搜索词；工具搜索匹配本地化标题和描述。
- **卡片无法打开**：检查它是否标记为“即将推出”。
- **曲线或区间图为空**：扩大日期范围、选择正确运动，并确认符合条件的活动包含所需传感器流。
- **修改阈值后数值变化**：区间分布和派生上下文可能改变；比较历史前先记录新设置。
- **功率、配速和心率结论不同**：它们衡量不同输入与响应。重新检查问题、来源活动和条件，不要只挑最有利的图表。
- **全部运动结果不一致**：切换到单一运动类型后重新比较。
