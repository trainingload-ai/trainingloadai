# 通知与复盘自动化

在通知中查看导入结果和已完成的复盘。开启复盘自动化后，符合条件的日、周或月复盘可以自动生成，无需每次手动发起。

## 开始前

- 设置正确时区，保证日、周、月边界准确。
- 持续导入活动，并保持当前计划有效。
- 需要复盘计划执行时，把活动关联到对应课程。
- 检查账号权益和智能教练用量是否可用。

## 通知类型

通知包括系统消息、安排已更新的持续训练计划，以及已生成的训练复盘。大型导入也可能在后台完成后发送通知，因此不必一直停留在导入弹窗。

你可以打开关联复盘或页面、把单条通知标为已读，或全部标为已读。标记已读不会删除对应活动、计划或教练会话。

## 阅读训练复盘

日报列出前一天的活动，周报按运动项目汇总上一个完整自然周，月报按周汇总上一个完整自然月。教练解读会提炼训练亮点、值得留意的地方和下一阶段的重点。打开引用的活动可以核对原始记录。

周报还显示训练天数、每次训练的平均时长，以及有记录时的训练负荷。一日多练会计入多次活动，训练天数仍只计一天。

有记录时，报告会显示睡眠时长、HRV 和静息心率。日报使用训练次日的恢复记录，数据充足时与个人近期基线对照。周报和月报标明有记录的天数，数据可比时提供上一周期的对照。

网页端的周报和月报用条形图对照本期和上期。训练次数、时长以及可比的恢复指标还会列出原值和环比；上期为零时只显示原值。

## 配置复盘自动化

从网页端打开**账号 → 智能教练复盘自动化**，或在移动端打开对应账号面板。

可用选项包括活动复盘、每日复盘、每周复盘、每月复盘和计划复盘。功能可用性取决于账号权益和智能教练用量。打开开关只是授权该类复盘，并不代表缺少计划或活动数据时也能生成有价值的结果。

## 让复盘使用完整的训练记录

1. 确认时区，日/周边界依赖它。
2. 持续导入真实活动。
3. 保持当前计划准确。
4. 把真实活动关联到计划课程。
5. 需要时补充整节训练 RPE 或当前状态。

## 手动触发复盘

如果界面提供手动触发，可以请求上一完整日、周或月的复盘。任务会在后台运行，请等结果生成后再提交。

## 验证结果

- 重新打开设置后，开关仍然保持保存状态。
- 完成复盘后出现通知或教练会话。
- 打开通知后进入正确复盘。
- 复盘引用了正确时间范围、计划或活动。

## 故障排查

如果复盘没有出现，检查账号权益、智能教练用量、时区、数据可用性，以及后台任务是否仍在执行。结构化操作失败时，打开[故障排查](/zh/docs/guide/troubleshooting)。

重复发起复盘不会补齐缺失的活动，还可能消耗 AI 用量。先确认相关活动已导入并处理完成；已有复盘正在生成时，请等待结果。
