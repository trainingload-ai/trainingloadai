# 通知与复盘自动化

通知用于报告后台任务完成和复盘可用状态；复盘自动化决定哪些符合条件的智能教练复盘可以自动运行。

## 开始前

- 设置正确时区，保证日、周、月边界准确。
- 持续导入活动，并保持当前计划有效。
- 需要复盘计划执行时，把活动关联到对应课程。
- 检查账号权益和智能教练用量是否可用。

## 通知类型

通知包括系统消息和训练复盘摘要。大型导入也可能在后台完成后发送通知，因此不必一直停留在导入弹窗。

你可以打开关联复盘或页面、把单条通知标为已读，或全部标为已读。标记已读不会删除对应活动、计划或教练会话。

## 配置复盘自动化

从网页端打开**账号 → 智能教练复盘自动化**，或在移动端打开对应账号面板。

可用选项包括活动复盘、每日复盘、每周复盘、每月复盘和计划复盘。功能可用性取决于账号权益和智能教练用量。打开开关只是授权该类复盘，并不代表缺少计划或活动数据时也能生成有价值的结果。

## 准备有效上下文

1. 确认时区，日/周边界依赖它。
2. 持续导入真实活动。
3. 保持当前计划准确。
4. 把真实活动关联到计划课程。
5. 需要时补充整节训练 RPE 或当前状态。

## 手动触发复盘

如果界面提供手动触发，可以单独请求日、周或月复盘。任务会在后台异步执行，不要连续重复提交。

## 验证结果

- 重新打开设置后，开关仍然保持保存状态。
- 完成复盘后出现通知或教练会话。
- 打开通知后进入正确复盘。
- 复盘引用了正确时间范围、计划或活动。

## 故障排查

如果复盘没有出现，检查账号权益、智能教练用量、时区、数据可用性，以及后台任务是否仍在执行。结构化操作失败时，打开[故障排查](/zh/docs/guide/troubleshooting)。

重复触发同一复盘不会补齐缺失上下文，还可能消耗用量。先修复底层数据，或等待现有任务完成。
