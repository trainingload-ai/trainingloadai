# 网页端与移动端

网页端和移动端是同一个 Trainingload.ai 账号的两个界面。计划、活动、个人资料、阈值、智能教练会话、通知和用量保存在服务端，同步后可在两端继续使用。

## 切换设备前

- 确认两个设备登录的是同一个 Trainingload.ai 账号。
- 在个人资料中检查时区和单位；日历日期与显示数值依赖这些设置。
- 在另一台设备打开同一计划或资料字段前，先保存当前修改。
- 计划、智能教练、导入和分析结果依赖网络，请先确认设备可以联网。

## 更适合使用网页端的任务

- 创建或检查多周训练计划。
- 编辑结构化耐力或力量课程。
- 对比地图、功率、配速、心率和 PMC 图表。
- 管理平台连接和历史导入。
- 搜索较早的活动记录。

## 更适合使用移动端的任务

- 在训练当天查看今日、日历、教练、计划和我的。
- 使用手机记录户外运动。
- 保存后立即查看活动。
- 把真实活动关联到计划课程。
- 更新当前状态、查看通知和跟进计划。

## 哪些数据会同步

| 数据             | 网页端         | 移动端                 | 说明                           |
| ---------------- | -------------- | ---------------------- | ------------------------------ |
| 资料、单位、时区 | 查看与编辑     | 查看与编辑             | 日历日期依赖时区。             |
| 活动与分析       | 完整详情       | 日常和详情视图         | 活动先出现，图表可能稍后完成。 |
| 计划与课程       | 完整创建和编辑 | 查看、创建、执行和关联 | 复杂编辑更适合网页端。         |
| 智能教练       | 会话和操作     | 会话和操作             | 已应用修改作用于同一计划。     |
| 通知与复盘       | 支持           | 支持                   | 自动复盘依赖账号设置。         |
| 平台连接         | 完整管理       | 部分连接和权限流程     | 能力取决于平台和设备。         |

## 刷新与冲突

如果两个设备同时编辑同一计划或资料字段，最后一次成功保存的数据会成为当前版本。继续编辑前，先返回列表或详情页并刷新。遇到版本冲突时，应重新读取计划并检查最新状态，而不是反复提交旧版本。

## 在另一台设备继续操作

1. 在第一台设备完成当前操作并保存。
2. 在第二台设备打开对应列表或详情页。
3. 移动端下拉刷新，网页端重新加载或刷新数据。
4. 检查刚刚修改的活动时间、计划版本或资料值。
5. 确认服务端最新数据已经出现后，再继续编辑。

## 离线预期

移动端会尽量在本地保护正在进行的记录，但计划、智能教练回复和分析结果仍依赖网络。恢复网络后，让上传完成，不要为同一训练再次创建重复上传，并在活动列表确认只有一条记录。

## 验证同步结果

- 两端显示相同的个人资料单位和时区。
- 完成的活动只出现一次，开始时间与来源一致。
- 当前计划和最近课程显示相同状态与最新修改。
- 一端应用的智能教练操作已经反映到另一端的同一计划。
- 通知或复盘完成后，刷新另一端不会重新变成未读。

## 故障排查

### 一台设备显示旧数据

返回列表或详情页刷新，检查网络，并确认两个设备使用同一账号。在最新服务端数据出现前，不要继续编辑旧副本。

### 修改计划时提示版本冲突

说明另一项请求先修改了计划。重新加载计划，对比当前课程与预期修改，再基于新版本操作。

### 手机记录没有出现在网页端

保持移动端可用，直到上传完成，再刷新网页端活动列表。如果活动已经出现但图表不完整，说明仍在处理，不要重复上传。

### 两端的平台连接设置不同

完整管理入口位于网页端的**账号 → 第三方平台连接**。移动端可能只提供部分授权或权限流程。

### 两端日历日期不同

比较账号时区与活动记录的开始时间。先修正资料设置，再移动或重新创建课程。
