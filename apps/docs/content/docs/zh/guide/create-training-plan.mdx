# 创建训练计划

Trainingload.ai 支持三种创建计划的方式：

- **官方模板**：免费预览经过审核的计划，匹配自己的日历，再创建草稿；预览时不调用模型。
- **手动计划**：你按周、按天自己搭建训练结构。
- **智能教练辅助计划**：你提供目标和限制条件，让智能教练生成草稿，再由你确认。

三种方式最终都会生成同一种核心对象：包含周期、周、天、课次、运动类型、训练内容和备注的结构化训练计划。

## 创建前先检查

建议先确认这些内容：

- 个人资料和阈值是最新的。
- 近期活动已经完成处理。
- 训练目标足够具体，能指导排期。
- 每周可训练天数和单次训练时长比较现实。

阈值和近期训练记录会帮助 Trainingload.ai 估算计划负荷，也会给智能教练更好的上下文。如果这些输入缺失，计划仍然可以创建，但负荷估算和建议可能没那么精确。

## 选择创建方式

1. 打开**计划**并选择创建入口。
2. 已审核模板已经符合目标和当前水平时选择官方模板。
3. 已经知道完整课表时选择手动计划。
4. 已知目标和限制、但仍需要每周结构草稿时选择智能教练辅助计划。
5. 先把结果保存为草稿，并在激活前检查完整课表。

## 官方模板

当模板的适用条件和每周频次已经符合目标时，优先使用官方模板。跑步计划库包括 3 份 5K 计划，以及 [10 公里](/zh/10k-training-plan)、[半程马拉松](/zh/half-marathon-training-plan)和[马拉松](/zh/marathon-training-plan)各自的完赛、进阶、挑战计划，共 12 份已审核模板。

完整模板预览免费。先选择开始日期和训练日，再创建草稿；创建草稿需要 PLUS 或 PRO。预览和创建都不会调用模型，也不会扣除 AI 积分。

智能教练会通过三个明确阶段影响整个流程：

1. Plan Prompt 离线生成结构化候选，再经过 Schema 校验、训练规则检查和人工审核，最后冻结为官方版本。
2. 预览时，确定性规则读取近期跑步、训练日、已保存的能力指标和可选比赛成绩，映射日期；只有证据充分时才解析配速区间。完赛和进阶计划在缺少可靠配速时回退到 RPE 与谈话测试；挑战计划还必须有已保存的目标赛事和可靠当前能力。
3. 创建后，智能教练可以比较计划与实际完成、解释负荷和恢复，并提出可审阅的调整建议；它不会静默改写冻结模板。

## 手动计划

当你已经知道自己要怎么安排训练时，使用手动创建。

手动流程通常分三步：

- 填写计划名称、周期和描述。
- 在周历里添加训练课次。
- 检查计划预览并保存。

每个课次可以包含：

- 运动类型。
- 第几周、第几天、第几练。
- 训练内容。
- 课次名称。
- 备注。

手动计划适合已经有教练安排、或你想把其他来源的计划搬进 Trainingload.ai 进行执行追踪的场景。

## 智能教练辅助计划

当你希望 Trainingload.ai 帮你起草训练结构时，使用智能教练创建。

计划条件可以包括：

- 主要运动项目。
- 训练意图，例如比赛备战、体能提升、专项能力强化、恢复训练或健康减脂。
- 计划周期。
- 每周训练天数。
- 单日可训练时长。
- 如果是比赛备战，还可以补充比赛项目和距离。

提交条件后，智能教练会收到计划请求，并生成训练计划草稿。保存为正式计划前，需要先检查草稿。

## 检查草稿

保存或激活前，重点看这些问题：

- 每周节奏是否符合你的真实日程？
- 强度日之间是否留出了足够恢复？
- 轻松日和恢复日是否真的足够轻？
- 计划是否从当前能力出发，而不是直接按目标能力排？
- 运动类型和训练描述是否正确？
- 接下来几周的总量是否可承受？

如果发现不合适，先修改计划，再激活。

## 保存和激活

保存后的计划不一定已经开始执行。草稿状态适合继续检查、编辑或对比。

当你准备按这份计划训练时，再激活它。激活会为计划设置开始日期，并让 Trainingload.ai 把这些课次作为当前训练安排。

激活后，计划可以进入这些流程：

- 日历和当前计划视图。
- 与真实完成活动关联。
- 预期负荷 vs 实际负荷。
- 智能教练跟进复盘。

## 预期负荷

当训练结构和你的阈值信息足够时，Trainingload.ai 可以估算计划课次的预期负荷。

一般来说：

- 草稿计划不一定有最终的预期负荷快照。
- 已激活或暂停中的计划，可以在执行复盘中使用预期负荷。
- 预期负荷是估算值，不代表训练当天一定会有同样体感。

相关概念见：[训练负荷](/zh/docs/metrics/training-load)。

## 验证计划

打开计划详情页，确认：

- 计划状态。
- 开始日期。
- 每周结构。
- 课次数量。
- 完成率和负荷汇总。

然后可以进入 [管理当前计划](/zh/docs/guide/manage-active-plan)，按天执行和复盘。

## 故障排查

- **没有预期负荷**：确认课程包含受支持的结构，并且运动员拥有所需阈值；不要为了产生估算而虚构阈值。
- **课程日期不正确**：检查周次、星期、当日课次、计划周期，以及激活时选择的开始日期。
- **智能教练草稿过于笼统**：补充近期基线、可训练时间、器材、比赛事实和限制，再要求修改草稿，不要原样保存。
- **进阶计划预览没有配速目标**：保存可靠的近期比赛成绩或受支持的跑步能力指标；没有合格锚点时，模板会有意使用 RPE 和谈话测试，而不是编造配速。
- **挑战计划无法生成预览**：确认已保存同距离跑步赛事和目标时间、比赛日已选为训练日、完整冻结周期来得及执行，并且当前能力能够支持目标。
- **计划无法保存**：从第一条验证错误开始修复，例如空课程、无效结构或课程超出计划周期。
- **激活后映射到意外日期**：取消确认，修正开始日期或时区，再次检查日期映射。
