# 活动详情

活动详情用于理解一次已完成的训练。这里集中展示活动记录、路线、图表、运动专项指标和可用的教练复盘。先确认来源和汇总，再调查某一段训练，最后结合原定目的解释结果。

[打开 10 公里目标赛示例](https://demo.trainingload.ai/zh/activities/17921623926005309429)。链接会进入只读 Demo 账号中的具体活动，可以查看标签和图表。保存修改需要使用自己的账号。

## 开始前准备

- 导入或记录一条活动，等待处理完成。
- 核对活动的运动类型和日期，在个人资料里检查单位与相关阈值。
- 选择包含目标数据的活动。心率分析需要心率采样，功率分析需要功率数据，路线需要 GPS。
- 需要比较计划与实际时，先确定对应的计划课程及活动关联。

只有汇总数值的活动仍可复盘，但可用图表会更少。实际显示的标签取决于运动类型和记录数据。

## 1. 打开活动并核对来源

打开**活动**，选择一条记录，检查标题、运动、开始时间、来源、距离和时长。也可以从搜索、地图、日历或关联的计划课程进入。

如果活动仍在处理，先等待，再判断图表是否缺失。活动记录可能先出现，部分分析稍后才完成。

| 处理状态 | 应怎样继续 |
| --- | --- |
| Analyzing | 等待分析完成后刷新。 |
| 已就绪 | 继续查看已有数据。 |
| Partial failed | 确认缺失的是哪项分析，先使用已完成的部分。 |
| Failed | 检查文件和失败信息后，再决定重试或重新导入。 |

## 2. 根据问题选择分析视图

桌面网页端的分析标签位于路线下方。先看**总览**，再选择能回答当前问题的标签。移动端使用该运动提供的详情和图表入口。下文的同步时间线流程适用于桌面网页端。

| 视图 | 适合查看什么 | 数据与范围 |
| --- | --- | --- |
| 总览 | 训练汇总、可用数据图表、天气和运动背景 | 字段随活动变化。 |
| 时间线 | 用同步图表和路线查看单点或一段训练 | 桌面网页端中有可用时序数据的跑步、骑行活动。 |
| 计圈 | 对比设备记录的圈段与汇总指标 | 需要活动提供计圈，并且该运动支持对应视图。 |
| 最佳表现 | 按距离或时长找到持续表现，并查看统计 | 取决于运动类型和可用数据流。 |
| 心率 | 心率响应、区间及受支持的衍生指标 | 对应分析需要心率数据。 |
| 功率 | 功率输出、区间与效率相关指标 | 需要对应功率数据，估算功率会有标记。 |
| 配速 | 配速变化与相关分析 | 在受支持的跑步活动中显示。 |
| 跑步动态 | 记录中的跑步技术相关测量 | 跑步活动需要包含对应传感器数据。 |

游泳和其他运动有各自的详情规则。缺少标签可能来自运动类型或数据不足，也可能需要等待处理完成。

## 3. 复盘某次用力或某段训练

调查爬坡、加速或间歇时，打开**时间线**。定位一个时刻可以对照当时读数，选择一个区间可以查看该段的平均、最小和最大值，以及它对应的路线。

完整的选区、图表配置和分析分段编辑步骤见[使用时间线分析一次训练](/zh/docs/guide/activity-timeline)。

用**计圈**比较设备原始圈段。需要查找最强的持续表现时，打开**最佳表现**，在页面提供的距离与时间模式之间切换。**编辑列**控制可用统计项的显示和顺序。选择某条表现的第一列或表现值，有定位数据时会定位对应路段。

## 4. 核对强度和训练负荷

结合运动类型与阈值阅读配速、心率和功率分析。比较不同活动前，先确认负荷来自哪类记录。

- 功率负荷使用功率和相关阈值。
- 跑步配速负荷依赖可用配速、地形与阈值背景。
- 心率负荷使用可用心率记录和个人设置。
- 上述信号不足时，可能采用其他负荷方法。

概念说明见[训练负荷](/zh/docs/metrics/training-load)。如果区间或强度明显不合理，检查[个人资料、阈值与区间](/zh/docs/guide/profile-thresholds-zones)。

受支持的心率分析可以展示有氧解耦，用来比较活动中输出与心率的关系。解读 Pw:Hr 或 Pa:Hr 前，先阅读[有氧解耦](/zh/docs/metrics/heart-rate/aerobic-decoupling)的适用条件。强度多变或有中断的训练，需要结合这些变化解释结果。

## 5. 加入路线和计划背景

用路线对照训练变化与地形。爬坡、停顿和环境条件都可能帮助解释配速或心率变化。没有 GPS 时，继续使用其他已记录证据。

如果这次训练属于计划课程，在日历或计划里核对活动关联。确认课程无误后，再比较计划内容、完成情况和负荷。关联错误时先修正，再请求计划复盘。具体操作见[管理进行中的计划](/zh/docs/guide/manage-active-plan)。

## 6. 阅读教练复盘或提出明确问题

**教练复盘**区域显示当前可用的 AI 复盘状态。页面要求了解数据共享时，先完成该选择，再让 AI 使用自己的数据。活动处理或复盘请求也可能仍在进行，失败时使用页面提供的重试操作。

继续向 AI 教练提问时，带上活动和明确问题，例如是否符合计划强度、后半程发生了什么、这次训练与近期安排是否一致。应用计划调整前，核对回答引用的活动、时间范围和证据。

复盘与确认流程见[智能教练](/zh/docs/guide/ai-coach)。

## 验证复盘结果

你应能确认是哪条活动、数据从哪里来，说明检查了哪段训练，以及哪些记录支持结论。有计划时核对关联课程，做下一步决定前写清缺失的传感器数据和仍有疑问的解释。

## 常见问题

### 为什么缺少一些图表或标签

检查处理状态、运动类型和传感器覆盖。只有汇总的文件和包含采样的文件，可用分析会不同。桌面网页端与原生移动端也提供不同的详情流程。

### 为什么不同视图里的数值不同

先确认单位、所选范围和计算含义。时间线左侧统计描述全程或选区，游标读数描述一个采样点。设备圈段汇总与重新计算的分析分段，也可能采用不同输入。

### 为什么没有路线

文件可能没有 GPS，隐私处理也可能移除定位数据，地图请求还可能加载失败。分别检查可用图表和地图错误状态。

### 可以修改 Demo 活动吗

公开 Demo 用于查看示例。活动修改、分析分段保存和计划变更，需要使用有相应权限的个人账号。
