# 管理当前计划

当前计划是 Trainingload.ai 认为你正在执行的训练安排。它把计划课次、真实活动、训练负荷和智能教练跟进连接在一起。

你可以从主导航的 **Plan** 进入当前计划，也可以从计划列表打开某一份计划。

## 开始前

- 使用正确开始日期激活目标计划。
- 确认个人时区和当前阈值。
- 关联前等待已完成活动处理结束。
- 检查本周安排，不要假设最初草稿仍然符合现实。

## 每日执行顺序

1. 打开当前计划，找到今天的计划课程。
2. 训练前阅读课程结构和备注。
3. 训练后打开已完成活动并确认身份。
4. 把它关联到计划课程，并如实更新课程状态。
5. 在上下文中比较预期和实际负荷，再决定是否调整未来课程。

## 计划状态

计划可能有这些状态：

- **Draft**：已保存，但还没开始执行。
- **Active**：正在执行。
- **Paused**：暂时暂停，但仍可调整排期。
- **Completed**：已经完成。
- **Cancelled**：提前终止。

通常只有一份计划会被当作当前执行计划。草稿和已完成计划仍然可以复盘，但它们不是当前执行界面。

## 课次状态

每个计划课次都有自己的状态：

- **Planned**：已排期，尚未开始。
- **In progress**：进行中或部分处理。
- **Done**：已完成。
- **Skipped**：确认跳过。
- **Moved**：已调整日期。

及时更新状态，可以让计划保持真实。跳过一次训练和低负荷完成一次训练不是同一件事，两者都应该被记录清楚。

## 关联真实活动

当一次真实活动对应某个计划课次时，把它们关联起来。

活动关联后，Trainingload.ai 才能进行这些对比：

- 计划训练 vs 实际完成。
- 预期负荷 vs 实际负荷。
- 课次完成率。
- 负荷执行匹配度。
- 智能教练计划跟进。

有些情况下系统会自动建议或建立关联，但如果关联错了，你也可以手动取消并选择正确活动。

## 预期负荷 vs 实际负荷

计划视图可以对比：

- **预期负荷**：计划课次的工作量估算。
- **实际负荷**：已关联主活动产生的负荷。

当预期负荷和实际负荷来自相近信号时，这个对比更有意义。比如功率计划负荷和功率活动负荷，比混合来源的估算更容易直接比较。

把它当成计划信号，而不是打分表。单次训练可以有意比计划轻或重，更重要的是几天到几周的趋势。

## 当前计划视图

当前计划视图适合日常执行。你可以用它：

- 查看今天安排的训练。
- 查看当前周结构。
- 打开课次详情。
- 关联已完成活动。
- 标记完成或跳过。
- 在日程变化时移动课次。
- 对比每周计划负荷和实际负荷。

当你想在更大的日期视图里看计划和活动时，可以使用 [日历视图](/zh/docs/guide/calendar)。

当计划处于 active 或 paused 状态时，未完成课次可以调整排期。已经完成或跳过的课次，通常应作为历史记录保留。

## 计划详情页

计划详情页更适合看完整周期。你可以用它：

- 查看计划信息和状态。
- 激活草稿计划。
- 检查每周结构。
- 查看训练图表或描述。
- 查看执行汇总。
- 让智能教练复盘剩余训练。

从计划详情页进入智能教练时，会携带计划上下文和未完成课次数量。

## 什么时候调整计划

当计划和现实明显偏离时，再考虑调整。

常见原因：

- 漏掉的训练越来越多。
- 实际负荷持续高于计划。
- 疲劳上升明显快于体能。
- 比赛、出差或恢复需求改变了下周安排。
- 关键训练完成了，但身体反应和预期差异很大。

不要因为每一次小波动都改计划。目标是让计划跟现实保持一致，同时不丢掉原本的训练意图。

## 让智能教练跟进

适合这样问：

- “帮我复盘当前计划进度和负荷。”
- “这周剩下的训练里，哪几次最重要？”
- “今天强度很高，明天训练要移动吗？”
- “最近两周实际负荷都高于计划，应该怎么改？”
- “帮我调整接下来 7 天，但不要偏离主要目标。”

## 验证当前状态

- 计划开始日期把课程映射到预期日历日期。
- 今天的课程状态和备注正确。
- 关联活动是真正完成该课程的实际训练。
- 预期与实际负荷保留各自的数据来源和含义。
- 移动未完成课程时，不会改写已完成或已跳过的历史。

## 故障排查

- **没有显示当前计划**：确认目标计划是 Active，而不是 Draft、Paused、Completed 或 Cancelled。
- **活动无法关联**：检查日期范围、运动类型兼容性、处理状态，以及它是否已关联其他课程。
- **自动关联了错误活动**：取消关联，核对开始时间和运动类型后手动选择正确活动。
- **计划修改发生冲突**：其他设备或智能教练操作已经更新版本；刷新并检查新计划后再重试。
- **没有实际负荷**：检查已完成活动及其负荷来源，不要修改计划估算来掩盖问题。
