# 使用今日建议与当前状态

网页端使用**首页**，移动端使用**今日**，整理当天的训练背景。先把建议和当前计划、已记录活动、负荷放在一起，再根据真实完成情况选择下一步。

[打开 Demo 首页](https://demo.trainingload.ai/zh)。Demo 用于浏览，保存课程、提醒或计划变更需要自己的账号。截图是实际网页应用中的合成示例，移动端使用自己的面板与记录控件。

## 开始前准备

检查账号时区、当前计划，以及近期活动是否已经处理完成。使用 AI 前，核对数据共享选择和当前部署提供的 AI 配置或权限。有计划时读取计划背景，没有已排课程的一天则从不同状态开始。

## 1. 操作前先读当天背景

在首页核对日期与当前计划，找到今日课程、近期活动和当前状态或周负荷区域。排在今天的课程表示训练安排，实际活动则提供已经发生的训练证据。

刚完成的活动尚未同步时，先处理同步状态，再解读可能缺少这次活动的建议。需要时按[连接训练数据](/zh/docs/guide/connect-data)继续。

## 2. 打开建议，查看判断依据

选择建议卡片，打开详情面板。阅读完整建议、不确定性说明，以及可用的**判断依据**。操作入口会随当天证据变化。

- 已有计划课程时，可能提供打开该课程的操作。
- 数据不足时，可能提供平台设置、导入或活动复盘入口。
- 待回答问题或待确认决定，会进入对应教练流程。
- 建议包含计划外课次或提醒时，才会显示相应操作。

打开详情本身不会创建课程或应用计划修改。新活动或计划信息到来后，建议可能更新，操作前应重新阅读当前版本。

## 3. 按当前情况选择操作

### 打开已有课程

使用页面提供的课程入口，核对日期、运动、结构、备注与状态。训练已完成时，还应检查活动关联。

移动端中，受支持计划课程可以进入耐力记录或力量执行。具体步骤见[移动端运动记录](/zh/docs/guide/mobile-recording)与[移动端计划和力量训练](/zh/docs/guide/mobile-plans-and-strength)。

### 检查提供的计划外课次

详情出现**建议课次**时，打开预览，检查运动、时长、强度与结构。选择页面提供的添加或安排操作后，会创建今天的独立课次，再核对跳转后的当天训练页。已有训练计划仍保留独立的排期背景。

建议过期、训练事实变化、当天已有课次或训练时间窗结束，都可能阻止创建。先读取最新结果，再决定是否重试。

### 设置提供的提醒

网页端选择提醒操作，填写**提醒时间**，再选择**设置提醒**。使用界面接受的时间范围，等待成功反馈。提醒用于稍后回来看，不代表完成训练。

移动端提供受支持的提醒间隔，实际通知还取决于应用通知设置与设备权限。以当天可选时间为准。

### 问教练或查看待确认决定

使用页面提供的教练入口，携带当前建议背景继续讨论。发送前核对问题与相关记录。待调整提议或待补充信息会进入自己的详情流程，应阅读受影响课程和确认操作的效果。

打开活动或计划属于导航；创建课程、保存提醒和确认调整会改变账号中的对应状态。每次操作后都应单独检查结果。

## 4. 记录真实完成情况

训练后同步或导入活动，等待处理完成，再关联到正确课程。比较原定内容与实际时长、距离、强度和可用负荷。

课程移动、缩短、跳过或在计划外完成时，保留真实背景。按[日历指南](/zh/docs/guide/calendar)与[管理当前计划](/zh/docs/guide/manage-active-plan)更新对应记录。

## 5. 使用移动端反馈与当前状态卡片

移动端建议详情可以提供休息、已在别处训练、等待同步或稍后查看等反馈，用于补充建议背景。实际活动仍需要通过正常流程记录并同步。

需要自定义移动端当前状态时，打开**当前状态**旁的设置入口，添加或移除受支持指标，排列已选卡片后完成编辑。点击卡片查看详情，通过文档入口了解指标。

负荷与能力历史见 [PMC](/zh/docs/guide/pmc-forecast)和[最大摄氧量](/zh/docs/guide/effective-vo2max-for-endurance)。当前卡片、历史点与未来估计分别描述不同证据。

## 6. 修改后刷新

移动端今日支持下拉刷新。在另一台设备导入活动或修改计划后，刷新并核对日期、状态和关联，再继续编辑。网页端重新回到页面时也可能更新，应以当前实际展示的内容为准。

## 验证结果

你应能说明当天计划课程、已记录活动、建议所依据的背景，以及所选操作的效果。保存课程、关联或提醒后，检查它们是否出现在预期位置。

## 常见问题

### 为什么今日建议缺失或暂时不可用

检查数据共享选择、AI 配置或权限、请求状态与训练证据。应分别识别错误、重试、加载与保底展示状态。

### 为什么建议变化了

新活动、计划调整、背景更新或过期，都可能触发刷新。应用旧提议前先核对当前版本。

### 为什么没有课程操作

入口取决于建议和当前证据。检查当前计划、排期日期与课程状态，再通过日历或计划找到目标课程。

### 为什么建议里没有提到已经完成的训练

检查同步、活动处理、本地日期和计划关联。移动端可以在补齐记录期间提供相应反馈。

### 建议会直接替我修改计划吗

应阅读具体操作并验证结果。建议、独立课次和计划调整提议具有不同效果，完整复核与确认见[智能教练](/zh/docs/guide/ai-coach)。
