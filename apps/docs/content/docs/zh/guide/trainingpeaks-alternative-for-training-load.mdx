# TrainingPeaks 训练负荷替代方案

如果你正在使用 TrainingPeaks，可以先比较自己最常做的任务：跟随教练安排、查看训练负荷，还是根据已完成训练调整接下来一周的课程。

TrainingPeaks 提供训练日历、教练协作、训练计划市场和 Virtual 室内训练。具体功能和套餐见 [TrainingPeaks 官网](https://www.trainingpeaks.com/)与[运动员定价页](https://www.trainingpeaks.com/pricing/for-athletes/)。

## 在 Trainingload.ai 中可以怎样管理训练

- 在日历中对照计划课程和实际活动，确认完成、跳过和未关联的课程。
- 查看 PMC 和表现趋势，结合近期训练与恢复情况复盘。
- 请智能教练解释活动或提出课程调整，检查修改内容后再应用。
- 从官方模板、手动编辑或智能教练草稿开始创建计划。

Trainingload.ai 不提供 TrainingPeaks 的教练市场或 Virtual。已有教练协作或设备工作流时，请先确认这些需求是否仍需要保留原平台。

## 用一周训练试用

1. [导入近期活动](/zh/docs/guide/connect-data)，核对来源、日期和阈值。
2. [创建计划草稿](/zh/docs/guide/create-training-plan)，安排近期课程。
3. 在[日历](/zh/docs/guide/calendar)中关联一条已完成活动，比较预期与实际负荷。
4. 从正确的活动或计划进入[智能教练](/zh/docs/guide/ai-coach)，先检查一次复盘，再决定是否应用调整。

试用期间保留原记录。不同平台的负荷算法、阈值与数据范围可能不同，不应期待历史曲线完全一致。

## 迁移前检查

- 活动文件可以上传，但不要把文件上传当作完整账号迁移。
- 训练计划、比赛和备注需要分别检查，不能假定会跟随活动自动迁移。
- 使用已有的 FTP、阈值心率和配速设置对照新结果，再逐步调整。
- 账号权益与 AI 用量见 [Trainingload.ai 定价](/zh/pricing)。

下一步可以阅读[训练分析流程](/zh/docs/guide/training-analysis-workflow)，或[打开 Demo](https://demo.trainingload.ai/zh)先浏览示例。
