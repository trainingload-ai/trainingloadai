# 导入你的第一条运动记录 [#从第一条活动开始使用]

把手表、码表或运动平台里的记录导入 Trainingload.ai，就可以查看活动详情、图表和训练负荷。下面以网页端为例，介绍平台同步和文件上传两种方式。

## 开始前 [#开始前准备]

先[打开 Trainingload.ai](https://app.trainingload.ai/zh)，登录自己的账号；自托管用户请打开自己的实例地址。想先看看界面，也可以[浏览 Demo](https://demo.trainingload.ai/zh)；Demo 里的数据只能查看，不能上传或修改。

## 1. 选择导入方式 [#2-为第一条活动选择接入路径]

| 你的运动记录在哪里 | 接下来怎么做 |
| --- | --- |
| 已经同步到 Strava、Garmin 等运动平台 | [连接运动平台](#连接运动平台) |
| 已经导出了 FIT、TCX 或 GPX 文件 | [上传运动文件](#上传运动文件) |
| 想直接用手机记录下一次运动 | 查看[移动端运动记录](/zh/docs/guide/mobile-recording) |

使用自托管版时，平台连接方式请看[自托管配置](/zh/docs/self-host/configuration)。你也可以直接使用下面的文件上传方式。

## 2. 导入运动记录 [#3-导入并等待处理]

### 方法一：连接运动平台 [#连接运动平台]

1. 在网页端左侧点击**设置**，找到**第三方连接**。
2. 选择保存着你运动记录的平台，按弹窗提示完成连接。
3. 如果平台提供首次导入或手动同步选项，按需要执行。
4. 打开左侧的**活动**，查看同步过来的记录。

不同平台能导入的历史范围不同。具体连接步骤和历史导入方式见[连接 Strava、Garmin 与其他运动平台](/zh/docs/guide/connect-third-party-platforms)。

### 方法二：上传运动文件 [#上传运动文件]

先从手表、码表或运动平台导出 FIT、TCX 或 GPX 文件，然后：

1. 打开左侧的**活动**。
2. 点击**上传活动文件**，打开导入窗口。

<DocsScreenshot
  id="activity-upload-location"
  title="在活动页找到上传按钮"
  description="打开“活动”，点击页面上的“上传活动文件”。"
  route="活动 → 上传活动文件"

3. 点击文件选择区域，选择要导入的文件；也可以把文件拖进窗口。
4. 等待文件检查完成，点击**上传**。
5. 在进度弹窗里等待导入完成，然后从活动列表打开新记录。

如果提示记录重复，可以保留已有记录，避免把同一次运动导入两遍。文件格式、重复提示和导入失败的处理方法见[上传活动文件](/zh/docs/guide/upload-activity-files)。

## 3. 查看导入的运动记录 [#4-验证第一条活动]

在**活动**列表中按日期找到这次运动，点击进入详情。这里可以查看时长、距离、训练负荷，以及原记录包含的图表和路线。具体操作见[活动详情](/zh/docs/guide/activity-detail)。

活动刚出现时可能还在处理，等分析完成后再查看完整结果。心率、功率和路线需要原记录包含相应数据；没有 GPS 的记录不会显示运动路线。

## 常见问题

### 连接平台后，没有看到运动记录

先检查平台是否已连接，再查看活动列表的日期筛选。历史记录不一定会自动导入，需要按平台提供的选项导入；也可以先从平台导出运动文件，再上传到 Trainingload.ai。

### 有运动记录，但没有心率或路线

先等待活动处理完成。如果原文件没有心率、功率或 GPS 数据，就不会出现对应的图表。如果原平台上能看到这些数据，可以重新导出原始运动文件再上传。

### 运动日期和实际日期不一致

检查账号时区，以及文件记录的开始时间。时区与单位的设置方法见[个人资料、阈值与区间](/zh/docs/guide/profile-thresholds-zones)。

### 为什么不能在 Demo 中上传

Demo 用来查看示例数据。导入自己的运动记录时，请[打开正式应用](https://app.trainingload.ai/zh)并登录自己的账号。
