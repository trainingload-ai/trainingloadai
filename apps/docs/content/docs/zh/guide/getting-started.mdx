# 从第一条活动开始使用

先把一条已完成训练带入 Trainingload.ai，确认记录正确。这条活动随后可以用于复盘、训练负荷分析，以及与计划课程对照。

[浏览只读 Demo](https://demo.trainingload.ai/zh)。截图使用真实应用中的示例训练数据，说明有数据后的首页怎样组织。初次进入自己的账号时，一些区域可能仍为空。

## 开始前准备

准备一个原始 FIT、TCX 或 GPX 活动文件，或者一个保存着已知训练的受支持平台账号。选择你能识别日期、运动类型和大致时长的活动。

云服务用户先登录，并按页面提示完成账号验证。自托管用户先按[安装指南](/zh/docs/self-host/installation)完成安装并创建本地账号。两种版本支持的平台连接方式不同，接入前请查看对应指南。

## 1. 检查资料与显示设置

网页端打开**设置 / 账号**，移动端打开**我的 / 账号**。比较日历日期或配速前，先核对账号时区和单位偏好。

填写可靠的个人信息和已知阈值，确认每项阈值对应正确运动。完整编辑步骤见[个人资料、阈值与区间](/zh/docs/guide/profile-thresholds-zones)。

需要估算阈值时，可以使用对应工具，检查结果后再保存。阈值尚不确定时，解读强度与负荷也应保留这个条件。

## 2. 为第一条活动选择接入路径

| 你已有的内容 | 下一步 |
| --- | --- |
| 原始活动文件 | 打开活动页，使用上传入口。 |
| 受支持在线平台中的训练 | 打开该平台的连接设置，完成授权与同步流程。 |
| 正在使用移动端记录 | 完成并同步记录，再到活动列表中查找。 |

使用[连接训练数据](/zh/docs/guide/connect-data)选择路径。同一次训练可能经过多个服务转发，启动历史导入前先确定想保留的主要来源。

## 3. 导入并等待处理

使用文件时，打开**活动**，选择上传入口，加入原始文件并查看格式检查结果。继续导入后，在批次进度弹窗核对每一项结果。检测到重复时，先对照已有活动，再决定是否需要单独副本。

使用平台连接时，按设置中提供的首次同步或导入操作继续。账号已连接和导入已完成是不同状态，任务执行后仍需在活动列表找到目标记录。

文件选择、重复处理与批次状态见[上传活动文件](/zh/docs/guide/upload-activity-files)。

## 4. 验证第一条活动

1. 在**活动**中按日期和运动找到记录。
2. 对照原始训练，核对来源、开始时间、距离和时长。
3. 等待**已就绪 / Ready**，或查看部分分析失败、失败等提示。
4. 打开活动详情，检查可用路线、计圈与传感器图表。
5. 在日历中确认它出现在预期的本地日期。

只有汇总值的文件，可用图表可能少于包含采样记录的文件。GPS 或心率缺失时，应能从源数据、处理状态或明确错误中找到解释。

按[活动详情指南](/zh/docs/guide/activity-detail)复核结果，需要调查某段训练时继续使用[时间线](/zh/docs/guide/activity-timeline)。

## 5. 选择下一项任务

- 想理解已记录负荷，打开 [PMC 历史与预测](/zh/docs/guide/pmc-forecast)。历史较短或不完整时，未来走势可能受限。
- 想安排后续训练，先[创建计划](/zh/docs/guide/create-training-plan)，核对日期与课程，再决定是否激活。模板、手动编辑与 AI 辅助草案是不同创建路径。
- 想进入日常流程，打开[今日与当前状态](/zh/docs/guide/today-and-current-state)。
- 想询问某次训练，带着明确活动或计划问题使用[智能教练](/zh/docs/guide/ai-coach)。先核对数据共享选择，并在应用修改前检查提议。

## 验证结果

账号时区与单位合适，一条可识别活动已经有明确处理结果，详情和日历日期与原记录一致，即完成首次接入任务。解读时继续标明缺失的传感器记录和不确定阈值。

## 常见问题

### 为什么首页内容比截图少

示例包含计划和活动。新账号会随着对应记录的加入逐步填充这些区域，应使用第一条活动的处理结果验证导入成功。

### 为什么图表或预测为空

检查所需传感器数据、处理状态和历史范围。有一条活动，并不代表所有分析和预测都有足够证据。

### 为什么活动显示在另一日

对照活动开始时间、时区与账号显示时区。移动或关联计划课程前，先确认日期背景。

### 为什么 Demo 不能上传或修改

Demo 用于浏览示例。导入文件、连接自己的平台与保存修改，需要使用个人账号或 Self-host 实例。
