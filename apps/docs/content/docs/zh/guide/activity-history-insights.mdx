# 活动历史与最佳表现

使用历史工具把“发生了什么”追溯到具体来源活动。活动统计汇总训练量，最佳距离排列持续表现，地图补充路线上下文。

这些页面描述已记录数据。它们不会认证比赛成绩、预测完赛时间，也不能在没有进一步复盘时解释表现为何变化。

## 开始前

- 等待导入活动进入已就绪状态。
- 确认运动分类、时区和单位制。
- 比较总量或成绩前，修正重复活动和明显传感器错误。
- 选择与问题匹配的时间范围。
- 记住地图需要可用 GPS 坐标；室内和无 GPS 活动仍可能正常出现在其他页面。

## 1. 查看年度活动量

打开**分析 → 活动统计**。该页面使用“活动”中的当前运动筛选，因此应先设置筛选，再解释报告。

在侧栏选择年份。可选年份会追溯到所选运动类型最早的活动。热力图显示所选年份中可用的 365 天窗口，并统计有活动的日期。

在热力图下方选择一个指标：

- 距离。
- 时长。
- 心率。
- 活动次数。
- 卡路里。

再按日、周或月聚合折线图。日数据适合调查短周期，周数据适合检查一致性，月数据适合比较大范围训练量。心率会对参与计算的值取平均；距离和时长等可累加指标则求和。

## 2. 查找最佳表现

打开**分析 → 最佳距离**，按以下顺序操作：

1. 选择**跑步**、**骑行**或**游泳**。
2. 选择**按距离**或**按时间**。
3. 设置日期范围。
4. 选择距离或时长目标。
5. 查看排名记录；页面会为每个目标请求最多十条结果。
6. 从记录行打开来源活动。

**按距离**回答“完成这个距离的最快时间是多少”；**按时间**回答“在这段时长内走了多远”。显示的配速用于在同一运动和上下文内比较表现。

不要把每一行都称为个人纪录。它只是所选数据和范围内找到的最佳有效分段，可能来自日常训练、受 GPS 质量影响，也可能在活动重新处理或修正后变化。

## 3. 在地图检查路线历史

打开**地图**，然后设置时间和运动筛选。页面会绘制匹配且包含可用 GPS 数据的活动路线。

地图可用于：

- 按地点或路线形状查找活动。
- 比较重复训练发生的位置。
- 在打开活动前发现不完整或明显异常的路线。
- 为选中的活动创建路线分享海报。

选择路线会打开对应活动海报。需要查看指标、处理状态或传感器证据时，再从海报进入完整活动详情。

地图属于敏感位置数据。分享前检查海报和路线，避免暴露住所、工作地点或其他隐私起点。

## 4. 调查异常结果

如果年度总量、最佳表现或路线看起来不对：

1. 打开来源活动。
2. 确认开始时间、运动类型、来源平台、处理状态和单位制。
3. 检查 GPS、距离、时长、暂停以及相关传感器流。
4. 检查重复活动或错误运动分类。
5. 修正来源活动或设置后，刷新汇总页面。

应把来源活动视为证据。汇总页面可以暴露问题，但通常不能独立解释或修复问题。

## 验证结果

- 活动统计使用预期运动、年份、指标和聚合方式。
- 最佳表现记录打开预期来源活动，且日期一致。
- 地图中选中的路线属于预期活动。
- 无 GPS 活动不会仅因地图中缺失而被误判为导入失败。
- 任何分享海报都已检查隐私位置数据。

## 故障排查

- **活动统计显示了错误运动**：返回“活动”修改运动筛选，再重新打开或刷新活动统计。
- **只能选择当前年份**：所选运动没有更早的有效活动，或最早活动查询尚未完成。
- **热力图和折线图看起来不同**：热力图统计活动日期；折线图使用所选指标和聚合方式。
- **缺少某项最佳表现**：扩大日期范围，确认运动与目标，并检查活动是否有可用距离和时间数据。
- **成绩明显不可能**：使用前检查 GPS 尖峰、暂停、距离、时长和重复活动。
- **活动不在地图中**：它可能不在筛选范围内，或没有可用 GPS 路线。
- **选择路线后海报看起来不对**：先核对活动日期，并在分享前打开完整详情。
