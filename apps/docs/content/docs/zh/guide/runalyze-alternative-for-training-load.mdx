# Runalyze 训练负荷替代方案

如果你常在 Runalyze 查看跑步表现，可以先用同一组近期活动，比较两种工具如何帮助你复盘和安排后续训练。

Runalyze 提供 effective VO2max、比赛预测、训练负荷和活动统计。具体方法与功能见它的[官方功能说明](https://runalyze.com/help/article/features?_locale=en)。

## 在 Trainingload.ai 中可以怎样复盘

- [查看活动详情](/zh/docs/guide/activity-detail)，先确认原始训练记录。
- [查看 effective VO2max 历史](/zh/docs/guide/effective-vo2max-for-endurance)，了解近期估算怎样变化。
- [查看 PMC](/zh/docs/guide/pmc-forecast)，结合近期训练安排解释负荷走势。
- 把活动关联到计划，再请[智能教练](/zh/docs/guide/ai-coach)复盘完成情况或提出调整建议。

## 用自己的记录比较

1. 从来源平台导出受支持的 FIT、GPX 或 TCX 文件，或使用[平台连接](/zh/docs/guide/connect-data)。
2. 导入一段近期训练，确认日期、来源和阈值设置。
3. 选择自己熟悉的一次训练，比较原始时长、距离、心率和配速。
4. 再查看负荷和能力估算；不要把单次数值差异直接当成体能变化。

## 哪些内容需要重新设置

不同平台可能使用不同的有效样本、修正方法和阈值。effective VO2max 与负荷曲线不保证完全一致。活动上传也不会自动迁移 Runalyze 的标签、装备、自定义设置或所有历史统计。

先保留原记录，完成一次计划与活动对照后，再决定是否迁移或同时使用。需要先体验界面时，[打开 Demo](https://demo.trainingload.ai/zh)。
