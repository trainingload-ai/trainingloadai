# 查看 PMC 历史与预测走势

PMC 把已记录的训练负荷与有条件的未来走势放在一起。它帮助你调查训练压力怎样变化，以及现有未来输入会带来怎样的负荷走势。预测依赖这些输入，不代表训练已经发生，也不能单独确认某项训练安排是否合适。

[在 Demo 中打开体能管理](https://demo.trainingload.ai/zh/pmc)。公开 Demo 为只读模式，进入后选择要查看的运动。带有预测曲线的截图使用应用中的合成示例数据。Demo 的数值和预测可用性以当前记录为准。

## 开始前准备

- 导入已完成活动，等待训练负荷处理完成。
- 核对运动分类、阈值、负荷来源设置和账号时区。
- 使用计划预测时，确认未来课程已排期，并有可用的预计负荷。草稿或未排期课程不会自动成为某天的未来负荷。
- 解读时区分已经发生的训练、计划训练与习惯估计。

## 1. 打开体能管理并选择运动

从分析工具进入 **PMC / 体能管理**。使用右上角的**运动范围**，选择全部运动、跑步、骑行或游泳。上方三张当前值卡片与图表都使用该范围。

调查专项训练阶段时，先选择单一运动。在概览、PMC 与相关活动之间切换时，再核对一次范围。

主 PMC 页面通常显示过去 60 天与未来 28 天的走势。上方一次展示一个选定指标，下方显示每日负荷。

## 2. 先读当前值，再看未来走势

把三张卡片放在一起解读。

| 数值 | 描述什么 | 不能单独证明什么 |
| --- | --- | --- |
| 体能 / CTL | 较长期累积训练负荷 | 实际表现已经提高。 |
| 疲劳 / ATL | 对近期训练负荷更敏感的信号 | 你真实疲劳程度的诊断。 |
| 状态 / TSB | 较长期与近期负荷的关系 | 某次训练或比赛必然准备充分。 |

卡片描述当前已记录状态。查看未来日期时，它们不会变成预测值。计算含义见 [CTL](/zh/docs/metrics/pmc/chronic-training-load)、[ATL](/zh/docs/metrics/pmc/acute-training-load)与 [TSB](/zh/docs/metrics/pmc/training-stress-balance)。

## 3. 切换指标，检查某一天

1. 在图表上方选择**状态、体能或疲劳**。
2. 将鼠标移动到目标日期。浮层展示日期、已记录或预测标记、CTL、ATL、TSB 与每日负荷。
3. 查看未来日期时，同时阅读数值和显示的负荷依据。
4. 对照同一天的每日负荷面板。指标曲线的变化和某天负荷是不同量。

也可以聚焦图表，用左右方向键逐日查看，按 **Escape** 隐藏浮层。触屏设备可以点击图表中的日期。

## 4. 区分已记录历史与条件预测

先用图例和**今天**的分界定位。已记录值使用实线，可用的未来估计使用虚线。每日负荷中，已记录负荷使用填充柱，未来负荷的显示更浅。

普通预测优先使用有可用负荷的已排训练。没有对应排期输入时，可以使用足够近期且可用的训练模式。查看某一天的浮层，确认实际使用的依据。

| 显示的依据 | 应怎样理解 |
| --- | --- |
| 已排训练 | 未来负荷来自适用的已排期课程。 |
| 近期训练习惯 | 使用近期训练模式的估计，不会因此在日历里新增课程。 |
| 暂停训练 | 当前情景假定这些天没有额外训练。 |
| 暂无预测 | 当前输入不能支持这一天的数值。 |

打开图表不会排课，也不会保存计划修改。没有已排课程的一天，不自动等于已经确认的休息日。缺失负荷不能当作零负荷。

如果未来中途出现缺失输入，后续数值也可能留空，因为计算依赖此前的状态。导入新活动或修改排期后，未来走势可能改变。

## 5. 理解空白的未来区域

未来曲线不可用时，历史仍然可能有参考价值。常见原因包括历史太短或过旧、已记录负荷缺失，以及已排课程没有可用的预计负荷。

先检查日期与运动范围，再核对近期活动和排期。浮层显示**暂无预测**时，应保留这个不确定性。页面显示**更新失败，保留上次结果**时，当前可见图表来自上次结果，并非刷新成功。首次请求失败会提供**重试**。

## 6. 携带当前背景问教练

选择页面右上角的**问教练**。链接会把所选运动和走势背景带入 AI 教练。发送前先检查准备好的问题，打开链接本身不会应用训练变更。

补充你正在调查的真实问题，例如近期负荷为何变化，或某节已排课程的时机是否合适。核对回答使用的活动和未来假设。任何计划或课程修改都继续走正常确认流程。

马拉松专项复盘见[用 PMC 做马拉松训练调整](/zh/docs/guide/pmc-marathon-adjustment)。

## 在概览中查看更近的时间窗

概览中的体能、疲劳和状态卡片可以打开对应指标详情。详情提供 **7、14、30、60 天**历史标签，图中可见的未来长度跟随标签变化，最多显示 30 天。这与主 PMC 页面的较大范围不同。

先选时间窗，再解读曲线，同时区分当前值与选定未来日期。

## 验证操作结果

你应能说明检查的运动、日期、指标、已记录或预测状态，以及对应的负荷依据。有效解释应把曲线追溯到活动或已排输入，并指出证据缺失的位置。

## 常见问题

### 为什么查看未来时，上方卡片没有改变

卡片表示当前已记录值，选定未来日期的数值应看浮层。

### 为什么完成训练后预测变了

真实负荷和计划关联会更新输入。比较结果前，先确认活动处理完成，并关联到正确课程。

### 为什么概览卡片里的图表范围不同

详情的历史标签同时控制较短的未来显示长度，主 PMC 页面使用自己的较大范围。应比较同一运动和日期，而不是屏幕上相似的位置。

### 可以在图表里选择预测情景吗

主页面提供运动和指标选择。普通访问会自动选择适用的计划与习惯输入，部分教练或分享链接可能携带其他情景。应读取日期浮层中的实际依据，避免假定每个视图使用相同输入。

### TSB 彩色区间能证明我已经准备好吗

这些区间帮助阅读负荷背景，不包含影响真实状态与表现的所有因素。
