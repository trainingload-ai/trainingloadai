# 日历视图

日历会把计划训练和已完成活动放在同一个日期视图里。它适合用来观察训练计划和真实完成情况在每天、每周是否对得上。

适合回答这些问题：

- 今天安排了什么？
- 我实际完成了什么？
- 这一天或这一周产生了多少负荷？
- 漏掉或移动的训练有没有改变计划节奏？
- 哪一天需要打开看更多细节？

## 开始前

- 正确设置账号时区。
- 等待新导入的活动完成处理。
- 如果希望看到计划课程，先激活训练计划。
- 对比计划相对日期和真实日历前，确认计划开始日期。

## 每日查看顺序

1. 先回到今天，再导航到需要查看的周或月份。
2. 选择日期，并区分计划训练与已完成活动。
3. 打开计划课程，理解原本的训练目的。
4. 打开已完成活动，确认实际发生了什么。
5. 如果两者属于同一次训练，从支持的计划或活动入口完成关联。

## 月视图和周视图

大屏上通常展示月视图。移动端可以使用更聚焦的周视图，保证每天的信息仍然清楚。

你可以用导航控件：

- 切换到上个月或下个月。
- 在移动端周视图里切换上一周或下一周。
- 回到今天。
- 选择其他月份。

选中的日期会决定侧边或底部详情面板展示什么。

## 每一天会展示什么

日历中的某一天可能包含：

- 当前计划里的计划课次。
- 已完成活动。
- 当日训练负荷。
- 计划周期范围提示。
- 按运动类型区分的视觉标识。

日历标记用于快速扫视。如果需要精确指标，打开单日面板或活动详情页。

## 单日详情面板

单日详情面板展示某一天的具体内容。

可能包含：

- 当前选中日期。
- 当日负荷。
- 活动数量。
- 计划课次数量。
- 计划课次卡片或训练图。
- 已完成活动列表。
- 进入完整单日页的链接。

打开计划课次，可以查看训练描述和结构图。打开已完成活动，可以进入活动详情页。

## 训练和活动标签

单日面板会把计划训练和已完成活动分开。

使用 **Training** 查看：

- 计划课次。
- 训练结构。
- 运动类型。
- 课次详情。

使用 **Activity** 查看：

- 当天完成的训练。
- 距离和时长。
- 运动类型。
- 活动详情链接。

这样可以避免把“原本计划什么”和“实际发生什么”混在一起。

## 汇总范围

日历可以按计划进度或按自然月汇总训练。

如果存在当前计划，计划范围可以帮助你查看当前周期内的进度。没有当前计划时，月份范围也能提供基础概览。

汇总指标可能包括：

- 活动数量。
- 训练负荷。
- 距离。
- 时长。
- 与前一周期的对比。

这些汇总适合用来发现趋势，不适合孤立评价某一天。

## 日历和当前计划的区别

想看多天之间的日期关系时，用日历。

想执行或调整训练计划时，用当前计划页：

- 标记完成或跳过。
- 移动未完成课次。
- 在计划流程里对比预期和实际负荷。
- 让智能教练跟进计划。

日历更偏“定位和观察”；当前计划页更偏“执行和调整”。

## 验证结果

- 选中日期、详情面板和当前周/月范围一致。
- 计划课程只出现在已激活计划的周期内。
- 已完成活动使用正确的本地日历日期。
- 打开每个条目后进入预期的课程或活动。
- 每日和周期汇总采用界面当前显示的统计范围。

## 故障排查

如果训练出现在意外日期：

- 检查个人资料里的时区。
- 检查活动开始时间和活动时区。
- 确认计划开始日期。
- 确认活动已经完成处理。
- 检查搜索或日历数据是否需要刷新。

如果计划课次缺失：

- 确认存在已激活计划。
- 确认选中日期落在当前计划周期内。
- 打开计划详情页检查课次排期。
