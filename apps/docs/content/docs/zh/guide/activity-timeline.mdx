# 使用时间线分析一次训练

时间线把一条活动的记录数据放在共享横轴上。你可以检查某个时刻，也可以选择一段训练，对照配速、功率、心率、步频和路线。范围统计和单点读数分别回答不同问题。

本指南适用于跑步、骑行的**桌面网页端**。可用图表取决于活动实际记录的数据。完整复盘顺序见[活动详情](/zh/docs/guide/activity-detail)。

## 打开示例

[打开 10 公里目标赛示例活动](https://demo.trainingload.ai/zh/activities/17921623926005309429)，在路线下方选择**时间线**。活动默认先进入总览。Demo 为只读模式，分段编辑与保存不可用。

使用自己的活动时，先等待处理完成，确认文件包含采样记录。只有汇总值的活动无法提供同步时间线。室内训练即使没有 GPS，也可以使用可用图表。解读前检查运动类型、阈值和单位。

## 1. 先看全程

选择**时间线**后，找到顶部的分段、左侧指标入口与范围统计，以及右侧对齐的曲线。横轴默认使用时间。有定位数据时，路线仍位于标签栏上方。

较长的活动会超出当前图表宽度，可以横向滚动查看后面的时间。选择区间前，范围统计仍描述全程。截图中已通过图表配置移除没有数据的海拔图。

首次进入时，左侧的**平均、最小、最大**描述整次活动。某项指标没有可用采样时可能不出现，记录中的采样缺口会表现为曲线断开。

## 2. 检查某个时刻

在曲线上移动鼠标，读取各图在同一位置显示的浮动数值。有 GPS 时，地图会显示对应位置。

点击曲线可以保留定位。鼠标移出图表后，临时悬停读数会隐藏。左侧范围统计仍然对应全程或所选区间。

也可以聚焦时间线定位控件，用左右方向键查看采样点，使用 **Home** 和 **End** 到达边界。定位控件失去焦点后，键盘读数会隐藏。

| 当前问题 | 应查看的位置 |
| --- | --- |
| 这个时刻记录了什么 | 各图内的单点读数。 |
| 这一段的整体情况怎样 | 左侧范围统计中的平均值。 |
| 这段有效记录的极值是多少 | 同一范围内的最小、最大值。 |

## 3. 选择一段训练并对照

可以选择设备圈段，也可以自己拖选范围。

1. 点击顶部分段，查看该段高亮和更新后的统计。再次点击同一分段可取消选择。
2. 想检查其他范围时，在曲线上横向拖动后松开，所有图表会同步放大到选区。
3. 结合曲线比较这段的平均、最小和最大值。继续移动鼠标，可检查区间内的单点记录。
4. 有定位数据时，核对地图高亮的路段。结合地图上下文，判断这段的位置。

复盘稳态训练时，可以检查配速或功率相近时心率怎样变化。复盘重复间歇时，结合训练目的对照工作段和恢复段。解释时记录时长、地形、停顿与可用传感器数据。

## 4. 恢复全程或切换横轴

打开**分段**旁的**时间线选项**，选择**恢复全程**，清除选区并恢复完整图表范围。双击图表，或在时间线中按 **Escape**，也可以重置选择和缩放。

同一菜单的**横轴**可以在**时间**和**距离**之间切换。距离模式需要可用的累计距离记录。切换后，所选片段仍保留原来的时间边界。

## 5. 配置图表

点击**配速**、**心率**等指标名打开配置，选择可用指标、线条颜色、图表高度和平滑方式。通过**上移、下移、删除图表**调整当前布局。

底部的**添加图表**可以加入其他可用数据流。同一指标可以重复添加，例如对照原始曲线与平滑显示。使用**放大**入口查看单条图表的大图。

平滑只改变曲线绘制，单点读数与范围统计仍保留记录数据的含义。布局保存在当前浏览器的偏好中，不会改写源活动。

## 6. 在自己的账号里编辑分析分段

需要使用与设备计圈不同的分析范围时，选择**编辑分段**。操作需要登录并拥有该活动的编辑权限。

1. 打开**编辑分段**，核对每段的名称、起点和终点。
2. 可以改名或调整边界。编辑器还会在适用位置提供**在空余区间新增分段、从中间拆分、合并下一段、删除分段**。
3. 时间须落在活动范围内，每段起点早于终点，分段之间不能重叠。
4. 选择**保存分段**，回到时间线核对更新后的统计。**取消**会关闭草稿并放弃本次保存。

保存的分析分段保留原始文件、设备圈段和全活动训练负荷。改过边界的分段会根据对应时间范围内的记录重新计算统计。**恢复设备圈段**会把编辑器中的定义恢复到原始圈段范围，再按需要保存。

如果其他窗口已经修改分段，先关闭并重新打开编辑器，载入最新版本后再编辑。保存失败时草稿会保留，可按提示重试。公开 Demo 禁用这套编辑流程。

## 验证操作结果

选择片段后，确认起止范围、范围统计和地图路段都指向同一段训练。恢复全程后，统计应回到整次活动。在自己的账号保存分析分段后，重新打开活动，核对定义仍然可用。

## 常见问题

### 为什么鼠标移动时，左边的数字没有变化

左侧汇总全程或当前选区。鼠标所在时刻的数值显示在图内浮动读数中。

### 为什么曲线断开或显示横线占位

缺少数据流、采样中断或无效数值都可能产生缺口。速度、步频和功率中的有效零值可以保留，停止时刻没有可用配速，缺失心率也不会补成零。

### 为什么修改边界后，计圈数值变了

边界未变的设备圈段可以使用导入汇总。自定义或修改边界后的分析分段，会用所选范围里的有效记录重新计算，覆盖缺口和边界都会影响结果。

### 为什么功率显示估算标记

该数据流使用估算功率。与功率计记录比较，或据此判断强度时，应保留来源背景。

### 为什么地图没有高亮所选范围

对应时段可能缺少有效 GPS，地图也可能暂时不可用。继续查看已加载的记录图表，并单独检查地图状态。

### 为什么手机上找不到时间线

本指南的同步时间线适用于桌面网页端。移动端可以使用对应运动的活动详情和数据图表，也可以在电脑上继续分析同一活动。

### 图表加载失败怎么办

页面提供重试操作时，可以重试对应图表，其他已加载图表仍可继续查看。刷新失败时，页面可能保留上次结果并提示状态。缺少数据和请求失败需要分别检查。
