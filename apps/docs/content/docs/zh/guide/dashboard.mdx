# 训练概览

概览是快速了解近期训练状态的入口。它把训练状态、活动汇总和可配置的指标视图放在一起。

适合用来回答：

- 最近训练了多少？
- 负荷是在上升、稳定，还是下降？
- 哪个运动类型贡献了主要变化？
- 是否需要进一步查看活动、PMC、功率、配速或心率？

## 开始前

- 导入足够的近期活动，让当前时间范围具有解释意义。
- 比较强度相关指标前，设置好阈值和负荷来源优先级。
- 跑步、骑行和游泳采用不同阈值时，优先逐个运动类型查看。

## 趋势查看顺序

1. 选择需要的时间范围和运动类型。
2. 把训练状态当作趋势，不要把它当成诊断结果或单独的训练许可。
3. 找到发生变化的卡片或图表。
4. 打开促成变化的真实活动。
5. 修改计划前，继续查看相关 PMC、功率、配速或心率页面。

## 筛选器

概览支持全局筛选：

- **时间范围**：切换近期不同周期。
- **运动类型**：查看跑步、骑行、游泳或全部活动。

切换筛选后，卡片和图表会按当前上下文更新。

## 训练状态

训练状态卡片用于快速查看当前趋势。它适合帮助你发现需要继续检查的变化，不适合单独作为最终结论。

常见信号包括：

- 长期负荷和体能趋势。
- 近期疲劳。
- 状态/新鲜度参考。
- 训练一致性。

底层模型可以参考：

- [长期训练负荷 CTL](/zh/docs/metrics/pmc/chronic-training-load)
- [短期训练负荷 ATL](/zh/docs/metrics/pmc/acute-training-load)
- [训练压力平衡 TSB](/zh/docs/metrics/pmc/training-stress-balance)

## 概览卡片

概览卡片汇总活动量和表现相关指标。根据你的数据，它可以展示距离、时长、爬升、心率、功率、踏频等字段。

看到变化后，可以进入对应页面深入查看：

- **活动**：查看这些数字来自哪些训练。
- **PMC**：查看训练负荷趋势。
- **功率**：查看 FTP、CP、NP、VI 和功率曲线。
- **配速**：查看跑步配速、GAP、NGP 和最佳距离。
- **心率**：查看心率反应、区间、EF 和有氧脱钩。

## 编辑布局

桌面端概览支持编辑关键区块布局。你可以让它更贴近当前训练重点。

例如：

- 基础期把负荷和一致性放前面。
- 备赛期把功率或配速指标放前面。
- 高负荷周后，让恢复和疲劳信号更显眼。

编辑后记得保存布局，下次打开会保持同样结构。

## 如何解读概览变化

不要因为某个卡片一天的变化就立刻调整训练。更稳的流程是：

1. 先确认时间范围和运动类型筛选是否正确。
2. 打开近期活动，看看变化来自哪些训练。
3. 把负荷变化和主观疲劳放在一起看。
4. 如果需要计划上下文，可以让智能教练帮你解释。

概览只是起点。训练决定还要结合计划、近期训练和身体感受。

## 验证结果

- 当前筛选条件与最初想回答的问题一致。
- 可见活动和汇总值采用相同日期及运动范围。
- 趋势变化可以追溯到具体已完成活动。
- 依赖阈值的指标使用当前有效的个人资料值。
- 保存桌面布局后，重新打开概览仍保持相同结构。

## 故障排查

- **卡片没有数据**：扩大时间范围、清除运动筛选，并确认活动已经就绪。
- **汇总与活动列表不一致**：对照时区、日期范围、运动类型和处理状态。
- **负荷或状态意外变化**：先检查阈值历史和负荷来源优先级，不要直接认为训练本身发生了变化。
- **布局没有保存**：确认已经保存编辑，并在刷新前检查账号登录状态。
- **单张卡片数值极端**：打开底层活动检查传感器质量，再决定是否处理异常值。
