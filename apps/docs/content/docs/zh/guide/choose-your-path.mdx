# 选择你的使用路线

你不需要先配置完所有指标，才能开始使用 Trainingload.ai。先选择当前最想完成的结果，跑通一条路线，再回来完善高级设置。

## 我想分析最近的训练

适合已经在其他平台有训练记录，或手里有 FIT、TCX、GPX 文件的用户。

1. 完成[开始使用](/zh/docs/guide/getting-started)。
2. [连接训练平台](/zh/docs/guide/integrations)，或[上传活动文件](/zh/docs/guide/upload-activity-files)。
3. 打开[活动详情](/zh/docs/guide/activity-detail)，核对时间、距离、运动类型和传感器数据。
4. 用[概览](/zh/docs/guide/dashboard)和[训练分析流程](/zh/docs/guide/training-analysis-workflow)理解趋势。

**完成标准：**至少一条活动处理完成，而且图表与原始数据基本一致。

## 我想执行训练计划

1. 检查[个人资料、阈值与区间](/zh/docs/guide/profile-thresholds-zones)。
2. 手动或通过智能教练[创建训练计划](/zh/docs/guide/create-training-plan)。
3. 检查课程内容，并使用正确的开始日期激活计划。
4. 在日历或当前计划中找到今天的训练。
5. 训练完成后，把真实活动[关联到计划课程](/zh/docs/guide/manage-active-plan)。

**完成标准：**计划已经激活，今天的课程可见，第一条真实活动已经关联或可以关联。

## 我主要使用移动端

移动端适合查看今日训练、记录运动、快速复盘和执行计划；网页端更适合编辑多周计划和比较复杂图表。

1. 阅读[网页端与移动端](/zh/docs/guide/web-and-mobile)。
2. 完成[移动端运动记录](/zh/docs/guide/mobile-recording)中的权限检查。
3. 记录或导入一条活动。
4. 从今日、日历、教练、计划或我的继续同一账号的训练闭环。

## 我希望智能教练帮忙制定或调整训练

先保证资料、近期活动和当前计划尽量完整。向智能教练说明目标、时间范围、限制条件和可训练日期，并在应用前检查每一个计划草案或课程调整。

**完成标准：**建议引用了真实计划或活动，而且修改前后内容在保存前清晰可见。

## 我需要力量训练

打开手动计划，在课程编辑器里选择**力量训练**，再按照[力量训练课程](/zh/docs/planning/strength-workouts)添加动作、正式组、负重、强度与休息。

如果仍不确定，从[开始使用](/zh/docs/guide/getting-started)开始即可。
