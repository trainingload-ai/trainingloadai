# 用 PMC 做马拉松训练调整

PMC 描述累积训练压力，但不能替你判断一节课是否安全、证明已经适应，更不能诊断疲劳。在马拉松周期中，它适合用来保护训练一致性和关键课目的。

## 开始前准备

- 等待相关活动完成处理，确保训练负荷已经进入 PMC。
- 在个人资料中确认跑步阈值与活动负荷来源优先级。
- 把已完成活动关联到对应计划课程。
- 选择一个明确的决策窗口，通常是过去 2–6 周加未来 7 天。
- 标出下一节关键课：长距离、马拉松配速、阈值课或比赛。
- 记录睡眠、疾病、疼痛、旅行、炎热天气和 session RPE 等图表外信息；PMC 并不包含这些事实。

## 1. 打开正确的 PMC 区间

进入**分析 → PMC**，选择**跑步**，让日期范围同时覆盖负荷累积期和最近需要解释的变化。不要凭单日数值或全历史图表判断一个马拉松阶段。

三个信号应放在一起读：

- [CTL](/zh/docs/metrics/pmc/chronic-training-load)概括较长期负荷趋势。
- [ATL](/zh/docs/metrics/pmc/acute-training-load)对近期训练压力反应更快。
- [TSB](/zh/docs/metrics/pmc/training-stress-balance)表示长期与近期负荷的关系，只是状态背景，并不保证准备度。

## 2. 找到曲线背后的事件

定位 ATL 加速、CTL 改变方向或 TSB 明显跳变的日期，再打开附近的活动和计划课程。

检查变化是否来自：

- 计划内的过载周。
- 比赛、长距离或异常困难的质量课。
- 计划外增加的活动。
- 阈值或负荷来源设置改变。
- 重复、运动类型错误或数据不完整的活动。

在曲线变化能被真实训练或已知设置改变解释前，不要调整计划。

## 3. 对照负荷与执行质量

在日历或当前计划中回答：

- 关键课是否完成了原定目的？
- 轻松跑是否仍然轻松，还是执行质量正在下降？
- 课程没完成是因为日程、疲劳、疼痛，还是课程设计错误？
- 真实完成这一周后，下一节关键课是否仍然合适？

PMC 告诉你压力累积了多少；计划与实际对照才能说明这些压力是否用于预期训练。

## 4. 选择最小且有用的调整

下面的模式用于触发复盘，不是固定阈值规则。

### 近期压力上升，关键课质量下降

- 尽可能保持每周训练节奏。
- 把一节非必要质量课替换为轻松有氧或休息。
- 在长距离和马配课中保护一项，不要两项都强行补救。
- 24–48 小时或下一节训练后再次复查。

### 关键课前 TSB 低于个人常态

- 与自己过去成功完成同类课程时的常态和当前主观状态比较。
- 日程允许时，把课程后移 24–48 小时。
- 如果后移会破坏整周结构，可缩短课程但保留目的。
- 不要从 TSB 推断伤病或疾病，应结合真实症状并在需要时寻求专业意见。

### CTL 上升但完成质量持续下降

- 暂停继续增加负荷。
- 检查阈值、来源优先级或重复活动是否抬高曲线。
- 先简化一周，再考虑增加训练量或强度。
- 用下一次可比较的关键课作为复查点。

### 曲线稳定且执行良好

保持计划不变。图表存在并不意味着一定要调整。

## 5. 记录这次决定

修改计划前写下五项：

1. **观察模式：**PMC 在什么日期发生了什么变化。
2. **执行证据：**哪些活动或未完成课程支持这次担忧。
3. **具体调整：**哪一节未来课程的哪个字段会改变。
4. **保留目的：**这一周仍然必须完成什么训练目标。
5. **复查点：**用哪一天或哪节训练检验决定。

可以把这份摘要交给 [智能教练](/zh/docs/guide/ai-coach)，要求它只生成一个保守且理解计划背景的草案。

## 验证调整结果

- 运动类型和日期范围与当前马拉松问题一致。
- 曲线变化能追溯到活动或明确的设置改变。
- 主观状态和关键课执行与 PMC 一起纳入判断。
- 只有目标中的未来课程被修改，已完成历史保持不变。
- 已经确定具体复查点。
- 下一份证据不支持当前判断时，调整可以撤回或修订。

## 故障排查

- **PMC 为空：**确认活动已完成处理，扩大日期范围，清除错误的运动筛选，再只执行一次页面计算操作。
- **修改设置后数值改变：**找出改变的阈值或负荷来源，并用同一口径重新解释整个对比区间。
- **单条活动造成异常尖峰：**检查时长、传感器、运动分类、重复记录和选用的负荷来源。
- **计划和图表日期不同：**检查账号时区与活动开始时间。
- **指标与主观感受冲突：**把冲突当作需要调查的证据，不要简单丢弃任一方，并保持下一步调整保守。
- **出现疼痛、疾病或异常症状：**不要把 PMC 或智能教练当作医疗许可；根据情况停止或修改训练，并寻求合格专业意见。
