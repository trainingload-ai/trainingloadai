# 连接训练数据

这条流程用于把一条已知训练带入 Trainingload.ai，并验证记录结果。先根据原始活动保存的位置选择路径，再核对具体活动，完成接入验证。

[在 Demo 中浏览活动](https://demo.trainingload.ai/zh/activities)。导入文件或授权平台需要自己的账号，上传截图使用真实应用中的合成账号。

## 1. 选择来源

| 路径 | 适用情况 | 随后验证什么 |
| --- | --- | --- |
| 受支持平台连接 | 来源平台保存着需要导入或同步的活动 | 页面提供的数据方向、日期范围与任务结果，以及导入后的活动。 |
| 原始 FIT、TCX 或 GPX 文件 | 某次训练、历史归档，或没有可用连接的来源 | 每个文件的检查与导入批次结果。 |
| 移动端记录 | 使用 Trainingload.ai 应用记录训练 | 完成后的同步状态与生成的活动。 |

平台能力和授权步骤见[平台连接方式](/zh/docs/guide/integrations)与[连接第三方平台](/zh/docs/guide/connect-third-party-platforms)。使用当前部署和账号实际提供的操作，一次性历史导入与持续同步是不同能力。

## 2. 为已知活动确定主要路径

先记下来源训练的日期、运动和大致时长。如果同一条记录会从设备转发到多个服务，批量回溯前先选定接入路径。

保留原始记录。转换文件或只有汇总的文件，字段可能少于原始 FIT 导出。活动导入需要活动记录，全天健康数据导出属于另一类数据。

## 3. 按所选方式导入

### 文件上传

1. 打开**活动**，选择上传入口。
2. 加入原始文件，等待格式检查。
3. 查看检测格式与验证错误，文件扩展名只是格式提示。
4. 继续上传，并处理出现的重复提示。
5. 在批次进度弹窗核对每项结果。关闭后可从最近批次入口重新查看。

完整文件检查、重复处理与批次状态见[上传活动文件](/zh/docs/guide/upload-activity-files)。

### 平台同步

打开平台连接设置，阅读提供的数据方向，完成授权，并执行页面提供的首次导入或同步。等待该任务的结果，再到活动列表查找目标训练。

不同平台的同步条件与历史范围不同。账号显示已连接后，仍需确认目标历史活动已经导入。凭证只在正式连接流程中填写。

### 移动端记录

结束并保存记录，让应用完成同步。再次记录同一训练前，先检查恢复状态或待上传项目，具体步骤见[移动端运动记录](/zh/docs/guide/mobile-recording)。

## 4. 区分导入进度与活动分析

| 当前看到的状态 | 应检查什么 |
| --- | --- |
| 导入项排队或处理中 | 等待该文件在批次中产生明确结果。 |
| Done 或活动链接 | 打开活动，继续检查它自己的分析状态。 |
| 作为重复项跳过 | 确认匹配的是哪条已有活动。 |
| 部分失败 | 找到失败的文件或分析，继续使用已经完成的结果。 |
| Failed | 阅读错误，再决定重试原始文件或平台操作。 |

活动可能先出现，图表和派生指标稍后完成。传感器缺失、处理请求失败和不受支持的文件，需要分别处理。

## 5. 验证活动记录

先核对来源、运动、本地日期、时长和距离，再检查记录实际包含的测量。

| 来源证据 | 可以支持什么 |
| --- | --- |
| GPS 采样 | 记录路线与定位背景。 |
| 心率采样 | 心率图表与受支持的派生分析。 |
| 功率采样 | 功率图表与相关阈值分析，估算功率会单独标记。 |
| 可用时序记录 | 受支持的详细图表、时间线与范围统计。 |

连接无法补出来源从未记录或未共享的数据。预期字段缺失时，先对照来源平台和原始文件，再决定是否重新导入。

## 6. 接回日常使用

打开[活动详情](/zh/docs/guide/activity-detail)进行复核，在日历中检查本地日期，并关联到正确的计划课程。之后再按运动与可用历史查看 [PMC](/zh/docs/guide/pmc-forecast)。

活动同步成功，不等于睡眠、HRV 和全部全天健康数据都已导入。应分别检查页面提供的各类数据。

## 验证结果

目标训练应通过所选路径出现一次，有明确的导入和分析结果，来源、日期正确，传感器覆盖能够解释。属于计划训练时，确认身份后再核对课程关联。

## 常见问题

### 平台已连接，但没有活动

检查受支持日期范围、来源账号、任务结果与活动列表筛选。页面提供手动同步时执行一次，等待任务处理后再启动其他导入。

### 同一训练出现两次

对照来源、开始时间、时长和记录覆盖。删除前先调查重复转发，尤其要确认是否有一份已经关联到计划。

### 导入后图表为空

检查活动处理状态与源文件是否有可用采样，只有汇总值不一定能生成所有图表。确实是请求失败时，再使用页面的重试操作。

### 断开连接会删除已导入历史吗

断开平台与删除活动是不同操作。确认前先阅读弹窗说明，再单独检查已有活动。
