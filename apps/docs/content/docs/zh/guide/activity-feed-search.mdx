# 活动列表与搜索

活动列表是 Trainingload.ai 中查看已完成训练的主要入口。它会把同步活动、上传文件、手动导入、地图预览、训练负荷和计划关联放在一起。

适合用来回答这些问题：

- 最近练了什么？
- 新导入的活动到了吗？
- 哪些训练还需要复盘？
- 这次活动有没有关联到正确的计划课次？
- 要去哪里打开活动详情做深入分析？

## 开始前

- 连接一个数据平台，或[上传活动文件](/zh/docs/guide/upload-activity-files)。
- 查找特定导入记录时，先确定大致日期、运动类型和来源。
- 需要关联计划时，确认目标计划已经激活，并且活动日期位于计划周期内。

## 推荐查看顺序

1. 打开**活动**并刷新列表。
2. 检查最新活动卡片和处理状态。
3. 使用日期、运动类型或其他可见条件缩小范围。
4. 判断指标或负荷缺失前，先打开活动详情。
5. 只有确认日期、运动类型和训练目的后，才把活动关联到计划课程。

## 活动列表

打开**活动**可以看到最近训练。每张活动卡片可能包含：

- 活动标题。
- 运动类型。
- 开始时间。
- 距离和时长。
- 可用时展示训练负荷。
- 来源平台，例如 Garmin、Strava 或手动上传。
- 活动状态。
- 有路线数据时展示地图缩略图。
- 活动落在当前计划周期内时，展示计划课次关联入口。

列表会在滚动到底部时继续加载。移动端在列表顶部下拉可以刷新。

## 活动状态

活动卡片可能展示这些状态：

- **Synced**：已经同步或导入到 Trainingload.ai。
- **Pending review**：活动可见，但还没有完成复盘。
- **Reviewed**：已经复盘或完成相关处理。
- **Unknown**：状态不可用。

状态标签适合快速分拣列表，但不能替代活动详情页。如果你要看图表、指标或处理结果，还是应该打开活动。

## 搜索与筛选

当活动列表太长时，使用活动搜索。

快捷筛选包括：

- 最近 7 天。
- 最近 30 天。
- 跑步。
- 骑行。
- 游泳。

搜索接口也支持运动类型、来源平台、日期范围、时长、距离、排序和时区等查询条件。界面可能只暴露常用筛选，但带参数的链接可以保留更具体的组合。

## 打开活动

当摘要卡片不够用时，打开活动详情页。

详情页适合查看：

- 完整汇总指标。
- 图表和时间序列。
- 路线与地形上下文。
- 训练负荷和强度。
- 心率、功率、配速和海拔信号。
- 针对这次训练的智能教练提问。

见：[活动详情](/zh/docs/guide/activity-detail)。

## 关联到计划课次

当存在当前计划，并且活动日期落在计划周期内时，活动卡片可以展示计划关联控件。

用它把真实完成的活动连接到原本计划的课次。

这样 Trainingload.ai 才能比较：

- 计划训练 vs 实际完成。
- 预期负荷 vs 实际负荷。
- 完成状态。
- 计划执行匹配度。
- 带计划上下文的智能教练跟进。

如果关联错了，可以取消关联，再手动选择正确课次。

## 导出或删除活动

活动卡片菜单可能包含：

- **View**：打开活动详情页。
- **Export**：在支持时导出 GPX、FIT 或 TCX 文件。
- **Delete**：确认后删除活动。

删除要谨慎。如果活动已经关联到计划课次，删除它会影响计划执行汇总和负荷对比。

## 地图入口

活动页可能展示地图入口，用于打开地图视图。路线背景重要时可以使用地图：

- 比较路线。
- 查看训练发生在哪里。
- 通过位置查找 GPS 活动。
- 判断路线是否不完整或异常。

地图适合看位置上下文；活动详情页更适合看指标。

## 常见排查

如果找不到活动：

- 确认导入批次已经完成。
- 刷新活动列表。
- 放宽搜索日期范围。
- 确认来源平台确实有这次训练。
- 检查活动是否被删除或筛选条件排除了。

如果负荷或图表缺失：

- 打开活动详情页查看处理状态。
- 确认源文件包含所需传感器数据。
- 检查个人阈值和区间设置。
- 如果刚上传，等待分析完成。

## 验证结果

- 目标活动只出现一次，开始时间、运动类型和来源正确。
- 打开卡片后进入预期的活动详情。
- 关联结果指向真正要完成的计划课程，而不只是日期相近的课程。
- 清除筛选条件后，活动不会意外消失。
- 只有确认目标活动后才进行导出或删除。
