# Garmin Personal API

在自托管版中，用自己的 Garmin Personal API Key 导入已完成活动，以及设备和账号可提供的睡眠、HRV、静息心率等数据。

本页仅适用于自托管。云服务的 Garmin 授权和历史导入请看[平台连接指南](/zh/docs/guide/connect-third-party-platforms#连接-garmin-接收新数据)。

## 连接自己的账号

1. 在 Garmin Connect 的[个人 API Key 设置](https://connect.garmin.com/app/settings/personalApiToken)中创建 Key。中国区账号使用对应地区的 Garmin Connect。
2. 在 Trainingload.ai 打开**账号 → 第三方连接 → Garmin → 连接设置**。
3. 选择账号地区，核对 Garmin 账号时区，例如 `Asia/Shanghai`。
4. 选择要导入的活动、睡眠与恢复数据，以及是否定期同步；粘贴 Key 后连接。
5. 点击**立即同步**。留空日期时默认同步最近 30 天，也可以选择历史范围。

无需提供 Garmin 密码或浏览器 Cookie。Key 加密保存在自己的实例中，不要发到聊天、Issue 或日志里。创建后妥善保存，并在撤销或到期后更换；有效期以 Garmin 创建页面为准。

## 同步后检查什么

| 内容 | 你可以检查的结果 |
| --- | --- |
| 已完成活动 | 活动列表出现对应记录，可以打开详情查看来源、时间和可用图表 |
| 睡眠、HRV、静息心率、步数 | 对应日期出现 Garmin 提供的数据；缺失值不会作为 0 填入 |
| 体重、压力、血氧、Body Battery | 保留 Garmin 提供的含义，不会替代训练负荷中的 ATL、CTL 或 TSB |
| 额外指标 | 可在**高级数据与操作**中按日期读取；不会自动修改本地运动设置 |
| 营养和经期 | 不参与定期同步，额外读取需要单独确认 |

数据是否可用取决于设备记录、地区和 Garmin 授权。表中项目不保证每个账号都有数据；连接后请检查同步结果。未识别的数据会显示错误，不能把空结果当作零值。

此连接只读取个人数据，不向 Garmin 创建或发送未来训练课程。

## 历史同步与进度

- 选择合适的日期范围，日期按账号时区解释。
- **已加入队列**表示请求已保存；活动完成下载和导入后，才计入**已导入**。
- 刷新页面不会清空正在处理的任务。大量导入时等待本次处理完成，不要反复提交。
- 历史范围最多一次选择十年，实际耗时取决于活动数量和 Garmin 限制。
- 再次同步会检查并更新已有 Garmin 记录，不会每次创建一条新活动。
- 某项读取失败时，查看显示的错误。其他成功读取的内容仍可能完成导入。

需要定期同步时，在连接设置中开启对应选项。不要把“发现记录数”当作“成功导入数”。

## Key 到期、断开与备份

Key 过期或被撤销时，使用**更换 Key 或重新授权**。请核对地区和账号，避免把新 Key 用到另一个连接上。

断开连接会停止后续同步，但不能清除你已经保存的离线备份。备份数据库时，按[备份与恢复指南](/zh/docs/self-host/operations)安全保管原实例密钥，恢复后才能继续使用已有连接。

此连接用于读取自己的 Garmin 数据。不要收集他人的 Key，在同一个个人实例中提供多人服务。更多说明见 [Garmin Personal API 官方介绍](https://developer.garmin.com/gc-developer-program/personal/personal-api/)。
