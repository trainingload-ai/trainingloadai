# 自托管

自托管让你在自己的电脑或服务器上使用 Trainingload.ai。活动、训练计划和上传文件都保存在你的设备上，你通过浏览器查看和管理训练。

一个自托管实例供一人使用。你负责设备、软件更新和数据备份；如果希望直接打开应用就开始使用，可以先看[自托管还是云服务](/zh/docs/self-host/self-host-vs-cloud)。

## 你可以做什么

- 导入自己的活动，查看详情、时间线和训练负荷。
- 在日历中安排训练，并对照计划和实际完成情况。
- 上传 FIT、GPX、TCX 文件，或使用个人 Key 连接 Intervals.icu、Garmin Personal API。
- 按需配置自己的 AI 服务，使用智能教练；也可以保持 AI 关闭。

## 安装前需要准备什么

- 一台符合[安装要求](/zh/docs/self-host/installation)的设备，并安装 Docker Compose。
- 足够保存训练数据和上传文件的磁盘空间。
- 一个独立保存备份的位置，以便设备故障时恢复数据。

请使用带版本号和签名的正式发行包，按安装指南先验证、再安装。你不需要编译源码或手工组合容器。目前正式支持的安装方式是 Docker Compose。

## 数据会发送到哪里

活动、计划和上传文件保存在你的设备上。连接训练平台时，应用会按你选择的范围联网同步；使用外部 AI 服务时，分析所需的训练信息会发送给该服务商。

AI 默认关闭。需要启用时，按[配置指南](/zh/docs/self-host/configuration)填写自己的服务商 API Key，相关 API 费用由该服务商收取。
