# COROS MCP

Self-host **不开启** COROS MCP。没有受支持的 Self-host 授权、活动导入或通过 MCP 下发课次流程。

Self-host 已支持的个人连接：

- [Intervals.icu](/zh/docs/self-host/configuration)
- [Garmin Personal API](/zh/docs/self-host/garmin-personal-api)

闭源/托管产品的集成能力请看对应产品说明。
