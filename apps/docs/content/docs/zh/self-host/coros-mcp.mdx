# COROS 连接

自托管版目前不支持直接连接 COROS。你可以从来源平台导出受支持的 FIT、TCX 或 GPX 活动文件，再[上传到 Trainingload.ai](/zh/docs/guide/upload-activity-files)。

自托管目前支持的个人连接：

- [Intervals.icu](/zh/docs/self-host/configuration)
- [Garmin Personal API](/zh/docs/self-host/garmin-personal-api)

云服务用户请查看[平台连接指南](/zh/docs/guide/connect-third-party-platforms)。
