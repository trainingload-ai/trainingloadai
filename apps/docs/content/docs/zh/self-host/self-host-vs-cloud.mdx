# 自托管还是云服务

想直接开始使用，可以选择云服务；希望把训练数据保存在自己的电脑或服务器上，并愿意自行安装和维护，可以选择自托管。

## 快速对比

| 你关心的事 | 云服务 | 自托管 |
| --- | --- | --- |
| 怎么开始 | 打开应用并注册账号 | 下载发行包，按安装指南在自己的设备上安装 |
| 数据存在哪里 | Trainingload.ai 云服务 | 你的设备，包括活动、计划和上传文件 |
| 怎么导入训练 | 连接支持的训练平台，或上传活动文件 | 上传活动文件，或使用自己的 Key 连接 Intervals.icu、Garmin Personal API |
| 怎么使用智能教练 | 按账号套餐和 AI 额度使用 | 默认关闭；配置自己的 AI 服务后使用，费用由该服务商收取 |
| 使用账号 | 使用云端账号 | 每个自托管实例仅供一人使用 |
| 备份与恢复 | 由 Trainingload.ai 维护云端服务 | 由你保存备份，并在需要时恢复 |
| 软件更新 | 由 Trainingload.ai 更新 | 由你按升级指南安装新版本 |

## 哪种更适合你

**选择云服务：** 你希望打开应用就能使用，把时间花在训练和复盘上，不想自己安装、更新软件或管理备份。

**选择自托管：** 你希望自己保存训练数据，能够维护一台运行应用的设备，也愿意定期更新和备份。自托管适合个人使用，不支持在同一个实例中创建多个用户。

## 导入训练前需要确认什么

自托管目前支持：

- 上传 **FIT、GPX、TCX** 活动文件；
- 使用个人 API Key 连接 **Intervals.icu**；
- 使用个人 API Key 连接 **Garmin Personal API**。

如果你依赖某个平台同步训练，请先查看[连接数据](/zh/docs/guide/connect-data)和[自托管连接设置](/zh/docs/self-host/configuration#连接-intervalsicu)。云服务和自托管提供的连接方式不同。其他平台如果能导出受支持的活动文件，也可以通过文件上传导入。

**目前不支持 Apple Watch App。**

## 自托管的 AI 怎么用，怎么收费

AI 默认关闭，不配置也可以使用非 AI 功能。需要智能教练时，在设置中选择服务商并填写自己的 API Key；详见[配置 AI](/zh/docs/self-host/configuration#在-client-中配置-ai)。

自托管不使用 Trainingload.ai 云端会员或 AI 积分。AI 请求的费用由你配置的服务商收取。

使用外部 AI 服务时，本次分析所需的训练信息会发送给该服务商。把应用装在本机，并不意味着外部 AI 也在本机运行。连接训练平台时，同步同样需要联网。

## 自托管后需要自己做什么

- 保持设备有足够的可用空间，并按需要运行应用。
- 在更新前备份，并把备份保存到应用设备之外的位置。
- 确认备份能够恢复，设备故障时才有可用的数据副本。
- 按[升级和管理指南](/zh/docs/self-host/operations)更新应用。

## 下一步

选择云服务，可以[打开应用](https://app.trainingload.ai/zh)，再按[快速上手](/zh/docs/guide/getting-started)导入第一条活动。

选择自托管，请从[快速安装](/zh/docs/self-host/installation)开始。安装、备份和更新的具体步骤都放在对应指南中。
