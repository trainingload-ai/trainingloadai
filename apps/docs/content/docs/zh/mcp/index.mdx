# TrainingLoad MCP

通过 TrainingLoad MCP，把自己的训练数据连接到 ChatGPT、Codex、Claude 等 AI 客户端。连接后，你可以直接提问近期负荷、计划完成情况、表现趋势或同步问题，无需逐条复制活动记录。MCP 只读取数据，不会修改你的训练安排。

**服务地址：** `https://api.trainingload.ai/mcp`

连接不需要 API Key。客户端通过 OAuth 打开 TrainingLoad 授权页；你可以检查客户端名称和申请的数据权限，之后也可以从账号中撤销访问。

## 可以读取哪些训练信息

| 问题 | 首选能力 |
| --- | --- |
| 我现在的训练状态怎样？ | 训练快照、训练 readiness 指标、负荷时间序列 |
| 最近两个训练周期有什么变化？ | 周期比较、按项目负荷拆分、活动统计与训练一致性 |
| 我的跑步、骑行或游泳能力在变化吗？ | 体能指标趋势、训练区间、个人最佳 |
| 计划执行得怎么样？ | 训练计划发现与总结、计划课程、课程详情、状态型计划完成率 |
| 最近完成了哪些训练？ | 活动列表、隐私精简详情、区间分布和 lap/split 摘要 |
| 接下来有什么比赛？ | 比赛列表与绑定当前用户的赛事详情 |
| 为什么没有同步？ | 第三方连接和同步 readiness |
| 健康背景是否有变化？ | 单独授权的每日健康摘要 |

完整字段和 scopes 见[工具参考](/zh/docs/mcp/tools)。客户端还可以发现 3 个内置 [Resources 与 Prompts](/zh/docs/mcp/resources-and-prompts)，用于理解指标、安全边界和复用分析流程。

## 可以直接这样提问

- “对比这周和上周的训练量与负荷，主要变化来自哪几次活动？”
- “本周计划完成了多少？哪些课程还没有关联活动？”
- “最近的跑步能力指标怎样变化？哪些日期缺少可比较的数据？”

阅读回答时，检查日期范围、引用的活动和缺失数据。图表中的变化可以帮助讨论训练安排，不能单独得出医疗结论。

## 连接前了解这些限制

- **只读：** 客户端不能修改活动、计划、比赛、资料、连接或账号。
- **仅限自己的数据：** 客户端只能查询你授权账号下的记录。
- **返回训练摘要：** 不提供精确 GPS、原始传感器数据流、平台密钥或完整 FIT 文件。
- **健康数据单独授权：** 默认权限不包含 `health:read`。
- **可以随时撤销：** 不再使用某个客户端时，在账号中取消其访问权限。
