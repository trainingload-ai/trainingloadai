# MCP 更新记录

## 2026-10-15 — 完整只读训练能力面

- 工具从 17 个扩展至 24 个。
- 新增活动聚合统计与训练一致性分析，并明确返回数据覆盖率和截断状态。
- 新增隐私精简的活动区间分布与 lap/split 详情。
- 新增训练计划发现、计划级完成/负荷汇总和单场比赛详情。
- 新增 3 个原生 MCP resources 和 3 个可复用 prompts，并纳入自动生成的双语参考与发布门槛。

## 2026-10-15 — 高级只读分析与完整接入指南（较早里程碑）

- 工具从 9 个扩展至 17 个。
- 新增训练周期比较、按项目负荷拆分和训练 readiness 指标。
- 新增体能趋势、训练区间和个人最佳。
- 新增状态型计划完成率与第三方连接/同步 readiness。
- 新增工作原理、使用场景和 7 个独立客户端连接指南。
- 功能页现在展示从 OAuth 连接、透明工具调用到证据回答的完整路径。

## 2026-10-14 — 初始只读产品面

- 新增 9 个只读工具，覆盖训练、活动、计划、比赛、资料和健康摘要。
- 新增聚合优先的 server instructions，以及基于 Zod 的输入/输出契约。
- 新增 OAuth scope 过滤、独立 `health:read` 授权、撤销可见性、限流、审计记录和 OpenTelemetry。
- 使用 MCP SDK v2 提供无状态传输，兼容 `2025-11-25` 与 `2026-07-28`。
- 新增自动生成的工具参考和客户端连接指南。

本次发布不包含任何写入工具。
