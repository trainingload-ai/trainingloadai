# 客户端指南

选择你实际使用的客户端。所有指南都连接同一个端点并通过 TrainingLoad OAuth 授权，不需要 API Key。

- [ChatGPT](/zh/docs/mcp/clients/chatgpt)
- [Codex](/zh/docs/mcp/clients/codex)
- [Claude Code](/zh/docs/mcp/clients/claude-code)
- [Claude Desktop](/zh/docs/mcp/clients/claude-desktop)
- [Cursor](/zh/docs/mcp/clients/cursor)
- [VS Code](/zh/docs/mcp/clients/vscode)
- [opencode](/zh/docs/mcp/clients/opencode)

配置完成后，使用[统一验收步骤](/zh/docs/mcp/connect#所有客户端通用的验收步骤)确认 OAuth、工具发现和首次调用都正常。
