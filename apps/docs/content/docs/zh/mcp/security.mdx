# MCP 安全与隐私

连接 TrainingLoad MCP 后，你授权的 AI 客户端可以读取训练摘要并回答问题。MCP 只读，不能修改活动、计划、比赛、个人资料或账号设置。

## 你决定授予哪些权限

连接时，客户端会打开 TrainingLoad 授权页。检查客户端名称和申请的数据权限，确认后再授权。无需向客户端提供 TrainingLoad 密码或 API Key。

每次读取数据都会检查当前账号的授权。客户端只能读取你已授权的数据；权限不足、授权过期或服务暂时不可用时，会返回对应错误。

健康数据需要单独授予 `health:read`，不包含在默认权限中。你可以在账号中撤销客户端访问。

## 客户端能读到什么

工具返回回答训练问题所需的摘要，例如活动时长、训练负荷、计划执行和指标趋势。活动和计划查询仅限你授权账号下的记录。

MCP 不返回邮箱、内部用户 ID、精确 GPS、原始传感器数据流、第三方平台密钥或完整 FIT 文件。列表和时间范围有数量限制，客户端可能需要分次获取较长时间的记录。

## 活动备注不会成为操作指令

活动名称、描述、训练名称和比赛备注都作为训练记录处理。服务会清理其中不安全的文本，并要求客户端不要执行备注中的指令或链接。

## 健康数据的用途

健康工具提供精简的日常健康摘要，用来补充训练分析。它不能用于医学诊断，也不能替代医生或其他专业人员的评估。

## 请求限制与排错记录

请求过于频繁或一次读取的数据太多时，服务可能限制请求。客户端应按错误提示缩小日期范围，或等待后重试。

服务保留工具名称、结果状态、错误码、耗时和请求编号等排错信息。用户和客户端标识经过处理；记录不包含访问令牌，也不保存完整请求或响应内容。

## 遇到可疑访问怎么办

先在 TrainingLoad 账号中撤销该客户端的访问，再通过官网支持渠道报告。可以提供发生时间、客户端名称和界面显示的请求编号。不要发送访问令牌或完整健康数据。
