## 从首次设置到训练复盘 [#一条完整训练闭环]

你可以按下面的顺序完成设置、记录训练和查看分析：

1. 设置个人资料、时区、单位、阈值和训练区间。
2. 连接运动平台或上传活动文件，导入已有训练记录。
3. 需要按计划训练时，创建或选择计划并安排课次。
4. 查看当天的训练安排，完成训练后同步或记录活动。
5. 打开活动详情，查看图表和训练负荷，并关联对应的计划课次。
6. 回顾一周的训练和负荷趋势，也可以向 AI 教练提问，再决定是否调整后续安排。
