## 一条完整训练闭环

Trainingload.ai 的价值来自这些环节彼此连接：

1. 设置个人资料、阈值、区间、单位和时区。
2. 连接一个可靠数据源，或者上传活动文件。
3. 创建或选择训练计划，检查接下来的安排。
4. 执行今天的课程，或者记录训练为什么发生变化。
5. 同步、记录或上传实际完成的活动。
6. 确认处理状态、训练负荷以及活动与计划课程的关联。
7. 把单次训练、当前状态和近期趋势放在一起复核。
8. 保持或调整后续训练，然后再次进行周度和周期复盘。
