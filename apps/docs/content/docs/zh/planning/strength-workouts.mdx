# 力量训练课程

力量训练需要记录动作、组数、次数、负重和休息，不能沿用耐力训练的时间与距离步骤。Trainingload.ai 会使用专门的力量训练编辑器，并在训练完成后把计划内容与实际记录放在一起查看。

## 开始前准备

- 打开计划草稿或一节尚未开始的未来训练。已经完成的训练记录不应再改成新的计划内容。
- 选择**力量训练**运动类型，进入力量训练编辑器。
- 选择**手动设置**或**规则输入**；两种方式最终都会得到同一份训练结构。
- 准备动作名称、器械、已知重量或 1RM，以及预期 RPE/RIR；没有可靠数值时选择**不指定负重**。

## 1. 选择力量训练

## 2. 设置整节训练

只有在计划确实需要时才填写预计时长和计划训练 RPE。这里的 RPE 表示整节训练的预期总体难度，并不等于每个正式组的强度目标。

## 3. 添加动作

每个动作必须有非空名称。使用稳定、容易识别的名称，便于之后对比计划与实际完成情况。器材为可选信息，用于说明运动员需要准备什么，不要简单重复动作名称。

示例：

- 杠铃深蹲 — 杠铃
- 罗马尼亚硬拉 — 杠铃
- 引体向上 — 自重
- 保加利亚分腿蹲 — 哑铃

## 4. 添加组方案

组方案用于描述多组相同的训练安排。

- **热身组**：为正式训练做准备，可以省略。
- **正式组**：构成主要训练内容，每个动作必须至少包含一个。

按次数完成的动作选择重复次数；等长或计时训练选择持续时间。使用次数范围时，最小值不能大于最大值。

## 5. 选择负重方式

- **不指定负重**：不规定具体重量。器械或当前力量水平未知时使用。
- **固定重量**：填写数值和受支持的单位。
- **1RM 百分比**：只有相关动作的 1RM 已知且仍然有效时才使用。
- **自重**：使用运动员自身重量。
- **自重偏移**：在支持的情况下，表示自重加上或减去外部重量。

如果没有可靠的训练历史或已知 1RM，智能教练生成的力量计划不应猜测公斤数、磅数或 1RM 百分比。此时应选择**不指定负重**，并配合 RPE 或 RIR 提示。

## 6. 添加强度和休息

RPE 描述主观用力程度，RIR 描述完成该组后还能保留多少次重复。训练提示应保持内部一致；除非有明确目的，不要同时安排很激进的重量和非常轻松的强度目标。

休息时间设置在每个组方案中，应以保证动作质量为准，不需要让所有动作使用相同的休息时间。

## 7. 使用力量 DSL 编写同一课程

在**规则输入**中，可以这样编写力量训练：

```text
duration 50m
session rpe 6

exercise "杠铃深蹲" equipment barbell {
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 80kg rpe 7 rest 3m
}

exercise "引体向上" equipment bodyweight {
  work 3x8 bodyweight rir 2 rest 90s
}
```

完整语法、中文动作名称、负重形式、校验流程和报错处理见[力量训练 DSL](/zh/docs/planning/strength-workout-dsl)。力量训练 DSL 是静态训练安排，不会执行 `if/else`、跨周进阶、减量脚本、嵌套块或任意可执行脚本。

## 验证课程结果

- 至少存在一个动作。
- 每个动作都有名称。
- 每个动作至少存在一个组别。
- 每个动作至少包含一个正式组。
- 组数、次数、秒数、主观强度和负重都在支持范围内。
- 预览与计划的训练内容一致。

保存后重新打开训练，确认手动设置或规范化后的力量 DSL 仍表示相同内容。预览中的动作和正式组数量应符合预期。

## 故障排查

- **“请为每个动作填写名称”：**在 DSL 中添加非空的引号名称，或在可视化构建器填写动作名称。
- **“每个动作至少需要一个组方案”：**关闭动作前增加热身组或主训练组。
- **“每个动作至少需要一个正式组”：**只有热身组的动作无效，至少添加一行 `work`。
- **次数范围验证失败：**较小值写在前面，例如 `3x8-12`。
- **负重或强度验证失败：**使用支持的负重形式，并且 RPE 与 RIR 只能二选一。
- **右大括号无法解析：**每个动作只闭合一次，不要嵌套动作块。
- **从力量切换回耐力后编辑器被清空：**两种结构本来就不同；切换运动前先保存或复制需要保留的文本。

## 完成力量训练

力量活动可以记录动作、每组完成情况和整节课状态。训练后打开力量活动详情，确认动作名称、实际组数、重量、次数或时间，以及整节课的上下文，再把它用于计划复盘。
