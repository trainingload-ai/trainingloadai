# 如何在 Trainingload 中手動編輯訓練

這是 **Trainingload.ai 應用內手動訓練編輯器** 的產品指南。打開計畫裡的一節課後，在這裡選擇運動、加入耐力步驟或肌力動作、檢查預覽，再儲存有效草稿。

它不是獨立的**訓練編輯器**或**訓練建構器**。若要先在瀏覽器起草步驟並複製訓練 DSL，請用[訓練編輯器與結構化訓練建構器](/zh-hant/workout-editor)。需要應用內儲存、肌力建構器和排到某一天時，再回到本頁。

## 開始前

- 開啟手動計畫，或一節可編輯的計畫課程。
- 若要使用區間或百分比目標，先確認運動員的閾值可靠。
- 判斷這節課屬於耐力或肌力。
- 若只想先公開起草，可先[用訓練編輯器起草結構化訓練](/zh-hant/workout-editor)，再貼上或在本頁重建。

## 1. 選擇運動類型

手動編輯器只保留適合編排計畫的精簡清單：

- 跑步：Running、Trail Running、Treadmill。
- 騎行：Cycling、Mountain Biking、Indoor Cycling。
- 游泳：Pool Swimming、Open Water Swimming。
- 其他：Strength Training。

所選運動會改變可用目標單位，也可能改變結構類型。耐力與肌力不相容，切換會重置草稿，請先選運動再寫細節。

## 2. 名稱與備註

名稱用短識別，例如「有氧間歇」或「下肢肌力」。備註放不該變成機器結構的人話：

- 技術提示。
- 器材。
- 補給。
- 路線或地形。
- 停止或減量條件。

不要把文章寫進 DSL 欄。步驟放 Manual 或 Rules，說明放備註。

## 3. 建立耐力課

在手動模式加入步驟或重複模組：

1. 選擇暖身、主課或恢復。
2. 設定時間或距離。
3. 只有閾值可信時才加目標。
4. 間歇用重複模組，不要複製同一組很多次。
5. 結構一變就看圖表。

有效耐力結構至少要有一個有意義的步驟。範圍目標的起始值不可大於結束值。

## 4. 建立肌力課

選擇 **Strength Training** 開啟肌力建構器。為每個動作填寫名稱，並至少加入一個正式組。若要用文字輸入，把對應的 DSL 寫進 Rules 並驗證。

## 5. 規則模式

Rules 接受支援的訓練 DSL，適合精簡重複輸入，不是自由備註欄。儲存前保持一條指令對應一條 DSL，口語說明放備註，並驗證渲染結果。見[耐力訓練 DSL](/zh-hant/docs/planning/workout-dsl)。也可以先[在公開訓練編輯器起草同一段 DSL](/zh-hant/workout-editor)，再貼到這裡。

## 6. 儲存

選擇 **Save Draft**。Trainingload.ai 會先驗證再加入計畫草稿。

## 常見問題

### 什麼是手動訓練編輯器？

它是 Trainingload 裡編輯計畫課程的應用內畫面。你選擇運動類型，加入耐力步驟或肌力動作，寫下教練備註，預覽課程，再儲存到某一週、某一天。公開的[訓練編輯器與建構器](/zh-hant/workout-editor)是另一套起草工具。

### 怎樣在 Trainingload 裡手動編輯訓練？

開啟可編輯的計畫課程，先選運動，再加入步驟或重複模組。設定時間或距離；只有閾值可靠時才加目標。

### 切換運動後草稿為什麼沒了？

耐力與肌力結構不能互轉。先選運動再寫細節；切換前先複製要保留的備註或規則。
