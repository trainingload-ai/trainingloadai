# 如何在 Trainingload 中手動編輯課表

本頁為 **Trainingload.ai 應用程式內手動課表編輯器的產品指南**，說明開啟訓練計畫後如何編輯單場計畫課表——包含選擇運動項目、新增耐力步驟或肌力組數、預覽課表並儲存有效草稿。

這並非獨立的**課表編輯器**或**課表建構器**。如果你想先使用免費的瀏覽器工具草擬步驟並複製課表 DSL，請前往[課表編輯與建構器](/zh-hant/workout-editor)。需要應用程式內儲存、肌力建構器與計畫日期排程流程時，再回到本頁。

## 開始之前

- 開啟一份手動計畫，或任一場可編輯的計畫課表。
- 若會使用區間或百分比目標，請先確認運動員閾值正確可靠。
- 決定這場課表屬於耐力訓練還是肌力訓練。
- 如果只需要先建立公開草稿，可先[在課表編輯器中建構課表](/zh-hant/workout-editor)，再貼上或在此重建。

## 1. 選擇運動項目

手動編輯器刻意提供精簡的規劃清單：

- 跑步：跑步、越野跑、跑步機。
- 自行車：自行車、登山車、室內自行車。
- 游泳：泳池游泳、開放水域游泳。
- 其他：肌力訓練。

所選運動項目會改變可用的目標單位，也可能切換課表結構類型。在耐力訓練與肌力訓練之間切換會重設不相容的草稿結構，因此請先選好運動項目，再輸入詳細步驟。

## 2. 新增名稱與備註

使用名稱簡短標示課表重點，例如「有氧間歇」或「下肢肌力」。備註則用來記錄不應轉成機器結構的人工指導：

- 技術提示。
- 器材提醒。
- 補給建議。
- 路線或地形說明。
- 停止或減量訓練的判斷條件。

請勿在 DSL 欄位中寫入一般敘述文字。訓練步驟應放在手動模式或規則模式；教練脈絡則放在備註中。

## 3. 建立耐力課表

在手動模式中，新增步驟或重複模組。針對每個步驟：

1. 選擇步驟類型，例如暖身、主課表或恢復。
2. 設定時間或距離。
3. 只有在運動員具備可靠參考值時才加入強度目標。
4. 規劃間歇訓練時，請使用重複模組，不要重複複製大量相同的主課表與恢復步驟。
5. 隨著結構變更隨時檢視圖表預覽。

有效的耐力結構至少需要一個有意義的步驟。區間目標的起始值不可大於結束值。

## 4. 建立肌力課表

選擇**肌力訓練**即可開啟肌力建構器。請依照[肌力訓練課表](/zh-hant/docs/planning/strength-workouts)新增動作與正式組；若要以文字輸入，請參考[肌力課表 DSL](/zh-hant/docs/planning/strength-workout-dsl)。

## 5. 適時使用規則模式

規則模式接受系統支援的課表 DSL，適合精簡撰寫與重複使用的文字格式，但並非自由填寫教練備註的欄位。

在規則模式儲存之前：

- 每條指令使用單一受支援的 DSL 表達式。
- 將自然語言說明放在備註中。
- 驗證結果並檢查產生的課表結構。
- 依據類型查閱[耐力課表 DSL](/zh-hant/docs/planning/workout-dsl)或[肌力課表 DSL](/zh-hant/docs/planning/strength-workout-dsl)的對應語法。
- 你也可以先[在公開課表編輯器中草擬相同的 DSL](/zh-hant/workout-editor)，再貼到此處。

## 6. 儲存

點選**儲存草稿**。Trainingload.ai 會先驗證課表內容，再將其加入計畫草稿中。

## 驗證已儲存的課表

請確認以下項目：

- 運動項目標籤正確無誤。
- 預覽畫面符合預期的主課表／恢復順序或肌力組數。
- 備註與結構內容保持分離。
- 已儲存的課表出現在正確的週次、日期與當日順序中。
- 只有在資訊充足時才會顯示預期負荷。

## 疑難排解

- **運動清單中出現預期外的項目：** 請確認你使用的是手動計畫課表編輯器。其建立清單僅限上述九項運動；活動分類畫面才會提供更廣泛的項目目錄。
- **切換運動項目導致草稿清除：** 耐力與肌力結構互不相容。請先選擇運動項目，切換前務必先複製可重複使用的備註或規則。
- **耐力課表預覽為空：** 請至少新增一個有效步驟，並確認時間／距離與目標數值皆有效。
- **目標範圍遭到拒絕：** 請將較小數值寫在較大數值前面，並確認單位符合所選運動項目。
- **提示「請為每個動作輸入名稱」：** 請填寫每個肌力動作的名稱；預設提示文字不會被儲存為實際內容。
- **肌力動作無法儲存：** 請為每個動作至少新增一個組數群組，且至少包含一組正式組。
- **規則錯誤訊息仍顯示英文：** 請勿將原始伺服器訊息複製進備註中。請記錄本地化警示、所選運動項目與失敗的 DSL 語法行，再回報給支援團隊。
- **已儲存課表出現在錯誤日期：** 請確認計畫開始日期、週／日偏移量、當日課表順序與帳號時區。

## 常見問題

### 什麼是手動課表編輯器？

它是 Trainingload 中用來編輯單場計畫課表的應用程式內畫面。你可以在其中選擇運動項目、新增耐力步驟或肌力動作、附加教練備註、預覽課表，並儲存到特定週次與日期。公開的[課表編輯與建構器](/zh-hant/workout-editor)則是獨立的草擬工具。

### 如何在 Trainingload 中手動編輯課表？

開啟可編輯的計畫課表，先選擇運動項目，再新增步驟或重複模組。設定時間或距離，僅在閾值可靠時加入目標，並使用重複模組來處理間歇段落，避免手動複製多次相同的組合。

### 應用程式內編輯器能建立肌力課表嗎？

可以。選擇**肌力訓練**即可開啟肌力建構器，為每個動作命名並至少加入一組正式組。文字輸入方式請參考[肌力課表 DSL](/zh-hant/docs/planning/strength-workout-dsl)。

### 該選用手動模式還是規則模式？

想透過點選方式編排步驟時使用手動模式；需要精簡且可重複使用的 DSL 時則使用規則模式。請勿將教練文字說明寫進 DSL 欄位，這類內容應放在備註。詳見[耐力課表 DSL](/zh-hant/docs/planning/workout-dsl)。

### 為什麼切換運動項目會重設草稿？

因為耐力與肌力結構互不相容。請先選好運動項目再輸入詳細步驟，切換前請先複製可重複使用的備註或規則。
