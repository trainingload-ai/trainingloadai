# 肌力訓練課表

肌力課表需要以動作、組數、次數、負重、費力程度與休息時間來構成，而非以時間與距離為基礎的耐力步驟。Trainingload.ai 提供專屬的肌力編輯器，並可將計畫處方與實際完成的肌力活動並排檢視。

## 開始之前

- 開啟一份計畫草稿或可編輯的未來課表。切勿將已完成活動改寫為新的處方。
- 將運動項目選為**肌力訓練**以開啟肌力編輯器。
- 決定使用**手動**或**規則**模式。兩者最終會儲存為相同的課表結構。
- 準備好動作名稱、器材、可靠的重量或 1RM 數值，以及目標 RPE／RIR。若尚無明確重量數值，請選擇**未指定負重**。

## 2. 設定課表層級指引

僅在對計畫有幫助時才填寫計畫時長與整場課表 RPE（Session RPE）。整場課表 RPE 描述的是整體預期難度，而非每一組的費力目標。

## 3. 新增動作

每個動作都必須有一個非空白的名稱。請使用穩定且易辨識的命名，方便日後將計畫與實際完成的訓練互相比較。器材欄位為選填，用來說明運動員所需的器材，不需要重複動作名稱。

範例：

- 槓鈴深蹲 — 槓鈴
- 羅馬尼亞硬舉 — 槓鈴
- 引體向上 — 自身體重
- 分腿蹲 — 啞鈴

## 4. 新增組數群組

組數群組用來描述採用相同處方的重複組數。

- **暖身（Warm-up）** — 準備組；選填。
- **正式組（Work）** — 定義主要訓練處方的組數；每個動作必填。

以次數為主的訓練選擇次數，等長或計時動作則選擇時間。填寫次數範圍時，最小值不可大於最大值。

## 5. 選擇負重

- **未指定負重（Open load）** — 不指定數值重量，適合器材或目前肌力水準不明確時使用。
- **固定重量（Fixed weight）** — 搭配受支援單位的具體重量數值。
- **1RM 百分比（Percent of 1RM）** — 僅適用於該動作有明確且最新 1RM 數值的情況。
- **自身體重（Bodyweight）** — 採用運動員自身體重。
- **自身體重增減負重（Bodyweight offset）** — 在支援的情況下，於自身體重加上額外負重或減去輔助重量。

當運動員缺乏工具紀錄的歷史資料或已知 1RM 時，AI 產生的肌力計畫不應憑空編造公斤、磅數或 1RM 百分比。搭配 RPE／RIR 提示的未指定負重是更安全的預設方式。

## 6. 新增費力程度與休息時間

使用 RPE 表示自覺費力程度，或使用 RIR 表示保留次數。請保持提示邏輯一致；除非刻意設計，否則應避免同時指定極高負重與極輕鬆的費力目標。

休息時間是依組數群組儲存的。請依訓練品質需求給予充足休息，不必強迫每個動作都使用相同的休息秒數。

## 7. 使用肌力 DSL 撰寫相同課表

在**規則**模式中，肌力課表可以這樣撰寫：

```text
duration 50m
session rpe 6

exercise "Back Squat" equipment barbell {
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 80kg rpe 7 rest 3m
}

exercise "Pull Up" equipment bodyweight {
  work 3x8 bodyweight rir 2 rest 90s
}
```

完整語法、本地化動作名稱、負重寫法、驗證流程與錯誤排除，請參閱[肌力課表 DSL](/zh-hant/docs/planning/strength-workout-dsl)。肌力 DSL 屬於靜態處方，不會執行 `if/else`、每週漸進規則、減量指令碼、巢狀區塊或任意可執行指令碼。

## 驗證課表

儲存前請確認：

- 至少存在一個動作。
- 每個動作皆已填寫名稱。
- 每個動作皆包含至少一個組數群組。
- 每個動作皆包含至少一個正式組群組。
- 組數、次數、秒數、費力程度與負重皆在支援範圍內。
- 預覽畫面符合預期課表內容。

儲存後請重新開啟課表，確認視覺化建構器或正規化後的肌力 DSL 呈現相同結構，且預覽摘要統計的動作數與正式組數正確無誤。

## 疑難排解

- **「請為每個動作輸入名稱」：** 在 DSL 中填入雙引號包住的非空白名稱，或在視覺化建構器中填寫動作欄位。
- **「每個動作至少需要一個組數群組」：** 在關閉動作區塊前新增暖身或正式組群組。
- **「每個動作至少需要一組正式組」：** 只有暖身組的動作無效，請至少加入一行 `work`。
- **次數範圍驗證失敗：** 請將較小數值寫在前面，例如 `3x8-12`。
- **負重或費力程度驗證失敗：** 請使用受支援的負重格式，並僅擇一填寫 RPE 或 RIR。
- **右大括號遭到拒絕：** 每個動作只關閉一次，且不可巢狀撰寫動作區塊。
- **從肌力切換到耐力時編輯器被清空：** 兩者結構本來就不同，切換運動項目前請先儲存或複製想保留的文字。

## 已完成的肌力課表

肌力活動可記錄各動作、組數完成情況與整場課表完成狀態。訓練結束後，開啟肌力活動詳情，核對動作名稱、完成組數、負重、次數／時間與整體課表脈絡，再將其納入訓練回顧。
