# 肌力課表 DSL

肌力 DSL 是肌力課表建構器的文字形式。當你需要貼上教練提供的課表、快速編輯多個組數群組，或檢視 Trainingload.ai 實際儲存的精確結構時，都非常適合使用。它描述單場靜態課表；每個動作包含一個或多個暖身或正式組數群組。

## 開始之前

- 開啟一場可編輯的課表，並將運動項目選為**肌力訓練**。
- 切換到**規則**分頁。**手動**分頁則會以視覺化方式編輯相同的課表結構。
- 確認哪些負重已有明確數值。若尚無依據，請使用 `open`，切勿憑空編造重量或百分比。
- 將教練說明保留在課表備註中。DSL 只負責訓練處方，不包含自由敘述文字。

## 從最小的有效課表開始

將以下內容貼到**規則**欄位中：

```text
exercise "Goblet Squat" equipment dumbbell {
  work 3x8 open rir 3 rest 90s
}
```

接著點選**驗證輸入**。這個範例代表：

- 一個名為「Goblet Squat」的動作；
- 器材為啞鈴（`dumbbell`）；
- 3 組正式組，每組 8 次；
- 未指定固定負重（`open`）；
- 保留次數（RIR）為 3 次；
- 每組結束後休息 90 秒。

每份有效的課表至少需要一個動作。每個動作都需要一個以雙引號包住的非空白名稱，以及至少一行 `work` 指令。

## 了解文件結構

一份完整的課表包含三個層級：

```text
duration 50m
session rpe 6

exercise "Back Squat" equipment barbell {
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 80kg rpe 7 rest 3m
}
```

1. `duration` 與 `session rpe` 描述整場課表。兩者皆為選填，且最多只能各出現一次。
2. `exercise "…" {` 開啟一個動作區塊，並以 `}` 結束。
3. `warmup` 與 `work` 行描述該動作內的各個組數群組。

允許使用空行。註解與一般敘述文字不屬於語法的一部分。

## 新增課表層級設定

請將這兩行放在第一個動作之前：

```text
duration 50m
session rpe 6
```

`duration` 接受秒、分或小時，例如 `45s`、`50m` 或 `1.5h`，代表整場課表的計畫時長，而非單一組的時間。

`session rpe` 接受 1 到 10 的數字，代表整場課表的預期整體難度。它與組數群組行中的 `rpe` 不同，後者代表特定組數的費力目標。

## 新增動作

基本格式如下：

```text
exercise "Romanian Deadlift" {
  work 3x8 open rir 2 rest 2m
}
```

動作名稱必須放在雙引號內且不可為空，並可使用運動員偏好的語言。若名稱內含雙引號，請寫作 `\"`；字面反斜線請寫作 `\\`。

器材欄位為選填：

```text
exercise "Romanian Deadlift" equipment barbell {
```

器材代碼可包含大小寫英文字母、數字、連字號與底線。儲存後的 DSL 會將代碼正規化為小寫。建議使用穩定代碼，例如 `barbell`、`dumbbell`、`bodyweight`、`cable` 或 `machine`。

## 撰寫組數群組

請依以下順序撰寫可讀性佳的標準 DSL：

```text
work PRESCRIPTION LOAD EFFORT rest DURATION
```

只有 `warmup` 或 `work` 與訓練處方為必填。省略負重時預設為未指定負重，但明確寫出 `open` 能讓意圖更清楚。費力程度與休息時間為選填。

| 組成         | 可接受格式                               | 範例                                                 |
| ------------ | ---------------------------------------- | ---------------------------------------------------- |
| 組別類型     | `warmup` 或 `work`                       | `work`                                               |
| 訓練處方     | 固定次數、次數範圍、AMRAP 或計時         | `3x5`、`3x8-12`、`1x5+`、`3x45s`                     |
| 負重         | 未指定、固定重量、1RM 百分比或自身體重   | `open`、`weight 80kg`、`weight 75%1rm`、`bodyweight` |
| 費力程度     | RPE 或 RIR                               | `rpe 7`、`rir 2`                                     |
| 休息         | `rest` 後接時間                          | `rest 90s`、`rest 3m`                                |

單一動作可以包含多個組數群組：

```text
exercise "Back Squat" equipment barbell {
  warmup 1x8 weight 20kg rest 60s
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 60kg rpe 7 rest 3m
}
```

暖身群組為選填，但至少必須包含一個正式組群組，因此只有 `warmup` 行的動作無法通過驗證。

## 選擇次數或計時處方

| 目標             | 語法     | 意義                                         |
| ---------------- | -------- | -------------------------------------------- |
| 固定次數         | `3x5`    | 3 組，每組 5 次                              |
| 次數範圍         | `3x8-12` | 3 組，每組 8 到 12 次                        |
| AMRAP            | `1x5+`   | 1 組，標記為 AMRAP，基準為 5 次              |
| 計時組（秒）     | `3x45s`  | 3 組，每組 45 秒                             |
| 計時組（分鐘）   | `2x1.5m` | 2 組，每組 90 秒                             |

組數與次數必須為正數。填寫次數範圍時，請將較小的數值寫在前面。

## 選擇負重

### 未指定負重

```text
work 3x10 open rir 3 rest 90s
```

當需要由運動員依當天狀態自行決定重量，或缺乏可靠歷史負重資料時，請使用 `open`。

### 固定重量

```text
work 3x5 weight 80kg rpe 7 rest 3m
work 3x5 weight 175lb rpe 7 rest 3m
```

數字與 `kg` 或 `lb` 之間請勿加入空格。

### 1RM 百分比

```text
work 4x4 weight 80%1rm rest 3m
```

僅在該動作有明確且最新的 1RM 資料時使用。可接受百分比須大於 0 且不超過 100。

### 自身體重與自身體重增減負重

```text
work 3x8 bodyweight rir 2 rest 90s
work 3x6 bodyweight +10kg rpe 8 rest 2m
work 3x8 bodyweight -20kg rir 2 rest 2m
```

`+10kg` 表示額外負重；`-20kg` 表示使用輔助來降低實際自體負重。

## 選擇 RPE 或 RIR

每一行組數群組只能使用一種費力模型：

```text
work 3x5 weight 80kg rpe 7 rest 3m
work 3x8 open rir 2 rest 2m
```

- `rpe` 接受 1–10。
- `rir` 接受 0–10。
- 請勿在同一行同時填寫兩者。

RPE 與 RIR 僅作為強度提示，不會自動換算重量。填寫 `rpe 7` 不會讓 Trainingload.ai 自行推算或調整負重。

## 建立完整的本地化課表

動作名稱屬於使用者內容，因此不一定要用英文；DSL 關鍵字則因屬於語法規範，必須維持英文。

```text
duration 45m
session rpe 6

exercise "槓鈴深蹲" equipment barbell {
  warmup 1x8 weight 20kg rest 60s
  warmup 1x5 weight 40kg rest 90s
  work 3x5 weight 60kg rpe 7 rest 3m
}

exercise "伏地挺身" equipment bodyweight {
  work 3x8-12 bodyweight rir 2 rest 90s
}

exercise "棒式" equipment bodyweight {
  work 3x45s bodyweight rest 60s
}
```

這份範例會建立三個動作：一個負重次數動作、一個自體重量次數範圍動作，以及一個計時自體重量靜態支撐動作。

## 驗證、比對並儲存

1. 點選**驗證輸入**。
2. 先修正第一筆回報的行錯誤，再處理其他行。
3. 比對肌力預覽與預期的動作數量及正式組數。
4. 若想以視覺化方式檢查解析結果，可切換至**手動**分頁。
5. 切回**規則**分頁，確認正規化後的 DSL 仍維持相同含義。
6. 點選**儲存草稿**，重新開啟該課表並再次確認。

正規化可能會將關鍵字、器材代碼與單位轉成小寫，或自動補上明確的 `open`。這些變動不會改變課表原意；但若動作、組數、處方、負重、費力程度或休息時間改變，就代表內容已變動。

## DSL 不支援的項目

肌力 DSL 是靜態的單場課表處方，請勿在文字中加入以下內容：

- `if/else` 或可執行邏輯；
- 每週漸進超負荷或減量週規則；
- 巢狀動作區塊；
- 以逗號分隔的屬性；
- 可執行的進度指令碼；
- 備註或教練文字段落。

請將人工指導放入課表備註中。不支援的外部指令碼應保留在原本的系統裡，而不要硬轉為不同的處方。

## 驗證課表

- 課表所選運動項目為**肌力訓練**，而非耐力項目。
- 每個動作都有以雙引號包住的非空白名稱。
- 每個動作都包含至少一個 `work` 群組。
- 次數範圍皆由小到大排列。
- 每個組數群組最多使用一種負重與一種費力模型。
- 預覽區顯示預期的動作與正式組數。
- 重新開啟已儲存課表後仍保有相同含義。

## 疑難排解

| 錯誤或症狀                                                   | 解決方式                                                                                     |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 動作名稱不可為空（Exercise name cannot be empty）            | 在雙引號中填入非空白名稱，例如 `exercise "Back Squat" {`。                                   |
| 肌力課表至少需要一個動作                                     | 新增一個完整的 `exercise` 區塊。                                                             |
| 動作至少需要一組正式組                                       | 新增一行 `work`；僅有暖身群組不算有效動作。                                                  |
| 無效的組數處方                                               | 使用 `3x5`、`3x8-12`、`1x5+` 或計時格式（如 `3x45s`）。                                      |
| 最大次數必須大於或等於最小次數                               | 將 `3x12-8` 改為 `3x8-12`。                                                                  |
| 請擇一使用 RPE 或 RIR，不可同時填寫                          | 從該組數群組行中移除其中一個費力目標。                                                       |
| 無效的重量格式                                               | 寫作 `weight 80kg`、`weight 175lb` 或 `weight 80%1rm`；數值與單位間請勿插入空格。           |
| 不支援的組數屬性                                             | 從該行移除文字敘述、逗號、未知關鍵字或動態邏輯。                                             |
| 動作缺少右大括號                                             | 在該動作的最後一個組數群組之後補上一個 `}`。                                                 |
| 切換運動項目導致編輯器清空或替換                             | 耐力與肌力使用不同結構，切換前請先複製或儲存 DSL。                                           |
