# 產品術語與狀態說明

遇到不熟悉的介面名稱或狀態標籤時，可隨時在此查詢其確切意義與建議的下一步操作。

## 常見核心術語

| 術語 | 意義說明 |
| --- | --- |
| 運動員檔案（Athlete profile） | 用來解讀訓練資料的時區、單位、閾值、訓練區間、偏好設定與運動背景資訊。 |
| 訓練計畫（Training plan） | 包含多堂獨立課表的訓練排程，可先儲存為草稿，準備好再啟用或結束。 |
| 計畫課表（Planned workout） | 針對特定日期預定執行的訓練內容，包含運動類型、課表結構、時間、強度與可用的預期負荷。 |
| 已完成活動（Completed activity） | 從穿戴裝置或第三方平台實際記錄、同步或上傳的訓練紀錄。 |
| 計畫與活動關聯（Plan-to-activity link） | 明確標示某筆已完成活動即對應某堂特定計畫課表的專屬關聯。 |
| 目前狀態（Current state） | 用於輔助今日訓練決策的近期訓練負荷、恢復資料、主觀回饋與其他即時脈絡。 |
| 回顧（Review） | 依據現有訓練證據，對單次活動、單日、單週、單月或整體計畫產出的分析解讀。 |
| AI 操作（AI operation） | 由智能教練提議或執行的訓練調整動作，例如建立、移動或修改計畫課表。 |

## 活動處理狀態

| 狀態 | 代表意義 | 建議操作 |
| --- | --- | --- |
| 上傳中或匯入中（Uploading or importing） | 檔案或第三方平台資料仍在傳輸中 | 先稍候，切勿急著重試 |
| 處理中（Processing） | 活動紀錄已建立，但衍生指標與圖表可能尚未算完 | 暫時不要判讀缺漏的負荷或圖表 |
| 就緒（Ready） | 活動分析已全數完成 | 可正常檢視原始資料所支援的各項分析 |
| 失敗（Failed） | 匯入或分析處理未能完成 | 閱讀畫面上顯示的錯誤訊息，再前往疑難排解 |
| 重複（Duplicate） | 系統已存在相同的來源活動或等效檔案 | 檢查既有紀錄，避免將同一場訓練匯入兩次 |

## 訓練計畫與課表狀態

| 狀態 | 代表意義 |
| --- | --- |
| 草稿（Draft） | 計畫在成為目前排程之前，仍可自由審閱與修改。 |
| 進行中（Active） | 您目前正在遵循的計畫，各課表會顯示於對應排定日期。 |
| 已完成（Completed） | 計畫週期已結束，紀錄仍會保留供日後回顧參考。 |
| 計畫中（Planned） | 課表已排定日期，但尚未產生最終執行結果。 |
| 已完成課表（Completed workout） | 計畫課表已標記完成，通常附帶一筆關聯活動或明確的完成紀錄。 |
| 已略過（Skipped） | 刻意跳過未執行的課表。 |
| 計畫外活動（Unplanned activity） | 不對應任何排定課表的獨立已完成活動。 |

## 訓練負荷、教練回顧與 AI 點數

- **訓練負荷（Training load）**是衍生計算出的訓練劑量估值，是否可用取決於運動類型、持續時間、感測器資料、閾值設定與負荷來源規則。
- **教練回顧（Coach review）**是基於訓練證據產出的輔助解讀，既非原始裝置感測值，也不構成醫療診斷。
- **AI 點數（AI credits）**是符合條件之 AI 操作的用量計量單位。點數帳本記錄的是 AI 額度消耗，與訓練負荷或帳號權限無關。
- **示範帳號（Demo account）**提供範例資料供公開瀏覽。若要儲存修改、匯入活動或管理自己的訓練紀錄，請登入個人帳號。
