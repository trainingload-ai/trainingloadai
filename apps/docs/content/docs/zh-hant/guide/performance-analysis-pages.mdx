# 表現分析頁面總覽

開啟**分析（Analysis）**即可切換至功率、心率、配速、PMC 或其他訓練表現與負荷檢視。透過下方對照表，快速找到能回答您問題的頁面。

## 開始之前

- 等待目標活動達到「就緒（Ready）」狀態。
- 解讀區間分布之前，先確認個人檔案閾值與各項運動專屬區間正確無誤。
- 每次分析鎖定單一運動類型與明確的決策時間區間。
- 確認相關活動包含該頁面所需的感測器資料：功率、心率，或可用的距離與時間紀錄。
- 跨頁面比較數值時，維持相同的單位系統與時區。

## 1. 在「分析」目錄選擇對應頁面

開啟**分析（Analysis）**，搜尋或點選所需工具：

| 想回答的問題 | 對應頁面 | 呈現內容 |
| --- | --- | --- |
| 我練了多少、訓練頻率多穩？ | 活動統計（Activity Stats） | 年度熱力圖與距離、時間、心率、次數或卡路里趨勢 |
| 近期的訓練負荷怎麼變化？ | PMC | CTL、ATL 與 TSB 訓練負荷脈絡 |
| 我最強的持續出力紀錄為何？ | 最佳距離（Best Distance） | 依固定距離或固定時間排序的表現排行 |
| 我的功率能力有什麼進展？ | 功率（Power） | 功率曲線、最大功率、區間分布與功率特徵檔 |
| 單一運動的配速如何演變？ | 配速（Pace） | 配速曲線與配速區間分布 |
| 心率出力與各區間時間分布如何？ | 心率（Heart Rate） | 心率曲線與心率區間分布 |

**進階趨勢（Progression）**卡片目前標示為**即將推出（Coming soon）**。請勿將其視為可用報表，也無須為了它等待，現有分析頁面即可解答大部分核心問題。

## 2. 判讀圖表前先固定篩選條件

在功率、配速與心率頁面中，請先選好運動類型與日期區間，並在切換各分頁比較時保持篩選條件一致：

- 單一日期區間適合回答「目前處於什麼水準」。
- 唯有頁面支援且具備明確對照目的時，才疊加多個日期區間比較。
- 配速頁面必須選定特定運動，不提供「全部運動」混排檢視。
- 功率與心率頁面雖支援檢視全部運動，但混合不同運動的結果通常較難精準解讀。
- 圖表空白往往代表所選區間內沒有符合條件的感測資料。

比較結果時請記下運動類型、持續時間與日期區間。例如，比較最近 90 天與前 90 天的 5 分鐘騎乘功率，會比只盯著單一最高紀錄更有參考價值。

## 3. 善用「功率」各分頁

功率頁面提供四種檢視：

- **曲線（Curve）**：呈現各持續時間最佳功率的表格與圖表，支援多日期區間疊加比較。
- **最大值（Maximum）**：所選篩選脈絡下的最大功率歷史走勢。
- **區間（Zones）**：依設定的功率區間統計訓練分布，支援多區間比較。
- **特徵檔（Profile）**：所選運動與日期區間下的功率特徵輪廓。

「曲線」用於評估特定時長的能力、「區間」用於觀察訓練量如何分配、「特徵檔」則提供能力結構脈絡；三者回答的是不同層面的問題，不應混為一談簡化成單一「體能好壞」結論。

## 4. 運用「配速」與「心率」分析

配速頁面包含：

- **曲線（Curve）**：各距離區間的配速表現表格與圖表。
- **區間（Zones）**：在所設配速區間中的時間或訓練量分布。

依篩選器支援選擇跑步、騎乘或游泳。游泳配速採用游泳專屬距離基準，跑步與騎乘則各自採用相應顯示方式，切勿跨運動直接拿原始配速數字相比。

心率頁面包含：

- **曲線（Curve）**：各時長持續心率數值的表格與圖表。
- **區間（Zones）**：在所設心率區間中的時間分布。

心率屬於身體內部的生理反應訊號，請務必搭配持續時間、配速或功率輸出、天候環境、疲勞程度與感測器品質共同解讀，切勿將較高心率直接視為表現更好。

## 5. 透過 PMC 補齊訓練負荷脈絡

當分析焦點在於累積的訓練壓力時，請開啟**PMC／體能管理（PMC / Fitness management）**。選定運動類型，同時判讀目前的 CTL、ATL 與 TSB 卡片，並在狀態（Form）、體能（Fitness）與疲勞（Fatigue）之間切換圖表。單日負荷面板與日期提示框能協助釐清每個點位的變化原因。

頁面清楚區分已記錄的歷史數據與可用的未來推估。解讀未來日期的數值前，請先查看該日的負荷估算依據；缺少預測不代表負荷為零。完整操作流程、資料需求與儀表板歷史分頁用法，請參閱[解讀 PMC 歷史與預測](/zh-hant/docs/guide/pmc-forecast)。

若想檢視能力反應歷史與獨立的四周趨勢展望，請參閱[理解有效 VO2max](/zh-hant/docs/guide/effective-vo2max-for-endurance)；接著搭配[訓練分析工作流程](/zh-hant/docs/guide/training-analysis-workflow)將所有證據串聯到訓練計畫回顧中。

## 6. 將分析結果追溯回原始證據

當某個曲線點位、區間比例或負荷變化影響決策時，請依序核實：

1. 記下運動類型、日期區間、分頁、持續時間與具體數值。
2. 點開相關活動，或透過活動搜尋找出最可能的來源課表。
3. 確認處理狀態、感測器覆蓋率、個人閾值，並排查明顯的飄移尖峰或斷訊。
4. 清楚區分客觀觀測結果與主觀解讀推論。
5. 只做出現有證據足以支撐的最小幅度調整決策。

## 驗證分析嚴謹度

- 所選頁面確實符合本次要回答的問題。
- 已記錄運動類型、時間區間、單位系統與區間設定。
- 分析結論建立在符合資格且狀態為「就緒」的活動上。
- 感測資料缺口或異常極值已被明確標註，而非悄悄被平均稀釋。
- 任何訓練調整決策都能回溯到具體的底層活動與計畫脈絡。

## 疑難排解

- **分析頁面搜尋不到結果**：清除搜尋關鍵字；工具搜尋比對的是目前介面語系的標題與說明。
- **卡片無法點擊開啟**：檢查該卡片是否標示為「即將推出（Coming soon）」。
- **曲線或區間圖表一片空白**：放寬日期區間、核對所選運動，並確認有效活動確實包含所需的感測資料流。
- **修改閾值後數值全變了**：訓練區間分布與衍生脈絡會隨閾值重算；比較歷史時期前請先記錄新設定。
- **功率、配速與心率說法互相矛盾**：它們量測的是不同的輸入輸出與生理反應；請重新審視分析問題、來源課表與當天環境條件，不要只挑看起來最順眼的那張圖。
- **全部運動的彙總結果顯得雜亂不一致**：切換回單一運動類型後重新比較。
