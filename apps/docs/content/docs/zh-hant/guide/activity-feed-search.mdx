# 活動動態與搜尋

活動動態是 Trainingload.ai 中管理所有已完成訓練的核心清單，整合了自動同步活動、手動上傳檔案、地圖預覽、訓練負荷數值以及訓練計畫關聯。

當您想回答以下問題時，這裡就是最佳起點：

- 我最近練了哪些課表？
- 剛匯入的活動是否已經進來了？
- 還有哪些訓練尚未回顧？
- 這筆活動是否正確連結到對應的訓練計畫課表？
- 要從哪裡進入活動詳情頁做更深入的分析？

## 開始之前

- 先連接第三方平台或[上傳活動檔案](/zh-hant/docs/guide/upload-activity-files)。
- 搜尋特定匯入紀錄時，先掌握大致的活動日期、運動類型與來源平台。
- 若打算關聯訓練計畫課表，請確認目標計畫已啟用，且活動日期落在計畫期間內。

## 檢視工作流程

1. 開啟**活動（Activities）**並重新整理動態清單。
2. 檢查最新出現的活動卡片與處理狀態。
3. 透過時間、運動類型或其他可見篩選條件縮小清單範圍。
4. 在判斷是否缺少指標或訓練負荷之前，先點開活動詳情頁確認。
5. 核對日期、運動類型與課表目的無誤後，再將活動連結至計畫課表。

## 活動動態清單

開啟**活動（Activities）**即可檢視近期的訓練紀錄。每張活動卡片可顯示以下資訊：

- 活動標題。
- 運動類型。
- 開始時間。
- 距離與持續時間。
- 訓練負荷（若有資料）。
- 資料來源平台，例如 Garmin、Strava 或手動上傳。
- 活動狀態。
- 地圖縮圖（當具備路線資料時）。
- 計畫課表連結（當活動日期落在進行中訓練計畫期間內時）。

向下捲動清單會自動載入更多紀錄；在行動 App 上，於清單頂端下拉即可重新整理。

## 活動狀態

活動卡片可能會顯示以下狀態：

- **已同步（Synced）**：已匯入或同步至 Trainingload.ai。
- **待回顧（Pending review）**：資料已可用，但尚未進行回顧。
- **已回顧（Reviewed）**：已完成回顧或已通過回顧流程。
- **未知（Unknown）**：暫時無法取得狀態資訊。

狀態標籤有助於快速分類與整理清單，但無法取代活動詳情頁。當圖表、詳細指標或處理結果很關鍵時，請務必點開活動本身檢視。

## 搜尋與篩選

當動態清單範圍過大時，可使用活動搜尋功能快速定位。

常用快速篩選條件包含：

- 近 7 天。
- 近 30 天。
- 跑步。
- 騎乘。
- 游泳。

善用搜尋頁面上顯示的篩選條件縮小結果範圍。若找不到某筆活動，請清除篩選條件、放寬日期區間，並核對其運動類型與資料來源。

## 開啟活動詳情

當摘要卡片提供的資訊不足以回答問題時，請點開活動進入詳情頁。

在活動詳情頁中，您可以完整檢視：

- 完整摘要指標。
- 圖表與時間序列資料。
- 路線與地形脈絡。
- 訓練負荷與強度分布。
- 心率、功率、配速與海拔訊號。
- 針對該筆訓練的智能教練提問入口。

詳情請參閱[活動詳情](/zh-hant/docs/guide/activity-detail)。

## 將活動連結至訓練計畫課表

當帳號有進行中的訓練計畫，且活動日期落在計畫期間內時，活動卡片會顯示計畫連結控制項。

透過這個功能，即可把實際完成的訓練關聯到對應的計畫課表。

完成關聯非常重要，因為 Trainingload.ai 才能準確比較：

- 計畫課表與實際完成活動的差異。
- 預期負荷與實際負荷。
- 課表完成狀態。
- 計畫執行度。
- 智能教練後續的計畫追蹤建議。

如果連結到了錯誤的課表，請先解除關聯，再手動選擇正確的課表。

## 匯出或刪除活動

活動卡片選單可提供以下操作：

- **檢視（View）**：開啟活動詳情頁。
- **匯出（Export）**：在支援的情況下，將活動下載為 GPX、FIT 或 TCX 檔案。
- **刪除（Delete）**：經確認後移除該筆活動紀錄。

執行刪除前請務必謹慎。若活動已連結至訓練計畫課表，刪除該活動會影響計畫執行摘要與訓練負荷比較結果。

## 地圖入口

活動頁面提供地圖入口，點擊後可開啟地圖檢視。當路線脈絡很重要時，建議切換到地圖頁面：

- 比較不同次的訓練路線。
- 回顧訓練進行的地點分布。
- 透過視覺方式快速尋找含 GPS 的活動。
- 檢查路線軌跡是否不完整或出現異常偏移。

地圖非常適合掌握地理位置與路線脈絡，而深入判讀數值指標仍應以活動詳情頁為主。

## 疑難排解

若找不到某筆活動：

- 確認匯入批次是否已處理完成。
- 重新整理活動動態清單。
- 以更寬的日期範圍進行搜尋。
- 確認來源平台確實存有該筆訓練紀錄。
- 檢查活動是否曾遭刪除或被目前的篩選條件排除。

若缺少訓練負荷或圖表：

- 開啟活動詳情頁並檢查處理狀態。
- 確認原始檔案包含所需的感測器資料。
- 檢查個人檔案中的閾值與訓練區間設定。
- 若活動剛剛才上傳，請等待系統分析完成。

## 驗證結果

- 目標活動僅出現一次，且開始時間、運動類型與來源平台皆正確。
- 點擊卡片可順利開啟預期的活動詳情頁。
- 已關聯的活動對應的是正確的計畫課表，而非只是日期相近的其他項目。
- 清除篩選條件後，活動不會意外消失。
- 匯出或刪除動作皆僅對已確認的目標活動執行。
