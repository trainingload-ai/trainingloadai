# 影子活動：為什麼只看得到摘要？

**影子活動（Shadow activity）是指系統已偵測到存在、但目前仍無法取得完整時間序列紀錄的活動。**Trainingload.ai 會先保留該活動的標題與開始時間，讓您確定這筆訓練沒有被遺漏，同時提示接下來可執行的處理操作。

影子活動並非完整匯入的活動。系統不會憑空從摘要捏造圖表或訓練負荷。一旦後續成功匯入完整資料，該筆影子活動就會自動升級為完整活動；相反地，如果帳號裡已經有一筆完整紀錄，即使之後某次同步抓不到資料，系統也不會把原本的完整紀錄清空。

目前主要有以下兩種常見情境：

## 情境一：Intervals.icu 有活動摘要，但無法提供原始檔案

Intervals.icu 可以顯示來自 Strava 的活動摘要，但其 API 明確限制外部服務下載這類活動的原始檔案。因此，即使在 Intervals.icu 上看得到這筆訓練，也不代表 Trainingload.ai 能透過該 API 取得完整紀錄。

遇到這種情況時，Trainingload.ai 會嘗試直接向 Strava 擷取資料。請依卡片提示連接 Strava、重新授權或開啟活動匯入開關，並等待同步完成。

如果 Strava 端同樣無法提供所需資料，這筆紀錄就會維持影子活動狀態。反覆手動同步 Intervals.icu 無法繞過其對原始檔案的 API 限制。

## 情境二：Strava 有活動詳情，但無法提供感測資料流

活動名稱、總距離與總時間，與每秒記錄的 GPS、心率、功率或距離時間序列屬於不同層級的資料。**看得到活動詳情，並不保證存在可供匯入的感測資料流（streams）。**

- **原本就不存在採樣資料**：例如在 Strava 上純手動輸入距離與時間、沒有透過運動裝置記錄的活動。這類活動會有詳情頁，但無論重試多少次都不會憑空生出採樣資料。
- **紀錄暫時無法取得**：來源平台可能仍在處理該筆上傳，或詳細資料 API 暫時異常。單一次「找不到」回應並不代表活動已被刪除或永久缺乏資料流。

針對狀態不明的暫時性失敗，Trainingload.ai 會進行有限次數的自動重試。若資料仍持續無法取得，系統會保留影子活動並提供手動重試入口。請留意，單純缺少心率、功率或 GPS 不一定會變成影子活動——只要活動具備可用的時間序列資料，仍會正常匯入，僅缺少對應的特定分析分頁。

## 我該怎麼處理？

| 已知狀況 | 建議操作 |
| --- | --- |
| 卡片提示需要連線、重新授權或開啟匯入 | 完成畫面指示的設定，接著等待同步或點擊重試。 |
| 活動剛剛上傳，或來源平台仍在處理中 | 等待原平台處理完成後，再手動重試一次。 |
| 來源平台的暫時性故障已排除 | 點擊重試一次，重新請求完整活動紀錄。 |
| 該活動為手動輸入，原本就沒有感測採樣 | 重覆重試沒有幫助；請尋找是否另有運動裝置記錄的原始檔案。 |
| 多次嘗試後依然維持影子活動 | 檢查原始平台是否能匯出活動檔案；必要時聯繫技術支援。 |

重試只會重新向來源平台請求資料，並不保證對方現在就能提供。處理前您無須先刪除影子活動或既有完整活動；反覆中斷並重新連接第三方平台也無法憑空補出不存在的採樣資料。

## 我手邊有原始活動檔案

如果您的運動裝置或最初記錄這筆訓練的平台可以匯出包含完整紀錄的 FIT、TCX 或 GPX 檔案，請直接透過[上傳活動檔案](/zh-hant/docs/guide/upload-activity-files)匯入。若系統提示重複，請核對日期與內容再決定是否覆蓋。

## 尋求協助

聯繫支援時，請提供活動日期、來源平台、畫面上顯示的提示訊息，以及原平台是否可匯出原始檔案；切勿傳送存取權杖或密碼。更多排錯指引請參閱[疑難排解](/zh-hant/docs/guide/troubleshooting)。
