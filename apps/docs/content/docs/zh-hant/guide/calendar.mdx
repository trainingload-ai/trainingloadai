# 在訓練日曆中對照計畫課表與實際訓練

訓練日曆將未來的課表安排與實際完成的訓練放進同一個日期脈絡中。同一天裡的計畫課表與實際活動屬於兩筆獨立紀錄，必須透過詳情與關聯設定，才能確認這筆活動是否就是該計畫課表的實際執行紀錄。

[在示範帳號中開啟訓練日曆](https://demo.trainingload.ai/en/calendar)。以下截圖取自真實網頁版中的範例計畫與活動資料。您可在示範環境中切換至對應日期檢視；若要儲存關聯或修改排程，則需登入自己的帳號。

## 開始之前

先確認帳號時區與活動開始時間是否一致；若有計畫訓練，請核對進行中計畫的開始日期與課表排程。匯入活動後請先等待處理完成，再判斷是否缺少負荷數值或分析結果。

在網頁版與 macOS 版 Trainingload.ai Personal 中，從側邊欄開啟**訓練日曆（Calendar）**；在窄螢幕網頁上，點選日曆按鈕即可開啟月份選擇器；在行動 App 中，則切換至**訓練日曆（Calendar）**分頁。

## 1. 尋找並選取目標日期

在寬螢幕上直接捲動日曆，或透過月份選擇器與箭頭切換月份。點選任一日期即可展開當日面板，點擊**今天（Today）**可快速跳回今日。

您選取的日期決定了當日面板呈現的內容。同一天可能同時包含計畫課表、獨立排定的課表、實際記錄的活動，或三者的組合。點開任何項目前，請先看清項目標籤。

## 2. 閱讀當日面板

切換至**訓練（Training）**分頁可檢視排定課表，切換至**活動（Activities）**分頁則可檢視實際記錄到的活動。請同步核對所選日期、顯示的負荷數值與項目數量；若需要更完整的單日檢視，請點選**檢視當日（View day）**。

| 紀錄類型 | 比較前先確認 |
| --- | --- |
| 計畫課表 | 訓練目的、排定日期、運動類型、課表結構、備註與執行狀態。 |
| 已完成活動 | 開始時間、資料來源、運動類型、實際時間／距離、處理狀態與感測器覆蓋情形。 |
| 兩者關聯 | 是否確實將正確的活動連結至預期的計畫課表。 |

單靠「已完成」標籤無法判斷實際執行品質。請點開[活動詳情](/zh-hant/docs/guide/activity-detail)檢視真實的出力表現。

## 3. 將正確的活動關聯至計畫課表

在自己的帳號中，開啟排定課表的詳情頁並點選**關聯活動（Link activity）**：

1. 確認該課表已排定日期且運動類型正確。
2. 先在活動詳情頁確認該筆紀錄的開始時間；在系統列出的當日候選清單中，比對標題與持續時間以辨識正確紀錄。
3. 選取對應的活動紀錄並等待成功提示。
4. 若該活動原本已關聯至另一堂計畫課表，請先仔細閱讀**取代關聯？（Replace link?）**確認視窗再決定是否覆蓋。
5. 重新開啟課表與活動詳情，確認關聯狀態正確。

若清單中沒有出現候選活動，請檢查資料同步狀態、活動的本地日期、課表排程與運動類型。請先排除這些差異，切勿隨意關聯不相關的活動。

若要修正錯誤關聯，可在現有關聯處點擊**移除關聯（Remove link）**或改選正確活動。請注意，移除關聯與刪除活動的效果完全不同。示範帳號會停用這些寫入操作。

## 4. 比較計畫內容與實際執行

比較時請先看訓練目的與課表結構，再對照實際的持續時間、距離、強度與可用訓練負荷。若課表遭縮短、替換或略過，建議記下原因；計畫外多做的額外活動同樣屬於真實訓練刺激。

若預期負荷或實際負荷顯示缺漏，這是需要排查的資料狀態，而非代表負荷為零。請先檢查閾值、運動類型與處理狀態。關於標記完成、略過、順延與其他課表執行操作，請參閱[管理進行中的訓練計畫](/zh-hant/docs/guide/manage-active-plan)。

## 5. 確認摘要統計範圍

訓練日曆可提供**計畫（Plan）**與**月份（Month）**兩種摘要統計。比較次數、距離、時間或負荷之前，請先看清目前啟用的統計範圍與顯示的日期邊界。

計畫進度對應的是目前進行中的訓練週期；月份總覽則對應畫面上顯示的日曆月份。兩者的比較視窗不同，請務必依據畫面標示的情境解讀，切勿誤以為所有摘要都在描述同一段期間。

更全面的週期檢討請參考[每週訓練回顧](/zh-hant/docs/workflow/weekly-review)；若想評估長期累積負荷與條件式走勢預測，請參閱 [PMC 預測](/zh-hant/docs/guide/pmc-forecast)。

## 檢查結果

所選日期、當日面板與點開的各項紀錄都應呈現一致的日期；計畫課表與實際活動應具備正確的關聯狀態；任何訓練負荷比較都應明確標註統計範圍與缺漏資料。

## 調整後續課表 [#adjust-upcoming-workouts]

1. 擁有進行中的訓練計畫時，在網頁版或 Personal 的月曆上對任一日期按右鍵，選擇**調整排程（Adjust schedule）**。
2. 將未來的課表拖曳到其他日期，或對課表按右鍵選擇**移動課表（Move workout）**指定新日期。透過課表選單的**編輯課表（Edit workout）**可修改內容；透過日期選單可新增課表，透過課表選單則可移除課表。編輯器會將這些變動集中成一份草稿。
3. 核對配對顏色以及**調整前（Before）**與**調整後（After）**標記。點選**檢視變更（Review changes）**，確認無誤後按**確認計畫變更（Confirm plan changes）**批次套用。若想稍後再完成，關閉編輯器時選擇**儲存草稿（Save draft）**，之後再從**調整排程**重新開啟待套用的草稿即可。
4. 重新開啟訓練日曆，確認新的日期與課表內容。若在確認前排程已被其他裝置異動，請點選**載入最新排程（Load latest schedule）**並重新審閱剩餘可套用的修改。

在窄螢幕上，可透過課表選單或拖曳手把在月曆格線中移動課表。過去的、已完成的或已關聯活動的課表可能受到保護而無法重新排程。

若只想在主日曆上移動單一課表，直接拖曳至新日期或由課表選單選擇**移動課表**，在預覽畫面核對日期後點選**確認調整（Confirm adjustment）**即可。

當智能教練對話中出現**檢視課表日曆（View workout calendar）**時，可直接於對話內開啟預覽、審閱或修改支援的變更，並在確認前驗證已儲存的草稿。

## 常見問題

### 為什麼活動出現在不同的日期？

請比較活動開始時間、活動時區與帳號的顯示時區，再核對計畫起始日與排定日期。確認日期無誤後再決定是否移動課表。

### 為什麼看不到計畫課表？

請檢查目前進行中的訓練計畫、計畫起訖範圍，以及該堂課表的排程與狀態。已挪動日期或標記略過的課表可能不再出現在原本預期的位置。

### 為什麼同一場訓練會顯示兩筆紀錄？

計畫課表與實際活動原本就是兩筆分開的紀錄，請確認兩者是否已正確關聯。若畫面上出現了兩筆「實際活動」，刪除前請先排查第三方平台轉發設定或重複匯入原因。

### 為什麼在示範帳號中無法關聯活動？

示範環境僅供瀏覽範例；建立關聯與調整排程需要對應的個人帳號權限。

### 如果變更遭到系統拒絕怎麼辦？

請詳讀錯誤訊息，重新整理最新的計畫或活動狀態後再重試，最後確認預期的關聯或排程確實已更新。
