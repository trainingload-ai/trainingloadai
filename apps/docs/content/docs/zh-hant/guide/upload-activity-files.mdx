# 上傳活動檔案

手動上傳從運動手錶、車錶或第三方訓練平台匯出的活動檔案，即可在 Trainingload.ai 中檢視活動詳情、感測圖表與訓練負荷。以下步驟適用於網頁版。

## 準備您的活動檔案 [#before-uploading]

系統支援 FIT、TCX 與 GPX 格式的訓練檔案，單次最多可同時上傳 100 個檔案。從穿戴裝置或原平台匯出的原始檔案，最能完整保留心率、功率與路線資料。

## 從「活動」頁面執行上傳

1. 點擊左側欄的**活動（Activities）**開啟活動頁面。
2. 在最右側的**上傳活動檔案（Upload activity files）**卡片中，點擊**選擇活動檔案（Choose activity files）**。

上傳後系統會自動開啟匯入進度視窗，逐一顯示每個檔案的處理結果。

## 追蹤匯入進度 [#import-statuses]

檔案在背景匯入期間，您可以繼續瀏覽其他頁面。若不小心關閉進度視窗，在「活動」頁面點擊**匯入進度（Import Progress）**即可重新開啟。

| 顯示狀態 | 建議操作 |
| --- | --- |
| 排隊中（Queued）、正規化中（Normalizing）、實體化中（Materializing）、建立分析中（Building analysis） | 檔案仍在背景處理中，請稍候匯入完成。 |
| 完成（Done） | 返回「活動」頁面即可檢視該筆紀錄。 |
| 已略過（Skipped） | 帳號中通常已存在相符紀錄，請直接於「活動」頁面查找。 |
| 失敗（Failed）、終止（Dead） | 閱讀該檔案旁的錯誤說明，並參考下方疑難排解。 |

## 查找已匯入的活動 [#after-upload]

匯入完成後，點擊左側欄的**活動（Activities）**，依訓練日期找到該筆紀錄並點開詳情，即可檢視持續時間、距離、圖表與訓練負荷。

詳細介面導覽請參閱[活動動態與搜尋](/zh-hant/docs/guide/activity-feed-search)與[活動詳情](/zh-hant/docs/guide/activity-detail)。

## 疑難排解

### 「上傳」按鈕處於停用狀態

請先選取至少一個檔案。若系統正在檢查檔案格式，請稍候片刻；若某個檔案顯示錯誤訊息，請依提示修正或移除該檔案後再重試。

### 看到重複紀錄警告

若該筆訓練已存在於「活動」清單中，可直接保留既有紀錄或取消本次上傳；唯有確定需要留存一份獨立複本時，才選擇強制重新匯入。

### 檔案上傳或匯入失敗

請先閱讀該檔案旁的錯誤訊息。建議回到裝置或原平台重新匯出原始 FIT、TCX 或 GPX 檔案，再單獨上傳該檔案測試。請留意，單純手動修改副檔名並不會轉換檔案格式。

螢幕截圖、一般 CSV 試算表以及僅包含全天健康數據的 FIT 檔，皆無法透過此處匯入為運動活動紀錄。

### 匯入的紀錄缺少心率、功率或路線圖

請先等待活動處理完全結束。各類圖表都仰賴原始檔案中確實存有對應採樣資料（例如無 GPS 的室內訓練自然不會有路線圖）。建議回原始平台確認，並嘗試重新匯出原始活動檔案。

## 需要轉換其他檔案格式嗎？ [#convert-between-formats]

上傳功能原生支援 FIT、TCX 與 GPX，一般情況下無須先行轉檔。若您需要將檔案轉換給其他平台使用，可利用 [FIT、GPX 與 TCX 轉檔工具](/zh-hant/converter)。
