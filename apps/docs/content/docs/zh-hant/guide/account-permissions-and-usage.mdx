# 帳號、權限、資料匯出與 AI 用量

帳號設定負責管理身分與存取權；權限決定哪些裝置與第三方平台的資料能匯入 Trainingload.ai；用量則說明會員方案與 AI 額度消耗情形。在設定新裝置或排查缺少的功能時，建議一併檢視這三項設定。

本頁內容適用於雲端帳號。自架版（Self-host）採用本機個人帳號，相關設定請參閱[自架設定說明](/zh-hant/docs/self-host/configuration)。

## 開始之前

- 在網頁版與行動 App 上登入同一個 Trainingload.ai 帳號。
- 確認可存取帳號電子郵件以收取驗證碼。
- 在行動裝置上，先確認作業系統是否已拒絕「健康」或「定位」存取權限。
- 在開啟任何開關之前，先決定哪些閾值指標允許系統自動更新。
- 請勿外洩驗證碼、密碼、連線憑證，或任何包含私人帳號識別資訊的螢幕截圖。

## 1. 驗證身分與密碼狀態

在網頁版中開啟**帳號（Account）**；在行動 App 中開啟**我的 → 選單 → 帳號（Me → Menu → Account）**。

您可以在此檢視：

- 顯示名稱。
- 帳號電子郵件與驗證狀態。
- 是否已設定密碼。

目前的電子郵件欄位為唯讀。如果帳號尚未驗證，請申請一組六位數驗證碼並在到期前輸入。在網頁版中，寄出的驗證碼有效期限為五分鐘，倒數計時結束前無法重新發送。

若帳號尚未設定密碼，請使用**設定密碼（Set password）**；若已設定，則使用**變更密碼（Change password）**。透過 OAuth 登入的帳號仍可能顯示尚未設定密碼，請直接使用畫面上提供的密碼操作，不需誤以為帳號異常。

### 恢復存取權與完成登入

在登入頁面點擊**忘記密碼（Forgot password）**即可申請重設密碼郵件。請務必開啟最新收到的重設連結，確認畫面導回 Trainingload.ai 的重設密碼頁面後再設定新密碼。過期、格式損毀或已使用過的權杖必須重新申請重設連結。

OAuth 登入過程中可能會先經過完成畫面或錯誤畫面再返回應用程式。若完成畫面沒有自動跳轉，請回到登入頁重試一次；若出現錯誤頁面，請記錄畫面上顯示的錯誤訊息文字，但切勿分享權杖或完整的回呼 URL。

當其他應用程式請求存取 Trainingload.ai 時，OAuth 授權同意頁面會顯示請求存取的應用程式、已登入的帳號、要求的權限範圍（scopes）以及返回目的地。唯有在四項資訊皆符合您的預期時才點擊核准；拒絕授權會返回原處且不會授予所請求的存取權。

## 2. 檢視行動裝置權限與資料來源 [#2-review-mobile-permissions-and-data-sources]

開啟**我的 → 選單 → 資料授權（Me → Menu → Data authorization）**或行動版**權限（Permissions）**頁面。資料來源分為本機裝置來源與第三方服務兩大類。

本機來源包含：

- **健康（Health）**：授權讀取支援的健康與訓練紀錄、檢視已授予或部分授予狀態、發起歷史資料同步、管理已連線的裝置，或前往系統「健康」設定。
- **定位（Location）**：允許記錄運動路線，或在權限曾遭拒絕後前往系統設定重新開啟。

第三方來源可包含 Strava、Polar、COROS、Suunto、Wahoo 與 Intervals.icu。每個來源列都會顯示目前的連線狀態。點開任一來源即可建立連線、檢視該平台的專屬設定，或繼續前往連線管理頁面。

裝置權限與伺服器連線屬於兩種獨立狀態。作業系統可能已經授權「健康」存取，但 Trainingload.ai 的裝置連線仍需要重新建立。從系統設定返回 App 後，請重新開啟該來源詳情頁面，讓應用程式同時重新整理兩者的狀態。

## 3. 控制指標自動更新

在網頁版或行動 App 中開啟**帳號 → 自動更新（Account → Auto update）**。每個開關分別控制一項指標的自動更新授權：

| 群組 | 指標 |
| --- | --- |
| 功率 | FTP、CP、W′、Pmax |
| 配速 | TP、CS |
| 心率 | LTHR、Max HR |

請只開啟您希望 Trainingload.ai 依據有效訓練證據自動更新的指標。開啟開關並不保證立刻產生新數值，系統仍需要足夠且符合條件的活動資料。

自動更新會改變訓練區間、圖表、結構化課表與負荷解讀所使用的閾值基準。每次閾值更新後，建議先檢視指標歷史紀錄並回顧近期一次訓練活動，再比較新舊時期的表現。

## 4. 檢視會員方案與 AI 用量

帳號頁面中的會員卡片會顯示：

- 目前方案與啟用狀態。
- 會員週期或到期資訊。
- 帳單來源。
- 是否已排定於本期結束後取消續訂。

唯有透過支援的訂閱帳單來源建立的啟用中訂閱，才會顯示 App 內的訂閱管理操作。其他取得存取權的管道可能僅顯示會員狀態，而不會出現相同的管理控制項。

從會員卡片或行動版帳號區域開啟**用量（Usage）**，頁面會顯示：

- 目前方案。
- 可用點數（當最近一次已完成的操作超出先前餘額時，可能顯示為負值）。
- 本月訂閱點數的已用額度、剩餘額度與到期時間。
- 可用或受會員鎖定的點數包餘額及其最近到期日。
- 未結清欠額、消耗趨勢、操作次數與逐筆帳本明細。

您可以切換檢視 1 天、7 天、30 天、本月迄今或上個月。帳本明細會標示標準模式（1×）、深度模式（3×）、混合模式操作、訂閱發放、點數包、贈送、退款與欠額抵扣。每 1 點代表在套用快取輸入、非快取輸入、輸出、模式與全域倍率後的 1,000 個等效 Token，並非固定的對話訊息則數。

## 5. 設定應用程式偏好

在網頁版開啟**設定（Settings）**，可自訂以下項目：

- 淺色、深色或跟隨系統主題；
- 公制或英制單位；
- 圖表 X 軸顯示方式；
- 12 小時制或 24 小時制時間顯示；
- 偏好介面語言。

這些設定在按下**儲存（Save）**之前皆為暫存值。變更語言會將目前頁面導向所選語系，並記錄此偏好供後續造訪使用。單位與時間格式只影響畫面呈現方式，不會改寫底層的原始活動紀錄。

## 6. 匯出帳號資料

在網頁版開啟**帳號 → 資料匯出（Account → Data export）**，依照後續用途選擇適合的匯出類型：

- **AI 分析（AI analysis）**：建立精簡的分析導向封裝檔，不包含原始上傳檔案。
- **完整備份（Full backup）**：建立更完整的封存檔，且在保留精確位置資料時可包含原始檔案。

在送出匯出請求前，請先決定路線位置資料的處理方式：

- 遮蔽常去地點；
- 移除 GPS 資料；
- 保留精確位置。

選擇包含原始檔案時，系統會強制保留精確位置處理方式，因為原始檔案本身可能即內嵌定位資訊。請將含精確位置的匯出檔視為敏感資料；在未完全瞭解封存檔內容之前，切勿上傳至外部 AI 服務或分享給他人。

資料匯出採非同步處理。您可以停留在頁面或稍後返回，重新整理最新任務狀態，待狀態轉為**就緒（Ready）**後再下載封存檔。頁面會顯示檔案大小與過期時間。狀態為就緒、失敗或過期的匯出任務皆可從清單中移除。

## 7. 安全地刪除帳號

帳號刪除屬於永久性且非同步執行的操作。在行動 App 啟動刪除流程前，請依序完成以下步驟：

1. 匯出所有需要保留的資料。
2. 檢視畫面上顯示的會員狀態與帳單供應商。
3. 若流程要求，先取消自動續訂。
4. 仔細閱讀並勾選所有最終確認項目。
5. 送出刪除請求，並等待出現已受理畫面後再離開流程。

送出請求後，系統會登出帳號並撤銷作用中的存取權，同時在背景持續執行刪除作業。一般預計於 24 小時內完成，最長可能需要 7 天。已受理畫面會導回登入頁，但這並不表示舊帳號可以復原。

訂閱處理方式取決於目前的帳單來源。網頁端計費的續訂可能需要先取消，才能繼續執行刪除。透過 Apple 計費的續訂由 Apple 端管理，即使刪除 Trainingload.ai 帳號，仍需另外前往 Apple 取消訂閱，否則可能持續扣款。刪除帳號本身不代表自動退款，日後重新購買訂閱也無法還原已刪除的資料。

## 8. 驗證跨裝置設定

變更帳號、平台連線、權限或自動更新設定後，建議依以下步驟確認：

1. 在目前裝置上儲存或完成該項操作。
2. 返回來源清單並確認顯示狀態正確。
3. 重新整理另一台裝置的畫面。
4. 確認兩端登入的是同一個帳號電子郵件，且伺服器端設定已同步更新。
5. 針對本機權限，請在授予權限的該台裝置上檢查作業系統狀態；本機權限不會自動移轉至另一支手機。

## 驗證設定結果

- 網頁版與行動 App 顯示相同的帳號電子郵件。
- 電子郵件驗證狀態與密碼狀態符合預期的登入方式。
- 「健康」與「定位」顯示預期的裝置端權限狀態。
- 第三方平台顯示預期的伺服器連線狀態。
- 僅開啟您計畫允許自動更新的指標開關。
- 會員狀態與用量帳本和近期的額度發放或 AI 操作紀錄一致。
- 已申請的資料匯出順利達到「就緒」狀態，能於過期前完成下載，且符合所選的位置隱私設定。
- 重新開啟設定頁後，主題、單位、圖表、時間格式與語言設定皆已保留。

## 疑難排解

- **驗證碼無法使用**：確認已完整輸入六位數、核對電子郵件並檢查是否過期；待重發按鈕恢復可用後再申請新的驗證碼。
- **無法編輯電子郵件**：目前的帳號介面未開放變更電子郵件，該欄位刻意設計為唯讀。
- **「健康」已授權但未連線**：重新開啟「健康」來源頁面，檢查 App／伺服器／裝置的連線狀態，並在畫面提供選項時執行重新連線。
- **「定位」持續處於拒絕狀態**：前往作業系統的應用程式設定開啟權限；先前被拒絕的權限可能不會再次彈出系統提示框。
- **完成 OAuth 後平台仍顯示未連線**：重新整理來源狀態、確認登入同一個 Trainingload.ai 帳號，並檢查該平台的專屬設定。
- **自動更新指標沒有變化**：確認對應開關已開啟，且近期符合條件的訓練活動包含足夠的支援資料。
- **用量頁面看起來是空的**：放寬查詢日期範圍，並確認該帳號曾有 AI 額度發放或消耗事件。
- **無法在 App 內管理會員方案**：僅支援特定啟用中訂閱來源的 App 內管理；請核對畫面上顯示的帳單來源。
- **無法啟動新的匯出請求**：等待目前的匯出任務完成後，重新整理頁面再重試。
- **匯出檔案已過期**：移除過期的匯出任務，並依照所需的位置隱私選項重新申請封存檔。
- **帳號刪除因訂閱狀態受阻**：依刪除流程中顯示的供應商專屬續訂步驟操作後再重新整理狀態。若為 Apple 計費，請另外透過 Apple 取消續訂。
- **重設密碼連結遭到拒絕**：重新申請重設郵件並使用最新收到的連結，切勿重複使用已失效或過期的權杖。
- **OAuth 授權同意頁面看起來很陌生**：請拒絕該請求，並重新核對請求存取的應用程式、權限範圍、帳號與返回目的地後再決定是否重試。
- **偏好設定看似未生效**：按下「儲存」後重新開啟設定頁；本機顯示偏好與伺服器端的語系設定可能於不同時間點完成重新整理。
