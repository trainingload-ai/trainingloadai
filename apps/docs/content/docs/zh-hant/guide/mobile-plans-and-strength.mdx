# 在行動 App 建立訓練計畫並完成肌力訓練

您可以直接在手機上建立訓練計畫草稿，或點開已排定的肌力訓練課表、逐組記錄實際完成的組數與重量。本指南涵蓋這兩項完整流程。

## 開始之前

- 登入行動 App，並確認「計畫（Plan）」分頁能正常載入您的帳號資料。
- 先想好訓練計畫的週期長度與簡短名稱。
- 若包含肌力課表，先確認欲安排的訓練動作與現場可用器材。
- 建議先建立草稿，待審閱整份排程無誤後再啟用。

## 1. 選擇建立計畫的方式

開啟**計畫（Plan）**，點選**建立計畫（Create plan）**，再選擇：

- **手動（Manual）**：由您親自編排每一堂耐力或肌力課表。
- **AI**：填寫訓練目標與限制條件，接著交由智能教練接續對話規劃。

本教學後續步驟以**手動**建立為主。

## 2. 填寫計畫基本資訊

輸入計畫名稱、選擇 1 至 24 週的計畫週期，並可選擇在簡介中記錄訓練原則、限制條件或執行重點。請確認名稱與週期正確後再往下一步；日後若縮短週期長度，不可留有超出新範圍的課表。

## 3. 編排每週課表

捲動瀏覽排程並點開需要安排課表的日期。同一天可安排多堂課表，透過課表序號控制執行順序。

可選擇以下兩種課表結構：

- **耐力訓練（Endurance）**：跑步、騎乘、游泳或伸展步驟。可使用視覺化手動模式編排步驟，或使用 DSL 模式輸入支援的文字語法。
- **肌力訓練（Strength）**：編排各訓練動作，並設定熱身組／正式組、組數、次數或持續時間、負重、出力程度與組間休息。

編排每堂課表時請依序確認：

1. 核對所屬週次、星期幾與當日課表順序。
2. 給予容易辨識的課表名稱。
3. 將指導要點寫在「備註（Notes）」欄位。
4. 建立並驗證耐力或肌力課表結構。
5. 將課表儲存回訓練計畫草稿。

## 4. 審閱並儲存草稿

至少新增一堂課表後即可進入審閱頁面。逐一核對總週數、課表總數、訓練天數以及依時間順序排列的整體排程。按下儲存後，新計畫會保持為草稿狀態，方便您在啟用前反覆檢查。

開啟計畫詳情頁，確認每堂課表都落在正確的相對天數。準備好正式執行時，請先參閱[管理計畫狀態](/zh-hant/docs/planning/plan-lifecycle)再行啟用。

## 5. 開始執行已排定的肌力課表

當肌力課表準備開始時，從「今日」、「訓練日曆」或進行中的訓練計畫點開該課表，並點選**依計畫開始（Start as planned）**。應用程式會依據課表內容建立一筆實際的肌力活動，並進入即時記錄畫面。

「開始記錄」與「完成課表」是兩個不同狀態；原始計畫內容會持續保留供參照，同時您記錄的實際組數資料會忠實反映當場執行情況。

## 6. 逐組記錄訓練內容

針對每個動作與每一組：

1. 查看原定負重與目標次數或秒數。
2. 若實際執行與原定不同，直接修改實際重量或完成數值。
3. 勾選該組完成；若誤觸可即時復原。
4. 持續記錄，直到每個動作與整堂課表的進度都符合實際完成內容。

訓練中途離開即時畫面並不會刪除紀錄，稍後隨時可以從同一堂計畫課表返回接續記錄。

## 7. 結束訓練並驗證結果

可視需求選擇 1 至 10 的課表主觀費力度（RPE），然後點擊**結束訓練（Finish workout）**。App 會完成這筆活動並自動開啟活動詳情頁。

完成後請核對：

- 持續時間與課表 RPE 符合實際訓練情況。
- 已完成組數、負重、次數與計時項目皆正確無誤。
- 該筆活動仍正確關聯至原本的計畫課表。
- 畫面清楚區分計畫數值與實際執行紀錄。

## 常見問題

- **排程步驟無法繼續下一步**：確認至少已新增一堂有效課表，且所有課表都落在計畫週期範圍內。
- **肌力課表無法儲存**：確認已填入動作名稱、至少新增一組訓練組群，並輸入有效的組數與次數。
- **點擊「依計畫開始」失敗**：檢查網路連線、重新整理該堂計畫課表，並確認其仍包含有效的肌力結構。
- **不小心離開了即時記錄畫面**：直接重新開啟原本的計畫課表即可，既有活動紀錄會完整保留。
