# 解讀 PMC 歷史與預測

PMC 將已記錄的訓練負荷與條件式未來展望整合在同一畫面中，協助您檢視訓練壓力的演變，以及現有未來輸入資料所推導出的趨勢。請留意，預測僅是基於這些輸入條件的模型估值，並不代表某堂課表已經執行，也不等同於系統認可特定訓練決策。

[在示範帳號中開啟體能管理](https://demo.trainingload.ai/en/pmc)。公開示範環境為唯讀模式，進入後請選擇欲檢視的運動類型。下方包含預測曲線的截圖取自應用程式渲染的範例資料；示範環境實際顯示的數值與預測可用性取決於當下的示範紀錄。

## 開始之前

- 匯入已完成活動，並等待其訓練負荷計算完畢。
- 核對活動運動分類、個人閾值、訓練負荷來源設定與帳號時區。
- 若想檢視基於訓練計畫的未來預測，請使用已排定且具備可用預期負荷的課表；草稿或未排定日期的課表不會自動產生未來每日負荷。
- 解讀圖表時，務必清楚區分已記錄訓練、計畫課表與推估的訓練習慣。

## 1. 開啟體能管理並選擇運動類型

從分析工具中開啟**PMC／體能管理（PMC / Fitness management）**。在右上角的**運動（Sport）**選單選擇全部運動、跑步、騎乘或游泳，上方三張目前數值卡片與下方圖表會同步套用此範圍。

調查特定訓練週期時，建議先聚焦單一運動類型。在儀表板、PMC 與相關活動之間切換時，請再次確認篩選範圍是否一致。

主 PMC 頁面通常顯示 60 天歷史資料，以及向未來延伸 28 天的條件式展望；圖表一次呈現一項所選指標，下方則列出每日訓練負荷。

## 2. 先判讀目前數值，再看未來展望

請始終把三張卡片放在一起綜合解讀：

| 指標 | 代表意義 | 無法單獨證明的事情 |
| --- | --- | --- |
| 體能（Fitness / CTL） | 較長週期累積的訓練負荷水準 | 實際比賽或體能表現已經提升。 |
| 疲勞（Fatigue / ATL） | 對近期訓練壓力反應更靈敏的負荷訊號 | 您當下主觀有多疲倦的臨床診斷。 |
| 狀態（Form / TSB） | 長期負荷與近期負荷之間的相對差值 | 面對課表或比賽的絕對準備度保證。 |

這三張卡片反映的是目前已記錄的現況；將游標移到未來日期時，上方卡片數值並不會被替換成預測值。詳細公式與原理請參閱 [CTL](/zh-hant/docs/metrics/pmc/chronic-training-load)、[ATL](/zh-hant/docs/metrics/pmc/acute-training-load) 與 [TSB](/zh-hant/docs/metrics/pmc/training-stress-balance)。

## 3. 切換指標並細查特定日期

1. 在圖表上方切換**狀態（Form）**、**體能（Fitness）**或**疲勞（Fatigue）**。
2. 將游標移至欲檢視的日期。提示框會顯示日期、已記錄或預測狀態、CTL、ATL、TSB 與當日訓練負荷。
3. 檢視未來日期時，除了數字外，務必一併查看畫面上標示的「負荷推估依據（basis）」。
4. 將指標曲線變化與同一天的下方每日負荷長條互相對照；曲線斜率與單日負荷屬於不同物理量。

圖表同樣支援鍵盤操作：將焦點移至圖表後，使用左右方向鍵逐日檢視，按 **Escape** 隱藏提示框。在觸控螢幕上，輕點圖表中的任一日期即可檢視詳情。

## 4. 區分已記錄歷史與條件式預測

善用圖例與**今天（Today）**分界線定位時間。已記錄數值以實線呈現，可用的未來估值則以虛線呈現；每日負荷面板中，實心長條代表已記錄負荷，較淺色樣式則代表未來預估負荷。

一般預測會優先採用可用的排定計畫課表；當某日沒有適用的排定輸入時，系統可視情況改採足夠近期且可用的訓練習慣模式。請透過日期提示框確認該日究竟採用了哪一種依據：

| 顯示的依據 | 解讀方式 |
| --- | --- |
| 排定訓練（Scheduled training） | 未來負荷來自當日適用的計畫課表。 |
| 近期訓練習慣（Recent training habits） | 預測依據您近期的訓練型態進行估算，並不代表日曆上新增了課表。 |
| 暫停訓練（Pause training） | 所選情境假設這段期間沒有新增額外訓練。 |
| 無預測（No forecast） | 現有輸入資料不足以支撐該日的預測數值。 |

單純開啟 PMC 圖表並不會幫您排定課表或儲存計畫變更。沒有排定課表的日期不自動等同於已確認的休息日，缺少負荷數據也絕不能直接當成負荷為零。

若預測在展望中途因缺少前置輸入而中斷，後續日期也可能維持空白。匯入新活動或修改訓練排程都可能使未來預測隨之更新。

## 5. 理解空白的未來預測區域

即使未來區段無法顯示預測曲線，歷史紀錄依然具有高度參考價值。常見原因包含訓練歷史過短或過久未更新、缺少已記錄負荷，或未來排定課表缺少可用的預期負荷。

遇到這種情況時，請先核對日期與運動篩選，再檢查近期活動與相關計畫排程。若提示框顯示**暫無預測（No forecast available）**，請如實保留這份不確定性。若頁面提示**更新失敗，目前顯示先前的結果（Update failed; showing the previous result）**，代表畫面保留的是舊版快取而非最新重新整理結果；若初始載入失敗，則可使用畫面提供的**重試（Retry）**按鈕。

## 6. 帶入目前脈絡詢問智能教練

點擊頁面頂端的**詢問教練（Ask Coach）**，系統會自動把目前所選的運動類型與負荷展望脈絡帶入智能教練對話。送出前請先審閱預填問題；點擊此連結本身不會擅自修改任何訓練計畫。

提問時請補充您真正想釐清的狀況，例如近期負荷驟升的原因，或下一堂關鍵課表的時機是否合適。審閱回覆時請核對引用的活動與未來假設，並在套用任何計畫或課表異動前走完標準確認流程。

針對馬拉松週期的實戰應用，請繼續閱讀[運用 PMC 調整馬拉松課表](/zh-hant/docs/guide/pmc-marathon-adjustment)。

## 運用儀表板檢視較短時間視窗

點擊儀表板上的「體能」、「疲勞」或「狀態」卡片，即可開啟單一指標詳情檢視。這些詳情頁提供 **7**、**14**、**30** 與 **60** 天歷史分頁，可見的未來預測視窗會跟著所選分頁連動（上限 30 天），與主 PMC 頁面的較大區間略有不同。

解讀圖表前請先選好時間視窗，並始終區分目前數值與所選未來日期的推估值。

## 檢查分析結果

完成檢視後，您應能明確說出所查點位的運動類型、日期、指標名稱、已記錄或預測狀態以及負荷推估依據。一份有價值的解讀會將曲線變化連結回真實活動或排定輸入，同時誠實指出缺少證據之處。

## 常見問題

### 為什麼檢視未來日期時，上方三張卡片的數字沒有跟著變動？

上方卡片固定顯示目前的已記錄狀態；若要查看特定未來日期的預測數字，請閱讀圖表提示框。

### 為什麼完成一堂課表後，未來的預測曲線跟著改變了？

實際記錄的訓練負荷與計畫課表關聯會更新計算輸入。比較前後變化前，請確認該筆活動已處理完成且正確關聯至對應課表。

### 為什麼儀表板卡片打開的圖表時間範圍和主 PMC 頁面不一樣？

儀表板詳情頁的歷史分頁會同步決定較短的可見未來預測視窗，而主 PMC 頁面擁有獨立的較廣範圍。跨頁比較時請核對相同的運動類型與具體日期，而非單純比對點位在螢幕上的相對位置。

### 可以在圖表上自由切換不同的預測情境嗎？

主頁面提供運動類型與指標切換，日常造訪時會自動採用適用的計畫與訓練習慣作為輸入。部分從智能教練或分享連結開啟的檢視可能帶入不同假設情境，請務必閱讀日期提示框中顯示的估算依據，不要假設每個畫面都採用同一套假設。

### 彩色的 TSB 區間帶是否代表我已經準備好比賽了？

彩色區間帶只是輔助閱讀訓練負荷脈絡的參考區間，並未涵蓋睡眠、壓力、傷痛或環境等所有影響實際競技狀態的因素。
