# AI 馬拉松訓練計畫微調

智能教練能串聯訓練計畫、已完成活動與訓練負荷脈絡，並草擬調整方案。但它不應該在未經您審核的情況下默默改寫整個馬拉松備賽週期。建議把它當成產出「單一、保守且可逐項檢查」提案的工具，經您確認後再套用。

## 開始之前

- 開啟正確的進行中訓練計畫，核對起訖日期、賽事目標與目前週次。
- 等待近期活動處理完成，並將其關聯至對應的計畫課表。
- 先檢視對應區間的 PMC 走勢，必要時搭配有效 VO₂max／VDOT 趨勢一起判斷。
- 整理真實限制條件：每週可訓練日、傷痛或不適疑慮、差旅安排、器材限制，以及本週最不能動的核心關鍵課表。
- 每次只鎖定一個決策。例如：明天馬拉松配速課要照常執行還是挪動日期、簡化未來七天安排，或因應漏掉的一次長跑。
- 切勿要求智能教練提供醫療許可或傷害診斷。

## 1. 從訓練計畫脈絡出發

直接從進行中的訓練計畫開啟智能教練，或在開啟新對話時明確寫出計畫名稱與目標週次。從計畫頁面進入，可大幅降低系統討論到錯誤課表的風險。

提問時建議包含四個要素：

1. **決策目標**：您現在需要回答的單一核心問題。
2. **現有證據**：已完成與錯過的課表、PMC 負荷型態、身體反應趨勢與主觀體感。
3. **保護條件**：不可更動的日期與核心課表。
4. **輸出要求**：最多一份保守調整草稿，外加下一次檢視節點。

提問範例：

> 請回顧我目前馬拉松訓練計畫的第 7 週。週二的閾值課跑得比預期吃力，週末過後 ATL 上升，且週六的長跑必須保留。請為未來七天草擬最多一項調整。維持每週訓練頻率，並說明依據證據、確切課表改動與下一次檢視時間點。先不要套用變更。

## 2. 核對系統引用的證據

在討論具體改動前，先確認回覆中正確引用了以下資訊：

- 正確的訓練計畫、週次與運動類型。
- 正確的已完成或錯過課表。
- 符合分析需求日期區間的 CTL、ATL 與 TSB。
- 實際上的下一堂關鍵課表。
- 您所提供的各項保護條件。

只要發現任何目標紀錄有誤，請立刻停下來重新指明，切勿確認一份建立在錯誤資料上的看似合理建議。

## 3. 要求最小幅度的調整

請依以下優先順序進行微調：

1. 證據不足時，維持原計畫不變。
2. 僅挪動課表日期，不改變原本訓練目的。
3. 縮短單一課表時間，同時保留核心結構。
4. 將一堂非核心品質課改為輕鬆有氧跑或休息。
5. 唯有較小幅度的選項無法解決問題時，才調整整體週跑量或強度配置。

避免同時更動訓練頻率、總量、強度與關鍵課表位置，否則後續將難以歸因效果，也不容易回溯修正。

## 4. 確認前先完整審閱提案

在智能教練對話中點選**檢視課表日曆（View workout calendar）**，透過預覽畫面逐一對照原始課表與建議課表：

| 檢查項目 | 核對問題 |
| --- | --- |
| 目標對象 | 修改的是否為預期的未來課表與正確日期？ |
| 變動範圍 | 是否只調整了單一主要變數？ |
| 訓練目的 | 調整後的課表是否仍服務於該馬拉松週期的訓練目標？ |
| 保護條件 | 受保護的長跑、比賽、休息日與可用時段是否都未遭更動？ |
| 證據區分 | 說明內容是否清楚區分客觀觀測資料與推論解讀？ |
| 檢視節點 | 是否明確訂出下一次回顧的時間點？ |

只要草稿動到了已完成的歷史紀錄、錯誤的訓練計畫、多堂無關課表，或破壞了保護條件，請直接拒絕或要求重新草擬。

## 5. 確認套用後回頭檢查計畫

審閱無誤後，點擊**確認計畫變更（Confirm plan changes）**，接著依序確認：

1. 重新開啟進行中的訓練計畫或訓練日曆。
2. 核對目標課表的日期、運動類型、持續時間與課表結構。
3. 確認前後相鄰的課表沒有遭到意外更動。
4. 若介面支援，在計畫或回顧脈絡中簡短記下本次調整理由。
5. 在下一次同類型關鍵課表完成後設定檢視節點。

若畫面提供復原（Undo）且發現套用結果有誤，請立即復原；否則先檢視最新版本的訓練計畫，再手動修正受影響的未來課表。

## 驗證調整結果

- 智能教練採用了正確的訓練計畫、週次、活動紀錄與日期範圍。
- 提案在確認前清楚呈現了調整前後的精確差異。
- 僅有預期的未來課表遭到修改。
- 已完成、略過與已關聯的歷史紀錄完全未受影響。
- 保護條件與馬拉松備賽週期目的皆獲得保留。
- 進行中的訓練計畫與訓練日曆顯示一致的更新後課表。
- 已記錄明確的下一次檢視節點。

## 疑難排解

- **回覆過於籠統**：直接從訓練計畫頁面發起對話，寫明具體週次與課表名稱，並附上關鍵證據與限制條件。
- **引用了錯誤的活動或計畫**：切勿確認。改由正確紀錄進入，或重新開啟具計畫脈絡的對話。
- **提案改動幅度過大**：明確要求最多只做一項變動、只調單一主要變數、遵守保護條件，且影響範圍限於七天內。
- **套用操作因版本衝突失敗**：重新載入進行中的訓練計畫、比對最新版本後，再重新提出或套用最小幅度變更。
- **套用後的課表與預期不符**：有復原按鈕時立刻復原；否則進入計畫檢查，僅手動修正受影響的未來課表。
- **佐證資料仍在處理或有缺漏**：暫時維持計畫不變，待活動處理與課表關聯完成後再進行調整。
- **決策主因涉及疼痛、生病或異常症狀**：請尋求專業醫療人員或執業教練協助，智能教練無法提供診斷或核可訓練。
