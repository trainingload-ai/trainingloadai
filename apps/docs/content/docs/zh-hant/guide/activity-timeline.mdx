# 使用時間軸分析訓練活動

時間軸會將單次活動記錄到的各項感測資料流對齊在同一條橫軸上。透過它，您可以細查某一瞬間的狀態，也能比較所選區段的配速、功率、心率、步頻／踏頻與對應路線。左側的區間統計與圖表內的單點讀數分別回答不同層次的問題。

本指南適用於**桌面網頁版**的跑步與騎乘活動，實際可用的圖表取決於活動中記錄到的資料。若想了解完整的活動回顧流程，請先參閱[活動詳情](/zh-hant/docs/guide/activity-detail)。

## 開啟範例活動

[開啟 10 公里比賽示範活動](https://demo.trainingload.ai/en/activities/17921623926005309429)，接著在路線圖下方點選**時間軸（Timeline）**。活動預設會先開啟總覽分頁。由於示範帳號為唯讀模式，儲存分析區段編輯的功能會處於停用狀態。

檢視自己的活動時，請先等待系統處理完成並確認檔案包含時間序列採樣資料。僅含摘要數值的活動無法提供同步時間軸；室內訓練即使沒有 GPS，仍可正常顯示可用圖表。解讀資料前，請先核對運動類型、閾值與單位設定。

## 1. 檢視整場活動

點選**時間軸（Timeline）**後，畫面上方為區段標頭，左側為指標控制與區間統計，右側為彼此對齊的多組圖表。橫軸預設採用時間模式；當活動包含定位資訊時，路線圖會保持顯示於分頁上方。

較長的活動會超出目前可視的圖表寬度，可水平捲動檢視後半段時間。在您手動選取特定區間之前，左側的區間統計會維持呈現整場活動的數值。

初始狀態下，左側的**平均（Average）**、**最小（Min）**與**最大（Max）**代表整場活動的統計結果。沒有有效採樣值的指標可能不會顯示，資料流中若有缺漏，圖表曲線上會呈現斷點。

## 2. 檢視單一時間點

將滑鼠游標移過任一圖表，即可在每個圖表相同的橫軸位置讀取浮動數值。若有 GPS 資料，上方地圖也會同步標示對應位置。

點擊即可固定選取該位置；將游標移出圖表區域會隱藏暫時性的懸停讀數。左側的區間統計則始終對應整場活動或目前選取的區間。

您也可以將焦點移至時間軸的定位控制項，使用左右方向鍵逐點檢視採樣值，或按 **Home** 與 **End** 跳至區間起訖邊界。當控制項失去焦點時，鍵盤檢視讀數會自動隱藏。

| 想確認的問題 | 查看位置 |
| --- | --- |
| 這個瞬間記錄到了什麼數值？ | 各圖表內的單點浮動讀數。 |
| 這段出力的典型水準為何？ | 左側區間統計中的平均值。 |
| 這段區間內的有效極值為何？ | 同一區間統計中的最小值與最大值。 |

## 3. 選取特定區段並進行比較

您可以直接選取裝置記錄的分段，或自行框選任意區間：

1. 點選上方的區段標頭即可突顯該區段並更新統計數據；再次點選即可取消區段選取。
2. 若想檢視自訂範圍，在圖表上水平拖曳並放開滑鼠，所有共用橫軸的圖表會同步縮放至所選區間。
3. 將所選區間的平均、最小與最大值與圖表波形互相對照，並移動游標細查區間內的單一採樣點。
4. 若具備定位資料，請檢視地圖上高亮顯示的路線區段，結合周遭地形理解該段出力發生的實際位置。

若是長時間穩定課表，可觀察在配速或功率維持相近的情況下，心率是否出現漂移；若是多組間歇課表，則比較衝刺段與恢復段是否符合訓練目的。分析變化規律時，請一併考量持續時間、地形坡度、中途停頓與可用的感測器資料。

## 4. 返回整場活動或切換橫軸

點擊**區段（Segments）**旁的**時間軸選項（Timeline options）**，選擇**顯示整場活動（Show full activity）**即可清除區間選取並還原完整圖表檢視。在圖表上雙擊滑鼠，或於時間軸內按下 **Escape** 鍵，同樣會重設選取與縮放。

在同一個選單中，您可將**橫軸（Horizontal axis）**在**時間（Time）**與**距離（Distance）**之間切換。距離模式需要有效的累計距離資料；切換橫軸時，已選取的區段仍會保留原本的時間邊界。

## 5. 自訂圖表配置

點選任一指標名稱（例如**配速**或**心率**）即可開啟該圖表的設定選單，自由調整顯示指標、線條顏色、圖表高度與平滑化程度。使用**上移（Move up）**、**下移（Move down）**或**移除圖表（Remove chart）**可調整顯示順序。

點擊底部的**新增圖表（Add chart）**可加入其他可用的資料流。您可以重複加入同一項指標（例如同時對照原始曲線與平滑曲線），點擊**展開（Expand）**則能以較大畫面檢視單一圖表。

平滑化只會改變繪製出來的曲線外觀，單點讀數與區間統計仍保留原始記錄資料的意義。圖表排版設定儲存在目前瀏覽器的偏好設定中，不會改動原始活動檔案。

## 6. 在個人帳號中編輯分析區段

若您希望以不同於裝置分段的方式切分分析區間，請使用**編輯區段（Edit segments）**。此操作需登入個人帳號且具備該活動的編輯權限。

1. 開啟**編輯區段（Edit segments）**，檢視每個區段的名稱、開始時間與結束時間。
2. 重新命名區段或調整邊界。編輯器也視情況提供**在空隙新增區段（Add segment in a gap）**、**對半分割（Split in half）**、**合併下一段（Merge next）**與**移除（Remove）**等操作。
3. 確保所有邊界皆落在活動範圍內，且每段起點早於終點、彼此不重疊。
4. 點選**儲存區段（Save segments）**後，即可檢視更新後的區段統計；點選**取消（Cancel）**則會直接關閉草稿而不儲存。

儲存分析區段不會改動原始檔案、裝置原始分段與整場活動的訓練負荷。修改邊界後，系統會依據該範圍內的記錄資料流重新計算區段統計。點選**還原裝置分段（Restore device laps）**可將編輯器內的切分恢復為原始裝置分段，確認後即可再次儲存。

若另一個視窗已變更區段定義，請先關閉再重新開啟編輯器以載入最新版本，避免覆蓋。若儲存失敗，草稿會保留以便重試。公開示範帳號會停用此編輯流程。

## 檢查分析結果

選取一個區段後，請確認邊界範圍、區間統計與高亮路線都對應到活動的同一區段。還原為完整檢視時，確認統計值已回復為整場活動數值。若您在個人帳號中儲存了自訂分析區段，建議重新開啟該活動以確認區段定義已正確保存。

## 常見問題

### 為什麼移動游標時，左側數值沒有跟著改變？

左側顯示的是整場活動或目前選取區間的彙總統計；若要看游標所在當下的數值，請查看各圖表內的單點浮動讀數。

### 為什麼圖表上會出現缺口或破折號？

缺少感測資料流、採樣中斷或無效數值都會造成曲線斷裂或顯示破折號。速度、步頻／踏頻或功率記錄為零可能是有效數值；但停止移動時的樣本沒有可用配速，缺少的心率採樣點也不會以零填補。

### 為什麼修改邊界後，同一分段的數值與原本不同？

未修改的裝置分段會直接沿用匯入時的摘要值；修改過或自訂的分析區段則會依據該區間內的有效採樣點重新計算。資料覆蓋缺口與所選邊界都會影響最終結果。

### 為什麼功率數值旁標註了「估算（Estimated）」？

這代表該資料流採用的是估算功率。將其與功率計實測紀錄相比或用來解讀訓練強度時，務必留意資料來源的差異。

### 為什麼地圖路線沒有高亮顯示選取的區間？

該時段可能缺少有效的 GPS 定位資料，或地圖服務暫時無法使用。請先繼續判讀圖表，並另行確認地圖狀態。

### 為什麼手機上沒有時間軸功能？

同步時間軸屬於桌面網頁版專屬流程。在手機上請使用行動 App 為該運動提供的活動詳情與圖表檢視，或改在桌面瀏覽器開啟該活動。

### 如果某張圖表載入失敗怎麼辦？

畫面提供重試按鈕時請先點擊重試，其他已載入的圖表仍可正常使用。若重新整理失敗，頁面可能會暫時保留先前結果並顯示錯誤狀態；請將資料缺失與請求失敗分開排查。
