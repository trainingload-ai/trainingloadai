# 行動 App 記錄訓練

完成本教學後，您將學會用手機安全記錄一堂訓練，並確認該活動順利同步至 Trainingload.ai 的活動歷史清單。

## 開始之前

- 在行動 App 登入與網頁版相同的帳號。
- 進行戶外 GPS 記錄前，先開啟手機的定位權限。
- 若打算在訓練過程中鎖定螢幕，請在作業系統提供此選項時允許「背景定位」。
- 若您的手機會主動凍結背景應用程式，請將 Trainingload.ai 移出嚴格的省電限制清單。
- 確認手機剩餘電量與儲存空間足以應付預定訓練時間。

## 1. 檢查權限狀態

開啟**我的 → 選單 → 資料授權（Me → Menu → Data authorization）**，在出發訓練前先確認定位與健康資料權限。請留意，第三方平台授權與手機 GPS 權限屬於兩件不同的事：連接了第三方平台並不會自動賦予手機記錄定位的權限。

## 2. 開啟訓練記錄器

在**今日（Today）**頁面點開排定課表，確認運動類型與課表結構後，點擊**開始今日訓練（Start today's workout）**。您也可以從進行中的訓練計畫點開課表。進行戶外課表前請再次確認定位權限已開啟。

## 3. 開始並監控訓練過程

1. 點擊一次**開始今日訓練（Start today's workout）**，依準備提示操作並等待倒數結束。
2. 確認已經過時間開始正常累加。
3. 進行戶外訓練時，確認距離或路線資料開始更新。
4. 確定訓練已穩定開始記錄後再鎖定螢幕。

若 App 在背景遭系統暫停後重新回到前景，請稍候系統自動復原進行中的訓練紀錄，切勿在復原期間另外開啟第二筆記錄。

## 4. 結束並儲存訓練

訓練結束時，請依序操作：

1. 停止記錄。
2. 核對持續時間、距離與運動類型。
3. 儲存訓練紀錄。
4. 讓 App 保持連網，直到上傳或匯入交接完成。

訓練進行期間，行動 App 會將記錄資料保存在本機，並為意外中斷的記錄提供復原機制。本機儲存成功不代表所有伺服器端圖表都會瞬間出現，上傳完成後系統會在雲端接續分析處理。

## 驗證同步結果

開啟**我的 → 活動（Me → Activities）**或切換至對應的訓練日曆日期，確認：

- 該堂訓練僅存在一筆活動紀錄。
- 開始時間、運動類型、持續時間與距離皆合理。
- 含 GPS 的戶外訓練正常顯示路線地圖。
- 感測器衍生圖表僅在記錄確實包含該資料時顯示。
- 該筆活動可順利關聯至預期的計畫課表。

## 疑難排解

### 時間有在增加，但距離始終停在零

檢查定位權限、GPS 訊號強度，以及所選運動類型是否預期記錄戶外距離。建議移至開闊處等待定位就緒。

### 螢幕鎖定後記錄就停止了

開啟「背景定位」權限，並取消作業系統對本 App 的電池最佳化限制；作業系統層級的限制會覆蓋 App 內的權限設定。

### 同一筆活動出現兩次

當同步仍在排隊進行時，請勿另外手動上傳本機檔案。先比對開始時間與持續時間，確認無誤後再刪除重複的那一筆。

### 活動已出現，但缺少圖表

請稍候系統分析完成後重新整理。缺少心率、功率或步頻圖表，也可能是因為當次記錄原本就沒有連上對應感測器。
