# 運用 PMC 調整馬拉松課表

PMC 指標反映的是累積的訓練壓力，但它們本身無法判定某堂課是否安全、無法證明身體已產生適應，也無法單獨診斷疲勞。在馬拉松備賽週期中，PMC 最大的價值在於協助您守住訓練規律性，並保護關鍵課表的執行品質。

## 開始之前

- 確認相關訓練活動皆已處理完成，負荷資料已反映在 PMC 中。
- 核對個人檔案中的跑步閾值與活動負荷來源優先順序。
- 將已完成活動關聯至對應的計畫課表。
- 選定一個明確的決策時間視窗，通常為過去 2 至 6 週加上未來 7 天。
- 標出接下來的核心關鍵課表：長跑、馬拉松配速課、閾值跑或賽事。
- 記錄圖表以外的關鍵脈絡，例如睡眠、生病、傷痛、差旅、高溫潮濕與單次課表 RPE；PMC 並不包含這些資訊。

## 1. 開啟正確的 PMC 視窗

開啟**分析 → PMC／體能管理（Analysis → PMC / Fitness management）**並選擇**跑步（Running）**。先透過已記錄歷史掌握負荷堆疊與近期轉折，再檢視相關未來日期。指標切換、單日檢視與預測假設細節請參閱[解讀 PMC 歷史與預測](/zh-hant/docs/guide/pmc-forecast)。若需要更短的觀察視窗，可點開儀表板的體能、疲勞或狀態卡片並切換歷史分頁。

請同時判讀三個訊號：

- [CTL](/zh-hant/docs/metrics/pmc/chronic-training-load) 彙整較長期的訓練負荷趨勢。
- [ATL](/zh-hant/docs/metrics/pmc/acute-training-load) 對近期訓練壓力變化反應最迅速。
- [TSB](/zh-hant/docs/metrics/pmc/training-stress-balance) 呈現長期與近期負荷之間的相對差值，屬於判斷脈絡，而非準備度保證。

## 2. 找出曲線轉折背後的真實事件

定位 ATL 加速攀升、CTL 轉向或 TSB 劇烈波動的日期，接著點開該日期前後的實際活動與計畫課表。

逐一排查造成波動的真正來源：

- 原定安排的負荷強化週。
- 一場比賽、長跑，或格外吃力的品質課。
- 計畫外多練的額外活動。
- 閾值或負荷來源優先順序遭到修改。
- 重複匯入、運動分類錯誤或不完整的活動資料。

在確認曲線變動確實來自真實訓練或已知的設定更動之前，切勿貿然修改訓練計畫。

## 3. 將負荷曲線與實際執行品質互相對照

透過訓練日曆或進行中的訓練計畫回答以下問題：

- 核心關鍵課表是否確實達成了原本的訓練目的？
- 輕鬆跑依然維持輕鬆，還是整體執行品質正在下滑？
- 錯過的課表是因為行程衝突、疲勞、疼痛，還是課表設計本身過重？
- 經歷了本週實際負荷後，下一堂關鍵課表是否仍然合適？

PMC 告訴您累積了多少訓練壓力；計畫與實際執行的對照，才告訴您這份壓力是否轉化成了預期的訓練效果。

## 4. 挑選最小且最實用的微調方案

請把 PMC 型態當成啟動檢視的訊號，而不是死板的數值紅線規則。

### 近期壓力攀升且關鍵課表品質下滑

- 盡量維持原有的每週訓練節奏。
- 將一堂非核心品質課改為輕鬆有氧跑或休息日。
- 優先保住「長跑」或「馬拉松配速課」其中之一，不要試圖兩頭硬撐。
- 於 24 至 48 小時後或下一次完成訓練後重新評估。

### 關鍵課表前 TSB 低於平時水準

- 先與您個人過往順利完課時的常見區間及當下主觀體感比對。
- 若行程允許，將該課表延後 24 至 48 小時。
- 若延後會打亂整週節奏，改為縮短總量但保留原本的核心強度結構。
- 切勿單靠 TSB 推斷受傷或生病，務必以真實身體症狀與專業醫療建議為準。

### CTL 持續上升，但課表完成品質惡化

- 暫停繼續往上加量。
- 檢查閾值、負荷來源優先順序或重複活動是否人為膨脹了曲線。
- 先簡化一週課表，待回穩後再考慮增加跑量或強度。
- 以下一次同類型關鍵課表作為檢驗節點。

### 曲線平穩且課表執行順暢

直接維持原計畫不變。圖表隨時都能看，並不代表每次看完都必須動手修改課表。

## 5. 記錄本次決策依據

在動手修改計畫之前，先整理好這五項紀錄：

1. **觀測型態**：PMC 在哪段日期出現了什麼變化。
2. **執行證據**：哪些實際活動或錯過課表支持這項擔憂。
3. **具體調整**：確切要修改哪一堂未來課表的哪個欄位。
4. **保護重點**：這一週仍然必須達成的核心目標。
5. **檢視節點**：用來驗證本次調整成效的日期或下一堂關鍵課表。

您可以將這份整理帶給[智能教練](/zh-hant/docs/guide/ai-coach)，請它依據計畫脈絡產出一份保守的調整草稿。

## 驗證調整結果

- 所選運動類型與日期區間完全對應本次馬拉松備賽問題。
- 曲線波動已追溯到具體活動或已知設定變更。
- 決策同時納入了主觀體感、關鍵課表執行品質與 PMC 趨勢。
- 僅更動了預期的未來課表，歷史紀錄完好無缺。
- 已排定明確的下一次檢視節點。
- 若後續證據顯示方向不符，這項調整隨時可逆轉或修正。

## 疑難排解

- **PMC 畫面空白**：確認活動狀態為「就緒」、核對運動篩選範圍，並確認活動具備可用的訓練負荷；若為請求載入失敗，請點擊重試。
- **修改設定後數值全變了**：確認是哪項閾值或負荷來源更動，並在一致基準下重新解讀整個對照視窗。
- **單一活動造成極端尖峰**：點開該活動檢查持續時間、感測器資料、運動分類、是否重複匯入以及採用的負荷來源。
- **計畫與圖表日期對不起來**：核對帳號時區與活動開始時間。
- **客觀指標與主觀體感互相矛盾**：將這個落差視為值得深入排查的證據，不要武斷忽略任何一方，下一步調整保持保守。
- **出現疼痛、生病或異常症狀**：切勿將 PMC 或智能教練視為醫療許可；請適度停止或調整訓練，並在必要時尋求專業醫療協助。
