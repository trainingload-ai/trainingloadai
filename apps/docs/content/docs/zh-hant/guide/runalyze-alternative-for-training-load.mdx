# Runalyze 訓練負荷替代方案比較

如果您平時使用 Runalyze 追蹤跑步表現，建議直接拿同一批近期訓練活動，搭配接下來的課表安排決策，同時對照兩套工具的實際體驗。

Runalyze 提供有效 VO₂max、完賽時間預測、訓練負荷與豐富的活動統計，其方法與最新功能可參閱 [Runalyze 官方功能總覽](https://runalyze.com/help/article/features?_locale=en)。

## 在 Trainingload.ai 中回顧訓練的方式

- 先開啟[活動詳情](/zh-hant/docs/guide/activity-detail)，核對單次實際記錄的訓練資料。
- 檢視[有效 VO2max 歷史](/zh-hant/docs/guide/effective-vo2max-for-endurance)，觀察近期估值的演變趨勢。
- 開啟 [PMC](/zh-hant/docs/guide/pmc-forecast)，結合訓練排程一起解讀累積負荷。
- 將實際活動關聯至對應的計畫課表，接著請[智能教練](/zh-hant/docs/guide/ai-coach)回顧執行狀況或提出微調建議。

## 使用自己的真實紀錄進行比較

1. 從原始平台匯出支援的 FIT、GPX 或 TCX 檔案，或直接建立[第三方平台連線](/zh-hant/docs/guide/connect-data)。
2. 匯入近期一個完整訓練週期，並核對日期、資料來源與個人閾值。
3. 挑選一筆自己非常熟悉的課表，先比對原始的持續時間、距離、心率與配速。
4. 接著再比較訓練負荷與體能估值；單一估值的差異並不足以代表真實體能有所改變。

## 轉換時需要重新設定的項目

不同平台採用的有效採樣規則、校正因子與閾值定義各異，因此有效 VO₂max 與訓練負荷歷史曲線未必會完全重合。此外，單純上傳活動檔案並不會自動移轉 Runalyze 裡的標籤、裝備紀錄、自訂設定或所有歷史統計報表。

建議先保留原始紀錄，完整體驗一次「計畫課表對照實際活動」的回顧流程後，再決定是否全面移轉或雙平台並用。想先看看操作介面，歡迎直接[開啟線上示範](https://demo.trainingload.ai/en)。
