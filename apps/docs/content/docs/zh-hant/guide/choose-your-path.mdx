# 選擇適合您的起步路徑

您不需要先設定完所有指標才能開始使用 Trainingload.ai。先挑選當下最想達成的目標，走完對應的最短路徑，等上手後再回來做更深入的個人化設定即可。

## 我想先了解近期的訓練狀況

如果您在其他平台已有歷史紀錄，或手邊有 FIT、TCX、GPX 活動檔案，請選擇這條路徑：

1. 完成[快速入門](/zh-hant/docs/guide/getting-started)。
2. [連接第三方平台](/zh-hant/docs/guide/integrations)或[上傳活動檔案](/zh-hant/docs/guide/upload-activity-files)。
3. 開啟[活動詳情](/zh-hant/docs/guide/activity-detail)，確認時間、距離、運動類型與現有感測器資料正確無誤。
4. 透過[儀表板](/zh-hant/docs/guide/dashboard)與[訓練分析工作流程](/zh-hant/docs/guide/training-analysis-workflow)解讀長期趨勢。

**完成標準**：至少有一筆活動完成處理，且顯示的圖表與原始資料相符。

## 我想跟著訓練計畫按表操課

如果「下一堂課該練什麼」比回顧歷史資料更重要，請選擇這條路徑：

1. 確認您的[個人檔案、閾值與訓練區間](/zh-hant/docs/guide/profile-thresholds-zones)。
2. 手動或透過 AI [建立訓練計畫](/zh-hant/docs/guide/create-training-plan)。
3. 檢視課表內容，並設定預期的開始日期以啟用計畫。
4. 在[訓練日曆](/zh-hant/docs/guide/calendar)或計畫頁面中查看今日課表。
5. 練完後，[將已完成的活動關聯至對應的計畫課表](/zh-hant/docs/guide/manage-active-plan)。

**完成標準**：訓練計畫已啟用、今日課表清晰可見，且第一筆已完成活動已關聯或準備好進行關聯。

## 我主要透過手機訓練

手機適合用來查看今日課表、直接記錄訓練、快速回顧與追蹤課表執行；當您需要更大畫面細看圖表或編排跨週訓練計畫時，再切換至網頁版。

1. 閱讀[網頁版與行動 App](/zh-hant/docs/guide/web-and-mobile)，了解兩端同步的資料範圍。
2. 完成[行動 App 記錄訓練](/zh-hant/docs/guide/mobile-recording)中的權限檢查清單。
3. 直接記錄或匯入一筆訓練。
4. 隨時在「今日」、「訓練日曆」、「計畫」、「教練」或「我的」分頁延續同一個帳號的工作流程。

**完成標準**：能順利儲存一筆行動端訓練紀錄，並在同步完成後於帳號中看到該筆活動。

## 我想請 AI 協助建立或調整訓練

當個人檔案、近期活動與訓練計畫都準備好時，智能教練能發揮最佳效果：

1. 填入您有把握的閾值數值；不確定的項目請先留空，不要隨意猜測。
2. 匯入足夠的近期訓練紀錄，讓系統掌握您平常的訓練負荷水準。
3. 開啟[智能教練](/zh-hant/docs/guide/ai-coach)，明確說明訓練目標、時間範圍、生活限制與每週可訓練日。
4. 套用前務必親自審閱每一份計畫草稿或課表調整提案。

**完成標準**：智能教練的建議有引用您真實的計畫或活動，且提議的變更在儲存前皆清晰可檢視。

## 我需要建立肌力訓練課表

1. 建立或開啟一份手動訓練計畫。
2. 在課表編輯器中選擇**肌力訓練（Strength Training）**。
3. 參考[肌力訓練課表](/zh-hant/docs/planning/strength-workouts)新增動作項目、訓練組數、負重、出力程度與組間休息。
4. 儲存並核對課表預覽後，再執行或匯出該堂課表。

## 如果還不確定從哪裡開始

請直接從[快速入門](/zh-hant/docs/guide/getting-started)開始。它涵蓋了最精簡的完整閉環：個人檔案 → 已完成活動 → 訓練負荷 → 訓練計畫 → 回顧分析。
