# 活動詳情

透過活動詳情頁面，您可以深入瞭解單次已完成的訓練。這裡整合了記錄到的活動資料、路線、圖表、各運動專屬指標與可用的教練回顧。建議先確認資料來源與摘要，接著檢視特定區段的出力表現，最後再將實際證據與原本的課表目標進行對照。

[開啟 10 公里比賽示範活動](https://demo.trainingload.ai/en/activities/17921623926005309429)。此連結會在唯讀示範帳號中開啟一筆真實活動紀錄，方便您檢視各分頁與圖表；若要儲存編輯內容，則需登入自己的帳號。

## 開始之前

- 匯入或記錄一筆活動，並等待系統處理完成。
- 確認活動的運動類型與日期，同時檢查個人檔案中的單位系統與相關閾值設定。
- 使用包含目標分析資料的活動紀錄。心率分析需要心率採樣資料，功率分析需要功率資料，路線顯示則需要 GPS 資訊。
- 若要比較計畫課表與實際完成情形，請先確認對應的訓練計畫課表與活動關聯。

即使活動只包含摘要數值，仍然可以進行檢視，只是顯示的圖表會較少。可用的分析分頁取決於運動類型與實際記錄到的資料內容。

## 1. 開啟活動並檢查資料來源

開啟**活動（Activities）**，點選一筆訓練紀錄，確認其標題、運動類型、開始時間、資料來源、距離與持續時間。您也可以從搜尋結果、地圖、訓練日曆或已連結的計畫課表進入活動詳情頁。

若系統仍在處理中，請先等待完成再判斷是否缺少圖表。活動卡片可能會在所有分析項目完成前先行顯示。

| 處理狀態 | 建議操作 |
| --- | --- |
| 分析中（Analyzing） | 等待活動處理完成後重新整理頁面。 |
| 就緒（Ready） | 繼續檢視所有可用資料。 |
| 部分失敗（Partial failed） | 檢查缺少哪一項分析，並先參考已完成的部分。 |
| 失敗（Failed） | 檢查原始檔案與失敗資訊後，再嘗試重試或重新匯入。 |

## 2. 依照分析問題選擇對應檢視

在桌面網頁版中，分析分頁位於路線圖下方。建議先從**總覽（Overview）**看起，再切換到符合您問題的分頁。行動 App 則會顯示該運動類型支援的詳情與圖表檢視；下文介紹的同步時間軸屬於桌面網頁版工作流程。

| 檢視分頁 | 適合調查的問題 | 資料或適用範圍 |
| --- | --- | --- |
| 總覽（Overview） | 單次訓練摘要、可用資料圖表、天氣與運動專屬情境 | 顯示欄位依活動資料而定。 |
| 時間軸（Timeline） | 在同步圖表與路線上比對特定時間點或選取區段 | 具備可用時間序列資料的跑步或騎乘活動（桌面網頁版）。 |
| 分段（Laps） | 比較裝置記錄的分段與其摘要指標 | 當活動包含分段資料且該運動支援此檢視時顯示。 |
| 最佳表現（Best efforts） | 依距離或時間找出最強的持續出力區段並檢視統計值 | 是否可用取決於運動類型與記錄的感測資料流。 |
| 心率（Heart Rate） | 心血管反應、心率區間與支援的衍生指標 | 需具備對應分析所需的心率資料。 |
| 功率（Power） | 功率輸出、功率區間與效率相關指標 | 需具備對應的功率資料；估算功率會加以標註。 |
| 配速（Pace） | 配速策略與配速相關分析 | 顯示於支援的跑步活動。 |
| 跑步動態（Running Dynamics） | 裝置記錄的跑姿與技術相關量測值 | 具備相應感測資料流的跑步活動。 |

游泳與其他運動各有對應的詳情顯示策略。某個分頁沒有出現，往往反映的是運動類型或缺少對應感測資料，而非系統處理失敗。

## 3. 在完整脈絡中檢視單一區段表現

若想深入分析某段爬坡、加速或間歇課表，請開啟**時間軸（Timeline）**。定位單一時間點即可對照當下各項數值，選取一段區間則能同時檢視該區段的平均、最小與最大值，以及對應的路線區段。

完整的區間選取流程、圖表配置與分析區段編輯方式，請參閱[使用時間軸分析訓練活動](/zh-hant/docs/guide/activity-timeline)。

使用**分段（Laps）**可比較裝置自動或手動記錄的分段表現；若想找出單次活動中最強的持續出力，請使用**最佳表現（Best efforts）**。在最佳表現分頁中，可視介面支援切換依距離或依時間檢視，透過**編輯欄位（Edit columns）**即可控制顯示的統計項目與排序。當活動包含定位資料時，點選某筆最佳表現的第一欄或數值，即可在地圖上定位其對應路線區段。

## 4. 解讀訓練強度與訓練負荷

檢視配速、心率與功率分析時，務必結合活動的運動類型與個人閾值一起判斷。比較不同訓練課表時，訓練負荷的計算來源非常關鍵：

- 功率型負荷依據功率資料與對應的功率閾值計算。
- 跑步配速型負荷取決於可用的配速、地形坡度與閾值設定。
- 心率型負荷依據可用的心率紀錄與個人檔案設定計算。
- 當上述訊號皆不可用時，系統會改採其他支援的負荷計算方式。

支援的指標概念請參閱[訓練負荷](/zh-hant/docs/metrics/training-load)。如果區間分布或強度看起來不合理，請先檢查[個人檔案、閾值與訓練區間](/zh-hant/docs/guide/profile-thresholds-zones)。

在支援的心率分析中，有氧解耦（Aerobic Decoupling）會比較整場活動前後半段的輸出與心率對應比例。解讀 Pw:Hr 或 Pa:Hr 之前，建議先查閱[有氧解耦](/zh-hant/docs/metrics/heart-rate/aerobic-decoupling)了解適用條件；強度起伏大或中途停頓較多的訓練，其解讀情境與穩定配速訓練截然不同。

## 5. 結合路線與訓練計畫脈絡

善用地圖路線將體感與輸出變化對照到實際地形。爬坡、停等紅燈或天候環境都可能造成配速或心率波動；若沒有 GPS 資料，則以其他已記錄的感測證據作為依據。

如果這筆訓練屬於計畫課表的一部分，請在訓練日曆或訓練計畫中確認關聯狀態。比較計畫內容、完成度與負荷之前，先核對是否連結到正確的課表；若關聯錯誤，務必先修正再請系統進行計畫回顧。相關操作請參閱[管理進行中的訓練計畫](/zh-hant/docs/guide/manage-active-plan)。

## 6. 檢視教練回顧或提出聚焦問題

**教練回顧（Coach review）**區塊會顯示目前可用的 AI 回顧狀態。若頁面提示您確認資料分享設定，請先完成選擇，再讓 AI 分析您的個人訓練資料。若分析處理或回顧請求仍在排隊中，請稍候；若請求失敗，則可使用畫面上顯示的重試按鈕。

進一步與智能教練對話時，請明確帶入該筆活動與具體問題。實用的提問方向包含：這堂課是否達到計畫強度、後半段出現了哪些變化，以及這筆訓練如何銜接近期整體負荷。在套用任何建議的計畫調整前，請先核對回答中引用的活動、日期範圍與分析證據。

完整的回顧與確認流程請參閱[智能教練](/zh-hant/docs/guide/ai-coach)。

## 驗證回顧結果

完成回顧後，您應能清楚指認該筆活動與其資料來源、說明所檢視的關鍵區段，並指出是哪些記錄訊號支持您的結論。若屬計畫內課表，請確認已連結至正確的計畫項目；在做出下一個訓練決策前，也請留意是否有缺失的感測資料或尚待釐清的解讀。

## 常見問題

### 為什麼部分圖表或分頁沒有顯示？

請先檢查處理狀態、運動類型與感測器覆蓋情形。僅包含摘要數值的檔案無法產出與完整時間序列檔案相同的分析內容；此外，桌面網頁版與原生行動 App 提供的詳情分析流程也有所不同。

### 為什麼同一個指標在不同檢視中的數值略有差異？

請確認顯示的單位、選取的時間範圍與採用的計算方式。時間軸的區間統計描述的是整段或所選區段，而游標讀數代表的是單一採樣點；裝置記錄的分段摘要與系統重新計算的分析區段，其輸入資料也可能不同。

### 為什麼看不到路線圖？

原因可能是原始檔案沒有 GPS 資料、隱私設定移除了位置資訊，或地圖載入請求失敗。建議分別檢視現有圖表與地圖區塊的錯誤狀態。

### 可以編輯示範活動嗎？

公開示範帳號僅供檢視範例內容。編輯活動資訊、儲存分析區段或調整訓練計畫皆需登入具備對應權限的個人帳號。
