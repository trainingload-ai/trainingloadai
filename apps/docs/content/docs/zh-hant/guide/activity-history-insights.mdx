# 活動歷史與最佳表現

歷史分析工具能幫助您從「過去練了什麼？」一路追溯到具體的原始活動紀錄。活動統計（Activity Stats）彙整整體訓練量，最佳距離（Best Distance）列出持續出力排行，地圖（Map）則補上完整的路線脈絡。

這些頁面反映的是已記錄的原始資料，並非官方認證的比賽成績、不會自動預測完賽時間，也無法在不做進一步檢視的情況下直接解釋表現變化的原因。

## 開始之前

- 確認匯入的活動已達到「就緒（Ready）」狀態。
- 核對運動分類、時區與單位系統設定無誤。
- 比較總量或紀錄排行前，先清理重複紀錄與明顯的感測器異常值。
- 選擇符合分析問題的時間區間。
- 請記得地圖需要可用的 GPS 座標；室內訓練或無 GPS 的活動仍會出現在其他分析頁面中。

## 1. 檢視年度活動訓練量

開啟**分析 → 活動統計（Analysis → Activity Stats）**。此頁面會沿用目前「活動」頁面的運動篩選條件，解讀報表前請先設定好對應的運動篩選。

從側邊欄選擇年份，可選年份會一路涵蓋至所選運動最早的一筆活動紀錄。熱力圖呈現所選年度內可用的 365 天區間，並統計有訓練活動的天數。

在熱力圖下方選擇一項指標：

- 距離（Distance）。
- 持續時間（Duration）。
- 心率（Heart rate）。
- 活動次數（Activity count）。
- 卡路里（Calories）。

接著選擇折線圖的彙總粒度：依日、依週或依月。依日資料適合細查短期變化，依週資料有助於檢視訓練規律性，依月資料則適合比較大週期訓練量。心率會以參與計算的數值取平均，而距離、時間等可累加指標則會進行加總。

## 2. 找出最佳表現紀錄

開啟**分析 → 最佳距離（Analysis → Best Distance）**並依以下順序操作：

1. 選擇**跑步（Run）**、**騎乘（Cycling）**或**游泳（Swim）**。
2. 選擇**依距離（By Distance）**或**依時間（By Time）**。
3. 設定日期區間。
4. 選擇目標距離或目標時間。
5. 檢視排名紀錄；頁面會針對每個目標請求最多十筆排行結果。
6. 直接從紀錄列點開對應的原始活動。

**依距離**回答的是「我在這段距離內跑出或騎出的最快時間是多少？」；**依時間**回答的則是「在這段時間內我最遠移動了多少距離？」。畫面顯示的配速有助於在同一運動與相似情境下比較不同次的出力表現。

請勿將每一筆排行都直接視為正式個人最佳成績（PR）。這裡列出的是在所選資料與日期區間內偵測到的最佳有效區段，可能出自日常訓練活動、受 GPS 精準度影響，也會在活動重新處理或修正後隨之變動。

## 3. 在地圖上檢視歷史路線

開啟**地圖（Map）**，再設定時間與運動篩選條件。系統會為符合條件且具備可用 GPS 資料的活動繪製路線軌跡。

善用地圖達成以下任務：

- 依地點或路線形狀尋找過往活動。
- 比較重複訓練課表的實際執行地點。
- 在點開活動前，先行發現不完整或不合理的路線軌跡。
- 為選定的單一活動建立路線分享海報。

點選任一條路線即可開啟該活動的海報預覽。當您需要查證詳細指標、處理狀態或感測器證據時，可從海報直接前往完整的活動詳情頁。

地圖包含敏感的位置資料。分享前請務必仔細檢查海報與路線內容，避免洩漏住家、工作場所或其他私人起訖地點。

## 4. 排查令人意外的統計結果

如果某項年度總量、最佳表現或路線看起來不太對勁，請依序檢查：

1. 開啟對應的原始活動。
2. 核對開始時間、運動類型、來源平台、處理狀態與單位系統。
3. 檢查 GPS 軌跡、距離、持續時間、暫停區段以及相關感測器資料流。
4. 確認是否存在重複紀錄或運動分類錯誤。
5. 修正原始活動或相關設定，接著重新整理彙總頁面。

請始終以原始活動作為最終依據。彙總頁面能幫您發現異常，但通常無法單靠摘要畫面完成歸因或修復。

## 驗證結果

- 活動統計採用的是預期的運動類型、年份、指標與彙總週期。
- 點擊最佳表現列表中的任一列，都能開啟正確日期的原始活動。
- 在地圖上點選的路線確實對應到目標活動。
- 不會因為無 GPS 活動未出現在地圖上，而誤判為匯入遺漏。
- 任何準備分享的海報都已確認不含私人位置隱私資訊。

## 疑難排解

- **活動統計顯示了錯誤的運動類型**：返回「活動」頁面變更運動篩選條件，再重新開啟或重新整理活動統計頁。
- **只能選擇今年**：所選運動尚未有更早之前的有效活動紀錄，或是最早活動查詢尚未完成。
- **熱力圖與折線圖看起來不一致**：熱力圖統計的是有活動的天數，折線圖則依據所選指標與彙總粒度計算。
- **找不到預期的最佳表現**：放寬日期區間、核對運動類型與目標項目，並確認該活動包含可用的距離與時間資料。
- **某筆紀錄看起來快得不合理**：採用該數據前，先檢查 GPS 漂移尖峰、中途暫停、距離、時間與是否重複匯入。
- **某筆活動沒有出現在地圖上**：可能是超出目前的篩選範圍，或該筆活動缺少可用的 GPS 路線資料。
- **點選路線開啟的海報似乎不對**：分享前請先核對活動日期，並進入完整活動詳情頁確認。
