# 理解耐力訓練中的有效 VO2max

Trainingload.ai 會依據可用的活動證據估算有效 VO₂max／VDOT 數值。詳情檢視能讓您追蹤其歷史走勢，並在累積足夠可比較的跑步歷史後提供條件式趨勢展望。請記得，這些皆屬模型估算值，而非實驗室實測數值，亦非未來成績的保證。

[在示範帳號中開啟儀表板](https://demo.trainingload.ai/en/dashboard)，接著點選 **VO2Max** 卡片。示範帳號目前的紀錄多寡決定了是否顯示預測曲線；下方的預測截圖取自應用程式渲染的範例資料。

## 開始之前

- 匯入近期跑步活動，並等待系統處理完成。
- 檢查個人檔案中的最大心率、所選估值來源以及任何校正因子設定。
- 優先參考輸入資料可靠且訓練目的具可比性的活動，並留意感測器、地形或估值設定是否曾經更動。
- 記錄分析結論時，務必區分「單次活動估值」、「目前數值」與「四周預測」三者。

趨勢預測僅採用符合資格的跑步觀測紀錄。切換儀表板的運動篩選條件，並不會為騎乘或游泳產生 VO2Max 預測。

## 1. 開啟 VO2Max 詳情檢視

在儀表板上找到 **VO2Max** 並點選卡片。詳情畫面包含目前數值、可用的四周趨勢展望、趨勢圖表、歷史區間分頁、說明文字以及**詢問教練（Ask Coach）**按鈕。

即使目前無法產生預測，畫面上仍可顯示目前數值。請留意可用性提示訊息，並確認圖表上是否真的包含未來估值曲線。

## 2. 選擇歷史檢視區間

透過 **7**、**14**、**30** 或 **60** 天分頁選擇欲檢視的歷史紀錄區間。建議先選擇包含數筆具可比性活動的視窗。

當預測可用時，圖表也會同步顯示與所選分頁對應長度的未來視窗（上限為 30 天）。例如，切換至 7 天分頁時看到的未來區段會比 30 天分頁短，但上方摘要中的**四周後（In four weeks）**數值仍固定指向完整的四周終點。

## 3. 辨識畫面上各項數值的含義

| 顯示項目 | 代表意義 |
| --- | --- |
| 目前 VO2Max（Current VO2Max） | 系統目前呈現的指標數值。 |
| 歷史數值與活動資料點 | 所選歷史視窗內各日期的可用估值或紀錄。 |
| 目前模型估算水準（Current estimated level） | 當圖表提供此讀數時，代表模型在歷史截止點估算出的水準。 |
| 四周後（In four weeks） | 目前可用四周預測的終點估值。 |
| 參考範圍或 80% 預測區間 | 與預測連帶呈現的區間，標示名稱依目前採用的模型而定。 |

產品顯示的「目前數值」與模型推算的「目前估算水準」可能略有不同，比較前請先看清標籤與日期。此外，圖表上的未來資料點並不代表已完成的訓練。

將游標移至任一歷史或未來資料點，即可檢視該點讀數。若發現某個歷史點顯得異常，請依該日期前往**活動（Activities）**找出原始活動，先核對感測紀錄與估值來源，再判斷是否真的出現體能變化。

## 4. 解讀預測結果與其區間範圍

當趨勢展望可用時，摘要區會一併呈現**四周後**數值、相對於目前數值的變化方向、對應區間範圍以及歷史資料截止日期，請務必綜合判讀。

**參考範圍（Reference range）**並不等同於經過統計校準的 **80% 預測區間（80% prediction interval）**。如果頁面上明確標示為 80% 預測區間，記錄或轉述時請保留原本標籤。無論哪一種標示，都不保證未來實際數值必定落在此帶狀範圍內。

這項預測依據歷史觀測資料與模型假設推算，與 PMC 基於課表排程推估未來負荷的邏輯完全獨立。單純在日曆上新增一堂未來課表，並不會直接證明 VO2Max 將依畫面幅度提升。

建議將這組估值作為訓練回顧的輔助脈絡，並與實際課表執行品質及訓練負荷互相比對。訓練負荷的分析流程請參閱 [PMC 歷史與預測](/zh-hant/docs/guide/pmc-forecast)。

## 5. 處理無法顯示預測的狀況

修改任何設定之前，請先閱讀畫面上顯示的狀態提示：

| 提示訊息 | 建議下一步 |
| --- | --- |
| 需要更多跑步歷史資料（More running history is needed） | 持續累積符合資格且處理完成的跑步紀錄；單靠目前數值不足以建立預測證據。 |
| 需要更新的跑步紀錄（New running records are needed） | 檢查最近一次符合資格的觀測日期是否已過時，並匯入近期跑步活動。 |
| 計算方式已變更（The calculation method changed） | 檢查估值來源與校正因子設定；系統可能需要重新累積具可比性的新觀測紀錄。 |
| 暫無預測資料（Forecast unavailable） | 先運用現有的歷史趨勢，並檢查網路請求或資料狀態。 |

歷史圖表呈現空白，也可能只是因為選取的 7 天視窗內剛好沒有符合條件的觀測值。在認定所有紀錄遺失之前，請先切換至較長的歷史視窗；缺少估值並不代表數值為零。

請勿單純為了刷出好看的預測曲線而隨意修改最大心率或校正因子，任意更動設定會破壞前後資料的可比性，也會連帶改變呈現數值。

## 6. 向智能教練請教背後的證據

在詳情檢視中點選**詢問教練（Ask Coach）**，系統會預先擬好關於目前水準、歷史變化與可用四周展望的提問。確認內容符合需求後即可送出。

您也可以補充想深入剖析的具體日期與活動，請智能教練明確區分客觀記錄證據與模型推估，並指出目前缺少哪些判斷脈絡。點擊此入口只會預填問題，不會自動送出對話，更不會擅自改動訓練計畫。

在確認任何建議的計畫變更前，請先核對活動證據、計畫脈絡，並遵循標準的[智能教練確認流程](/zh-hant/docs/guide/ai-coach)。

## 檢查分析結果

建議一併記下歷史視窗長度、輸入資料來源、關鍵日期、目前數值、預測是否可用以及區間標籤名稱。完成檢視後，您應能清楚說出哪些實際觀測紀錄支撐了目前趨勢，哪些部分仍屬於模型展望。

## 常見問題

### 為什麼切換到 7 天分頁時，「四周後」摘要數值沒有改變？

分頁切換的是圖表的顯示視窗。摘要仍描述完整的四周預測終點，而圖表則只會呈現對應長度的一小段未來曲線。

### 為什麼有「目前數值」，卻沒有趨勢預測？

目前顯示值與趨勢預測對證據的要求門檻不同。當符合資格的跑步觀測數量不足、資料過舊、前後不具可比性或模型無法取得資料時，預測即可能無法顯示。

### 為什麼單次活動的估值與整體趨勢不同？

單次活動估值反映的是單場表現，而模型目前水準綜合了多筆歷史證據。請檢查該筆活動的來源、感測器品質、地形坡度與課表目的；評估整個訓練週期成效時，應綜合觀察多筆合適紀錄，切勿只看單一點位。

### 新增計畫課表會改變這項預測嗎？

PMC 是依據排定課表與過往訓練習慣推估未來負荷，而 VO2Max 展望則是建立在歷史觀測模型之上，請勿將兩者視為相同的計算機制。

### 為什麼這裡的數值與運動手錶或實驗室測驗結果不同？

不同工具採用的演算法、輸入資料與量測日期皆可能不同，請各自保持同一序列內的前後一致比較。完整量測與估算原理請參閱 [VO2 Max 最大攝氧量](/zh-hant/docs/metrics/maximal-oxygen-uptake)。
