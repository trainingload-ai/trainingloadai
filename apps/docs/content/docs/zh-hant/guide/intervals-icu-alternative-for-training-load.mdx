# Intervals.icu 訓練負荷替代方案比較

如果您目前已經在 Intervals.icu 分析訓練資料，可以先思考是要完整轉換工具，還是保留原有分析流程、同時使用 Trainingload.ai 負責計畫編排與回顧。

Intervals.icu 提供活動時間軸、功率與心率圖表、間歇分析與高度自訂圖表，其最新功能可參閱 [Intervals.icu 活動分析總覽](https://www.intervals.icu/features/analyze/)。

## 在 Trainingload.ai 上值得優先體驗的功能

- 將已完成活動關聯至計畫課表，直觀對照原始排程與實際執行結果。
- 在訓練計畫脈絡下，同步檢視活動時間軸、PMC 與表現趨勢。
- 直接從單筆活動或訓練計畫開啟智能教練，檢視分析回覆或審閱課表調整建議。

建議先從[活動詳情](/zh-hant/docs/guide/activity-detail)、[時間軸](/zh-hant/docs/guide/activity-timeline)與[管理計畫狀態](/zh-hant/docs/planning/plan-lifecycle)開始，直接比較您平常真正會用到的訓練任務。

## 連接您的 Intervals.icu 紀錄

1. 雲端帳號請依循[第三方平台連線指南](/zh-hant/docs/guide/connect-third-party-platforms#connect-intervalsicu)；自架版請參考 [API 金鑰設定](/zh-hant/docs/self-host/configuration#connect-intervalsicu)。
2. 勾選所需的同步方向。在開放雙邊同時更新同一份排程之前，先決定由哪一個平台維護訓練區間與計畫課表。
3. 先同步一筆已知活動，確認日期、持續時間、資料來源與感測器資料正確無誤。
4. 在[訓練日曆](/zh-hant/docs/guide/calendar)中將其關聯至計畫課表，接著比較預期負荷與實際負荷。

## 比較兩邊的數據結果

同一筆訓練活動在不同平台上的訓練負荷或區間分布可能略有差異。解讀落差前，請先核對原始紀錄、閾值設定以及訓練負荷來源優先順序。此外，連接活動紀錄並不會自動複製 Intervals.icu 裡所有的自訂圖表、自訂欄位或計畫。

建議先同時保留兩個平台，完整走完一次匯入、課表關聯與回顧流程，再決定哪種組合最符合需求。想先看介面操作，也可以直接[開啟線上示範](https://demo.trainingload.ai/en)。
