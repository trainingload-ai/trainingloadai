# 疑難排解

排錯時請從實際觀察到的現象著手。在還沒釐清究竟是哪一個環節出錯之前，切勿急著反覆斷開重連平台、刪除活動或重建訓練計畫。

## 登入或授權陷入無限迴圈

1. 確認瀏覽器或行動 App 能夠正常連線至服務。
2. 在發起 OAuth 授權的同一個瀏覽器工作階段中完成跳轉流程。
3. 在解除某項登入方式之前，確認帳號已綁定其他可用的登入方式或密碼。
4. 重新整理登入頁面後重試一次。

若第三方平台授權已核准，但 Trainingload.ai 仍顯示未連線，請重新開啟該平台設定視窗，查看是否出現回呼失敗或權限錯誤提示。

## 同步後的活動沒有出現

1. 先確認該筆訓練確實存在於原始來源平台。
2. 檢查該平台的連線狀態是否正常。
3. 若介面提供手動同步或對帳操作，點擊執行一次。
4. 等待匯入批次處理完成。
5. 到「活動」頁面依日期與運動類型搜尋。

切勿反覆中斷連線再重新連接；這麼做可能產生重疊的匯入任務，卻無法真正解決來源端權限問題。

## 看得到活動，但分析內容不完整

活動紀錄可能會在所有衍生圖表計算完成前先行顯示，請等處理結束後重新整理。若僅缺少某一類指標，請檢查原始感測資料流：

- 心率分析需要心率採樣資料。
- 功率分析需要功率採樣資料與相符的運動／檔案設定。
- 路線與海拔檢視需要 GPS／海拔資料。
- 配速與距離分析需要可用的距離與時間資料。

## 某項指標數值看起來不合理

請依以下順序逐項排查：

1. 運動類型與細項定義。
2. 單位系統與帳號時區。
3. 閾值數值與生效日期。
4. 訓練區間模型與自訂邊界。
5. 設定的負荷來源優先順序。
6. 原始活動感測資料流。

修改閾值會影響後續計算的解讀基準。調整時請記錄變更理由，避免為了讓單一課表看起來順眼而不斷微調數值。

## 課表無法儲存

若為耐力課表，請確認每個結構化步驟都具備有效的時間或距離以及支援的強度目標。若為肌力課表，請確認：

- 至少包含一個訓練動作。
- 每個動作皆已命名。
- 每個動作至少包含一組訓練組群。
- 每個動作至少包含一組正式訓練組（work set）。

編輯器會顯示對應語系的驗證提示，並保留草稿畫面方便您直接修正。

## 訓練計畫在其他地方遭到修改

若系統回報版本或狀態衝突，代表畫面載入後有另一個裝置或請求修改了同一份計畫。請先重新整理計畫、核對最新狀態後再重新套用編輯，切勿對過期版本盲目重試刪除或覆蓋操作。

## 行動 App 記錄尚未同步完成

在尚可復原的情況下，請保持 App 安裝狀態且切勿清除本機儲存空間。重新開啟記錄畫面讓 App 復原該筆訓練，並確認手機恢復網路連線。詳情請見[行動 App 記錄訓練](/zh-hant/docs/guide/mobile-recording)。

## 智能教練無法完成請求

- 精簡過於龐大的指令，或拆分成多個階段逐步處理。
- 確認目標訓練計畫或活動仍存在且具備存取權限。
- 檢視帳號剩餘的 AI 用量額度。
- 若結構化操作未通過驗證，改以清楚白話描述預期改動後重試。
- 切勿套用任何無法在變更前後預覽中核對的調整。

## 回報問題時請蒐集有效資訊

聯繫技術支援時，建議附上：

- 問題發生的大約時間與所屬時區。
- 使用平台（網頁版或行動 App）、作業系統與 App／瀏覽器版本。
- 發生問題的頁面或工作流程（不含任何登入憑證）。
- 安全可提供的活動雜湊 ID、計畫 ID 或第三方平台名稱。
- 畫面上顯示的完整原始錯誤文字。
- 已遮蔽個人隱私資訊的螢幕截圖。

切勿在回報內容中附上密碼、OAuth 權杖、API 金鑰或精確住家座標。
