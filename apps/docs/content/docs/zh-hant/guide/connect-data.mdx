# 連接訓練資料

將已完成的訓練匯入 Trainingload.ai，並確認其日期、資料來源與各項細節。請依據原始紀錄存放的位置，選擇第三方平台連線、手動上傳檔案或行動 App 記錄。

[在示範帳號中瀏覽活動](https://demo.trainingload.ai/en/activities)。上傳檔案或授權第三方平台需要登入您自己的帳號；下方的上傳畫面截圖取自真實應用程式中的示範測試帳號。

## 1. 選擇資料來源

| 匯入方式 | 適用情境 | 完成後請核對 |
| --- | --- | --- |
| 支援的第三方平台連線 | 來源平台存放了您想匯入或持續同步的訓練活動 | 平台提供的同步方向、日期區間、任務結果與匯入後的活動。 |
| 原始 FIT、TCX 或 GPX 檔案 | 單筆特定訓練、歷史封存檔，或暫不支援直連的平台 | 單檔格式檢查結果與匯入批次狀態。 |
| 行動 App 記錄 | 直接使用 Trainingload.ai 行動 App 記錄訓練 | 結束記錄後的同步狀態與產生的活動紀錄。 |

各平台支援能力與授權流程請參閱[整合平台總覽](/zh-hant/docs/guide/integrations)與[連接第三方平台](/zh-hant/docs/guide/connect-third-party-platforms)。請以您目前部署環境與帳號中實際顯示的操作為準；一次性歷史匯入與持續自動同步屬於兩種不同能力。

## 2. 為已知訓練指定單一主要來源

先鎖定一筆已知的原始訓練，記下日期、運動類型與大概時間。如果同一筆運動紀錄會從手錶或車錶同時轉發到多個服務，請在進行大量歷史回補前，先決定只由哪一個管道提供該紀錄。

建議妥善保留原始檔案。經過轉檔或僅含摘要的檔案，欄位完整性可能不如原始匯出的 FIT 檔。此外，活動匯入需要的是運動活動紀錄；全天健康資料匯出屬於另一種資料類型。

## 3. 透過選定的管道匯入資料

### 上傳活動檔案

1. 開啟**活動（Activities）**並進入上傳入口。
2. 選取原始活動檔案，等待系統完成格式檢查。
3. 核對偵測到的檔案格式與任何驗證錯誤；單憑副檔名並不足以保證真實檔案格式無誤。
4. 繼續執行上傳，並留意是否出現重複活動提示。
5. 在批次進度視窗中追蹤各檔案的處理結果；若不慎關閉視窗，可隨時重新開啟最近一次批次紀錄。

完整的格式驗證、重複偵測與批次狀態說明請參閱[上傳活動檔案](/zh-hant/docs/guide/upload-activity-files)。

### 第三方平台同步

開啟該平台的連線設定，詳讀可選的資料同步方向，完成授權並在畫面提供時執行首次匯入或同步。等待同步任務結束後，再前往「活動」清單中尋找該筆已知訓練。

不同平台的同步條件與歷史回溯天數各有差異。帳號顯示「已連線」並不代表預期的歷史活動已經全數到位。切記只在該平台的官方連線流程中輸入登入憑證。

### 行動 App 記錄

完成並儲存記錄後，讓 App 將其同步至帳號。在重新開始記錄同一堂訓練前，請先檢查是否有待恢復或待上傳的紀錄。詳細步驟請見[行動 App 記錄訓練](/zh-hant/docs/guide/mobile-recording)。

## 4. 區分「匯入進度」與「活動分析狀態」

| 畫面上看到的狀態 | 應該檢查的重點 |
| --- | --- |
| 匯入項目排隊中或處理中 | 在匯入批次畫面等待其最終處理結果。 |
| 完成或顯示活動連結 | 點開該活動，進一步確認其本身的分析處理狀態。 |
| 因重複而略過 | 確認系統比對到的是哪一筆既有活動。 |
| 部分失敗 | 辨識出失敗的檔案或分析項目，並先使用已成功的部分。 |
| 失敗 | 詳讀該項目的錯誤訊息後，再重試原始檔案或平台同步。 |

活動紀錄可能會在所有圖表與衍生指標計算完成前先行顯示。感測器資料原本就缺失、分析請求失敗，以及來源檔案不受支援，三者需要採取不同的處理方式。

## 5. 驗證匯入後的活動紀錄

核對資料來源、運動類型、本地日期、持續時間與距離，接著只檢視該筆紀錄實際包含的量測項目：

| 原始感測證據 | 可支援的分析內容 |
| --- | --- |
| GPS 採樣點 | 運動路線軌跡與地理位置脈絡。 |
| 心率採樣點 | 心率圖表與支援的心率衍生分析。 |
| 功率採樣點 | 功率圖表與基於閾值的強度分析；估算功率會額外標註。 |
| 可用的時間序列紀錄 | 詳細圖表、時間軸檢視與支援的區間統計。 |

平台連線無法憑空補出裝置當初未記錄或未分享的數據。若某項預期欄位缺漏，請先比對來源平台與原始檔案，再決定是否重試匯入。

## 6. 將活動銜接至日常訓練流程

開啟[活動詳情](/zh-hant/docs/guide/activity-detail)檢視表現，到訓練日曆核對本地日期並關聯至對應的計畫課表，最後依相應的運動類型與歷史區間檢視 [PMC 預測](/zh-hant/docs/guide/pmc-forecast)。

請注意，成功同步運動活動並不代表睡眠、HRV 或所有全天健康指標也一併匯入，請針對各項資料類別分開確認。

## 檢查結果

目標訓練應透過您指定的主要管道恰好出現一次，具備清楚的匯入與分析結果、正確的來源與日期，以及符合實際裝置配置且可解釋的感測器覆蓋情形。若該訓練屬於計畫課表，請確認身分無誤後完成關聯。

## 常見問題

### 平台顯示已連線，但找不到活動

請確認該平台支援的回溯區間、登入的是否為正確來源帳號、同步任務執行結果以及活動清單的篩選條件。可執行一次手動同步並等待該任務結束，切勿連續重複觸發匯入。

### 同一筆訓練出現了兩次

比較兩筆紀錄的來源標籤、開始時間、持續時間與感測資料完整度。在刪除任何一筆之前，先排查平台間的重複轉發設定，尤其要確認其中一筆是否已關聯至訓練計畫。

### 匯入後圖表是空的

檢查活動分析處理狀態，以及原始檔案是否確實包含可用的時間序列採樣點。僅含摘要數值的檔案無法產出所有圖表；若屬於請求載入失敗，請使用畫面上顯示的重試按鈕。

### 中斷第三方平台連線會刪除已匯入的歷史活動嗎？

中斷平台連線與刪除活動屬於兩種獨立操作。確認中斷前請詳讀對話框說明，中斷後亦可獨立檢視既有的歷史活動紀錄。
