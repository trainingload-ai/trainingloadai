# 管理進行中的訓練計畫

進行中的訓練計畫代表您已啟用並正在執行的課表排程。透過這個檢視，您可以查看每日課表、關聯已完成活動、對照訓練負荷，並隨時與智能教練展開後續討論。

您可從主選單的**計畫（Plan）**區域直接開啟，或從計畫清單中點選特定訓練計畫。

## 開始之前

- 以正確的開始日期啟用目標訓練計畫。
- 確認個人檔案時區與最新閾值設定無誤。
- 等待已完成活動處理完畢後再進行關聯。
- 檢視本週實際情況，而非假設當初的草稿至今仍完全吻合現實。

## 每日執行工作流程

1. 開啟目前計畫並找到今天的排定課表。
2. 開始訓練前先閱讀課表結構與備註。
3. 訓練完成後，點開實際活動紀錄並確認身分無誤。
4. 將該活動關聯至對應的計畫課表，並如實更新課表執行狀態。
5. 結合前後脈絡對照預期負荷與實際負荷，再判斷後續課表是否需要調整。

## 訓練計畫狀態

訓練計畫具備以下幾種狀態：

- **草稿（Draft）**：已儲存，但尚未開始執行。
- **進行中（Active）**：目前正在執行的計畫。
- **已暫停（Paused）**：暫時中止，但仍可進行排程調整。
- **已完成（Completed）**：已結束的完整計畫。
- **已取消（Cancelled）**：在完成前提前終止。

系統通常只會將單一計畫視為目前的執行排程。草稿與已完成計畫仍很適合回顧參考，但不屬於當前的每日執行工作區。

## 課表狀態

每堂計畫課表各有獨立狀態：

- **計畫中（Planned）**：已排定但尚未開始。
- **進行中（In progress）**：正在進行或部分處理中。
- **已完成（Done）**：已順利完成。
- **已略過（Skipped）**：刻意跳過未練。
- **已移動（Moved）**：已調整至其他日期。

如實更新課表狀態能保持計畫紀錄真實可靠。「略過一堂課」與「完成一堂低負荷課表」代表不同意義，兩者都應該清楚留存。

## 關聯已完成活動

當實際活動對應到某堂計畫課表時，請將兩者建立關聯。

建立關聯後，系統才能準確呈現以下比較：

- 計畫課表 vs 實際完成課表。
- 預期負荷 vs 實際負荷。
- 課表完成率。
- 訓練負荷達成度。
- 智能教練的計畫進度追蹤。

Trainingload.ai 在部分情境下會自動建議或建立關聯；如果系統配對到了錯誤的活動，您隨時可以手動解除關聯並改選正確紀錄。

## 預期負荷與實際負荷對照

訓練計畫檢視可同步比較：

- **預期負荷（Expected load）**：系統依課表結構估算出的計畫負荷值。
- **實際負荷（Actual load）**：實際完成之主要關聯活動的訓練負荷。

當預期負荷與實際負荷採用相容的訊號來源時（例如兩者皆為功率型負荷），比較結果最具參考價值；混合來源的估值則需要多加留意差異。

請將這項對照視為規劃參考訊號，而不是打分數的成績單。單一課表本就可能因當天狀況而特意放輕或加重，跨天與跨週的整體規律才更關鍵。

## 目前計畫檢視

目前計畫檢視專為每日按表操課設計，方便您快速完成：

- 查看今日排定課表。
- 瀏覽本週整體課表安排。
- 點開單堂課表詳情。
- 關聯已完成活動。
- 將課表標記為已完成或已略過。
- 因應作息變動挪動課表日期。
- 比較本週計畫負荷與已完成負荷。

若想在更廣的月曆視角下同時瀏覽計畫與實際活動，請切換至[訓練日曆](/zh-hant/docs/guide/calendar)。

當計畫處於進行中或已暫停狀態時，排程調整可套用於尚未完成的課表；已完成或已略過的課表一般應維持原狀作為歷史紀錄。

若需要一次調整多堂即將到來的課表，請開啟**訓練日曆（Calendar）**、對任一日期按右鍵並選擇**調整排程（Adjust schedule）**，在同一份草稿中審閱所有修改後再確認套用。詳細步驟請參閱[訓練日曆排程調整](/zh-hant/docs/guide/calendar#adjust-upcoming-workouts)。

## 計畫詳情檢視

計畫詳情頁更適合用來檢視整個訓練週期：

- 確認計畫中繼資料與目前狀態。
- 啟用草稿計畫。
- 瀏覽逐週課表結構。
- 檢視課表強度圖表或文字說明。
- 查看整體執行摘要。
- 請智能教練回顧剩餘課表。

從計畫詳情頁發起的智能教練對話，會自動帶入計畫脈絡與尚未完成的課表數量。

## 何時應該調整訓練計畫？

當原定排程與現實生活出現明顯落差時，就應該適時調整。

常見觸發情境包含：

- 錯過的課表持續累積。
- 實際訓練負荷連續高於預期負荷。
- 疲勞累積速度快於體能成長。
- 臨時賽事、差旅或額外恢復需求影響了下一週行程。
- 關鍵課表雖然練完了，但身體反應與預期落差極大。

切忌因為單日小幅波動就頻繁改動課表。調整的目標是讓計畫重新貼合現實，同時守住原本的核心訓練目的。

## 請智能教練協助追蹤

實用的提問範例：

- 「請回顧我目前訓練計畫的進度與負荷狀況。」
- 「這週還沒完成的課表中，哪幾堂最關鍵？」
- 「今天這堂課練得特別硬，明天課表應該挪動嗎？」
- 「我已經連續兩週實際負荷高於計畫，接下來應該怎麼微調？」
- 「請幫我在不偏離主目標的前提下，調整未來七天的排程。」

## 驗證目前狀態

- 計畫開始日期已將所有課表正確對應到目標日曆日期。
- 今日課表具備正確的執行狀態與備註。
- 關聯的活動確實是完成該堂課的真實訓練紀錄。
- 預期負荷與實際負荷各自保留其資料來源與意義。
- 移動未完成課表時，已完成或已略過的歷史紀錄完全不受影響。

## 疑難排解

- **看不到「目前計畫」**：確認目標計畫狀態為「進行中（Active）」，而非草稿、已暫停、已完成或已取消。
- **活動無法關聯至課表**：檢查日期區間、運動類型相容性、活動處理狀態，以及該活動是否已關聯到其他課表。
- **系統自動關聯了錯誤活動**：手動解除關聯，核對開始時間與運動類型後再改選正確活動。
- **編輯計畫時發生衝突**：代表另一台裝置或智能教練操作更新了計畫版本；請重新整理並檢視最新計畫後再重試。
- **缺少實際負荷數值**：應檢查已完成活動本身與其負荷來源，切勿改動計畫課表的預期估值。
