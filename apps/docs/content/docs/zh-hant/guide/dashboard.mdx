# 儀表板

儀表板是掌握近期訓練型態最快的方式，將摘要卡片、體能狀態與可自訂的總覽指標整合於同一畫面。

當您想快速回答以下問題時，請先看儀表板：

- 我最近練了多少？
- 我的訓練負荷正在上升、持平還是下降？
- 是哪一項運動主導了這波趨勢？
- 我是否需要進一步點開活動紀錄、PMC、功率、配速或心率頁面深究？

## 開始之前

- 匯入足夠數量的近期活動，讓所選時間區間具備參考意義。
- 比較強度型指標前，先設定好閾值與訓練負荷來源優先順序。
- 當跑步、騎乘與游泳採用不同閾值系統時，建議一次聚焦檢視單一運動類型。

## 趨勢檢視工作流程

1. 選定目標時間區間與運動類型。
2. 將體能狀態視為趨勢參考，而非醫療診斷或絕對準備度判定。
3. 找出出現明顯變化的卡片或圖表。
4. 點開背後造成該變化的具體訓練活動。
5. 調整訓練計畫之前，進一步查看對應的 PMC、功率、配速或心率分析頁。

## 全域篩選條件

儀表板支援全域篩選功能：

- **時間區間（Time range）**：在近期各個統計週期間切換。
- **運動類型（Sport type）**：聚焦於跑步、騎乘、游泳或全部活動。

調整篩選條件後，所有卡片與圖表都會同步更新以符合所選情境。

## 體能狀態

體能狀態卡片用於快速掃描目前的訓練全貌，適合作為初步觀察，而非單獨作為最終決策依據。

常見訊號包含：

- 長期訓練負荷與體能趨勢。
- 近期急性疲勞水準。
- 準備度／競技狀態脈絡。
- 訓練規律性。

想了解背後模型原理，請參閱：

- [長期訓練負荷（CTL）](/zh-hant/docs/metrics/pmc/chronic-training-load)
- [短期訓練負荷（ATL）](/zh-hant/docs/metrics/pmc/acute-training-load)
- [訓練壓力平衡（TSB）](/zh-hant/docs/metrics/pmc/training-stress-balance)

## 總覽卡片

總覽卡片彙整訓練量與表現相關指標。依您的紀錄資料而定，可呈現距離、持續時間、爬升高度、心率、功率、步頻／踏頻等各項訓練欄位。

先透過總覽卡片捕捉變化，再進入對應頁面深入檢視：

- **活動（Activities）**：查看數值背後的單次訓練課表。
- **PMC**：追蹤長期訓練負荷趨勢。
- **功率（Power）**：檢視 FTP、CP、NP、VI 與功率曲線脈絡。
- **配速（Pace）**：查看跑步配速、GAP、NGP 與最佳距離表現。
- **心率（Heart Rate）**：檢視心率反應、訓練區間、效率因子（EF）與有氧解耦。

## 編輯版面配置

在桌面版上，儀表板支援自訂核心區塊的版面配置，讓畫面更貼合您當前的訓練重點。

常見配置範例：

- 基礎期優先將訓練負荷與規律性擺在最上方。
- 賽前專項期優先呈現功率或配速指標。
- 高負荷週結束後的恢復階段，讓疲勞與恢復相關卡片保持醒目。

編輯完成後記得儲存配置，下次開啟儀表板時就會維持相同的版面結構。

## 如何解讀儀表板的變化

不要因為單一卡片某天突然波動就過度反應，更穩健的流程是：

1. 確認時間區間與運動篩選條件是否正確。
2. 開啟造成變化的近期活動紀錄。
3. 將客觀訓練負荷與主觀疲勞體感相互對照。
4. 需要結合計畫脈絡綜合解讀時，請教智能教練。

儀表板是分析的起點，最終訓練決策仍應綜合考量計畫目標、近期課表與實際身體感受。

## 驗證結果

- 啟用的篩選條件與您想回答的問題完全一致。
- 顯示的活動與總計涵蓋相同的日期與運動範圍。
- 每項趨勢變化都能追溯回具體的已完成活動。
- 仰賴閾值的指標均採用最新的個人檔案設定值。
- 桌面版儲存的版面配置在重新開啟儀表板後依然保留。

## 疑難排解

- **卡片內容為空**：放寬時間區間、清除運動篩選條件，並確認活動已達到「就緒」狀態。
- **總計與活動清單兜不攏**：核對時區、日期區間、運動篩選條件與處理狀態。
- **負荷或體能狀態出現非預期變動**：先檢查閾值變更歷史與負荷來源優先順序，不要立刻假設訓練量突變。
- **自訂版面沒有保留**：確認編輯後有按下儲存，且重新整理前帳號仍維持登入狀態。
- **單一卡片數值顯得極端**：先點開底層活動檢查感測器資料品質，再決定是否採信異常值。
