# 設定自行託管實例

請於安裝前選定資料存放位置與本機存取連接埠。安裝完成後，可在應用程式設定中選擇或更換 AI 服務商。

## 開始之前

- 僅使用發行套件內 `.env.example` 與實例結構定義中宣告的設定項目。
- 每次執行會改變狀態的生命週期操作前，請先執行對應的 `--dry-run --json`。
- 切勿將 `.env.selfhost`、密碼、API 金鑰或權杖貼到聊天室、問題回報單或共享終端機紀錄中。
- 既有資料目錄包含你的訓練紀錄，切勿手動替換或清空。

## 選擇本機資料路徑 [#choose-the-local-data-path]

預設路徑為發行目錄內的 `./data`，其中包含 PostgreSQL 資料、上傳檔案、操作紀錄、備份與快取。應用程式會將該主機路徑的上傳目錄掛載至容器內的 `/data/uploads`，無須額外架設物件儲存服務。

若要在首次安裝前指定其他路徑：

1. 在已解壓縮且通過驗證的發行目錄中，從隨附範本建立私有的實例設定檔：

   ```bash
   umask 077
   cp .env.example .env.selfhost
   chmod 600 .env.selfhost
   ```

2. 在本機使用 `openssl rand -hex 32` 產生三組不同的 32 位元組隨機值，並替換 `.env.selfhost` 中的三個機密佔位符。一般安裝程式會自動完成此步驟。
3. 取消註解 `SELF_HOST_DATA_ROOT` 並設為專用路徑，例如：

   ```dotenv
   SELF_HOST_DATA_ROOT=/srv/trainingload-data
   ```

4. 執行安裝程式預演，確認回傳 `"ok": true` 後再正式安裝：

   ```bash
   ./install.sh --dry-run --json
   ./install.sh --json
   ```

目標目錄可以尚未建立，或專屬於此實例。管理 CLI 會拒絕檔案系統根目錄、發行目錄的上層路徑、已簽章發行目錄的子樹、不安全的符號連結，以及含有無關既有檔案的目錄。

切勿在運作中的實例直接修改 `SELF_HOST_DATA_ROOT` 作為檔案遷移捷徑。搬移既有實例必須先建立已驗證備份，再還原至全新初始化的目標路徑。

## 控制網路暴露範圍

預設僅將客戶端 HTTP 連接埠發佈於本機迴路：

```dotenv
SELF_HOST_SITE_ADDRESS=http://localhost:43210
SELF_HOST_HTTP_BIND=127.0.0.1
SELF_HOST_HTTP_PORT=43210
```

若要改用其他可用連接埠，請同時修改網站位址與 HTTP 連接埠。請將 PostgreSQL 與伺服器保留在私有 Compose 網路內。若需從其他電腦連線，請使用 SSH 通道並維持瀏覽器來源為本機位址。應用程式套件不包含 Caddy、HTTPS 連接埠或 Docs 設定檔。

請透過生命週期入口驗證主機層級變更：

```bash
./self-host start --dry-run --json
./self-host start --json
./self-host doctor --json
```

### 本機請求路徑

在瀏覽器中透過已設定的本機位址存取應用程式。資料庫與內部應用程式服務不需要公開連接埠，切勿為了排解連線問題而將其暴露到網際網路。

## 你的個人帳號

首次開啟應用程式時輸入使用者名稱，接著完成引導設定。單一實例僅供單人使用，不支援公開註冊或多帳號模式。

自行託管採用本機帳號，而非雲端版的註冊或社群登入流程。逾期的本機工作階段會自動恢復。確認刪除帳號後，系統會移除該帳號資料並在完成後回到使用者名稱設定畫面。請另行管理備份與實例設定檔；刪除帳號不會移除這些檔案。

## 連接 Intervals.icu [#connect-intervalsicu]

自行託管透過擁有者的**個人 API 金鑰**連接 Intervals.icu，不需要也不支援 Intervals.icu OAuth 客戶端、重新導向 URI 與 Webhook。

自行託管亦支援 [Garmin Personal API](/zh-hant/docs/self-host/garmin-personal-api)，但未啟用 COROS MCP。這兩項個人連接皆不需要額外的主機機密設定。

連接 Intervals.icu 的步驟如下：

1. 開啟 [Intervals.icu Settings](https://intervals.icu/settings)，在頁面下方複製個人 API 金鑰。客戶端連接對話框中的**取得 API 金鑰**按鈕可直接開啟此頁面。
2. 在新手引導的「匯入活動」步驟中選擇 **Intervals.icu**，或稍後開啟**帳號 → 第三方連接 → Intervals.icu**。
3. 輸入 API 金鑰，依需求選擇活動、計畫課表、健康資料與運動設定的同步方向，然後儲存。
4. 執行一次手動同步，並確認最新同步時間與匯入結果。

依據 [Intervals.icu Open API 文件](https://www.intervals.icu/features/open-api/)，每位使用者皆可使用個人 API 金鑰呼叫 REST API，涵蓋活動上傳／下載、健康資料與計畫課表。金鑰只會傳送到你的本機伺服器；伺服器會以安裝期間產生的專用整合機密透過 AES-256-GCM 加密，將密文存入 PostgreSQL，且絕不會在後續 API 回應中回傳明文。

這並非離線功能。啟用後，本機伺服器會直接連線至 `intervals.icu`，並依你選擇的同步方向讀取或傳送資料。此金鑰專屬於個別 Intervals.icu 使用者，切勿放入共用環境變數，或貼進日誌、問題回報單或聊天室。

備份檔包含 API 金鑰的密文，但實例機密必須另行妥善保存於安全位置。還原資料庫時請一併還原原始驗證與整合機密，以確保已儲存的憑證能正常解密。管理工具不會列印或匯出這些機密，完整步驟請參閱發行套件中的 `BACKUP_RESTORE.md`。

## 在客戶端設定 AI [#configure-ai-in-the-client]

AI 功能預設為停用。新手引導最後一步會直接提供 BYOK AI 設定，而非 Trainingload.ai 雲端服務商同意畫面；你也可以先略過，日後再設定：

1. 開啟本機客戶端。
2. 於新手引導期間開啟**設定你的 AI 服務**，或稍後開啟**設定 → 自行託管 AI**。
3. 選擇 OpenAI、DeepSeek、OpenRouter、DashScope 或**自訂 OpenAI 相容服務**。
4. 初次設定或切換服務商時輸入服務商 API 金鑰，並填入標準模型與推理模型名稱。內建服務商的 Base URL 可留空以採用預設端點，自訂 OpenAI 相容服務商則必須填寫。
5. 儲存後開啟任一 AI 功能並驗證一次請求。

請使用服務商支援的模型識別碼。遠端 Base URL 應使用 HTTPS；只有在你完全了解並掌控該區網網路路徑的情況下，自訂區網模型端點才可使用 HTTP。

OpenAI API 金鑰與 ChatGPT Plus 或 Pro 訂閱分屬不同服務。ChatGPT 訂閱無法當作 API 金鑰輸入，也不包含此實例的 API 使用量。

### 金鑰儲存方式

- 瀏覽器只會將金鑰傳送到你的本機 `server`。
- 伺服器會從實例驗證機密衍生加密金鑰，並以 AES-256-GCM 將服務商金鑰加密儲存於 PostgreSQL。
- 後續 API 回應僅回傳是否已設定金鑰，絕不回傳明文金鑰。
- 在應用程式內儲存的 AI 設定會立即生效，並優先於環境變數設定。
- 選擇**無（None）**會刪除已儲存的服務商憑證並停用 AI。

還原資料庫時，請一併還原原始實例驗證機密。不同的機密無法解密既有 AI 憑證或驗證狀態；重新啟動前請先確認使用原始設定。

### 離開主機的資料

即使停用 AI，你仍可正常使用活動紀錄、訓練計畫與分析功能。啟用外部 AI 服務商後，系統會將回答該問題所需的提問內容與訓練資訊傳送給該服務商，請事先確認其資料保留、隱私、所在地與計費條款。

自行託管不使用 Trainingload.ai 雲端會員方案或 AI 點數。**AI 使用量**頁面說明使用自有服務商時的計費方式，實際 API 用量、餘額與帳單請前往該服務商後台查看。

## 公開檔案工具的選用診斷功能

在 `.env.selfhost` 中設定 `PUBLIC_FAILED_UPLOAD_CAPTURE_ENABLED=true`，可在公開檔案工具遇到伺服器錯誤時保留原始檔案。此設定預設為 `false`。擷取的檔案可能包含 GPS 或其他個人資料；它們會存放在 `data/operations/public-upload-failures`，排除於備份之外，並於 72 小時後或達到容量／數量上限時自動清除。

## 自動化佈建的環境變數備援

發行套件結構仍允許在 `.env.selfhost` 中填入完整的服務商設定群組，以支援無人值守佈建。此為備援機制，並非建議的互動式設定路徑。客戶端絕不顯示環境變數中的金鑰；當擁有者從環境變數管理切換為客戶端管理設定時，必須重新輸入新的金鑰。

## 驗證設定

- 主機層級變更後，`./self-host doctor --json` 回傳 `"ok": true`。
- 資料根目錄包含實例標記與預期的子目錄，且無無關檔案。
- AI 設定頁面僅對實例擁有者顯示。
- 儲存 AI 設定後輸入欄位會自動清空，頁面只顯示已設定金鑰。
- 自行託管的第三方連接頁面顯示 Intervals.icu 與 Garmin Personal API（皆為 API 金鑰流程，無 OAuth），不會顯示 COROS MCP 為可用項目。
- **AI 使用量**頁面不會顯示會員結帳、點數餘額或點數包，也不會呼叫 `/billing/*` 端點。
- 儲存 Intervals.icu 金鑰後輸入欄位會清空，僅顯示末四碼，且手動同步可順利完成。
- 停用 AI 後可阻止新的服務商呼叫，同時不影響任何非 AI 產品功能。

## 疑難排解

- **資料根目錄遭到拒絕：** 請選擇位於發行目錄之外的空白專用路徑，切勿繞過標記或符號連結檢查。
- **找不到 AI 設定區塊：** 確認實例為自行託管模式，且目前已使用已認領的擁有者身分登入。
- **更換服務商時要求重新輸入金鑰：** 系統刻意設計在切換服務商時必須重新提供憑證。
- **還原後 AI 無法運作：** 重新啟動前，請先確認已還原原始實例驗證機密。
- **還原後 Intervals.icu 無法運作：** 確認已隨資料庫一併還原原始整合機密。
- **上游服務商拒絕模型名稱：** 請從服務商帳號複製精確的模型識別碼，並確認該金鑰具備存取權限。
