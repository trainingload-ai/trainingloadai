# 自行託管與雲端版比較

如果想直接開始使用 Trainingload.ai，請選擇雲端版。如果你希望將訓練資料保存在自己的電腦或伺服器上，且願意自行安裝與維護應用程式，請選擇自行託管。

## 快速比較

| 重視項目 | 雲端版 | 自行託管 |
| --- | --- | --- |
| 開始使用 | 開啟應用程式並建立帳號即可使用 | 下載發行套件，並依照安裝指南在自有裝置部署 |
| 資料存放位置 | Trainingload.ai 雲端服務 | 你的裝置，包含活動紀錄、訓練計畫與上傳檔案 |
| 匯入訓練資料 | 連接受支援的運動平台或上傳活動檔案 | 上傳活動檔案，或使用個人金鑰連接 Intervals.icu 與 Garmin Personal API |
| 使用智能教練 | 使用帳號方案隨附的 AI 額度 | 預設關閉；自行設定外部 AI 服務並向該服務商付費 |
| 帳號模式 | 使用你的雲端帳號 | 每個自行託管實例僅供單人使用 |
| 備份與還原 | 由 Trainingload.ai 維護雲端服務 | 由你自行保存備份並在需要時還原 |
| 軟體更新 | 由 Trainingload.ai 自動更新服務 | 依照升級指南安裝新的發行版本 |

## 哪一種更適合你？

**選擇雲端版**：如果你希望把時間專注在訓練與回顧課表，不想自行安裝軟體、執行更新或管理備份。

**選擇自行託管**：如果你希望自行掌控訓練資料的存放位置、能夠維護運行應用程式的裝置，並願意持續更新與備份。自行託管僅供個人使用，單一實例無法容納多位使用者。

## 先確認訓練資料的匯入方式

自行託管目前支援：

- 上傳 **FIT、GPX 與 TCX** 活動檔案；
- 使用個人 API 金鑰連接 **Intervals.icu**；
- 使用個人 API 金鑰連接 **Garmin Personal API**。

如果你高度仰賴特定運動平台，請先檢視[連接資料](/zh-hant/docs/guide/connect-data)與[自行託管連接設定](/zh-hant/docs/self-host/configuration#connect-intervalsicu)。雲端版與自行託管的連接方式不盡相同。若其他平台支援匯出受支援格式的活動檔案，你也可以改用手動上傳。

**Trainingload.ai 目前尚未支援 Apple Watch 應用程式。**

## AI 的運作方式與費用

AI 功能預設為關閉，不設定 AI 也能完整使用所有非 AI 功能。若要使用智能教練，請在設定中選擇服務商並輸入你自己的 API 金鑰；詳見[在客戶端設定 AI](/zh-hant/docs/self-host/configuration#configure-ai-in-the-client)。

自行託管不使用 Trainingload.ai 雲端會員方案或 AI 點數，API 使用費用由你所選的 AI 服務商直接向你收取。

當你使用外部 AI 服務時，該次請求所需的訓練資訊會傳送至該服務商。將應用程式安裝在本機並不會讓外部 AI 服務改為本機運行；與第三方運動平台同步資料同樣需要網際網路連線。

## 你需要負責的維護事項

- 維持裝置有足夠的可用磁碟空間，並在需要時啟動應用程式。
- 更新前務必先執行備份，並將複本存放在運作實例以外的其他位置。
- 定期確認備份可正常還原，確保裝置故障時擁有可用複本。
- 依照[管理與升級指南](/zh-hant/docs/self-host/operations)更新應用程式。

## 下一步

選擇雲端版者，請[開啟應用程式](https://app.trainingload.ai/en)並依照[快速上手](/zh-hant/docs/guide/getting-started)匯入第一筆活動。

選擇自行託管者，請從[安裝指南](/zh-hant/docs/self-host/installation)開始。安裝、備份與升級步驟均於各自專屬指南中詳細說明。
