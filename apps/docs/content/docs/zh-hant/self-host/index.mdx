# 自行託管

透過自行託管，你可以在自己的電腦或伺服器上使用 Trainingload.ai。你的活動紀錄、訓練計畫與上傳檔案皆保存在自有裝置上，並透過瀏覽器檢視與管理訓練。

每個自行託管實例僅供單人使用，由你自行負責維護裝置、更新軟體與管理備份。如果你希望開啟應用程式就能直接開始使用，請先閱讀[自行託管與雲端版比較](/zh-hant/docs/self-host/self-host-vs-cloud)。

## 支援功能

- 匯入活動紀錄，並檢視活動詳情、時間軸與訓練負荷。
- 在行事曆中安排訓練課表，並比較計畫與實際完成的訓練。
- 上傳 FIT、GPX 或 TCX 檔案，或使用個人金鑰連接 Intervals.icu 與 Garmin Personal API。
- 設定自己的 AI 服務以啟用智能教練，或將 AI 功能保持關閉。

## 安裝前的準備工作

- 一台符合[安裝需求](/zh-hant/docs/self-host/installation)且已安裝 Docker Compose 的裝置。
- 足以容納訓練資料與上傳檔案的磁碟空間。
- 獨立於主機之外的備份存放位置，以便在裝置故障時進行還原。

請使用官方提供、具明確版本號且經簽章的發行套件，並在安裝前依照指南完成驗證。你不需要自行編譯原始碼或組裝容器。Docker Compose 為目前支援的安裝方式。

## 資料流向說明

活動紀錄、訓練計畫與上傳檔案皆儲存在你的裝置上。連接第三方運動平台時，系統會依照你選擇的同步選項傳送或接收資料；使用外部 AI 服務時，僅會將該次請求所需的訓練資訊傳送給所選的服務商。

AI 功能預設為關閉。若要啟用，請依照[設定指南](/zh-hant/docs/self-host/configuration)填入你自己的服務商 API 金鑰，API 使用費將由該服務商計費。
