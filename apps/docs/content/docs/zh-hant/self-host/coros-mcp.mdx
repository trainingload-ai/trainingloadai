# COROS 連接

自行託管版本目前不支援直接連接 COROS。請先從來源平台匯出受支援的 FIT、TCX 或 GPX 活動檔案，再[上傳至 Trainingload.ai](/zh-hant/docs/guide/upload-activity-files)。

自行託管版本目前支援的個人連接包括：

- [Intervals.icu](/zh-hant/docs/self-host/configuration)
- [Garmin Personal API](/zh-hant/docs/self-host/garmin-personal-api)

若使用雲端版，請參閱[第三方平台連接指南](/zh-hant/docs/guide/connect-third-party-platforms)。
