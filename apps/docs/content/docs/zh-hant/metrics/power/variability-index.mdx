# 變異指數（VI）

**變異指數（Variability Index，簡稱 VI）**用來描述一趟騎乘（或具備跑步功率資料的跑步）中功率輸出的平穩程度。白話來說，它能告訴你這趟訓練是穩定巡航，還是反覆劇烈加減速。

## 計算公式

VI 等於[標準化功率（NP）](/zh-hant/docs/metrics/power/normalized-power)除以平均功率（Average Power）：

```text
VI = NP / AvgPower
```

- **NP** 反映生理代價（包含功率波動帶來的額外耗損）。
- **平均功率** 反映實際輸出的機械作功。

## 為何要關注 VI？

雖然 VI 最初是為了單車功率分析而設計，但在跑步功率計（Stryd、Garmin、COROS 等）普及後，也成為跨項目的實用參考指標。

### 1. 配瓦／配速效率
- **單車**：在鐵人三項與個人計時賽中，VI 反映你維持穩定輸出的能力。越接近 1.0，通常代表越少把體力浪費在無謂的拉扯與衝刺上。
- **跑步**：在馬拉松配速中，VI 反映跨地形與路況的體能分配經濟性。由於跑步不會像單車那樣「滑行不出力」，跑步的 VI 通常比單車低；若偏高，常表示上坡太衝或節奏忽快忽慢。

### 2. 辨識賽事型態需求
- **公路車賽**：繞圈賽常出現很高的 VI（> 1.2），因為選手必須反覆在 0 W 滑行與出彎全力抽車之間切換。
- **越野跑**：因地形劇烈起伏，VI 通常高於平路路跑；這反映的是賽道本質，而非配速失誤。

## 常見參考值

由於運動型態不同，**跑步的 VI 通常顯著低於單車**。

### 單車（粗略參考）

| VI 範圍 | 騎乘類型 | 說明 |
| :--- | :--- | :--- |
| **1.00 - 1.05** | 鐵人三項／計時賽 | 極為平穩，長距離穩態賽事常見目標範圍。 |
| **1.05 - 1.10** | 爬坡／穩定訓練 | 相對平穩，許多 Zone 2 有氧騎乘落在此區間。 |
| **1.10 - 1.20** | 丘陵路線／團騎 | 受坡度變化與集團輪車拉扯影響，呈現中度變異。 |
| **> 1.20** | 繞圈賽／登山車（MTB） | 高度變異，包含大量滑行與無氧加速。 |

### 跑步（粗略參考）

| VI 範圍 | 跑步類型 | 說明 |
| :--- | :--- | :--- |
| **1.00 - 1.02** | 田徑場／平路馬拉松 | 極為平穩，配速控制良好的馬拉松常見水準。 |
| **1.02 - 1.05** | 起伏路跑／城市街道 | 受路口停等、天橋與緩坡影響的正常波動。 |
| **1.05 - 1.15** | 越野跑／法特雷克變速跑 | 高度變異，伴隨爬升、技術下坡或間歇加速。 |

## Trainingload.ai 如何運用 VI

- **跑步／馬拉松**：平路馬拉松中，較低的 VI 通常代表更穩定的配速；在丘陵路線上，建議以功率或體感控制出力，而非硬追平路目標配速。
- **鐵人三項／計時賽**：較低的 VI 多半代表較少高耗能的無謂衝刺，但仍須考量路線起伏與風勢。
- **公路車／登山車**：高 VI 往往是項目本身的需求特徵；Trainingload.ai 會將其視為賽事脈絡，而不會直接判為配速失誤。
- **課表回顧**：VI 會與 NP、平均功率、IF、地形以及原訂課表目標合併解讀。
