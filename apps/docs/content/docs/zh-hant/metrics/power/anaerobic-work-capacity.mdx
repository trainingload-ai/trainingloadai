# W'（無氧做功容量）

**W'**（讀作 “W prime”）代表你嘅 **無氧做功容量（Anaerobic Work Capacity）**。佢係一個能量量（通常以 Joules 計），用嚟描述當你高過 **[臨界功率（CP）](/zh-hant/docs/metrics/power/critical-power)** 時，你可以「額外消耗」嘅有限電池。

## 核心概念

你可以將表現理解成兩部份：

1. **有氧引擎（CP）**：好似油缸。只要強度低過 CP，理論上可以維持好耐。
2. **無氧電池（W'）**：好似容量有限嘅電池。一旦功率高過 CP，就開始放電。

## W' 耗盡同回復

- **耗盡（depletion）**：當功率 > CP，`消耗速度 = 當前功率 - CP`。超得愈多，W' 耗得愈快。
- **回復（recovery）**：當功率 < CP，電池開始回復。回復速度取決於你低過 CP 幾多（越輕鬆回得越快），同你嘅有氧回復能力。

## 「用盡」代表乜？

當 **W' 去到 0**，唔代表你郁唔到；代表你 **維持唔到任何高過 CP 嘅功率**。你被迫降返到 CP 或以下。

## 實用場景

- **比賽配速**：短 TT 或短爬坡，合理管理 W'，目標係衝線時接近「用盡」。
- **間歇訓練**：睇 W' balance（W' bal），檢查你嘅間歇係咪真係耗到無氧儲備。
