# W′（無氧作功能力）

**W′**（讀作「W prime」）代表你的**無氧作功能力（Anaerobic Work Capacity）**。它是一個能量總量，通常以焦耳（J）或千焦（kJ）表示，用來描述高於**[臨界功率（CP）](/zh-hant/docs/metrics/power/critical-power)**之上可供消耗的有限作功儲備。

## 核心概念

你可以將高強度表現拆成兩個部分來理解：
1. **臨界功率（CP）**：模型中可長時間維持的高強度穩態門檻。
2. **W′**：當輸出功率超過 CP 時所動用的有限作功儲備。

## W′ 的消耗與恢復

- **消耗**：當輸出功率 > CP 時，`消耗速率 = 當前功率 − CP`。超過 CP 越多，W′ 消耗得越快。
- **恢復**：當輸出功率 < CP 時，W′ 開始回充。恢復速度取決於輸出低於 CP 的幅度，以及你的有氧恢復能力。

## 「耗盡」代表什麼？

當 **W′ 降至 0** 時，並不代表你完全踩不動或跑不動，而是代表你**無法再維持任何高於 CP 的功率輸出**，被迫回落至 CP 或以下。

## 實務應用

- **賽事配瓦策略**：在短距離計時賽或爬坡賽段中，妥善規劃 W′ 的消耗節奏，力求衝過終點線時剛好把儲備用盡。
- **間歇課表檢核**：透過追蹤 W′ 餘量（W′ bal），確認高強度間歇是否真的有效刺激並消耗無氧儲備。

## Trainingload.ai 如何運用 W′

Trainingload.ai 運用 W′ 解讀高於 CP 的作功負荷。兩次總 TSS 相近的課表，可能因為消耗的 W′ 不同而對身體產生截然不同的超閾值壓力。

W′ 特別適合用來回顧：

- 短距離進攻、坡度重複段或 VO₂max 間歇的強度是否到位；
- 間歇之間的恢復段是否夠輕鬆，足以恢復下一趟的重複輸出能力；
- 個人能力輪廓偏向較大的短時間爆發儲備，還是較強的持續穩態輸出。

若想透過模型估算，請使用[臨界功率與 W′ 計算機](/zh-hant/critical-power-calculator)，可一次擬合 CP 與 W′。

## 使用限制

W′ 高度依賴模型擬合，其準確度取決於用來建立功率—時間曲線的全力輸出資料。如果近期紀錄缺乏 1–5 分鐘與 10–20 分鐘的全力測試，估算結果可能較不穩定。
