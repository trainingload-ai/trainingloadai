# 臨界功率（CP）

**臨界功率（CP）**係耐力生理學入面其中一個最重要嘅概念。佢界定咗一條生理分界線：介乎「可持續」同「不可持續」嘅運動強度。

簡單講，CP 係你可以維持而唔會進入 **代謝非穩態（metabolic non‑steady‑state）**嘅最高功率（例如乳酸一路失控上升、VO2 slow component 持續向 VO2max 攀升）。

1965 年 Monod 同 Scherrer 提出 Critical Power 模型，將 CP 描述成「喺唔出現逐步疲勞下可維持嘅最大做功速率」，同時引入一個「高於 CP 可用但有限嘅能量儲備」（後來稱為 W'）。

## 核心模型：兩參數模型

CP 嘅理論基礎常被稱為 **兩參數模型（two-parameter model）**：將表現拆成兩個部份：

1. **臨界功率（CP）**：
   - **性質**：有氧系統嘅「上限」
   - **類比**：一個大油缸。只要強度低過 CP，理論上可以維持好耐（實際會受肝醣耗盡等因素限制）
   - **單位**：Watts（W）

2. **[W'（W Prime）](/zh-hant/docs/metrics/power/anaerobic-work-capacity)**：
   - **性質**：無氧做功容量（Anaerobic Work Capacity）
   - **類比**：容量有限嘅電池。一旦功率高過 CP，就開始「用電」
   - **單位**：Joules（J）或 kilojoules（kJ）

### 功率—持續時間關係

呢兩個參數形成大家熟悉嘅雙曲線關係：

```text
P = CP + W' / t
```

或者改寫成「力竭時間」：

```text
t = W' / (P - CP)
```

意思係：

- **當 P > CP**：你可以頂得幾耐，取決於 W' 有幾大，以及你超過 CP 幾多。超得愈多，W' 耗得愈快。
- **當 P ≤ CP**：模型入面時間趨近無限（實際上會受其他限制）。

## 生理意義：強度域嘅分界

運動生理學入面，CP 常被視為 **Heavy** 同 **Severe** 強度域之間嘅分界：

- **低過 CP**：
  - 可以達到生理穩態
  - 血乳酸可能上升但可以穩定
  - VO2 可以穩定喺次最大水平

- **高過 CP**：
  - **冇穩態**
  - 血乳酸會一路上升直至你停
  - VO2 常見 slow component，並向 VO2max 上升
  - 一旦 W' 用盡，就維持唔到該功率，需要跌返到 CP 或以下

## CP 同 FTP

雖然 CP 同 [功能性閾值功率（FTP）](/zh-hant/docs/metrics/power/functional-threshold-power) 常被混用，但定義同典型數值其實有少少差別：

1. **定義唔同**：
   - **FTP**：一般定義為約 60 分鐘可維持嘅最高平均功率，屬於實用、表現導向概念
   - **CP**：模型參數，代表 CP 模型入面嘅疲勞閾值

2. **典型數值**：
   - CP 往往會比 FTP **略高**
   - 以 CP 強度踩，通常大概頂到 30–40 分鐘，而唔係 60 分鐘
   - 喺 Trainingload.ai，我哋常用近似：`FTP ≈ CP 的 95%–96%`

3. **用途**：
   - **FTP** 多用作訓練區間基準（Zone 1–Zone 7）
   - **CP + W'** 模型對短時間高強度（間歇、突圍、衝刺）嘅力竭時間預測好有用

## W' 耗盡同回復

W' 好似一個可充電電池：

- **放電**：當 P > CP，W' 會按 (P - CP) 比例消耗
- **充電**：當 P < CP，電池開始回復；回復速度視乎你低過 CP 幾多（愈易愈快），同你嘅有氧回復能力
  - 完全休息（0W）回得最快
  - 只係略低過 CP（例如 90% CP）回得好慢

所以做間歇訓練時，回復段強度點樣設好重要。

## Trainingload.ai 點樣估算 CP

Trainingload.ai 會用歷史數據嘅 **MMP（Max Mean Power）** 去擬合，而唔需要你做特定協議（例如 3 分鐘全力測試）。

1. **揀數據**：過去約 90 日唔同時長嘅最佳平均功率（例如 1 分、3 分、5 分、10 分、20 分……）
2. **模型擬合**：由呢啲 time–power 點擬合 CP 同 W'
3. **估算 FTP**：由 CP 推算 FTP（預設 0.95 × CP）

如果你有測試檔案，亦可以上載做一次性估算：見 [從活動檔案估算 FTP 與 CP](/zh-hant/ftp-calculator)。

### 提升準確度嘅小貼士

要令 **CP** 估算更準，最好令你嘅功率—時間曲線包含足夠嘅 **最大努力**：

- **短時長**：包含 3–5 分鐘最大努力（對 W' 好重要）
- **中/長時長**：包含 10–20 分鐘或更長嘅最大努力（對 CP 好重要）

如果你長期只做低強度踩，系統可能會低估你嘅 CP 同 W'。
