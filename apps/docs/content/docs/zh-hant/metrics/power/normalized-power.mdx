# 標準化功率（NP）

標準化功率（Normalized Power，簡稱 NP）能將起伏波動的功率曲線轉換成單一等效穩定強度。直覺上，它試圖回答的問題是：

- 如果我改以固定功率騎乘、卻承受相同的生理消耗，那個固定功率大約會是多少瓦？

相較於平均功率，NP 對高強度瞬間拉扯更加敏感，因此非常適合用來估算訓練負荷（例如功率版 TSS）。

## 為何需要 NP？

運動生理學指出，運動強度與生理代價（肝醣消耗、乳酸堆積、內分泌壓力）之間並非線性關係——強度越高，生理代價的攀升幅度越不成比例。

### 線性 vs 指數
- **線性視角（平均功率）**：穩定騎 1 小時 200 W，與「30 分鐘 100 W ＋ 30 分鐘 300 W」的算術平均完全一樣（都是 200 W）。
- **生理視角（NP）**：300 W 造成的生理壓力，遠遠無法被 100 W 的輕鬆段完全抵銷；後者給身體帶來的感受往往更接近全程穩定騎乘約 260–270 W。

NP 透過**四次方加權**放大高功率路段的權重，目的就是比簡單平均功率更貼近真實的代謝成本。

## Trainingload.ai 如何計算 NP

Trainingload.ai 遵循業界標準的 NP 演算法：先計算 30 秒滑動平均，接著取四次方、求平均值，最後再取四次方根。

```text
P_smooth(t) = (1/30) * sum_{i=0..29} P(t-i)
NP = 4th_root( (1/N) * sum_{j=1..N} (P_smooth(j))^4 )
```

其中：
- $P(t)$ 為時間 $t$ 的瞬時功率
- $P_{smooth}(t)$ 為時間 $t$ 的 30 秒滑動平均功率
- $N$ 為採樣點總數

## 常見應用情境

### 1. 賽事分析
- **繞圈賽（Criterium）**：頻繁過彎加速常讓 NP 遠高於平均功率，看 NP 才能真正反映比賽有多艱苦。
- **計時賽／鐵人三項**：因講求穩定配瓦，NP 應相當接近平均功率；若 NP 明顯高出許多，代表配瓦起伏過大。

### 2. 訓練負荷計算（TSS）
NP 是計算 [TSS（訓練壓力分數）](/zh-hant/docs/metrics/training-load/training-stress-score) 的核心輸入：

```text
IF = NP / FTP
TSS ∝ Duration_sec * NP * IF
```

採用 NP 能讓 TSS 更如實反映間歇或變速課表的真實負荷，而非僅憑平均功率低估壓力。

> **Trainingload.ai 建議**：
>
> 1. **極短課表參考性有限**：短於約 20 分鐘的訓練，身體往往尚未進入穩態，NP 容易出現雜訊。短衝刺課表建議改看最大功率、平均功率與單段間歇資料。
> 2. **不要刻意「刷高」NP**：恢復騎的目的就是低強度放鬆，切勿為了數字好看而刻意加幾腳衝刺；NP 應該服務於課表目的。
> 3. **搭配 VI 判讀**：結合 [變異指數（VI）](/zh-hant/docs/metrics/power/variability-index) 一起看：`VI = NP / Avg Power`。VI 越高，代表這趟輸出起伏越劇烈。

## 使用限制

- 高度依賴可靠的功率資料：訊號中斷與感測器異常都會影響計算結果。
- 受視窗與採樣率影響：不同記錄頻率或補值方式可能造成細微數值差異。
- 反映的是「代謝強度」而非直接疲勞：NP 並不等同於實際恢復需求或肌肉損傷程度。
