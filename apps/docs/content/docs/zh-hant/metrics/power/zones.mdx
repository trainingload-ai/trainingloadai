# 功率區間

功率區間將連續的瓦特輸出切分成具體可執行的訓練「檔位」，讓你用一致的語言（Z1–Z7 / Z1–Z5）溝通強度，並讓訓練目標精準對齊能量系統與賽事配瓦情境。

## 基準功率：FTP 與 CP

計算各區間百分比前，必須先有一個基準功率：

- **FTP**：詳見[功能性閾值功率（FTP）](/zh-hant/docs/metrics/power/functional-threshold-power)
- **CP**：詳見[臨界功率（CP）](/zh-hant/docs/metrics/power/critical-power)（特別常見於 Stryd 等跑步功率模型）

如果你已經知道自己的 FTP 或 CP，可以直接透過[功率訓練負荷區間計算機](/zh-hant/power-zones-calculator)算出精確的瓦數邊界。

## 如何解讀區間邊界

下方所有「% FTP」區間皆以**不重疊**區段撰寫，例如：

- Z1：≤ 55%
- Z2：56%–75%

當數值剛好落在交界點上（例如 128%）時，應採取一致的歸屬規則。Trainingload.ai 通常會將邊界值歸入**較高**區間（例如 128% → Z7），避免判讀模糊。

## 1. Joe Friel：單車 7 區模型

Joe Friel 的 7 區模型涵蓋從動態恢復到神經肌肉衝刺的完整光譜，廣泛用於單車訓練；只要閾值基準適當，也可用於跑步。

| 區間 | 名稱 | 英文 | % FTP | 典型用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 主動恢復 | Active Recovery | ≤ 55% | 輕鬆踩踏／恢復跑，促進循環與恢復。 |
| **Z2** | 耐力 | Endurance | 56%–75% | 長距離慢騎（LSD）／有氧基礎，提升有氧能力與脂肪氧化。 |
| **Z3** | 節奏 | Tempo | 76%–90% | 穩定中強輸出，提升持久力與肝醣運用效率。 |
| **Z4** | 閾值 | Threshold | 91%–105% | 閾值課表，強化可持續功率與閾值能力。 |
| **Z5** | 最大攝氧 | VO2 Max | 106%–120% | VO₂max 間歇，推升有氧上限。 |
| **Z6** | 無氧 | Anaerobic | 121%–150% | 無氧間歇，提升乳酸耐受度與重複高強度能力。 |
| **Z7** | 神經肌肉 | Neuromuscular | ≥ 151% | 短衝刺／瞬間加速，強化神經肌肉徵召。 |

> 來源：[Joe Friel](https://joefrieltraining.com/a-quick-guide-to-setting-zones/)

## 2. Jim Vance：跑步 7 區模型

Jim Vance 同樣採用 7 區架構，但在中低強度切分更細緻。Z1–Z3 貼近日常「健走／輕鬆跑／穩定巡航」的層次，有助於更精細地掌握耐力與節奏跑強度。

| 區間 | 名稱 | 英文 | % FTP | 典型用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 恢復／步行 | Recovery/Walking | ≤ 80% | 恢復、暖身、極輕鬆活動。 |
| **Z2** | 耐力 | Endurance | 81%–88% | 主要的有氧耐力區，可長時間穩定維持。 |
| **Z3** | 節奏 | Tempo | 89%–95% | 偏高但可持續的穩定強度，接近閾值。 |
| **Z4** | 閾值 | Threshold | 96%–105% | 閾值訓練與耐力持久度強化。 |
| **Z5** | 高強度 | High Intensity | 106%–115% | 高強度有氧上緣間歇。 |
| **Z6** | 最大攝氧 | VO2 | 116%–128% | VO₂max 間歇（邊界 128% 常歸入 Z7）。 |
| **Z7** | 無氧能力 | Anaerobic Capacity | ≥ 128% | 短距離重複衝刺，著重無氧能力與爆發力。 |

> 來源：[Jim Vance, *Run with Power*](https://www.velopress.com/books/run-with-power/)

## 3. Stryd：跑步 5 區模型

Stryd 模型將高強度區段整併為更簡潔的跑步 5 區架構。它通常以 **CP** 作為基準，但若改以 FTP 計算，百分比對應規則相同。

| 區間 | 名稱 | 英文 | % FTP | 典型用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Z1** | 輕鬆 | Easy | ≤ 80% | 恢復跑與輕鬆跑。 |
| **Z2** | 中等 | Moderate | 81%–90% | 穩定有氧耐力跑、長距離課表主力強度。 |
| **Z3** | 閾值 | Threshold | 91%–100% | 閾值跑與節奏跑核心區間。 |
| **Z4** | 間歇 | Interval | 101%–115% | VO₂max 與高強度間歇。 |
| **Z5** | 快跑重複 | Repetition | ≥ 116% | 短距離快跑、衝刺與無氧爆發。 |

> 來源：[Stryd](https://blog.stryd.com/2018/02/21/nicks-training-manual-lesson-3-if-you-dont-follow-a-plan-you-can-easily-trash-your-legs-for-weeks/)

## 如何計算你的區間邊界

設你的基準功率為 $B$（FTP 或 CP），將對應百分比乘以 $B$ 即可得出瓦特邊界：

```text
W = B * (pct / 100)
```

### 範例：FRIEL Z2（56%–75%）

假設 $B = 250\text{ W}$：

```text
Z2_min = 250 * 0.56 = 140 W
Z2_max = 250 * 0.75 = 187.5 W
```

因此你的 Z2 約為 **140 W – 188 W**（介面顯示通常會四捨五入至整數瓦特）。

## Trainingload.ai 的使用建議

Trainingload.ai 透過功率區間比對原訂課表強度與實際完成強度：

1. **依運動項目分別設定閾值**：跑步與單車功率數值不同，應各自維護 CP / FTP 並套用對應模型。
2. **定期更新基準**：FTP 與 CP 會隨訓練進度改變，建議定期重測或開啟自動推估，維持區間準確性。
3. **將區間視為目標帶而非硬牆**：不必為了 1–2 瓦斤斤計較，重點是讓主要訓練時間落在目標刺激區段內。
4. **課後回顧區間分布**：檢視實際停留時間分布，快速確認輕鬆日是否不小心騎／跑太衝，或關鍵間歇是否強度不足。
