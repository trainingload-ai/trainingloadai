# 有氧解耦（Aerobic Decoupling）

**有氧解耦（Aerobic Decoupling）**，又稱**心率解耦或心率飄移（Cardiac Decoupling / Cardiac Drift）**，用來衡量在穩定配速或穩定功率的耐力訓練中，心率與輸出之間的對應關係是否隨時間改變。

## 核心概念：耦合與解耦

在控制良好的穩定耐力訓練中，你的**內部投入**（心率）與**外部輸出**（功率或配速）應維持相對穩定的耦合狀態。如果到了訓練後半段，維持相同輸出需要更高的心率，或相同心率下輸出下降，就代表有氧效率開始衰退。

在長距離穩定訓練中，若出現以下任一種情況，就稱為**解耦（Decoupling）**：
1. **心率飄移**：功率或配速維持相近，但心率逐漸上升。
2. **功率／配速下滑**：心率維持相近，但功率或配速逐漸下降。

這可能反映疲勞累積、高溫熱壓力、脫水、補給不足、當日配速過於激進，或感測器資料品質問題。

常見解讀方式：

- **正值**：有氧效率隨時間下降（常見原因包括疲勞、炎熱／脫水、補給不佳或配速過快）。
- **常見範圍**：多落在 **0% - 10%**（實際數值會因平台演算法、環境與資料品質而異）。
- **最佳適用情境**：長時間、**穩定強度**的訓練（例如有氧耐力課表或穩定巡航路段）。過短或強度大幅波動的課表參考價值較低。

## 計算公式

做法是取一段穩定強度的訓練（排除暖身），將其**對半分為前後兩半**：

1. 計算**前半段**的效率係數（$EF_1$）。
2. 計算**後半段**的效率係數（$EF_2$）。

此處的 **EF / AE（有氧效率，Aerobic Efficiency）** 本質上就是「輸出 / 心率」：

- **Pw:Hr**：以功率作為輸出，$EF = \frac{Power}{HR}$
- **Pa:Hr**：以速度作為輸出，$EF = \frac{Speed}{HR}$

$$
Pw:Hr[\%] / Pa:Hr[\%] = \frac{AE_1 - AE_2}{AE_1} \times 100\%
$$

通常以 **Pw:Hr** 或 **Pa:Hr** 的百分比變化來表示。

## 常見參考標準：5% 原則

依據 **Joe Friel** 的實務經驗，**5%** 常被作為判讀參考線：

| 解耦率 | 狀態 | 含義與建議 |
| :--- | :--- | :--- |
| **< 5%** | **穩定** | 在此時間與強度下效率保持相當穩定，是有氧持久力良好的正向訊號。 |
| **5% - 10%** | **中度飄移** | 疲勞、氣溫、補給、地形或配速可能影響了後半段表現。建議先與同類型課表比較，再決定是否調整訓練計畫。 |
| **> 10%** | **高度飄移** | 以目前狀態而言，本次課表可能過長、過強、過熱或補給不足，建議結合當時情境進一步檢視。 |

## 實務指南：如何測試？

不要只依賴隨意安排的課表，建議以結構化的**有氧閾值測試**來觀察：

1. **強度**：嚴格控制在 **Zone 2**（有氧耐力區）。
   - 功率／配速：65–75% FTP / FTPa。
   - 心率：低於 AeT（有氧閾值），通常約為 LTHR 減去 20–30 bpm。
2. **時間**：
   - 標準鐵人三項／半程馬拉松目標：1–1.5 小時。
   - 超級鐵人三項／超級馬拉松目標：2–4 小時。
3. **環境**：平坦路線或室內訓練台，並維持充足水分與電解質補給（避免因脫水造成假性解耦）。

## Trainingload.ai 如何運用有氧解耦

- **長距離課表品質檢核**：在穩定的長跑或長距離騎乘後，透過解耦率觀察有氧效率是否維持穩定。
- **結合情境回顧**：Trainingload.ai 在判讀偏高的解耦率時，會同時考量氣溫、爬升、配速／功率變異、補給狀況與近期訓練負荷，而不會直接視為警訊。
- **基礎期進步回饋**：在相似條件的課表中持續維持低解耦率，可作為有氧持久力提升的佐證。
- **並非所有課表都適用**：間歇訓練、節奏劇烈變化的賽事、起伏劇烈的丘陵路線與短時間課表，往往會產生雜訊過高的解耦數值。
