# 什麼是訓練負荷？一次看懂 TSS、TRIMP 與 IF

**訓練負荷（Training Load）**是針對單次課表、單週或單一訓練週期所建立的模型化訓練劑量。本總覽頁介紹核心指標家族——TSS、TRIMP 與強度係數（IF）——幫助你把「長時間輕鬆課表」與「短時間高強度間歇」放在同一個尺度下比較，進而評估訓練計畫該推進、維持、安排恢復或微調。關於產品內的決策應用請參考[訓練負荷管理](/zh-hant/training-load)，各指標的完整定義則收錄於下方頁面。

沒有負荷指標時，很難客觀比較「2 小時輕鬆騎／輕鬆跑」與「30 分鐘高強度間歇」的壓力差異，也更難察覺近期負荷是否拉升得超過身體恢復速度。

## 為什麼要量化訓練負荷？

1. **客觀比較**：用統一的尺度評估不同時長與不同類型的訓練。
2. **追蹤趨勢**：清楚掌握每週模型化負荷是穩健成長還是突然飆升。
3. **補齊恢復脈絡**：在規劃課表與休息時，將負荷歷程與課表執行品質、個人體感回饋整合判讀。

## 訓練負荷如何支援自適應訓練計畫

訓練負荷本身不是訓練計畫，而是支撐更佳訓練決策的證據層：

- **課表完成後**：不只看「有沒有打卡完成」，而是比對實際負荷與原訂負荷的差距。
- **週期回顧時**：CTL、ATL 與 TSB 用來比較長期與近期負荷趨勢，而非直接量測真實體能、疲勞或準備度。
- **調整課表前**：缺課、異常疲勞或負荷爬升過快，都能作為微調接下來幾天課表的具體依據。

## 常見問題

### 什麼是訓練負荷？

訓練負荷是模型化的訓練劑量。單次課表分數（例如 TSS 或 TRIMP）估算該次訓練壓力，而 CTL 與 ATL 則隨時間彙整這些分數，讓你能跨週比較，而不只是記錄「有沒有完成」。

### TSS 與 TRIMP 該用哪一個衡量訓練負荷？

當具備功率或可靠配速資料時，通常以 TSS 作為外部負荷分數；TRIMP 則是依據心率與時間計算的內部負荷。Trainingload.ai 可依運動項目與你設定的負荷來源優先順序彈性選用。

### 跑步與單車分別如何量測訓練負荷？

單車通常透過 NP、IF 與 FTP 計算功率 TSS；跑步常透過 NGP 與閾值配速計算 rTSS，若僅心率資料可靠則改用 TRIMP。建議先在同一運動項目內比較數值，再謹慎看待跨項目比較。
