# 訓練負荷是什麼？TSS、TRIMP 與強度係數怎麼看

**訓練負荷**是一次課、一週或一個週期的模型化劑量。本頁說明 TSS、TRIMP 和強度係數如何比較「兩小時輕鬆」和「三十分鐘間歇」，並判斷計畫該繼續加量、維持、恢復還是調整。產品決策見[訓練負荷管理](/zh-hant/training-load)；下面各頁負責定義。

如果冇負荷指標，就好難比較「2 個鐘輕鬆踩/跑」同「30 分鐘間歇課」到底邊個更“傷”；亦更難判斷最近負荷係咪升得太快，令恢復跟唔上。

## 點解要量化訓練負荷？

1. **客觀比較**：用同一把尺去衡量唔同時長、唔同類型嘅課表
2. **追蹤進步**：確保每週負荷逐步上升，避免突然暴衝增加受傷風險
3. **管理恢復**：負荷越高，一般需要越多恢復；量化可以令你更理性咁安排訓練同休息

## 常見問題

### 訓練負荷是什麼？

訓練負荷是模型化的訓練劑量。TSS 或 TRIMP 估算一次課；CTL 和 ATL 把這些分數彙總成趨勢，用來比較週與週，而不只看「有沒有完成」。

### TSS 和 TRIMP 哪個衡量訓練負荷？

有功率或可靠配速時，TSS 是常用的外部負荷。TRIMP 用心率和時長看內部負荷。Trainingload.ai 會按項目和你設定的負荷來源優先順序選擇。
