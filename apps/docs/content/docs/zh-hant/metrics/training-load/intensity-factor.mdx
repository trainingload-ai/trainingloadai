# 什麼是單車與跑步的強度係數（IF）？

**強度係數（Intensity Factor，簡稱 IF）**衡量的是課表強度相對於自身閾值的比例：[標準化功率（NP）](/zh-hant/docs/metrics/power/normalized-power) ÷ [FTP](/zh-hant/docs/metrics/power/functional-threshold-power)。它直接回答「這趟訓練有多吃力？」，因此同樣 150 W 的騎乘，對某位選手可能是輕鬆有氧，對另一位則是全力輸出。

透過將絕對輸出標準化，IF 讓不同實力層級的運動員也能以相對尺度比較訓練強度。

## 計算公式

IF 是[標準化功率（NP）](/zh-hant/docs/metrics/power/normalized-power)與[功能性閾值功率（FTP）](/zh-hant/docs/metrics/power/functional-threshold-power)的比值：

$$
IF = \frac{NP}{FTP}
$$

**舉例**：
- 假設你的 FTP 為 200 W。
- 完成一趟 NP = 150 W 的騎乘。
- 則 $IF = 150 / 200 = 0.75$。

> **注意**：相同邏輯也適用於跑步（改用跑步閾值功率 rFTP 或 NGP）。相較於功率，心率因具有**延遲與飄移**特性，精準度通常較低。

### 跑步中的 IF 計算

跑步項目若具備功率資料，通常以 **rFTP（跑步閾值功率）**或 **CP（臨界功率）**作為基準：

$$
IF_{run} = \frac{RunPower}{CP}
$$

若改用配速，則以速度形式計算：

$$
IF_{pace} = \frac{NGP}{ThresholdPace}
$$

*註：[NGP（標準化坡度配速）](/zh-hant/docs/metrics/pace/normalized-graded-pace)為考量坡度與強度變異後的等效配速。*

## 為何要關注 IF？

### 1. 跨能力水準比較
- **絕對功率**：職業選手騎 200 W 輕鬆寫意，新手騎 200 W 可能已接近極限，單看瓦數看不出相對付出。
- **相對強度（IF）**：只要兩位選手的 IF 都是 0.75，就代表兩人都處於相同相對強度的有氧耐力區。

### 2. 快速辨識訓練區間
IF 是最快看出單次課表落在哪個強度域的指標：

| IF 範圍 | 訓練區間 | 典型特徵 |
| :--- | :--- | :--- |
| **< 0.75** | **Z1 / Z2** | **恢復／有氧耐力**。輕鬆至中低強度，常用於基礎堆量或恢復日。 |
| **0.75 - 0.85** | **Z3 / 甜區（Sweet Spot）** | **節奏／甜區**。具一定挑戰性但可穩定持續，視時間長度與項目而定。 |
| **0.85 - 0.95** | **Z4** | **閾值區**。相當吃力且貼近 FTP，常見於閾值間歇或計時賽。 |
| **0.95 - 1.05** | **Z5** | **VO₂max 區**。極高強度輸出，多以較短間歇分段執行。 |
| **> 1.05** | **Z6 / Z7** | **無氧／衝刺區**。短時間極限爆發，通常僅見於短距離賽事或測驗。 |

## 常見應用情境

### 1. 檢驗 FTP 設定是否準確
如果你在**獨推 1 小時計時賽（TT）**中能維持 **IF ≈ 1.1**（也就是 NP 達到 FTP 的 1.1 倍），通常代表你的 **FTP 設定偏低**。
- **原因**：FTP 實務上代表接近穩態下約 1 小時能維持的最高功率；若整整 1 小時 IF 仍遠高於 1.0，就應該重新檢視閾值估計。

### 2. 長距離賽事配速與配瓦策略
在長距離耐力賽中，控管 IF 有助於保留後段體力並避免腸胃補給失控：

| 賽事類型 | 目標 IF 範圍 | 風險提醒 |
| :--- | :--- | :--- |
| **超級鐵人三項（226）** | **0.65 - 0.75** | 單車強度過高會大幅提高跑步崩盤與補給失衡風險。 |
| **半程鐵人三項（113 / 70.3）** | **0.75 - 0.85** | 區間上緣相當激進，高度仰賴跑步持久力。 |
| **標準距離鐵人三項（51.5）** | **0.85 - 0.95** | 單車接近閾值輸出，仍須替路跑預留餘裕。 |

### 3. 構成訓練壓力分數（TSS）的核心因子
IF 是 **[TSS](/zh-hant/docs/metrics/training-load/training-stress-score)** 的關鍵乘數，決定 TSS 累積的速度：

$$
TSS = \frac{t \times NP \times IF}{FTP \times 3600} \times 100
$$

- IF 只要小幅上升，TSS 就會顯著放大（本質上與 $IF^2$ 成正比）。

## Trainingload.ai 的使用建議

Trainingload.ai 不只看總負荷，也透過 IF 解讀課表性質：

1. **讓 IF 對齊課表目標**：有氧基礎課表應保持克制；閾值或 VO₂max 課表才會刻意拉高 IF。
2. **謹慎看待極短課表**：少於約 20 分鐘的活動，IF 容易顯得異常偏高，不宜比照長距離穩定課表解讀。
3. **定期檢視閾值設定**：如果輕鬆課表經常出現 IF > 0.8，不是你騎／跑得不夠輕鬆，就是閾值設定需要重新校正。

## 使用限制

- **短時間高強度偏差**：在極短課表（如 10 分鐘左右）中，NP 演算法特性會使 IF 偏高。
- **高度依賴準確的 FTP**：一旦 FTP 過時或設錯，IF 就會失去參考意義。

## 常見問題

### 什麼是強度係數（IF）？

強度係數等於 NP ÷ FTP（跑步則為 NGP ÷ 閾值配速）。對多數運動員而言，IF 0.75 代表控制良好的有氧課表，IF 接近 1.0 則約等於在閾值全力輸出 1 小時。

### 單車訓練中如何運用 IF？

可透過 IF 區間確認騎乘是否落在目標區、規劃長距離賽事配瓦，以及檢查 FTP 是否設太低——若能維持 IF ≈ 1.1 長達一小時，多半代表 FTP 被低估了。

### IF 也適用於跑步嗎？

適用，可透過跑步閾值功率／CP 或以 NGP 對照閾值配速計算。心率推算的 IF 精準度較低，因為心率會有延遲與飄移現象。

### IF 如何影響 TSS？

TSS 與 $IF^2$ 成正比。IF 小幅上升帶來的負荷增幅，會遠大於同等比例拉長時間所增加的負荷；這也是為何 FTP 設錯會同時扭曲 IF 與 TSS。
