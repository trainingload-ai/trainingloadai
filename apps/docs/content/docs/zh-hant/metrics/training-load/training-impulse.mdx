# 什麼是 TRIMP？心率訓練負荷公式詳解

**TRIMP（Training Impulse／訓練衝量）**是一項以心率為核心的訓練負荷評分。它將運動時間乘以非線性強度權重，讓高強度分鐘數比輕鬆分鐘數佔有更高比重。Banister 於 1975 年提出此方法並於 1991 年完善，旨在缺乏功率或可靠配速時，仍能有效量化**內部訓練負荷**。

功率與配速衡量的是外部作功，而 TRIMP 則透過**心率與時間**推估身體內部的生理壓力，解決一個非常務實的問題：**在沒有功率資料或不適合用功率的項目中，如何把心率與時間結合成單一負荷指標？**

## 核心概念

基本邏輯是：**負荷 = 時間 × 強度**。

但在 TRIMP 中，「強度」並不是單純取平均心率，而是反映心率升高時呈現的**非線性**生理壓力：

- 心率從 130 升到 140 bpm，增加的生理壓力相對溫和。
- 心率從 180 升到 190 bpm（逼近最大心率），身體承受的內部負荷則大幅躍升。

因此 Banister 引入指數加權，使同樣時長下高心率訓練的負荷貢獻遠高於低心率訓練。

## 計算公式（Banister TRIMP）

當具備必要的心率輸入資料時，Trainingload.ai 會優先採用經典的 **Banister TRIMP（指數模型）**：

```text
TRIMP = t_min * HR_ratio * 0.64 * exp(k * HR_ratio)
```

其中：

- $t_{min}$ = 運動時間（分鐘）
- $HR_{ratio}$ = 儲備心率比例（HRR ratio）

  ```text
  HR_ratio = (HR_avg - HR_rest) / (HR_max - HR_rest)
  ```

- $e$ = 自然常數（2.718…）
- $k$ = 性別係數（男性 **1.92**、女性 **1.67**），反映不同性別在高心率下的血乳酸反應曲線差異。

### 計算範例

假設一位男性運動員（最大心率 200、靜息心率 50）：

1. **輕鬆跑 1 小時 @ 平均心率 140 bpm**（HR_ratio = 0.6）：

   ```text
   TRIMP ≈ 60 * 0.6 * 0.64 * exp(1.92 * 0.6) ≈ 72
   ```

2. **高強度訓練 1 小時 @ 平均心率 185 bpm**（HR_ratio = 0.9）：

   ```text
   TRIMP ≈ 60 * 0.9 * 0.64 * exp(1.92 * 0.9) ≈ 194
   ```

同樣是 1 小時，高強度課表的 TRIMP 約為輕鬆課表的將近 3 倍，清楚展現強度的非線性影響。

## 常見變體與演進

除了 Banister 模型外，實務上還有多種衍生演算法，Trainingload.ai 會依資料完整度支援以下選項：

| 變體 | 全稱 | 核心訊號 | 優缺點說明 |
| :--- | :--- | :--- | :--- |
| **TRIMP** | **Banister TRIMP** | **指數加權心率** | ⭐⭐⭐⭐ 心率資料可靠時非常適合穩定有氧訓練；對短間歇較不敏感。 |
| **TRIMP_zone** | **Edwards TRIMP** | **心率區間累計** | ⭐⭐⭐ 簡單直覺。將心率分為 5 區並給權重（例如 Z1=1、Z5=5），但存在區間邊界跳動問題。 |
| **TRIMP_avg** | **平均心率法** | **平均心率** | ⭐⭐ 過於簡化。使用 `Time * HR_avg`，忽略高強度代價，容易低估艱苦課表。 |
| **sRPE** | **課表自覺強度** | **主觀評分** | ⭐ 備援方案。$Time \times RPE(1-10)$。無心率資料時非常實用，但仰賴誠實自評。 |

## 常見應用情境

### 1. 作為 PMC 的負荷資料來源

在不易取得功率的運動項目（游泳、越野跑、重訓／肌力課表）中，TRIMP 可作為計算 [ATL](/zh-hant/docs/metrics/pmc/acute-training-load) 與 [CTL](/zh-hant/docs/metrics/pmc/chronic-training-load) 的實用替代輸入：

- **TSS** 常見於單車與路跑。
- **TRIMP** 幾乎可套用於任何有氧活動。

## Trainingload.ai 如何運用 TRIMP

Trainingload.ai 將 TRIMP 定位為內部負荷輸入，在缺少功率、可靠配速或結構化目標時特別實用。在訓練計畫回顧中，TRIMP 能幫助解釋為何某趟外部輸出不亮眼的課表，身體實際付出卻很高。

結合以下脈絡解讀效果最佳：

- 對照 RPE 與當次訓練筆記；
- 留意高溫、脫水與心率飄移影響；
- 避免單獨依賴它評估短衝刺或無氧間歇課表。

### 2. 檢視心率與 RPE 是否脫鉤

若 **TRIMP / RPE 比值**出現異常，往往值得留意：

- **正常狀況**：高 TRIMP 對應高 RPE。
- **異常訊號**：TRIMP 很高但 RPE 偏低（可能因脫水、高溫或初期生病引起心率飄移）；或 TRIMP 偏低但 RPE 很高（心率拉不上去，常見於副交感神經過度疲勞或累積性疲憊）。

## 使用限制

1. **心率延遲效應**：30 秒全力衝刺時，功率瞬間衝頂，但心率上升緩慢且常常在衝刺結束後才攀升，因此 TRIMP 容易低估短時間無氧間歇的負荷。
2. **環境與生理雜訊**：高溫、脫水、咖啡因與睡眠不足都會推高心率（心率飄移），導致 TRIMP 虛高——心臟跳得更快，不見得代表肌肉作了更多功。
3. **無法區分肌肉骨骼衝擊**：同樣是 100 TRIMP，游泳與跑步對肌腱與關節造成的機械壓力完全不同，TRIMP 無法反映這層差異。

## 常見問題

### 訓練中的 TRIMP 是什麼？

TRIMP 是訓練衝量分數：時間 × 心率強度權重，高強度分鐘數權重更高。它估算的是內部訓練負荷，不同於以單車功率計算外部作功的 TSS。

### Banister TRIMP 怎麼算？

公式為 `分鐘數 × 儲備心率比例 × 0.64 × exp(k × 儲備心率比例)`。儲備心率比例等於 `(平均心率 − 靜息心率) / (最大心率 − 靜息心率)`，男性係數 `k = 1.92`、女性 `k = 1.67`。

### TRIMP 與 TSS 應該選哪一個？

具備功率或可靠路跑配速時，優先選用 TSS；若活動以心率為主（如游泳、越野跑、健身房有氧或無可靠外部負荷資料），則使用 TRIMP。

### 為什麼 TRIMP 容易低估短間歇？

因為心率反應慢於功率。30 秒衝刺的瞬間輸出極高，但心率還沒來得及升到對應高度就結束了，導致短時間無氧負荷被低估。建議搭配 RPE、功率或配速分數判讀。
