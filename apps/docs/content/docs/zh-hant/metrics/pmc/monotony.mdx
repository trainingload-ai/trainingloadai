# 訓練單調性（Monotony）：Foster 公式與有界評分比較

**訓練單調性（Training Monotony）**描述最近 7 個日曆日內每日訓練負荷的相似程度。若每天負荷非常接近，數值會偏高；若高負荷日、低負荷日與休息日分布較分明，數值通常較低。

Trainingload.ai 呈現的是經過正規化的有界版本，而非無上限的經典 Foster 數值。它僅描述負荷數字的分布特徵，並不直接量測疲勞、恢復、過度訓練、受傷機率或訓練品質。

## 資料範圍與公式

Trainingload.ai 納入今日與前 6 個日曆日。同一天若有多筆活動會先加總；無負荷紀錄的日期計為 0。

```text
mean_load = sum(loads) / 7
sd_load = sqrt(sum((load − mean_load)²) / 7)
monotony = mean_load / (sd_load + mean_load)
```

若 `sd_load + mean_load = 0`，代表 7 天負荷皆為 0，系統回傳 `monotony = 0`。

訓練應變（Training Strain）採用相同的 7 天視窗：

```text
total_load = sum(loads)
training_strain = total_load × monotony / 0.5
```

## 與經典 Foster 指標的差異

```text
foster_monotony = mean_load / sd_load
foster_strain = total_load × foster_monotony
```

經典 Foster 數值沒有上限，只要連續 7 天每日負荷完全相同，數值就會趨近無限大。Trainingload.ai 改用 `mean_load / (sd_load + mean_load)`，使有訓練負荷的一週始終落在 0 到 1 之間。

當平均值與標準差皆大於 0 時，兩者換算關係為：

```text
trainingload_monotony = foster_monotony / (1 + foster_monotony)
```

因此，Trainingload.ai 的 `0.8` 並不能直接等同於經典 Foster 的 `2.0`，兩套系統的訓練應變公式也不相同。

## 如何解讀數值

- 連續 7 天零負荷會回傳 0。
- 1 天有負荷加上 6 天零負荷，結果約為 0.29。
- 7 天負荷完全相同（且大於 0）會回傳 1。
- 介於上述情況之間時，數值越高通常代表每日負荷越接近。

數值偏低並不代表結構一定較好：例如 1 天極端爆量加上 6 天完全休息，單調性同樣偏低。反之，數值偏高也不構成受傷或過度訓練診斷，它只反映這 7 天的負荷數字彼此相近。

介面顯示的 `<0.6`、`0.6–0.8` 與 `>0.8` 僅為檢視規則，而非經臨床驗證的安全門檻；全週休息產生的 0 值也不代表「訓練結構極佳」。

## 實務回顧方式

請將這 7 天的每日負荷與週總負荷並列檢視，判斷該分布源自於既定訓練計畫、真正的休息日、單日爆量、活動檔案遺漏，或是閾值／負荷來源變更。接著再補充運動類型、課表內容、實際表現、睡眠、疼痛、生病狀況與主觀疲勞做綜合評估。

## 常見問題

### 什麼是訓練單調性？

訓練單調性是衡量過去 7 天每日訓練負荷相似度的指標。每天負荷越接近，分數越高；強弱日與休息日交替較明顯時，分數通常較低。它描述的是數字分布，而非受傷風險。

### 與經典 Foster 單調性公式有何不同？

經典 Foster 公式為「平均負荷 ÷ 標準差」，沒有上限，若每天負荷相同會趨近無限大。Trainingload.ai 改用 `mean / (sd + mean)`，讓有負荷的週次穩定落在 0 至 1 之間。本系統的 0.8 不等同於 Foster 的 2.0。

### 什麼是訓練應變（Training Strain）？

訓練應變是將 7 天總負荷乘以單調性（本產品再除以 0.5）。當總負荷高且每日負荷又很相似時，應變值就會攀升。應與 7 天明細一同判讀，不要當成單獨的警訊。

### 單調性越低越好嗎？

不是。單日極端高負荷加上 6 天零負荷，單調性同樣很低。這項指標的價值在於提醒你留意「過於平直的一週」，進而回頭檢視計畫安排、缺漏檔案與真實體感。
