# 什麼是急性：慢性負荷比（ACWR）？

**ACWR（Acute:Chronic Workload Ratio）**用來比較模型推算的近期負荷與長期負荷。在 Trainingload.ai 中，A:C 比值等於同日的[疲勞（ATL）](/zh-hant/docs/metrics/pmc/acute-training-load)除以同日的[體能（CTL）](/zh-hant/docs/metrics/pmc/chronic-training-load)。

這個比值能標示出近期負荷結構的變化，但 ACWR 並不是受傷或準備度預測指標。它不會直接量測身體適應、生理疲勞、恢復狀態或醫療風險。

## 公式與資料來源

ATL 與 CTL 使用同一組每日訓練負荷序列：

```text
decay_ATL = exp(-1 / 7)
decay_CTL = exp(-1 / 42)
ATL_today = ATL_yesterday × decay_ATL + daily_load × (1 − decay_ATL)
CTL_today = CTL_yesterday × decay_CTL + daily_load × (1 − decay_CTL)

ACWR_today = ATL_today / CTL_today
```

若今日 ATL 為 60、CTL 為 50，則 ACWR 為 `1.20`。當 CTL 為 0 時，系統會回傳 `0` 以避免除以零。

活動紀錄、閾值設定與負荷來源優先順序的變動，都可能同時影響分子與分母。ACWR 為無單位比值，會隱藏原本的絕對負荷規模。

## 這是哪一種 ACWR？

ACWR 並沒有單一標準演算法。Trainingload.ai 採用的是**耦合式 PMC 指數比值**：今日負荷同時進入 ATL 與 CTL，且兩條曲線均使用指數衰減時間常數。

它並非簡單的「最近 7 天 ÷ 最近 28 天週平均」，也不是將近期視窗從長期視窗中剔除的解耦式（uncoupled）變體。因此，來自其他演算法、運動項目、族群或負荷來源的門檻不可直接套用。

## 如何解讀比值

- **大於 1**：ATL 高於 CTL。
- **接近 1**：ATL 與 CTL 相近，但這不代表訓練狀態最佳。
- **小於 1**：ATL 低於 CTL。

請務必同時查看分子與分母。`ATL 12 / CTL 10` 與 `ATL 120 / CTL 100` 的結果都是 1.20，但兩者的絕對負荷規模天差地遠。新帳號或 CTL 極低的初期階段，只要完成一次訓練也可能出現偏高的比值。

介面目前呈現四個區段：`<0.8`、`0.8–<1.3`、`1.3–<1.5` 與 `≥1.5`。這些僅是協助回顧相對負荷變化的顯示規則，並不能證明處於「最佳」、「安全」、「危險」、「訓練不足」或「過度訓練」狀態。

## 實務回顧方式

先確認 ACWR、ATL 與 CTL 對應的是同一日期，接著檢視兩者的絕對數值，回頭追溯造成變動的具體活動，並確認閾值與負荷來源優先順序是否曾被修改。最後再結合課表執行品質、睡眠、疼痛、生病訊號、主觀疲勞與過往傷病史，才決定是否調整訓練計畫。
