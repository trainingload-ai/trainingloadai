# 什麼是疲勞（ATL）？

**疲勞（ATL，Acute Training Load／急性訓練負荷）**是每日訓練負荷的快速指數移動平均。它賦予最近幾天更高的權重，變化速度比體能（CTL）更快。Trainingload.ai 預設採用 7 天時間常數。

「疲勞」是方便閱讀的介面標籤。ATL 彙整的是模型推算的近期負荷，並不會直接量測生理或主觀疲勞、恢復程度、健康狀態或身體適應。

## 數值從何而來

Trainingload.ai 會依據你設定的負荷來源優先順序，為每一筆活動選取一個可用的負荷數值。視活動內容與設定而定，來源可能是功率、心率、配速或課表自覺強度（Session RPE）。同一天內多筆活動的負荷會加總為當日的 `daily_load`。

遺漏或重複的活動紀錄、閾值設定修改與負荷來源順序變更，都會影響 ATL。沒有記錄負荷的日期會以 0 代入，前一天的 ATL 會隨時間衰減，而不會瞬間歸零。

## 計算公式

```text
decay_ATL = exp(-1 / 7)
ATL_today = ATL_yesterday × decay_ATL + daily_load × (1 − decay_ATL)
```

其中 `exp` 為自然指數函數。在預設的 7 天時間常數下，`decay_ATL ≈ 0.866878`，因此今日負荷所佔權重約為 `0.133122`。

請注意，7 天是**時間常數**，並不是最近 7 個日曆日的簡單平均或總和。更早之前的訓練仍會以遞減權重持續影響。當每日負荷階躍至一個固定值時，ATL 會在 1 個時間常數內完成約 63.2% 的變化，在 3 個時間常數內完成約 95.0%。

## 如何解讀趨勢

- **ATL 上升**：近期每日負荷整體高於目前的 ATL 水準。
- **ATL 平穩**：近期負荷大致維持目前的模型水準。
- **ATL 下降**：近期負荷低於目前水準，常見於休息日、恢復週或賽前減量期。

由於 ATL 反應靈敏，單一次高負荷訓練就會讓曲線明顯波動。數值上升只代表模型化的近期負荷增加，並不代表身體是否已順利吸收這份刺激。

## ATL 能回答與不能回答什麼

ATL 能幫助你找出連續堆疊的高負荷訓練日、確認恢復週是否確實降低近期壓力，並比對實際負荷與原訂訓練計畫的落差。

但單靠 ATL 無法判斷你是否處於生理疲勞、某個數值是否安全、明天的課表應不應該取消，也無法證明你是否已完全恢復或具備比賽狀態。

請務必搭配[體能（CTL）](/zh-hant/docs/metrics/pmc/chronic-training-load)、[狀態（TSB）](/zh-hant/docs/metrics/pmc/training-stress-balance)、已完成課表的執行品質、睡眠、疼痛、生病訊號、課表 RPE 與主觀體感一同解讀。
