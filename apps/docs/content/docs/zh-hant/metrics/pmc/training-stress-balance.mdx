# 什麼是狀態（TSB）？

**狀態（TSB，Training Stress Balance／訓練壓力平衡）**是體能（CTL）減去疲勞（ATL）的差值，用來呈現變化較快的近期負荷相對於較慢長期負荷模型所處的位置。

「狀態」是便於閱讀的介面標籤。TSB 衍生自兩條模型化的負荷曲線，本身並非直接的準備度、恢復度、健康狀況或比賽表現量測值。

## 數值從何而來

TSB 本身沒有額外的獨立活動輸入。Trainingload.ai 會先利用同一組每日負荷序列，以 42 天時間常數計算同日 CTL，並以 7 天時間常數計算同日 ATL。任何會影響這兩條曲線的活動紀錄、閾值調整或負荷來源變更，都會連動改變 TSB。

TSB 與 CTL、ATL 採用相同的模型負荷尺度，並非百分比或生理單位。

## 計算公式

Trainingload.ai 採用與 Intervals.icu 相同的「當日相減」慣例：

```text
TSB_today = CTL_today − ATL_today
```

舉例來說，若今日 CTL 為 50、ATL 為 65，則今日 TSB 為 `50 − 65 = −15`。

請注意，不同平台的日期定義並不完全一致：Intervals.icu 使用同日 CTL 減同日 ATL，而 TrainingPeaks 公開說明中則以昨日體能減昨日疲勞作為今日狀態。跨平台比較前，請先確認日期慣例、時間常數與負荷來源是否相同。

## 如何解讀狀態（TSB）

- **負值 TSB**：ATL 高於 CTL，代表近期模型負荷高於較慢的長期基準。
- **接近 0 的 TSB**：兩條負荷曲線相近，但這不代表生理上處於完全平衡。
- **正值 TSB**：ATL 低於 CTL，代表近期模型負荷低於較慢的長期基準。

加量期開始時，ATL 通常比 CTL 升得更快，因此 TSB 會下降；進入休息週或賽前減量期時，ATL 衰減較快，TSB 便會回升。正負號只描述兩條負荷曲線的相對位置，不代表身體「應該」有什麼感受。

## 用途與限制

TSB 適合用來驗證強化期、恢復週或減量期是否如預期改變了近期與長期負荷的關係，尤其在與自己過往相似備賽階段對照時最有價值。

但單靠 TSB 無法判定是否具備比賽準備度、不能把負值直接等同於危險、不能把正值直接等同於最佳狀態，也無法開立休息日處方或解釋疼痛與生病。

避免盲目追逐所謂通用的「巔峰區」、「最佳區」或「高風險區」。這些區間高度依賴負荷計算方式、運動項目、訓練年資、個體反應與資料品質。請務必結合[體能（CTL）](/zh-hant/docs/metrics/pmc/chronic-training-load)、[疲勞（ATL）](/zh-hant/docs/metrics/pmc/acute-training-load)、原始活動、表現趨勢與主觀體感綜合判斷。
