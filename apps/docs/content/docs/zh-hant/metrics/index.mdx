# 訓練指標詞彙表

最後更新：2026-05-23

本頁為 Trainingload.ai 的耐力訓練指標詞彙表，整理訓練負荷、PMC、功率、心率、配速、VO₂max 與運動生理文件中的核心術語，並連結至各指標的深入參考頁面。

訓練指標彼此搭配使用時最具價值。單一數字很少能獨立說明訓練狀態：負荷指標描述訓練劑量，心率反映內部生理反應，功率與配速代表外部輸出，而運動生理指標則解釋底層能力。

## 快速定義

| 術語 | 白話含義 | 常見用途 |
| ---- | -------- | -------- |
| 訓練負荷 | 已完成訓練隨時間累積造成的身體壓力。 | 決定接下來應該加量、維持，還是安排恢復。 |
| PMC | 表現管理圖（Performance Management Chart），整合 CTL、ATL 與 TSB 模型化負荷歷程。 | 跨時間比較長期與近期負荷趨勢。 |
| CTL | 慢性訓練負荷（Chronic Training Load），變化較慢的長期負荷趨勢。 | 建立長期訓練負荷脈絡。 |
| ATL | 急性訓練負荷（Acute Training Load），變化較快的近期負荷趨勢。 | 辨識近期訓練負荷的變化。 |
| TSB | 訓練壓力平衡（Training Stress Balance），即目前 CTL 減去目前 ATL。 | 觀察近期模型負荷與長期模型負荷之間的落差。 |
| TSS | 訓練壓力分數（Training Stress Score），依據時間與強度計算的單次訓練壓力。 | 比較不同課表或不同週次的訓練負荷。 |
| TRIMP | 訓練衝量（Training Impulse），以心率為基礎的負荷估算值。 | 在缺乏功率資料時估算內部負荷。 |
| FTP | 功能性閾值功率（Functional Threshold Power），實務上常用的閾值功率基準。 | 設定功率區間與課表目標。 |
| CP | 臨界功率（Critical Power），以模型推估的可持續功率邊界。 | 理解功率—時間能力曲線與 W′。 |
| LTHR | 乳酸閾值心率（Lactate Threshold Heart Rate），實務上常用的閾值心率基準。 | 設定心率區間。 |
| VO₂max | 最大攝氧量（Maximal Oxygen Uptake），或推估的有氧能力參考指標。 | 追蹤有氧能力變化趨勢。 |

## 如何使用本詞彙表

請將這份詞彙表視為導覽地圖，而非單獨的判定工具。若想回顧負荷變化，建議先從訓練負荷、PMC、CTL、ATL 與 TSB 入手，再檢視模型背後的實際活動與個人情境。若要設定課表強度，請從 FTP、CP、LTHR、功率區間、心率區間與配速區間開始。若想評估長期表現反應，則可搭配 VO₂max、有效 VO₂max、運動生理指標、訓練品質與主觀體感訊號。
