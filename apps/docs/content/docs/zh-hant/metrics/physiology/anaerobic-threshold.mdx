# 無氧閾是什麼？AnT 與閾值訓練強度分界怎麼看

**無氧閾（AnT）**是從「還能穩住的巡航強度」轉到「疲勞開始更快累積」的分界。教練用它安排閾值課。它常和 FTP、閾值心率、閾值配速靠近，但那些是場地近似，不是同一個實驗室定義。

## 主要特徵

- **能維持的時間有限**：對很多訓練者來說，它大致對應「能努力維持數十分鐘到約 1 小時的最高穩態強度」（會隨項目與訓練水平而變化）。
- **過線後代價很高**：一旦超過它，疲勞與乳酸/酸化相關的不適往往會更快累積，強度不容易「硬扛住」。
- **實驗室測量（方法之一）**：有些體系會用呼吸氣體分析找通氣/氣體交換的拐點；另一些體系用血乳酸測試找拐點。不同定義口徑會帶來「數字不完全一致」，這是正常的。

## 估算方法

如果你沒有條件做實驗室測試，訓練裡更常用的做法是用可重複的場地測試去「近似」它：

- **20 分鐘穩態測試（常見做法）**：
  - 做一個最大、盡可能穩定的 20 分鐘努力。
  - 用這 20 分鐘的平均功率/配速（或心率）作為參考，並結合經驗系數做換算。
  - 這也是很多人熟悉的 FTP 估算思路之一。

## 訓練意義

提升無氧閾值（AnT）往往意味著：你可以用更高的強度做「穩態輸出」，在比賽中更容易維持更快的巡航速度而不容易爆掉。但它不是唯一決定因素——經濟性、耐久性、補給與配速策略同樣重要。

## 常見問題

### 無氧閾是什麼？

無氧閾是你還能接近穩態維持的最高強度；再往上，同樣配速或功率會很快撐不住。

### 無氧閾等於乳酸閾嗎？

它們常指向相近的訓練區間，但測法不同。乳酸閾看血乳酸，AnT 可能看氣體交換或乳酸拐點。不要把兩個數字當成同一個。見[乳酸閾值](/zh-hant/docs/metrics/physiology/lactate-threshold)。

### 沒有實驗室怎麼估無氧閾？

用可重複的場地測試，常見是 20 分鐘盡量平穩的全力。取平均功率、配速或心率，再做經驗折算——和許多 FTP 估算同一思路。
