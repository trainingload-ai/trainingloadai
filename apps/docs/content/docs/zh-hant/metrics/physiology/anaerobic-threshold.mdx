# 無氧閾值（AnT）：訓練強度分界線

**無氧閾值（Anaerobic Threshold，簡稱 AnT）**是指原本可以穩定維持的配速或功率，開始迅速累積疲勞的強度轉折線。教練常用它來設計閾值課表；實務上它經常接近 FTP、LTHR 與閾值配速，但這些皆為實地代理指標，與實驗室定義並不完全相同。

## 核心特徵

- **維持時間有限**：對多數運動員而言，大約對應能穩定全力輸出數十分鐘至約 1 小時的強度（因運動項目與個人能力而異）。
- **越線後代價迅速攀升**：一旦高於 AnT，維持相同配速或功率的難度會急劇提高。
- **實驗室定義多元**：部分檢測使用氣體交換轉折點，部分使用血乳酸轉折點。不同方法得出略有差異的數值屬於正常現象。

## 實務估算方式

若沒有實驗室檢測條件，可透過可重複執行的實地測驗近似推估：

- **20 分鐘穩定全力測驗（常見做法）**：
  - 進行一次盡可能均速且全力發揮的 20 分鐘測驗。
  - 以這 20 分鐘的平均功率、配速或心率作為基準，再套用實務修正係數。
  - 此做法與常見的 FTP 推估流程一致。

## 訓練上的意義

提高 AnT 通常代表你能在疲勞急劇上升之前，維持更快的穩定配速或更高的穩定功率。然而它並非表現的唯一決定因子：運動經濟性、持久力、補給與配速策略同樣重要。

## 常見問題

### 什麼是無氧閾值？

無氧閾值是在疲勞開始急速累積之前，身體能維持近似穩態輸出的最高強度。一旦超過這條線，相同的配速或功率很快就會變得難以維持。

### 無氧閾值跟乳酸閾值一樣嗎？

兩者通常指向相近的訓練強度區帶，但檢測方法不同：乳酸閾值依據血乳酸濃度判定，AnT 則可能依據氣體交換或乳酸轉折點定義，因此兩者數值不應直接互換。詳見[乳酸閾值（LT）](/zh-hant/docs/metrics/physiology/lactate-threshold)。

### 沒有實驗室設備時，如何估算無氧閾值？

使用可重複的實地測驗即可，最常見的是 20 分鐘穩定全力測試：取平均功率、配速或心率並套用實務修正係數，與多數 FTP 推估做法相同。

### AnT 與 FTP、LTHR 有什麼關係？

FTP、LTHR 與閾值配速都是實務上用來代表同一強度區帶的代理基準。Trainingload.ai 會運用可靠的閾值估計來辨識閾值課表，並提高配速、功率與心率區間的準確度。
