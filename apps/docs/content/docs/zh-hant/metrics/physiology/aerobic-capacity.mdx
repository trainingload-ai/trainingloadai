# 有氧能力（Aerobic Capacity）

在多數耐力訓練語境中，**有氧能力（Aerobic Capacity）**指的就是 **VO₂max**：身體在極限運動時所能利用的最大氧氣量，通常以相對體重的方式表示（`ml/kg/min`），反映有氧系統的輸出上限。

更高的有氧能力意味著你有更大空間支撐較高強度，但它絕不是決定比賽成績的唯一因素。

## 核心特徵

- **屬於上限指標**：一旦接近攝氧上限，光靠意志力也無法讓有氧供能系統繼續拉高。
- **看趨勢而非單次讀數**：手錶或平台顯示的 VO₂max 多為推估值，容易受高溫、坡度、疲勞與感測器雜訊影響。
- **不等於完賽保證**：兩位 VO₂max 相近的選手，仍可能因閾值能力、運動經濟性與持久力差異而在比賽中跑出懸殊成績。

## 評估方式

### 實驗室檢測（直接量測 VO₂max）
透過漸增負荷至力竭的測驗並搭配氣體分析儀直接測得。

### 實地推估（更適合日常訓練）
如果你的目標是調整訓練決策與追蹤進步，可重複執行的實地估算往往比偶爾做一次實驗室檢測更具實用價值。

## 有氧能力與有氧閾值的差異

- **有氧能力（VO₂max）**描述的是有氧系統的「天花板上限」。
- **有氧閾值（AeT）**描述的則是輕鬆有氧訓練的「上緣邊界」。

有效的耐力訓練不僅能推高 VO₂max，更重要的是提高 AeT 與 AnT 佔 VO₂max 的比例，讓你能在更接近自身上限的強度下穩定維持更久。

## Trainingload.ai 如何運用有氧能力

- **有氧上限脈絡**：透過 VO₂max 理解高強度有氧潛力，特別有助於規劃間歇課表。
- **趨勢追蹤**：將推估 VO₂max 視為長期趨勢指標，並與近期訓練負荷、疲勞與實戰表現交叉檢核。
