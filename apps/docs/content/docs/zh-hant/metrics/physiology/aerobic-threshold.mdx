# 有氧閾值（AeT）

你可以把**有氧閾值（Aerobic Threshold，簡稱 AeT）**理解為「輕鬆有氧」轉向「中度有氧」的分界線：越過這條線後，呼吸會變得更明顯，長時間運動時對肝醣的依賴度也會開始升高。

## 核心特徵

- **呼吸狀態**：輕鬆平穩，通常能以鼻呼吸或順暢交談。
- **主觀體感**：感覺「這個強度我可以持續好幾個小時」。
- **實驗室定義**：通常接近血乳酸首度高於靜息基準值的轉折點（常見約 2 mmol/L 左右）。

## 實務上的估算方式

在沒有實驗室儀器的情況下，運用穩定可重複的體感與訊號，往往比執著於某個「絕對精確」的數字更實用：

- **談話測試與體感**：能長時間維持、且仍能流暢說出完整句子的最高強度。
- **心率粗略範圍**：許多運動員會先以「比乳酸閾值心率再低一階」作為起點，但個體差異相當大。

## 訓練上的意義

AeT 常被視為基礎期有氧堆量的「上緣護欄」：

- **低於 AeT**：適合輕鬆累積跑量／騎量與主動恢復，有助於維持長期訓練穩定度。
- **高於 AeT**：肝醣消耗與恢復成本會明顯加快，因此較適合有明確目的時才刻意安排。

Joe Friel 也強調類似觀點：在真實訓練環境中，找到一個能穩定重複執行的強度區間，遠比糾結於實驗室裡的一條精確界線更有價值（見下方參考資料）。

## Trainingload.ai 如何運用有氧閾值

- **輕鬆課表護欄**：協助辨識輕鬆有氧訓練的合理上緣。
- **長距離課表回顧**：當配速或功率保持穩定、心率卻飄升超過預期區間時，Trainingload.ai 可標記該課表以便結合情境檢視。
- **基礎期脈絡分析**：將 AeT 與心率區間、有氧解耦、EF 以及近期訓練負荷一併解讀。
