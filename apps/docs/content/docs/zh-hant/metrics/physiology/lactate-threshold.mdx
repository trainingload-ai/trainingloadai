# 乳酸閾值（LT）

在訓練語境裡，很多人會把 **乳酸閾值（LT）** 當作 **[無氧閾值（AnT）](./anaerobic-threshold)** 的「另一種說法」。更準確地說：兩者常常指向同一段強度區間，但 **定義口徑與量測方式不同**，所以數字不一定完全一致，這是正常的。

## 定義與測試

- **乳酸閾值（LT）**：通常用血乳酸測試來找「開始持續累積」的拐點。
  - 實驗室的遞增負荷測試中，會每隔幾分鐘採血測乳酸（指尖/耳垂）。
  - 有些體系會用固定濃度（例如常見的 4 mmol/L）作為參考點，但這不代表「每個人的閾值都必然是 4」。更穩妥的理解是：它提供一個可操作的定義口徑。
- **無氧閾值（AnT）**：也常用呼吸氣體分析（氧氣攝取與二氧化碳排出關係的拐點）或血乳酸拐點來確定。

## 實務用法

雖然不同體系會對 LT、AnT、OBLA 等術語做更細的區分，但在日常訓練裡，最有用的抓手往往是：

- **它大致對應「你能穩住一段時間的最高強度」**（常被口語化地理解為「接近 1 小時強度」，但個體差異很大）。
- **它適合用來設定閾值訓練**：例如穩態閾值跑/閾值功率訓練等。

如果你已經在使用 FTP / 閾值心率 / 閾值配速這類指標，可以把乳酸閾值當作「生理學量測視角下的閾值參照」來理解。

## 為什麼關注乳酸？

乳酸本身不是「毒素」——它是糖酵解的產物，也可以被身體再利用。但當強度繼續上升，你會更明顯感到「頂不住」的那種灼熱感與掉速，往往與酸化相關的過程一起出現。把乳酸閾值當作訓練參照點的價值在於：它能幫你把「強度」和「可持續性」連起來，而不是只靠感覺硬頂。
