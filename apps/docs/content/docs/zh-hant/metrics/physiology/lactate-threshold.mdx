# 乳酸閾值（LT）

在日常訓練中，許多運動員會把**乳酸閾值（Lactate Threshold，簡稱 LT）**視為**[無氧閾值（AnT）](/zh-hant/docs/metrics/physiology/anaerobic-threshold)**的近親。更精確地說，兩者多半指向相近的訓練強度帶，但**定義與量測方式不同**，因此測得的數值未必完全一致。

## 定義與測試方式

- **LT**：通常透過漸增負荷測驗中的**血乳酸採樣**來判定。
  - 每隔數分鐘採集微量指尖或耳垂血樣。
  - 部分系統會採用固定參考值（常見為 4 mmol/L），但這不代表每個人的真實閾值都剛好落在「4」。
- **AnT**：依採用的定義不同，可能透過**氣體交換測試**或血乳酸曲線轉折點來判定。

## 實務應用

儘管學界與實務界術語繁多（LT、AnT、OBLA 等），對訓練最具價值的核心重點是：

- 它代表**能長時間維持穩定輸出的最高強度**（常簡稱為「約一小時的全力強度」，但個體差異很大）。
- 它是設計**閾值課表**（穩定間歇、節奏／閾值巡航分段等）的重要錨點。
- 只要長期保持一致的測試方式，它就能可靠地用來設定**心率、配速與功率區間**。

## Trainingload.ai 如何運用乳酸閾值

Trainingload.ai 將乳酸閾值視為實務錨點，而非單一神話數字：

- **校正強度區間**：閾值推估值可用於校準心率區間、配速區間與功率區間。
- **回顧閾值課表**：檢視接近閾值的課表時，會同時對照配速／功率、心率、RPE 與近期疲勞。
- **追蹤長期趨勢**：將閾值變化結合 CTL、ATL、TSB 以及近期同類型訓練表現判讀，更有意義。
- **一致性優先**：穩定可重複的實地測試，往往比偶爾一次追求完美的檢測更具實戰指導價值。

## 為何乳酸值得關注

乳酸本身並不是造成痠痛的「毒素」——它既是糖解作用的代謝產物，也是身體可直接利用的能量燃料。當強度升高時，伴隨乳酸快速累積而來的代謝變化，才會引發灼熱感與肌力衰退。LT 的價值在於把**運動強度**與**可持續時間**連結起來，而不只是衡量有多辛苦。
