# 無氧能力

你可以把 **無氧能力**理解成：身體在很短時間裡能「透支」出多少高強度輸出，以及這段輸出能撐多久。它常常決定你能不能在關鍵時刻突然加速、拉開差距或完成衝刺。

## 核心特徵

- **持續時間很短**：通常是幾秒到幾十秒（常見說法會拿「~30 秒」做一個直觀錨點）。
- **更像「能量儲備」而不是「巡航能力」**：它和你能否長時間穩定輸出（閾值/有氧）是兩類問題。
- **常見場景**：
  - 自行車比賽的終點衝刺、突然加速
  - 越野/公路跑的變速與短坡進攻
  - 間歇訓練中短時間的高強度重複

## 訓練意義

對長距離耐力運動（馬拉松、鐵人三項）來說，無氧能力的重要性通常較低。但對需要頻繁變速、進攻或終點衝刺的項目（公路自行車、越野跑），無氧能力往往能決定最後幾百公尺的勝負。

你可以把它理解成「渦輪增壓」——不會持久，但關鍵時刻很致命。
