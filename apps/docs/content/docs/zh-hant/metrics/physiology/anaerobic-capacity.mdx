# 無氧能力（Anaerobic Capacity）

你可以把**無氧能力（Anaerobic Capacity）**理解為：在超過可持續強度（閾值）之上，你能在短時間內爆發出多少高強度作功，以及能將這股輸出撐多久。它直接展現在終點衝刺、突然加速與短陡坡進攻等場景。

## 核心特徵

- **時間短促**：通常落在數秒至數十秒之間（實務上常以約 30 秒作為代表區間）。
- **不同於「穩定耐力」**：與閾值能力或有氧基礎屬於不同維度。
- **典型場景**：終點衝線、節奏突變加速、短陡坡拉扯。

## 訓練上的意義

對於長距離耐力項目（馬拉松、長距離鐵人三項），無氧能力通常不如有氧基礎、閾值與持久力關鍵；但對於經常需要變速拉扯、進攻突圍或終點衝刺的項目（公路車賽、技術型越野跑），無氧能力往往在決勝瞬間扮演關鍵角色。

雖然無氧輸出無法像閾值強度那樣長時間維持，但在賽事或課表要求瞬間拉高強度時，它仍是不可或缺的能力儲備。

## Trainingload.ai 如何運用無氧能力

- **短時間爆發脈絡**：辨識課表中是否包含反覆加速、衝刺或超閾值高強度輸出。
- **功率模型連結**：在單車訓練中，無氧能力與 W′／無氧作功能力（Anaerobic Work Capacity）緊密相關。
- **訓練結構平衡**：與閾值、VO₂max 及恢復狀態一同判讀，避免過多短爆發課表排擠核心耐力目標。
