# 坡度調整配速（GAP）

**坡度調整配速（Grade Adjusted Pace，簡稱 GAP）** 會透過生物力學與能量消耗模型，將你在**上坡**或**下坡**路段跑出的實際配速，換算為能量成本相近的平地等效配速。

它要回答的是跑者最常問的核心問題：「如果剛才不是在爬這個坡，以同樣的出力在平地跑，配速大概是多少？」

## 核心概念

在起伏地形上，**實際配速**往往容易造成誤判：
- **上坡**：必須額外對抗重力作功，配速變慢，但生理負荷很高。
- **下坡**：重力協助前進，配速變快，但能量消耗未必呈線性下降（離心煞車力同樣耗能）。

GAP 能扣除部分坡度造成的干擾，提供標準化的配速參考，讓你得以跨路線比較相近的運動強度。

## 計算方式

Trainingload.ai 採用基於 **Minetti（2002）** 的能量消耗模型計算 GAP，量化不同坡度下的**能量成本（EC）**。

### 能量消耗方程式

$$
C_r = 155.4 \times i^5 - 30.4 \times i^4 - 43.3 \times i^3 + 46.3 \times i^2 + 19.5 \times i + 3.6
$$

其中：
- $C_r$：能量成本（J/kg/m）
- $i$：坡度（例如 5% 坡度為 0.05）

### GAP 計算公式

```text
GAP = Pace_actual / (C_r / C_flat)
```

- 在 0% 平地時，$C_{flat} \approx 3.6$。
- 上坡：$C_r > 3.6$，因此 GAP 會比實際配速更快（時間數值較小）。
- 緩下坡：$C_r < 3.6$，因此 GAP 會比實際配速更慢。
- **注意**：在極陡下坡（通常低於 -20%）時，強烈的**離心煞車負荷**會讓能量消耗再次上升，使 GAP 看起來又「變快」。

## 常見應用

### 1. 越野跑與山路訓練
在陡峭路線上，單看實際配速很難判斷當下強度。
- **舉例**：爬一段 15% 的陡坡時，實際配速掉到 12:00/km。
- **GAP**：換算顯示為 5:00/km。
- **解讀**：身體實際承受的代謝強度遠高於原始配速所呈現的樣子。

### 2. 跑步配速負荷估算
GAP 為跑步配速負荷估算提供坡度修正。 [跑步配速負荷估算](/zh-hant/docs/metrics/pace/normalized-graded-pace)

```text
Pace_actual  --(grade adjustment)-->  GAP  --(weighted smoothing)-->  NGP
```

### 3. 賽事配速策略
透過 GAP 分析賽事路線的 GPX 資料，可以提前規劃各個爬升與下坡路段的實際目標配速，讓全程體力分配更均勻。

## Trainingload.ai 如何運用 GAP

- **補齊地形脈絡**：GAP 能解釋為何看起來很慢的上坡分段，其實代表相當高的運動強度。
- **切勿盲目追逐**：GAP 只反映代謝等效成本，並未完全納入肌肉骨骼衝擊。長距離高速下坡在 GAP 上看似輕鬆，但對股四頭肌與膝關節造成的離心負荷依然很高。
- **以分段或賽後趨勢為主**：GPS 坡度估算存在雜訊與延遲，即時 GAP 往往跳動較大，建議以單圈平均或活動後的分析資料為準。
