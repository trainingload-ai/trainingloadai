# 標準化坡度配速（NGP）

**標準化坡度配速（Normalized Graded Pace，簡稱 NGP）** 是一項專為跑步設計的強度指標。它建立在 **[GAP（坡度調整配速）](/zh-hant/docs/metrics/pace/grade-adjusted-pace)** 之上，整體演算法邏輯則與單車領域的 **[NP（標準化功率）](/zh-hant/docs/metrics/power/normalized-power)** 相似。

用白話區分兩者：
- **GAP** 回答：「這段上坡或下坡配速，相當於平地多快的配速？」（即時／分段等效）。
- **NGP** 回答：「把這整趟配速與坡度都在變化的跑步攤平來看，相當於全程穩定跑多少平地配速的生理消耗？」（整趟活動等效）。

## 核心概念

生理消耗（肝醣消耗、乳酸堆積與整體代謝壓力）與運動強度之間呈現**非線性**關係。

> **舉例**：
> 全程穩定跑 5:00/km，生理壓力通常低於「一半時間跑 4:00/km、另一半時間跑 6:00/km」。
> 即使兩者的平均配速都是 5:00/km，第二趟的 **NGP** 會明顯更快，藉此反映加速衝刺所帶來的額外生理負荷。

## 計算方式

NGP 會先從坡度調整後的強度序列進行加權計算，最後再轉回配速格式顯示。

### 標準化步驟

由於配速是時間單位（數值越小代表越快），Trainingload.ai 會先將 GAP 轉換為速度／強度等效值再加權，接著套用類似 NP 的標準化流程：

1. **轉換**：將 GAP 配速轉換為速度或強度值。
2. **平滑**：計算 30 秒滑動平均（rolling average）。
3. **加權**：對平滑後數值取四次方，提高高強度路段的權重。
4. **平均並開根號**：計算平均值後再取四次方根。
5. **回轉顯示**：將結果轉回配速格式，方便閱讀。

```text
NGP_intensity = 4th_root( (1/N) * sum_{i=1..N} (GAP_intensity_rolling(i))^4 )
```

## 常見應用

### 1. 為越野跑與山路課表補齊強度脈絡
在丘陵或山徑地形上，平均配速常顯得非常慢，而 NGP 能協助看出你的真實生理付出其實並未下降。
- **舉例**：一趟高爬升越野跑的平均配速為 10:00/km。
- **NGP**：換算結果可能快上許多，更能如實反映身體承受的代謝壓力。

### 2. 跑步配速負荷估算

有體重資料時，Trainingload.ai 以 GOVSS 計算跑步的配速負荷。缺少體重時，系統根據有效配速樣本與活動開始時生效的跑步閾值，採用類似 rTSS 的方式估算。優先使用閾值配速（TP），其次使用臨界速度（CS）。此估算無須實測心率或功率。

```text
100 × observed hours × (normalized speed / threshold speed)²
```

有坡度資料的時間達到有效配速時間的 80% 時，系統會對有坡度資料的部分做修正。其餘按平路估算。若沒有完整的 30 秒視窗，則使用有效時段的平均速度。沒有配速記錄的時間不計入。

## 指標比較

| 指標 | 全稱 | 含義 | 適用情境 |
| :--- | :--- | :--- | :--- |
| **Avg Pace** | 平均配速 | 實際跑出的平均配速 | 平路穩定配速跑、推估完賽時間 |
| **Avg GAP** | 平均坡度調整配速 | 經坡度調整後的平均配速 | 起伏地形但節奏相對穩定的路線 |
| **NGP** | 標準化坡度配速 | 經坡度調整與非線性加權的配速 | 越野跑、間歇訓練、複雜地形與 rTSS 計算 |

## Trainingload.ai 如何運用 NGP

- **作為考量地形的強度參考**：在山路或配速起伏大的課表中，NGP 通常比平均配速更有參考價值。
- **搭配 VI（變異指數）觀察配速穩定度**：計算 **VI = NGP / Avg GAP**（以速度計算）。
  - 若 VI 接近 1.0，代表出力相當穩定。
  - 若 VI > 1.05，通常代表課表包含間歇加速或地形起伏劇烈。
