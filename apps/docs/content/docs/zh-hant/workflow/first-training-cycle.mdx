# 完成首次訓練與回顧

## 完成結果

建立一份可信賴的運動員檔案、一筆「已就緒」的活動、一份已啟用或已檢視的訓練計畫，以及明確的下一次課表決策。

## 開始之前

- 請使用你自己的活動紀錄。分享截圖或檔案前，請先檢查是否包含帳號憑證或住家位置。
- 在啟用多個雙向整合之前，先選擇一條主要匯入路徑。
- 如果尚未準備好連接平台，請先準備一份近期的 FIT、TCX 或 GPX 檔案。

## 1. 校準運動員檔案

請依照[個人檔案、閾值與區間](/zh-hant/docs/guide/profile-thresholds-zones)完成設定。確認時區、單位、各運動項目的閾值，以及偏好的負荷來源。

## 2. 匯入一筆已完成活動

使用[連接資料](/zh-hant/docs/guide/connect-data)建立持續同步，或使用[上傳活動檔案](/zh-hant/docs/guide/upload-activity-files)進行可控的首次匯入。

請等待活動進入「已就緒」狀態。僅看到活動卡片並不代表圖表與訓練負荷已經處理完成。

## 3. 檢查活動紀錄

開啟[活動詳情](/zh-hant/docs/guide/activity-detail)。檢查資料來源、開始時間、時長、距離、心率或功率是否齊全、分段紀錄與訓練負荷。缺少的感測器資料應保持空白，而不應推測為實測資料。

## 4. 建立或選擇計畫

使用[建立訓練計畫](/zh-hant/docs/guide/create-training-plan)檢視排程，確認目標、日期、運動項目與訓練量都合理後再啟用。

## 5. 核對計畫與實際內容

開啟[行事曆](/zh-hant/docs/guide/calendar)。當已完成活動與計畫課表對應同一場訓練時，將兩者關聯；無關或計畫外的活動則保持分開。

## 6. 決定下一步

開啟[今日與目前狀態](/zh-hant/docs/guide/today-and-current-state)，然後向[智能教練](/zh-hant/docs/guide/ai-coach)提出一個聚焦的問題，包含你要做的決策、時間範圍、限制條件，以及希望檢查的證據。

## 驗證整個週期

- 運動員檔案使用正確的單位、時區與閾值。
- 有一筆活動處於「已就緒」狀態，並顯示來源實際提供的資料。
- 可以清楚看到目前的訓練計畫與今日課表。
- 只有在代表同一場訓練時，計畫與實際活動才互相連結。
- 任何未來的變更皆清楚呈現且可供檢視。
