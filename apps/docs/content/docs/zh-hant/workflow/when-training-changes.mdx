# 當訓練與計畫不符時

## 完成結果

保留誠實的計畫與實際歷史紀錄，並只對未來訓練做出最小且有充分依據的調整。

## 選擇對應情況

| 實際情況 | 正確記錄方式 | 不要這樣做 |
| --- | --- | --- |
| 跳過課表 | 將計畫課表保留為跳過或未完成 | 上傳一筆假的零時長活動 |
| 縮短課表 | 將實際較短的活動連結到該計畫課表 | 修改已完成資料以符合原定目標 |
| 替換課表 | 讓計畫與實際完成的訓練類型同時可見 | 重新命名無關活動來掩飾變更 |
| 計畫外訓練 | 除非它實際取代了特定課表，否則保持未連結 | 僅因日期接近就強行連結到鄰近課表 |
| 移動課表 | 只有在反映真實決策時才移動計畫課表 | 修改已完成活動的時間戳記 |

## 調整前先回顧

1. 在[行事曆](/zh-hant/docs/guide/calendar)中開啟對應日期。
2. 在[活動清單](/zh-hant/docs/guide/activity-feed-search)中確認活動來源與處理狀態。
3. 在[活動詳情](/zh-hant/docs/guide/activity-detail)中檢視訓練負荷與感測器涵蓋範圍。
4. 將這項變化與近期負荷、睡眠或恢復脈絡，以及下一個關鍵課表一併比較。
5. 如果確實需要調整，先只變動一個主要變數：時間、時長或強度。

## 套用排程調整

在網頁版或 Personal 的行事曆中，於日期上按右鍵並選擇**調整排程**。在草稿中移動接下來的課表或編輯訓練內容，比較原始與修訂後的日期及內容後再確認。如需儲存草稿並稍後繼續，請參考[行事曆調整步驟](/zh-hant/docs/guide/calendar#adjust-upcoming-workouts)。

## 精準使用智能教練

提出具體的決策問題，例如：「昨天因為睡眠不佳，輕鬆跑從 45 分鐘縮短為 25 分鐘。週六的長距離跑需要調整嗎？」避免在沒有條件限制的情況下要求教練重寫整份計畫。

## 驗證結果

行事曆仍應清楚呈現原本計畫、實際完成、差異原因，以及調整了哪一項未來課表。原始活動證據必須保持不變。
