# 診斷活動、負荷與恢復資料問題

## 從症狀著手

| 症狀 | 優先檢查 | 建議下一步指南 |
| --- | --- | --- |
| 缺少活動紀錄 | 服務商連接狀態、匯入時間範圍與檔案狀態 | [連接資料](/zh-hant/docs/guide/connect-data) |
| 活動重複出現 | 多條匯入路徑與來源識別碼 | [平台整合](/zh-hant/docs/guide/integrations) |
| 活動存在但沒有負荷 | 處理狀態、時長、心率、功率、配速與個人檔案閾值 | [活動詳情](/zh-hant/docs/guide/activity-detail) |
| 圖表或分段紀錄載入失敗 | 來源檔案是否提供逐點紀錄與分段資訊 | [上傳活動檔案](/zh-hant/docs/guide/upload-activity-files) |
| 睡眠、HRV 或靜止心率為空 | 健康權限、服務商涵蓋範圍、日期與時區 | [帳號、權限與使用量](/zh-hant/docs/guide/account-permissions-and-usage) |
| PMC 數值異常偏低或偏高 | 重複紀錄、缺漏日期、所選運動項目、負荷來源與閾值變更 | [訓練分析流程](/zh-hant/docs/guide/training-analysis-workflow) |

## 依序診斷

1. 確認預期的資料來源與時間範圍。
2. 確認來源是否提供了必要的感測器資料流。
3. 檢查匯入與處理狀態。
4. 檢查個人檔案閾值與負荷來源優先順序。
5. 將一筆受影響的活動與一筆已知正常的活動進行比對。
6. 完成以上步驟後，再考慮更改設定或聯繫支援團隊。

## 蒐集安全的支援證據

請附上活動日期、運動項目、資料來源、目前可見狀態、預期與實際結果，以及問題是否可重現。請務必移除電子郵件地址、OAuth 權杖、API 金鑰、精確住家位置與私人服務商識別碼。

切勿僅為了得到偏好的負荷數值而修改閾值。設定變更會影響後續解讀，也可能改動衍生歷史資料。
