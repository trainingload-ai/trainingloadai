# 完整訓練流程

請依照以下順序操作：從匯入活動與規劃訓練，到回顧實際完成內容。每個步驟都附有對應指南與可檢核的完成標準。

## 訓練循環

| 階段 | 關鍵問題 | 主要指南 | 完成標準 |
| --- | --- | --- | --- |
| 1. 校準 | 單位、時區、閾值與區間是否可用？ | [個人檔案、閾值與區間](/zh-hant/docs/guide/profile-thresholds-zones) | 個人檔案符合運動項目與目前能力 |
| 2. 連接 | 哪個來源提供活動與健康資料？ | [連接資料](/zh-hant/docs/guide/connect-data) | 至少有一筆活動進入「已就緒」狀態 |
| 3. 規劃 | 目前的目標與排程是什麼？ | [建立訓練計畫](/zh-hant/docs/guide/create-training-plan) | 已檢視的計畫已啟用或準備啟用 |
| 4. 執行 | 今天應該完成什麼訓練？ | [今日與目前狀態](/zh-hant/docs/guide/today-and-current-state) | 運動員清楚今日計畫課表與限制條件 |
| 5. 記錄 | 實際發生了什麼？ | [行動裝置記錄與檔案上傳](/zh-hant/docs/guide/mobile-recording) | 已儲存或匯入完成的活動紀錄 |
| 6. 核對 | 這筆活動是否屬於某個計畫課表？ | [活動清單與搜尋](/zh-hant/docs/guide/activity-feed-search) | 計畫與實際狀態已正確關聯或刻意區分 |
| 7. 回顧 | 活動資料與近期趨勢支持什麼解讀？ | [活動詳情](/zh-hant/docs/guide/activity-detail) | 來源、負荷、圖表與情境均支持該解讀 |
| 8. 決策 | 接下來的訓練需要調整嗎？ | [智能教練](/zh-hant/docs/guide/ai-coach) | 任何建議變更都明確列出並經過檢視 |
| 9. 重複 | 本週與整個週期是否仍朝目標前進？ | [每週訓練回顧](/zh-hant/docs/workflow/weekly-review) | 下一次回顧時間與下一個關鍵課表皆已明確 |

## 從主要路徑開始

設定新帳號或確認整套產品流程是否順暢運作時，請先使用[完成首次訓練與回顧](/zh-hant/docs/workflow/first-training-cycle)。

當實際執行與計畫有所落差時，請使用對應的情境指南：

- [跳過、縮短、替換或計畫外訓練](/zh-hant/docs/workflow/when-training-changes)
- [缺少活動、負荷或恢復資料](/zh-hant/docs/workflow/data-and-load-problems)
- [每週計畫與實際回顧](/zh-hant/docs/workflow/weekly-review)

## 將觀察與決策分開

活動紀錄、圖表與 AI 訊息都是證據，而非自動變更計畫的指令。請先確認資料來源與時間範圍，再說明你的解讀，最後才決定接下來的訓練是否需要調整。
