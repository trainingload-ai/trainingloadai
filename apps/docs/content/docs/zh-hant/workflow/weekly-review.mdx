# 每週訓練回顧

## 完成結果

以 15–20 分鐘完成一次回顧，產出一份文字結論、最多一項主要調整，以及用來檢驗決策是否有效的日期或課表。

## 1. 檢查資料完整性

開啟[活動清單](/zh-hant/docs/guide/activity-feed-search)。在檢視每週總計之前，先解決處理失敗、重複項目與誤連結的計畫關聯。

## 2. 比較計畫與實際

透過[行事曆](/zh-hant/docs/guide/calendar)與目前的訓練計畫，統計已完成、縮短、跳過、替換與計畫外的課表。不要只憑完成率百分比來做回顧。

## 3. 檢視訓練劑量

使用[儀表板](/zh-hant/docs/guide/dashboard)與[訓練負荷](/zh-hant/docs/metrics/training-load)。保持運動項目與時間範圍篩選條件一致，找出真正造成變化的單場課表，而非只看彙總數值。

## 4. 納入身體反應與脈絡

若資料可用，請一併檢視睡眠、HRV、靜止心率、單次訓練 RPE、肌肉痠痛與主觀疲勞度。缺少恢復資料會降低判斷信心，但並不代表恢復良好或不佳。

## 5. 決定下一步行動

從以下選項中擇一：

- 維持原計畫不變。
- 移動一場課表。
- 降低一場課表的時長或強度目標。
- 將一場課表替換為恢復訓練。
- 當問題超出訓練指導範圍時，尋求專業教練或醫療評估。

## 驗證回顧結果

記錄下證據、決策內容、受影響的具體未來課表，以及下一次檢視時間點。如果使用[智能教練](/zh-hant/docs/guide/ai-coach)，請確認其回覆引用了相同的時間範圍與證據。
