# MCP 更新日誌

## 2026-10-15 — 完整唯讀訓練能力面

- 工具目錄由 17 個擴充至 24 個。
- 新增活動彙總統計與訓練一致性分析，具備明確的資料覆蓋率與截斷狀態語意。
- 新增經隱私降維處理的活動區間分布與單圈／分段詳情。
- 新增訓練計畫探索、計畫層級完成度與負荷摘要，以及單一賽事詳情。
- 新增三項原生 MCP 資源與三個可重複使用的提示詞，並搭配自動產生的雙語參考文件與發布前檢查驗證。

## 2026-10-15 — 進階唯讀分析與完整導入流程（早期里程碑）

- 工具目錄由 9 個擴充至 17 個。
- 新增週期比較、運動項目負荷拆解與訓練準備度指標。
- 新增體能趨勢、訓練區間與個人最佳成績查詢。
- 新增依狀態計算的計畫達成度與第三方整合／同步就緒狀態。
- 新增運作原理、使用情境以及七份專屬用戶端連線指南。
- 擴充功能介紹頁面，涵蓋從 OAuth 連線、透明工具呼叫到基於證據的回答全流程。

## 2026-10-14 — 初始唯讀產品能力面

- 新增 9 項唯讀能力，涵蓋訓練負荷、活動、訓練計畫、賽事、個人檔案與健康資料。
- 新增彙總優先的伺服器指引，以及由 Zod 支援的輸入／輸出資料規格。
- 新增 OAuth 權限範圍篩選、獨立的 `health:read` 授權、撤銷狀態可視性、請求上限、稽核紀錄與 OpenTelemetry 觀測整合。
- 新增無狀態 MCP SDK v2 傳輸層，相容 `2025-11-25` 與 `2026-07-28` 協定版本。
- 新增自動產生的工具參考文件與用戶端連線指南。

本版本不包含任何寫入型工具。
