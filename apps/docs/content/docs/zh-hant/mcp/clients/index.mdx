# 用戶端指南

請選擇您所使用的用戶端。每一份指南都會透過 TrainingLoad OAuth 連線至相同端點，無須 API 金鑰。

- [ChatGPT](/zh-hant/docs/mcp/clients/chatgpt)
- [Codex](/zh-hant/docs/mcp/clients/codex)
- [Claude Code](/zh-hant/docs/mcp/clients/claude-code)
- [Claude Desktop](/zh-hant/docs/mcp/clients/claude-desktop)
- [Cursor](/zh-hant/docs/mcp/clients/cursor)
- [VS Code](/zh-hant/docs/mcp/clients/vscode)
- [opencode](/zh-hant/docs/mcp/clients/opencode)

完成設定後，請依照[通用驗收檢查](/zh-hant/docs/mcp/connect#所有用戶端通用的驗收檢查)確認 OAuth 授權、工具探索與首次工具呼叫皆正常運作。
