# MCP 工具參考

本頁面由伺服器能力目錄自動產生。請勿直接編輯；更新時請執行 `pnpm --dir apps/server mcp:reference`。每個工具僅讀取已透過 OAuth 授權的運動員資料。

> `health:read` 未包含於預設授權中。首次呼叫 `get_health_summary` 前，用戶端應發起增量授權請求。

| 工具 | 用途 | OAuth 權限範圍 |
| --- | --- | --- |
| `get_training_snapshot` | 彙總已授權運動員的近期訓練負荷、體能、疲勞、狀態、週對週變化與近期活動。在發起多次細粒度呼叫前，應優先使用此工具。 | `training:read` `plan:read` `activity:read` |
| `get_athlete_profile` | 讀取已授權運動員的運動偏好與訓練閾值。不會回傳姓名、電子郵件、出生日期或內部使用者 ID。 | `profile:read` |
| `list_activities` | 在指定範圍內搜尋已授權運動員的活動摘要。不會回傳原始感測器串流或精確 GPS 軌跡。 | `activity:read` |
| `get_activity` | 依不透明雜湊 ID（hash ID）讀取單筆已授權活動。僅回傳摘要指標，排除精確路線與原始感測器取樣點。 | `activity:read` |
| `get_activity_zones` | 讀取單筆已授權活動已儲存的心率、功率與配速區間分布。僅回傳彙總時長與百分比，絕不回傳感測器取樣點。 | `activity:read` |
| `get_activity_splits` | 透過不透明分頁讀取單筆已授權活動有上限的單圈或分段摘要。排除精確座標與原始感測器取樣點。 | `activity:read` |
| `get_activity_statistics` | 依運動項目彙總指定期間內的活動次數、活躍天數、時長、距離與標準化訓練負荷，包含指標覆蓋率與截斷狀態。 | `training:read` `activity:read` |
| `get_training_load` | 讀取已授權運動員最長 180 天內的訓練負荷、體能、疲勞與狀態時間序列。 | `training:read` |
| `compare_training_periods` | 比較兩個指定訓練週期的總負荷、日均負荷與活躍天數。結果僅供觀察，不構成體能或恢復變化的定論。 | `training:read` |
| `get_training_breakdown` | 將已授權運動員最長 180 天內的訓練負荷，依跑步、騎車、游泳與其他項目進行拆解。 | `training:read` |
| `get_training_consistency` | 摘要 14 至 180 天內的資料儲存天數覆蓋率、連續活躍天數、每日負荷波動度與每週負荷。缺失日期會維持缺失，不會被視為零值。 | `training:read` |
| `get_training_readiness` | 回傳目前負荷、狀態、新鮮度與近期負荷區間作為觀察性訓練指標。此結果並非醫療評估，亦非訓練指令。 | `training:read` `plan:read` `activity:read` |
| `get_fitness_trends` | 讀取單一運動員體能指標在明確資料來源軌道上的有界歷史紀錄。推估值僅供參考；AUTO 或 MANUAL 數值則為個人檔案紀錄。 | `profile:read` |
| `get_training_zones` | 讀取運動員目前已解析的心率、配速與功率區間，並標示各項設定屬於自訂、推導或不可用。 | `profile:read` |
| `get_personal_bests` | 讀取指定日期範圍內，針對標準或自訂距離／時間目標所處理出的最佳表現。不會回傳路線或原始感測器資料。 | `activity:read` |
| `list_training_plans` | 探索與指定日期範圍重疊的已授權訓練計畫。持續型計畫的 `periodWeeks` 與 `endDate` 為 `null`；`generatedThrough` 代表最新發布日期，而非計畫結束日或無中斷覆蓋的保證。 | `plan:read` |
| `get_plan_summary` | 讀取屬於使用者的訓練計畫摘要，包含完成度、計畫與實際負荷比較、每週進度與運動項目拆解。持續型計畫的總計僅涵蓋 `workoutWindow` 且 `periodWeeks` 為 `null`，並非生涯累計總值。此工具絕不修改計畫。 | `plan:read` `activity:read` |
| `list_planned_workouts` | 透過不透明分頁列出指定日期範圍內的已授權計畫課表。 | `plan:read` |
| `get_planned_workout` | 讀取單筆已授權計畫課表及其結構化步驟。此工具絕不修改訓練計畫。 | `plan:read` |
| `get_plan_adherence` | 摘要指定日期範圍內依狀態計算的計畫達成度。`DONE` 為已完成、`SKIPPED` 為已跳過，而 `PLANNED` 或 `IN_PROGRESS` 則維持待執行。 | `plan:read` |
| `list_competitions` | 透過不透明分頁列出已授權運動員在指定日期範圍內的賽事。 | `competition:read` |
| `get_competition` | 依不透明賽事 ID 讀取單筆已授權賽事，包含時程、目標、地點與備註。此工具絕不修改賽事資料。 | `competition:read` |
| `get_health_summary` | 讀取選定的每日恢復、睡眠、心率、壓力與活動摘要。此為身心健康背景資訊，並非醫療診斷或醫療建議。 | `health:read` |
| `get_integration_status` | 讀取所支援第三方訓練平台的連線與同步就緒狀態，不會回傳外部帳號識別碼、憑證或原始錯誤訊息。 | `profile:read` |
