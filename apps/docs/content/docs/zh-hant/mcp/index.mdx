# TrainingLoad MCP

透過 TrainingLoad MCP，將您的訓練資料連線至 ChatGPT、Codex、Claude 或其他相容的 AI 用戶端。無須逐筆複製活動紀錄，即可直接詢問近期負荷、訓練計畫完成度、表現趨勢或同步異常問題。MCP 僅供讀取資料，不會修改您的訓練排程。

**伺服器 URL：** `https://api.trainingload.ai/mcp`

不需使用 API 金鑰。用戶端會開啟 TrainingLoad OAuth 授權頁面，讓您檢視用戶端名稱與請求的權限範圍。之後您隨時可從帳號設定中撤銷存取權。

## 可讀取的訓練資訊

| 問題 | 主要能力 |
| --- | --- |
| 我目前的訓練狀態如何？ | 訓練快照、準備度指標、負荷時間序列 |
| 兩個訓練週期之間有哪些變化？ | 週期比較、運動項目拆解、活動統計與一致性分析 |
| 我的跑步、騎車或游泳體能有變化嗎？ | 體能趨勢、訓練區間、個人最佳成績 |
| 我目前的訓練計畫執行度如何？ | 訓練計畫探索與摘要、計畫課表、課表詳情、依狀態計算的計畫達成度 |
| 我完成了哪些訓練？ | 活動清單、隱私降維後的活動詳情、區間停留時間與單圈／分段摘要 |
| 接下來有哪些賽事？ | 賽事清單與限於本人帳號範圍的賽事詳情 |
| 為什麼某個第三方平台沒有同步？ | 連線與同步就緒狀態 |
| 我的身心健康背景有變化嗎？ | 需另行授權的每日健康摘要 |

完整的欄位與權限範圍請參閱[工具參考](/zh-hant/docs/mcp/tools)。用戶端亦可探索三項內建的[資源與提示詞](/zh-hant/docs/mcp/resources-and-prompts)，用於指標解讀、安全邊界說明及可重複使用的分析流程。

## 試著問這些問題

- 「比較本週與上週的訓練量與訓練負荷，哪些活動是造成主要變化的原因？」
- 「我這週完成了多少訓練計畫？還有哪些課表尚未關聯到實際活動？」
- 「我近期的跑步指標有什麼變化？哪些日期缺乏可比較的資料？」

閱讀回答時，請確認其使用的日期範圍、引用的活動以及缺失資料說明。趨勢可作為訓練討論的參考，但不能構成醫療結論。

## 連線前須了解的限制

- **唯讀存取：** 用戶端無法修改活動、訓練計畫、賽事、個人檔案、平台連線或帳號設定。
- **僅限本人資料：** 用戶端只能查詢屬於您已授權帳號的紀錄。
- **訓練摘要：** 工具不會提供精確 GPS 軌跡、原始感測器資料串流、第三方平台憑證或完整 FIT 檔案。
- **獨立的健康資料權限：** 預設不包含 `health:read`。
- **可撤銷授權：** 當您不再使用某個用戶端時，可隨時從帳號中移除其存取權限。
