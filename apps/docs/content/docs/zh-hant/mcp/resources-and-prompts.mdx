# MCP 資源與提示詞

本頁面由伺服器 MCP 內容目錄自動產生。請勿直接編輯；更新時請執行 `pnpm --dir apps/server mcp:reference`。

資源可為用戶端提供穩定的指標說明、安全指引與已授權能力目錄，無須額外讀取運動員資料。提示詞則會產生結構化的提問範本；實際資料仍須透過符合 OAuth 權限範圍的工具讀取。

## 資源

| URI | 名稱 | 用途 |
| --- | --- | --- |
| `trainingload://guide/training-metrics` | TrainingLoad 指標解讀指南 | 說明訓練負荷、ATL、CTL、TSB、準備度區間、資料覆蓋率與缺失資料的定義與解讀邊界。 |
| `trainingload://guide/privacy-and-safety` | TrainingLoad 隱私與安全指南 | 說明唯讀邊界、非信任文字處理方式、健康資料限制及排除回傳的資料類別。 |
| `trainingload://catalog/capabilities` | 已授權 TrainingLoad 能力目錄 | 列出目前已授權的唯讀工具名稱、說明與對應的 OAuth 權限範圍。 |
