> **Missing one run rarely derails a nine-week plan. Cramming it into the next 48 hours can cost you the recovery the plan was built around.**

It is Thursday night. You open your Couch to 5K plan, and Tuesday's session is still sitting there: Week 4, five rounds of three minutes, not done.

So you do the maths. Run Thursday, run Friday, and the week is back on track.

It feels responsible. For a beginner runner, it is usually the wrong trade.

## The make-up run is the bigger problem

A nine-week Couch to 5K plan has 27 runs. Missing one is about 4% of the schedule. One empty slot will not erase the work around it.

Running on back-to-back days changes something more important: recovery.

In the first months of running, breathing often starts to feel easier before the legs are fully accustomed to repeated impact. Tendons, bones, calves, and the small muscles around the shins still have to absorb every landing. The rest day between beginner runs gives that tissue time to recover before the next dose of impact.

That is why beginner plans are normally spaced out. The NHS Couch to 5K plan, for example, recommends a rest day between runs. The point is not that two consecutive runs automatically cause injury. It is that a static plan has already budgeted for recovery, and a make-up run quietly spends it.

The make-up run also tends to happen under poor conditions: late in the day, tired from work, a little guilty, and keen to get it over with. An easy session can quickly stop feeling easy—and easy is the only intensity this plan asks for.

Every session in the second half of our plan carries the same reminder: **do not make up missed training by stacking sessions.** A missed Tuesday is a small disruption. Turning it into Thursday and Friday back to back creates a new problem that did not need to exist.

## Why a missed run feels like a debt

The plan was written before you started it. It does not know what happened on Tuesday.

When you open the calendar on Thursday, the workout is still there, unticked. Nobody has told you that it can be skipped, so it looks like a debt that still has to be paid.

The plan is not being strict. It is simply static.

## What to do instead

The simplest answer is often to skip the missed run. Decide now, so it is not still hanging over the weekend.

Moving it can also work, with one condition: after the move, leave at least one complete rest day between any two runs. If you normally run Monday, Wednesday, and Friday, miss Wednesday, then run Thursday and move Friday to Saturday, the spacing still works. If the only option is Thursday and Friday back to back, let the missed session go.

Then ask a better question than “How do I make it up?”

**How did the runs I actually completed feel?**

In [our free nine-week Couch to 5K plan](/couch-to-5k-training-plan), the three sessions within each week are identical during Weeks 1–6. The running blocks progress from one minute to one, two, three, four, and then five minutes.

If you miss the third run of Week 4 but the first two sets of three-minute running felt controlled, moving on to four-minute blocks is reasonable. If the second session was already a struggle, repeat Week 4. Your place in the plan is better defined by the last session you completed comfortably than by the week number on the calendar.

The same principle gives you a few useful defaults:

- **Missed two runs in one week:** repeating the week is usually the cleaner choice. Week 5's four sets of four minutes build on Week 4's five sets of three. One completed session is a thin base for treating the week as finished.
- **Two weeks away:** restart one week earlier and treat the first run as a check. If it stays easy and conversational, continue. If the running blocks feel unexpectedly long, step back again.
- **Three weeks or more away:** do not jump straight back to the date on the calendar. For a true beginner, Week 1 or 2 is a cautious restart; previous running history and the reason for the break may justify a different starting point.
- **A race is already booked:** if there is no longer enough time to preserve the progression, move the race or treat it as a low-pressure run-walk finish. Do not compress six weeks of training into three.

These are conservative starting points, not medical rules. Research has not found one universal combination of weekly distance, frequency, or progression that predicts running injury for every runner. The useful principle is simpler: avoid sudden catch-up work, preserve recovery, and adjust from what you have actually completed.

None of this is “making up” a workout. Making up adds more. These choices step back, restore the rhythm, and then move forward.

## Sometimes missing the run was the right call

If you have slept badly for several nights or the week has emptied you out, missing one run may have been the sensible decision. Count it as recovery rather than a moral failure. Adding another session on top of real fatigue does not guarantee more fitness; it may simply make the next run worse.

If you are ill, wait until you feel like yourself again before testing the plan. If pain stays in one specific spot, gets worse as you run, or changes your stride, stop. If it does not settle, seek advice from an appropriate healthcare professional.

This article cannot diagnose pain. An AI coach cannot diagnose it either.

## The transition many runners get stuck on

One of the easiest sessions to postpone is Week 7, Run 1.

Week 7 is where the walk recoveries disappear. The first session is 15 minutes of continuous easy running. On paper, that is less running than Week 6, which uses four five-minute blocks for 20 minutes in total. It may not feel easier, because there is no scheduled walk break waiting after each block.

Moving the session to tomorrow does not always help. The reluctance often moves with it.

Shrink the commitment instead. Go outside. Complete the five-minute warm-up walk. Run the first few minutes, and give yourself permission to stop.

Once you are moving, you may finish. If you do not, log what happened anyway. A short or difficult run gives you evidence for the next decision. A blank record gives you nothing to work with.
