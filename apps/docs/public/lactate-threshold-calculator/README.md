# Lactate threshold product previews

- `zones-*.png`: the mobile app's `SingleSelectContent` and `ProfileZonePreview` components rendered with the existing `scripts/audit-zone-previews.mjs` fixture (Joe Friel / LTHR). Screenshots are 393 × 852 CSS pixels at 2× resolution. Navigation chrome is a web preview adapter; values are illustrative fixtures, not an athlete's assessment. The capture adapter loads the matching Simplified Chinese, Traditional Chinese, English, and Japanese app translations.
- `plan-*.png`: existing localized `apps/mobile/design/app-store/*/demo-sources/02-plan.png` product screenshots showing a planned tempo run and its threshold-pace segment.

The page composes these separate views with CSS phone frames. They illustrate configuring training zones and using intensity in a plan; their sample values are independent of the calculator result.
