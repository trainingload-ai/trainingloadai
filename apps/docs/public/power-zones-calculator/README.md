# Power zones calculator product previews

`phone-pmc-dark-{en,zh,zh-hant,ja}.webp` reuse the existing training-load PMC captures in `apps/docs/public/training-load-calculator/`. Those are iPhone simulator screenshots of the `app-store-demo` fixtures (CTL 52, ATL 44, TSB +8 on 2026-08-14), not an athlete's account and not a power-zone settings screen.

The web collage reuses `/ftp-calculator/web-pmc.webp`. The hero reuses the localized FTP calculator recording and Apple Watch assets, which show live workout recording rather than a power-zone chart.

A power-zone settings screenshot from the product UI is still needed. This environment could not capture one: the demo power overview had no zone data, and account pages were out of scope.
