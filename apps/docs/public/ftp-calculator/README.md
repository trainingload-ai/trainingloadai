# FTP calculator product previews

- `phone-*.webp`: existing Today screen screenshots used in the lower product section.
- `web-pmc.webp`: existing web training-load dashboard screenshot.
- `recording-*.png`: localized product previews rendered from the mobile app's `RecordingRealtimeCard` and `DashboardPage` components, with illustrative workout data and the Watch recording notice. These are component previews, not captures of an athlete's activity. Four languages: English, Simplified Chinese, Traditional Chinese, Japanese.
- `watch-*.png`: native Apple Watch simulator captures of the existing `live-metrics` App Store screenshot scenario, in the same four languages.

The phone and watch are composed with CSS device frames on the page. The previews show live recording; they do not depict a completed FTP assessment or imply that GPS-only recordings contain cycling power.
