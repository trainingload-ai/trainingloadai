# Workout editor plan screenshots

Phone plan screens used on `/workout-editor`. These are real Trainingload plan
screens with demo data, not a redrawn interface and not a private account.

Source files:

- `apps/mobile/design/app-store/en/demo-sources/02-plan.png`
- `apps/mobile/design/app-store/zh-Hans/demo-sources/02-plan.png`
- `apps/mobile/design/app-store/zh-Hant/demo-sources/02-plan.png`
- `apps/mobile/design/app-store/ja/demo-sources/02-plan.png`

Each PNG is 1320 × 2868. This directory stores a WebP encode of that file
(`plan-en.webp`, `plan-zh.webp`, `plan-zh-hant.webp`, `plan-ja.webp`) so the
page can use `next/image`. The sample plan is demo content, not a real athlete.
