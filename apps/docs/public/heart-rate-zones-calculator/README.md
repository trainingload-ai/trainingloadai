# Heart-rate zone product preview

The calculator hero and promo reuse `apps/docs/public/lactate-threshold-calculator/zones-*.png`.

Those files are the mobile zone settings screen from `scripts/audit-zone-previews.mjs`, rendered at 393 × 852 CSS pixels (2× PNG). The fixture is Joe Friel's cycling / general LTHR table. The person in the screenshot is sample data, not a Trainingload user, and the numbers are not this calculator's live result.

A capture from a real device can replace this reuse later. Do not treat the current PNG as that capture.
