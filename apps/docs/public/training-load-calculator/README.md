# Training load calculator product previews

`phone-pmc-{en,zh,zh-hant,ja}.webp` are native iPhone 17 Pro Max simulator captures of the existing PMC screen, exported with **Device Hub → Screenshot** at 1320 × 2868 and encoded as WebP (quality 92).

Captured on 2026-09-28 using the isolated `ai.trainingload.mobile.coachpreview` development app and the existing `app-store-demo` fixtures, fixed at 2026-08-14. Values (CTL 52, ATL 44, TSB +8) are illustrative fixture data, not an athlete's account. Dark appearance was enabled temporarily for capture; no mobile product code changes are required.

The web image reuses `/ftp-calculator/web-pmc.webp`, the existing dark training-load dashboard preview. Phone and web show separate example views. The hero reuses the existing localized iPhone recording and Apple Watch assets.
