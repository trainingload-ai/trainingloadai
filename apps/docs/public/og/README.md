# Open Graph assets

The SVG files in this directory are editable source assets. Their PNG counterparts are the production Open Graph images referenced by page metadata.

Regenerate both formats from the repository root:

```bash
pnpm --dir docs og:generate
```

The generator keeps tool cards at `1200 × 630` and uses a shared TrainingLoad.ai introduction-card layout.

The homepage preview is `home.jpg` (`2400 × 1260`, 2× the 1200 × 630 social card). It is the product screenshot banner, not generated by this script. Bump `?v=` in `apps/docs/src/lib/social-metadata.ts` after replacing it so X/LinkedIn refetch the file.

`brand-card-square.png` remains a `600 × 600` mark-only fallback for compact cards that still request a square image.
